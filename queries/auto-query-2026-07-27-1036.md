# 에피소드 경계에 최적화된 메모리 인프라의 근본적 한계

## 1. 기존 진단 체계의 에피소드 내 한정성

Wiki에 등록된 메모리 관련 진단 도구들은 모두 에피소드 내부에 국한되어 있습니다:

- [[adema]]는 "지식 상태 오케스트레이션"을 다루지만, 이는 개별 에피소드 내에서의 지식 상태 위반을 진단하는 수준에 머뭅니다. 긴 컨텍스트 내에서의 일관성은 다루되, 에피소드를 넘어서는 지식의 지속성은 설계 범위 밖입니다.
- [[agentic-vlm]]에 기록된 Three-Step Nav의 실증 역시, MLLM 에이전트의 구조적 실패(경로 이탈·조기 정지)를 **단계별 판단과 다단계 기획 사이의 간극**으로 진단합니다. 이는 메모리의 누적·재사용 문제가 아니라, 단일 에피소드 내 추론 구조의 문제로 프레이밍됩니다.

이들 진단은 공통적으로 "에피소드가 시작될 때 상태가 초기화된다"는 전제를 무비판적으로 수용합니다.

## 2. 에피소드 리셋이 은폐하는 병목

최근 논문 *"Beyond Episodic Evaluation: Memory Architectural Bottlenecks in Sequential Embodied Question Answering"*이 지적하듯, 에피소드 간 상태 리셋을 전제한 평가는 세 가지 병목을 체계적으로 은폐합니다:

**첫째, 누적 메모리 오염(Cumulative Memory Contamination).** 에피소드가 독립적으로 평가되면, 이전 에피소드의 잔여 정보가 후속 에피소드의 추론에 미치는 간섭이 측정되지 않습니다. [[adaptive-forgetting]]이나 [[adaptive-forgetting-as-function]] 같은 엔티티가 Wiki에 존재하긴 하지만, 이들은 에피소드 내 적응적 망각을 다룰 뿐, 에피소드 간 망각의 **필요성과 실패**를 다루지 않습니다. 에피소드 리셋 전제하에서는 망각이 설계 문제가 아니라 자동으로 해결되는 것처럼 보입니다.

**둘째, 재사용 불능(Reuse Failure).** 연속 환경에서는 이전 에피소드에서 획득한 공간 지도, 객체 위치 기억, 사용자 선호 등을 재사용해야 합니다. 그러나 에피소드 평가에서는 매번 처음부터 구축하는 비용이 정상적인 연산량으로 간주됩니다. [[agent-knowledge-separation]]이 다루는 지식 분리 문제가, 에피소드 간 전이가 아닌 에피소드 내 모듈 간 분리에만 초점을 맞추면 이 병목은 보이지 않습니다.

**셋째, [[belief-state-grounding]]의 에피소드 경계 붕괴.** 연속 환경에서는 에이전트의 믿음 상태가 에피소드 경계를 넘어 지속·갱신되어야 합니다. 그러나 에피소드 리셋 평가에서는 믿음 상태가 매번 tabula rasa에서 시작되므로, grounding의 지속성이 평가 대상 자체에서 소외됩니다.

## 3. 평가 방법론이 인프라 설계를 역지배하는 구조

이 문제의 본질은 [[benchmark-specification-gap]]의 특수한 형태입니다:

> 벤치마크가 에피소드 경계를 규정하면, 메모리 인프라는 그 경계 내에서만 최적화된다. 그리고 그렇게 최적화된 인프라는 다시 "에피소드 내에서는 잘 작동한다"는 결과를 낳아, 벤치마크의 타당성을 재생산한다.

이 순환 구조 속에서 WorldDB, MeMo 같은 저장-검색 시스템은 **에피소드 내에서의 검색 정확도**를 극대화하도록 튜닝됩니다. 교차 에피소드 검색의 충돌(conflict), 구식화(staleness), 일관성(consistency) 문제는 벤치마크에 없으므로 최적화 대상에서 제외됩니다.

[[closed-loop-evaluation]]이 Wiki에 존재하는 것은 이 문제에 대한 인식의 싹이 있음을 보여주지만, 현재로서는 에피소드 내 폐루프와 에피소드 간 폐루프의 구분이 명확히 현현되지 않았습니다.

## 결론

기존 메모리 인프라는 실제 배포 환경이 아닌 **'에피소드 경계'라는 인공적 구분에 최적화된 것**이 맞습니다. 이는 단순한 누락이 아니라, [[benchmark-specification-gap]]이 인프라 설계를 역지배하는 구조적 문제입니다. 에피소드 리셋이 메모리 관리의 가장 어려운 부분(누적 오염, 재사용 불능, 믿음 상태 단절)을 **측정 불가능하게 만들어** 문제가 없는 것처럼 보이게 합니다.

"Beyond Episodic Evaluation" 논문이 제기하는 도전은 개별 메모리 모듈의 성능 개선이 아니라, **평가 단위 자체를 에피소드에서 연속 스트림으로 재정의**해야 한다는 메타-레벨의 요구입니다. 이것이 충족되지 않으면, 어떤 메모리 인프라 개선도 에피소드 경계 안에서의 국소 최적점에 갇힐 위험이 있습니다.

## 핵심 통찰

에피소드 경계에 최적화된 메모리 인프라의 한계는 개별 모듈의 결함이 아니라, 평가 단위 자체가 인프라 설계를 역지배하여 문제를 측정 불가능하게 만드는 구조적 순환의 산물이다.
