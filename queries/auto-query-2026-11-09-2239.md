## 2. 합성 전제가 붕괴하는 세 가지 구조적 근거

### (a) 접근-계획 간극: 샘플 있음 ≠ 최적 선택 가능

[[access-planning-gap]]의 Near-Optimal Reinforcement Learning with Multi-Step Transition Lookahead (2026-09-13)이 이 질문에 가장 직접적인 형식적 근거다:

> "정보 접근(전망 관찰)과 계획 능력(최적 행동 산출) 사이의 간극을 계산 복잡도 언어로 형식화… ℓ-스텝 예지 접근은 관측 데이터를 제공하지만 이를 최적 결정으로 번역하는 것이 **구조적으로 어려운 영역이 존재**"

턴 수준 Best-of-N의 N개 샘플은 '정보 접근'일 뿐이다. 이를 에피소드 수준 최적으로 번역하는 선택기는 별개의 능력이며, ℓ=1(턴 수준) 예지에서 이 간극이 가장 크다. **전제가 성립하지 않는 영역의 존재가 계산 복잡도 수준에서 증명되어 있다.**

### (b) 지연 보상: 턴 단위 신용 배분의 불안정성

[[adaptive-credit-granularity]]의 HySTAR (2026-09-29)가 핵심이다. 다중 스텝 설정에서 신용 배분이 불안정하여 **앵커드 하이퍼그래프라는 특수 구조가 필요했다는 사실 자체**가, "턴별 국소 보상으로 턴 선택을 평가하는 것"이 지연 보상 체제에서 기본적으로 불안정함을 시사한다. Best-of-N 선택기는 사실상 **암묵적인 턴 단위 신용 배분기**인데, 그 신용 모델의 타당성이 검증되지 않은 채 가정되고 있다.

### (c) 상태 종속성: 선택이 상태를 바꾸고 상태가 선택을 바꿈

- LLM 에이전트에서 과거 턴의 선택은 삭제되지 않는다. [[attention-carried-conversational-state]]와 [[autocompaction]]이 보여주듯, 선택 결과는 컨텍스트 상태로 **물리적으로 누적**되어 이후 후보 분포를 변형시킨다 — 턴 독립성 가정이 구현 수준에서 붕괴한다.
- [[adaptive-validity]]의 Artificial Id (2026-09-12)는 "'현재 행동이 여전히 타당한가'를 **지속 재평가**"하는 판단을 요구한다. 턴 시점에 국소 최적으로 선택된 행동은 상태가 드리프트하면서 유효성이 감쇠하며, 턴 단위 선택은 이 재평가를 구조적으로 생략한다.
- [[attractor-state-evaluation-confound]]가 경고하듯, 착상 상태에서의 턴별 승리는 일시적 이점일 수 있어 국소 평가가 착시를 낳는다.
- [[adaptive-forgetting]]의 Benchmarking World Models for Continual Learning (2026-09-22)은 망각 비용이 "구성적 태스크 **재방문 시점**"에 관측됨을 보인다 — 턴 선택의 대가는 에피소드 후반에야 관측되는 **지연 관측성**의 실증이다.

## 3. 전제가 성립하는 경계 조건

턴 단위가 옹호될 조건도 Wiki에서 질적으로 특정된다:

- **턴별 검증 가능 보상이 밀집**하고 행동의 미래 상태 효과가 약할 때
- [[agreement-based-reliability]]: N개 샘플 간 합동이 정답과 상관될 때 선택 신호가 턴 수준에서 신뢰 가능

- [[action-level-speculation]]: 최적화 단위를 액션 수준까지 내리는 시도가 이미 존재하며, 단위 선택 자체가 설계 변수임을 보여줌

## 4. Generator-Selector 결합 자체의 문제

- [[audit-oracle-self-reference]]: 선택기가 생성기와 동일 모델이면 자기 참조 검증 문제 — BoN의 선택 신호가 독립 오라클이 아닐 때 신뢰성이 붕괴한다.
- [[agent-voting]]: 턴 수준 BoN은 사실상 샘플 간 투표인데, 다수결이 에피소드 최적과 일치한다는 보장은 없다.
- **비용 구조**: 매 턴 ×N 샘플링은 [[adaptive-inference]]의 SpecKV 철학("필요할 때만 할당")과 정면 충돌한다. 최근 논문 **Context–Answer Metamodels**(단일 컨텍스트에서 답변 변동을 첫 토큰 전에 예측)는 "샘플링 전에 선택 결과를 예측"하는 방향으로, 균일 BoN의 낭비를 제거할 단서다. **Visual Token Routing** 역시 CUA의 장기 과제에서 턴당 비용이 실행 자체를 제한함을 보여, 균일 턴 단위 스케일링의 경제성 문제를 확인한다.

Wiki가 이미 보유한 에피소드/궤적 수준 축들이 답의 뼈대를 제공한다:

- [[adaptive-trajectory-steering]] — 궤적 수준 조정 축 존재
- [[adaptive-control-hierarchy]] — 제어 계층화 원리
- [[accumulation-budget-design]] — 예산을 누적 관점에서 설계
- [[adaptive-transition-discovery]]의 SBS (2026-09-07): "사전 정의된 규칙이 아닌 **관찰 결과(증거 가용성)에 따라 적응적으로** 배치" — 이 원리를 추론 시간 스케일링에 이식하면 **균일한 매-턴 BoN이 아니라 증거가 있는 중요 턴에서만 BoN을 트리거**하는 설계가 도출된다

**종합 답변**: 턴 수준 BoN은 에피소드 수준 정책의 내부에서 **탐색 연산자/제안 분포**로 위치해야 하며, 선택 신호의 신뢰 범위와 행동의 상태 파울 효과가 커질수록 최적화 단위를 궤적으로 상향해야 한다. [[adaptation-axis-misalignment]]의 관점에서, 지배적 축이 에피소드인 과제에 턴 축으로 적응하는 것 자체가 축 불일치 오류다.
