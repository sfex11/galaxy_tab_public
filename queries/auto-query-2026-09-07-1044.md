## 핵심 답변

재정의가 필요합니다. 다만 "추론의 주체 → 오케스트레이션 인터페이스"라는 단순 교체가 아니라 **추론 주체의 분할**로 정밀화해야 합니다. SENTINEL-RL은 LLM이 '보장을 수반하는 계산적 추론'의 *독점적* 주체라는 전제를 무너뜨리지만, LLM이 '개방형 세계에 대한 의미론적 판단'을 수행하는 주체라는 지위는 오히려 강화합니다. 그 결과 LLM은 (1) 전용 추론기들을 호출·해석하고 그 산출물을 의미론적으로 번역하는 인터페이스이자, (2) 형식화 불가능한 판단의 최종 담지자라는 **이중 역할**로 재정의됩니다.

### 1. SENTINEL-RL이 공격하는 것: 전제의 양단 침식

위키의 현재 프레임은 두 개의 암묵적 전제 위에 섭니다.

- **전제 A (하네스 중립성)**: [[agentic-harness-engineering]]에서 Crab은 결함 내성·롤백·분기를 구현하는 **인프라 계층**으로 규정됩니다. "Semantics-Aware"라는 명칭 자체가 LLM이 만든 의미론이 1차이고 C/R 런타임이 이를 보존·서빙하는 2차 계층임을 전제합니다. [[agent-os-semantic-gap]]도 상태 의미론의 경계 문제이지, 추론 수행의 경계 문제는 아닙니다.
- **전제 B (기능 범주의 단일 주체)**: [[agentic-security-investigation]]은 "LLM 에이전트가 보안 경보를 조사하는" 기능 범주로, 조사 행위의 주체가 LLM입니다.

SENTINEL-RL의 두 제한은 이 전제들을 **양단에서 동시에** 침식합니다.

- **입력측**: 수천 호스트 위상 그래프가 컨텍스트 윈도우를 초과 — 이는 검색·요약으로 완화 가능한 정보 과잉이 아니라, **추론 대상 자체가 LLM의 표현 용량 밖**에 있다는 판정입니다.
- **출력측**: 자유 형식 생성이 행동 보장을 못 함 — LLM의 출력 모달리티가 SOC 행동의 안전 요건과 모달리티 불일치를 겪습니다.

따라서 이 오프로딩은 "컨텍스트를 늘리거나 RAG를 붙이면 되는" 최적화가 아니라, **어떤 추론이 원리적으로 LLM 내부에 있을 수 없는가에 대한 아키텍처 판정**입니다.

### 2. 위키 내부에 이미 축적된 수렴 증거

'LLM=단일 추론 주체' 관점은 SENTINEL-RL 이전부터 위키 전반에서 침식되어 왔습니다.

| 논문 | 축 | 인터페이스화의 형태 |
|---|---|---|
| Continuous Actions from Discrete Minds ([[action-tokenization]]) | 출력 | VQ-VAE가 연속·물리 제약 공간을 이산 토큰 어휘로 번역하는 '표현 계약' — VLM의 이산 추론과 자율주행의 연속 물리를 LLM 직접 추론이 아닌 **인터페이스가** 연결 |
| RunAgent ([[agentic-harness-engineering]]) | 출력 | 자연어 계획을 제약 유도 런타임이 해석·집행 — **LLM이 제안하고, 런타임이 보장**하는 분업 |
| Tool Attention Is All You Need ([[aggregate-pipeline-serving]]) | 시스템 | 병목이 개별 LLM 호출이 아닌 스키마 축적으로 결정 — 성능 결정축이 이미 LLM 밖 |
| SpecKV ([[adaptive-inference]]) | 디코딩 | 추측 길이 γ조차 모델이 아닌 외부 적응기가 선택 — 생성 자체가 위임된 제어 대상 |
| The Natural Language Interaction Protocol ([[agentic-language]]) | 프로토콜 | 자연어가 추론의 매개가 아니라 에이전트 간 **접속 규격**으로 격상 |
| TRACE ([[agent-execution-semantic-opacity]]) | 투명성 | LLM 실행의 인과를 LLM이 아닌 실행 시점 문서화가 담보 |

공통분모가 명확합니다: **형식적 보장이나 물리적 정합이 요구되는 순간, 해당 기능은 인터페이스·모듈·런타임으로 이전된다.** SENTINEL-RL은 이 패턴을 행동 출력과 디코딩 제어를 넘어 **도메인 지식 추론(위상)**으로 확장한 사례입니다.

### 3. 그러나 '인터페이스로만' 재정의하면 놓치는 것

Telecom RCA 논문([[agentic-security-investigation]])이 보였듯, 관찰→가설→인과 귀인→검증의 진단 루프는 도메인 불변입니다. SENTINEL-RL과 겹쳐 보면: **루프는 그대로 남지만 구현이 이질화됩니다.** 수천 호스트 위상에 민감한 단계(도달성·영향 반경 판정)는 전용 모듈로 이전되고, 가설의 언어적 구성·우선순위 판단·분석가 커뮤니케이션은 LLM에 잔류합니다.

- LLM이 잃는 것: 보장 수반 계산의 **독점**
- LLM이 유지하는 것: 무엇을 조사할지, 모듈 결과를 어떤 가설로 해석할지, 경보를 어떻게 설명할지라는 **형식화 불가능한 판단**

따라서 재정의된 LLM은 단순 라우터가 아니라 **이질적 추론기들 사이에서 의미를 번역하고 판단을 담당하는 '의미 인터페이스'**입니다. 라우팅은 오케스트레이션의 최소 정의이고, 번역과 판단은 LLM만의 잔여 핵심입니다.

### 4. 강제되는 이론 수정: 하네스 중립성 명제의 붕괴

가장 중요한 귀결은 질문 전제 자체에 대한 수정입니다. Crab의 하네스는 중립적(의미 보존)이었지만, SENTINEL-RL의 위상 모듈은 **결정적 추론을 수행**합니다 — 모듈이 틀리면 에이전트 결론이 틀어집니다. 하네스는 더 이상 '중립적 실행 인프라'가 아닙니다. 이로써:

- [[algebraic-harness]]가 암시하던 '형식 보장의 하네스 내재화' 노선이 SENTINEL-RL에서 실체화됩니다.
- SENTINEL-RL은 [[agentic-security-investigation]](기능)과 [[agentic-harness-engineering]](구조)의 **경계에 걸친** 논문으로 재분류되어야 합니다.
- [[capability-safety-inseparability]]: 위상 모듈은 공격 경로를 찾는 능력 구성요소이자 행동을 제한하는 안전 구성요소로 한 몸입니다.
- [[auditability-as-scaling-requirement]]: 모듈화된 보장 계층이 엔터프라이즈 규모의 감사 가능성을 제공합니다.
- [[agent-loop-as-computation]]: 에이전트를 루프로서의 계산으로 보면, SENTINEL-RL은 루프 구성 성분을 이질화합니다. 에이전트의 정의 단위가 '모델'에서 **이질적 회로(모델+모듈+계약)**로 이동합니다.
- SWE-Gate("Passing Functional Tests Is Not Enough…")와 결합하면, 분해된 에이전트에서 보장 계층 그 자체가 새로운 평가 대상이 됩니다.

### 5. 새로 발견된 개념·연결 (위키 반영 제안)

1. **보장 수반 추론 오프로딩 경계**: 오프로딩 트리거의 두 조건 — (i) 추론 대상의 표현 용량 초과, (ii) 출력의 형식적 보장 요구. Crab(중립 지원)·SpecKV(실행 최적화)와 달리 SENTINEL-RL은 **결정적 추론의 이전**이라는 최초 사례. 이 판별 기준 자체를 개념화할 것.
2. **추론 수반 인프라 (reasoning-bearing infrastructure)**: [[agentic-harness-engineering]] 정의 갱신 — 하네스가 결정적 추론을 수행하는 순간 중립성 명제는 유지 불가.
3. **구조 불변·구현 이질 진단 루프**: Telecom RCA × SENTINEL-RL의 교차점 — 루프 구조는 도메인 불변, 구현은 이질화.
4. **인터페이스 계약의 대칭성**: [[action-interface-latent-alignment]](행동 출력측 계약)과 SENTINEL-RL(지식·보조 추론 입력측 계약)을 하나의 '계약' 축으로 통합 가능.
5. **주체의 이원화**: '추론 주체 vs 인터페이스' 이분법 대신 **판단 주체 / 계산 주체** 분할을 독립 개념으로.

### 결론

그렇습니다 — 단, 정밀하게: LLM은 추론의 **배타적** 주체일 수 없으며, 이질적 전문 추론기들을 오케스트레이션하는 인터페이스로 재정의되어야 합니다. 그러나 그 인터페이스는 라우터가 아니라 (a) 모듈 간 의미 번역, (b) 형식화 불가능한 판단, (c) 개방형 세계와의 접속을 담당하는 **의미 인터페이스이자 판단 주체**입니다. SENTINEL-RL은 [[agentic-security-investigation]] 내부의 개별 논문이 아니라, 위키의 'LLM 중심 + 중립 인프라'라는 상위 프레임 자체에 대한 반례로 기록될 가치가 있습니다.
