# Auto Query: 현재 Wiki에서 적응적 추론(adaptive-inference)은 SLM이 처리할 수 없는 난이도를 LLM에 위임하는 계층적 계산 할당으로 발전해 왔는데, 동등한 규모의 오픈 가중치 SLM들을 오케스트레이션하여 단일 폐쇄형 LLM을 상회하는 성능을 달성한다면 적응적 추론의 본질적 목표가 '어떤 모델에 계산을 맡길 것인가'가 아니라 '동등한 모델 간 인지적 이질성을 어떻게 구성하고 조율할 것인가'로 근본적으로 전환되어야 하는가?

**날짜**: 2026-07-26
**대상 논문**: Small, Free, and Effective: Orchestrating Open-Weight Small Language Models to Outperform Single LLM for Malware Analysis
**선택 이유**: 기존 적응적 추론이 모델 라우팅과 추측 디코딩 길이 선택 등 '계층적 계산 예산 할당'에 집중한 것과 대비되어, SLM 간 오케스트레이션이 LLM 성능 한계를 넘어선다는 발견이 적응적 추론 패러다임의 근본 전제(계층적 규모 의존성)를 도전하기 때문이다.

## 1. SpecKV가 이미 보여준 결정 차원의 확장

[[adaptive-inference]] 엔티티에 기록된 **SpecKV** 논문은 결정적 단서를 제공한다:

> 기존 컨텍스트 기반 적응(CADENCE 등)이 외부 환경에 반응했다면, SpecKV는 압축이라는 내부 시스템 상태에 반응하는 적응의 새로운 유형을 제시한다.

즉, 적응적 추론의 결정 축이 이미 **"어떤 모델에 위임할 것인가"(외부 라우팅)**에서 **"내부 상태에 어떻게 반응할 것인가"(γ 선택)**로 이동했다. 이는 모델 간 계층적 위임이라는 원래의 프레임이 이미 해체되기 시작했음을 의미한다.

## 2. 동등 모델 오케스트레이션이 파생시키는 근본적 질문 변화

동등 규모 SLM들의 오케스트레이션이 단일 폐쇄형 LLM을 상회한다면, 적응적 추론이 해결해야 할 문제는 완전히 재구성된다:

| 기존 패러다임 | 전환된 패러다임 |
|---|---|
| 난이도 추정 → 모델 위임 | 인지적 이질성 구성 → 조율 메커니즘 |
| 계산 비용의 최적화 분배 | [[agent-epistemic-pluralism]]의 설계 |
| 단일 의사결정자의 라우팅 정확도 | [[belief-aggregation]]의 건전성 |
| SLM ↔ LLM의 비대칭적 계층 | 동등 모델 간 [[agent-coordination]]의 대칭적 구조 |

핵심은 **"어떤 모델이 더 적합한가"가 아닌 "동등한 모델들이 어떻게 다르게 생각하게 만들고, 그 차이를 어떻게 수렴시킬 것인가"**가 된다.

## 3. Agora-Opt와 MASPO가 이미 구조화한 이중 축

[[agora-opt]] 엔티티의 기술이 이 전환의 구체적 설계 공간을 이미 제시하고 있다:

> Agora-Opt가 런타임 메모리·토론 구조를 통해 다중 에이전트 정렬을 달성했다면, MASPO는 프롬프트 설계 시점에서 사전 정렬을 보장하는 상보적 경로를 제공하여, 런타임 정렬 메커니즘의 부담을 설계 시점으로 분산시킨다.

이는 동등 모델 간 인지적 이질성 조율이 **설계 시점(사전 정렬)과 런타임(토론 구조)**이라는 이중 축에서 구조화될 수 있음을 보여준다. 계층적 위임이 필요 없는 세계에서는, 적응적 추론이 이 이중 축 사이의 **동적 균형점을 찾는 문제**로 재정의된다.

## 4. 새로운 연결 발견

이 질문을 통해 다음 연결이 새롭게 드러난다:

- **[[adaptive-inference]] → [[agent-epistemic-pluralism]]**: 적응적 추론의 결정 대상이 "모델 선택"에서 "인식론적 다원성의 구성"으로 전환
- **[[adaptive-inference]] → [[belief-aggregation]]**: 추론 적응의 출력이 "위임 결정"에서 "신념 집계 방식의 동적 선택"으로 변화
- **[[adaptive-inference]] → [[bayes-consistent-agentic-orchestration]]**: 동등 모델 간 조율의 정당성 기준이 베이즈 일관성으로 정식화될 수 있음
- **[[adaptive-bottleneck-migration]]과의 관계**: 병목이 "모델 간 라우팅 오류"에서 "이질성 수렴 실패"로 이동함을 나타낼 가능성

## 요약

SpecKV가 이미 모델 라우팅을 넘어 내부 상태 반응으로 적응의 결정 차원을 확장했고, Agora-Opt/MASPO가 동등 에이전트 간 정렬의 이중 축(설계 시점 vs 런타임)을 구조화했다. 따라서 동등 규모 SLM 오케스트레이션이 단일 폐쇄형 LLM을 상회하는 시점에서 적응적 추론의 본질적 목표는 **명확하게 "인지적 이질성의 구성과 조율"로 전환**되어야 하며, 이는 Wiki의 기존 논문들이 이미 부분적으로 조명한 방향이다.
