## 1. 적응의 축이 '계산'에서 '표현'으로 이동 중이라는 구조적 증거

[[adaptive-inference]] 항목은 적응적 추론의 진화를 두 단계로 기록하고 있다:

- **1단계(CADENCE 등)**: 외부 환경에 반응한 모델/라우트 선택
- **2단계(SpecKV)**: 압축이라는 **내부 시스템 상태**에 반응하는 추측 길이(γ) 선택

시각적 필요도 라우팅은 이 논리의 **3단계**다. SpecKV가 "압축 상태"라는 내부 상태에 주목했다면, 모달리티 라우팅은 내부 상태 중에서도 **기억의 정보 손실 상태** — 텍스트 요약이 temporal structure를 얼마나 잃었는가 — 에 반응한다. 적응의 결정 공간이 "얼마나 계산할 것인가(γ, 사고 길이)"에서 **"무엇을 표현할 것인가(모달리티)"** 로 확장되는 것이며, 이는 이미 [[adaptive-inference]]가 보여준 확장 경로(외부 환경 → 내부 상태)의 자연스러운 연장이다.

## 2. 핵심 실증 근거: Caption-once, Frames-on-Demand

[[absence-as-headroom-signal]] 항목의 최근 논문 목록에 정확히 이 논문이 있다:

> **"Caption-once, Frames-on-Demand: Visual-Need Routing for Budget-Aware Agentic Long Video Understanding"** — 엣지 디바이스의 장시간 비디오 이해는 계산·대역폭 예산 하에서 이루어지며, 비주얼 토큰 서브샘플링은 시간 구조를 잃고, 텍스트 전용 비디오 메모리는 [시각적 필요를 충족하지 못한다]

이 논문은 질문의 가정 — 질의별 시각 필요도에 따른 텍스트 요약 ↔ 원본 프레임 동적 라우팅 — 을 **이미 구현한 사례**다. 같은 목록의 **"Beyond One-Size-Fits-All: Sample-Adaptive Strategy Routing for Vision Token Pruning in MLLMs"** 은 한 걸음 더 나아가, 비주얼 모달리티 *내부*에서도 샘플별 전략 라우팅이 필요함을 보여준다. 즉 모달리티 선택 후에도 토큰 수준 결정이 남는다. **"Why Is Video Still So Expensive?"** 서베이는 이러한 효율 메커니즘들이 하나의 분류 체계로 정리되고 있음을 시사한다.

## 3. 이론적 뼈대: 기억 = 표현 계약

[[action-tokenization]] 항목의 *Continuous Actions from Discrete Minds* 분석이 결정적 단서를 제공한다. VQ-VAE 액션 토크나이저는 연속 행동 공간을 이산 토큰 어휘로 번역하는 **'표현 계약'**이며, "토크나이저 설계가 곧 물리 제약의 인코딩 방식을 결정"한다.

이 프레임을 기억에 이식하면:

- 텍스트 요약을 기본 단위로 삼는 것은 **하나의 표현 계약** (시공간 정보를 언어 어휘로 손실 압축)
- 원본 프레임을 기본 단위로 삼는 것은 **또 다른 계약**
- 질의별 모달리티 선택은 이 계약을 **저장 시점에 고정하지 않고 검색 시점까지 위임**하는 것

즉 기억의 기본 단위는 "토큰 vs 모달리티"의 이분법이 아니라, **질의 조건부로 체결되는 표현 계약의 선택**으로 재정의된다. 같은 항목의 *Show-Harness: Just a VLM Agent Can Play Robots* 역시 VLM 에이전트가 행동 인터페이스의 표준이 되고 있음을 보여주어, 기억이 시각 지각과 직접 인터페이스해야 할 요구를 뒷받침한다.

## 4. 운영 메커니즘: 부재가 라우팅 신호가 된다

[[absence-as-headroom-signal]] (부재의 이중 기능: 롤백 트리거·여유공간 신호)은 재정의의 **작동 원리**를 제공한다. 텍스트 전용 메모리에서 시각 정보의 부재는:

1. **롤백 트리거**: 요약으로 답이 불가하면 원본 프레임 fetch (Frames-on-Demand의 정확한 작동 방식)
2. **여유공간 신호**: 어떤 질의 유형이 반복적으로 프레임을 요구하는지가 표현 정책 개선의 방향을 제시

부재가 수동적 결손이 아니라 능동적 라우팅 신호가 되는 순간, 기억은 저장 인프라에서 **적응 시스템**으로 성격이 바뀐다.

## 5. 타당성 재평가의 세 번째 확장

[[adaptive-validity]] 항목은 *Artificial Id*를 통해 적응적 타당성 판단이 **메모리 도메인 → 행동 도메인**으로 확장되었음을 기록한다. 모달리티 라우팅은 이 확장의 **세 번째 다리**다: "현재 *표현*이 이 질의에 대해 여전히 타당한가"의 지속 재평가. 저장 시점에 선택된 모달리티는 검색·사용 시점에 재검증되어야 한다.

또한 [[adaptive-transition-discovery]](SBS)는 '적응'의 판단 기준을 **시각적 증거 가용성**으로 구체화한 선례다 — 시각 필요도 추정 역시 사전 정의된 규칙이 아니라 VLM 관찰에 기반해야 한다는 방법론적 원칙을 제공한다.

## 6. 반론과 정제: '대체'가 아니라 '이중 축'

모달리티 선택이 토큰을 기본 단위로 **대체**해서는 안 되는 이유가 두 가지 있다.

- **두 축은 직교적이다**: 모달리티 선택은 표현 계층의 결정(무엇을 유지할까), 토큰 예산은 계산 계층의 결정(선택된 표현을 얼마나 처리할까). *Beyond One-Size-Fits-All*이 보여주듯 프레임을 선택한 뒤에도 프레임 내 토큰 프루닝 결정이 남는다. 기본 단위는 **(모달리티, 예산)의 쌍**이다.
- **필요도 판단 자체가 메타 추론 비용을 요구한다**: "Caption-once"가 캡션을 한 번만 생성하는 설계는 바로 이 비용의 절감이다. 필요도 추정의 캐싱 + on-demand fetch의 하이브리드가 현실적 설계다.

## 7. 새로 발견된 개념·연결 (Wiki 신규 항목 후보)

**신규 슬러그 후보** (슬러그 목록에 없으므로 링크 없이 제안):

1. **visual-need-routing** — *Caption-once, Frames-on-Demand*에서 직접 추출. 질의 조건부 모달리티 라우팅.
2. **memory-representation-contract** — [[action-tokenization]]의 '표현 계약'을 메모리로 일반화.
3. **compression-aware-memory-routing** — SpecKV의 압축 인지 γ 선택을 표현 선택으로 이식 ([[adaptive-inference]]의 축 확장).
4. **absence-driven-frame-retrieval** — [[absence-as-headroom-signal]]의 메모리 도메인 구체화.

**기존 항목 간 신규 연결**:

- [[adaptive-inference]] ↔ [[action-tokenization]]: "계산 예산의 적응"과 "표현 계약의 설계"가 모달리티 라우팅에서 수렴한다. 적응적 추론의 결정 공간에 표현 선택이 편입됨.
- [[adaptive-validity]]: 메모리 → 행동에 이은 **표현 도메인으로의 3차 확장** 사례로 기록 가능.
- [[adema]]: 지식 상태 오케스트레이션은 이 새 단위 아래에서 **텍스트 모달리티에 특화된 특수 사례**로 재위치된다. 궁극적 일반화 방향은 "지식 상태 → 모달리티 인덱스 상태 오케스트레이션"이다.

**요약**: 질문의 직관은 옳다. 다만 정확히는 *기본 단위의 교체*가 아니라, [[adaptive-inference]]가 추적해온 적응 축의 확장(라우팅 → γ → 사고 길이 → **표현**)에 기억이 편입되는 것이며, 이때 기억은 [[action-tokenization]]이 행동에 대해 이미 정립한 '표현 계약'의 메모리판으로 재정의된다.

## 핵심 통찰

기억의 기본 단위는 저장 시점에 고정된 표현이 아니라 질의 조건부로 검색 시점에 체결되는 표현 계약이며, 모달리티(표현 계층)와 토큰 예산(계산 계층)의 직교적 쌍 (모달리티, 예산)으로 재정의된다.
