## 핵심 논거: "Utility Under Attack"의 실증

최근 논문 **"Utility Under Attack: Agent Memory Poisoning and the Limits of Content Screening and Provenance Ranking"**이 이 질문에 대해 거의 직접적인 답을 제공합니다. 해당 연구는 다음과 같이 명시합니다:

> "Persistent memory makes false information durable: once a false statement is stored, it can be retrieved into future sessions that match it."

이 문장은 [[entities/adema.md|adema]]나 [[entities/agora-opt.md|agora opt]] 같은 메모리 아키텍처가 추구하는 '저장·검색의 정교화'가 방어의 충분조건이 아님을 함의합니다. 콘텐츠 스크리닝(Content Screening)과 출처 순위(Provenance Ranking)라는 두 가지 주요 방어선이 모두 단일 패스 거짓 주장 앞에서 실패한다는 것을 측정으로 입증했기 때문입니다.

## 왜 기존 아키텍처는 근본적으로 방어 불가능한가

### 1. 방어 모델의 구조적 한계: 사후 필터링에 대한 의존

[[entities/adema.md|adema]]의 지식 상태 오케스트레이션이나 [[entities/agora-opt.md|agora opt]]의 런타임 메모리 기반 정렬은 모두 **"무엇을 어떻게 저장하고 검색할 것인가"**를 최적화합니다. 그러나 이들은 **"저장 자체가 적절한가"**를 사전에 판단하는 메커니즘이 아니라, 저장 이후의 검색 품질을 다루는 메커니즘입니다.

이는 [[concepts/alignment-irreversibility.md|alignment irreversibility]]의 문제와 직결됩니다. 한 번 메모리에 정착한 거짓 주장은 후속 세션에서 매칭되어 반복적으로 검색되며, 이는 [[concepts/bayesian-update-cumulative-error.md|bayesian update cumulative error]]를 통해 에이전트의 믿음 상태를 점진적으로 왜곡합니다. 필터링이 '입구'가 아니라 '출구'에 있기 때문에, 이미 내부에 있는 오염은 스스로를 강화합니다.

### 2. 출처 순위의 순환적 무력화

출처 기반 순위(Provenance Ranking)는 "이 정보가 어디서 왔는가"를 평가하지만, 적대적 오염 시나리오에서는 다음이 성립합니다:

- 단일 패스로 생성된 거짓 주장은 **출처 자체가 없거나 위조 가능**합니다.
- [[concepts/agent-knowledge-separation.md|agent knowledge separation]]이 제대로 구현되지 않은 아키텍처에서는 외부 소스와 자기 생성 간의 경계가 모호해집니다.
- 순위 매기기에 사용되는 메타데이터 자체가 조작 가능하다면, 순위는 방어가 아니라 공격의 표면이 됩니다.

### 3. 트리거/최적화 부재의 의미: "보이지 않는" 오염

질문에서 핵심적으로 지적한 "트리거나 최적화 없이 단일 패스로"라는 조건이 중요합니다. 기존 연구들이 주로 다룬 적대적 공격(예: [[concepts/adversarial-prompting.md|adversarial prompting]])은 명시적인 트리거 패턴을 포함하므로 패턴 매칭 기반 탐지가 가능합니다. 그러나 트리거가 없는 자연스러운 거짓 주장은:

- [[content-screening]]의 규칙 기반 필터를 우회합니다 (명시적 공격 패턴이 없으므로)
- 출처 순위를 우회합니다 (정상적인 대화 맥락에서 발생하므로)
- [[entities/belief-state-grounding.md|belief state grounding]]을 교란하지만, 교란 자체가 은폐됩니다

## 새로운 개념적 연결 발견

이 분석을 통해 다음의 연결이 드러납니다:

### 연결 1: 메모리 아키텍처 ≠ 면역 체계
[[concepts/agent-native-immune-system.md|agent native immune system]]이라는 슬러그가 존재한다는 것은, 연구 커뮤니티가 이미 "메모리 아키텍처와는 별도의 방어 계층"의 필요성을 인식하고 있음을 시사합니다. [[entities/adema.md|adema]]가 기억의 **구조**를 다룬다면, [[concepts/agent-native-immune-system.md|agent native immune system]]은 기억의 **무결성**을 다뤄야 하는데, 이 두 축이 현재 Wiki에서 분리되어 있지 않은 것으로 보입니다.

### 연결 2: [[concepts/algebraic-taint-confinement.md|algebraic taint confinement]]의 잠재적 역할
이 슬러그가 존재한다는 것은, 오염된 정보를 대수적(propagational)으로 격리하려는 접근이 이미 제안되었음을 의미합니다. 이는 콘텐츠 필터링(문자열 패턴)이나 출처 순위(메타데이터)와는 차원이 다른 **정보의 전파 경로 자체를 차단**하는 접근으로, 근본적 방어 불가능성에 대한 유일한 대안 경로가 될 수 있습니다.

### 연결 3: [[concepts/asymmetric-alignment-fragility.md|asymmetric alignment fragility]]와의 연결
정렬(Alignment)이 비대칭적으로 취약하다는 개념은 메모리 오염에도 적용됩니다. 에이전트가 올바른 정보를 수용하는 것보다 거짓 정보를 수용하는 것이 구조적으로 더 쉽다면(비대칭성), 필터링 기반 방어는 수학적으로 불완전합니다.

## 결론: 근본적 방어 불가능성 여부

**부분적으로 그렇습니다.** 현재 Wiki에 등장하는 메모리 아키텍처([[entities/adema.md|adema]], [[entities/agora-opt.md|agora opt]])의 설계 철학—저장·검색 최적화—만으로는 단일 패스 무트리거 오염에 대해 방어 불가능합니다. "Utility Under Attack" 논문이 이를 실증으로 보여줍니다.

그러나 **완전한 방어 불가능성**을 주장하려면 다음이 추가로 검증되어야 합니다:

1. [[concepts/algebraic-taint-confinement.md|algebraic taint confinement]]가 단일 패스 오염을 실제로 차단할 수 있는가?
2. [[concepts/agent-native-immune-system.md|agent native immune system]]이 메모리 쓰기 시점에 사전 검증(prewrite validation)을 수행할 수 있는가?
3. [[concepts/belief-drift-as-reward-signal.md|belief drift as reward signal]]을 역으로 활용해, 비정상적인 믿음 이동을 오염 신호로 감지할 수 있는가?

즉, **기존 메모리 아키텍처의 패러다임 내에서는 방어 불가능하지만, [[concepts/algebraic-taint-confinement.md|algebraic taint confinement]]나 [[concepts/agent-native-immune-system.md|agent native immune system]] 같은 별도 방어 축이 메모리 아키텍처와 통합된다면 가능성이 열립니다.** 현재 Wiki의 지식 상태에서는 이 통합이 아직 이루어지지 않았으므로, 실질적으로는 방어 불가능한 상태라고 평가해야 합니다.
