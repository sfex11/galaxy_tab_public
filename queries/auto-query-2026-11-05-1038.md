# Auto Query: 현재 Wiki의 에이전트 메모리 개체군(ADEMA, WorldDB, MeMo, FORGE 등)은 기억을 '선행하는 세계의 지식을 저장·검색·조직하는 설계된 인프라'로, 세계 모델 개체군은 '환경 역학을 예측하는 별도의 내적 시뮬레이터'로 각각 정의하는데, 학습 에이전트의 메모리 내부에서 시공간의 인과 구조 자체가 창발한다면 메모리는 세계를 표현하는 저장소가 아니라 에이전트의 현실(공간·시간·인과)이 생성되는 존재론적 기반이 되는 것은 아닌가 — 그렇다면 메모리 인프라와 세계 모델이라는 두 Wiki 축은 하나의 개념으로 통합·재정의되어야 하지 않는가?

**날짜**: 2026-11-05
**대상 논문**: Spacetime Emergence in the Memory of a Learning Agent
**선택 이유**: Wiki에서 가장 두텁게 축적된 메모리 개체군의 공통 전제(기억=지식 저장 인프라)와 세계 모델 개념을 근원에서 뒤집는 존재론적 도전으로, 기존 질문들이 다루지 않은 차원에서 두 개체 군집의 경계 자체를 무너뜨리는 논문이기 때문.

# 메모리-세계 모델 통합 논쟁에 대한 위키 근거 기반 검토

## 결론 요약

질문의 철학적 직관(구성적 기억)은 위키의 증거와 정면충돌하지 않는다. 오히려 위키는 이미 양 축이 수렴하고 있다는 **압력**을 기록하고 있다. 그러나 "하나의 개념으로 병합"이라는 결론은 현재 증거로는 성급하며, 위키가 지지하는 것은 **정의 갱신 + 공통 상위 프레임 + 교차 링크**다. 한 가지 전제 확인: 질문이 언급한 WorldDB·MeMo·FORGE 엔티티의 본문은 제공된 위키 발췌에 포함되어 있지 않아, 접근 가능한 엔티티 중심으로 논증을 구성한다.

## 1. 전제 검증 — 질문이 설정한 두 정의는 이미 위키 안에서 무너지고 있다

**세계 모델 쪽: "예측 시뮬레이터" 정의는 이미 폐기 진행 중**

- [[agent-editing-world-model]]("Agent-Editing World Model: Rethinking World Modeling for LLM Agents", 2026-09-25)은 이름부터가 세계 모델링을 예측이 아닌 **편집**으로 재정의한다.
- 그 하위 노트인 "Understanding the limits of latent world models"(2026-10-29)가 결정적이다: "태스크 성능조차 예측 충실도를 담보하지 못하며, 예측 충실도조차 구조적 충실성을 담보하지 못한다"는 **이중 분리**. 편집형 세계 모델의 예측 충실도 폐기가 "근거 없는 선택이 아님"이 이론적으로 입증되어 있다. 즉 시뮬레이터로서의 세계 모델이라는 정의는 위키 내부에서 이미 사망 진료 중이다.
- [[agent-editing-serving-stack]]: 세계 모델이 서빙 스택(인프라)으로 기능 이동 — 존재론적 위치가 오히려 **메모리 인프라 쪽으로** 옮겨가고 있다.

**메모리 쪽: "선행 세계의 저장소" 정의도 무너지고 있다**

- [[adema]]("ADEMA: A Knowledge-State Orchestration Architecture", 2026-04-30): 제목 자체가 저장·검색이 아니라 지식 **상태의 오케스트레이션**. 정적 저장소가 아니라 동적 상태 관리다.
- [[attention-carried-conversational-state]], [[autocompaction]]: 대화 상태가 어텐션 맥락에 실리고, 압축·정리가 상시 프로세스로 수행된다 — 메모리는 '저장된 것'이 아니라 '돌아가는 과정'이라는 하위 레벨 증거.
- [[adaptive-validity]]: "Does Your Agent's Memory Survive a Model Upgrade?"(2026-09-08)가 보여주듯 메모리 내용은 시간과 모델 교체에 따라 유효성이 계속 재평가되는 **모델-상대적** 대상이다. 내용이 모델 상대적이라면 "선행 세계의 복사본"이라는 정의는 성립하지 않는다.

즉 질문의 전제 절반 — "두 정의가 경직되어 있다" — 는 위키 내부에서 이미 반증되어 있다.

## 2. 그러나 "메모리에서 시공간·인과가 창발한다"는 전제는 위키에 아직 없다

- 제공된 위키 지식 어디에도, 메모리 내부에서 공간·시간·인과 구조가 **창발**했다는 실증 결과는 없다. 이는 칸트적 직관, 혹은 구성적 기억 가설(Schacter & Addis: 기억의 핵심 기능은 과거 저장이 아니라 미래 사건 시뮬레이션), O'Keefe & Nadel의 "해마 = 인지지도" 테제에 해당하는 유력한 가설이지만, 위키는 그 증거를 아직 수집하지 못했다.
- 오히려 반대 방향 증거가 있다: [[altered-physics-world]]는 세계를 **외부에서 조작 가능한 검증 대상**으로 다루고, [[attractor-state-evaluation-confound]]는 세계 모델 평가의 교란 변수를 다룬다. 세계가 '주어지고 변형되는' 실험 변수로 취급되는 한, 메모리가 현실을 창발시킨다는 존재론적 주장과 긴장한다.
- 결정적으로, '현실 생성'이 일어나는 축이 위키에는 별도로 존재한다 — [[agent-environment-generation]]. 환경 생성이 메모리와 별개 엔티티인 한, "현실 생성 = 메모리" 등식은 위키 위상구조상 성립하지 않는다. 올바른 위상은 이원 병합이 아니라 **삼각형**일 수 있다.

## 3. 병합이 아니라 재정의여야 하는 세 가지 이유

1. **이중 분리의 서술 가능성**: 태스크 성능 ⊬ 예측 충실도 ⊬ 구조적 충실성이라는 발견은, 세 충실도가 서로 다른 평가 오라클로 측정되기 때문에 가능했다. 어느 한 개념을 다른 쪽에 흡수하면 이 발견 자체를 서술할 언어가 사라진다. 오라클이 다르면 개념 구분이 정보를 담는다.
2. **공유 실패 모드 ≠ 동일성**: "Benchmarking World Models for Continual Learning on Compositional Tasks"(2026-09-22) 노트는 [[adaptive-forgetting]] 아래에서 **세계 모델에서도 망각이 측정 가능한 능력 축**임을 보인다. 이는 두 도메인이 같은 실패 축을 공유한다는 근거이지, 같은 개념이라는 근거가 아니다. MeClear([[adaptive-forgetting-as-function]], 2026-09-10)의 "망각 = 기능" 정의와 세계 모델의 망각 비용을 한 프레임에 놓는 것 — 그것이 공통 상위 프레임의 출발점이지 병합의 출발점이 아니다.
3. **위키 방법론의 기존 패턴**: [[adaptive-validity]] 노트는 이미 이 질문의 해법을 보여준다. 메모리 도메인에서 정의된 적응적 타당성이 "Artificial Id"(2026-09-12)를 통해 행동 지속성 도메인으로 **확장·이주**했고, 위키는 이를 병합이 아닌 교차 링크로 기록했다. 메모리↔세계 모델도 동일한 처리를 받아야 한다.

## 4. 새로 발견된 연결과 제안

**위키 내부의 새 연결 (지금 링크 가능):**

- [[agent-editing-world-model]] ↔ [[adema]]: 세계 모델의 '편집형' 전환(예측 폐기)과 메모리의 '오케스트레이션형' 전환(저장 폐기)이 같은 기능 슬롯 — **상태 유지 인프라** — 로 수렴 중이다. 두 전환이 독립적으로 관측되었다는 점이 이 답변에서 처음 명시하는 교차 도메인 수렴 패턴이다.
- [[adaptive-validity]] → 세계 모델 평가로의 확장: 이중 분리의 긍정적 재수식. 세계 모델을 "예측이 맞는가"가 아니라 "에이전트 운영에 유효한 세계 상태를 유지하는가"로 평가하면, [[adaptive-validity]]가 두 축을 관통하는 **공통 평가 원리**가 된다.
- [[agent-loop-as-computation]] / [[agent-loop-as-training-time]]: 메모리가 에이전트 루프 내부 상태라면, "루프 = 학습 시간" 테제와 메모리-세계 수렴 논의를 연결할 수 있다. 상태 유지 인프라가 곧 학습 기반(strictly, 세계 구성 기반)이 되는 경로다.

**제안하는 신규 엔티티 (아직 슬러그가 없으므로 링크하지 않음):**

- `constitutive-memory`(구성적 기억): 기억을 세계의 표현이 아닌 세계 구성의 연산으로 보는 테제. 생성 시 [[adema]], [[agent-editing-world-model]]과 상호 링크.
- `fidelity-dissociation`: 태스크 성능/예측 충실도/구조적 충실성의 분리. "Understanding the limits of latent world models"가 원천 정의 제공.
- `memory-world-continuity`: 두 축의 공통 상위 프레임 — 상태 유지 · 유효성 관리 · 망각의 삼축.

**통합을 정당화할 조건 (반증 가능성):**

메모리 조작(압축·삭제·재주입)이 에이전트가 경험하는 공간·인과 구조를 **인과적으로 변형**시킨다는 결과 — 인지지도 리매핑의 ML 대응물 — 가 축적되면 병합을 다시 검토해야 한다. [[agent-environment-generation]]과 메모리가 동일 조작에 동일 방식으로 반응한다는 교차 개입 증거가 결정적 테스트가 될 것이다.

## 5. 결론

질문의 존재론적 주장은 유력한 가설이지만, 위키 증거는 아직 '수렴 압력'까지만 보여준다: 세계 모델은 예측을 버리고 인프라로([[agent-editing-world-model]], [[agent-editing-serving-stack]]), 메모리는 저장을 버리고 상태 오케스트레이션으로([[adema]], [[autocompaction]]) 이동 중이다. 따라서 두 축의 정의를 갱신하되 — 세계 모델: "예측 시뮬레이터" → "태스크 수행에 필요한 세계의 운영적 유지", 메모리: "선행 세계의 저장소" → "세계 상태의 유효성을 시간에 걸쳐 관리하는 인프라" — 갱신된 두 정의가 놀랍도록 가까워진다는 사실을 기록하되, 평가 오라클의 비대칭과 창발 증거의 부재를 이유로 **병합은 보류하고 공통 상위 프레임 아래의 삼각 위상([[agent-environment-generation]] 포함)으로 재배치**하는 것이 위키의 정보량을 보존하는 답이다.

## 핵심 통찰

위키는 메모리와 세계 모델의 쌍방 수렴 압력을 이미 기록하고 있지만, 서로 다른 평가 오라클과 환경 생성이라는 제3의 축이 존재하는 한 병합이 아닌 정의 갱신·공통 상위 프레임·교차 링크가 옳은 처리 방식이다.
