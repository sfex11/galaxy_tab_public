## 2. Wiki 개념 체계로 본 재규격화

### (a) 순간 상태 vs 궤적 누적 — 정확한 구조적 평행

[[accumulated-effective-learning-rate]]의 MuonGS 노트가 이 질문의 인식론적 뼈대를 제공합니다: "스칼라 학습률이 순간 상태를 기술한다면 C_T는 궤적 전체의 누적을 기술하여..." 질문의 주장은 이 구분의 **능력 분석 버전**입니다 — 최종 가중치는 순간 상태이고, 에이전트 능력은 궤적 적분(체크포인트 개체군)이다. 체크포인트 선택은 궤적 적분을 순간 상태 하나로 압축하는 투영 연산입니다.

### (b) 소멸의 정체: attribution 없는 망각

- [[adaptive-forgetting]]의 "Benchmarking World Models for Continual Learning on Compositional Task" (2026-09-22) 노트는 망각 비용이 태스크 재방문 시점에 **직접 관측 가능**하며, 망각을 고장이 아닌 **측정 가능한 능력 축**으로 다뤄야 한다고 규정합니다. GRPO의 무감독 체크포인트 폐기는 이 망각 축의 극단 사례 — 측정조차 없이 발생하는 망각입니다.
- [[adaptive-forgetting-as-function]] (MeClear)은 게임이론적 기여도로 망각 대상을 결정하는 '함수적 망각'을 제시합니다. 이 원리로 읽으면 표준 체크포인트 선택은 **attribution 없는 망각** — 무엇이 사라지는지 계산하지 않고 버리는 행위이며, MeClear가 세운 원칙의 위반 사례입니다.

### (c) 'best'의 조건부 타당성

[[adaptive-validity]]의 Artificial Id 노트는 "현재 행동이 여전히 타당한가"를 **지속 재평가**하는 적응적 타당성 판단을 제시합니다. 최고 검증 체크포인트의 '최적성'도 특정 검증 분포·시점에 조건부된 타당성일 뿐입니다. 폐기된 체크포인트가 최종 모델이 실패하는 문제를 푼다는 사실은 **validation 지표가 능력 공간을 under-determine한다**(결정 불충분)는 실증입니다.

### (d) 적응-유지 얽힘의 시간적 기록

[[adaptation-retention-entanglement]]가 시사하듯 GRPO의 갱신마다 새 능력 획득과 이전 능력 유지는 얽혀 있습니다. 체크포인트 개체군은 이 얽힘의 **시간 분해 기록**이며, 폐기는 분해 작업 없이 얽힌 상태 하나만 남기는 것입니다.

## 3. 정교화가 필요한 지점

질문에 "아닌가?"라는 단정 대신 세 가지 쐐기:

- **완전 소멸이 아니라 재압축**: Agentic-OPD가 증류로 회복 가능함을 보였다는 것은 능력 정보가 데이터/환경 상호작용 쪽에 잔존함을 뜻합니다. 손실은 복원 가능한 형태입니다.
- **모든 폐기 체크포인트가 귀금속은 아님**: 손실의 실체는 개별 체크포인트가 아니라 **검증 지표에 직교하는 능력 분포의 꼬리**입니다. 문제는 지표 맹목성이지 개별 체크포인트의 가치가 아닙니다.
- **보존 비용의 존재**: 개체군 보존·증류 파이프라인에는 저장·연산 예산이 들며, 이는 [[accumulation-budget-design]] 엔티티가 다룰 예산 설계 문제로 귀결됩니다.

## 4. 새로 발견된 연결·개념 (신규 엔티티 후보 — wiki-link 없이 표기)

1. **capability-as-checkpoint-population (체크포인트 개체군으로서의 능력)**: 능력을 최종 가중치의 속성이 아닌 궤적상 분산 자원으로 모델링하는 상위 개념. [[artifact-evolution-state-identity]]가 이름에서 시사하는 '아티팩트의 정체성 = 진화 상태' 관점과 접합 가능.
2. **checkpoint-selection-as-lossy-projection**: 다축 능력 궤적을 스칼라 검증 점수로 정렬해 단일점으로 투영하는 연산으로서의 표준 관행. under-determination 분석은 [[attractor-state-evaluation-confound]], 능력 축 간 정렬 문제는 [[adaptation-axis-misalignment]] 엔티티와의 접합 후보.
3. **training-trajectory chronometry**: [[architectural-chronometry]] (Deep Noir가 모델 *내부* 신호의 시간적 위치를 판독하듯)의 훈련 궤적 확장 — 능력이 개체군의 *어디에서* 출현했는지의 고고학. 최근 논문 **"Shortcuts and Boundaries: Verifiable RL Misalignment and Contextual Safety Learning"**(RL이 능력과 함께 문맥 위반을 강화함)과 결합하면, 오정렬이 어떤 체크포인트에서 유입됐는지의 시간적 국소화도 가능해집니다.
4. **개체군 > 단일 대표체 원리의 이중 성립**: 최근 논문 **"Test-Time Compute Scales Better with Parallel Agent Teams"**는 추론 시점에서도 병렬 에이전트 팀(개체군)이 단일 궤적보다 잘 스케일함을 보입니다. 훈련 시점(체크포인트 개체군)과 추론 시점(병렬 시도)에서 동일 원리가 성립 — Wiki 차원의 횡단 연구 주제 후보입니다.
5. **documentation debt ↔ checkpoint debt 대칭**: 최근 논문 **"When Instruction Files Go Stale: Documentation Debt and Hidden Cost in Coding Agents"**는 *보존된* 아티팩트가 낳는 비용(부채)을 다룹니다. 체크포인트 폐기는 반대 극단(*보존하지 않아* 낳는 손실)입니다. 아티팩트 수명주기 관리의 두 실패 모드 — 보존 부채 vs 폐기 손실 — 를 한 축으로 묶을 수 있습니다.
6. **훈련-추론 경계의 적응성 비대칭**: [[adaptive-inference]] (SpecKV)는 추론 중 시스템이 내부 상태(압축 수준)에 적응함을 보이는 반면, 훈련 종료 처리는 궤적을 고정 단일점으로 축소합니다. 적응성이 경계를 기준으로 비대칭적으로 끊긴다는 관찰.
