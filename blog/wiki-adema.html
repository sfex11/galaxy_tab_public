기억을 매번 지우는 AI:
에피소드 경계라는 환상이 숨긴 것

체화 에이전트의 메모리 인프라는 '진짜 환경'이 아니라 '시험장'에 최적화되어 있다. 이 환상을 어떻게 깨야 하는가.

2025년 7월 · 체화 AI · 메모리 아키텍처
01

호텔 체크아웃을 반복하는 여행자

매일 아침 호텔 방에서 깨면, 전날 기억이 전부 사라진다고 상상해 보세요. 어제 찾은 맛집 위치도, 길을 걷다 알게 된 골목의 지형도, receptionist가 알려준 정보도 — 모두 증발합니다. 그래서 매일 지도를 처음부터 펴고, 길을 처음부터 묻고, 맛집을 처음부터 검색해야 합니다.

비효율적이라는 말로는 부족합니다. 이건 여행이 아닙니다. 그런데 체화 에이전트(embodied agent) 연구의 주류 평가 방식은 정확히 이런 상황을 '정상'으로 가정하고 있습니다. 이를 에피소드 경계(episodic boundary)라고 부릅니다 — 하나의 작업이 끝나면 에이전트의 기억을 싹 지우고 다음 작업을 시작하는 방식입니다.

"에피소드가 시작될 때 상태가 초기화된다"는 전제를 무비판적으로 수용하는 것이 현재 메모리 진단 체계의 공통된 blind spot이다.

문제는 이 전제가 단순히 '평가의 편의'를 넘어, 메모리 인프라 자체의 설계 방향을 지배하고 있다는 점입니다. 시험에 나오는 것만 공부하는 학생처럼, 에피소드 안에서만 쓸모 있는 기억 장치를 만들어내고 있습니다.

02

기존 진단 도구들의 치명적 사각지대

현재 Wiki에 등록된 메모리 관련 진단 도구들을 하나하나 들여다보면, 모두 같은 경계 안에 갇혀 있습니다.

진단 도구 사례

ADEMA — 에피소드 내 지식 상태 오케스트레이션

에이전트가 긴 컨텍스트 내에서 지식을 일관되게 유지하는지 진단합니다. "방금 열어놓은 서랍을 닫았는가" 같은 질문에 잘 대답하는지 봅니다. 하지만 이것은 하나의 에피소드 안에서의 일관성입니다. 어제의 서랍 기억이 오늘의 추론에 영향을 주는지는 아예 측정 대상이 아닙니다.

진단 도구 사례

Three-Step Nav — 단계별 판단과 기획의 간극

MLLM 에이전트가 경로를 이탈하거나 조기에 멈추는 현상을 "단계별 판단과 다단계 기획 사이의 간극"으로 진단합니다. 메모리의 누적·재사용 문제가 아니라, 단일 에피소드 내 추론 구조의 문제로 프레이밍됩니다.

진단 도구 사례

Adaptive Forgetting — 컨텍스트 내 적응적 망각

긴 대화에서 불필요한 정보를 잊어버리는 능력을 다룹니다. 그런데 에피소드 리셋이 존재하면, 이 망각은 "설계해야 할 문제"가 아니라 "자동으로 해결되는 것"이 됩니다. 진짜 어려운 망각 — 에피소드 간에 무엇을 지우고 무엇을 남길 것인가 — 는 보이지 않습니다.

이 세 도구는 각각 유용하지만, 공통적으로 "기억을 매번 지워도 괜찮은 세계"를 전제하고 있습니다. 마치 기억 상실증 환자에게 "오늘 하루 동안의 기억은 잘 유지하시네요"라고 평가하는 것과 같습니다.

03

리셋이 은폐하는 세 가지 병목

최근 논문 "Beyond Episodic Evaluation: Memory Architectural Bottlenecks in Sequential Embodied Question Answering"이 이 문제를 정면으로 지적합니다. 에피소드 간 상태 리셋을 전제한 평가는 다음 세 가지 병목을 체계적으로 은폐한다는 것입니다.

병목 1: 누적 메모리 오염

비유하자면, 하루 종일 요리하는 주방을 생각해 보세요. 아침에 굽던 생선 냄새가 점심 국물에 배어들고, 저녁 디저트에까지 영향을 미칩니다. 에피소드가 독립적으로 평가되면 이런 잔여 정보의 간섭은 측정되지 않습니다. 10번째 에피소드에서의 추론 오류가 1~9번째 에피소드의 정보 잔여 때문인지, 아니면 10번째 자체의 문제인지 알 수 없습니다.

병목 2: 재사용 불능

연속 환경에서는 이전에 구축한 공간 지도, 객체 위치 기억, 사용자 선호 등을 재사용해야 합니다. 그런데 에피소드 평가에서는 매번 처음부터 지도를 그리고, 처음부터 방을 탐색하는 비용이 "정상적인 연산량"으로 간주됩니다. 이건 매번 새로운 도시에 도착할 때마다 지도를从头 그리는 것을 "정상"으로 평가하는 것과 같습니다.

병목 3: 믿음 상태의 단절

에이전트의 믿음 상태(belief state)는 에피소드 경계를 넘어 지속·갱신되어야 합니다. "이 집의 열쇠는 서랍 둘째 칸에 있다"는 믿음은 다음 에피소드에서도 유효해야 합니다. 하지만 리셋 평가에서는 믿음 상태가 매번 tabula rasa(백지상태)에서 시작되므로, grounding의 지속성 자체가 평가 대상에서 소외됩니다.

핵심 포인트: 이 세 병목은 "에피소드 리셋"이라는 조작 때문에 측정 불가능해집니다. 측정 불가능하므로 최적화 대상에서 제외되고, 최적화되지 않으므로 실제 배포에서는 여전히 실패합니다. 그런데 벤치마크에서는 실패가 보이지 않으니, "문제가 없다"는 결론에 도달합니다.

04

평가가 인프라를 역지배하는 순환 구조

이 문제의 본질은 단순한 누락이 아닙니다. 구조적인 순환 고리입니다.

벤치마크가 에피소드 경계를 규정하면, 메모리 인프라는 그 경계 내에서만 최적화된다. 그리고 그렇게 최적화된 인프라는 다시 "에피소드 내에서는 잘 작동한다"는 결과를 낳아, 벤치마크의 타당성을 재생산한다.

이 순환을 시각적으로 풀어보겠습니다.

순환 고리의 해부

1단계: 벤치마크가 "에피소드 = 독립된 단위"라고 규정한다.

2단계: 연구자들은 에피소드 내 성능을 높이는 메모리 모듈을 설계한다. WorldDB, MeMo 같은 저장-검색 시스템은 에피소드 내 검색 정확도를 극대화하도록 튜닝된다.

3단계: 벤치마크에서 성능이 오른다. 논문이 쓰인다.

4단계: "메모리 문제가 해결되고 있다"는 인상이 강화되어, 벤치마크의 기본 전제(에피소드 독립성)에 대한 의문이 제기되지 않는다.

→ 다시 1단계로.

이 순환 속에서 교차 에피소드 검색의 충돌(conflict), 구식화(staleness), 일관성(consistency) 문제는 벤치마크에 없으므로 존재하지 않는 것이 됩니다. 마치 지도에 없는 바다는 없는 바다인 것처럼요.

이것은 benchmark-specification-gap의 특수한 형태입니다. 단순히 "벤치마크와 실제 능력 사이에 격차가 있다"가 아니라, 평가 단위(에피소드) 자체가 인프라 설계를 구속하는 메타-겹차(meta-gap)로 확장되는 것입니다.

05

기존 개념을 다시 읽는다

에피소드 경계라는 렌즈를 끼면, 기존에 알려진 개념들이 다르게 보입니다.

기존 개념 기존 해석 새로운 해석
adema 에피소드 내 지식 상태 오케스트레이션 에피소드 경계가 존재한다는 전제 위에 구축된 사후 대응 체계
adaptive-forgetting 컨텍스트 내 적응적 망각 에피소드 리셋이 대신해주므로 실제 망각 메커니즘의 필요성이 은폐됨
benchmark-specification-gap 벤치마크와 실제 능력 간 격차 평가 단위 자체가 인프라 설계를 구속하는 메타-겹차로 확장
closed-loop-evaluation 에피소드 내 폐루프 평가 에피소드 간 폐루프(cross-episode closed loop)로 개념 확장 필요
agent-scene-instruction-triad 장면-지시 삼항 관계 에피소드 경계를 넘어 장면 기억이 지속되지 않으면 삼항 관계가 매번 재구축됨

특히 마지막 행이 직관적입니다. 장면-지시 삼항 관계는 에이전트가 환경을 이해하는 기본 단위인데, 에피소드 리셋 하에서는 이 삼항 관계를 매 에피소드마다 처음부터 맺어야 합니다. 이건 대화할 때마다 상대방의 얼굴을 처음 보는 것처럼, 관계 자체의 비용이 누적되는 구조입니다.

06

패러다임 전환: 에피소드에서 연속 스트림으로

지금까지의 분석이 하나의 결론을 향해 수렴합니다.

기존 메모리 인프라는 실제 배포 환경이 아닌 '에피소드 경계'라는 인공적 구분에 최적화된 것이 맞습니다. 이는 단순한 누락이 아니라, 평가 방법론이 인프라 설계를 역지배하는 구조적 문제입니다.

그렇다면 어떻게 전환해야 할까요. "Beyond Episodic Evaluation" 논문이 제기하는 도전은 개별 메모리 모듈의 성능 개선이 아닙니다. 평가 단위 자체를 재정의해야 한다는 메타-레벨의 요구입니다.

구체적으로 무엇을 바꿔야 하는가

  1. 평가 단위를 에피소드에서 연속 스트림(continuous stream)으로 전환합니다. 에이전트가 N개의 에피소드를 순차적으로 수행하면서, 이전 경험이 후속 성능에 미치는 영향을 정량화하는 메트릭이 필요합니다.
  2. 교차 에피소드 메모리 관리를 일등 시민으로 격상합니다. 누적 오염을 억제하는 메커니즘, 이전 지식을 재사용하는 라우팅, 믿음 상태의 단절 없는 갱신 — 이것들이 부가 기능이 아니라 핵심 아키텍처가 되어야 합니다.
  3. closed-loop evaluation을 cross-episode 차원으로 확장합니다. 에피소드 내에서의 행동-관찰 루프만이 아니라, 에피소드 간의 기억-활용-갱신 루프를 평가框架에 편입시킵니다.
  4. 벤치마크가 인프라를 지배하는 순환을 끊습니다. 벤치마크 설계와 인프라 설계를 동시에 진행하거나, 최소한 벤치마크의 암묵적 전제(에피소드 독립성)를 명시적으로 문서화하고 대안 벤치마크를 병행해야 합니다.

이것이 충족되지 않으면, 어떤 메모리 인프라 개선도 에피소드 경계 안에서의 국소 최적점에 갇힐 위험이 있습니다. 아무리 세련된 서랍장을 만들어도, 매일 아침 서랍을 비우는 호텔이라면 소용없는 것처럼요.

진짜 기억이란, 어제와 오늘을 연결하는 능력이다. 체화 에이전트의 메모리 연구가 "진짜"가 되려면, 에피소드라는 인공적 경계를 넘어 연속적인 경험의 흐름 속에서 기억이 어떻게 살아남고, 변형되고, 활용되는지를 직시해야 한다.
체화 에이전트 메모리 아키텍처 벤치마크 설계 에피소드 평가 연속 학습 belief state
