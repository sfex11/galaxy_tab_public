# 환경 합성의 데이터 큐레이션 재분류

**생성일**: 2026-10-30

## 정의

환경 합성을 '실행 무대 공급 인프라'가 아니라 과제 분포를 정의해 습득 가능 능력의 상한과 방향을 선결정하는 훈련의 1급 변수, 즉 에이전트 훈련의 데이터 큐레이션으로 재분류하는 입장. RL 알고리즘은 메커니즘이고 환경은 탐색 공간을 정의한다는 역할 구분을 전제하며, '격상'이지 '환경 > 훈련'의 역전이 아니다.
