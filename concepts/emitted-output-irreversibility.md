# 발화 출력 비가역성 (Emitted-Output Irreversibility)

**생성일**: 2026-09-15

## 정의

이미 발화된 출력은 청자가 들었다는 사실 자체가 되돌릴 수 없어, 자기회귀 패러다임의 커밋된 토큰 불변성과 물리 행동의 되돌릴 수 없성이 동형 구조를 이룬다는 개념. 회고적 수정이 파라다임 구속 문제와 물리적 비가역성 문제를 동시에 건드리는 접점이 된다.
