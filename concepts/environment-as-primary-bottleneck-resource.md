# 환경 = 훈련의 1차 병목 자원

**생성일**: 2026-11-01

## 정의

유한한 롤아웃 예산이 전제되는 순간 환경을 무한히 공급되는 무대가 아니라 탐색·검증·커리큘럼·평가라는 상충하는 사용처 사이에서 배분되는 희소 자원으로 재정의하는 관점. 환경 접근(롤아웃)은 최적 결정의 필요조건이지 충분조건이 아니며, 환경별 롤아웃 한계 가치가 달라 균등 배분은 구조적으로 비효율이다.
