# 통신 접근–계획 간극

**생성일**: 2026-09-19

## 정의

접근–계획 간극(access-planning-gap)의 통신 도메인 확장으로, 채널 대역폭(비트를 실어 보낼 접근 능력)이 충분해도 어떤 비트를 보낼지를 산출하는 질문 생성·계획 능력이 별도의 구조적 병목임을 규정한다. 극소 채널 고정은 대역폭 변수를 제거하고 정책 품질만 분리 측정하는 실험 설계 전략이기도 하다.
