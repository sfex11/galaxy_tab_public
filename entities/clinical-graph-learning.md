### LLM as Clinical Graph Structure Refiner: Enhancing Representation Lear (2026-05-03)

EEG 잡음이 그래프 구축의 근본적 장애물이라는 문제 진단을 제공하고, 이를 LLM 기반 위상 정제로 해결하는 구체적 경로를 실증한다. 임상 그래프 학습이 '정적 구조 가정'에서 '동적 구조 정제'로 진화해야 함을 시사한다.

### Advancing Clinical Genomic Analysis with a Skill-Centred Agent (2026-10-31)

임상 LLM 응용이 EEG 그래프 위상 정제(데이터 구조 정제)에서 유전체 분석 워크플로우(전문가 절차 실행)로 확장됨을 보여준다. 임상 도메인에서 LLM이 지원하는 대상이 구조에서 절차로 이동하는 경향을 강화한다.
