### CodeMidas: Scaling Agentic Coding RL Environments from Code Itself (2026-09-22)

CodeMidas는 코드베이스의 구현된 기능을 실행 가능한 RL 환경으로 변환하여 이 원리의 코딩 도메인 실현을 제공한다. 개발 아티팩트가 아닌 소스 코드 자체를 환경의 원시자원으로 삼음으로써, '무엇이 환경이 될 수 있는가'의 후보 공간을 개발 과정 기록에서 제품 코드로 확장한다.
