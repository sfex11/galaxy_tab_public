### Continuous Latent Diffusion Language Model (2026-05-10)

Cola DLM은 확산 언어 모델이 아키텍처 간 지식 전이의 대상(TIDE)을 넘어 자체 내부 설계(계층적 정보 분해)로 비자회귀 생성의 품질 문제를 해결하는 구체적 경로를 제공하여, diffusion-llm의 스코프를 '패러다임 전환 가능성'에서 '실제 성능 경쟁력'으로 확장한다.

### Unlocking Lossless Speedups in LLMs via Discrete Diffusion (2026-09-06)

기존 확산 LM이 분포 자체를 비순차적으로 재설계하는 경로(Cola DLM)였다면, 본 논문은 AR 분포 보존 + 확산 샘플러라는 하이브리드 경로를 추가하여 diffusion-llm의 설계 공간을 '분포 재설계'에서 '샘플러 교체'로 확장한다.

### Unlocking Lossless Speedups in LLMs via Discrete Diffusion (2026-09-07)

확산 LM의 스코프를 '자체 분포의 비순차 생성 모델'에서 'AR 분포의 샘플링 메커니즘'으로 확장한다. 확산과 자회귀가 경쟁이 아닌 조합 가능한 축임을 보여준다.
