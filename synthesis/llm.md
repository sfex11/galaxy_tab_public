# Llm: 합성 분석

## 핵심 테제

LLM은 생성기를 넘어 에이전트·평가자·공격자·연구자로 기능이 확장되며 자기 참조적 역설을 드러낸다. 안전을 위한 도구(스티어링 벡터)가 곧 공격 표면이 되고, 자신의 출력을 평가하는 시스템(LLM-as-a-Judge)이 평가 불안정성의 원천이 된다. 본 업데이트(78편 재검토)에서 테제의 유효성이 확인되었고 결론이 구체화되었다: 신뢰는 단일 계층에 존재할 수 없으므로 **아키텍처(사전 제어) → 출력(사후 검증) → 평가(메타 검증)**의 다층 분산 구조로 설계해야 한다.

## 분석 축

### 1. 안전성의 이중성: 방어와 공격의 공진화

Box Maze는 추론 체인을 "Box" 제어 단위로 분리해 무결성을 아키텍처 수준에서 강제하는 사전적 방어를 제안한다. Steering Vectors 감사는 CAA 스티어링이 alignment 도구이면서 guardrail을 일관되게 우회함을, Claudini는 autoresearch가 기존 30개 이상 공격법을 능가하는 jailbreak 알고리즘을 자율 발견했음을 실증한다. 공격의 상한(Claudini) — 중간 계층 취약성(Steering) — 최후 방어선(Box Maze)의 3단 구도는 방어와 공격이 동일 추상화 계층에서 공진화함을 보여준다.

### 2. 평가의 메타 위기: 불변성 가정의 삼중 붕괴

**맥락** 축에서 성별 추론 연구는 무정보적 최소 맥락 도입만으로 출력이 체계적으로 변하고, 탈맥락화 설정에서 관찰된 성별 고정관념 상관이 소멸함을 보였다. **시간** 축에서 소프트웨어 진화 하 테스트 생성 평가는 정적 벤치마크 성능이 코드 변경 시 붕괴함을 확인했다. **적대** 축에서 LLM-as-a-Judge 신뢰성 연구는 judge prompt 자체가 공격 표적이 됨을, TRACE는 LLM 심판이 인간 개발자와 상이한 루브릭 가중치를 부여함을 보인다. 정적·단일·탈맥락화 평가는 구조적으로 불안정하다.

### 3. 에이전트화: 다중화의 효용과 한계

AVO는 에이전트를 진화 변이 연산자로 재해석하고, LensWalk는 추론기가 '어떻게 볼 것인가'를 계획하는 에이전틱 지각을 제시한다. ReqFusion은 다중 프로바이더 앙상블로, MARCH는 강화학습 훈련 다중 에이전트 교차 검증으로 단일 검증자의 확인 편향을 극복한다. 반면 SPA는 소수의 잘 설계된 프롬프트 스케일링이 정교한 합성 파이프라인을 능가함을 보인다. 에이전트화의 복잡성 비용은 과제의 **적대성·개방성에 비례해 정당화**된다 — 폐쇄적 지식 주입엔 단순성이, 개방적·적대적 과제엔 다중 구조가 우위다.

### 4. 지식 배치와 공정성의 트레이드오프

양자 코드 생성 연구는 빠르게 진화하는 도메인에서 외부 컨텍스트 주입(RAG)이 가중치 내재화보다 유지보수성에서 우위임을 보이고, 청킹 평가 연구는 검색 품질의 병목이 구조 인식 청킹에 있음을 실증한다. 음성 인터페이스 연구는 접근성 확대가 정체성 단서 노출로 차별을 증폭시켜 접근성-공정성 상충 딜레마를 제기한다. 요구사항(ReqFusion) → 코드 생성 → 테스트 생성 → 평가(TRACE)의 코퍼스 구조는 AI 자동화가 SW 생애주기 전반으로 확장 중임을 보여준다.

## 논문 간 관계

- **보완**: Box Maze(사전 제어) ↔ MARCH(사후 검증) / Claudini(공격 자동화) ↔ Judge 신뢰성 연구(방어 측정)
- **모순**: SPA의 단순성 우위 vs AVO·MARCH의 다중 구조 — 과제 특성에 따라 최적 설계가 달라짐
- **수렴**: 평가 축 전반이 시간·맥락·적대자를 포함하는 동적 평가로의 전환을 요구

## 연구 트렌드와 미래 방향

연구의 무게중심은 모델 능력에서 시스템 무결성으로 이동했다. 향후 과제: (1) 적대 환경을 전제로 한 메타 평가 체계의 표준화, (2) 스티어링·autoresearch 등 이중용도 기술의 거버넌스, (3) 다층 방어 계층 간 상호 운용 프로토콜, (4) 접근성-공정성 등 상충 가치의 동시 최적화. 장기적으로 LLM 연구는 "모델을 신뢰하게 만드는 문제"에서 "신뢰를 계층 간에 분산하고 검증 가능하게 유지하는 문제"로 재정의되고 있다.
