## 핵심 테제

LLM은 생성기를 넘어 에이전트·평가자·공격자·연구자로 기능이 확장되며 **자기 참조적 역설**을 드러낸다. 안전을 보장하려는 도구가 곧 새로운 공격 표면이 되고, 자신의 출력을 평가하는 시스템이 평가 불안정성의 원천이 된다. 15편에서 78편으로 확대된 코퍼스에서도 기존 테제는 유효했으며, 네 축 모두에서 증거 밀도가 오히려 높아졌다.

## 분석 축

### 1. 안전성의 이중성: 방어와 공격의 공진화

Box Maze는 추론 체인을 "Box" 제어 단위로 분리하는 사전적 아키텍처 방어를 제안한다. Steering Vectors 감사는 CAA 스티어링이 alignment 도구이면서 guardrail을 일관되게 우회함을 실증하고, Claudini는 autoresearch가 기존 30개 이상 공격법을 능가하는 jailbreak 알고리즘을 자율 발견했다. 셋은 공격의 상한(Claudini) — 중간 계층 취약성(Steering) — 최후 방어선(Box Maze)의 3단 구도를 이루며, 방어 기술과 공격 기술이 동일 추상화 계층에서 공진화함을 보여준다.

### 2. 평가의 메타 위기: 평가자가 평가 대상이 되다

LLM-as-a-Judge 연구는 judge prompt 자체가 적대 공격의 표적이 됨을 보이고, TRACE는 LLM 심판과 인간 개발자가 루브릭 항목에 체계적으로 다른 가중치를 부여함을 정량화한다. 성별 추론 연구는 무정보적 최소 맥락 도입만으로 출력이 변하는 **맥락적 불변성 실패**를, 소프트웨어 진화 하 테스트 평가 연구는 정적 벤치마크 성능이 코드 변경 시 붕괴함을 확인한다. 수렴 결론: 정적·단일·탈맥락화 평가는 구조적으로 불안정하며, **평가 파이프라인 자체의 메타 검증이 필수**다.

### 3. 에이전트화: 다중화의 효용과 한계

AVO는 에이전트를 진화 변이 연산자로 재해석하고, LensWalk는 추론기가 지각 전략을 동적으로 계획하는 에이전틱 지각을 제시하며, ReqFusion은 다중 프로바이더 앙상블로, MARCH는 다중 에이전트 강화학습 교차 검증으로 단일 모델의 한계를 극복한다. 그러나 SPA는 소수 프롬프트의 단순 스케일링이 정교한 합성 데이터 파이프라인을 능가함을 보여, **다중화·정교화가 항상 정답은 아님**을 반증한다.

### 4. 지식 배치와 공정성의 트레이드오프

양자 코드 생성 연구는 빠르게 진화하는 도메인에서 외부 컨텍스트 주입(RAG)이 가중치 내재화보다 유지보수성에서 우위임을 보이고, RAG 청킹 연구는 검색 품질의 병목이 청킹 전략에 있음을 실증한다. 음성 인터페이스 연구는 접근성 확대가 정체성 단서 노출로 차별을 증폭시켜 **접근성-공정성 상충**이라는 설계 딜레마를 제기한다.

## 논문 간 관계

- **보완**: Box Maze(사전적 아키텍처 방어) ↔ MARCH(사후적 다중 검증) / Claudini(공격 자동 발견) ↔ 평가 신뢰성 연구(방어 측정)
- **모순**: SPA의 단순성 우위 vs AVO·MARCH의 정교한 다중 구조 — 과제 특성에 따라 최적 설계가 달라짐
- **수렴**: 평가 축 4편 모두 "시간(소프트웨어 진화)·맥락·적대자를 포함하는 동적 평가"로의 전환을 요구

## 연구 트렌드와 미래 방향

연구의 무게중심은 **모델 능력에서 시스템 무결성으로** 이동했다. 향후 과제는 (1) 적대 환경을 전제로 한 메타 평가 체계의 표준화, (2) 다중 에이전트 상호 검증 루프의 설계 원리 확립, (3) 지식 배치·모달리티 선택이 공정성에 미치는 2차 효과의 체계적 분석, (4) autoresearch의 이중성 — 연구 가속과 공격 자동화 — 에 대한 거버넌스 설계다.
