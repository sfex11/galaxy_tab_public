# Closed Loop Training: 합성 분석

> **대상 논문**: Terminal-Universe (arXiv 2609.04148, 2026-09-06/07), Environment Evolution for Terminal Agents (arXiv 2609.04128, 2026-09-07)

## 공통 주제와 핵심 발견

두 논문은 폐루프 훈련([[closed-loop-training]])의 생존 조건이 데이터가 아니라 **실행 가능한 환경의 지속 공급**임을 공통으로 진단한다. 프론티어 모델이 강해질수록 고정 환경은 도전성을 상실하여 [[learning-signal-exhaustion]]이 발생하며, 이에 대응하는 환경 공급 경로를 각기 제시한다.

**Terminal-Universe**는 궤적의 도구 실행 이력이 환경 구조를 이미 노출한다는 관찰에서 출발해, 축적된 궤적을 재질의(re-query) 가능한 터미널 환경으로 변환한다. 궤적은 동결된 단일 데모지만 환경은 검증 가능한 다수 태스크와 실행 피드백을 주는 학습 프리미티브라는 위상 구분이 핵심이며, [[environment-absence-bottleneck]]이 제작 능력이 아닌 '환경화 관점'의 결여에서 비롯됨을 보인다.

**Environment Evolution**은 롤아웃에서 드러난 약점 부근([[environment-frontier-drift]])에서 환경을 반복 합성하는 공진화를 다루되, [[on-policy-environment-coupling]]이라는 구조적 한계를 규명한다 — 진화 근거가 정책 내부에만 있으면 환경은 능력의 그림자를 복제할 뿐이다.

## 논문 간 관계: 보완과 긴장

- **보완**: 궤적→환경(오프라인·경험 기반)과 약점→환경(온폴리시·약점 기반)의 두 경로가 서로의 결속 한계를 상보적으로 완화한다.
- **긴장**: Terminal-Universe의 자기 궤적 순환은 [[bootstrap-paradox]](분포 고착)를, 공진화는 온폴리시 결속을 안는다. 어느 단일 경로로도 폐루프를 안전하게 닫을 수 없다.
- **수렴**: 폐루프의 닫힘 조건이 정교화된다 — 환경 갱신 빈도뿐 아니라 **갱신 데이터 소스의 정책 독립성**이 요구된다. 병목 개념도 '환경 부재 → 신호 피로 → 피로 재발 조건'의 3단계로 진화했다.

## 연구 트렌드와 미래 방향

1. **경험의 인프라화**: 궤적이 소모성 산출물에서 학습 인프라의 원료로 격상되어 [[rlvr]]의 검증 태스크 희소성 제약을 완화한다.
2. **신호 지속성 삼축**: Claw-Eval-Live(평가 신호 갱신) · Environment Evolution(도전성 갱신) · Terminal-Universe(환경 파생)가 폐루프의 신호 유지 체계를 구성한다.
3. **미래 과제**: 오프폴리시 파생과 온폴리시 진화의 **하이브리드 환경 공급**, 외부 궤적 유입 등 정책 독립적 진화 근거 확보, 자기 생성 환경의 분포 고착 완화 메커니즘이 후속 연구의 축이 될 것이다.
