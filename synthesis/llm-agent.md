# Llm Agent: 합성 분석

**생성일**: 2026-07-27 | **최종 업데이트**: 2026-09-14
**관련 논문**: 254편 (+3편)

> 본 업데이트: 논문 수를 251편에서 254편으로 갱신하고, 이전판에서 중단된 트렌드·미래 방향 섹션을 완성했다. 6대 연구축 구조는 유지하되 세부 근거를 보강했다.

## 1. 핵심 연구축

**(1) 평가의 현실화**: TDAD는 AST 기반 코드-테스트 그래프와 가중 영향 분석으로 "풀면서 망가뜨리지 않는지"를 측정해 해결률 중심 벤치마크의 사각지대를 메운다. Blindfolded LLMs는 티커 익명화로 암기·생존자 편향을 제거하고, Traffic Responsibility는 법적 근거의 해석 가능성 자체를 척도로 삼는다. 공통 질문은 "성능 수치의 진위를 어떻게 보장하는가"다.

**(2) 구조적 효율성**: 64-Token Template은 64토큰 템플릿으로 반복적 프롬프트 확장과 동등한 창의성을 달성하고, Post-Training Local LLM은 4B 모델이 SFT+RL 후훈련만으로 Claude Opus 4.6급 성능(95.8% vs 97.5%)에 도달해 추론 비용을 100배 이상 절감한다. "Less LLM, More Structure"의 쌍둥이 실증이다.

**(3) 보안·거버넌스 내재화**: Differential Privacy는 기업 데이터 관점의 프라이버시–품질 최적 트레이드오프를 수학적으로 정립하고, Governed Memory는 메모리 사일로·거버넌스 파편화 등 5가지 구조적 과제를 통해 공유 메모리 거버넌스가 시스템 신뢰성을 좌우함을 보인다. 보안이 외부 장치가 아닌 아키텍처의 내재적 설계 과제로 이동했다.

**(4) 자기 진화의 코드화**: AgentFactory는 성공 경험을 텍스트가 아닌 실행 가능한 서브에이전트 코드로 축적·재사용한다. 서브에이전트는 에이전트가 스스로 구축하는 도구 라이브러리이자, RL의 정책 저장 철학을 코드 수준에서 구현한 자기 진화 연구의 전환점이다.

**(5) 통합 환경 설계**: VideoAtlas는 비디오를 계층적 그리드로 표현해 캡션 없이 로그 스케일 무손실 탐색을 실현하고, AgentVLN은 VLM의 2D 의미 이해를 3D 공간 추론으로 확장한다. FileGram·MAESTRO·CADENCE와 함께 디지털–물리–시각 환경을 아우르는 범용 에이전트 스펙트럼을 형성한다.

**(6) 도메인 특화 확장**: MALLES는 LLM을 이질적 경제 행위자로 활용해 선호도 정렬 기반 경제 시뮬레이션을 구현하고, Traffic Responsibility는 시각 이해와 법률 추론의 간극을 멀티 에이전트 협업(영상 해석–법규 매칭–책임 산정)으로 최초로 메운다.

## 2. 논문 간 관계

**일치**: "개별 능력보다 구조적 설계가 성능을 좌우한다"로 강하게 수렴한다. 경량 템플릿, 소형 모델 후훈련, 메모리 거버넌스, 경험의 코드 결정화가 모두 이를 지지한다.

**보완**: 평가 축(TDAD, Blindfolded)이 드러낸 신뢰성 결핍에 구조 축(Governed Memory, Differential Privacy)이 설계적 해법을 제시한다. VideoAtlas(표현)와 AgentVLN(행동)은 환경 이해 파이프라인의 상·하류를 담당하며, Blindfold의 편향 차단 익명화와 Differential Privacy의 프라이버시 익명화는 동일 기법의 목적 분화다.

**긴장**: 확장론(embodied 확장, 서브에이전트 증식)과 축소론(경량 템플릿, 소형 모델)이 자원 배분 관점에서 대비된다. 특히 AgentFactory의 무한 증식 가능한 서브에이전트 풀은 Governed Memory가 경고하는 거버넌스 공백을 정확히 겨냥한다 — 모순이라기보다 서로가 상대의 다음 연구 과제를 제시하는 관계다.

## 3. 트렌드와 미래 방향

1. **검증 가능성의 1급 원리화**: 검증 가능한 보상(PrivEsc), 실행 가능 코드(AgentFactory), 익명화 검증(Blindfolded), 회귀 테스트(TDAD)가 훈련·진화·평가 전반의 공통 분모가 되고 있다.
2. **에이전트 인프라 시대**: 단일 에이전트 능력 경쟁에서 메모리·정체성·프라이버시 거버넌스를 갖춘 프로덕션 인프라 경쟁으로 이동하고 있다.
3. **코드라는 공통 매개**: 경험→코드(AgentFactory), 코드→영향 그래프(TDAD), 소프트웨어→환경(Gym-Anything)으로, 코드가 학습·평가·환경을 잇는 1급 매개체로 부상했다.
4. **미래 방향**: 증식하는 서브에이전트 풀의 거버넌스 통합, 회귀·편향·해석 가능성을 아우르는 다차원 벤치마크 표준화, 프라이버시 보장형 엔터프라이즈 배포, 창의적·체화 영역까지 확장되는 범용 에이전트의 통합 평가가 다음 과제다.
