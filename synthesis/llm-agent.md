# Llm Agent: 합성 분석

**생성일**: 2026-09-21 | **최종 업데이트**: 2026-11-02
**관련 논문**: 264편 (+5편)

> 본 업데이트: 논문 수를 259편에서 264편으로 갱신. 신규 편입 논문은 기존 6대 축의 근거를 보강하는 방향으로 수렴해 축 구조를 유지했으며, 전판에서 미완성이던 트렌드·미래 방향 섹션을 완성했다.

## 1. 핵심 연구축

**(1) 평가의 현실화**: TDAD는 AST 기반 코드-테스트 그래프로 "풀면서 망가뜨리지 않는지"를 측정하고, Blindfolded LLMs는 티커 익명화로 암기·생존자 편향을 제거하며, Traffic Responsibility는 법적 근거의 해석 가능성 자체를 척도로 삼는다. 공통 질문은 "성능 수치의 진위를 어떻게 보장하는가"다.

**(2) 구조적 효율성**: 64-Token Template은 64토큰 템플릿으로 반복적 프롬프트 확장과 동등한 창의성을, Post-Training Local LLM은 4B 모델의 SFT+RL 후훈련만으로 Claude Opus 4.6급 성능(95.8% vs 97.5%)과 100배 비용 절감을 실증한다. "Less LLM, More Structure"의 쌍둥이 증거다.

**(3) 보안·거버넌스 내재화**: Differential Privacy는 기업 데이터 관점의 프라이버시–품질 최적 트레이드오프를 수학적으로 정립하고, Governed Memory는 메모리 사일로 등 5가지 구조적 과제를 통해 공유 메모리 거버넌스가 시스템 신뢰성을 좌우함을 보인다. 보안이 외부 장치에서 아키텍처의 내재적 설계 과제로 이동했다.

**(4) 자기 진화의 코드화**: AgentFactory는 성공 경험을 텍스트가 아닌 실행 가능한 서브에이전트 코드로 축적·재사용한다. RL의 정책 저장 철학을 코드 수준에서 구현한 자기 진화 연구의 전환점이다.

**(5) 통합 환경 설계**: VideoAtlas는 비디오를 계층적 그리드로 표현해 로그 스케일 무손실 탐색을 실현하고, AgentVLN은 VLM의 2D 의미 이해를 3D 공간 추론으로 확장한다. FileGram·MAESTRO·CADENCE와 함께 디지털–물리–시각 환경을 아우르는 범용 에이전트 스펙트럼을 형성한다.

**(6) 도메인 특화 확장**: MALLES는 LLM을 이질적 경제 행위자로 활용한 선호도 정렬 기반 경제 시뮬레이션을 구현하고, Traffic Responsibility는 영상 해석–법규 매칭–책임 산정의 멀티 에이전트 협업으로 시각 이해와 법률 추론의 간극을 최초로 메운다.

## 2. 논문 간 관계

**일치**: "개별 능력보다 구조적 설계가 성능을 좌우한다"로 강하게 수렴한다. 경량 템플릿, 소형 모델 후훈련, 메모리 거버넌스, 경험의 코드 결정화가 모두 이를 지지한다.

**보완**: 평가 축(TDAD, Blindfolded)이 드러낸 신뢰성 결핍에 구조 축(Governed Memory, Differential Privacy)이 설계적 해법을 제시한다. VideoAtlas(표현)와 AgentVLN(행동)은 환경 이해 파이프라인의 상·하류를 담당하며, Blindfold의 편향 차단 익명화와 Differential Privacy의 프라이버시 익명화는 동일 기법의 목적 분화다.

**긴장**: 확장론(embodied 확장, 서브에이전트 증식)과 축소론(경량 템플릿, 소형 모델)이 자원 배분 관점에서 대비된다. 특히 AgentFactory의 증식형 서브에이전트 풀은 Governed Memory가 경고하는 거버넌스 공백을 정확히 겨냥한다 — 모순이라기보다 서로가 상대의 다음 연구 과제를 제시하는 관계다.

## 3. 트렌드와 미래 방향

1. **검증 가능성으로의 중심 이동**: 벤치마크의 질문이 "풀 수 있는가"에서 "망가뜨리지 않는가, 암기가 아닌 이해인가"로 이동한다. 회귀율·편향 제거 성능이 해결률과 병렬되는 새 평가 문법이 형성되고 있다.

2. **경험의 매개체 진화**: 텍스트 프롬프트 → 실행 가능 코드(AgentFactory) → 검증 가능 보상(Post-Training RL)으로, 에이전트 학습 결과물이 구조화되고 감사 가능해진다.

3. **거버넌스 인프라의 부상**: 메모리 거버넌스·프라이버시·기계 정체성 등 배포 단계의 문제가 연구 주류로 편입되며 에이전트 연구가 학계–산업 공통의 인프라 과제화되고 있다.

4. **행위자화의 확산**: 경제 시뮬레이션(MALLES)과 법적 책임 판단(Traffic Responsibility)에서 LLM 에이전트가 사회·제도적 의사결정 주체로 기능하기 시작한다.

**미래 방향**: (a) 자기 진화(AgentFactory)와 거버넌스(Governed Memory)의 통합 — "진화하되 감사 가능한" 에이전트, (b) 소형 특화 모델과 대형 범용 모델의 하이브리드 오케스트레이션, (c) 디지털–물리–시각 환경을 관통하는 범용 에이전트 평가 표준의 정립.
