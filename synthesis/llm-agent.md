# Llm Agent: 합성 분석

**생성일**: 2026-09-21 | **최종 업데이트**: 2026-10-05
**관련 논문**: 258편 (+4편)

> 본 업데이트: 논문 수를 254편에서 258편으로 갱신하고, 전판에서 중단된 트렌드·미래 방향 섹션을 완성했다. 신규 편입 논문은 기존 6대 축의 근거를 보강하는 방향으로 수렴하여, 축 구조는 유지한다.

## 1. 핵심 연구축

**(1) 평가의 현실화**: TDAD는 AST 기반 코드-테스트 그래프로 "풀면서 망가뜨리지 않는지"를 측정해 해결률 중심 벤치마크의 사각지대를 메우고, Blindfolded LLMs는 티커 익명화로 암기·생존자 편향을 제거한다. Traffic Responsibility는 법적 근거의 해석 가능성 자체를 척도로 삼는다. 공통 질문은 "성능 수치의 진위를 어떻게 보장하는가"다.

**(2) 구조적 효율성**: 64-Token Template은 64토큰 템플릿으로 반복적 프롬프트 확장과 동등한 창의성을 달성하고, Post-Training Local LLM은 4B 모델의 SFT+RL 후훈련만으로 Claude Opus 4.6급 성능(95.8% vs 97.5%)과 100배 추론 비용 절감을 실증한다. "Less LLM, More Structure"의 쌍둥이 증거다.

**(3) 보안·거버넌스 내재화**: Differential Privacy는 기업 데이터 관점의 프라이버시–품질 최적 트레이드오프를 수학적으로 정립하고, Governed Memory는 메모리 사일로·거버넌스 파편화 등 5가지 구조적 과제를 통해 공유 메모리 거버넌스가 시스템 신뢰성을 좌우함을 보인다. 보안이 외부 장치에서 아키텍처의 내재적 설계 과제로 이동했다.

**(4) 자기 진화의 코드화**: AgentFactory는 성공 경험을 텍스트가 아닌 실행 가능한 서브에이전트 코드로 축적·재사용한다. RL의 정책 저장 철학을 코드 수준에서 구현한 자기 진화 연구의 전환점이다.

**(5) 통합 환경 설계**: VideoAtlas는 비디오를 계층적 그리드로 표현해 로그 스케일 무손실 탐색을 실현하고, AgentVLN은 VLM의 2D 의미 이해를 3D 공간 추론으로 확장한다. FileGram·MAESTRO·CADENCE와 함께 디지털–물리–시각 환경을 아우르는 범용 에이전트 스펙트럼을 형성한다.

**(6) 도메인 특화 확장**: MALLES는 LLM을 이질적 경제 행위자로 활용해 선호도 정렬 기반 경제 시뮬레이션을 구현하고, Traffic Responsibility는 영상 해석–법규 매칭–책임 산정의 멀티 에이전트 협업으로 시각 이해와 법률 추론의 간극을 최초로 메운다.

## 2. 논문 간 관계

**일치**: "개별 능력보다 구조적 설계가 성능을 좌우한다"로 강하게 수렴한다. 경량 템플릿, 소형 모델 후훈련, 메모리 거버넌스, 경험의 코드 결정화가 모두 이를 지지한다.

**보완**: 평가 축(TDAD, Blindfolded)이 드러낸 신뢰성 결핍에 구조 축(Governed Memory, Differential Privacy)이 설계적 해법을 제시한다. VideoAtlas(표현)와 AgentVLN(행동)은 환경 이해 파이프라인의 상·하류를 담당하며, Blindfold의 편향 차단 익명화와 Differential Privacy의 프라이버시 익명화는 동일 기법의 목적 분화다.

**긴장**: 확장론(embodied 확장, 서브에이전트 증식)과 축소론(경량 템플릿, 소형 모델)이 자원 배분 관점에서 대비된다. 특히 AgentFactory의 무한 증식 가능한 서브에이전트 풀은 Governed Memory가 경고하는 거버넌스 공백을 정확히 겨냥한다 — 모순이라기보다 서로가 상대의 다음 연구 과제를 제시하는 관계다.

## 3. 트렌드와 미래 방향

1. **검증 가능성으로의 중심 이동**: 벤치마크의 질문이 "풀 수 있는가"에서 "믿을 수 있는가"로 이동한다. 회귀(TDAD), 편향(Blindfolded), 해석 가능성(Traffic Responsibility)이 새 평가 차원으로 부상했다.
2. **경험의 재산화**: 리플렉션·프롬프트 같은 텍스트 저장에서 실행 가능 코드(AgentFactory), 최소 템플릿(64-Token)으로 학습 산물이 구조화되고 검증 가능한 형태로 경화된다.
3. **에이전트 인프라의 성숙**: 메모리 거버넌스, 기계 정체성, 차등 프라이버시 등 운영체제 계층의 문제가 연구의 중심 무대로 올라왔다.
4. **환경의 무한 확장**: 코드·웹·GUI를 넘어 물리 공간(VLN), 장시간 비디오, 경제·법률 시뮬레이션까지 행동 공간이 도메인 불문 확장 중이다.

**미래 방향**: (a) 자기 진화 에이전트 풀에 대한 거버넌스·감사 체계, (b) 암기와 이해를 구분하는 표준화된 신뢰성 인증, (c) 에지 배포 가능한 경량 체화 에이전트의 실증이 차기 연구 과제다.
