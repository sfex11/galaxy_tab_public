# Transformer: 합성 분석

**생성일**: 2026-10-12 | **관련 논문**: 77편 | **최종 업데이트**: 2026-11-02(제3판)

> **업데이트 노트**: 4대 패턴 골격과 중심 테제("외부 보조물의 내부 구조물화") 유지. 전 패턴을 관통하는 상위 방법론 **"동결 모델 프로빙"** 을 신설하고, 신뢰·효율·그라운딩 축의 긴장 구조를 재정리했다.

## 공통 주제: 가중치는 얼린 채, 탐침을 꽂는다

2026년 초 Transformer 연구의 표면 조건은 "training-free"지만, 이면의 통일된 동작은 둘이다. (1) 학습되거나 상대적인 **보조물** — draft 모델, 캡션 파이프라인, RLHF 사후 교정, 소프트웨어 베이스라인 — 을 가중치 내부 구조 혹은 문제 고유의 절대 기준으로 교체한다. (2) 동결된 모델에 추론 시점의 **탐침(probe)** 을 꽂아 미기록 능력을 끌어낸다: mask token(프로빙 MTP), 탈편향 프롬프트 쌍(임베딩 보간), 중요도 스코어(토큰 프루닝), 계층 그리드(VideoAtlas). 학습 대신 탐침과 검증으로 능력을 확장하는 것이 이 시기의 방법론적 서명이다.

## 네 가지 핵심 패턴

**① 잠재 공간의 미개척 능력** — next-token 학습만 한 모델에서 mask token 프로빙으로 드래프트 없는 multi-token prediction(트리 샘플링+검증 패스)이, 텍스트 임베딩 보간으로 학습 없는 연속 이미지 편집이 성립한다. 동결 가중치 안에 다중 토큰 예측 능력과 시각 제어 축이 이미 존재한다.

**② 토큰의 전 생애주기 최적화** — LoST의 의미 계층 토큰화가 **설계**(토큰화가 학습될 구조적 사전 지식을 결정), ViT–LLM 경계를 관통하는 통합 시공간 스코어링이 **선택**, VideoAtlas의 로그 복잡도·무손실 계층 그리드가 **재구성**, 프로빙 MTP가 **병렬 탐색**을 담당한다.

**③ 물리 세계 확장, 두 전략** — GMT(6-DOF 궤적 합성)와 RHYME-XT(갈레르킨 투영으로 PIDE→ODE 축소)는 어텐션의 전역 상호작용 모델링을 제어·시뮬레이션 인터페이스로 전용한다. 공간 그라운딩은 입력 증강(Egomotion-Aware의 IMU)과 능력 내재화(Loc3R-VLM의 단안 3D 추론)로 갈리나, 무거운 3D 표현 탈피에서 수렴한다.

**④ 상대 지표에서 절대 지표로** — Box Maze는 신뢰성을 사후 행동 교정이 아닌 추론 프로세스 아키텍처에서 강제하고, SOL-ExecBench는 커널 성능을 하드웨어 이론 한계(Speed-of-Light) 대비 절대 효율로 측정한다. 행동·소프트웨어 기준선의 구조·물리 기준선 대체다.

## 일치·모순·보완

가장 날카로운 긴장은 **"내부를 믿는다"(프로빙·보간) vs "내부를 통제한다"(Box Maze)**다. 표현의 풍부함을 능력의 원천으로 보는가, 방어 대상으로 보는가의 축이되, 풍부함≠신뢰성이므로 상보적이다. 효율 진영에는 손실 스펙트럼이 성립한다: VideoAtlas의 무손실 원칙 → MTP의 손실 탐색+엄격 검증 → 프루닝의 task-aware 손실 허용. "어디의 손실을 허용할 것인가"의 설계 연속선이다. 공통 메커니즘은 **검증 루프**다 — 샘플 후 검증(MTP), 스코어 후 프루닝, 한계 대비 측정(SOL-ExecBench), 단계 무결성 확인(Box Maze). 신뢰의 근거가 학습된 관습에서 검증 가능한 앵커로 이동 중이다.

## 트렌드와 전망

시퀀스 병목은 네 방향에서 동시 공격받는다: 토큰 수 감소(프루닝·LoST), 순차 병렬화(MTP), 계층 내비게이션(VideoAtlas), 차원 축소(RHYME-XT). 단기엔 설계–선택–재구성–병렬화를 아우르는 '토큰 거버넌스' 통합과 zero-draft speculative decoding의 배포 확산이, 중기엔 프로빙의 범용 기법화(임베딩 공간 프로그래밍)가, 장기엔 하드웨어 한계·프로세스 무결성 같은 절대 앵커의 표준화가 관건이다. Transformer는 텍스트 생성기를 넘어 물리 세계의 제어 인터페이스이자, 검증 가능한 절대 기준 위에서 평가되는 연산 단위로 재정의되고 있다.
