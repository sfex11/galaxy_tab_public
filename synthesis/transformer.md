# Transformer: 합성 분석

**생성일**: 2026-07-27
**관련 논문**: 73편
**최종 업데이트**: 2026-09-14

> **업데이트 노트**: 논문 수 71편 → 73편 확대를 반영해 재생성. 기존 4대 패턴 골격을 유지하되, 토큰 중심 최적화를 '설계–선택–재구성' 생애주기 프레임으로 재편하고, 프루닝(손실 허용)과 VideoAtlas(무손실 원칙)의 대립을 신규 논점으로 추가했다.

## 공통 주제: 가중치는 얼린 채, 가능성을 깨운다

2026년 초 Transformer 연구는 "추가 학습 없이"라는 공통 전제 아래 네 갈래로 수렴한다. ① 동결된 가중치의 내부 표현을 탐침 삼아 숨은 능력을 끌어내는 **훈련 없는 능력 유발**, ② 토큰을 제1 최적화 단위로 삼는 **토큰 경제학**, ③ 텍스트를 넘어 기하·물리·시공간으로 뻗는 **모달리티 확장**, ④ 상대 평가를 탈피하는 **절대 지표 전환**이다.

## 네 가지 핵심 패턴

**① 잠재 공간의 미개척 능력**: 임베딩 공간 프로빙은 next-token prediction만 학습한 모델에 mask token을 즉석 입력해 드래프트 모델 없는 speculative decoding을 실현한다. 텍스트 임베딩 보간은 학습 없이 보간만으로 연속적 이미지 편집을 보인다. 공통 발견은 "동결된 가중치 안에 다중 토큰 예측 능력과 시각 제어 축이 이미 존재한다"는 것.

**② 토큰의 전 생애주기 최적화**: LoST가 토큰의 **설계**(의미론적 계층 토큰화가 구조적 사전 지식을 결정)를, 통합 시공간 토큰 스코어링은 **선택**(ViT–LLM 경계를 관통하는 프루닝)을, VideoAtlas는 **재구성**(계층적 그리드, 로그 복잡도 탐색)을 담당한다. 토큰 처리가 아키텍처 전층의 통합 최적화 대상이 된 것이다.

**③ 물리 세계로의 확장**: GMT(6-DOF 궤적 합성), Loc3R-VLM(단안 비디오 3D 추론), Egomotion-Aware(IMU 통합), RHYME-XT(PIDE의 ODE 축소)는 어텐션의 전역 상호작용 모델링을 기하·물리 인터페이스로 전용한다.

**④ 상대 지표에서 절대 지표로**: Box Maze는 추론 신뢰성을 RLHF류 사후 교정이 아닌 프로세스 아키텍처에서 강제하고, SOL-ExecBench는 커널 성능을 하드웨어 이론 한계(Speed-of-Light) 대비 절대 효율로 측정한다.

## 일치·모순·보완 관계

가장 날카로운 모순은 **"내부를 믿는다"(프로빙·보간) vs "내부를 통제한다"(Box Maze)**다. 전자는 표현의 풍부함을 능력의 원천으로, 후자는 구조적 방어 대상으로 삼는다 — 풍부함이 곧 신뢰성은 아니라는 점에서 양자는 상보적이다. 효율 진영 내부에는 통합 토큰 스코어링의 task-aware 손실 프루닝과 VideoAtlas의 무손실 원칙이라는 대립축이 형성됐다. 한편 LoST의 설계와 프루닝의 선택, VideoAtlas의 계층화와 TriAttention류 어텐션 효율화는 각각 토큰·장문맥 문제의 서로 다른 층위를 공략한다.

## 트렌드와 전망

단기에는 토큰 설계–선택–탐색을 관통하는 '토큰 거버넌스'의 통합이, 중기에는 잠재 공간 프로그래밍(프로빙·보간)의 범용 기법화가, 장기에는 효율·신뢰·확장을 아우르는 절대 평가 기준의 정립이 관건이다. Transformer는 텍스트 모델을 넘어 물리 세계와 하드웨어를 관통하는 **범용 시퀀스 처리기**로 진화하고 있다.
