# Transformer: 합성 분석

**생성일**: 2026-07-27
**관련 논문**: 76편
**최종 업데이트**: 2026-09-14

> **업데이트 노트**: 논문 수 73편 → 76편 확대를 반영해 재생성. 4대 패턴 골격을 유지하되, ② 토큰 생애주기에 '병렬 예측'(임베딩 프로빙 기반 MTP) 단계를 추가하고, ③ 물리 확장 진영에서 '입력 증강 vs 능력 내재화'라는 하위 축을 분리했으며, 효율 진영의 손실 스펙트럼을 신규 논점으로 정리했다.

## 공통 주제: 가중치는 얼린 채, 가능성을 깨운다

2026년 초 Transformer 연구는 "추가 학습 없이"라는 전제 아래 네 갈래로 수렴한다: ① 동결된 가중치의 잠재 표현을 탐침 삼아 숨은 능력을 끌어내는 **훈련 없는 능력 유발**, ② 토큰을 제1 최적화 단위로 삼는 **토큰 경제학**, ③ 기하·물리·시공간으로 뻗는 **모달리티 확장**, ④ 상대 평가를 탈피하는 **절대 지표 전환**.

## 네 가지 핵심 패턴

**① 잠재 공간의 미개척 능력**: 임베딩 공간 프로빙은 next-token prediction만 학습한 모델에 mask token을 즉석 입력해 드래프트 모델 없는 speculative decoding을 실현한다. 텍스트 임베딩 보간은 학습 없이 연속적 이미지 편집을 보인다. 공통 발견은 "동결된 가중치 안에 다중 토큰 예측 능력과 시각 제어 축이 이미 존재한다"는 것.

**② 토큰의 전 생애주기 최적화**: LoST가 **설계**(의미론적 계층 토큰화가 구조적 사전 지식을 결정), 통합 시공간 토큰 스코어링이 **선택**(ViT–LLM 경계 관통 프루닝), VideoAtlas가 **재구성**(계층적 그리드, 로그 복잡도 탐색), 임베딩 프로빙 MTP가 **병렬 예측**(토큰 트리 샘플링+검증)을 담당한다. 토큰의 생성·선택·조직·예측 전 과정이 통합 최적화 대상이 됐다.

**③ 물리 세계로의 확장, 두 전략**: GMT(6-DOF 궤적 합성), RHYME-XT(PIDE→ODE 축소)는 어텐션의 전역 상호작용 모델링을 제어 인터페이스로 전용한다. 공간 그라운딩은 두 갈래로 갈린다 — Egomotion-Aware는 IMU라는 외부 물리 신호로 입력을 증강하고, Loc3R-VLM은 3D 추론 능력을 2D VLM 내부에 내재화한다. 무거운 3D 표현 의존에서 벗어난다는 지점에서 수렴한다.

**④ 상대 지표에서 절대 지표로**: Box Maze는 추론 신뢰성을 RLHF류 사후 교정이 아닌 프로세스 아키텍처에서 강제하고, SOL-ExecBench는 커널 성능을 하드웨어 이론 한계(Speed-of-Light) 대비 절대 효율로 측정한다. 행동·소프트웨어 기준선을 구조·물리 기준선으로 대체하는 공통 전략이다.

## 일치·모순·보완 관계

가장 날카로운 모순은 **"내부를 믿는다"(프로빙·보간) vs "내부를 통제한다"(Box Maze)**다. 전자는 표현의 풍부함을 능력의 원천으로, 후자는 구조적 방어 대상으로 삼는다 — 풍부함이 곧 신뢰성은 아니므로 상보적이다. 효율 진영 내부에는 손실 스펙트럼이 형성됐다: VideoAtlas의 무손실 원칙 → MTP의 손실 탐색+엄격 검증 → 토큰 프루닝의 task-aware 손실 허용. 공간 확장에서도 입력 증강(IMU)과 능력 내재화(단안 3D)가 상보적 대안으로 공존하며, LoST·프루닝과 TriAttention류 어텐션 효율화는 각기 다른 층위의 병목을 공략한다.

## 트렌드와 전망

단기에는 토큰 설계–선택–탐색–병렬화를 관통하는 '토큰 거버넌스'의 통합이, 중기에는 잠재 공간 프로그래밍(프로빙·보간)의 범용 기법화와 zero-draft speculative decoding의 배포 확산이, 장기에는 하드웨어 한계와 프로세스 무결성 같은 절대 평가 기준의 정립이 관건이다. Transformer는 텍스트 모델을 넘어 물리 세계와 하드웨어를 관통하는 **범용 시퀀스 처리기**로 진화하고 있다.
