# Vlm: 합성 분석

**생성일**: 2026-07-27
**관련 논문**: 26편
**최종 업데이트**: 2026-09-21

## 1. 공간 맹점의 해소: 암묵-명시 스펙트럼

Loc3R-VLM, Generation Models Know Space, 3D-Layout-R1, Meanings and Measurements, 3DCity-LLM은 "VLM은 의미적 그라운딩에 강하나 3D·메트릭 추론에는 설계되지 않았다"는 진단을 공유한다. 해법은 스펙트럼을 이룬다. 한 극단은 **암묵적 프라이어 전이**다 — 비디오 생성 모델이 학습 중 획득한 3D 이해를 명시적 3D 데이터 없이 전이한다(Generation Models Know Space). 중간은 모델 내재 능력의 직접 훈련(단안 비디오만으로 3D 위치 추정을 학습하는 Loc3R-VLM)과 스케일 확장(객체·관계·전역의 coarse-to-fine 인코딩으로 도시 규모를 다루는 3DCity-LLM)이다. 반대 극단은 **명시적 구조 주입**으로, 장면 그래프 위의 구조적 추론(3D-Layout-R1)과 의미·공간·메트릭을 에이전트별로 분담해 확률적으로 융합하는 모듈 분리(Meanings and Measurements)가 있다. 암묵과 명시의 하이브리드 결합은 아직 시도되지 않았다.

## 2. 평가 축의 이동: 정답률에서 불확실성 하 과정의 질로

NavTrust와 AMIGO는 평가 패러다임을 **불확실성 하 의사결정 과정의 질**로 옮긴다. NavTrust는 VLN·OGN에 체계적 입력 손상을 가해 명목-손상 성능 격차를 정량화한다 — 외부 교란에 대한 강건성이다. AMIGO는 다중 턴 전략적 질문 생성과 정보 통합을 측정한다 — 내부 정보 획득 전략의 효율이다. 기술 연구와 상보적인데, DRIVE-Nav는 프론티어 포인트 대신 지속적 방향을 탐색 단위로 삼아 관측 불완전성을, Chameleon은 원시 지각 단서를 보존하는 에피소딕 메모리로 비마르코프 의사결정을 구조적으로 해소하며, MARCUS는 에이전틱 VLM 설계를 임상 심장학에 이식해 도메인 특화 멀티모달 에이전트의 실현 가능성을 입증한다. 구축(DRIVE-Nav)과 평가(NavTrust)의 역할 분담이 뚜렷하다.

## 3. 압축 논쟁: 유무가 아니라 계층과 시점의 문제

VISOR와 Chameleon은 서로 다른 계층에서 같은 결론에 도달한다 — **조기 정보 압축이 어려운 태스크 실패의 원인**이라는 것. VISOR는 시각 토큰 축소 대신 레이어별 cross-attention을 동적으로 희소화하고, Chameleon은 의미 압축 메모리 대신 원시 지각 단서를 보존한다. 3DCity-LLM은 계층적 압축으로 도시 규모를 달성하는 반례다. 쟁점은 '압축하느냐 마느냐'가 아니라 **어느 계층에서 무엇을 언제 보존할지**며, 세 연구는 압축을 의사결정이 정보를 소비하는 시점까지 미루는 **압축 지연 원리**로 수렴한다 — VISOR는 연산에서, Chameleon은 메모리에서, 3DCity-LLM은 태스크별 필요 해상도에서 이를 구현한다.

## 4. 구조적 긴장: 내재화 vs 모듈화, 그리고 공진화

내재 능력 강화로 일반성을 추구하는 축(Loc3R-VLM, 3D-Layout-R1)과 모듈화·상호작용 설계로 정밀성·신뢰성을 얻는 축(Meanings and Measurements, MARCUS, AMIGO)이 대비된다. 주목할 점은 신뢰성·상호작용 중심의 신규 평가(§2)가 구조적으로 에이전틱 설계에 유리하다는 것 — 평가와 아키텍처가 공진화하고 있으며, VLM 연구의 질문이 "모델이 얼마나 아는가"에서 "얼마나 신뢰 가능하게 상호작용하는가"로 이동 중임을 시사한다.

## 5. 트렌드와 미래 방향

트렌드: ① 2D 인식 → 3D·메트릭 그라운딩, ② 정적 단일 턴 평가 → 손상 인식·상호작용형 평가, ③ 단일 모델 → 에이전틱·다중 에이전트 구조, ④ 효율화의 축이 토큰 축소 → 상호작용 희소화로 이동. 미래 과제: **강건성×상호작용 통합 벤치마크**(NavTrust의 손상 조건 하에서 AMIGO식 전략적 질의 능력 측정), **암묵-명시 하이브리드 공간 프라이어**(생성 모델 프라이어와 장면 그래프·메트릭 구조의 결합), **도메인 에이전트의 신뢰성 평가**(MARCUS적 의료 VLM에 NavTrust식 손상 평가 적용)가 유망하다.
