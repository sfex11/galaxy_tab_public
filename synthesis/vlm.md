# Vlm: 합성 분석

**생성일**: 2026-07-27
**관련 논문**: 26편
**최종 업데이트**: 2026-08-31

## 1. 공간 맹점과 극복의 두 갈래

Loc3R-VLM, 3D-Layout-R1, Meanings and Measurements, Generation Models Know Space는 일관되게 "VLM은 의미적 그라운딩에 강하지만 3D·메트릭 추론에는 설계되지 않았다"는 문제 의식을 공유한다. 해결 경로는 둘로 나뉜다. **암묵적 프라이어 전이**는 비디오 생성 모델이 학습 과정에서 획득한 3D 이해를 명시적 3D 데이터 없이 전이하고, **명시적 구조 주입**은 장면 그래프 추론(3D-Layout-R1), 단안 비디오 기반 3D 학습(Loc3R-VLM), 의미·공간·메트릭의 모듈 분리(Meanings and Measurements), coarse-to-fine 인코딩(3DCity-LLM)으로 구현된다. 두 경로는 상보적이나 상호 검증은 아직 이루어지지 않았다.

## 2. 체화된 배포: 성능에서 신뢰성·상호작용으로

가장 뚜렷한 공통 논점은 평가 패러다임의 전환이다. NavTrust는 입력 손상 하의 강건성을, AMIGO는 다중 턴 전략적 질문과 정보 통합 능력을 측정하며, 공통적으로 정답률이 아닌 **의사결정 과정의 질**로 평가 축을 이동시킨다. 기술 측면에서 DRIVE-Nav는 지속적 방향(persistent direction) 탐색으로 관측 불완전성 문제를, Chameleon은 에피소딕 메모리로 비마르코프 의사결정 문제를 구조적으로 해소한다. MARCUS는 에이전틱 VLM 설계를 임상 심장학에 이식해 도메인 특화 멀티모달 에이전트의 실현 가능성을 입증한다.

## 3. 정보 압축을 둘러싼 공통 반론

VISOR와 Chameleon은 서로 다른 계층에서 같은 결론에 도달한다: **조기 정보 압축이 어려운 태스크 실패의 원인**이라는 것. VISOR는 시각 토큰 축소의 정보 병목을 비판하며 레이어별 cross-attention을 동적으로 희소화하고, Chameleon은 의미 압축 메모리가 세밀한 지각 단서를 버림을 지적한다. 반면 3DCity-LLM은 coarse-to-fine 압축으로 도시 규모 스케일을 달성한다. 쟁점은 압축의 유무가 아니라 **어느 계층에서 무엇을 보존할지**다.

## 4. 단일 모델 vs 다중 에이전트의 긴장

Loc3R-VLM·3D-Layout-R1이 단일 모델의 내재적 능력 강화를 추구하는 반면, Meanings and Measurements는 다중 에이전트 분담과 확률적 통합을 택한다. MARCUS와 AMIGO의 성공은 상호작용·도메인 특화 시나리오에서 모듈화된 에이전틱 설계가 유리함을 시사한다. 단일 모델은 일반성을, 다중 에이전트는 정밀성과 신뢰성을 우선하는 trade-off로 읽힌다.

## 5. 미래 방향

- **신뢰성-성능 통합 평가**: NavTrust의 강건성 평가와 AMIGO의 상호작용 평가를 결합한 통합 벤치마크
- **암묵-명시 하이브리드**: 생성 모델 프라이어와 장면 그래프 구조의 결합 및 교차 검증
- **보존 계층의 체계화**: 효율화(VISOR)와 메모리(Chameleon)를 아우르는 "무엇을 어디에 보존할 것인가"의 통합 이론
- **효율적 스케일 확장**: VISOR식 희소 상호작용의 도시 규모 3D 처리(3DCity-LLM) 적용
