# Distribution Shift: 합성 분석

## 📌 개요

수집된 3편의 논문은 분포 이동을 서로 다른 축에서 조명하며, 합쳐지면 하나의 분류체계를 이룬다: **외생적 이동**(환경이 스스로 변함), **내생적 이동**(정책의 행동이 자신의 입력 분포를 오염), **성분 분해된 이동**(이동의 종류별 효과 분리). 세 논문이 함께 시사하는 통합 명제는 "분포 이동은 단일 장애물이 아니라, 유형별로 대응 전략·평가 방법·성공의 정의가 달라지는 다층 구조"라는 것이다.

## 🔍 이동의 세 유형

1. **외생적 이동 → 신호로 전환** (UAV 야생화재, 2026-09-11): 화재 경계처럼 스스로 확산하는 환경은 비정상 동역학을 만들지만, 이를 추적 좌표계로 삼으면 장애물이 항행 신호가 된다. 정책 수렴의 의미가 '최적해 도달'에서 '추적 행동의 안정화'로 재정의된다. 단, 시뮬레이션 전용이라 실환경 검증 간극이 남는다.

2. **내생적(자기유발) 이동 → 교정 대상** (OPTED, 2026-09-21): 행동 클로닝 사전학습 정책은 폐루프 배포에서 오류 누적으로 스스로 훈련 분포 밖으로 이탈한다. 렌더 프리 교사를 통한 온폴리시 폐루프 포스트트레이닝이 이를 완화하며, LLM 에이전트의 다단계 도구 호출과 동일 구조임을 입증해 도메인 불변 문제임을 보인다.

3. **성분 분해된 이동 → 측정 변수** (신경 PDE 서러게이트, 2026-09-21): 사전학습 이득은 기하학적 이동과 물리 모델링 이동으로 분해하고 조건을 일치시켜야만 측정 가능하다. 사전학습의 가치는 이동 종류와 무관한 보편 속성이 아니라 **성분별 조건부** 가치다.

## ⚖️ 논문 간 관계 분석

- **대비**: UAV는 이동을 기회(항행 신호)로, OPTED는 병리(교정 대상)로 취급한다. 동일 현상의 양면이며, OPTED 측 분석이 이 대비를 명시적으로 수행한다.
- **보완**: PDE 논문은 외생/내생이라는 두 축에 '성분 분해'라는 제3축을 추가해 분류체계를 완성한다.
- **공통 발견**: 세 경우 모두 이동이 '성공/이득의 정의' 자체를 바꾼다 — 수렴의 재정의, 폐루프 성능 우선, 조건부 이득.
- **공통 한계**: 전부 시뮬레이션 기반 검증이며, 이동 유형을 아우르는 통합 이론은 제시하지 않는다.

## 📈 트렌드와 미래 방향

1. **배포 현실적 평가로의 이행**: 개루프·정적 벤치마크에서 폐루프·온폴리시 평가로 패러다임이 이동 중 (closed-loop training).
2. **교차 도메인 수렴**: 언어 에이전트, 자율주행, 로보틱스, 과학 ML에서 동일한 이동 구조가 재현 — 도메인 불변 이론에 대한 수요.
3. **미래 방향**: ① 이동 성분 분해와 온폴리시 교정의 결합, ② 외생 비정상성과 내생 오염이 공존하는 실제 재해 대응 환경용 통합 프레임워크, ③ 이동 유형별 sim-to-real 간극의 정량화.
