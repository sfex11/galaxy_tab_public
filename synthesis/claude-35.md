## 개요

Claude 3.5 계열 모델(Claude 3.7 Sonnet, Claude Opus 4.7, Claude Code 등)은 다국어 사회언어학, 법률 추론, 과학 소프트웨어·양자 컴파일러 생성, 에이전트 학습 인프라, 지식 검증 보안 등 광범위한 도메인에서 핵심 평가 대상으로 활용되고 있다. 본 분석은 관련 논문 8종을 바탕으로 Claude 계열의 다각적 역할과 구조적 한계를 종합적으로 고찰한다.

## 핵심 발견 및 논문 간 관계

### 1. 사회언어학적 컨텍스트 민감성

다국어 정중함 연구에 따르면, Claude 3.7 Sonnet은 영어·힌디어·스페인어 환경에서 사용자의 정중함 정도에 따라 응답 품질과 태도가 변동한다. '보편적 예의'란 존재하지 않으며, 상호작용 이력과 언어권에 따라 반응이 달라진다. 다국어 고객 지원 시스템 구축 시 프롬프트 기준을 문화권별로 차별화해야 함을 시사한다.

### 2. 법률 도메인 적용의 양면성: 평가 깊이에 따른 격차

베트남 법률 텍스트 연구에서 Claude 3 Opus는 이중 평가 프레임워크 하에서 법률 문장 단순화 및 추론 벤치마크에서 최상위권 성능을 기록했다. 반면 경쟁법 전문 에이전트(Maat) 연구에서는 일반 Claude 모델이 **전문 도메인 지식 부족**과 **공식 인용 누락**이라는 명백한 한계를 보였다. 이는 모순이 아닌 **평가 깊이의 차이**에서 비롯된다. 표면적 요약에는 강하나, 전문가 수준의 판례 인용이 요구되는 태스크에서는 RAG 결합 없이 한계가 뚜렷하다.

### 3. 과학 코딩 에이전트: 자율성의 프론티어와 한계

"Physics Is All You Need" 연구는 Claude Code(Sonnet/Opus)로 물리학 소프트웨어(CLAX-PT)를 12일간 57세션에 걸쳐 개발하는 과정을 정량화했다. 15개 감독 이벤트 중 10개를 오라클 테스트 기반 자율 반복으로 해결했으나, 도메인 특화 지식이 필요한 3개 문제는 인간 개입으로도 해결되지 않았다. 양자 컴파일러 연구는 이를 한 차원 확장하여, Claude Opus 4.7이 **명세서로부터 전체 파이썬 컴파일러 코드를 생성하고 반복적으로 개선**하는 능력을 최초로 입증했다. 선형 트랩에서 분기 구조 트랩까지 점진적 확장이 가능했으나, 복잡한 아키텍처에서는 여전히 인간 피드백 루프가 필수적이었다.

### 4. Claude Code의 인프라화와 보안 거버넌스 격차

OpenForgeRL 연구는 Claude Code를 Codex, OpenClaw와 함께 **"elaborate inference harness"**로 분류하며, 에이전트 생태계의 기준점으로 자리매김했다. 그러나 CLAUDE.md 보안 규칙 연구는 이 인프라에 내재된 거버넌스 격차를 실증한다. 481개 공개 CLAUDE.md 파일 분석 결과, 자연어 지시어("do not")와 Claude Code의 빌트인 deny 컨트롤은 **동일한 보안 목표를 표현하더라도 상이한 방식으로 에이전트를 제어**하며, 이 격차는 측정 가능한 수준이다. 자연어 규칙은 모델 해석에 의존하는 반면, deny는 실행 차단이므로 보안 보장 수준이 근본적으로 다르다.

### 5. 인식론적 불안정성: 배포 설정에 따른 지식 검증의 변동

의사과학 검증 연구는 Claude가 인종민족주의 의사과학 주장을 평가할 때, API와 웹 인터페이스라는 **배포 설정에 따라 태도가 달라지며**, 5개월간의 시간적 스냅샷에서도 안정적이지 않음을 보였다. Claude가 지식 참조원으로 사용될 때 그 인식론적 입장은 투명하지 않다는 비판을 제기한다.

## 공통 구조: 자율성 한계선의 다면적 현현

여섯 도메인은 Claude의 능력 스펙트럼을 다르게 조명하지만 하나의 결론으로 수렴한다. Claude는 **정형화된 패턴 인식과 일반 추론**에서 뛰어나나, 도메인 깊이가 특정 임계치를 넘으면 반드시 외부 보완이 필요하다. 법률에서의 인용 누락, 과학 코딩에서의 교착, 보안 규칙에서의 해석 의존성, 의사과학에서의 태도 불안정성은 동일한 구조적 한계의 다른 얼굴이다.

## 연구 트렌드 및 미래 방향

논문들은 Claude를 '단독 완결형 솔루션'이 아닌 **고도화된 에이전트 시스템의 구성 요소**로 바라보는 추세를 공유한다. Maat는 Claude를 전문 RAG 파이프라인의 추론 엔진으로, OpenForgeRL은 하네스 아키텍처를 오픈 인프라로 재구성하여 학습 가능하게 만들며, 양자 컴파일러 연구는 인간 피드백 루프와 결합한 반복적 코드 생성 파이프라인을 제안한다. 향후 연구는 자연어 거버넌스와 프로그래밍적 통제의 정형화된 변환 매커니즘, 그리고 배포 설정에 독립적인 인식론적 안정성 보장 방법을 중심으로 전개될 것이다.
