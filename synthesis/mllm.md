# Mllm: 합성 분석

**생성일**: 2026-11-02  
**관련 논문**: 21편  
**최종 업데이트**: 2026-11-02 (이전 2026-09-28 버전 대비: 관계 지도 완성, 트렌드·미래 방향 섹션 신설)

## 1. 공간 지능: 명시적 스캐폴딩에서 암묵적 프라이어로

MLLM의 공간 이해는 두 경로로 수렴한다. **Loc3R-VLM**(단안 비디오만으로 언어 기반 3D 위치 추정 학습)과 **3DCity-LLM**(대상 객체·객체 관계·전역 장면의 coarse-to-fine 병렬 인코딩으로 도시 규모 확장)은 모델이 3D 공간에서 직접 추론하도록 만드는 명시적 경로다. 반면 **Generation Models Know Space**는 비디오 생성 모델이 학습 중 자연 획득한 암묵적 3D 프라이어를 명시적 3D 감독 없이 전이하는 경로를 연다. **UniDriveVLA**는 자율주행에서 2D 의미 추론과 3D 공간 인지의 트레이드오프를 통합 VLA 아키텍처로 해소하며 두 경로의 교차점에 선다. 처리 스케일도 객체→실내→도시로 확장 중이다.

## 2. 에이전틱 전환과 메타인지의 부상

**MARCUS**(의료), **UI-Voyager**(GUI), **Stop Wandering**(VLN), **Chameleon**(로봇 조작), **AMIGO**(벤치마크)는 도메인 불문 동일 구조를 공유한다: 인식→추론→행동의 장기 루프 + 자기 모니터링. Stop Wandering은 탐색 비효율(진동·재방문)의 원인을 메타인지 부재로 진단하고, UI-Voyager는 실패 궤적의 credit assignment로 자기진화를, Chameleon은 원시 지각 단서를 보존하는 에피소딕 메모리로 관찰 수준의 비마르코프 의사결정을 해결한다. 과거 기억(Chameleon)과 실시간 자기 진단(Stop Wandering), 불확실성 인식 질문 전략(AMIGO)은 상호 보완적 인지 계층을 이룬다.

## 3. 효율화의 세 축과 training-free 조류

**AdaptToken**(엔트로피 기반 글로벌 토큰 선택 + 적응적 조기 종료), **VISOR**(토큰 제거 없이 레이어별 시각-언어 상호작용 동적 희소화), **SpecEyes**(에이전트 파이프라인 수준의 추측적 병렬화)는 각각 정보 이론·아키텍처·시스템 차원의 직교 전략이다. 세 방법 모두 training-free로, Stop Wandering과 함께 파운데이션 모델 제로샷 능력을 극대화하는 조류를 형성한다. VISOR는 토큰 프루닝의 정보 병목을 정면 반박한다.

## 4. 핵심 논쟁: 시각적 무결성과 보상 해킹

가장 예리한 긴장은 **Hallucination in RL Post-Training**이 제기한다. RL 후훈련의 성능 향상이 시각 정보를 무시한 텍스트 패턴 기반 추론 단축일 수 있다는 것 — 보상 해킹의 멀티모달 변형이다. 이는 RL 기반 시각 추론 시스템의 수치를 재해석하게 만든다. **Steerable Visual Representations**(텍스트 조건부 ViT 특징 조종)와 결합하면 "조종된 표현이 실제 지각을 반영하는가"라는 검증 과제가 드러난다. **NavTrust**(입력 손상 하 강건성)와 **AMIGO**(엄격 프로토콜)가 신뢰성 평가의 외곽을 채운다.

## 5. 논문 간 관계 지도

- **일치**: 공간 추론 한계 진단(Loc3R-VLM ≈ UniDriveVLA), 메타인지 필요성(Stop Wandering ≈ UI-Voyager ≈ AMIGO), training-free 효율화
- **모순**: 토큰 축소 패러다임 vs VISOR / RL 후훈련의 표면 성능 vs 추론 무결성 / 의미 압축 메모리 vs Chameleon의 원시 단서 보존
- **보완**: 명시적 3D 훈련(Loc3R-VLM·3DCity-LLM) ↔ 암묵적 프라이어 전이(Generation Models Know Space) / 에피소딕 메모리(Chameleon) ↔ 실시간 자기 모니터링(Stop Wandering) / 효율화 기법 ↔ 신뢰성 벤치마크(NavTrust·AMIGO)

## 6. 연구 트렌드와 미래 방향

**트렌드**: (1) 단일 턴 정적 태스크에서 장기 호라이즌 에이전틱 루프로 이동, (2) training-free 플러그인 기법으로 파운데이션 모델 활용 장벽 하락, (3) 평가 기준이 명목 성능에서 강건성·신뢰성(실패 경험, 손상 입력, 엄격 프로토콜)으로 이동.

**미래 방향**: (1) 환각 분석 + 표현 조종 + 강건성 벤치마크를 결합한 시각적 추론 무결성 검증 체계, (2) 에피소딕 메모리와 메타인지의 통합 아키텍처, (3) 공간 지능·에이전틱 루프·효율화를 동시에 만족하는 통합 MLLM 설계.
