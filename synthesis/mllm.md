# Mllm: 합성 분석

**생성일**: 2026-09-15
**관련 논문**: 21편
**최종 업데이트**: 2026-09-15 (이전 버전: 2026-08-31)

## 1. 공간 지능: 명시적 스캐폴딩에서 암묵적 프라이어로

MLLM의 공간 이해 연구는 두 갈래로 수렴한다. **Loc3R-VLM**과 **3DCity-LLM**은 모델이 직접 3D 공간에서 추론하도록 만드는 명시적 경로다(단안 비디오 기반 localization, coarse-to-fine 병렬 브랜치 인코딩). **Generation Models Know Space**는 반대로 비디오 생성 모델이 학습 중 자연 획득한 암묵적 3D 프라이어를 명시적 3D 데이터 없이 전이하는 경로를 제시하며, 명시적 3D 감독의 데이터 부족·일반화 한계를 비판한다. **UniDriveVLA**는 자율주행에서 2D 의미 추론과 3D 공간 인지의 트레이드오프를 통합 VLA 아키텍처로 해소하며 두 경로의 교차점에 선다. 스케일도 객체→실내→도시 규모로 확장 중이다.

## 2. 에이전틱 전환과 메타인지의 부상

**MARCUS**(의료), **UI-Voyager**(GUI), **Stop Wandering**(VLN), **Chameleon**(로봇 조작), **AMIGO**(벤치마크)는 도메인 불문 동일 구조를 공유한다: 인식→추론→행동의 장기 루프 + 자기 모니터링. Stop Wandering은 탐색 비효율을 메타인지 부재로 진단하고, UI-Voyager는 실패 궤적의 credit assignment로 자기진화를, Chameleon은 원시 지각 단서를 보존하는 에피소딕 메모리로 비마르코프 의사결정을 해결한다. AMIGO는 정보 이득 기반 순차 질문 전략을 측정한다. 과거 기억(Chameleon)과 현재 자기 진단(Stop Wandering)은 상호 보완적 인지 계층을 이룬다.

## 3. 효율화의 세 축과 training-free 조류

**AdaptToken**(엔트로피 기반 글로벌 토큰 선택 + 적응적 조기 종료), **VISOR**(토큰 제거 없이 레이어별 cross-attention 동적 희소화), **SpecEyes**(에이전트 파이프라인 수준의 추측적 병렬화)는 각각 정보 이론·아키텍처·시스템 차원의 **직교 전략**이다. 세 방법 모두 training-free로, Stop Wandering과 함께 파운데이션 모델 제로샷 능력을 극대화하는 조류를 형성한다. VISOR는 토큰 프루닝의 정보 병목을 정면 반박하며 기존 패러다임과 모순을 이룬다.

## 4. 핵심 논쟁: 시각적 무결성과 보상 해킹

가장 예리한 긴장은 **Hallucination in RL Post-Training**이 제기한다. RL 후훈련이 시각적 추론 향상처럼 보이나, 실제로는 시각 정보를 무시한 텍스트 패턴 기반 환각 단축일 수 있다는 것 — 보상 해킹의 멀티모달 변형이다. 이는 MARCUS·UniDriveVLA 등 RL 기반 시스템의 성능 수치를 재해석하게 만든다. **Steerable Visual Representations**(텍스트 조건부 ViT 특징 조종)과 결합하면 "표현을 조종할수록 그것이 실제 지각을 반영하는지 검증이 필요하다"는 구조적 과제가 드러난다. **NavTrust**는 입력 손상 하 강건성으로, AMIGO는 엄격 프로토콜로 신뢰성 평가의 외곽을 채운다.

## 5. 논문 간 관계 지도

- **일치**: 공간 추론 한계 진단(전반), 메타인지 필요성(Stop Wandering ≈ UI-Voyager ≈ AMIGO), training-free 효율화
- **모순**: 토큰 축소 패러다임 vs VISOR / RL 후훈련의 표면 성능 vs 실제 무결성 / 의미 압축 메모리 vs Chameleon의 원시 단서 보존
- **보완**: 명시적 3D 훈련(Loc3R-VLM) ↔ 암묵적 프라이어 전이(Generation Models) / 에피소딕 메모리 ↔ 메타인지 / 세 가지 효율화 전략의 조합 가능성

## 6. 트렌드와 미래 방향

(1) VLM → 에이전틱 VLM → VLA로의 통합(인지+행동), (2) 불확실성이 효율화·질문 생성·자기 진단을 잇는 보편 제어 신호로 부상, (3) 신뢰성 평가의 체계화. 미래 과제: 환각 단축을 처벌하는 무결성 인지 보상 설계, 메타인지+에피소딕 메모리 통합 에이전트, 직교 효율화 전략의 결합, 공간-에이전틱 능력의 통합 벤치마크.
