# Llm As Judge: 합성 분석

> 초기 합성 (3편, 2026-04 ~ 2026-09)

## 🎯 공통 주제: 측정 기기로서의 LLM Judge 감사

세 논문 모두 LLM judge를 단순 '평가 도구'가 아닌 **측정 기기(measurement instrument)**로 취급하며, 그 적격성을 서로 다른 축에서 감사한다.

- **신뢰도(reliability) 축** — *Clean Engineering, Unstable Measurement*: 52,988건 사전등록 감사에서 same-window 반복 순위 합의가 Spearman 0.400에 그쳐 "같은 요청은 같은 판독값" 전제가 실증적으로 붕괴. 비일관성의 원인이 추론 논리가 아니라 공유 엔드포인트의 **도구 드리프트**일 수 있음을 밝혀 [[transitivity-violation]]의 동시성 문제에 시간축 비일관성을 추가했다.
- **타당성(validity) 축** — *Legibility is Not Interpretability*: judge가 판단한 CoT 단계 중요도와 인과적 개입으로 측정한 실제 기능적 중요도가 체계적으로 발산. judge가 **일관되게 측정해도 잘못된 대상**을 측정할 수 있으며, PRM·generative critics의 공통 전제를 직접 공격한다.
- **적용 확장 축** — *ASR 평가*: WER의 의미 무감각성을 메우려 judge를 음성 도메인으로 확장하되, 위 두 결함을 그대로 상속함을 명시한다. LLM의 음성-의미 매핑 지식 질이 평가 신뢰성의 상한이 된다.

## 🔗 논문 간 관계

**보완**: 신뢰도 실패와 타당성 실패는 독립적인 양상이다. 전자는 "오늘과 내일 판독값이 다름", 후자는 "측정 대상 자체가 다름". ASR 논문은 두 결함을 안고 새 도메인에 진입하는 실무 사례로, judge 도입 전 도구 검증(신뢰도)과 개입적 검증(타당성)의 필요성을 동시에 동기 부여한다.

**긴장**: ASR 논문은 "WER보다 나은 대안"이라는 구축적 관점, 나머지 두 논문은 "기기 자체 부적격"이라는 파괴적 관점이다. 이 긴장이 분야의 현 상태를 요약한다 — 대안 부족으로 judge를 쓸 수밖에 없으나, 검증 없는 사용은 정당화되지 않는다.

**방법론적 기여**: 사전등록 감사가 실험을 조기 차단한 [[preregistered-measurement-audit]]의 희귀 실증 사례 + "판독 문제 → 개입 문제"로의 재정의([[causal-mechanistic-interpretability]] 강화).

## 📈 트렌드와 미래 방향

1. **감사 3축 표준화**: 동시성 일관성 + 시간축 신뢰도 + 개입적 타당성 검증이 judge 배포 전 프로토콜로 표준화될 전망.
2. **측정 메타데이터 격상**: '언제, 어떤 기기로 측정했는가'가 리더보드 필수 항목으로. 점수 변동이 능력 변화인지 도구 드리프트인지 구분해야 [[score-narrative-conflation]]을 차단.
3. **개입 기반 평가로의 이동**: 텍스트 표면(가독성, 완결성)에서 인과적 개입 검증으로 평가 패러다임 이동.
4. **인식론적 재정의**: 평가 연구의 '어떻게 측정할까' 집착을 넘어 WER→의미 보존, 가독성→기능 중요도로 **측정 목표 자체를 재정의**하는 흐름.

## ⚠️ 미해결 논점

- 도구 드리프트가 능력 변화와 혼입될 때 벤치마크·인증 결과의 소급 무효화 기준
- 타당성 검증된 judge를 신뢰도 있게 만드는 엔지니어링 — 세 논문 모두 미해결
- 도메인 특화 지식이 judge 상한을 결정하는 경우(LALM 논점)의 일반화 가능성
