핵심 연구 질문

새로운 에이전트를 작은 예산의 태스크 부분집합에만 실행하면서도, 전체 벤치마크에서의 성능과 상대 순위를 신뢰할 수 있게 복원할 수 있는가?

  • 전체 벤치마크 실행 없이 점수(score) 복원
  • 에이전트 간 순위(ranking) 복원
  • 기존 IRT 기반 방법 대비 낮은 보정(calibration) 예산에서도 우수한 정확도

기존 방법의 한계: 결과만 보는 평가

Result-only 접근

  • 과거 pass/fail 응답 행렬 또는 정적 태스크 의미에만 피팅
  • 궤적을 이진 결과로 축소 → 측정 신호 손실
  • 탐색한 컨텍스트, 시도한 편집, 실패 지점 등 프로세스 정보 소실

실제 에이전트의 해결 과정

SWE 에이전트의 결과는 추론 → 컨텍스트 탐색 → 도구 사용 → 코드 편집 → 검증이라는 멀티스텝 궤적을 통해 산출됩니다.

이 과정에는 성공/실패에 도달한 방법(how)에 대한 풍부한 측정 신호가 담겨 있습니다.

SWE 벤치마크(Lite, Verified)는 여전히 규칙 기반 필터링이나 사람 검증에 의존

제안: PTA-IRT 프레임워크

Privileged Trajectory-Aware Item Response Theory — 프로세스 신호와 결과 신호의 융합

1
궤적 표현 구축
이종 궤적을 구조화된 의미 요약으로 압축
2
정보성 아이템 선택
궤도 인지 Fisher 정보로 난이도 계층화된 보정 부분집합 선택
3
능력 추정 (LUPI)
교사-학생 지식 전이로 전체 벤치마크 성능 추정

궤적은 훈련 시에만 사용되는 특권 정보(privileged information) — 새 에이전트 평가 시에는 선택된 보정 태스크의 결과만 필요

이론적 기반

Preliminary 1

Item Response Theory (IRT)

응답자(에이전트)의 잠재 능력 θi와 아이템(벤치마크 인스턴스)의 난이도 bj로 응답 확률을 모델링

P(Xij=1 | θi) = 1 / (1 + exp[−(θi − bj)])

Item Characteristic Curve로 정답 확률 조건부 모델링

Preliminary 2

Learning Using Privileged Information (LUPI)

훈련 시에만 사용 가능한 추가 정보 x*로 예측기를 개선하되, 추론 시에는 표준 입력 x만 사용

  • 교사: 특권 정보(궤적) 접근 → 지식 증류로 전달
  • 학생: 표준 입력만으로 추론, 특권 정보 불필요
  • SWE 설정에서 에이전트 궤적이 특권 정보

Stage 1 — 에이전트 궤적 표현 구축

이질적이고 긴 실행 궤적을 구조화된 의미 요약으로 압축

탐색된 컨텍스트
어떤 코드·파일을 탐색했는가
시도한 편집
어떤 수정·패치를 시도했는가
해결 경로
문제 해결 과정이 어디서 붕괴했는가
  • 궤적 요약은 pass/fail 이상의 프로세스 수준 증거 제공
  • 이후 단계에서 궤도 인지 아이템 측정 특성(4PL) 학습에 활용

Stage 2 — 정보성 보정 아이템 선택

궤도 인지 스코어러

궤적 요약으로부터 궤도 인지 4-모수 로지스틱(4PL) 아이템 측정 특성을 학습

아이템의 난이도·판별도가 에이전트의 해결 방식에 따라 달라짐을 반영

정보 인지 계층화 선택

궤도 인지 Fisher 정보를 기준으로 아이템을 계층화

제한된 보정 예산에서 측정 정보량을 최대화하는 난이도 계층화 부분집합 구성

목표: 작은 부분집합으로 전체 벤치마크의 측정 능력을 최대한 보존하는 것

Stage 3 — LUPI 기반 능력 추정

훈련 단계

교사–학생 학습

  • 교사 네트워크: 궤적 요약(특권 정보) + 표준 입력 접근
  • 학생 네트워크: 표준 입력만 사용
  • 교사의 측정 지식을 증류(distillation)로 학생에 전이
평가 단계

테스트 시점 추정

  • 새 에이전트를 선택된 보정 태스크에만 실행
  • 제한된 보정 관측값으로 전체 벤치마크 성능·순위 추정
  • 테스트 시점에는 궤적이 전혀 필요 없음

실험 설정

데이터셋

4개 SWE 벤치마크
SWE-bench 전체 및 파생 벤치마크
Lite(규칙 기반)·Verified(사람 검증)는 별도 소규모 부분집합

베이스라인

Classical IRT
Deep-IRT / PSN-IRT (신경망 IRT)
AutoJudger (멀티모달용 IRT+LLM)
휴리스틱(SWE-bench Lite)·사람 검증(Verified)

평가 지표

점수 복원: 부분집합으로 추정한 전체 성능의 정확도
순위 복원: 에이전트 간 상대 순위 보존

현실적 프로토콜: 새 에이전트는 보정 부분집합에만 실행, 과거 궤적은 오프라인 훈련에만 사용

주요 결과 (RQ1): 낮은 예산에서도 일관된 우위

  • 4개 SWE 벤치마크 전체에서 낮은 보정 예산 조건의 점수·순위 복원 모두 기존 IRT 베이스라인을 지속적으로 능가
  • pass/fail만 사용하는 방법 대비 궤적의 프로세스 신호가 복원 정확도 향상의 핵심
  • 예산이 적을수록(정보가 부족할수록) PTA-IRT의 상대적 이득이 커짐
Score

전체 벤치마크 점수 복원 정확도 향상

Ranking

에이전트 간 상대 순위 신뢰성 있게 보존

분석 (RQ2–RQ4): 궤적 정보가 이득의 원천

RQ2

소거 실험

결과만 모델링하거나 궤적 요약을 오염시키면 복원 성능이 저하 → 특권 궤적 정보가 이득의 근원

RQ3

궤적 요약의 기여

구조화된 궤적 요약은 이슈 텍스트나 제출 패치를 넘어서는 프로세스 신호를 담고 있어 예산 평가의 정보량 증대

RQ4

궤적 요약의 특성 분석

채널 간 유사도: 궤적 요약 채널들이 서로 다른 측정 관점 포착

동일 아이템 결과 기하: 같은 태스크에서도 궤적이 성공/실패 이면의 구조를 구분

기존 방법과의 비교

SWE-bench Lite / VerifiedSWE—휴리스틱 / 사람 판단— / 많음

PTA-IRT는 SWE 도메인에서 프로세스+결과 신호를 모두 활용하는 유일한 접근

결론

  • 효율적 SWE 벤치마킹을 예산 제약下的 부분집합→전체 평가 문제로 공식화 (현실적 프로토콜)
  • PTA-IRT: 과거 에이전트 궤적을 특권 정보로 IRT 기반 아이템 선택·성능 추정에 통합
  • 4개 SWE 벤치마크에서 예산화된 점수·순위 복원 모두 기존 IRT 베이스라인 대비 향상
