Show-Harness

Just a VLM Agent Can Play Robots

단 하나의 VLM 에이전트로 로봇을 구동하는 Embodied Harness

Yanzhe Chen*, Zechen Bai*, Zhijun Cao*, Wenzheng Zeng*, Kevin Qinghong Lin, Yiqi Lin, Guoqiang Liang, Kevin Yuchen Ma, Qiming Huang, Mike Zheng Shou†

Show Lab · National University of Singapore

문제 정의: VLM의 지식은 왜 로봇으로 이어지지 않는가?

VLM이 이미 갖춘 능력

  • 객체와 공간 관계 인식
  • 장기 목표(long-horizon) 분해
  • 세계에 대한 광범위한 상식

로봇 제어가 요구하는 것

  • 정밀한 저수준 물리 실행
  • 실행 피드백 기반 실패 복구
  • 임바디먼트별 적응

"Foundation VLM의 지능을 물리 세계로 옮기려면 적절한 인터페이스가 필요하다"

기존 접근법의 한계

VLA 패러다임

저수준 제어로 파인튜닝

  • 연속 동작 회귀로 학습
  • 넓은 의미 지식이 불투명한 픽셀→구동 매핑으로 붕괴
  • 태스크·환경·임바디먼트마다 반복 적응 필요

계층적 · 프로그래밍 시스템

중간 추상화 생성

  • 서브태스크 호출·제어 API 프로그램 생성
  • 물리 제어는 다운스트림 컨트롤러가 중재
  • 의도(intent)와 실행(execution)의 직접 연결 약화

핵심 딜레마: 의미(semantic)를 지키면 물리(physics)를 잃고, 물리를 지키면 의미를 잃는다

핵심 아이디어: Semantic Action Interface

VLM에 의미론적으로 자연스러우면서, 직접 물리 제어가 가능할 만큼 fine-grained한 동작 공간

1
Semantic Action Unit
VLM이 자연스럽게 추론하는 이산적 의미 동작 단위 (이동·그리퍼)
2
Embodiment Interpreter
임바디먼트별 해석기가 결정론적으로 로봇 동작으로 grounding
3
Physical Execution
모든 의사결정이 물리 세계에 직접 반영, 실행 피드백 반환

VLM이 "어떻게(how)"까지 직접 결정 — fine-grained 물리적 결정에 VLM이 직접 책임을 진다

Show-Harness 아키텍처

모델 불가지론적(model-agnostic) Embodied Harness가 인지-추론-실행 루프를 닫는다

Perception

멀티뷰 관측과 고유수용감각(proprioception)을 지각 컨텍스트로 구성하여 VLM에 제공

Reasoning

서브태스크 단위 추론과 실패 복구(recovery)를 지원 — VLM이 이해하는 의미 공간에서 사고

Action

semantic unit을 결정론적으로 소규모 bounded 로봇 모션으로 변환, 매 유닛 후 피드백 반환

디지털 VLM을 상황에 몰입한 에이전트(situated agent)로 전환하는 closed-loop 구조

Semantic Action Space

이동(Movement) 유닛

주어진 방향으로의 단일 이동 스텝을 지정

VLM이 직접 해석 가능한 언어적 방향 표현

그리퍼(Gripper) 유닛

물체 잡기·놓기 등 그리퍼 동작을 지정

임바디먼트 해석기가 결정론적으로 실행

왜 효과적인가?

  • 해석 가능성: 각 유닛이 단일 이동 스텝이라 VLM이 자연스럽게 추론 가능
  • 결정론적 grounding: 각 의미 결정이 작고 제한된( bounded) 로봇 모션으로 확정 변환
  • 물리적 책임: 불투명한 실행기가 아닌, VLM 자신이 물리적 결과에 직접 책임

하나의 인터페이스, 두 가지 모드

ZS Mode Frontier VLM · Zero-shot

  • 폐쇄형 최전선(closed-source frontier) VLM을 파인튜닝 없이 즉시 로봇 에이전트화
  • 대표 agentic harness 대비 태스크·임바디먼트·환경 전반에서 우수
  • Frontier 모델의 발전을 그대로 상속

FT Mode 소형 VLM · 경량 파인튜닝

  • 2B급 오픈소스 VLM을 몇 GPU-hours 만에 적응
  • 저비용 배포 가능한 로봇 제어 실현
  • 대표 VLA 패러다임보다 강한 일반화와 sim-to-real 전이

추가 모델 용량도, 비용이 많드는 embodiment-specific 사전학습도 불필요

GUMI: GUI 기반 조작 인터페이스

GUI-based Manipulation Interface — 동일한 semantic action space를 GUI로 확장

인간 · 에이전트 공용

사람과 AI 에이전트가 같은 동작 공간에서 로봇 시연(demonstration) 데이터 수집

특수 하드웨어 불필요

전용 텔레오퍼레이션 장비 없이 GUI만으로 로봇을 직접 "플레이"

임바디먼트 간 재사용

수집된 시연이 cross-embodiment 재사용 및 인간-에이전트 협업 수집을 자연 지원

컴퓨터·게임 에이전트의 마우스·키보드 인터페이스처럼, 실제 조작에도 인간과 모델이 함께 쓸 수 있는 단순한 인터페이스를 제시

실험 설정

하드웨어 & 태스크

  • 다양한 로봇 임바디먼트에서 실제 조작 태스크 평가
  • 태스크별 성공률(success rate) 등 메트릭 측정

VLM 에이전트 & 베이스라인

  • 에이전트: Frontier VLM (zero-shot) + 소형 오픈소스 VLM (fine-tuned)
  • 베이스라인: 대표 agentic harness 시스템 및 VLA 패러다임

평가 관점

  • 일반화: 새로운 태스크 · 환경 · 임바디먼트에서의 성능
  • 적응성: 물리적(physical) / 의미적(semantic) 변화에 대한 대응력
  • 효율성: 파인튜닝 비용 및 배포 비용 (몇 GPU-hours)

주요 결과: 광범위한 일반화

태스크 일반화

다양한 조작 태스크에서 강건한 성능 유지

임바디먼트 일반화

하나의 semantic interface로 여러 로봇 구동

환경 일반화

다양한 장면·환경 변화에도 안정적 동작

  • ZS 모드: Show-Harness를 장착한 frontier VLM이 대표 agentic 및 VLA 패러다임을 능가
  • FT 모드: 소형 VLM이 통제된 실험에서 대표 VLA보다 강한 일반화와 sim-to-real 전이 달성

적응성 분석: 물리적 · 의미적 유연성

Physical Adaptability

물리적 상황 변화에 대한 적응

  • 객체 위치·형태·물성 변화 대응
  • 실행 피드백 기반 수정 동작 수행
  • 새로운 임바디먼트로의 전이

Semantic Adaptability

지시·의미 변화에 대한 적응

  • 지시어 표현 변화 이해
  • 새로운 목표·서브태스크로의 재구성
  • VLM의 의미 지식이 동작 선택으로 연결

이 분석은 효과적인 VLM-로봇 인터페이스의 핵심 속성을 밝힌다

Ablation Study

요인분석 내용시사점
Frontier VLM · Thinking Effort 백본 선택과 추론량(thinking) 변화 강한 백본과 충분한 추론이 물리 결정 품질 향상
FT Backbone 스케일링 파인튜닝된 소형 VLM 크기별 성능 소형 모델로도 경쟁력 있는 제어 달성 가능
Harness 플러그인 지각·피드백 등 모듈 기여도 closed-loop 구성 요소가 성공률에 기여
Action-space 표현 동작 공간 표현 방식 비교 semantic unit 표현이 해석성과 제어에 유리

정성적 분석에서도 실행 피드백 기반 실패 복구 및 재시도 행동이 확인됨

기여 요약

1
Show-Harness 제안 — 컴팩트한 semantic action interface를 통해 foundation VLM이 로봇을 직접 조작하는 모델 불가지론적 Embodied Harness
2
두 가지 제어 모드 입증 — 폐쇄형 frontier VLM의 zero-shot 제어 해방 + 소형 모델의 몇 GPU-hours 경량 적응
3
강한 일반화 입증 — 태스크·임바디먼트·환경 전반에서 agentic 및 VLA 패러다임 능가, 물리·의미 적응성 분석
4
GUMI 제안 — 인간·에이전트·협업이 동일 동작 공간에서 임바디먼트 전반으로 시연을 수집하는 GUI 인터페이스

"적절한 인터페이스는 추가 모델 용량이나 값비싼 사전학습 없이도 foundation VLM의 상당한 embodied 능력을 해방한다"

결론 및 한계

결론

  • 의미-동작을 잇는 인터페이스 설계가 embodied AI의 핵심 레버
  • frontier 모델의 발전을 그대로 로봇 제어로 상속
  • 소형·저비용 모델로의 확장 가능한 경로 제시

한계 및 향후 방향

  • 프론티어 VLM API 의존 시 지연·비용 존재
  • 고속·정밀 동작에는 저수준 정책 병행 필요 가능
  • 논문에서 결론 및 한계 절에서 상세히 논의
