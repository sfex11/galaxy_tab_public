Convolutional Memory for Long-Context Reasoning

긴 문맥 추론을 위한 합성곱 메모리

Hongming Zhang, Zhaozhen Gu, Fengshuo Bai, Ming Hao, Qingyang Zhang, 외

문제 상황: 초장문맥 처리의 한계

LLM은 책 전체를 소화하거나 복잡한 다단계 추론을 수행하기 어렵습니다

이차 복잡도 O(N²)

표준 self-attention은 토큰 수에 대해 이차 복잡도를 가지며, 대량의 입력 처리를 사실상 불가능하게 만듭니다

Lost in the Middle

문맥 길이가 길어질수록 추론 성능이 저하되어, 중간에 위치한 핵심 정보를 놓치기 쉽습니다

  • 위치 인코딩·어텐션 개선으로 수백만 토큰 확장은 가능하나, 실제 배포 시 지연 시간과 성능 저하가 병목

기존 접근법: 순차 메모리 에이전트의 두 가지 한계

MemAgent, Mem-α 등은 세그먼트를 읽으며 고정 크기 메모리를 반복 갱신 (O(N))

순차적 병목 (Sequential Bottleneck)

메모리 상태의 엄격한 시간 의존성으로 인해 병렬화가 불가능하며, 추론 지연 시간이 큽니다

RL 과적합 위험

메모리 정책 최적화에 강화학습(RL)이 필수적인데, 특정 데이터셋에 과적합되어 사전학습 지식에 기반한 그럴듯한 hallucination을 생성합니다

RL 기반 에이전트는 문맥 내 추론이 아닌 파라메트릭 암기(parametric memorization)에 의존하는 경향이 관찰되었습니다

핵심 아이디어: CNN을 닮은 계층적 추론

학습 불필요(training-free)하며 고도로 병렬화 가능한 프레임워크

  • 질의가 주어진 동결된 LLM을 의미론적 합성곱 커널로 취급
  • 텍스트 세그먼트를 계층적으로 요약하여 선형 체인 → 로그 트리 (O(log N) 깊이)로 변환
  • 추론 경로 단축으로 오차 누적 완화 + 텍스트 세그먼트·추론 스레드 양방향 대규모 병렬화

의미론적 합성곱 커널 (Semantic Convolutional Kernel)

(h, r) = 𝒦LLM(x, q; p)

동결된 LLM과 지시 프롬프트 p로 매개변수화된 비선형 텍스트→텍스트 변환

  • h: 수용 영역(receptive field) 역할의 텍스트 세그먼트 x에서 질의 q에 관련된 정보를 추출·압축한 요약
  • r: 세그먼트 중요도의 이산 관련성 점수 (Skip Connection에서 활용)
r = 0

Irrelevant
유용한 정보 없음

r = 1

Relevant
유용할 수 있는 배경/맥락 존재

r = 2

Critical
직접적 증거 또는 정답 포함

동시에 두 가지 기능: 정보 추출(노이즈 필터링) + 차원 축소(토큰 길이 압축)

핵심 기법 ① Configurable Strides

겹치는 윈도우를 통한 다중 뷰 스캔으로 강건한 증거 포착

  • 단일 패스만 사용하면 경계 절단(boundary truncation)과 모델의 확률적 변동성에 취약
  • Stride S < W로 설정하여 각 토큰을 여러 수용 영역에서 반복 스캔
  • 서로 다른 수용 영역 간 정보를 교차 검증하여 핵심 증거의 안정성과 회상률 향상

Over-Scanning 요인

W/S 비율을 조절하여 증거 누락 위험과 계산 비용 간의 균형을 설정할 수 있습니다

핵심 기법 ② Skip Connections & ③ Multi-Kernel Convolution

Skip Connections: 세부 정보 보존

계층적 요약은 정보를 압축하여 미세한 세부사항을 잃을 위험이 있습니다

해결 고신뢰 원본 증거(r=2 세그먼트)가 중간 레이어를 우회(bypass)하여 최종 추론 단계로 직접 전파

답변이 정확한 세부사항에 기반하도록 보장하는 의미론적 잔차(semantic residual) 메커니즘

Multi-Kernel Convolution: 의미 분리

복잡한 작업은 얽힌 논리 스레드를 포함합니다

해결 질의를 하위 질문으로 분해하고, 서로 다른 커널이 분리된 의미 채널에 관련 정보를 추출

직교하는 추론 경로 간 간섭 방지

계층적 병렬 추론 워크플로우

1
Layer 0: 입력 처리
커널 𝒦가 원본 텍스트 세그먼트들을 병렬로 스캔하여 요약 생성
2
Layer l: 재귀 요약
이전 레이어의 연결된 요약들을 재귀적으로 처리, 정보 점진적 응축
3
최종 집계
Skip Connection된 원본 증거와 최종 요약을 결합하여 답변 생성

병렬화

모든 세그먼트 스캔이 각 레이어에서 동시 수행되며, 다중 채널(하위 질문)도 독립적으로 병렬 실행 — 순차 병목을 근본적으로 제거

실험 설정

데이터셋

RULER-HotpotQA 및 RULER-2WikiMultiHopQA — 다중 홉 QA를 초장문맥 설정으로 확장한 벤치마크

평가 지표

Sub-EM (부분 문자열 정확 일치) + LLM-as-a-Judge — 데이터셋 모호성과 결측 증거에 강건한 평가

베이스라인

Training-free 베이스라인 + RL 훈련 기반 메모리 에이전트 (MemAgent 등)

구현

동결된 LLM 위에서 동작하며, 질의 분해·파싱 및 계층적 재귀 구성으로 학습 과정 완전히 제거

주요 결과

  • Training-free 베이스라인 대비 우수성 — 두 벤치마크에서 최고 성능 달성 (학습 불필요 방법 중 SOTA)
  • RL 유발 불안정성에 대한 강건성 — RL 훈련 에이전트는 데이터셋에 과적합되어 파라메트릭 hallucination 발생
  • 분포 외(OOD) 일반화 — RL 훈련 모델은 사전학습 지식에 기반한 그럴듯한 오답 생성, ConvMem은 제공된 문맥에 충실하게 추론
  • 모델 불문성과 확장성 — 다양한 LLM 백본에서 동작하며 문서 길이 증가에도 성능 유지

ConvMem은 학습 비용 없이 O(log N) 깊이의 병렬 추론으로 O(N) 순차 방식의 성능을 능가합니다

결론 및 기여

  • 최초의 학습 불필요 CNN 영감 계층 프레임워크 — 순차 병목을 깨고 병렬화 가능한 초장문맥 추론 실현
  • RL 기반 메모리 에이전트의 과적합 위험 실증 — 성능이 문맥 내 추론이 아닌 파라메트릭 암기에 의존함을 밝힘
  • 원칙적 메커니즘 통합 — Configurable Strides + Semantic Skip Connections + Multi-Kernel Convolution으로 training-free SOTA 및 우수한 OOD 일반화 달성

한계: LLM 호출 횟수에 따른 계산 비용, 질의 분해 품질 의존성 등이 향후 과제로 남아 있습니다
