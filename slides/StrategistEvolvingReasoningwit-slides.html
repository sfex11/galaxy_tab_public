Strategist

에이전트로 추론을 진화시키다

모델이 스스로 학습하는 것에 그치지 않고,
모델을 사용하는 '추론 전략'까지 진화시키는 메타-에이전트

Taiming Lu · Zhuang Liu (Princeton) · Qi Xu · Zhigang Hua (Meta)

문제 제기: 모델은 시스템의 절반일 뿐

절반: 모델

스스로 학습하고 개선됨 — 사전학습, 파인튜닝, RLHF까지 방대한 연구 축적

나머지 절반: 추론 전략

모델 호출을 응답으로 바꾸는 절차 — 프롬프트, 추론 흐름, 도구 사용 설계

  • 현재 이 절반은 사람이 손으로 작성하고, 한 번 완성되면 고정됨
  • 한 작업에서 쌓은 설계 경험이 다음 작업으로 전혀 이어지지 않음
  • AI 시스템에서 스스로 개선되지 않는 유일한 부분

핵심 아이디어: 설계를 누적형으로

"기존 자동화는 설계를 자동으로 만들었다. 우리는 설계를 누적되게 만든다."

기존 접근법의 한계

  • 고정된 전략 집합 검색/라우팅 → 새 전략 발견 불가
  • 작업별 학습 기반 최적화 → 매 작업마다 처음부터 재시작

Strategist의 접근

  • 사람이 하는 "작성 → 시험 → 수정" 루프를 대규모로 실행
  • 모든 후보를 공유 라이브러리에 축적 → 후속 작업이 선행 발견 위에서 출발

표현 방식: Strategy Blueprint

모든 추론 전략은 결국 프로그램이다. 표현 방식이 자동 설계자의 능력을 결정한다.

계산 그래프 / 파이프라인

조합은 가능하지만 사전 정의된 패턴만 표현 가능

단일 코드

무엇이든 표현 가능하지만 전략이 고립됨

Blueprint

코드의 개방성 + 조합 가능성을 모두 확보

  • 단일 인터페이스 execute(llm, task) → str — 어떤 blueprint든 다른 blueprint의 컴포넌트가 될 수 있음
  • 두 개의 기반: chat(대화)과 agent(스캐폴드·도구)
  • 추론 구조만 담고, 프롬프트를 채우면 실행 가능한 전략이 됨

Blueprint Library: 성장하는 그래프

Blueprint들은 측정된 성능과 경험 노트와 함께 공유 라이브러리에 축적되어, 조합을 통해 유방향 그래프를 형성합니다.

구조 (a)

  • 최상단에 chat·agent 두 기반 노드
  • 전략은 기반과 서로를 조합해 생성
  • 조합 깊이에 따라 계층이 자연스럽게 형성

4가지 프로토콜 (b)

  • 모든 노드가 하나의 추상 인터페이스 공유
  • 자신보다 먼저 만들어진 노드만 호출 가능 (순방향 호출 금지)
  • 사이클 금지 · 중복 금지
초기 blueprint는 두 기반 위에, 이후 것들은 그 위에 — 라이브러리는 복리처럼 성장한다.

다중 계층 모델 라우팅

모든 추론 단계가 같은 지능을 필요로 하지 않습니다. 각 단계가 서로 다른 모델 계층을 목표로 할 수 있어 정확도와 비용 효율을 동시에 달성합니다.

fast

간단한 단계 — 빠르고 저렴한 호출

balanced

중간 복잡도 — 균형 잡힌 선택

complex

어려운 단계 — 최고 성능의 호출

각 계층은 nothink / thinking 두 모드를 지원하며, 이는 주요 모델 제공사의 계층별 가격·노력 수준을 반영합니다.

Strategist의 4단계 반복 파이프라인

1
Retrieve
라이브러리에서 관련 blueprint와 다양한 영감을 검색
2
Propose
신규·조합·재사용 blueprint K개를 작업별 프롬프트와 함께 제안
3
Evaluate
학습 set 전체 트레이스와 검증 set 집계 점수로 평가
4
Accumulate
측정값과 경험 노트와 함께 라이브러리에 축적

모델은 완전히 동결 — 학습도 파인튜닝도 없음. 바뀌는 것은 오직 전략뿐이며, 매 라운드 후 모든 후보가 라이브러리로 돌아가 후속 작업의 출발점이 됩니다.

교차 모델 전이

발견된 전략을 한 줄도 수정 없이 다른 모델로 옮겨도 성능이 유지됩니다.

전이 대상

GPT-5 · Gemini-2.5 — 전혀 다른 제공사의 최신 모델

결과

추가 탐색 없이도 해당 모델에서 베이스라인을 여전히 능가

  • 전략은 모델에 종속되지 않는 추론 구조를 담고 있음
  • Blueprint의 다중 계층 라우팅이 새 모델의 계층에도 자연 매핑됨
  • 전이 비용은 총액 기준 USD로 측정 — 실용성 입증

발견된 전략의 해부

Strategist가 발견한 전략은 작업 특성에 맞는 흥미로운 추론 구조를 보입니다.

논리 (BBH)

high_precision_execution_router — 높은 정밀 실행 라우터로 문제 유형별 분기

멀티홉 QA (MuSiQue)

strict_roundtrip_count_multihop — 왕복 검증 횟수를 강제하는 다중 홉 구조

수학 (GSM8K)

dual_verbatim_evidence_lens — 이중 축자적 증거 관점으로 풀이 검증

각 전략은 측정 성능과 "언제 통하고 언제 통하지 않는가"에 대한 경험 노트를 함께 남겨, 후속 검색과 조합의 재료가 됩니다.

결론

"지금까지 AI 시스템에서 학습할 수 있는 것은 모델뿐이었다.
이제 나머지 절반도 학습한다."
  • Strategy Blueprint — 개방성과 조합 가능성을 모두 갖춘 전략 표현
  • 누적형 설계 — 모든 후보가 라이브러리로 축적되어 후속 작업이 더 나은 출발점을 가짐
  • 24/30 승리, 동일 정확도(74.7% vs 74.0%)에서 39% 저비용
  • 미지 작업·미지 모델로 추가 탐색 없이 전이 가능
