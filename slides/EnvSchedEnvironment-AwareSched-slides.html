EnvSched

Environment-Aware Scheduling for Rollout-Efficient Agent Reinforcement Learning

환경 인지 스케줄링으로 롤아웃 효율을 높인 에이전트 강화학습

PKU · XJTU · THU · Samsung Research · CASIA · CUHK

배경: 실행 가능한 환경의 급격한 확장

LLM 에이전트는 상태 기반 도구 환경에서 다중 턴 상호작용과 도구 사용, 상태 갱신을 요구받습니다. 최근 Agentic RL 시스템은 학습 환경 풀을 수십 개에서 수천 개로 확장했습니다.

수천 개

확장되는 실행 환경의 수

수십만

GPU-시간 단위의 RL 학습 비용

증가

환경 수에 비례해 증가하는 롤아웃·검증 비용

환경이 늘어날수록 롤아웃 생성과 검증 비용이 함께 증가 — 유한한 롤아웃 예산의 효율적 사용이 핵심 과제

문제: 기존 온라인 태스크 선택의 한계

기존 연구는 난이도·프롬프트 표현·과거 보상으로 학습 가치를 추정하지만, 실행 환경을 선택 모델 밖에 둡니다.

환경이 결정하는 것

  • 사용 가능한 도구 집합
  • 초기/중간 상태와 전이 규칙
  • 태스크별 검증기(verifier)

놓치는 학습 신호

  • 동일 태스크라도 환경에 따라 전개와 학습 신호가 달라짐
  • 환경 수준의 다양성 제어 불가
  • 도구·상태·검증 구조의 공유 정보 미활용

환경 수준 데이터 관리라는 새로운 정식화

태스크 인스턴스를 그것이 수행되는 실행 환경과 함께 조직·평가·스케줄링한다

GRPO 계열 그룹 상대 RL의 업데이트 메커니즘에서 출발합니다: 같은 태스크 롤아웃들의 보상 차이가 상대적 이점을 결정하므로, 결과가 거의 동일한 태스크는 학습 신호가 거의 없습니다.

활용

정보성 있는 보상 차이를 만들 가능성이 높은 태스크 우선 선택

커버리지

배치를 관측이 부족한 환경과 상호작용 패턴에 고루 분산

핵심 방법 ①: 이중 관계 그래프

환경–태스크 쌍을 노드로 하는 그래프로 표현하고, 두 종류의 엣지로 관계를 모델링합니다.

환경 내 엣지

  • 태스크 의미론의 공유
  • 공통 도구·DB 필드·검증기 제약 연결
  • 같은 환경 내 태스크 유사성 반영

환경 간 엣지

  • 추상적 실행 구조·보상 토폴로지 연결
  • 유사 환경 간 정보 전이 가능
  • 예: 상담사 재배정 ↔ 병상 간 환자 이동 (조회→자격 확인→관계 교체→검증)

  • 추가 파일럿 롤아웃 없이 기존 학습 신호만으로 스케줄링

핵심 방법 ③: 커버리지 인지 배치 구성

50% — 커버리지

관측이 부족한 환경과 태스크에 배치의 절반 할당

50% — 활용

예측 보상 분산이 높은 태스크에 배치의 절반 할당

  • 환경 쿼터로 배치 내 특정 환경에의 집중 제한
  • 유사도 페널티로 배치 내 중복 감소
  • 파일럿 롤아웃 추가 비용 없이 정보성 + 다양성을 모두 갖춘 배치 구성

결론 및 기여

  • Agentic RL을 위한 환경 수준 데이터 관리를 최초로 정식화 — 태스크 명세와 실행 환경 구조를 함께 모델링
  • 이중 관계 그래프 + 보상 분산 예측 + 커버리지 인지 배치 구성으로 파일럿 롤아웃 없이 학습 태스크 스케줄링
  • 다양한 모델 크기에서 일관된 롤아웃 효율 향상과 다양한 도구 사용 벤치마크에서 성능 개선 입증

보상 차별화와 환경 커버리지는 상호 보완적인 학습 가치의 원천이며, 환경 수준 데이터 관리는 효율적인 Agentic RL 확장을 위한 데이터 중심 방향을 제시합니다.
