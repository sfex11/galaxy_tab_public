Semantic Action Graph

에이전트 그라운딩과 인간 해석을 위한
스포츠 하이라이트 공유 표현

Tica Lin · Deepak Chandran · Gauri Jagatap · Chen Chen · Andrea Fanelli · David Gunawan · Josh Kimball
Dolby Laboratories

그래프 기반 비디오 표현 하이라이트 생성 에이전틱 시스템 Human-AI 상호작용

  왜 새로운 표현이 필요한가?

생성형 에이전트가 하이라이트 선택과 해설을 자동화하지만, 대부분 비정형·프레임 수준(frame-level) 표현 위에서 동작합니다.

  검증 불가

해설이 실제 이벤트와 연결되지 않아, "수비를 분해하는 패스"가 실제로 있었는지·누가 했는지·언제였는지 시청자가 확인할 방법이 없음

  선호 반영 불가

시작점을 앞당기거나, 슛 대신 슛으로 이어지는 패스를 보고 싶어도 시스템이 이벤트를 노출하지 않아 지정 불가

  핵심 원인: 에이전트와 시청자가 공유하는 중간 표현(shared intermediate representation)의 부재 — 시각화 도구의 구조화 인덱스는 인간 전용이고, 에이전트의 구조는 내부에만 존재

  형성 연구: 팬들이 겪는 4가지 간극

축구 팬 6명(18–55세, 여 1·남 5: 캐주얼 1·일반 2·열성 3)과 30분 준구조화 인터뷰 + 반성적 주제 분석

콘텐츠  내용 간극

하이라이트가 주변 사건과 득점 빌드업을 생략 — 6명 중 4명이 골 자체보다 이어지는 공격 과정을 선호

서사  내러티브 간극

"무엇이"뿐 아니라 "왜 중요한지"에 대한 맥락과 스토리텔링 부족 (예: 골 직전의 레드카드)

개인화  개인화 간극

일률적인(one-size-fits-all) 편집 — 특정 선수 중심 등 개인 선호를 반영할 방법 없음

탐색  발견 간극

페널티 킥 같은 덜 주목받는 장면을 찾기 어려움

  세 가지 디자인 목표

형성 연구의 간극을 표현(representation)에 대한 요구사항으로 변환

G1
연결된 시퀀스로 표현

고립된 장면이 아닌 연결된 이벤트 시퀀스로 경기를 표현하여, 빌드업과 결과가 시스템과 시청자 모두에게 접근 가능해야 함

G2
공유 가능한 어휘

시스템이 추론하는 단위가 시청자가 선호를 표현할 때도 사용할 수 있는 어휘여야 함

G3
주소 지정 가능한 순간

개별 순간이 직접 주소 지정 가능해야 시청자가 스크러빙 없이 특정 이벤트에 도달 가능

  Semantic Action Graph 스키마

경기를 5개 노드 타입과 5개 엣지 타입으로 구성된 가벼운 도메인 스키마로 표현

  Performer

행동을 수행한 주체 (로스터에서 선택)

  Action

발생한 행동 — 종목별 폐쇄 카탈로그 (Tackle, Foul, ShotOnTarget, Save, Score, YellowCard…)

  Recipient

행동의 영향을 받은 대상

  Moment

경기 시계·비디오 시간·프레임 인덱스라는 시간 정보

  State

행동이 만든 경기 상태 (예: 스코어)

  Edge 5종

역할(role)·순서(temporal)·결과(outcome) 관계를 담는 5가지 엣지 타입

  예시: 골 시퀀스의 그래프 표현

then 엣지가 행동 시퀀스를 체인으로 연결 — 빌드업부터 득점까지 하나의 흐름으로

  각 행동 노드에 Moment(경기 시계·프레임 인덱스)가 연결되어, 시퀀스의 어느 지점이든 정확한 비디오 프레임으로 주소 지정 가능

  3가지 핵심 설계 속성, 2명의 소비자

1

연결된 이벤트 시퀀스

빌드업과 결과를 함께 표현 (G1 충족)

2

공유·폐쇄 어휘

시청자도 선호 표현에 사용 가능한 단위 (G2 충족)

3

프레임 주소 지정

순간마다 프레임 경계 제공 (G3 충족)

  에이전트를 위한 소비

경기 통계 계산, 해설 작성, 노드 시퀀스·프레임 경계 기반 클립 검색

  시청자를 위한 소비

동일한 구조를 시각 인터페이스로 렌더링하여 필터링·검수·탐색

  SportSAGE: 4모듈 하이라이트 파이프라인

축구 하이라이트용 디자인 프로브 — 공식 리그 피드의 구조화 경기 이벤트 데이터를 입력으로 사용

  모든 모듈이 동일한 그래프를 기반(grounding)으로 동작 — 생성 결과가 임의의 텍스트가 아닌 그래프 상의 검증 가능한 노드 시퀀스

  그래프 기반 시청 인터페이스

에이전트가 사용하는 동일한 그래프 구조를 시청자용으로 렌더링

  (a) 필터링

선수·액션 타입 등 그래프 어휘로 원하는 이벤트 검색

  (b) 탐색

then 엣지로 연결된 시퀀스를 따라 경기 흐름 이동

  (c) 내러티브 포커스 지정

선호하는 서사 관점(예: 특정 선수, 빌드업 중심)을 그래프 어휘로 표현

  (d) 개인화 하이라이트

포커스에 맞춰 생성된 결과를 재생하며, 해설을 비디오·그래프와 대조 검증

  사용자 피드백: 12명의 축구 팬

프로 경기 1경기에 SportSAGE를 적용한 평가

12

축구 팬 참가

생성 하이라이트·해설 품질에 만족

그래프 인터페이스로 검색·탐색·해석 능동적 활용

  • 같은 경기에서 서사 포커스가 다른 개인화 하이라이트를 받는 것을 높이 평가
  • 그래프 레이어로 생성된 클립을 검수하고 해설을 비디오와 대조 확인
  • 하나의 작고 인간이 읽을 수 있는 스키마가 에이전트 생성과 인간 해석을 동시에 지원한다는 초기 증거

  결론 및 향후 연구

  작고 인간이 읽을 수 있는 하나의 스키마가 에이전트 생성의 그라운딩과 인간 해석을 동시에 지원할 수 있음을 보이는 초기 증거
  • 구조는 모델 내부에 숨기지 않고 시청자와 공유 — 검증 가능성과 조종 가능성 확보
  • 프레임 주소 지정 가능한 순간으로 정밀 탐색 실현 (발견 간극 해소)
  • 폐쇄 어휘를 통한 선호 표현으로 개인화 간극 해소
