From Natural Language to Exact Cover

제브라 퍼즐을 위한 신경-기호학적 접근법

LLM이 자연어 퍼즐을 Exact Cover 인코딩으로 변환하고,
결정론적 기호 솔버가 정확하고 신뢰할 수 있는 해를 보장

TU Wien · JKU Linz · University of Klagenfurt

왜 이 연구가 필요한가?

순수 신경망 LLM의 한계

  • CoT 생성으로 코드 생성·데이터 분석·시험형 QA 성능은 크게 향상
  • 그러나 기초적인 논리 추론 문제에는 여전히 취약
  • 결정성·건전성(soundness)·신뢰성 결여, 환각과 노이즈 증가

기호적 방법의 한계

  • SAT·Exact Cover 솔버는 정확성과 완전성을 보장
  • 그러나 전문화된 형식 인코딩이 필수적
  • 자연어 입력을 형식화하려면 상당한 모델링 전문성 필요

핵심 격차: 자연어 이해와 형식 기호 추론 사이의 다리가 필요하다

배경: Exact Cover 문제

집합 𝒳의 부분집합 모음 𝒮이 주어졌을 때, 𝒳의 모든 원소(item)를 정확히 한 번씩 덮는 부분집합 선택 𝒮* ⊆ 𝒮를 찾는 문제

예시 (Knuth, 2020)

items: {a, b, c, d, e, f, g}
options: [c,e], [a,d,g], [b,c,f], [a,d,f], [b,g], [d,e,g]

해 𝒮* = {[c,e], [a,d,f], [b,g]} → 모든 item이 정확히 1회 등장

Colored Exact Cover로 확장

  • Primary items: 반드시 정확히 한 번 덮여야 함
  • Secondary items: 최대 한 번 등장, 색(color)으로 상태 변경 가능
  • exact-1 성질은 강력한 솔버 성능을 제공 (SAT 인코딩 연구)

과제: Zebra Puzzle (제브라 논리 퍼즐)

엔티티와 속성

사람·색·직업 등 카테고리별 속성 목록이 주어짐

단서(Clues)

자연어로 된 제약 조건들의 목록

유일한 해

단서로부터 엔티티-속성 관계를 유일하게 추론 가능

기존 연구의 발견: 모델 크기를 키워도 퍼즐 복잡도(해 공간 크기)가 임계점을 넘으면 성능이 정체 — 긴 추론보다는 검증 가능한 구조적 접근이 필요

제안 프레임워크: NeuralExactCover

1
퍼즐 입력
자연어 제브라 퍼즐 + 프롬프트 템플릿
2
LLM 언어 모듈
속성 조화, 엔티티·단서 추출, 도구 호출 생성
3
MiniExact 솔버
Exact Cover 인스턴스를 결정론적으로 해결
4
피드백 루프
실패 원인을 LLM에 전달, 인코딩 반복 개선

유일해를 찾거나 재시도 한도에 도달할 때까지 루프 반복 → 최종 해를 일반 텍스트로 변환

모듈 1: 언어 모듈 (LLM 기반 파싱)

  • 조화(Harmonization) — 퍼즐 내 상이한 속성 표현을 일관된 형태로 정규화
  • 엔티티·속성 추출 — 도메인 초기화에 필요한 구조적 정보 식별
  • 단서 추출 — 각 자연어 단서를 구조화된 도구 호출(tool call)로 변환

LLM은 번역 계층으로 동작 — 추론은 수행하지 않음

시스템 프롬프트에 도구 명세를 제공하여 안정적 파싱 유도

모듈 2: 추론 모듈 (MiniExact 솔버)

인코딩 구성

  • LLM의 도구 호출로 items와 options 집합을 구축
  • Colored Exact Cover의 primary/secondary items로 제브라 제약 표현
  • 단서 제약을 색(color) 메커니즘으로 인코딩

솔버의 보장

  • 결정론적 — 동일 입력에 항상 동일 결과
  • 건전성·완전성 — 해의 부재, 유일성, 다중성을 정확히 판별
  • 결과를 구조화된 피드백으로 반환

신경망의 유연한 파싱 + 기호 솔버의 수학적 보장이 결합되어 신뢰할 수 있는 추론 실현

모듈 3: 피드백 메커니즘

제브라 퍼즐의 유일해(uniqueness) 성질을 검증 기준으로 활용

솔버 출력진단LLM 후속 조치
해 없음과잉 제약(overconstrained) 인코딩잘못된 단서 번역 수정
다중 해부족 제약(underconstrained) 인코딩누락된 제약 보강
무효 호출파싱 오류 · 잘못된 도구 사용도구 호출 재생성
유일해올바른 인코딩해를 자연어로 변환 후 종료

재시도 한도에 도달할 때까지 반복적으로 인코딩을 정제(refine)

주요 기여 3가지

1

Exact Cover 인코딩

제브라 스타일 논리 퍼즐의 효율적인 기호 솔빙을 위한 exact cover 인코딩 도입·적응

2

신경-기호 프레임워크

LLM을 exact cover 솔버의 번역 계층으로 활용하고, 기호 결과를 LLM 피드백으로 재적용

3

ZebraExtreme 데이터셋

ZebraLogic을 확장하여 8×10 엔티티·속성 규모의 더 어려운 퍼즐까지 포함

실험 설정

평가 대상

  • 다양한 LLM 계열(family)
  • 다양한 파라미터 스케일
  • 다양한 포스트트레이닝 패러다임 (베이스 / 지시 튜닝 / 검증가능 보상 RL 기반 추론 모델)

비교 베이스라인

  • CoT 프롬프팅 — 대표적인 순수 신경망 기법
  • Logic.py — 도메인 전용 표현 + 정확 제약 솔버
  • Logic-LM — ZebraLogic 퍼즐에 맞게 확장하여 적용

데이터셋: ZebraLogic + 자체 구축 ZebraExtreme (최대 8×10 규모)

결과: 하이브리드가 이긴다

접근법방식특징
CoT 프롬프팅순수 신경망긴 추론 → 노이즈·환각 유발, 복잡한 퍼즐에서 정체
Logic-LM / Logic.py신경-기호강력하지만 제안 기법 대비 열세
NeuralExactCover 제안신경-기호exact cover + 반복 피드백으로 유일해 보장
  • 강력한 순수 신경망 베이스라인(CoT 포함)을 일관되게 능가
  • 최근 신경-기호 방법들보다도 우수한 성능
  • 모델 계열·크기·학습 패러다임 전반에서 강건한 경향 확인

결론

"LLM의 자연어 이해 능력과 exact cover 솔버의 결정론적 정확성을 결합하면, 순수 신경망으로는 불가능한 신뢰할 수 있는 논리 추론이 가능해진다."
