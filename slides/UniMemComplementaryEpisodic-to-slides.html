UniMem

경계 없는 태스크 스트림을 위한
에피소딕-파라메트릭 보완적 메모리

Siyu Xia, Chenheng Zhang, Yanting Wu, Haoxuan Li 외 · CAS, PKU, Meituan, UCL

왜 메모리가 필요한가?

LLM 에이전트는 다양한 태스크를 수행하며 경험을 축적하고 태스크별 실행 전략을 재사용할 수 있어야 합니다.

외부 메모리 (RAG)
  • 새로운 증거를 즉각 흡수
  • 높은 가소성(Plasticity)
  • 재발 패턴의 내재화 부족
  • 추론 시 검색 오버헤드
파라메트릭 메모리 (PEFT)
  • 학습 후 안정적·효율적 실행
  • 높은 안정성(Stability)
  • 명시적 태스크 경계 필요
  • 고정 파라미터 예산 제약

핵심 문제: 안정성-가소성 딜레마

실제 배포 환경에서 LLM 에이전트는 경계 없고(boundary-agnostic) 지속적으로 진화하는 태스크 스트림을 마주합니다.

외부 메모리만 의존하면 내재화 불가, 파라메트릭 메모리만 의존하면 유연성 부족 — 단일 메모리 체계로는 양쪽을 동시에 달성할 수 없습니다.

인간 뇌에서 영감을 받다

보완적 학습 시스템(CLS) 이론에 따르면, 인간 뇌는 두 가지 메모리 시스템을 협력시켜 이 딜레마를 해결합니다.

해마 (Hippocampus)
새로운 경험을 빠르게 에피소딕으로 저장. 가소성이 높지만 장기적 안정성은 낮음.
신경피질 (Neocortex)
반복되는 구조를 점진적으로 안정적인 장기 지식으로 통합. 안정성이 높음.

에피소딕 → 파라메트릭 생명주기

UniMem의 메모리는 고정된 구조가 아닌 동적으로 진화하는 생태계입니다.

에피소딩 단계
  • 𝐞NOVEL에 라우팅된 쿼리 수집
  • 버퍼에 검색 가능한 형태로 저장
  • 추론 시 RAG로 보강 실행
  • 희소/일회성 태스크에 적합
파라메트릭 통합
  • 버퍼에서 반복 패턴 자동 발견
  • 클러스터 품질 검증 후 승격
  • 새 라우팅 토큰 + Pk 할당
  • 이후 안정적 파라메트릭 실행

핵심: 태스크 라벨 없이, 파라미터가 무제한으로 증가하지 않으면서, 수요에 따라(on-demand) 메모리를 확장합니다.

절제 연구 분석

라우팅 메커니즘의 영향
  • 𝐞NOVEL 센티널 없이는 신규 태스크 성능 급락
  • 라우팅-실행 목표 분리가 성능 핵심
  • 학습 가능한 라우팅이 하드코딩보다 우수

핵심 기여 요약

1
문제 제기
이종적·경계 없는·진화하는 태스크 스트림을 LLM 에이전트 메모리 관리 과제로 공식화. 단일 메모리 체계의 안정성-가소성 딜레마를 명시적으로 식별.
2
방법론 제안
CLS 이론에서 영감을 받은 UniMem — 드문 태스크는 에피소딕 메모리에, 빈번 패턴은 파라메트릭 메모리에 자율 라우팅하는 통합 프레임워크.
3
실증적 검증
다양한 장기 스트리밍 설정에서 일관되게 베이스라인 초과 성능. 평균 4.0 EM 향상, 자율 확장 중에도 실행 충실도 유지.
