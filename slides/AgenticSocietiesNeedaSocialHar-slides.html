에이전틱 사회란 무엇인가?

서로 다른 주체(principal)를 대신해, 신뢰 경계를 넘어 자율적으로 조율하는 AI 에이전트들의 집합 — 주체들의 목표는 부분적으로만 일치할 수 있다

독립적인 주체 대리

각 에이전트는 서로 다른 인간·조직을 대표

실세계 영향 작업

실제 결과를 낳는 과업에서 협업 수행

인간 없는 자율 조율

루프에서 인간을 빼고 에이전트끼리 협상

협력과 경쟁의 공존

주체 목표가 불완전히 정렬되어 경쟁도 발생

왜 자율 조율이 필요한가 — 인간은 병목

오늘날

인간이 중개하는 협업

  • 교수의 에이전트가 연구 동향 요약 전달
  • 교수가 직접 읽고 학생에게 질문 전달
  • 학생이 에이전트 답변을 편집해 회신

매 단계마다 인간의 읽기·판단 속도에 제약

미래

에이전트 간 직접 조율

  • 교수 에이전트가 학생 에이전트에게 직접 문의
  • 학생별 맥락과 프로젝트 정보를 유지
  • 완료 후 두 인간에게만 결과 통보

다자 과업에서 인간 개입 제거가 생산성의 핵심

기존 접근법으로는 부족하다

실험 방법론 — 미팅 스케줄링

제약을 만족하면서도 경쟁적으로 시간대를 협상해야 하는, 단순하지만 본질적인 조율 과제

S1

학생 → 교수 1:1 미팅 요청

N명의 학생이 각자 Alvarez 교수와 30분 미팅을 확보 — 교수 캘린더에는 연구 시간이 이미 배정

S2

교수 주관 그룹 미팅

Alvarez 교수가 N명의 TA와 CSE455 스태프 미팅 조율 — 공통 가능 시간이 극히 적음

규모
N ∈ {1, 3, 5, 7}, 시나리오당 10회 반복, 항상 복수의 해가 존재
모델
M1: 전원 GPT-5.4 / M2: 교수만 Claude Opus 4.8
통신
E1 격리 p2p 세션 / E2 공유 컨텍스트 p2p / E3 그룹 메시징(순서 보장 멀티캐스트)

RQ1 결과 — 정직한 에이전트도 자주 실패한다

참여 에이전트 수와 동시 과업 수가 늘어날수록 성공률이 급락 — 조율 규모가 핵심 장벽

핵심 병리는 모델 능력이 아니라 "불량한 커뮤니케이션" — 현재 맥락에서 무효한 메시지를 생성·수신·처리하는 것

기존 에이전트 하네스는 주체와의 상호작용에는 최적화되어 있지만, 에이전트 사이의 커뮤니케이션 실패는 막지 못한다

RQ2 — 결함 있는 에이전트가 만드는 추가 위협

"Faulty" = 무능, 일시적 장애, 설정 오류, 침해(compromised), 악의적 — 원인은 다양하지만 효과는 공통

협업 정체

진행 자체를 막아 합의에 도달하지 못하게 함

결과 왜곡

커뮤니케이션("speech") 취약점을 착취해 합의를 자신의 목표로 조종

유해 목표 추구

정상 에이전트의 신뢰를 역이용해 다른 위해 행위 수행

실험 기준: 수락된 시간이 정직한 에이전트가 제안했고 결함 에이전트의 영향이 없어야 성공으로 인정

근본적 한계 — 기만은 감지할 수 없을 때가 많다

사후 검증만 가능한 진실성

"진실"이 오직事后에만 확인될 수 있다면, 전략적 기만과 정직한 통신을 런타임에 구분하는 것은 원리적으로 불가능

국소 시야의 사각지대

공모(collusion) 같은 행위는 개별 에이전트의 지역적 관점으로는 탐지 불가 — 전체 그룹 수준의 정보가 필요

LLM 개선과 컨텍스트 관리로 정직한 에이전트의 성과는 올라가겠지만, 악의적 에이전트의 공격 능력도 함께 진화한다

해결책 — 소셜 하네스(Social Harness)

개인 하네스

주체와의 통신·사적 컨텍스트를 각 에이전트가 자체 관리 (기존 개념)

사회 하네스

신뢰 경계를 넘는 에이전트 간 상호작용을 위한 공용 인프라 (본 논문의 제안)

하네스가 제공해야 할 3가지 기능

1
예방
무효한 메시지가 생성·전송되지 않도록 원천 차단
2
런타임 탐지
대역 내(in-band) 실시간 검증으로 자기보존 지원
3
사후 제재
악의적·결함 행동을 조사하고 결과에 대한 책임을 물어 미래 위반 억제

5계층 소셜 하네스 스택 제안

각 계층은 특정 서비스를 제공하고, 상위 계층이 하위 계층의 서비스를 활용·구성

5
거버넌스·집행 — 위반 조사, 제재, 사회 규칙의 최종 집행
4
과업별 커뮤니케이션 규범 — 예: 제안 후에는 수락 또는 반제안이 뒤따라야 함
3
행동 가드레일 — 부적절한 에이전트 행동에 대한 방지책
2
신뢰성·순서 보장 통신 — 순서가 보장된 안정적 메시지 전달
1
기반 서비스 (신원 등) — 상위 모든 계층이 의존하는 기본 서비스

인간 협업을 효과적으로 만드는 요소에서 착안 — 전통적 네트워킹 스택이 컴퓨터 통신을 해방시킨 것처럼, 계층화가 에이전트 협업의 잠재력을 해방

열린 질문과 향후 연구

  • 이 5계층 분해가 최선의 구조인가? — 커뮤니티 피드백과 실전 경험을 통한 반복적 개선이 필요
  • 각 계층의 서비스를 어떻게 구현·검증할 것인가 — 예방, 런타임 탐지, 사후 제재의 구체적 메커니즘
  • 국소 시야로 탐지 불가능한 공모 등을 잡아내려면 사회 수준의 관측을 누가, 어떻게 수행하는가
  • 인간 사회의 제도(규범·집행)를 에이전트 사회에 얼마나 이식 가능한가

계층화된 소셜 하네스는 에이전틱 협업의 방대한 잠재력을 발현하는 길이다

결론

  • 정직·유능한 에이전트만으로도 기존 인프라에서는 만족스러운 결과에 자주 실패
  • 결함·악의적 에이전트는 "speech" 취약점으로 협업을 정체시키거나 결과를 왜곡 — 감지 불가능한 경우도 많음
  • 에이전트 사회에는 개인 하네스를 넘어 사회적 하네스가 필요: 예방 → 런타임 탐지 → 사후 제재
  • 5계층 스택 제안을 통해 네트워킹 스택에 준하는 협업 인프라 혁신을 촉구
