배경: 왜 LLM 워터마킹인가?

필요성

  • 가짜 뉴스, 허위 정보 확산 방지
  • 악의적 행위자에 의한 모델 증류(model distillation) 차단
  • EU AI Act가 AI 생성 콘텐츠 표시 요구

이미 대규모 배포 중

  • SynthID-Text → Gemini
  • Anthropic → Claude 출력 표시
  • OpenAI → textGrain
  • Meta → TextSeal (전작)
워터마킹: 비밀 키와 직전 토큰으로부터 유도된 의사난수와의 결합(coupling)을 통해, 생성 시점에 각 토큰에 keyed 통계적 신호를 삽입

배포 수준 워터마크의 4가지 요구사항

01

출력 분포 보존

모든 키에 대해 평균 시 모델의 다음 토큰 분포와 동일 (distortion-free)

02

출력 다양성 유지

고정된 워터마크 키에서도 답변이 반복 생성 시 다양하게 유지

03

최소 지연

디코딩에 측정 가능한 추가 지연 없음

04

Speculative Decoding 호환

토큰 수용률(acceptance rate) 보존 — 워터마크가 속도를 해치면 안 됨

기존 방법들의 한계

TextSeal: 코인 플립의 신호 손실

각 토큰을 코인 플립으로 두 키 중 하나로 생성 → 검출기는 어느 키를 썼는지 모르므로 양쪽 키의 점수를 평균해야 함 → 신호 절반 손실, SNR은 √2배 감소

textGrain: 최적 수송의 비용

매 디코딩 스텝마다 정규화된 최적 수송 결합을 풀어야 함 → post-logits 지연 발생, 사양 디코딩 변형은 수용률 -5%로 요구사항 (iii), (iv) 위반

SynthID-Text: 사양 디코딩에서 급락

토너먼트 방식은 사양 디코딩 시 검출률이 89% → 50%로 하락

Copula Mixing

두 키의 Gaussian 값을 단일 가상 키로 병합하고, AutoMark의 copula를 신선한 노이즈와 결합

희석 없는 병합

공개 키를 포함한 임의 개수의 키도 검출 신호를 희석하지 않고 병합 가능

왜 코인 플립은 신호를 잃는가?

TextSeal (코인 플립)

  • 각 토큰은 사실 한 키 아래 생성됨
  • 그러나 검출기는 어느 키인지 모름
  • 두 키 점수의 평균 → 신호 ½로 감소
  • SNR은 √2배 저하

AutoMark / textGrain (단일 키)

  • 단일 키를 매 토큰마다 스코어링
  • 다양성은 신선한 랜덤성에서 확보
  • 검출 신호 손실 없음
TextSeal2는 TextSeal의 두 키를 그대로 유지하면서, copula 병합으로 단일 키 방식과 동일한 검출 효율을 달성

핵심 아이디어 2: Memoryless Races

Speculative decoding: 드래프트 모델이 토큰을 제안하고, 타깃 모델이 블록 단위로 검증. 거절된 드래프트를 대체하는 토큰도 같은 키로 워터마킹되어야 함.

1
키드 드래프트 생성
드래프트 모델이 8개 토큰 제안 (키 적용)
2
블록 검증
지수 레이스(exponential race)로 타깃 분포 검증
3
잔여 레이스
드래프트 레이스의 leftover에서 지수 레이스 1회 추가 실행

무기억성(Memorylessness)

지수 분포의 무기억성 덕분에 잔여 레이스가 블록 검증을 정확히 재현

정확한 출력 보존

출력이 타깃 모델 분포를 정확히 따르며 수용률 불변

엔트로피 제어와 검출

엔트로피 예산 관점

  • 키가 토큰을 완전히 결정 → 검출 최강, 그러나 다양성 0
  • 키와 무관 → 다양성 유지, 그러나 신호 없음
  • 워터마킹 = 각 토큰 엔트로피의 일부를 제거하는 예산 할당 문제

검출 및 위치 추적

  • 키와 텍스트로 의사난수 값을 재계산
  • 토큰과의 통계적 정렬을 검정 (FPR 10⁻³에서 평가)
  • 공개 검출 옵션: 하나의 키를 공개하고 다른 키는 비공개 유지 가능

TextSeal2는 제거되는 엔트로피 양을 명시적으로 제어하여 다양성–검출률 트레이드오프를 정밀하게 조정

다양성–검출률 트레이드오프

사양 디코딩 없이 (a)

  • TextSeal2는 단일 키 copula처럼 동작하므로 AutoMark의 copula와 곡선이 일치
  • 코인 플립 방식(TextSeal)의 곡선을 상회

사양 디코딩 적용 시 (b)

  • TextSeal2는 잔여 레이스(residual race) 사용
  • 기존 방법들의 네이티브 정지 규칙 대비 전 구간에서 우수
  • AutoMark copula와의 격차가 바로 잔여 레이스의 기여
다양성 지표: Self-BLEU (낮을수록 다양함) — TextSeal2는 동일 Self-BLEU 수준에서 가장 높은 검출률 달성

결론

기여 요약

  • Copula Mixing: 복수 키를 가상 키로 병합해 코인 플립의 신호 손실 제거
  • Memoryless Races: leftover上的 지수 레이스로 사양 디코딩 하에서도 왜곡 없는 워터마킹 유지
  • 엔트로피 제어: 다양성–검출률 트레이드오프의 명시적 조절
