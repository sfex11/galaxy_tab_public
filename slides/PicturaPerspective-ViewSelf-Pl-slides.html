Pictura

Perspective-View Self-Play at Scale for Driving

관점 이미지에서 직접 학습하는 최초의 대규모 자율주행 셀프플레이 정책

문제 제기

기존 Self-Play의 근본적 한계

특권 상태(Prioritized State) 의존

기존 대규모 셀프플레이(Gigaflow 등)는 벡터화된 내부 시뮬레이션 상태를 관측으로 사용합니다. 이는 카메라로 절대 얻을 수 없는 정보 — 가려진 에이전트의 정확한 위치, 속도 등 —를 포함합니다.

증류의 근원적 모순

특권 정책을 카메라 입력 학생으로 증류하는 방식은, 학생이 자신의 시야로 정당화할 수 없는 결정을 모방하게 만듭니다. LEAD 연구에서 문서화된 이 모순을 본 연구도 확인합니다.

"특권 단계는 불필요하다. 강화학습을 관측 가능한 이미지에서 직접 수행할 수 있다."

핵심 아이디어

관점 뷰 셀프플레이

특권 정보를 제거한 채, 시뮬레이션 내에서 직접 카메라 관점의 이미지를 렌더링하여 셀프플레이를 수행합니다.

1
가시성 제약(Observability Constraint)

정책이 카메라로 볼 수 없는 정보를 활용하지 못하도록 원천 차단

2
래스터라이제이션 중간 지점

광실사 렌더링은 비용이 과대하므로, 외형을 버리고 구조만 래스터라이징

3
인식과 제어의 통합 학습

특권 교사나 증류 절차 없이, 셀프플레이 루프 안에서 이미지에서 직접 주행 학습

시뮬레이터

Pictura: GPU 가속 다중 에이전트 주행 시뮬레이터

Gigaflow의 세계 설계를 벡터화하여 재구현하고, 커스텀 CUDA 래스터라이저를 통합한 완전한 시뮬레이터입니다.

렌더러

GPU 네이티브 래스터라이저

설계 철학

  • 학습 스택에 맞춤 설계 (PyTorch 텐서 I/O)
  • 외형(Appearance) 생략, 구조만 렌더링
  • 매 시뮬레이션 스텝마다 모든 에이전트 관점 렌더링
  • Madrona 기반 렌더러 대비 월등한 효율

렌더링 피처

  • 이동 차량 (바운딩 박스)
  • 차선 및 도로 그래프
  • 교통 신호등 (상태 포함)
  • 보행자, 자전거, 벽, 주차 차량
  • 거리 기반 깊이 정보

"장면 구조와 역학이 외형보다 학습 신호를 더 많이 전달한다는 증거가 늘고 있다."

학습

수집된 트레이스로 정책 경사 업데이트

특권 교사 없음 · 증류 절차 없음 · 인간 시연 데이터 없음 · 오직 셀프플레이만으로 주행 학습

정책

Alberti: 관점 뷰 셀프플레이 정책

아키텍처

  • CNN 백본으로 렌더링된 이미지 인코딩
  • 목적지 및 속도 제한 등 조건 정보 결합
  • 액션: 조향각 및 가속도 연속 출력
  • 다중 카메라 리그 지원

학습 규모

500억 에이전트 스텝

3,500만 km 주행 거리

단일 H100에서 순수 PPO로 학습

가려진 영역에서는 감속하고, 전방이 확실히 비었다고 판단하면 재가속하는 인간 같은 거동이 자발적으로 출현합니다.

성능

렌더링 효율성 비교

렌더러 처리량 (SPS) GPU 비고
Pictura 래스터라이저 500K H100 CUDA 네이티브, 학습 루프 내장
Madrona (GPUDrive) — A100 렌더링 없음 (벡터 상태만)
CARLA ~수십 GPU 광실사, 단일 환경
MetaDrive ~수백 GPU 게임 엔진 기반

Pictura의 래스터라이저는 병목이 되지 않습니다 — 시뮬레이션 스텝 속도가 렌더링 처리량보다 느리게 유지되어, 관점 렌더링이 셀프플레이의 속도를 제한하지 않습니다.

평가

주행 성능: 도메인 내 셀프플레이 평가

Alberti (관점 뷰)

  • 이미지에서 직접 학습
  • 특권 정책에 근접한 주행 성능 달성
  • 해상도 변화에 대한 강건성 확인

벡터화된 특권 정책

  • 내부 시뮬레이션 상태 직접 관측
  • 가려진 에이전트 정보 포함
  • 동일 학습 조건에서 성능 상한

핵심 발견: 특권 정보 없이도 유사한 수준의 주행 성능에 도달할 수 있음을 실증. 관점 뷰가 가시성 제약을 강제하지만, 정책은 시야 내 정보만으로 충분히 효과적인 결정을 학습합니다.

전이

제로샷 전이: WOMD 레이아웃

Waymo Open Motion Dataset의 실제 도로 맵, 에이전트 초기 상태, 목적지를 Pictura에 재렌더링하여 제로샷 평가합니다.

Alberti (관점 뷰)

더 우수한 전이 성능

훈련에 없던 실제 맵에서 특권 벡터 에이전트를 능가

특권 벡터 에이전트

상대적으로 낮은 전이 성능

특권 정보에 과적합으로 인한 도메인 간 격차

관점 뷰로 학습한 정책이 오히려 더 잘 전이된다는 역설적 결과 — 가시성 제약이 일반화에 도움이 됨.

분석

시각적 정착(Visual Grounding) 분석

반사실 탐색(Counterfactual Probes)

특정 객체(차량, 보행자 등)를 렌더링에서 제거했을 때 정책의 행동 변화를 분석하여, 정책이 실제로 시각적 정보에 기반하여 결정을 내리는지 검증합니다.

폐루프 주행 중 가려짐 인식

가려진 영역이 많은 장면에서 자연스럽게 감속하고, 시야가 확보되면 재가속하는 행동이 관찰됩니다. 이는 특권 정보 없이도 장면의 불확실성을 시각적으로 추론함을 보여줍니다.

반면, 특권 벡터 정책은 가려진 에이전트에 직접 반응하므로, 카메라 학생이 이를 모방하면 보이지 않는 것에 반응하는 비정상 행동이 발생합니다.

기여

결론 및 세 가지 기여

1
온보드 관측 기반 대규모 셀프플레이

특권 벡터 상태에 국한되었던 대규모 주행 셀프플레이를 관점 이미지에서 직접 수행 가능함을 최초로 실증

2
Pictura: GPU 네이티브 렌더러 통합 시뮬레이터

이동 차량 외에 교통신호, 보행자, 자전거, 벽, 주차 차량을 포함한 완전한 벡터화 시뮬레이터. 단일 H100에서 500K SPS 달성

3
Alberti: 관점 뷰 셀프플레이 정책

특권 교사나 증류 없이 순수 PPO로 학습. 특권 대응체에 근접한 성능 + WOMD 제로샷 전이에서 오히려 우수
