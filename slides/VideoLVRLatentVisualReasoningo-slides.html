VideoLVR

Latent Visual Reasoning over Grounded Video Evidence

추론 중 필요한 시각 증거를 잠재 상태(latent state)로 재방문하는 비디오 추론 프레임워크

arXiv: 2610.37613v1 · 2026

문제: 시각 망각 (Visual Forgetting)

CoT 추론의 발전

  • MLLM의 비디오 이해·추론 능력 크게 향상
  • 시간적 위치 추적 + 다단계 추론 가능
  • SFT와 강화학습으로 역량 강화

그러나 — 추론 흔적은 언어 중심

  • 추론이 진행될수록 관련 시각 증거 접근성 상실
  • 이후 단계에 필요한 시간적으로 드문(sparse) 증거를 재방문하기 어려움
  • 비디오 내용에 대한 추론 능력 저하
언어 기반 추론만으로는 중간 추론 단계에서 필요한 시각 증거를 신뢰롭게 재방문할 수 없다.

기존 접근법의 한계

접근법방식장점한계
텍스트 좌표 기반
Video-R2, Open-o3-Video		 타임스탬프·바운딩 박스 좌표로 증거 참조 컴팩트하고 추적 가능 증거의 위치만 표현, 시각 내용 자체는 부재
시각 도구 기반
DeepEyes, VITAL, VideoSearcher		 영역 크롭·프레임·클립을 재삽입 세밀한 시각 정보 확보 재인코딩·삽입으로 컨텍스트 급증, 미리 정의된 연산에 종속
두 방식 모두 시각 의미(visual semantics)를 보존하면서 컴팩트하고 유연하게 시각 내용을 재방문할 방법을 제공하지 못한다.

핵심 아이디어: 잠재 시각 추론 (LVR)

VideoLVR의 제안

  • 관련 비디오 순간의 국소 영역에서 잠재 시각 증거를 구성
  • 텍스트 토큰과 잠재 시각 상태를 인터리빙하며 추론
  • 프레임·크롭 삽입 없이 멀티모달 컨텍스트를 거의 확장하지 않고 증거 재방문

핵심 설계

1
증거 기반 데이터 합성 — 시공간 그라운딩 주석이 포함된 추론 궤적
2
Visual Token Prediction (VTP) — 시각 토큰 재구성을 예측 문제로 통합
3
TVPO — 텍스트·시각 토큰 행동의 강화학습 공동 최적화

방법 ① 증거 기반 데이터 합성

궤적 거부 샘플링
Trajectory Rejection Sampling

추론 궤적을 생성하고, 시공간 그라운딩 주석에 부합하는 증거 기반 궤적만 선별하여 학습 데이터로 사용

궤적 폴리싱
Trajectory Polishing

선별된 궤적을 증거 지침(evidence guidance)으로 정제하여, 각 추론 단계가 국소 영역의 시각 증거를 명시적으로 지원하도록 개선

결과: 추론 단계마다 어느 순간의 어느 영역이 증거인지 주석된 고품질 학습 궤적 확보

방법 ② 그룹화된 잠재 증거 + VTP

그룹화된 잠재 시각 증거

  • 하나의 잠재 블록 = 같은 추론 단계를 지원하는 국소 영역 증거들의 묶음
  • 서로 다른 비디오 순간의 증거를 공동 모델링
  • 단일 순간의 증거로 부족한 다단계 비디오 추론에 적합

Visual Token Prediction (VTP)

  • 입력 비디오에서 파생된 시각 어휘(vocabulary)에 대한 예측으로 재구성 공식화
  • 유사한 인접 프레임 토큰 사이에서 목표 증거를 구별 (MSE 회귀의 한계 보완)
  • 시각 증거 재구성과 텍스트 생성을 동일한 토큰 예측 프레임워크로 통합

방법 ③ TVPO: 텍스트–시각 정책 최적화

1
행동 확장 — 시각 토큰을 텍스트 토큰과 함께 행동(action)으로 취급
2
시각 토큰 샘플링 — VTP 공식화를 통해 입력 비디오의 시각 어휘에서 시각 토큰 샘플링
3
공동 최적화 — 최종 답변 보상(final-answer reward)으로 텍스트·시각 토큰 정책을 동시에 강화학습

효과 SFT로 학습된 VideoLVR을 강화학습으로 확장하여, 추론 중 어떤 시각 증거를 선택할지까지 보상 기반으로 개선

추론 과정: 컨텍스트 확장 없는 증거 재방문

1
질문 + 비디오 입력
텍스트 추론 시작
2
잠재 증거 생성
VTP로 시각 토큰 예측
3
히든 스테이트 투영
디코더 상태 → 잠재 시각 상태
4
모델 재주입
프레임·크롭 삽입 없이 피드백
5
답변 생성
증거 기반 최종 답변
추가 프레임이나 영역 크롭을 멀티모달 컨텍스트에 삽입하지 않고, 잠재 상태만으로 과업 관련 시각 정보를 효율적으로 재방문

실험 결과

주요 결과

  • 다수의 비디오 이해·추론 벤치마크에서 전반적 성능 향상
  • 특히 세밀한(fine-grained) 시각 증거가 필요한 과제에서 큰 개선
  • 멀티모달 컨텍스트를 크게 확장하지 않고 비디오 이해 개선

왜 효과적인가?

1
추론 중 국소 영역 증거를 잠재 상태로 유지 → 시각 망각 완화
2
VTP가 유사 토큰 사이에서 정확한 증거 구별 유도
3
TVPO가 답변 보상에 맞춰 증거 선택 정책까지 최적화

절제 연구 (Ablations)

  • Visual Token Prediction — 예측 기반 목표가 MSE 회귀보다 유사 증거 구별에 효과적
  • 증거 기반 학습 데이터 — 그라운딩 주석 궤적이 증거 생성 품질 향상
  • 그룹화된 잠재 증거 — 시간적으로 분산된 증거의 공동 모델링에 기여
  • TVPO — 강화학습 확장이 전반적 정답률 추가 향상

추가 분석

1
잠재 스텝 예산 — 추론 시 잠재 증거 생성 횟수가 성능에 영향
2
RL 학습 동역학 — 텍스트·시각 행동의 공동 수렴 과정 관찰
3
어휘 온도 — 시각 토큰 샘플링 온도의 효과 분석
4
잠재 상태 내용 — 잠재 상태가 실제 시각 의미를 인코딩하는지 검증

핵심 기여 요약

1

VideoLVR 프레임워크

증거 기반 추론 궤적으로부터 비디오 순간들의 국소 영역을 그룹화된 잠재 시각 증거로 구성하여, 시간적으로 분산된 증거를 공동 모델링

2

VTP + TVPO

입력 비디오의 시각 어휘에 대한 Visual Token Prediction으로 잠재 증거 생성을 텍스트 예측과 통일하고, 이를 바탕으로 텍스트·시각 행동을 TVPO로 공동 최적화

3

광범위한 검증

다수의 비디오 추론 벤치마크 평가와 핵심 설계에 대한 철저한 절제 연구로, 세밀한 시각 증거가 필요한 과제에서 특히 큰 향상 입증

결론

VideoLVR은 비디오 순간의 국소 영역에서 잠재 시각 증거를 구성하고, VTP로 시각 증거 생성을 토큰 예측 체계에 통합하며, TVPO로 강화학습까지 확장하여 — 컨텍스트 확장 없이 추론 중 시각 증거를 재방문하는 새로운 비디오 추론 패러다임을 제시한다.
