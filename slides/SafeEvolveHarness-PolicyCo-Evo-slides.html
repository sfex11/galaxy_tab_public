LLM Agent Safety arXiv 2609.02786

SafeEvolve

Harness-Policy Co-Evolution from Agent Experience for Safety Alignment

에이전트 경험으로부터의 하네스–정책 공동 진화를 통한 안전 정렬

Qinghua Mao*, Wanying Qu*, Dadi Guo, Leitao Yuan, Qingyu Liu, Yu Li, Guanxu Chen, Yanwei Fu, Xi Lin, Xia Hu, Dongrui Liu†

Shanghai AI Laboratory · SJTU · Fudan University · HKUST · Zhejiang University

배경: 에이전트의 성능과 안전은 두 요소의 결합으로 결정

베이스 모델 (Policy)

장기 시간에 걸쳐 계획을 세우고, 도구를 호출하고, 메모리를 갱신하는 LLM 자체. 안전 능력은 파라미터에 내재됨.

하네스 (Harness)

지시문, 스킬, 메모리 등 모델 외부의 편집 가능한 구성요소. 에이전트가 환경과 상호작용하는 방식을 매개함.

안전 실패는 유해한 최종 응답뿐 아니라 다단계 실행 궤적에서도 발생
— 안전하지 않은 도구 호출, 주입된 지시문(prompt injection) 추종 등

기존 안전 정렬의 두 패러다임과 한계

하네스 중심

외부 아티팩트(지시문·스킬·가드레일)로 안전 규제 제공

  • 약한 frozen 정책이 정교한 아티팩트를 신뢰성 있게 따르지 못함
  • 다단계 실행 중 행동과 분리(decouple)되어 효과 감소

정책 중심

파라미터 업데이트(SFT, DPO, RLHF 등)로 안전 지식을 흡수

  • 고정 하네스 아래 최적화 → 신규 실패 모드에 적응 불가
  • 파라미터에 내재된 안전 능력은 모델 간 전이가 어려움

핵심 도전: 런타임 제어(하네스)와 내재적 안전(정책)을 긴밀히 결합해 지속적인 안전 자기 개선을 달성하는 것

SafeEvolve: 경험 주도 자가 진화 프레임워크

완료된 on-policy 궤적의 안전 경험을 공유 기반으로 삼아, 외부 하네스와 내부 정책이 상호 진화하는 공진화 플라이휠(co-evolutionary flywheel)을 구축

하네스 진화

궤적 수준 안전 증거 → 명시적 위험 귀속이 포함된 구조화·버전화된 업데이트 (감사·되돌리기 가능)

정책 최적화

2단계 SFT–RL로 진화된 하네스를 다단계 실행 중 내재적 안전 행동으로 전환

지속성

최적화된 정책의 새로운 상호작용이 다음 진화의 안전 증거로 축적

관측가능성 주도 하네스 진화

롤아웃 궤적에서 안전 증거를 추출하여 제한적(bounded) 컴포넌트 단위 업데이트로 변환

1
궤적 수집
에이전트–환경 상호작용 롤아웃
2
증거 추출
궤적 수준 안전 실패·위험 패턴 분석
3
위험 귀속
명시적 risk attribution
4
컴포넌트 업데이트
안전 프롬프트 + 계층적 스킬(SkillBank)

안전 프롬프트 · 계층적 스킬로 구성된 안전 하네스를 대상으로 제한된 범위의 갱신만 수행

버전화된 아티팩트 → 감사 가능(auditable)하고 되돌리기 가능(reversible)

하네스 증강 정책 최적화: 2단계 SFT–RL

1
Harness-use SFT
진화된 하네스 아티팩트를 능동적으로 활용하도록 정책을 부트스트랩 — 외부 가이던스 준수 능력 확보
2
Harness-Augmented RL
verifier 분해 보상(verifier-decomposed rewards)으로 다단계 탐색 중 자율적 안전 의사결정을 내재화

왜 두 단계인가?

SFT 없이는 약한 정책이 진화된 하네스를 활용하지 못하고, RL 없이는 안전 행동이 외부 의존에 머무름

보상 설계

안전–유틸리티 결합 보상으로 다단계 실행 전반의 행동을 형성

지속적 하네스–정책 공진화 루프

1
상호작용
정책이 환경에서 롤아웃 수행
2
증거 축적
궤적에서 안전 증거 도출
3
하네스 갱신
bounded·버전화된 아티팩트 업데이트
4
SFT–RL
진화된 하네스로 정책 재최적화
갱신된 정책이 다시 환경과 상호작용하며 새로운 안전 증거를 생성 → 복잡한 다단계 과제에서 지속적 안전 자기 개선 달성

실험 설정

벤치마크

  • AgentDojo — 환경 주입 공격
  • AgentDyn — 동적 위험 분포
  • AgentHarm — 악성 쿼리

베이스라인

  • SFT · DPO · GRPO
  • MetaSecAlign
  • AgentAlign

평가 지표

  • ASR (공격 성공률) ↓
  • Harm Score ↓
  • Benign Utility · Refusal Rate ↑

백본: Qwen3.5-4B 등 — 환경 주입, 유해 도구 사용, 악성 쿼리 등 다양한 궤적 수준 위험에 대해 평가

주요 결과: 안전–유틸리티 트레이드오프 동시 개선

AgentDojo

동시에 clean utility 59.79% → 61.86% 향상

AgentHarm

측면기존 정렬 기법SafeEvolve

유틸리티 보존안전 강화 시 흔히 저하오히려 소폭 향상

진화 기제 분석

Skill-Bank 진화 동역학

스킬 뱅크가 반복 루프를 거치며 안전 위험 패턴을 점진적으로 정제·축적. 스킬 검색(skill retrieval) 제거 시 성능 저하 → 검색 기반 활용이 기여

안전 능력의 내재화

OPSD 분석: 하네스에 의존하던 안전 능력이 공진화를 거치며 정책 행동 자체에 부분적으로 내재화됨을 확인

  • 하네스–정책 진화 결합의 ablation: 어느 한쪽만 진화할 때보다 결합 시 안전–유틸리티 균형이 가장 우수
  • 학습 중 온라인 하네스 갱신: 정책 훈련 도중 하네스를 함께 갱신해도 추가 이점 확보

일반화 및 사례 분석

강한 제안자

Strong-model proposer 제거 시 하네스 진화 품질 저하 → 고품질 증거 컴파일의 중요성 확인

하네스 전이

진화된 하네스가 다른 정책으로 전이(cross-policy transfer) 가능 — 외부 아티팩트로서의 재사용성 입증

비가산적 효과

프롬프트+스킬 결합 하네스는 단순 합산 이상의 상호작용 효과로 안전 개선 달성

실패 유형 분석·정성 사례: AgentHarm 악성 쿼리 사례에서 진화된 안전 프롬프트와 스킬이 유해 실행 경로를 조기에 차단하는 과정 확인, Held-out 벤치마크에서도 일반화 성능 유지

결론

  • 경험 주도 자가 진화 프레임워크 — SafeEvolve: 완료된 on-policy 궤적을 안전 능력으로 변환하는 하네스–정책 결합 루프 제안
  • 두 갈래 교차 과정 — 하네스: 궤적 수준 증거 → bounded·버전화된 아티팩트 갱신 / 정책: 2단계 SFT–RL로 진화된 하네스를 다단계 실행에 적용
  • 강한 안전–유틸리티 트레이드오프 — Qwen3.5-4B에서 AgentDojo ASR 3× 감소, benign utility 동시 향상; AgentHarm 유해도 4.6× 감소, 거부율 대폭 상승
외부 하네스와 내부 정책의 공진화를 통해 런타임 제어와 내재적 안전을 통합 — 지속 가능한 에이전트 안전 정렬의 새로운 패러다임 제시
