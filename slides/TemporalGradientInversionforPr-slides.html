그래디언트 역전 공격

프라이빗 입력에서 계산된 그래디언트로 원본 데이터를 고피델리티로 복원하는 근본적 위협. Embodied RL에서는 위험이 더욱 심화됨:

  • 시간 순서의 카메라 뷰 → 방 구조·물체·시선·체류 지점 노출
  • 활동 프로파일링, 공간 매핑, 지속적 감시로 이어질 수 있음

문제의식: 단일 프레임 공격의 한계

기존 그래디언트 역전 기법

  • 단일 이미지·정적 i.i.d. 미니배치 대상
  • 교차 엔트로피 등 단순 지도 손실로 최적화
  • 각 그래디언트 g₍t₎를 독립적으로 역산
  • 시간적 일관성(temporal coherence) 완전히 무시

Embodied 궤적의 실제 구조

  • 물리적 과정의 순서 있는 측정 — i.i.d. 표본이 아님
  • 전이 동학이 연결: 제한된 이동·회전, 지속되는 3D 장면
  • 인접 관측이 레이아웃·물체·조명·기하를 공유
  • PPO/A2C 그래디언트는 정책·가치·엔트로피 항이 결합된 형태

RL 그래디언트 누출은 독립적인 이미지 역산의 집합이 아니라 궤적 역전(trajectory inversion) 문제다.

문제 정식화: 궤적 그래디언트 역전

공격자 모델

  • Honest-but-curious 서버: 정상적으로 집계하면서 클라이언트 그래디언트를 관찰
  • 화이트박스 가정: 모델 구조·체크포인트 θ₀·행동 공간·학습 규칙을 알고 있음
  • 동일 작업군의 보조 궤적으로 공격 모델을 오프라인 학습 후 그래디언트만으로 추론

공격 목표

연속 궤적 그래디언트 𝒢₁:T = (g₁, …, g_T)로부터

  • 프라이빗 RGB 관측 시퀀스 ŝ₁:T 복원
  • 이산 행동 시퀀스 â₁:T 예측
  • 기대 재구성 오차 + 행동 예측 오차 최소화

설정 클라이언트는 A2C/PPO로 정책 학습 → 각 라운드마다 서버가 모델 θ₀ 브로드캐스트 → 클라이언트가 프라이빗 환경에서 롤아웃 수행 → 스텝별 그래디언트 g₍t₎ = ∇θ ℒᵗᵃᶜ(θ)|θ₀ 를 순서대로 전송

TRACE: 핵심 아이디어

연속된 관측은 정책 그래디언트에 상관된 서명을 남긴다 — 시간 맥락이 프라이버시 누출을 증폭시킨다.

① 교차 시간 상관

연속된 embodied 그래디언트 간 교차 시간 상관을 조건부 상호정보량 상한으로 형식화. 과거 그래디언트들이 다음 스텝 복원의 부수 정보(side information)를 제공하여 스텝별 재구성 모호성을 감소시킴.

② 닫힌 형태 행동 복원

정책 헤드(policy-head) 그래디언트 구조로부터 실행된 행동을 닫힌 형태로 직접 복원. 표준 엔트로피 정규화가 충분히 작으면 복원이 정확함(exact)을 이론적으로 증명.

Amortized 기존의 그래디언트별 최적화나 단일 프레임 학습 기반 매핑과 달리, 궤적 전체에 걸쳐 공격 비용을 상각 — 프레임당 밀리초 단위의 근사 실시간 추론

자기회귀 학습

이전 스텝의 복원 결과를 조건으로 다음 스텝을 순차 디코딩 — 시간 일관성 제약이 환경의 전이 동학을 만족하는 복원을 유도

상각화된 공격

프레임마다 최적화 반복이 불필요. 한 번 학습된 모델이 관측된 그래디언트 스트림만으로 즉시 추론 수행

이론 ①: Actor-Critic 그래디언트의 행동 복원 가능성

스텝별 통합 actor-critic 목적함수 (A2C / PPO):

ℒᵗᵃᶜ(θ) = ℓᵖᵒˡ(θ) + c_v (V_θ(s₍t₎) − R̂₍t₎)² − c_e ℋ(π_θ(·|s₍t₎))

정책 항 + 가치 항 − 엔트로피 정규화 항의 결합. 가중치는 롤아웃에서 유도된 advantage Â₍t₎와 return R̂₍t₎에 의해 결정되며 공격자에게는 숨겨져 있음.

닫힌 형태 행동 복원

정책 헤드 그래디언트 구조로부터 실행 행동 a₍t₎를 닫힌 형태로 직접 복원. 엔트로피 정규화 계수 c_e가 충분히 작으면 복원이 정확(exact)함을 증명.

A2C–PPO 등가성과 분해

그래디언트 분해를 통해 A2C와 PPO 목적함수의 그래디언트 등가성을 정식화 — 두 알고리즘 모두 동일한 누출 구조를 공유
