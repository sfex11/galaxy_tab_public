arXiv 2611.12885

World In-Context Learning
for Agentic Robot Manipulation

세계 모델의 피드백으로 완성하는 로봇 조작의 문맥 내 학습

학습된 정책의 분포 종속성을 벗어나, 시연만으로 새로운 장면에서 조작을 수행하는 에이전틱 프레임워크

배경: 학습된 정책의 근본적 한계

기술이 가중치에 각인됨

조작 스킬(manipulation skill)은 학습을 통해 네트워크 가중치 안에 저장됩니다. 즉, "무엇을 배웠는가"가 곧 "어디서 배웠는가"와 결합됩니다.

분포 종속성 (Distribution Coupling)

학습 데이터 분포를 벗어난 새로운 객체, 배치, 조명, 장면에서는 성능이 급격히 저하됩니다.

→ 새로운 환경마다 재수집·재학습이 필요한 비효율이 발생합니다.

In-Context Learning: 가능성과 벽

  • 가중치를 수정하지 않고 시연(demonstration)을 문맥으로 제공해 행동을 유도
  • 새로운 태스크에 대한 적응이 추론 시점에 일어남
  • 파운데이션 모델(VLM 등)의 일반 지식을 로봇 조작에 활용 가능

그러나 ICL은 아직 학습된 정책(trained policies)의 성능에 미치지 못했습니다.

핵심 질문: 왜 다른 장면에서 잘 작동하는 시연이 현재 장면에서는 실패하는가?

문제의 본질: 시연에는 "세계의 피드백"이 없다

다른 장면에서 기록된 시연은 그 장면의 세계로부터 받은 피드백을 담고 있지 않습니다.

  • 물체의 위치·형상·마찰 등 장면별 물리적 차이를 반영하지 못함
  • 행동을 취한 뒤 세계가 어떻게 반응했는지에 대한 검증 부재
  • 결과적으로 시연을 현재 장면에 "그대로 복사"하게 됨
바닐라 ICL

시연 모방 → 장면 차이에 취약

필요한 것

현재 장면에서 행동을 검증하고 수정하는 피드백 루프

핵심 아이디어: World In-Context Learning

세계 모델(World Model)을 문맥 내 학습 루프 안에 결합하여, 시연에 빠진 "세계로부터의 피드백"을 복원합니다.

1

가상 롤아웃
세계 모델이 행동의 결과를 미리 시뮬레이션

2

차이 정량화
시연 장면과 현재 장면의 갭을 피드백으로 변환

3

자율 수정
에이전트가 스스로 시도 → 검증 → 행동 보정

가중치는 그대로, 변하는 것은 오직 문맥과 피드백뿐입니다.

전체 파이프라인

1
시연 주입
타 장면의 조작 시연을 문맥으로 제공
2
후보 행동 생성
VLM/정책이 현재 관찰 기반으로 행동 초안 생성
3
세계 모델 롤아웃
가상 공간에서 행동 결과 예측·평가
4
피드백 반영
실패 요인을 분석해 행동 수정
5
실제 실행
검증된 행동을 실제 로봇에 적용

2~4단계가 실패 없는 실행이 확인될 때까지 에이전틱 루프로 반복됩니다.

에이전틱 루프: 스스로 시도하고, 스스로 고친다

1
계획 (Plan) — 시연 문맥 + 현재 관찰로 조작 계획 수립
2
시뮬레이션 (Imagine) — 세계 모델이 계획의 미래 결과를 렌더링
3
평가 (Evaluate) — 목표 상태와 예측 결과의 불일치 탐지
4
수정 (Refine) — 파악된 차이를 반영해 행동 파라미터 갱신
5
실행 (Act) — 수렴한 행동을 실제 환경에서 수행

실행 결과는 다시 관찰로 들어와 다음 사이클의 문맥이 됩니다.

왜 이 조합이 작동하는가

시연 = "무엇을 할지"의 지식

태스크의 목표와 절차적 지식을 담고 있으며, 장면이 달라져도 의도는 유효합니다.

세계 모델 = "어떻게 할지"의 피드백

현재 장면의 동역학을 반영해, 의도를 실행 가능한 행동으로 보정합니다.

시연이 분포에 묶여 있던 이유는 '세계의 검증'이 없었기 때문 → 세계 모델이 그 빈자리를 채운다.

  • 기술은 문맥에, 검증은 세계 모델에 — 두 결합이 분리됨
  • 실제 로봇 시행착오 없이 가상 공간에서 실패 비용 절감

실험 설정

  • 태스크: 집기(pick-and-place), 정렬, 도구 사용 등 다양한 테이블톱 조작 태스크
  • 평가 환경: 시뮬레이션 벤치마크 + 실제 로봇 팔 실험
  • 일반화 조건: 객체 위치·형상·색상, 배치, 카메라 시점 변화
  • 비교 대상: (1) 학습된 조작 정책, (2) 피드백 없는 바닐라 ICL, (3) 제안 기법

핵심 평가 지표: 태스크 성공률 — 특히 학습 분포 밖(out-of-distribution) 장면에서의 성공률에 주목

주요 결과와 분석

일반화 성능 향상

새로운 객체 배치와 미지 장면에서 바닐라 ICL 대비 성공률이 크게 향상되며, 학습된 정책과 comparable한 수준에 도달합니다.

루프 반복의 효과

세계 모델 피드백 루프의 반복 횟수가 늘어날수록 행동이 점진적으로 정교해지는(수렴하는) 경향이 관찰됩니다.

Ablation 세계 모델 피드백을 제거하면 성능이 바닐라 ICL 수준으로 급락 → 피드백 루프가 성능 향상의 핵심 요인

한계와 향후 연구

한계

  • 세계 모델의 예측 정확도에 전체 성능이 의존
  • 접촉이 많은 조작(tight contact)의 정밀 동역학 모델링은 여전히 어려움
  • 롤아웃 반복에 따른 추론 시간 오버헤드

향후 방향

  • 장기 호라이즌·다단계 태스크로의 확장
  • 실제 실행 결과를 문맥에 누적하는 지속적 적응
  • 더 강력한 비디오 생성 기반 세계 모델과의 결합

결론

  • ICL의 실패 원인은 "세계로부터의 피드백 부재"였다
  • 세계 모델을 루프에 결합해 시연의 장면 갭을 추론 시점에 보정
  • 학습된 정책 수준의 성능 + 분포에 묶이지 않는 일반성을 동시 달성

기술을 가중치가 아닌 문맥과 세계의 대화에 저장하라.
