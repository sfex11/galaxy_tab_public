문제 제기

오디오-언어 모델의 추론 격차

감각 능력 — 우수

음성 인식, 오디오 캡셔닝, 화자 식별 등 청각 지각 능력은 이미 텍스트 LLM 수준에 도달

논리 추론 — 부족

다단계 논리 추론, 복잡한 오디오 사건 분석, 운율 기반 대화 이해 등에서 텍스트 LLM에 크게 뒤처짐

근본 원인: 고품질 오디오 추론 데이터의 극심한 부족. 텍스트 LLM은 조 단위의 논리적 토큰으로 학습되지만, 오디오 모델은 주로 얕은 정렬 목표(전사, 캡셔닝)만으로 훈련됨

기존 방법의 한계

오프라인 증류의 두 가지 병목

1

감각–텍스트 발산

텍스트 교사가 생성한 정적 궤적은 학생이 실제로 인지하는 오디오 입력과 불일치. 교사는 텍스트 전사만 보지만, 학생은 운율·환경음·감정 등 추가 정보를 처리함

2

跨모달 노출 편향

오프라인 증류는 학생이 결코 방문하지 않는 상태의 정답에만 의존. 학생의 인지 전제가 교사의 논리 다양체에서 벗어난 순간, 보정 신호가 부재함

기존 온정책 방법도 텍스트 전용 논리 코퍼스에만 국한되어, 비언어적 오디오 사건 추론과 운율 기반 대화 추론은 여전히 미흡

제안 방법

X3-OPD 프레임워크 개요

Xross-modal X three-tier On-Policy Distillation — 강력한 텍스트 교사가 오디오 학생 모델의 온정책 탐색 중에 동적 보정과 지도를 제공하는 교차 모달 증류 프레임워크

데이터 측면

3계층 대칭 코퍼스 구축 — 모든 인스턴스가 (xt, xa, q, a*) 스키마로 텍스트 입력과 오디오 입력을 동시에 제공

알고리즘 측면

교차 모달 온정책 증류 — 학생은 자신의 오디오 인지로 궤적을 생성하고, 교사가 매칭된 텍스트 입력으로 토큰별 점수를 부여

핵심 아이디어: 온정책 롤아웃이 학생이 실제 방문하는 상태에 감독을 위치시키고, 3계층 대칭 코퍼스가 논리·음향·운율 추론 전 영역에 교사 감독을 적용

데이터 구축

3계층 대칭 데이터셋

T1

텍스트 추론 → 음성 렌더링

텍스트 논리 추론 데이터셋(수학, 논리 퍼즐 등)을 TTS로 음성으로 변환. 텍스트/오디오 쌍 모두에서 동일한 추론 경로 유지

논리 추론
T2

캡션 기반 오디오 사건 추론

환경음·음향 사건에 대한 캡션을 기반으로 추론 질문 생성. 텍스트 전사로는 복원 불가능한 음향 증거에 대한 추론 포함

오디오 사건
T3

운율 인식 음성 대화

운율 정보(억양, 망설임, 감정 변화)를 포함하는 캡션과 함께 음성 대화 데이터 구축. 운율 단서 기반 추론 요구

운율 대화

모든 계층은 통일된 (xt, xa, q, a*) 스키마를 따라 텍스트-오디오 대칭 구조 유지

알고리즘

교차 모달 온정책 증류

1
오프라인 웜스타트
정적 교사 궤적으로 SFT 사전 학습. 온정책 증류의 안정적인 시작점 확보
2
온정책 다경로 롤아웃
학생이 자신의 오디오 인지 xa로부터 K개의 추론 궤적을 샘플링
3
교차 모달 교사 채점
텍스트 교사가 매칭된 xt와 정답 a*로 각 토큰의 확률 분포를 계산
4
증류 목적 함수
학생 정책과 교사 확률 간 KL 발산 최소화로 온정책 업데이트

핵심: 교사는 정답 a*에 대한 특권적 접근을 가지며, 개방형 질의에서는 자신의 견고한 추론 흔적을 동적으로 부여. 학생의 인지 전제가 교사의 논리 다양체에서 이탈하는 정확히 그 지점에서 동적 재정렬 발생

핵심 메커니즘

온정책 증류 vs 오프라인 증류

특성 오프라인 증류 X3-OPD (온정책)
감독 상태 학생이 방문하지 않는 상태 학생이 실제 생성한 상태
교사 입력 텍스트 전사만 매칭된 텍스트 xt + 정답 a*
추론 범위 텍스트 논리만 논리 + 오디오 사건 + 운율 대화
노출 편향 심각 (분포 불일치) 완화됨
동적 보정 불가능 (정적 궤적) 토큰별 동적 교사 지도

분석

CoT 품질 평가 및 감각 퇴화 방지

Chain-of-Thought 품질

GPT-4o 기반 자동 평가 결과, X3-OPD는 추론 궤적의 논리적 일관성과 정확성에서 오프라인 증류를 큰 폭으로 상회. 온정책 교사의 동적 보정이 정적 타겟 암기보다 효과적임을 입증

감각 능력 보존

추론 훈련 후에도 ASR, 오디오 캡셔닝 등 기본 지각 능력에서 퇴화 없음. 3계층 데이터의 대칭 구조가 도메인 시프트로 인한 감각 역량 손실을 방지

절제 연구 핵심 발견

  • 3계층 데이터 모두 사용 시 각 계층 단독 사용보다 추론 성능이 유의미하게 높음
  • SFT 웜스타트 기간이 너무 길면 오히려 온정책 증류의 이점이 감소 (과적합)
  • 전체 코퍼스 웜스타트는 노출 편향을 심화시켜 온정책 전환 시 성능 저하 유발
남은 과제

잔존 격차와 한계

감각 축에서의 잔존 격차

추론 능력은 크게 향상되었으나, 순수 음향 지각 벤치마크(예: 환경음 분류, 화자 인식)에서는 폐쇄형 모델(GPT-4o-Audio)과 여전히 격차 존재

방법론적 한계

  • 텍스트-오디오 정렬에 의존하므로, 완벽한 매칭이 어려운 실제 오디오에 적용 제한
  • 온정책 롤아웃의 계산 비용이 오프라인 방식보다 높음
  • 교사 모델의 편향이 학생에게 전달될 가능성

향후 방향: 멀티모달 교사 도입, 강화 학습과의 결합을 통한 보상 밀도 문제 해결, 실시간 오디오 스트리밍 환경으로의 확장

결론

핵심 기여 요약

3계층 대칭 추론 코퍼스 — 텍스트 추론, 오디오 사건 추론, 운율 인식 대화를 아우르는 최초의 통일된 교차 모달 증류 데이터셋

교차 모달 온정책 증류 — 학생의 오디오 조건부 정책에서 생성된 궤적을 텍스트 교사가 매칭된 텍스트 입력으로 채점하는 새로운 패러다임

종합적 실증 — MMAU, MMSU, BIG-Bench Audio에서 강력한 베이스라인들을 상회하며, 텍스트 도메인 능력 보존과 감각 퇴화 방지도 입증

X3-OPD는 오디오-언어 모델에서 지각과 추론의 통합을 향한 새로운 경로를 제시하며, 모달리티 간 추론 격차를 해소하기 위한 체계적 접근법의 유효성을 보여줌
