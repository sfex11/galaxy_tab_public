추론 시간 스케일링의 한계

최근 LLM의 추론 성능 향상을 위한 추론 시간 스케일링 방법들이 제안되었으나, 근본적인 한계가 존재합니다.

반복 생성

다수의 응답을 생성하여 최적 결과를 선택하나, 토큰 비용이 기하급수적으로 증가

자기 정제

반복적인 자기 피드백 루프로 추론을 개선하나, 여러 세대의 생성이 필요

외부 검증

더 강한 모델이나 검증기를 사용하나, 추가 모델 호출에 따른 오버헤드 발생

핵심 문제: 기존 방법들은 모두 다중 생성에 의존하며, 이는 상당한 추론 비용을 수반합니다.

핵심 통찰: 구조화된 실패 모드

LLM의 오류는 무작위가 아닌 구조적이고 예측 가능한 패턴을 보입니다.

  • 같은 모델 패밀리 내에서 실패 모드 분포가 일관되게 유지
  • Qwen 1.5B와 Qwen 72B가 유사한 실패 구조 공유
  • 약한 모델의 실패가 강한 모델의 실패를 예측 가능하게 함
W→S

약-강 일반화

약한 모델의 실패 모드를
강한 모델의 추론 가이드로 활용

실패를 단순한 부정적 결과가 아닌, 구조화된 가이던스의 원천으로 재해석

CritICL 프레임워크 전체 구조

두 단계로 구성된 추론 시간 약-강 일반화(W2SG) 방법

1
CritBank 구축
SLM으로 응답 생성 → 오답 추출 → 실패 모드 라벨링 → 비판(critique) 생성
2
추론 시간 활용
CritICL-dynamic: 입력 의존적 실패 모드 예측 및 검색
CritICL-static: 전역 실패 모드 프로필 기반 안정적 가이드

CritICL-dynamic

각 입력에 대해 실패 모드를 적응적으로 예측하고 관련 비판을 검색

CritICL-static

모델 패밀리별 전역 실패 모드 프로필을 사용하여 일관된 가이던스 제공

CritBank 구축 과정

1

응답 생성

소형 모델 집합 M이 질문 Q에 대해 CoT 프롬프팅으로 각 5개 응답 생성

2

오답 필터링

정답 여부 함수 φ(q,r)로 오답(R_incorrect)만 추출하여 근본적 추론 실패 노출

3

실패 모드 라벨링 및 클러스터링

프론티어 LLM이 최대 5개 후보 실패 모드 라벨 생성 → 클러스터링으로 대표 실패 모드 추출

4

비판(Critique) 생성

각 (질문, 오답) 쌍에 대해 추론 과정에 대한 세밀한 자연어 비판 생성

최종 데이터셋: {(q, r, l, 𝒞(q,r))} — 질문, 오답, 실패 모드 라벨, 비판의 구조화된 튜플

CritICL-dynamic: 적응적 검색

입력별로 실패 모드를 예측하여 가장 관련성 높은 비판을 동적으로 선택합니다.

작동 원리

  • 새로운 질문 q'이 주어지면 타겟 모델이 해당 입력에 대한 실패 모드 예측
  • 예측된 실패 모드 라벨 l에 대해 ℒ⁻¹(l) 역사상 함수로 관련 (q,r) 쌍 검색
  • 검색된 비판을 in-context 예제로 구성하여 타겟 LLM에 프롬프트 제공

장점

  • 입력 특화적 가이던스로 정밀한 피드백
  • 단일 생성만으로 다중 생성 방법 대비 우수한 효율
  • 질문 유형에 따라 적응적으로 대응

핵심 차별점: 일반적인 의미적 검색이 아닌 실패 모드 기반 검색으로 모델의 실제 약점을 정확히 타겟팅

CritICL-static: 전역 프로필 기반

모델 패밀리 전체의 실패 모드 분포를 사전에 분석하여 안정적인 가이던스를 제공합니다.

작동 원리

  • CritBank에서 모델 패밀리별 실패 모드 빈도 프로필 구축
  • 가장 지배적인 실패 모드에 해당하는 비판 예제를 사전 선택
  • 모든 입력에 대해 동일한 in-context 예제 세트 적용

장점

  • 추론 시 추가 모델 호출 불필요 — 최고 효율
  • 입력에无关한 변동 없이 일관된 성능
  • 프로필은 오프라인에서 한 번만 계산

왜 CritICL이 작동하는가?

모델 스케일 간 실패 모드 분포 일관성

Qwen 1.5B와 Qwen 72B의 실패 모드 상대 분포가 매우 높은 상관관계를 보입니다.

  • 특정 실패 모드의 비율이 모델 크기에 관계없이 유지
  • 약한 모델이 자주 범하는 오류 유형이 강한 모델에서도 동일하게 우세

실패 모드 기반 정밀 샘플 선택

의미적 검색과 달리, 실패 모드 기반 검색은 모델의 실제 약점을 직접적으로 타겟합니다.

  • 의미적으로 유사한 예제가 아닌, 같은 실패 유형의 예제를 제공
  • 모델이 범하기 쉬운 특정 추론 함정에 대한 경고 역할

추가 분석

절제 연구: 실패 모드 기반 선택의 효과

실패 모드 기반 선택을 무작위 선택 및 의미적 검색과 비교

  • 무작위 선택보다 현저히 우수
  • 의미적 검색보다 일관되게 우수
  • 실패 모드 정보가 핵심 성능 기여 요인임 확인

타 도메인으로의 확장

수학 추론 외에 다른 도메인에서의 일반화 가능성 검증

  • 수학 외 도메인에서도 긍정적 전이 효과 관찰
  • 실패 모드 구조가 도메인에 걸쳐 보존되는 경향
  • 패밀리 간 전이(cross-family transfer)도 부분적으로 유효

CritBank는 한 번 구축하면 재사용 가능하며, 오프라인 구축 비용은 추론 시 지속적으로 상쇄됩니다.

결론

새로운 패러다임 제시

실패 모드를 부정적 결과가 아닌 구조화된 가이던스의 원천으로 활용하는 추론 시간 W2SG 프레임워크

효율성과 성능의 동시 달성

단일 생성으로 Best-of-N 수준의 성능을 토큰 비용 대폭 절감과 함께 달성

유연한 변형 제공

정밀도 우선의 CritICL-dynamic과 효율성 우선의 CritICL-static으로 상황에 맞는 선택 가능

광범위한 적용 가능성

수학 추론을 넘어 다른 도메인 및 모델 패밀리로의 확장 가능성 확인
