Cascaded 방식

ASR → 텍스트 LLM → TTS를 순차 연결

  • 모듈 간 정보 병목 발생
  • 지연시간 누적
  • 운율·감정 등 언어 외 신호 손실

SpeechLLM 방식

음성 토큰을 직접 입출력하는 LLM

  • 낮은 추론 지연시간
  • 간단한 배포
  • 화자 identity·prosody·감정 보존

하지만 SpeechLLM의 두 가지 난제

난제 1

추론 성능 열위

비슷한 규모·학습 데이터의 텍스트 LLM 대비
복잡한 추론 과제에서 성능이 크게 뒤처짐

난제 2

엄격한 실시간 제약

음성 에이전트 사용자는 거의 실시간인
응답을 기대함 — 긴 사고 시간을 허용하지 않음

CoT는 정확도를 높이지만 지연을 키우고 → 정확도-지연 트레이드오프 발생

기존 접근: 동시 추론과 남은 한계

Early Reasoning

사용자가 말하는 도중에 추론 시작 ("thinking while listening")

동시 생성

추론하면서 동시에 음성 출력 생성

지연은 줄었지만, 정확도-지연 Pareto 트레이드오프는 여전히 존재한다. 이 Pareto 경계선을 넘어서려면?

핵심 아이디어: 회고적 사고

인간은 복잡한 질문을 받으면 내적 추론 중에 실수를 해도, 대화 흐름 속에서 스스로 되돌아보고 실시간으로 수정한다.

  • 실시간 제약 속에서 SpeechLLM의 추론에 오류가 생기는 것은 불가피
  • 오류를 동적으로 식별하고 수정하면 정확도를 끌어올릴 수 있음
  • 이미 출력한 음성은 되돌리지 않는 forward-only 검증·수정 (숨겨진 CoT 스트림에서만)

기반 모델: Moshi

멀티스트림, 풀듀플렉스(full-duplex) SpeechLLM

User Audio

사용자 음성 스트림

System Text

내적 독백
(inner monologue) — CoT 주입 지점

System Audio

시스템 음성 출력 스트림

  • Mimi codec: 80ms 간격, 8 codebook으로 음성을 이산 토큰화
  • Temporal + Depth Transformer: 텍스트 다음 토큰 → 오디오 토큰 8개 예측
  • 텍스트 스트림에 CoT를 넣어도 음성 입출력 동기화가 깨지지 않는 유연성

사전 지식 ①: Early Reasoning & LengthDPO

표준 추론 vs 조기 추론

Standard Reasoning: 질문이 끝난 후 CoT 생성
Early Reasoning: 듣는 도중 추론 시작
→ QC(Question Completeness) 지표와 임계값 θ로 추론 시작 시점 제어

LengthDPO

Positive: 정확하고 간결한 CoT
Negative: 부정확하거나 장황한 CoT
→ 성능을 유지하며 지연시간 축소

RetroThinker는 이 두 기법과 상호보완적으로 결합 가능

사전 지식 ②: Retrospective Sampling (REVERSE)

Vision-Language Model의 환각 완화 기법에서 착안

1
캡션을 여러 세그먼트로 분할
2
규칙 + LLM 프롬프트로 오류 세그먼트를 합성해 정답 앞에 삽입
3
세그먼트 끝에 자기 검증 토큰 부착 (정확/부정확 표시)
4
학습 시 오류 세그먼트의 손실(loss)은 마스킹 — 잘못된 생성 패턴 학습 방지

단, REVERSE는 오류 발견 시 생성을 롤백하는 방식 → 실시간 음성에는 부적합

RetroThinker: 3단계 포스트트레이닝

1
규칙 기반 초기화
합성 오류를 삽입해 자기 검증·수정의 형식을 학습
2
실오류 정렬
외부 LLM judge로 Stage 1 모델의 실제 오류를 주석
3
LengthDPO
judge로 인한 분포 불일치 완화 + 불필요하게 긴 회고 압축
  • Standard / Early Reasoning 모두와 호환 가능
  • 음성 스트림은 그대로 유지, 오직 텍스트(CoT) 스트림만 수정

추론 시 동작 방식

사용자 음성을 들으며 CoT를 텍스트 스트림에 생성 (조기 추론 가능)
CoT 단계마다 자기 검증 — 오류 여부를 스스로 판단
오류 발견 시 되돌리지 않고 앞으로(forward) 수정된 추론을 이어감
수정된 결론에 따라 음성 응답 생성 — 사용자는 롤백을 인지하지 못함

숨겨진 텍스트 스트림에서의 검증·수정 = 지연 증가를 최소화하면서 정확도 향상

실험 설정

항목내용
기반 모델Moshi (멀티스트림 풀듀플렉스 SpeechLLM)
벤치마크TTS로 음성화된 GSM8K (다단계 수학 추론)
비교 대상회고 사고 없는 non-retrospective 베이스라인 (CoT + Early Reasoning)
평가 축정확도(accuracy) vs 응답 지연(latency)의 Pareto 곡선
변인회고 사고 유무, Early Reasoning, LengthDPO의 조합

주요 결과

+11%p

동일한 지연시간에서의
절대 정확도 향상

  • 정확도-지연 Pareto 경계선 전체를 개선
  • Early Reasoning + LengthDPO + 회고 사고의 3기법 결합이 최고 성능
  • 제어된 다단계 추론 환경에서 일관된 이득 확인

지연시간을 늘리지 않고도 더 정확한 실시간 음성 추론이 가능해졌다

심층 분석 포인트

규칙 기반 vs 샘플 기반

실제 모델 오류로 정렬한(Stage 2) 학습이 합성 오류만 사용한 초기화보다 효과적

정확도 병목 분석

추론 중 오류 발생 지점과 회고 사고가 이를 바로잡는 양상 분석

LengthDPO의 역할

외부 judge 주석의 분포 불일치를 완화하고 길고 장황한 회고 추론을 압축

추론 복잡도별 분석

문제 난이도에 따라 회고 사고의 이득이 달라지는 양상 확인

결론

  • 스트리밍 SpeechLLM에 회고적 사고 도입 — 생성된 음성을 롤백하지 않고 숨겨진 CoT를 검증·수정
  • 규칙 기반 초기화 → 샘플 기반 정렬 → LengthDPO로 이어지는 구체적인 포스트트레이닝 레시피 제시
  • GSM8K에서 동일 지연시간 대비 11%p 정확도 향상으로 정확도-지연 Pareto 경계 확장
