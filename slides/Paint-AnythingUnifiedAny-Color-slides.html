Paint-Anything

이미지 생성과 편집을 위한 통합 Any-Color 제어

24-bit hex 값 하나로 원하는 객체의 색상을 정확하게 지정하는 통합 프레임워크

Any-Color Control이란?

이미지 속 객체의 목표 색상을 24-bit hex 값(예: #E07A5F)으로 자유롭게 지정하고, 이를 생성과 편집 모두에 적용하는 능력

16,777,216

24-bit RGB가 표현할 수 있는 전체 색상 공간 — 프로페셔널 디자인이 요구하는 정밀한 색상 지정의 기준

기존 연구의 세 갈래 접근

색상 생성

텍스트 프롬프트와 함께 특정 색상의 객체를 새로 생성. 그러나 대부분 제한된 팔레트나 언어적 색상 이름에 의존

색상 편집

기존 이미지의 객체 색상을 변경. 그러나 별도의 편집 모델이나 복잡한 추론 과정이 필요한 경우가 많음

색상 채색

흑백 이미지나 선화에 색을 입힘. 채색 전용 파이프라인으로 구현되어 다른 태스크와의 통합이 어려움

왜 기존 방법으로는 부족한가?

  • 전용 색상 표현(dedicated color representation) 의존 — 특수 인코더·팔레트·추가 네트워크가 필요
  • 특화된 추론 과정(specialized inference) — 태스크마다 별도 파이프라인을 구성해야 함
  • 언어 기반 색상의 모호함 — "빨강"은 스펙트럼 전체를 가리킬 뿐, 정확한 hex 값을 보장하지 못함
  • 생성·편집·채색의 분절 — 동일한 색상 의도를 여러 도구로 반복 지정해야 하는 비효율

핵심 아이디어

색상은 태스크별 특수 표현이 아니라, 24-bit hex 값 그 자체로 통일할 수 있는 하나의 조건이다.

  • hex 값 → RGB 튜플 → 확산 모델의 조건 신호로 직접 주입
  • 별도의 색상 인코더나 특화 추론 과정 없이 단일 모델로 처리
  • 텍스트 프롬프트 + 대상 지정 + hex 값의 하나의 통합 인터페이스

색상 조건화 설계

Hex 값 인코딩

"#E07A5F" 같은 hex 문자열을 RGB 수치로 분해하고, 이를 모델이 이해할 수 있는 조건 신호로 변환. 전용 색상 표현 학습 없이 연속적인 24-bit 색상 공간 전체를 다룹니다.

대상 영역 지정

텍스트로 대상을 명시하거나 영역을 지정하여, 어느 객체에 색상을 적용할지 결정. 나머지 영역은 원본의 구도와 색감을 유지합니다.

핵심: 색상 정보와 위치 정보를 분리하되, 하나의 조건 인터페이스 안에서 함께 전달

하나의 모델, 세 가지 태스크

생성

Text-to-Image

"빨간 자동차"가 아니라 #C0392B 자동차 — 프롬프트와 hex 값을 함께 주어 원하는 색의 이미지를 처음부터 생성

편집

색상 변경

기존 이미지에서 특정 객체만 골라 목표 hex 색으로 교체. 질감·반사·조명의 자연스러움을 유지

채색

Colorization

흑백 이미지·선화에 각 객체별 hex 색상을 지정해 채색. 별도 채색 모델 없이 동일 인터페이스로 처리

평가: 무엇을 측정하는가?

  • 색상 정확도 — 대상 객체 영역의 실제 RGB 값이 지정된 hex 값과 얼마나 일치하는지 (RGB 오차)
  • 텍스트-이미지 정합성 — 색상 제약을 주었을 때도 프롬프트 내용이 온전히 반영되는지
  • 이미지 품질 — 색상을 강제로 주입하면서도 자연스러운 질감과 조명이 유지되는지
  • 비편집 영역 보존 — 편집 대상 외 영역이 원본과 얼마나 동일하게 남는지

활용 시나리오

브랜드 디자인

브랜드 컬러 가이드의 hex 값을 그대로 이미지에 적용. 마케팅 소재 제작 시 색상 일관성을 보장

제품 변형 목업

하나의 제품 사진에서 색상만 바꾼 변형들을 빠르게 생성. 이커머스 카탈로그 제작에 즉시 활용

캐릭터/아트 채색

선화·흑백 아트웍에 각 부위별 정확한 색상을 지정해 채색. 애니메이션·웹툰 파이프라인에 적합

디자인 반복 작업

클라이언트 피드백("조금 더 차분한 톤으로")에 hex 값 수정만으로 즉시 대응

한계와 향후 방향

복잡한 재질

반사·투명·발광 재질은 표면색과 관찰 색이 달라져 hex 정합도가 떨어질 수 있음

다중 객체 다색 제어

여러 객체에 서로 다른 색상을 동시에 지정할 때 객체 간 색상 간섭 관리가 과제

향후 방향: 재질 인식 색상 조건화, 다색·그라디언트 지정 확장, 실시간 편집 워크플로우 통합

결론

  • 24-bit hex 값을 조건으로 사용해 전용 색상 표현·특화 추론 없이 임의 색상 제어 달성
  • 생성·편집·채색을 하나의 통합 프레임워크로 처리하는 통일된 인터페이스 제시
  • 프로페셔널 디자인 워크플로우에 바로 적용 가능한 정밀 색상 제어 실현
