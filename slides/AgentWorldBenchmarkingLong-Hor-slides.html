왜 다중 에이전트 협업 평가인가?

  • LLM 에이전트가 단일 턴 추론에서 자율적 도구 사용 · 계획 · 다단계 실행으로 진화
  • 소프트웨어 개발, 과학 연구, 복잡한 운영 등 실제 과제는 여러 전문 에이전트의 조율이 필수
  • 자연어를 통한 정밀한 의사소통이 새로운 조율 방식을 가능하게 함
  • 현대 모델의 강점과 한계를 이해하려면 협업 역량의 체계적 평가가 필요
하지만 기존 벤치마크는 진정한 협업(collaboration) 능력을 분리해 평가하지 못하고 있음

기존 벤치마크의 3가지 한계

짧은 과제 수행 기간

대부분 10스텝 이하, 20스텝 미만의 단기 상호작용 → 지속적 조율 능력 평가 불가

행동 제어와 협업의 혼동

정밀 3D 내비게이션, 블록 배치 등 저수준 제어에 노력 소모 → 협업 능력이 점수에 반영되지 않음

측정 불가능한 대규모 시뮬레이션

기존 다중 에이전트 벤치마크(MindCraft, MineLand, MINDAGENT 등)는 20스텝 미만의 짧은 수행 기간 또는 비대칭 역할·블랙박스 상호작용의 부재

과제 설계: 8개 카테고리

전투 제작 채집 거래 탐험 생존 건설 협조
  • 각 에이전트는 고유한 스킬, 장비, 인벤토리, 스폰 위치를 가진 비대칭 역할
  • 모든 과제에 검증 스크립트(verifier) 포함 → 자동·객관적 성공 판정
  • 인간 전문가의 주석 + LLM 기반 과제 증강으로 확장
예시 — Task 86: Forge Vanguard
광부(채굴) → 제련사(주괴 제련) → 대장장이(검·도끼 제작)의 협업 파이프라인

평가 지표: SR과 CCE

Task Success Rate (SR)

기존 방식의 이진(binary) 과제 성공 여부 — 과제가 완수되었는지만 측정

CCE (Causal Collaboration Effectiveness)

에이전트 행동 간 인과 의존성을 추적하는 그래프 기반 지표 — 팀 노력 중 실제로 결과에 기여한 비율 측정

  • 행동 간 인과 관계 그래프 구축에만 LLM 활용 → LLM 단독 저지의 주관성 감소
  • 에이전트별 기여도(PAC, Per-Agent Contribution)도 함께 산출

CCE 산출 과정: 역방향 인과 추적

1
성공 행동 식별
LLM 저지가 과제 완수에 기여한 핵심 행동 도출
2
역방향 추적
라운드별로 선행 행동들의 인과 기여 검증
3
인과 행동 그래프
CAG(Causal Action Graph) 구축
4
CCE / PAC 계산
기여 집합 대비 전체 행동의 비율 산출
CCE = 결과에 인과적으로 기여한 행동의 비율 — "많이 행동했다"가 아니라 "의미 있게 협업했는가"를 측정

실험 설정 및 주요 결과

52.0%

최고 성능 모델(Gemini 3 Flash)의 과제 성공률

0.320

최고 모델의 CCE — 전체 행동의 1/3 미만만 실제 기여

  • 4개 프론티어 모델(Gemini 3 Flash, Claude Haiku 4.5, GPT-5 Mini, DeepSeek R1-70B) 평가
  • 최강 모델조차 과제의 절반 가까이 실패 — 장기 협업은 여전히 공통의 난제

핵심 발견

  • 통신이 많다고 협업이 좋아지지 않음 — 메시지량과 성공률은 비례하지 않음
  • 과제 난이도는 카테고리와 증강 여부에 따라 크게 달라짐
  • 대다수 에이전트 행동이 성공에 기여하지 않음 — CCE로 정량적으로 확인
  • CCE는 SR을 추적하면서도 더 세밀한 뉘앙스 제공
  • CCE는 인간의 인과 판단과 일치하며, 저지 모델 선택에도 강건

체계적 실패 모드 분석

통신 붕괴

에이전트가 핵심 정보를 공유하지 못해 팀 전체가 잘못된 방향으로 진행

역할 혼란

작업 중복 수행 또는 지정된 역할을 벗어난 행동으로 비효율 발생

공유 계획 상실

라운드가 진행되며 공유된 계획을 유지하지 못하고 조율이 붕괴

이는 개별 모델의 지능 문제가 아니라, 현재 기반 모델들에 공통적으로 나타나는 협업 능력의 격차

기여 및 결론

  • 장기 협업 벤치마크: 비대칭 역할의 3–20개 에이전트가 25–55라운드 동안 블랙박스 환경에서 협업하는 100개 작업
  • 협업 중심 평가 지표: 인과 행동 그래프 기반의 CCE — LLM 저지의 주관성 최소화
  • 실증적 발견: 최고 모델도 52.0% 성공, CCE 0.320 — 협업은 현재 모델의 공통적 약점
  • 완전한 오픈소스: 시뮬레이터, 과제 정의·검증기, 평가 스크립트, 주석 플랫폼 전체 공개
