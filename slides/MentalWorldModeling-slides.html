Mental World Modeling

물리적 세계를 넘어, 그 세계에서 행동하는 마음을 시뮬레이션하는 차세대 월드 모델

Hao Fei, Yiran Zhao

NUS · 2026년 7월

MOTIVATION

기존 월드 모델의 한계

"If the organism carries a 'small-scale model' of external reality and of its own possible actions within its head, it is able to try out various alternatives."

— Kenneth Craik, 1943

표현 월드 모델

잠재 상태 학습으로 예측과 제어 지원 (Dreamer, JEPA)

비디오 생성 모델

시간적 일관성을 갖는 미래 관측 합성 (Sora, Genie)

3D 인터랙티브 모델

공간 구조, 내비게이션, 편집 (Marble)

공통점: 모두 물리적 기질만 모델링 — 객체, 위치, 기하학, 운동, 접촉

PROBLEM

물리만으로는 부족하다

기존 모델이 묻는 질문

  • 무엇이 어디에 있는가?
  • 물리적으로 어떻게 변화할까?

인간 행동을 결정하는 것은?

  • 무엇을 믿고 있는가?
  • 무엇을 원하는가?
  • 무엇을 의도하는가?
  • 어떤 감정을 느끼는가?
  • 사회적으로 허용된다고 생각하는가?

서비스 로봇은 사용자가 혼란스러운지, 간접적으로 도움을 요청하는지 추론해야 한다.

의료 보조 시스템은 환자의 신념, 두려움, 신뢰를 고려해야 한다.

물리적으로 올바른 장면에서도, 정신 상태를 모르면 잘못된 행동을 예측한다.

FRAMEWORK

Mental World Modeling (MWM)

정신 변수를 사후 정당화가 아닌 월드 모델의 핵심 구성 요소로 만드는 범용 이론적 프레임워크

FORMULATION

MWM의 핵심 정형화

결합 세계 상태 s_t

  • 물리 상태: 객체, 위치, 관계, 사건
  • 정신 상태: 신념, 목표, 의도, 감정, 규범, 역할
  • 각 에이전트별로 개별 정신 상태 추적

관측 생성 함수

전체 상태에서 대상 에이전트가 실제로 인지할 수 있는 정보만 필터링하여 부분 관측 생성

행동 제안 함수

대상의 관측과 정신 상태로부터 물리적 행동과 정신적 행동(의도 형성, 감정 변화 등)을 분해하여 생성

상태 전이 함수

후보 행동이 물리 상태와 정신 상태를 동시에 어떻게 변화시키는지 시뮬레이션

APPLICATION DOMAINS

MWM이 필요한 영역

몰입형 협업

공동 진행은 물리적 + 정신적이다. 파트너의 이해도와 의도를 동시에 추적해야 한다.

돌봄, 지원, 자문

실패는 사실적 오류가 아닌 경우가 대부분이다. 환자의 두려움과 신뢰가 핵심이다.

교육과 훈련

개입은 학습자의 '다음 상태'를 겨냥한다. 오개념과 동기를 파악해야 한다.

인터랙티브 에이전트와 사회적 세계

지속적인 상호작용에는 정신 상태 전이 모델링이 필수적이다.

EXPERIMENT 1

필요성 사다리 (Necessity Ladder)

핵심 발견

  • 모든 단계에서 F1이 지속적으로 상승
  • 옵션 전용 바닥은 낮고 평평함
  • 더 많은 컴퓨팅을 줘도 직접 답변은 부족
  • 약한 기본 모델일수록 MWM의 이득이 더 큼

시사점

정신 상태 모델링은 단순한 스케일업으로 대체될 수 없다. 구조적 표현과 시뮬레이션이 본질적으로 필요하다.

EXPERIMENT 2

병목 지역화 (Bottleneck Localization)

오라클 대체 분석

MWM 파이프라인의 각 모듈을 골드 표준(oracle)으로 대체하며 어느 단계가 가장 큰 병목인지 식별

결과

1위

상태 전이 시뮬레이션이 가장 큰 단일 병목

  • 오라클 이득은 부가적이지 않음 (sub-additive)
  • 남은 갭의 대부분은 중간 단계에서 발생

병목 순위 (큰 → 작은)

1

전이 시뮬레이션 (물리+정신 상태 업데이트)

2

중간 단계 모듈들 (관측 생성, 행동 분해)

3

초기 상태 파싱

4

최종 가치 평가 및 의사결정

EXPERIMENT 3

시나리오 및 모달리티 분석

시나리오 연구

대인간 장면에서 이득 최대

다수 에이전트의 정신 상태를 동시에 추적해야 하는 상황에서 MWM의 효과가 가장 두드러짐

도메인 간 이득은 평탄

돌봄, 교육, 협업 등 도메인에 관계없이 일관된 개선을 보임 — 프레임워크의 범용성 입증

모달리티 분석

모달리티MWM 이득구조의 역할
텍스트기준선상태 구조화로 안정적
이미지유사구조가 모달리티 갭 해소
비디오유사오디오 채널도 활용 확인

채널 개입 실험(confirmed by channel interventions) 결과, 구조화된 상태 표현이 모달리티 차이를 상당 부분 극복함을 확인

KEY INSIGHTS

핵심 발견 요약

정신 상태는 선택이 아닌 필수

스케일업이나 프롬프트만으로는 대체 불가. 명시적 모델링이 본질적으로 필요함.

전이 시뮬레이션이 최대 병목

물리-정신 결합 전이를 더 정확하게 모델링하는 것이 가장 중요한 개선 방향.

약한 모델에 더 큰 이득

MWM 프레임워크는 강력한 모델의 한계를 넘어, 약한 모델의 성능을 끌어올리는 효과도 있음.

구조가 모달리티 갭 해소

텍스트-이미지-비디오 간 성능 차이를 구조화된 상태 표현이 상당히 줄여줌.

범용적 적용 가능성

돌봄, 교육, 협업 등 도메인에 구애받지 않고 일관된 개선 효과.

정신 상태 추론은 가설이지 측정이 아니다. 프레임워크는 이를 명시적으로 관리하고 검사 가능하게 만든다.

FUTURE DIRECTIONS

향후 방향

모델링 기계 확장

현재 학습 불필요 베이스라인에서 학습 기반 전이 모델로 발전. 신경 기호적 하이브리드 접근 탐색.

모델링 대상 확장

더 긴 시간 지평, 더 깊은 물리적 기반(grounding), 다수 에이전트 상호작용 확장.

안전은 부록이 아니다

정신 상태 모델링 자체가 조작, 프라이버시, 편향 등의 윤리적 문제를 내재. 안전을 핵심 설계 원칙으로.

"MWM은 월드 모델링의 다음 단계이다: 물리적 장면을 시뮬레이션하는 것에서, 그 장면에서 행동하는 마음을 시뮬레이션하는 것으로."
