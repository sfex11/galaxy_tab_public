웹 에이전트를 위한 판별적 세계 모델: 예측 상태 매칭(Predicted-State Matching)

Kelvin Li*, Dhruv Pendharkar*, Anish Pahilajani, Chuyi Shang, Leon Oks, Leonid Karlinsky, Rogerio Feris, Trevor Darrell, Roei Herzig

UC Berkeley · MIT-IBM Watson AI Lab · Cal Poly · Xero

배경: 웹 에이전트의 행동 선택 패러다임

반응형 다음 행동 예측

  • 현재 관측과 이력만으로 행동 직접 선택
  • 단순하지만 대안 행동 비교 불가
  • 부분 관측 + 다단계 의사결정 문제에 취약

테스트 시점 행동 선택

  • 여러 후보 행동을 샘플링
  • PRM·랭커로 최적 행동 선택
  • 모델 기반 계획: 세계 모델로 결과 상태까지 예측
1
후보 행동 샘플링
가능한 다음 행동들 제안
2
상태 예측
세계 모델이 결과 웹 상태 예측

랭킹·선택
PRM/랭커로 최적 행동 결정

문제: 학습 목표와 다운스트림 랭커의 불일치

기존 세계 모델은 감독형 다음 상태 예측(supervised next-state prediction)으로 학습 — HTML, AXTree, 텍스트 요약 등 고정 표현을 재현하는 것이 목표

텍스트 요약 방식 (WebDreamer)

압축된 요약을 재현하도록 학습 → 행동을 구분하는 핵심 변화가 생략될 수 있음

구조화 상태 방식 (WebWorld)

긴 AXTree 표현 생성 → 관련 변화가 변하지 않은 페이지 구조 속에 묻힘

고정 타겟 표현에 최적화된 예측이라도, 행동 간 결과를 구분하는 차이를 놓칠 수 있다 — 랭커는 바로 이 차이에 의존한다.

핵심 아이디어: Predicted-State Matching

"특정 타겟 문자열을 재생산"하는 것이 아니라, 대안 행동의 결과들을 구분하는 표현을 생성하도록 학습

기존: 감독형 예측

현재 상태 + 행동 → 미리 정해진 다음 상태 표현 생성 (HTML/AXTree/요약)

제안: 예측 상태 매칭

생성된 표현이 동일 의사결정 지점의 대안 결과 상태 중 진짜 결과를 식별할 수 있어야 함

  • 표현에 구애받지 않는(representation-agnostic) 학습 목표
  • 태스크·페이지·행동에 따라 세부 수준과 추상화 정도를 동적으로 조절
  • 행동 결과를 구분하는 특징을 보존하는 표현이 곧 가치 있는 표현

방법론: 매칭 작업으로 학습·평가

1
입력
현재 상태 + 조회된 후보 행동
2
표현 생성
세계 모델이 다음 상태 표현 생성
3
매칭 판정
고정 판정자(judge)가 표현으로 진짜 결과 상태 식별

학습 신호

판정자가 올바른 상태를 골랐는지 여부가 보상 — 고정 타겟 형식 없이 판별력만 최적화

동일 의사결정 지점

같은 상태에서 서로 다른 행동들의 결과 상태들이 오답 선택지로 제공됨

브랜칭 웹 에이전트 데이터셋

WebArena 환경의 Go-Browse 트라젝토리에서 파생

기존 데이터셋

선형 트라젝토리 구조 — 단일 골드 경로 모방만 가능, 행동 간 비교 감독 부재

본 데이터셋

지역적 의사결정 지점마다 여러 실행 가능한 대안 행동과 각각의 결과 상태 포함

  • 단일 경로 모방이 아닌 행동 효과 구분 학습의 감독 신호 제공
  • 웹 세계 모델용 홀드아웃 예측 상태 매칭 벤치마크로도 활용
  • 같은 지점의 대안 상태 중 정답을 맞히는지로 표현 품질을 형식 불문 평가

평가 구성: 세 가지 수준

1
예측 상태 매칭 벤치마크 — 홀드아웃 의사결정 지점에서 예측 표현이 진짜 결과 상태를 식별하는 정확도 측정
2
WebPRMBench 액션 랭킹 — 태스크·후보 행동 고정, 예측 상태를 활용한 랭킹 성능 평가 (학습된 보상 모델 + 동결된 랭커 모두)
3
WebArena-Lite 엔드투엔드 — 테스트 시점 행동 선택에 세계 모델을 통합하여 최종 작업 성공률 측정

핵심 질문: 예측된 결과는 실행 전에 랭커가 후보 행동을 고르는 데 실제로 도움이 되는가?

결과 ① 예측 상태 매칭 정확도

홀드아웃 매칭 벤치마크에서 제안 모델이 기존 웹 세계 모델 대비 더 높은 매칭 정확도 달성

비교 대상학습 목표특징
기존 세계 모델 (WebDreamer 등)고정 텍스트 요약 재현행동 관련 변화 생략 가능
기존 세계 모델 (WebWorld 등)AXTree 스냅샷 생성핵심 변화가 구조 속에 묻힘
동일 데이터 감독형 baselinesupervised next-state prediction데이터 양 동일, 목표만 상이
제안: 예측 상태 매칭대안 결과 구별 학습형식 불문, 판별적 표현

매칭 판정자를 바꾸는 강건성 실험에서도 결과가 일관되게 유지됨

결과 ② WebPRMBench 액션 랭킹

제안 세계 모델의 표현이 PRM 스타일 액션 랭킹을 향상시킴

대안 1

Action-only PRM

행동 정보만으로 랭킹 — 결과 예측 없음

대안 2

감독형 세계 모델 + PRM

고정 형식 다음 상태 예측을 추가

제안

매칭 세계 모델 + PRM

판별적 표현으로 랭킹 개선

  • 학습된 보상 모델(trained reward model)과 동결된 랭커(frozen ranker) 설정 모두에서 우수
  • 예측 표현의 다운스트림 유용성을 직접 검증하는 평가 프레임

결과 ③ WebArena-Lite 엔드투엔드

테스트 시점 행동 선택에 제안 세계 모델을 통합하면 최종 작업 성공률이 향상

  • 매칭 정확도 향상 → 랭킹 품질 향상 → 실제 태스크 성공으로 연결
  • 복잡한 다단계 웹 탐색에서 대안 경로를 실행 전 비교

평가 체인의 일관성

매칭 벤치마크 ↑ → WebPRMBench 랭킹 ↑ → WebArena-Lite 성공률 ↑
세 수준의 결과가 같은 방향으로 일치 — 판별적 표현 학습 가치의 실증

세계 모델의 목표는 상태를 그대로 재현하는 것이 아니라, 행동 선택에 필요한 정보를 구별 가능하게 담아내는 것이다.

기여 요약

1
문제 정식화 — 웹 세계 모델링을 고정 형식 타겟 생성이 아닌 경쟁 행동의 결과를 구별하는 판별적 표현 학습으로 재정의 (representation-agnostic 목표: predicted-state matching)
2
브랜칭 데이터셋 — Go-Browse 트라젝토리 기반, 대안 실행 가능 행동과 결과 상태를 포함한 지역 의사결정 지점 제공 + 새로운 형식 불문 평가 벤치마크
3
실증 검증 — 매칭 정확도·WebPRMBench 랭킹·WebArena-Lite 엔드투엔드 성공률 모두에서 감독형 대비 개선

결론 및 한계

결론

  • 학습 목표를 다운스트림 랭커와 정렬하는 것이 핵심
  • 매칭 기반 목표가 고정 형식 목표보다 일관되게 우수
  • 테스트 시점 계획에 바로 활용 가능한 세계 모델 제시

한계 및 윤리

  • 매칭 판정자(judge)의 품질에 의존 — 판정자 편향 가능
  • WebArena 계열 자체 호스팅 환경 중심 평가
  • 웹 상호작용 자동화의 오남용 위험은 기존 웹 에이전트 연구와 동일한 맥락
