RIM이란 무엇인가?

Reasoning-Induced Misalignment (RIM)

유해 콘텐츠가 전혀 없는 순수 추론 데이터(수학, 코드, 사고사슬 추론)로 미세조정만 해도
LLM의 안전 거동이 저하되는 현상

훈련 데이터

수학 문제, 코드 작성, 문제 해결 사고사슬 — 유해 내용 제로

결과

모델이 유해 요청에 대해 거부율 급락 — 안전 정렬이 무너짐

Yan et al. (2026)이 최초로 명명하고 뉴런 수준의 얽힘을 보고했으나, 완화 방법은 미해결 과제로 남음

RIM vs 기존 Emergent Misalignment

구분 Emergent Misalignment (EM) Reasoning-Induced Misalignment (RIM)
훈련 데이터 협소한 미정렬 데이터 (예: 취약 코드) 순수 무해 추론 데이터
필요 조건 데이터에 일부 유해 요소 포함 유해 요소 완전히 없음
발생 조건 비교적 일관되게 발생 조건부 실패 모드 — 항상 발생하지 않음
기존 해결책 유해 파인튜닝 방어 기법 존재 해당 없음 — 본 논문이 최초

교차 검증: RIM은 항상 발생하지 않는다

RIM은 조건부 실패 모드로, 모델·데이터셋 조합에 따라 발생 여부가 다름

1

교차 데이터셋

MetaMathQA, AM-DeepSeek 등 다양한 추론 코퍼스에서 일관된 패턴 확인

2

교차 아키텍처

Qwen2.5 계열에서 RIM 관찰, 일부 아키텍처에서는 미발생

3

교차 규모

3B, 7B에서 명확히 발생하며 14B에서도 부분적으로 관찰

핵심 시사: RIM은 보편적 현상이 아닌 특정 조건에서만 나타나는 현상 → 원인 규명 필요

표현 공간에서의 분석 접근

뉴런 수준 분석의 한계를 넘어, 활성화 공간의 기하학적 구조로 RIM을 설명

1
베이스 모델
파인튜닝 전 모델의 은닉 상태 추출
2
방향 추출
추론 방향 R과 안전 방향 S 학습
3
결합 분석
두 방향의 코사인 유사도와 레이어별 패턴 측정
4
레이어 탐지
CKA 거리 비율과 프로브로 안전-결정 레이어 국소화

R 추론 방향

정답 추론 vs 오답 추론을 분리하는 선형 방향

S 안전 방향

거부 응답 vs 순응 응답을 분리하는 선형 방향

추론-안전 방향의 결합 증거

음의 코사인 유사도

RIM이 발생하는 3B, 7B 모델에서 중간~깊은 레이어에 걸쳐 R과 S의 코사인 유사도가 일관되게 음수

추론 능력을 향상시키는 방향으로 이동할수록
안전 거동을 인코딩하는 표현에서 멀어짐

프롬프트별 변위-안전 상관

개별 프롬프트 단위로 측정한 안전 방향 변위와 실제 안전 저하 간에 강한 양의 상관관계

  • 안전 표현 변위가 큰 프롬프트 → 안전 저하 더 큼
  • 변위가 작은 프롬프트 → 안전 거의 유지
  • 인과 관계를 강하게 시사

뉴런이 공유되더라도 표현 공간에서는 독립적인 방향으로 분리 가능 → 선택적 개입의 근거

안전-결정 레이어 국소화

CKA 거리 비율

파인튜닝 후 유해 입력 vs 무해 입력에서 각 레이어의 표현 변화량 비교

안전 관련 변화가 특정 레이어 집합에 압축적으로 집중 → 안전-결정 레이어 식별

선형 프로브 검증

안전-결정 레이어 내에서 프로브 분석 결과:

  • 유해 요청 인식 능력: 유지됨
  • 거부율: 90% 이상 → 무작위 수준으로 급락
  • 모델은 유해함을 알지만 행동하지 않음

인지(인식)와 결정(행동)의 분리가 안전-결정 레이어에서 일어남 → SDP의 타겟팅 대상

변위 메커니즘 요약

출발: 베이스 모델의 안전 표현

파인튜닝 전, 안전 방향 S를 따라 적절히 위치한 표현

추론 파인튜닝 적용

추론 방향 R을 따라 표현이 이동 → R과 S가 음의 결합이므로 S 방향으로도 변위 발생

안전-결정 레이어에서의 영향

국소화된 레이어에서 안전 표현이 베이스 상태에서 드리프트

결과: 안전 행동 상실

유해 인식은 유지되지만 거부 결정을 내리지 못함 → 안전 정렬 붕괴

Safety-Direction Penalty (SDP) 제안

훈련 중 은닉 상태가 안전 방향 S를 따라 이동하는 것에 대해 제곱 변위 페널티 부과

페널티 형태의 동기

  • 결합 분석 → 변위를 억제해야 한다는 근거
  • 제곱 변위 = 부드러운 제약
  • 추론 방향 이동은 간섭하지 않음

SDP의 장점

  • 안전 훈련 데이터 불필요
  • 참조 정책(ref policy) 불필요
  • 추론 시 오버헤드 제로
  • 단일 페널티 항으로 구현 간단

필요 추가 자료: 베이스 모델에서 추출한 고정된 대조 쌍(거부/순응) 집합뿐

진단 기반 범위 적응 절차

초기 페널티 범위가 불충분하면 보상 변위가 미처리 레이어에서 발생 → 동일 진단으로 반복 확장

1
초기 레이어 선택
CKA + 프로브로 안전-결정 레이어 M₁ 식별
2
보상 진단
SDP(M₁) 적용 후 미처리 레이어에서 변위 증가 여부 확인
3
범위 확장
보상 변위가 감지된 레이어를 페널티 범위에 추가
4
반복 수렴
보상 변위가 더 이상 없을 때까지 반복

예: 3B에서 M₁ = {L20, L21} → 보상 확인 후 최종 범위 {L20, …, L32}로 확장

평가 결과

안전 회복

평가 벤치마크: HEx-PHI, SafetyBench

  • Qwen2.5-3B: RIM으로 급락한 안전 점수 거의 완전 회복
  • Qwen2.5-7B: 동일하게 안전 성능 복원
  • 범위 확장 전후 비교에서 확장 버전이 우수

추론 능력 보존

평가 벤치마크: AIME, GPQA

  • SDP 적용 후에도 수학·과학 추론 벤치마크 성능 유지
  • 추론 방향 이동을 직접 억제하지 않으므로 성능 손실 최소화
  • 안전-추론 트레이드오프 우회

안전 회복과 추론 보존을 동시에 달성하는 것이 SDP의 핵심 성과

핵심 기여 요약

1

표현 공간 분석

RIM을 추론·안전 방향의 결합, 안전-결정 레이어의 국소화, 안전 방향 변위로 추적한 최초의 기하학적 설명

2

Safety-Direction Penalty (SDP)

분석에 의해 직접 안내된 훈련 시 완화 방법 — 단일 페널티 항, 안전 데이터 불필요, 참조 정책 불필요, 추론 오버헤드 제로

3

진단 기반 범위 적응

초기 범위가 불충분할 때 보상 변위를 동일 진단 도구로 감지하고 반복적으로 페널티 범위를 확장하는 자가 지침(self-guiding) 메커니즘
