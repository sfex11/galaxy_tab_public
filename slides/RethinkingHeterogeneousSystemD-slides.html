Rethinking Heterogeneous System Disaggregation for Subquadratic Attention

SQD: 서브쿼드래틱 어텐션을 위한 이기종 시스템 디스애그리게이션의 재설계

프론티어 LLM은 서브쿼드래틱 어텐션으로 추론 메모리와 연산량을 줄이고 있습니다. 하지만 기존 시스템은 여전히 dense attention 중심으로 분산 배치를 결정합니다. SQD는 어텐션의 산술 강도와 메모리 풋프린트에 맞춰 디코드를 quadratic / subquadratic으로 분리하여, DRAM 기반 GPU와 SRAM-only ASIC 이기종 시스템에서 상당한 처리량·에너지 효율 향상을 달성합니다.

arXiv:2609.13134v1 · 2026년 9월

배경: 저지연 추론의 비용 문제

디코드의 구조적 비효율

  • 추론 비용이 훈련을 초과하는 가운데, 디코드는 높은 메모리 대역폭·낮은 처리량 요구로 시스템 활용률 저하
  • 연산 강도(arithmetic intensity)가 낮아 에너지당 토큰 수가 감소

대화형 서비스의 딜레마

  • 낮은 TPOT(토큰당 시간)를 위해 배치 크기를 줄이면 → 시스템 전체 처리량 감소
  • 사용자가 실시간 참여하는 지연 민감 워크로드에서 빠른 토큰의 비용이 크게 상승

빠른 토큰의 비용을 줄이는 것이 모든 사람이 프론티어 지능과 상호작용할 수 있게 하는 핵심입니다.

이기종 하드웨어 디스애그리게이션

LLM 추론의 각 단계를 특성에 맞는 하드웨어에 배치하는 접근법

DRAM 기반 GPU

  • 큰 메모리 용량 (KV 캐시 저장 가능)
  • 상대적으로 낮은 대역폭, 높은 처리량
  • Prefill 등 연산 집약 단계에 적합

SRAM-only ASIC

  • 작은 작업 셋(working set)만 상주 가능
  • 한 자릿수 높은 대역폭·에너지 효율
  • 메모리 바운드 연산에 이상적

기존 Attention-FFN 분리는 디코드가 dense attention이라 가정 → dense attention이 GPU에 남고, 활성화를 토큰당 레이어마다 2회씩 인터커넥트로 전송해야 합니다.

서브쿼드래틱 어텐션의 부상

Quadratic (밀집) 어텐션

FLOPs가 컨텍스트 길이에 따라 제곱으로 증가. 디코드 스텝마다 프리픽스와 함께 성장하는 상태(live state)를 읽음. 메모리 풋프린트는 선형 증가 → 긴 컨텍스트에서 추론이 어려워짐.

Subquadratic 어텐션

프리픽스가 아무리 길어도 디코드 스텝이 읽는 상태가 고정. 연산량과 메모리 요구량을 크게 절감하면서 프론티어급 정확도 유지.

Sparse Top-k 희소 어텐션
GLM-5.2, Nemotron 등 — 인덱서가 전체 KV를 훑고 top-k 선택

Linear 선형·순환 어텐션
Nemotron, Mamba 계열 — 고정 크기 상태

Sliding 슬라이딩 윈도우
Gemma-4 등 — 고정 길이 윈도우만 참조

핵심 관찰: 디코드 내부의 이질성

서브쿼드래틱 어텐션 LLM의 디코드는 하나의 단일 연산이 아니라 성격이 다른 두 스테이지의 혼합입니다.

Quadratic 스테이지

밀집 어텐션, top-k 선택(인덱싱)

  • 메모리 풋프린트가 컨텍스트 길이와 함께 성장
  • 전체 KV에 접근 필요 → 대용량 DRAM 필요

Subquadratic 스테이지

top-k 어텐션, 선형·슬라이딩 윈도우 어텐션, FFN

  • 연산 강도가 낮고 메모리 풋프린트가 정적
  • GPU에서도 메모리 바운드 → SRAM-only ASIC에 적합

프론티어 LLM에서 quadratic attention은 몇 레이어마다 한 번만 등장 → 활성화 이동 자체도 더 희소해집니다.

SQD: SubQuadratic Disaggregation

연산자 유형이 아니라 어텐션의 스케일링 특성 기준으로 디코드를 분리

DRAM 기반 GPU 풀

  • Prefill + Quadratic 디코드 어텐션 배치
  • 동일한 KV 캐시를 공유 → 복사 오버헤드 제거
  • 희소 어텐션 LLM: top-k 선택(selection) 도 이곳에서 수행

SRAM-only ASIC 풀

  • Subquadratic 디코드 어텐션 + FFN 배치
  • 정적 풋프린트 → 온칩 SRAM에 상주 가능
  • 메모리 바운드 연산을 고효율로 실행
1
활성화 전송 최소화 — 레이어 그룹당 토큰당 2회만 전송 (기존 attention-FFN 분리는 매 레이어마다 2회)
2
범용 적용 — sparse, linear, sliding-window 등 모든 서브쿼드래틱 변형에 동일 원리 적용

Top-k 희소 어텐션 캐싱 메커니즘

인터커넥트 횡단을 지연 인지적으로 은닉하는 설계

1

지역성 활용

공유 인덱서 레이어 간 top-k 선택의 지역성을 활용해 SRAM ASIC에서 높은 캐시 적중률 달성

2

캐시 크기 튜닝

인터커넥트 지연에 최적화된 캐시 크기 설정으로 오버헤드 최소화

3

미스 파이프라이닝

캐시 미스 전송을 파이프라인 처리하여 대부분의 레이어에서 통신 지연 완전 은닉

결과: GPU → ASIC으로 전송해야 하는 KV는 top-k 값뿐. 상대적으로 낮은 대역폭의 인터커넥트로도 충분합니다.

차세대 시스템을 위한 아키텍처 인사이트

SRAM 프로비저닝

온칩 SRAM은 LLM의 정적 풋프린트가 상주할 만큼만 있으면 됩니다. 그 이상의 용량은 효용이 없습니다 — 서브쿼드래틱 어텐션의 정적 특성이 직접적인 용량 상한을 제공합니다.

인터커넥트 설계

GPU–ASIC 패브릭은 높은 대역폭보다 낮은 최소 지연을 우선해야 합니다. 캐시 메커니즘이 전송량을 줄이므로, 남는 병목은 지연입니다.

서브쿼드래틱 어텐션 시대의 이기종 시스템은 "용량과 대역폭"이 아닌 "정적 풋프린트와 최소 지연"으로 설계 기준이 바뀝니다.

기여 요약

세분화된 디스애그리게이션 — 산술 강도와 메모리 풋프린트 기준으로 서브쿼드래틱 LLM 디코드를 분리: quadratic+prefill → GPU, subquadratic+FFN → SRAM ASIC
지연 인지 top-k 캐시 — 인덱서 지역성 활용, 미스 파이프라이닝으로 대부분 레이어의 통신 지연 완전 은닉
실측 에너지 효율 — 8×B200 프록시에서 전력 57%로 처리량 63–97% 유지, Tokens/J 31–56% 개선
고정 전력 모델링 — Rubin+LPX에서 1.2–1.5× 지연 개선, 최대 3.6× 처리량, 인터커넥트 프로비저닝 가이드 제시
