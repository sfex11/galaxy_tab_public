배경 및 동기

법률 실무자는 표현은 다르지만 사건이 유사한 판례를 해석·비교해야 합니다.

기존 접근의 한계

  • 어휘 매칭·임베딩 검색은 의미상 관련 구절만 반환
  • 결과는 대부분 비정형 텍스트
  • "누가, 누구에게, 무엇을, 언제, 왜"가 명시되지 않음

법률 서사에서 중요한 것

  • 참여자의 법적 역할
  • 사건 간 시간적·인과적 관계
  • 이 구조가 두 사건의 의미 있는 비교 가능성을 결정

ARGUS란 무엇인가?

소장 서사를 소스 근거 기반(source-grounded) 문서 수준 이벤트 지식 그래프(EKG)로 변환하는 파이프라인

데이터
CourtListener 연방 고용차별 소장

표현
이벤트 + 참여자, 법적 역할, 근거 문장, 시간·인과 관계

기법
5W1H 스키마 + 법률 도메인 모델 + LLM 구조화 생성

연구 질문

1
단계별 파이프라인이 신뢰할 수 있는 소스 근거 기반 법률 이벤트 그래프를 만들 수 있는가?
2
이 그래프가 텍스트 기반 표현 대비 법률 분류와 문서 범위 질의응답을 개선하는가?
3
그 이득이 외부 데이터셋과 오픈 검색(open-retrieval) 법률 QA 환경으로 확장되는가?

ARGUS 4단계 파이프라인

1
사실 문장 추출
이벤트성 진술만 선별 (LEGAL-BERT/LexLM + LLM)
2
의미적 청킹
서사 국면별 사건 시퀀스로 그룹화
3
2단계 미니그래프
5W1H 기반 개체·이벤트 → 시간·인과 간선
4
문서 수준 병합
결정적 규칙 + LLM 교차 청크 해소

각 구성요소를 개별 평가하여 사실 선별 → 이벤트·관계 추출 → 그래프 병합의 오류를 구분

1단계: 사실 문장 추출

"사실(fact)" = 구체적 행위, 의사소통, 결정, 결과를 기술하는 이벤트성 진술 (절차적·수사적 텍스트와 구분)

  • 미세조정된 LEGAL-BERT / LexLM 인코더로 문장별 Fact/Non-Fact 분류
  • 최대 softmax 확률 p(s) ≥ τ인 문장은 직접 유지
  • p(s) < τ인 애매한 문장은 LLM이 재판정
  • 최종 "사실"로 판정된 문장만 그래프 구성에 전달

2단계: 의미적 청킹

유지된 사실 문장을 [S1], [S2], … 식별자와 함께 입력으로 제공하고, LLM이 일관된 사건 시퀀스로 그룹화

청크 경계 기준

주제·시간·행위자의 변화와 연관된 지점에서 분할

제약 조건

하나의 사건을 여러 청크로 분할 금지 · 모든 문장 커버 필수 · 약 2~3문장의 오버랩 도입

이벤트 표현: 5W1H 기반 스키마

개체(Entity) 레코드

  • 식별자 · 이름 · 개체 종류
  • 정규화된 법적 역할 · 선택적 별칭

이벤트(Event) 레코드

  • 식별자 · 이벤트 유형 · 주동사 · 트리거
  • 참여자(이벤트별 역할) · 시간 정보 · 근거 문장 ID · 신뢰도
시간: before · after · overlap · same-time 인과: causes · enables · prevents

소스 텍스트가 뒷받침하는 관계만 유지 — 명시적/상대적/미상의 시간 정보 허용

3단계: 2단계 미니그래프 추출

Stage 1 — 개체·이벤트

근거 기반 개체와 이벤트만 추출하며, 시간·인과 간선 생성 금지

Stage 2 — 관계 추가

원문 청크 + Stage 1 JSON을 받아 소스가 뒷받침하는 시간·인과 관계만 추가

  • 두 단계 모두 엄격한 JSON · 문장 식별자 보존 · 미지원 개체/날짜/관계 금지
  • GEPA로 모델·프롬프트·재시도 설정 등 추출 구성 최적화
  • 스키마 유효성·참조 무결성·시간/인과 일관성 등 구조 검사 + 다면 LLM 심판 점수

4단계 병합 & 다단계 평가 프로토콜

청크 그래프를 결정적 규칙 + LLM 지원 교차 청크 해소로 문서 수준 EKG로 병합

1

사실 추출 평가
자동 지표

2

미니그래프 평가
사람 주석 + LLM 심판

3

병합 평가
다중 모델 교차 검증

어떤 단계에서 오류가 발생했는지 국지화할 수 있는 구성요소별(component-level) 평가 설계

결과 ①: 청구 유형 분류

표현 방식특징성능
원문 텍스트 (Raw)비정형 문서 전체기준선
선형화 그래프 (Linearized)EKG를 텍스트로 직렬화기준선 대비 일부 개선
그래프 구조 분류기 (GNN)이벤트·참여자 노드 + 참여/시간/인과 간선홀드아웃 세트에서 최고 성능

역할·시간·인과 구조를 보존한 그래프 표현이 법률 서사 이해에 실질적 이득 제공

결과 ②: 문서 범위 QA와 일반화

문서 범위 FAQ QA

EKG 기반 검색이 QA 정확도를 향상 — 증거의 구조적 조직화가 효과적

변호사 시험 QA (외부)

객관식 법률 QA로 일반화 검증 · 오픈 검색 실험 + 오라클 문서 분석 수행

오픈 검색에서의 이득은 1단계 후보 재현율(candidate recall)이 낮아 제한적 — EKG는 관련 자료가 검색된 이후 증거를 조직하고 추론할 때 가장 유용

기여 요약

  • 참여자·시간·인과 구조를 갖춘, 미국 고용차별 소장 대상 소스 근거 기반 역할 인식 EKG 파이프라인 제안
  • 사람 주석 + 자동 지표 + LLM 기반 평가를 결합한 법률 이벤트 그래프 다단계 평가 프로토콜 도입 (주석 공개 예정)
  • 그래프 구조 분류기가 원문·선형화 기준선을 능가하고, EKG 검색이 문서 범위 QA를 개선함을 실증 — 단, 오픈 검색에서는 1단계 재현율이 병목
