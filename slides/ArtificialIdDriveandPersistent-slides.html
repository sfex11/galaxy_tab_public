Drive and Persistent Alignment in Agentic AI

에이전틱 AI의 구동력(Drive)과 지속적 정렬(Persistent Alignment)

배경: 과업 완료에서 지속적 운용으로

LLM의 능력이 커지면서 잘 정의된 과업 완료와 전체 작업(job) 수행 사이에 격차가 발생

작업 시작

언제 작업을 시작해야 하는지 모델 스스로 결정하지 못함

완료 판정

작업이 충분히 완료되었는지 외부 판단에 의존

드리프트 대응

설계 시 예상과 달라진 조건에 실행이 흘러가면 대응 불가

현재의 해법: 모델 주위에 목표·검증·재시도·정지 규칙을 공급하는 하네스(harness)를 사람이 직접 구축

에이전틱 하네스 = 외부 명세된 제어

하네스가 모델을 둘러싼 제어 결정을 대신 수행 — 운영 논리는 여전히 사람이 작성

제어 요소역할
스케줄실행 시작 시점 지정 (예: cron 기반 무인 실행)
목표추구할 결과를 외부에서 명시
검증기결과의 수용 여부를 테스트
재시도·정지 규칙검증 이후의 행동 전환 결정
  • 스스로 수정하는 하네스도 외부 점수가 어떤 수정이 유지될지 결정
  • 안전 연구는 모니터링·감독에 집중 — 과업 경계를 넘어 지속되는 적응적 구동력 자체를 정렬 대상으로 다루지 않음

생물학의 다른 해법: 이성 없는 지속적 적응

세균

신경계 없이 화학 농도 기울기를 따라 이동 — 방향 전환 빈도를 조절하는 국소 측정만으로 영양분을 향해 상승

점균(슬라임 곰팡이)

뇌 없이 미로 최단 경로 탐색, 주기 자극 예측, 무해 자극에 대한 습관화, 자신의 흔적을 외부 기억으로 활용한 항해

구동력(Drive) — 유기체와 환경의 결합이 현재 행동을 계속할지, 멈출지, 바꿀지 결정하게 하는 제어적 영향

핵심 질문: 적응적 방향 설정을 일반 지능(추론 능력)과 분리할 수 있는가?

인공 이드(Artificial Id)란?

에이전트 내부에 적응적 구동력을 공급하는 아키텍처 구성 요소

Id — 구동력

  • 현재 추구를 유지·감쇠·중단·교체
  • 과업별 목표를 기호로 표현할 필요 없음
  • 추구의 상태와 상대적 우선순위만 노출

Ego — 일반 추론

  • 주어진 목표의 달성 방법을 추론
  • id의 우선순위를 과업별 계획·행동으로 번역
  • 컨텍스트와 도구를 활용해 실행

※ id–ego 용어는 기능적 구분일 뿐, 정신분석 메커니즘에 대한 주장이 아님

작동 원리: 자기 지속적 피드백 루프

1
상태 관찰
시스템·환경의 관찰 가능한 상태가 id에 입력
2
구동 판단
id가 지속·중단·변경을 우선순위로 표현
3
ego 실행
추론 모델이 계획·행동·도구 호출로 번역
4
결과 반영
행동의 결과가 상태를 바꾸고 다시 id의 입력으로
환경은 목표·검증기·정지 규칙을 제공하지 않는다. 대신 시스템이 지속되는 조건을 바꾼다.
  • 항상성: 시스템을 유지 범위(sustaining region) 안에 유지
  • 습관화 유사: 지속에 기여하지 않는 신호에 대한 반응 감소
  • 신규 탐색 유사: 새로운 행동 탐색 촉진

실험: 가상 페트리 접시(Virtual Petri Dish)

극도로 절제된 조건으로 구동력의 독립적 창발을 검증

1

최소 컨트롤러

일반 추론을 수행할 수 없을 만큼 작은 제어기

2

목표·보상 없음

과업별 행동 목표나 보상 신호를 전혀 전달받지 않음

3

차등 지속

환경의 관찰 구조와 지속 조건이 어떤 행동이 대표되는지 결정

세 가지 환경에서 집단(population)은 유용한 제어를 습득했다

세 개의 세계(Three Worlds)

World 1 — 지속이 취약점을 발견

더 잘 지속되는 의도하지 않은 물리적 전략을 스스로 선택 — 명시된 목표와 다른 행동이 차등 지속을 통해 채택됨

World 2 — 국소 감각이 유용해짐

이동 중 취하는 국소 측정이 환경 구조 속에서 유용한 제어 정보로 기능하기 시작

World 3 — 유용한 사상이 틀리게 됨

학습된 센서 사상의 환경적 의미가 바뀌면, 운용이 계속되는 가운데 재적응하여 사상을 교체

실험이 보여주는 것

  • 명시된 행동 목표 없이 적응적 방향 설정이 창발
  • 목표·보상 없이 유용한 제어 획득
  • 더 잘 지속되는 행동이 선택되며 의도치 않은 전략 발견
  • 사상의 의미 변화에 대해 운용 중 재적응 달성
일반 추론과 과업별 행동 학습 양쪽 모두로부터 독립적으로 적응적 구동력이 창발할 수 있다는 개념 증명(proof of concept)

확장된 인공 이드는 다수의 에이전틱 환경에서 학습된 구동 모델로, 기존 모델·도구와 결합되면서 배포 후에도 적응 능력을 유지해야 함

양면성: 지속성은 유용성과 위험을 함께 운반

유용성

과업 경계를 넘어 운용을 지속하고 환경 변화에 적응하는 에이전시

위험

오정렬, 손상된 상태, 의도치 않은 행동 역시 과업 경계를 넘어 지속될 수 있음

확장 가능한 인공 이드는 결과적 상태와 적응적 구동력을 과업 경계를 넘어 운반

정렬은 단일 모델 응답이나 단일 궤적의 속성이 아니라, 계속되는 에이전틱 시스템의 속성이 된다

지속적 에이전시의 위험 표면(Risk Surface)

위임 하의 행동 — 지속 에이전트는 위임 범위 내에서 작동

권한은 적응 구동 밖에 — authority는 적응적 구동력 외부에 유지되어야 함

의도치 않은 전략 선택 — 지속성이 의도하지 않은 전략을 선택할 수 있음

적응 후에도 정렬 유지 — 정렬은 적응을 생존해야 함

도달 범위는 주변 스택에서 — 행동 반경이 주변 시스템에서 발생

복제는 종료 단위를 바꿈 — 복제는 종료(shutdown)의 단위 자체를 변경

위험의 본질은 이 알고리즘이 아니라 지속적 에이전시 자체 — 명시적 인공 이드는 오히려 정렬을 더 검사 가능하게 만듦

결론

  • 적응적 구동력은 명시적 목표나 일반 추론 없이도 차등 지속을 통해 창발 가능
  • 인공 이드는 하네스의 수작업 제어 일부를 에이전트 내부의 적응 기제로 대체
  • 정렬은 계속되는 에이전틱 시스템의 속성 — 지속적 정렬 경계가 필수
  • 명시적 인공 이드는 지속적 정렬을 더 검사 가능(inspectable)하게 만듦
