배경: 의료 LLM의 맹점

  • 프리트레이닝 확장으로 의료 언어모델은 임상 질의응답·치료 조언에서 급속히 발전
  • 에이전트는 도구·메모리·환경 피드백을 결합해 다단계 작업을 수행
  • 그러나 지속적 개입을 통한 생리학적 제어 능력에 대한 체계적 정량 평가는 부재
  • 기존 평가는 응답 품질이나 정보 조작에 국한 → 실제 생리 궤적 자체를 평가해야 함
"언어모델이 생리를 제어할 수 있는가?"를 측정 가능한 형태로 만드는 것이 이 연구의 출발점

왜 1형 당뇨혈당 조절인가?

문제의 구조

인슐린 분비 손상 → 외부 인슐린에 대한 완전 의존. 식사·운동·질병·개인 상태에 따라 투여량을 끊임없이 조정해야 함

장기 호라이즌

인슐린은 수 시간 동안 작용이 지속 → 현재 결정이 과거 치료와 이후 사건들과 연쇄적으로 연결됨

개인차와 변동성

사람마다 다른 생리, 매일 달라지는 인슐린 필요량 → 지속적 상태 추론과 처치 조정이 필수

불완전한 관측

지연되고, 노이즈가 있고, 누락되는 혈당 측정 → 피드백 추적이 어려운 부분 관측 문제

Rule-based 폐루프(예: OpenAPS)는 자유 텍스트 맥락과 개인 기록을 사전 정의된 입력으로 매핑해야 하는 한계 존재

3대 기여

1

APC 프레임워크

인체 생리를 인터랙티브 환경으로 다루는 에이전트 제어 프레임워크. 모니터링 기기로 정보를 얻고, 의료기기로 약물을 투여하며, 피드백으로 결정을 조정

2

DiabetSim

개인 생리, 의료기기, 이벤트, 관측 조건을 통합한 설정 가능한 혈당 조절 시뮬레이터. 재현 가능한 가상 테스트 기반 제공

3

SweetBench

212개 혈당 조절 태스크 벤치마크. Claude Opus 5.5 기반 APC가 COGI 73.5 vs OpenAPS 71.2 달성

APC: 문제 정식화

치료를 제어 문제로 — 제어기는 에이전트, 센서와 액추에이터는 의료기기

xt+1 ~ Pθ(· | xt, at)   ·   ot ~ Od,ρ(· | xt)   ·   at ∈ 𝒜d(ht)
  • 숨겨진 상태 xt: 생리 + 기기 상태 + 맥락, 개인 파라미터 θ로 진화 → 부분 관측 마르코프 결정 과정(POMDP)
  • 기기 구성 d가 관측 모델과 행동 집합을 동시에 결정
  • 에이전트는 가시 이력 ht와 개인 기록 Mt를 유지 → 정책 π(at | ht, Mt)
  • 목표: maxπ 𝔼[S(m0:T)] — 단, 실제 생리 변수는 에이전트가 직접 관측 불가

APC 에이전트의 4대 구성요소

1
의사결정
개입·측정·대기를 선택하고 근거를 명시
2
디바이스 도구
작업을 실행하고 측정값·투여 로그를 반환
3
모니터링
대기 구간 종료 또는 조건 발생 시 제어를 에이전트에 반환
4
개인 기록
개인에 대해 학습한 내용을 이후 결정에 반영
해석 가능성

행동의 근거를 결정 규칙이나 명시적 논리로 추적 가능

정보 통합

혈당 측정 + 자연어·멀티모달 보고 + 개인 이력으로 숨겨진 상태 추론

롱테일 적응

맥락 보고를 활용해 희귀 상황에 대한 처치 조정

DiabetSim: 확장 가능한 가상 시험대

시뮬레이터 엔진

개인별 생리 파라미터 θ에 따른 혈당 동역학 시뮬레이션. 기존 동역학 모델과 평가 지표 체계에 기반

디바이스 모델

혈당 측정 기기와 인슐린 투여 기기 모델링. 지연·노이즈·바이어스 등 현실적 관측 조건 재현

인스턴스 생성

다양한 환자·이벤트·기기 조건을 조합해 대규모 가상 테스트와 학습 환경 구축

APC가 실제로 직면하는 상호작용 환경을 재구성하여 재현 가능한 가상 테스트의 기반을 제공

시나리오 그룹

  • 진짜 혈당 궤적은 에이전트에게 숨겨짐 — 채점은 에이전트가 볼 수 없는 실제 생리 변수로 수행
  • COGI(복합 혈당 조절 지표): 목표 범위 체류 시간, 고혈당·저혈당 발생을 종합 반영
  • 다양한 이벤트: 식사 계획 변경, 질병 회복, 기기 이상 등이 상호작용

Ablation: 무엇이 조절을 개선하는가

개인 경험의 효과

개인 기록 + 하루 마무리 복습(end-of-day review)이 가중치 업데이트 없이도 날 간 혈당 조절 개선을 지원

경험 축적만으로 교차 일자 개선 달성 — 파라미터 학습 없이 자기 적응

정보·결정 빈도의 효과

테스트된 사례에서 맥락 정보 추가가 에이전트 결정 빈도 증가보다 조절 개선에 더 효과적

에이전트 호출이 잦아질수록 계산 비용도 증가 → 빈도만 늘리는 전략은 비효율적

CL-on/off: 고빈도 규칙 기반 배경 혈당 조절 + 저빈도 에이전트 결정의 하이브리드로 성능-비용 균형의 잠재력 확인

케이스 스터디

미보고 혈당 급락 대응

환자가 보고하지 않은 혈당 하락 사건을 궤적 패턴에서 스스로 감지하고 투여를 조정

센서 바이어스에 가려진 저혈당

측정값이 정상처럼 보이는 센서 편향 상황에서 숨겨진 저혈당을 추론해 위험 회피

반복 투여 장애 추적

재발하는 인슐린 투여 오류를 개인 기록에 축적해 패턴으로 인식하고 추적

세 사례 모두 규칙 매핑으로 처리하기 어려운 자유 텍스트 맥락 + 관측 불확실성 + 개인 이력이 결합된 상황

논의: 한계와 향후 과제

불완전한 정보

지연·노이즈·누락된 관측 하에서 상태 추론과 위험 판단을 수행하는 구조적 어려움

안전성

의료기기를 직접 제어하는 만큼 오류 허용 범위가 매우 작음 — 엄격한 안전 보장 필요

Sim2Real 간극

가상 시뮬레이터의 결과가 실제 환자 환경으로 원활히 이전되어야 함 (Real2Sim2Real)

  • 향후 방향: 강화학습 기반 제어, Real2Sim2Real 전이, 1형 당뇨 이외의 생리 시스템으로 확장

결론

  • APC 프레임워크: 인체 생리를 인터랙티브 환경으로 보는 에이전트 제어의 첫 체계적 접근
  • DiabetSim + SweetBench: 재현 가능한 시뮬레이션과 212개 태스크 평가 기반 제공
  • APC가 COGI 73.5로 규칙 기반 폐루프(71.2)를 능가
  • 개인 기록·복습으로 가중치 없는 날 간 개선, 하이브리드 제어로 성능-비용 균형 가능성 제시
에이전트가 인간의 생리학적 제어에 참여하기 위한 프레임워크·시뮬레이터·평가 기반을 제공
