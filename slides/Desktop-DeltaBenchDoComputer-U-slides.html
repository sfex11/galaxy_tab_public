Desktop-Delta Bench

컴퓨터 사용 모델은
데스크톱 GUI 전환을 이해할 수 있는가?

Computer-Use Agents의 인과적 전환 재구성 능력 평가

연구 배경

컴퓨터 사용 에이전트의 부상

CUA(Computer-Use Agents)는 데스크톱 GUI를 통해 장기적(long-horizon) 작업을 수행하는 능력을 갖추고 있습니다. 클릭, 타이핑, 스크롤 등의 행동을 통해 GUI와 상호작용합니다.

기존 벤치마크의 한계

현재 벤치마크는 최종 작업 성공 여부나 단일 프레임 정밀도만 측정합니다. 행동이 초래하는 인과적 전환을 이해하는지는 격리해서 평가하지 못합니다.

핵심 질문

"모델이 특정 행동(action) 후에 발생하는 인과적이고 작업 관련적인 GUI 전환을 정확히 재구성할 수 있는가?"

단순히 "어디를 클릭해야 하는가"가 아니라,
"이 클릭이 화면을 어떻게 변화시키는가"를 이해하는지 평가해야 합니다.

기존 접근 방식의 문제점

1
최종 성공 측정
작업 완수 여부만 확인
→ 어느 단계에서 실패했는지 불명확
2
단일 프레임 정밀도
하나의 스크린샷에서 요소 탐지
→ 행동-전환 인과관계 무시
3
격리 불가
전환 이해 능력을 분리 측정 불가
→ 본질적 능력 평가 부재

Desktop-Delta Bench 제안

GUI 전환 이해를 직접적이고 격리된 방식으로 평가하는 새로운 벤치마크입니다.

Δ

Delta (변화량) 중심

행동 전후의 화면 차이를
정확히 예측하도록 설계

작업 관련성 필터링

무관한 시각적 변화가 아닌
인과적 변화만 평가

통제된 실험 환경

변수를 격리하여
순수 전환 이해력 측정

벤치마크 구성 방식

1

스크린샷 쌍 구성

행동 실행 전(Before)과 후(After)의 데스크톱 스크린샷을 페어로 제공

2

행동 설명 제공

수행된 특정 행동(예: "파일 메뉴 클릭", "텍스트 입력")을 자연어로 명시

3

전환 예측 요구

모델이 어떤 시각적 변화가 발생했는지를 정확히 설명하도록 요청

4

정답과 비교 평가

실제 발생한 작업 관련 변화와 모델 예측을 정량적으로 비교

평가 차원

미시적 전환 (Micro)

  • 버튼 색상 변화 감지
  • 텍스트 내용 변경 인식
  • 팝업/토스트 메시지 출현
  • 포커스 상태 변화

거시적 전환 (Macro)

  • 창/패널 열림 및 닫힘
  • 페이지 네비게이션 전환
  • 레이아웃 구조 변화
  • 다이얼로그 모달 표시

왜 전환 이해가 중요한가

계획 수립(Planning)의 전제 조건

다음 행동을 결정하려면, 이전 행동이 어떤 결과를 낳았는지 파악해야 합니다. 전환 이해 없이는 맹목적 시행착오에 갇힙니다.

오류 복구(Error Recovery)의 핵심

예상과 다른 결과가 나타났을 때, 어떤 변화가 발생했는지 정확히 인식해야 적절히 대응할 수 있습니다.

일반화(Generalization)의 지표

새로운 애플리케이션에서도 행동-전환 인과관계를 이해한다면, 진정한 GUI 이해를 달성한 것입니다.

주요 발견 사항

핵심 발견 1

전환 이해가 취약함

최신 CUA 모델들조차 행동에 의한 GUI 전환을 정확히 재구성하는 데 상당한 어려움을 보입니다. 단순 지시 수행과 전환 이해는 별개 능력입니다.

핵심 발견 2

미시적 변화에서 특히 취약

큰 레이아웃 변화보다 작은 시각적 변화(색상, 텍스트, 포커스 등)를 감지하는 데 더 큰 어려움을 보입니다.

핵심 발견 3

기존 지표와 상관관계 낮음

전환 이해 점수는 기존 벤치마크 성능과 뚜렷한 상관관계를 보이지 않아 독립적 평가의 필요성을 강하게 시사합니다.

핵심 발견 4

무관 변화의 혼란

시스템 알림, 시계 변경 등 작업과 무관한 변화에 쉽게 주의가 분산되어 관련 변화를 놓치는 경향이 있습니다.

모델별 비교 개요

모델 유형 거시적 전환 미시적 전환 무관 변화 필터링
전용 CUA 모델 중간 수준 취약 부분적
일반 VLM 기반 중간 수준 취약 취약
GUI 전문 미세조정 모델 양호 중간 수준 중간 수준

※ 모든 모델 유형에서 미시적 전환 이해가 가장 큰 병목으로 확인됨

시사점 및 방향성

훈련 데이터 개선

단순한 (스크린샷, 행동) 쌍을 넘어, (스크린샷, 행동, 전환 결과) 트리플렛을 활용한 학습 필요

멀티스케일 변화 감지

거시적+미시적 변화를 모두 포착하는 계층적 변화 감지 아키텍처 연구 필요

관련성 판별 능력

작업과 무관한 시각적 변화를 자동으로 필터링하여 핵심 전환에 집중하는 메커니즘 필요

새로운 평가 패러다임

전환 이해를 표준 평가 차원으로 채택하여 CUA 발전 방향 제시

결론

Desktop-Delta Bench는 컴퓨터 사용 에이전트가 행동의 결과로 발생하는 GUI 전환을 인과적으로 이해하는 능력을 최초로 격리하여 평가한 벤치마크입니다.

  • 기존 벤치마크가 놓치고 있던 전환 이해력이라는 핵심 능력을 조명
  • 최신 모델들이 미시적 전환과 무관 변화 필터링에서 현저한 취약성을 보임
  • 전환 이해 점수는 기존 지표와 독립적이어서 보완적 평가 도구로 활용 가치
  • CUA의 진정한 GUI 이해를 위한 새로운 연구 방향을 제시
