Hierarchical World Models
with Implicit Dynamics

ID-WM: 암시적 동역학을 통한 계층적 월드 모델 플래닝

Gaoyue Zhou · Yvonne Wu · Zichen Jeff Cui · Nicolas Ballas · Mido Assran · Lerrel Pinto · Yann LeCun

NYU Courant Institute · Meta-FAIR · AMI Labs

id-wm.github.io

월드 모델 기반 플래닝이란?

환경의 동역학을 예측 모델로 학습하여, 행동 공간에서의 탐색을 통해 테스트 시점에 새로운 행동을 합성

직접 정책 학습 vs

특정 작업에 과적합되기 쉬움, 일반화 한계

월드 모델 플래닝

테스트 시 적응 가능, 보지 못한 목표에 대한 제로샷 일반화

하지만 장기(long-horizon) 과제에서는 누적 오차와 탐색 복잡도가 발목을 잡습니다.

두 가지 근본적 한계

1

탐색 복잡도의 폭발

플래닝 지평(plan horizon)이 길어질수록 행동 공간 탐색 비용이 지수적으로 증가

2

예측 오차 누적

긴 롤아웃(rollout)에서 월드 모델의 예측 오차가 복합적으로 누적되어 계획 붕괴

  • 그 결과 대부분의 WM 플래너는 짧은 지평 과제에만 국한
  • 단순화된 행동 추상화(action abstraction)나 언어 공간 사용 시 세밀한 제어 상실

기존 계층적 방법의 한계

경직된 매크로 행동

프레임 스킵 기반 거친 추상화, 유연성 부족

잠재 스킬 의존

사전 학습된 스킬·저수준 정책 필요, 취약한 표현

가치 함수 의존

서브골프 실현 가능성 검증에 보상·가치 함수 필수

"웜홀(Wormhole)" 문제: 이런 제약 없이 강력한 옵티마이저를 돌리면, 학습된 월드 모델의 결함을 악용해 비현실적인 상태 전이를 발견해버림

핵심 아이디어: 도달 가능성과 제어의 분리

ID-WM은 상태 공간의 도달 가능성(reachability)을 국소 제어(local control)로부터 분리합니다.

"어디로 갈 것인가"

고수준 모델이 상태 다양체(manifold) 위에서 실현 가능한 이웃 상태를 샘플링 → 도달 가능한 서브골 도출

"거기에 어떻게 갈 것인가"

저수준 월드 모델이 역동역학 솔버로 동작해 서브골을 정밀한 실행 가능 행동으로 변환

플래너는 저수준 실행 세부사항에 구애받지 않고 도달 가능한 서브골만 탐색

고수준: 암시적 동역학 모델

이웃 상태 생성기 (Neighboring State Generator)

  • 확산(diffusion) 기반 월드 모델 — 동역학을 명시적으로 모델링하지 않음
  • 현재 상태에서 고정 거리 Δ 떨어진 상태만 출력 → 상태 다양체 위의 실현 가능한 전이
  • 단위 가우시안 잠재 공간을 실현 가능한 이웃 상태들의 다양체로 매핑

핵심 통찰: 확산 노이즈를 암시적 고수준 행동으로 취급 → 복잡하고 불연속적인 스킬 공간 대신, 구조적으로 잘 행동화된(well-behaved) 분포 위에서 탐색

저수준: 역동역학 솔버

Inverse Dynamics Solver

  • 결정론적(deterministic) 월드 모델 — 현재 상태와 목표 상태에 조건화
  • 서브골 사이를 연결하는 정밀한 실행 가능 행동 시퀀스 복원
  • 스킬 사전(skill prior)이나 사전 학습 정책 불필요

ID-WM 계층적 플래닝

두 단계가 교차(interleaved)하며 진행되는 플래닝 과정

A
고수준 플래닝
노이즈 공간에서 CEM 탐색으로 Δ 간격의 서브골 시퀀스 발견
B
저수준 제어
역동역학 솔버로 각 서브골 사이의 실행 행동 추출
C
실행 & 반복
도달한 상태에서 다시 고수준 플래닝 수행

탐색 공간 축소: 긴 행동 시퀀스 대신 소수의 서브골만 탐색

오차 누적 완화: 짧은 구간 단위 예측으로 복합 오차 방지

왜 잘 동작하는가?

국소 물리적 실현 가능성 우선

전역 행동 패턴 대신 짧은 구간의 물리적 타당성에 집중 → 학습에서 본 행동 모드를 넘어선 새로운 장기 계획 합성

잘 조건화된 탐색 공간

HWM류의 매크로 행동과 달리, 매끄러운 가우시안 노이즈 공간에서 탐색 → 웜홀 악용 원천 차단

  • 작업별 가치 함수 · 사전 학습 정책 · 보상 함수 모두 불필요
  • 태스크 불가지론적(task-agnostic) 월드 모델로 보지 못한 목표에 대한 제로샷 장기 플래닝 달성
  • 학습 데이터의 행동 모드를 재조합하는 방식의 일반화

실험 결과

내비게이션 + 조작(manipulation) 3개 환경 스위트에서 평가

+38.5%

SOTA 대비 성능 향상

계층적 오프라인 RL · 모방학습 · 확산 플래너 (HIQL, Diffuser, H-Diffuser 등)

+135%

단일 계층 WM MPC 대비

특히 보지 못한 복잡한 구성의 장기 과제에서 극적인 성능 향상

  • 임의의 목표 도달(arbitrary goal reaching)에서 강력한 베이스라인 대비 우위
  • 픽셀 기반 비전 플래닝으로도 확장 가능
  • 과제 복잡도가 증가해도 성능 견고하게 유지

방법론 비교 요약

접근법 탐색 공간 사전 지식 요구 장기 과제
단일 계층 WM + MPC 원시 행동 없음 오차 누적 심각
계층적 RL / 모방학습 스킬 · 옵션 가치함수·정책 필요 분포 외 일반화 약함
확산 플래너 (H-Diffuser 등) 전체 궤적 고정 지평 학습 고정 지평에 한정
ID-WM (본 논문) 확산 노이즈 (잘 행동화됨) 불필요 제로샷 장기 플래닝

계층 구조가 복합 오차를 완화하여, 학습에서 본 적 없는 복잡한 장기 구성에서 특히 강함

기여 및 결론

  • ID-WM 제안: 도달 가능성과 제어를 분리하는 계층적 월드 모델 — 작업별 가치 함수·사전 학습 정책 불필요
  • 계층적 플래닝 알고리즘: 고수준 추상화와 국소 동역학을 연결하여 견고한 장기 의사결정 실현
  • 실증 검증: 3개 내비게이션·조작 환경에서 SOTA 대비 38.5%, 단일 계층 WM 대비 135% 향상

"국소적 물리적 실현 가능성을 전역 행동 패턴보다 우선시함으로써, 학습된 행동 모드를 초월하는 새로운 장기 계획을 합성할 수 있다"
