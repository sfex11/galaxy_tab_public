월드 모델에게 '지속 학습'이 중요한 이유

  • 월드 모델의 바람직한 특성: 과제에 걸쳐 지속적으로 학습하며, 이미 학습한 것을 잊지 않고 새로운 환경에 적응하는 능력
  • 이전 경험에서 얻은 지식을 보존하고 재사용하는 것이 에이전트의 효율적 적응의 기반
  • 학습된 동역학 모델은 과제에 걸쳐 지속되는 구성 요소이므로, 월드 모델이 자연스러운 해법
"물리 세계의 동역학은 종종 소수의 재사용 가능한 메커니즘으로 설명할 수 있다"

문제: 뒤섞인 '적응' 측정

기존 로봇 조작 지속 학습 벤치마크(Continual World, LIBERO 등)의 적응 지표는 두 능력을 하나로 혼재시킴

학습 능력

미지의 과제를 학습하는 속도와 용량

재사용 능력

이미 습득한 지식을 재활용하는 능력

새 과제는 미지의 내용 + 반복되는 내용을 함께 담고 도착하기 때문에, 재사용을 분리하지 않으면 무엇이 실제로 개선된 것인지 알 수 없음

핵심 기여

구성적 지속 학습 벤치마크

각 과제 시퀀스가 이전 기본 과제들의 재조합으로 끝나며, 행동·지각 축으로 분해되어 재사용 실패 지점을 국소화

월드 모델의 원칙적 분리

과제 무관 backbone(지속 학습 대상)과 과제별 head(불필요)를 구분하고, 전자에만 지속 학습 방법 적용

최신 월드 모델 평가

단일(monolithic) 월드 모델 + 표준 지속 학습 방법과, 명시적으로 재사용 가능한 구성 요소를 가진 모듈형 월드 모델 비교

벤치마크 구조: 기본 과제 → 구성 과제

각 커리큘럼은 원시 조작 과제 시퀀스로 시작해, 이들을 재조합한 구성 과제로 마무리

A·B·C의 재조합

순방향 전이 = 구성 과제에서의 지식 재사용 측정

역방향 유지 = 시퀀스 전체에 걸친 망각 방지 측정

구성(composition)의 세 축

월드 모델의 두 입력, 즉 행동과 지각을 따라 구성을 분해 → 어떤 입력 모달리티가 재사용의 병목인지 규명

행동 구성

이전 과제에서 본 행동(스킬) 요소들을 재조합한 과제

지각 구성

이전 과제에서 본 관측(객체·장면) 요소들을 재조합한 과제

전체 구성

행동과 지각 요소를 모두 재조합한 과제

문제 설정

  • T개 과제가 순차적으로 도착하는 커리큘럼, 각 과제는 부분 관측 MDP 𝒯 = (𝒮, 𝒜, 𝒪, p, r, γ)
  • 관측 공간 𝒪과 연속 행동 공간 𝒜는 모든 과제에서 공유
  • 목표: 지금까지 마주한 모든 과제에서 기대 할인 수익 최대화 — 단, 상호작용은 현재 과제 환경에서만 가능
  • 월드 모델 𝒲 = (θ, φt): 과제 무관 매개변수 θ(재사용 가능한 동역학) + 과제별 매개변수 φt

월드 모델의 분리와 지속 학습 변형

과제 무관 Backbone (θ)

지각을 잠재 z로 압축하고 잠재의 진화를 예측 — 재사용 가능한 메커니즘을 포착하는 부분으로, 지속 학습의 대상

과제별 Head (φt)

과제별 출력을 담당 — 과제마다 갱신되며 지속 학습 불필요

단일형
단일 네트워크 동역학 모델

모듈형
전문가 혼합(MoE) 동역학 backbone + 라우터

실험 결과 ① — 기준 성능 비교

  • DreamerV3가 TD-MPC2를 능가 — 구성적 지속 학습 설정에서 더 강건한 성능
  • 기존 지속 학습 방법들은 순방향 전이(재사용) ↔ 역방향 전이(망각 방지) 사이의 상충을 보임
  • 구성 축을 따라 난이도 상승 — 행동·지각 구성보다 전체 구성이 가장 어려움
어떤 기존 방법도 재사용과 망각 방지를 동시에 달성하지 못함

실험 결과 ② — 명시적 모듈성의 효과

프론티어 확장

모듈형 월드 모델(MoE backbone)이 재사용-망각 프론티어를 더 앞으로 밀어냄

더 나은 균형

모듈성이 기존 지속 학습 방법보다 재사용과 망각의 균형을 더 잘 유지

그러나 어떤 방법도 문제를 완전히 해결하지 못함 — 잊지 않으면서 재사용하도록 설계된 지속형 월드 모델의 명확한 개선 여지가 남아 있음

모듈형 월드 모델 심층 분석: 재사용 탐구

  • 라우터 가중치가 여러 커리큘럼에서 과제 수준의 재사용 구조를 회복 — 유사 과제끼리 유사한 전문가 조합 사용
  • 과제 수준 라우팅은 시간적 구성(순차적 스킬 결합)을 제한할 수 있음
  • 구성 과제 학습 이후에도 전문가 수준의 선호가 보존됨
  • 전문가 소거(ablation) 실험로 이전 전문가들의 기능적 재사용이 실제로 일어남을 확인

결론

1

구성 과제로 끝나는 커리큘럼을 통해 지식 재사용을 망각·학습 속도와 분리하여 측정하는 벤치마크를 제안

2

행동·지각 축으로의 분해로 재사용이 어디서 성공하고 실패하는지 국소화

3

명시적 모듈성이 기존 지속 학습 방법보다 재사용-망각 균형에 유리하지만, 완전한 해결은 미완

"재사용하면서 망각하지 않는" 지속형 월드 모델을 향한 명확한 연구 방향 제시
