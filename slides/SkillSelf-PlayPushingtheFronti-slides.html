Skill Self-Play —

기존 방법들은 과제 다양성과 검증 신뢰성 사이에서 근본적 trade-off에 직면해 있다.

핵심 아이디어

스킬을 기본 학습 단위로 삼고, 스킬 간 공진화를 통해 다양성과 검증 신뢰성을 동시에 달성한다.

1

스킬 단위 분해

복잡한 능력을 독립적 스킬로 구조화

2

공진화 메커니즘

스킬끼리 서로 과제를 출제하고 검증

3

자기 플레이 루프

경쟁적 과제 생성으로 지속적 성장

스킬의 정의와 구조

스킬이란?

특정 유형의 과제를 생성하고 해결하는 능력을 캡슐화한 자기 포함적 단위

  • 과제 생성자(Task Generator)
  • 과제 해결자(Task Solver)
  • 응답 검증자(Response Verifier)

스킬 계층

원시 스킬 (Primitive Skills)

기본 추론, 요약, 번역 등

복합 스킬 (Composite Skills)

다중 스킬 조합으로 복잡한 과제 해결

Skill Self-Play 메커니즘

스킬 A가 과제를 출제하면 스킬 B가 해결하고, 스킬 A가 검증한다.

1
과제 생성
스킬 A가 자신의 도메인에서 과제 생성
2
과제 해결
스킬 B가 생성된 과제에 응답
3
교차 검증
스킬 A가 스킬 B의 응답을 평가
4
업데이트
검증 결과로 양쪽 스킬 동시 개선

교차 검증은 자기 검증의 오류 문제를 해결하고, 다른 스킬과의 상호작용이 과제 다양성을 보장한다.

공진화 과정

생성자 진화

해결자가 너무 쉽게 풀면 → 더 어려운 과제 생성

해결자가 틀리면 → 적절한 난이도로 조정

적대적 과제 난이도 조절 (Curriculum)

해결자 진화

어려운 과제에 도전하며 능력 확장

다양한 스킬에서 출제된 과제로 일반화 향상

지속적인 능력 경계 확장

이 공진화 루프는 Red Queen 효과처럼 양쪽을 동시에 끌어올린다.

전체 학습 파이프라인

1
스킬 초기화
시드 스킬 세트 정의 및 초기화
2
Self-Play 라운드
스킬 쌍 간 과제 생성→해결→검증
3
품질 필터링
신뢰도 임계값 기반 데이터 선별
4
모델 업데이트
선별된 데이터로 SFT 또는 RL
5
스킬 확장
새로운 스킬 발견 및 통합

단계 2~5를 반복하며 모델과 스킬 세트가 함께 진화한다.

검증 신뢰성 보장 방안

교차 스킬 검증

자기 검증이 아닌 다른 스킬이 검증하여 편향 완화

합의 기반 필터링

다중 스킬의 검증 합치도로 신뢰도 점수 산출

난이도 적응

검증 신뢰도가 높은 난이도 수준으로 자동 조절

환경 없이도 환경 수준의 검증 정확도를 달성하면서 개방 도메인의 다양성을 유지한다.

핵심 발견과 인사이트

발견 1 공진화의 힘

단일 스킬 자기 플레이보다 다중 스킬 공진화가 훨씬 더 빠르고 높은 성능 향상을 달성

발견 2 스킬 emergence

초기에 정의하지 않은 새로운 스킬이 학습 과정에서 자발적으로 출현

발견 3 검증 품질의 중요성

학습 데이터 품질은 생성량보다 중요하며, 엄격한 필터링이 핵심

발견 4 스케일링 법칙

스킬 수와 Self-Play 라운드에 대해 예측 가능한 스케일링 관계 확인

한계점과 향후 방향

현재 한계

  • 초기 스킬 시드 품질에 의존
  • 계산 비용이 여전히 상당함
  • 검증 오류가 완전히 제거되지는 않음
  • 안전성 보장 메커니즘 필요

향후 연구 방향

  • 에이전트 시스템과의 통합
  • 안전성 제약이 내장된 진화
