자기훈련(RFT)도 마찬가지 — 그러나 반복 샘플은 의미 있게 다를 때(functional diversity)만 가치를 발휘합니다.

문제: IID 샘플링의 다양성 붕괴

  • IID 샘플은 대부분 동일 전략의 표면적 변형 — 모델은 단일 접근법에 확률을 집중
  • 샘플링 예산이 커져도 추가 샘플의 가치는 급격히 감소
  • 모델의 능력 경계 근처에서 실패가 특히 심각

RL에서의 실패

롤아웃 그룹이 동일한 보상을 받아 그래디언트가 0

Test-time Scaling에서의 실패

거의 동일한 후보 모집단 — 결합할 것이 없음

포스트 훈련이 이런 붕괴를 조장하며, IID 샘플링 + 정확성 필터 중심의 표준 자기훈련도 분포를 더 집중시킵니다.

핵심 아이디어: 전략적 다양성 (Strategic Diversity)

문제를 푸는 접근법(approach)의 실질적 변화 — 합리적 결정 공간을 의미 있게 커버하는 것

전략적 다양성

서로 다른 알고리즘 · 계획 · 설계 선택 — 표면이 아닌 접근 방식의 차이

어휘적 다양성과의 차이

단어·표현만 다른 변형은 해당하지 않음 — 정확성과도 직교(틀려도 가치 있음)

  • IID 자기훈련은 모델이 이미 선호하는 전략만 과잉 대표·강화
  • 전략적으로 샘플링된 데이터는 파인튜닝된 모델에 다양성을 보존

Groot: 계층적 전략 트리 샘플링

  • 모델이 문제에 대한 접근법 결정 트리를 직접 구성
  • 알고리즘 → 자료구조 → 구현 등 계층적 의사결정 반영
  • 서로 다른 n개의 루트-리프 경로 선택
  • 각 경로를 히든 인스트럭션으로 주입해 솔루션 생성

왜 트리 구조인가?

경쟁 프로그래밍의 접근 공간은 알고리즘·자료구조·구현 선택으로 이루어진 자연스러운 트리 구조

이름(Groot)도 트리 구조에서 착안

Verbalized Sampling (VS): 확률화된 접근법 제안

  • 모델이 여러 접근법과 추정 확률을 함께 예측 (예: p=0.6, 0.2, 0.1, 0.1)
  • 트리 없이 비구조화된 접근법 집합을 직접 생성
  • 각 접근법을 히든 인스트럭션으로 전달하여 완전한 응답 생성
  • 계층이 뚜렷하지 않은 공간(예: NCP의 상호의존적 서사 결정)에 적합
두 방법 모두 동일한 샘플링 예산에서 학생 모델 자신의 접근 공간 개념만 활용 — 외부 교사나 추가 데이터 불필요
