행동 클로닝(BC) 사전 학습

  • 인간 시범 주행 데이터로 센서 → 궤적 매핑을 학습
  • 개방 루프(open-loop) 목적함수
  • 시범자가 방문한 상태에서만 감독 가능

폐쇄 루프 배포 시 문제

배포 시에는 정책의 자신의 행동이 미래 상태를 결정

오차 누적(compounding errors) → 데이터 분포 밖의 상태 도달 → 안전 필수(safety-critical) 사고 위험 증가

사전 학습 데이터 확장만으로는 수확 체감 — 이제 자율주행을 포함한 물리 AI에서 포스트 트레이닝이 핵심 과제

핵심 아이디어: 탐색과 감독의 분리

폐쇄 루프 포스트 트레이닝의 두 비용 — 샘플 비효율적 탐색과 샘플 효율적 감독 — 은 서로 다른 시뮬레이터에서 분리하여 부담할 수 있다

특권 교사 (Privileged Teacher)

  • 벡터화 입력(HD-map 폴리라인, 바운딩 박스)으로 RL 학습
  • 렌더링 불필요 시뮬레이터 → 대규모 탐색 가능
  • 증류용 데이터에 맞춘 추가 RL 학습 후 동결

엔드투엔드 학생 (Student)

  • RGB 카메라 기반으로 BC 사전 학습 완료
  • 실제 로그의 뉴럴 재구성에서 폐쇄 루프 롤아웃
  • 방문한 상태마다 교사가 감독(target) 제공

교사-학생을 별도 시뮬레이터에 두면 독립적·비쌍립적(unpaired) 데이터로 각각 사전 학습 가능 → 확장성과 범용성 향상

OPTED 파이프라인: 3단계 반복

1
폐쇄 루프 롤아웃
학생이 렌더링 시뮬레이터에서 주행 — 프레임 입력 → 궤적 예측 → 컨트롤러가 행동으로 변환하여 환경 전진
2
교사 레이블링
방문 상태를 벡터화 시뮬레이터로 동기화 → 동결된 교사를 K 스텝 롤아웃 → 학생 좌표계의 목표 궤적 생성
3
온폴리시 증류
최근 롤아웃의 유한 FIFO 버퍼로 학생 학습 — 모방 손실로 교사의 행동을 모방

렌더링 상호작용은 엔드투엔드 모델에만 집중

RL 탐색은 렌더링 불필요 시뮬레이터에만 confinement — 렌더링으로는 불가능한 규모

표현 불일치 해소: 교사는 행동, 학생은 궤적

출력 불일치 문제

최신 RL 정책 → 행동(action) 출력

엔드투엔드 정책 → 웨이포인트 궤적 예측

OPTED: 학생의 상태에서 교사를 롤아웃하고, 결과 모션을 학생 프레임의 목표 궤적으로 변환

아키텍처 제약 없음

학생의 출력 표현에 맞춰 증류 손실을 적응

  • 행동 헤드 → KL 발산 손실
  • 웨이포인트 헤드 → 가중 L1 손실
대규모 벡터화 RL의 폐쇄 루프 역량 + 기존 엔드투엔드 모델의 인간 데이터 사전(prior)

실험 설정

시뮬레이터 & 데이터

  • AlpaSim — 센서 기반 폐쇄 루프 시뮬레이터
  • 실제 주행 로그의 뉴럴 재구성(3DGS)으로 렌더링

학생 모델 (공개 모델 2종)

  • TransFuser (LTFv6) — 카메라 기반 엔드투엔드
  • VaVAM — VLM 기반 이기종 아키텍처

Driving Score 폐쇄 루프 씬 점수 개방 루프 변위 오차 AlpaSim Challenge

교사는 동일한 벡터화 상태 공간에서 학습되며, 두 시뮬레이터 간 상태 동기화로 온폴리시 레이블링이 수행됨

샘플 효율성: 직접 RL 대비 약 1000배 절약

10³×

직접 RL 포스트 트레이닝과 동등한 폐쇄 루프 성능을 약 3자릿수 적은 시뮬레이터 상호작용으로 달성

인간 사전 보존

RL 파인튜닝보다 인간 운전 사전(prior)에 더 가까이 유지

개방 루프 인간 주행 동의도(agreement)가 더 높게 유지되며, 폐쇄 루프 SFT 대비해서도 우수한 성능

교사의 RL 탐색은 렌더링이 필요 없는 벡터화 상태에서 수행되므로, 값비싼 렌더링 상호작용이 탐색 비용에 묶이지 않는다

통제 실험: 수렴 가능한 설정에서의 검증

실험 설정

  • PufferDrive + WOMD (벡터화 정책)
  • RL 파인튜닝을 수렴까지 실행할 수 있는 통제 환경
  • 교사 설계, 출력 표현, 컨트롤러 분석 가능

핵심 발견

  • OPTED가 RL 파인튜닝의 폐쇄 루프 성능과 일치
  • 필요한 폐쇄 루프 에피소드는 ~10³배 적음
  • RL 파인튜닝보다 인간 사전에 더 가까움

교사를 학생의 시뮬레이터와 분리 학습해도 전이가 잘 된다는 것이 정량적으로 확인됨

기여 요약

1
일반적인 폐쇄 루프 포스트 트레이닝 프레임워크 — 렌더링 불필요 RL 교사가 시각 입력 학생의 롤아웃을 감독. 학생의 아키텍처와 출력 표현에 어떠한 제약도 없음
2
실제 공개 모델에서 실증 — AlpaSim의 3DGS 재구성에서 TransFuser 1.6×, VaVAM 9.5× 씬 점수 향상
3
효율성 정량 분석 — 직접 RL 대비 약 1000배 적은 폐쇄 루프 상호작용으로 동등한 성능, 인간 사전 보존

결론

RL 탐색은 렌더링 불필요 시뮬레이터에, 렌더링 비용은 학생 롤아웃에만 — 두 시뮬레이터의 동기화로 엔드투엔드 주행의 폐쇄 루프 포스트 트레이닝을 실용화했다
  • 센서 기반 정책의 RL 포스트 트레이닝 병목(렌더링 비용)을 구조적으로 해결
  • 교사-학생 분리로 독립적인 데이터 수집·사전 학습 가능 → 확장성과 적용 범위 확대
  • 대규모 RL의 폐쇄 루프 역량과 기존 엔드투엔드 모델의 인간 데이터 사전을 결합
  • 폐쇄 루프 성능 향상과 함께 인간 주행과의 동의도 유지 — 안전성과 신뢰성의 균형
