TTPO: Test-Time Policy Optimization

정답 레이블 없이 테스트 시간에 수학 추론 능력을 자가 향상하는 비대칭 학습 목표

Aozhe Wang, Zhengxi Lu, Jianze Wang, Shangke Lv, Ying Liu, Weiming Lu, Jun Xiao, Yueting Zhuang, Hua Yang, Qianglong Chen, Yongliang Shen

浙江大学 · 阿里巴巴集团

문제 정의: 레이블 없는 테스트 시간 학습

기존 후속 학습

  • RLVR: 검증 가능한 보상 기반 강화학습
  • OPSD: 정답 조건부 자가 증류
  • 둘 다 정답 레이블 필수

테스트 시간 학습(TTT)의 한계

  • 정답이 도달하지 않음
  • 보상도, 교사도 구성 불가
  • 기존 방법 전면 적용 불가

"결과 보상은 하나의 스칼라만 제공하고, OPSD 교사는 정답을 필요로 한다. 레이블 없는 TTT 환경에서는 두 신호 모두 직접 사용할 수 없다."

자연스러운 대안과 그 한계

다수결 투표 의사레이블 (Majority-Vote Pseudo-Label)

각 문제에 대해 K개 궤적을 샘플링 → 다수결로 의사레이블 â 획득

TTRL (RL 접근)

의사레이블을 보상으로 사용 → 다수결이 틀리면 오류 강화

의사레이블 OPSD

의사레이블로 교사 구성 → 틀린 정답이 모든 토큰을 오도

~85%

경쟁 수준 문제에서 의사레이블 오류율

밀집 감독은 레이블 오류를 증폭시킨다

핵심 관찰: 왜 비대칭적인가?

핵심 발견

의사레이블이 틀려도, 의사레이블에 동의하지 않는 궤적의 약 79%는 진짜로 틀린 궤적이다.

불일치 페널티 → 안전

"이 궤적은 다수결과 다르다"는 판단만 사용. 의사레이블의 실제 답을 참조하지 않으므로 레이블 오류에 강건.

의사레이블 증류 → 취약

틀린 답이 교사 컨텍스트에 직접 주입되어 모든 토큰의 로그 확률을 왜곡. 밀집 감독이 오류를 증폭.

노이즈 레이블에서의 부정 학습(Negative Learning)과 동일한 원리: "이것이 무엇이 아닌지"는 레이블이 틀려도 신뢰할 수 있다. (Kim et al., 2019)

TTPO 전체 구조

1
다수결 투표
K개 궤적 샘플링 후 다수결로 â 결정
2
라우팅 분리
동의(양성) / 불일치(음성) 궤적 분할
3
비대칭 학습
OPSD + GRPO 병렬 적용
4
토큰 선택
각 분기에서 토큰 단위 정제

OPSD 분기 (양성 샘플)

â 조건 교사 → 학생 토큰별 Forward KL

이미 수렴한 위치는 가중치 축소

GRPO 분기 (음성 샘플)

그룹 내 어드밴티지 기반 페널티

자신감 높은 오류 토큰만 선택적 마스킹

OPSD 분기: 양성 샘플의 증류

다수결에 동의한 궤적 yk ∈ P에 대해, â를 컨텍스트로 준 교사와 학생 간의 Forward KL 최소화

LOPSD = Σt wt · DFKL(πteacher(·|x,â,y<t) ∥ πθ(·|x,y<t))

토큰 가중치 wt 설계

학생 엔트로피

낮은 엔트로피 → 이미 수렴 → 가중치 감소

교사-학생 발산

낮은 발산 → 이미 학습됨 → 가중치 감소

효과

아직 못한 위치에 집중

의사레이블이 틀려도: 교사는 동의 궤적이 스스로 생성한 답으로 조건화되므로, 모델의 사고 모드를 비사고 모드로 증류하는 방향으로 작동.

GRPO 분기: 음성 샘플의 페널티

다수결에 불일치한 궤적 yk ∈ N에 대해, 그룹 내 어드밴티지를 활용한 정책 경사 페널티

LGRPO = -Σk∈N Σt mt · (rk - mean(r)) / std(r) · log πθ(yk,t|x,y<t)

토큰 마스킹 mt 설계

보호 대상

높은 확률 + 높은 엔트로피 → 불확실하나 올바른 토큰 → 마스킹하여 페널티 면제

페널티 대상

높은 확률 + 낮은 엔트로피 → 자신감 높은 오류 → 선택적으로 페널티 부여

불일치 여부만으로 페널티를 부여하므로, 의사레이블이 틀려도 페널티 방향은 대부분 올바름.

통합 목표 함수

LTTPO = LOPSD(P) + λ · LGRPO(N)

P: 다수결 동의 궤적 집합 (양성)  |  N: 불일치 궤적 집합 (음성)  |  λ: RL 가중치

설계 철학 요약

신호를 신뢰 가능한 곳에만 적용

증류는 동의 궤적에만, 페널티는 불일치 궤적에만

토큰 단위 정제로 효율 극대화

수렴 위치 감소, 자신감 높은 오류만 타겟

다수결 라우팅의 자가 보정

모델 개선 → 투표 품질 향상 → 더 나은 학습 순환

정답 라우팅 불가능한 자가 진화

GT 기반 라우팅은 모델 능력 초과 시 붕괴

제거 연구: 각 구성요소의 기여

토큰 단위 선택의 효과

  • OPSD 분기: 토큰 가중치 제거 시 성능 하락
  • GRPO 분기: 토큰 마스킹 제거 시 올바른 토큰 오페널티로 성능 급락
  • 전체 토큰의 ~10%만으로 거의 동등한 성능

업데이트 전략 비교

  • OPSD만: 양성 샘플만 활용, 페널티 없음
  • GRPO만: 음성 페널티만, 밀집 감독 부재
  • 비대칭 결합(TTPO): 두 신호의 상보적 이점 극대화

RL 가중치 λ에 따른 민감도

λ=0.1 부근에서 최적. λ가 너무 크면 RL의 노이즈가 지배하고, 너무 작으면 음성 샘플의 페널티 신호가 약화됨. Ktrain은 양성/음성 비율에 따라 자동 결정.

분석: 범용성과 지속적 자가 진화

교차 작업 일반화

한 벤치마크로 TTT 학습 후 다른 벤치마크 평가

  • AIME 학습 → HMMT/BRUMO 향상
  • HMMT 학습 → AIME/BRUMO 향상
  • 문제 특화 과적합이 아닌 추론 능력 자체 향상

지속적 자가 진화

다수결 라우팅 vs 정답 라우팅의 장기 거동

  • GT 라우팅: 모델이 GT 수준을 초과하면 라우팅 붕괴
  • 투표 라우팅: 모델 능력에 자동 보정 → 선순환 구조

특권 정보 분석

레이블이 주어진 상한선(정답 OPSD)과 TTPO 간의 격차는 모델 스케일이 커질수록 축소. 8B에서는 TTPO가 오히려 정답 OPSD를 상회하는 결과도 관찰.

결론 및 한계

핵심 기여

1

의사레이블 오류율 ~85% 환경에서도 불일치 궤적의 ~79%가 진짜 오류임을 발견하고, 이 비대칭성을 학습에 활용

2

TTPO: 동의 궤적은 OPSD 증류, 불일치 궤적은 GRPO 페널티, 양쪽에 토큰 단위 선택 적용

3

레이블 없이 정답 감독 OPSD에 필적하며, 교차 작업 일반화와 지속적 자가 진화 입증

한계 및 향후 과제

  • 다수결 품질에 대한 의존성: 난이도가 극단적으로 높은 문제에서는 투표 신뢰도 저하
  • 도메인 범위: 수학 추론 외 영역(코딩, 논리 등)으로의 확장 필요
  • 동적 학습 커리큘럼: 문제 난이도에 따른 적응적 샘플링 전략
