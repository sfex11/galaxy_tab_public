Diffusion LLM 추론 가속

Flash-dLLM

IO-Aware KV Caching and Parallel Decoding
for Fast, Memory-Efficient Diffusion LLMs

Quan Nguyen-Tri · Mukul Ranjan · Zhiqiang Shen

VILA Lab, MBZUAI

arXiv: 2609.26796

배경: Diffusion LLM (dLLM)의 부상

비자기회귀 생성

dLLM은 텍스트 생성을 반복적 디노이징(denoising) 과정으로 재정의하여, 왼쪽→오른쪽 순차 생성이 아닌 마스킹된 시퀀스를 여러 단계에 걸쳐 정제

알고리즘적 장점

유연한 생성 스케줄, 전역 시퀀스 정제, 제어 가능한 생성, 향상된 병렬성 등 자기회귀 LLM과 차별화된 잠재력

그러나 현실적인 문제: 오픈소스 dLLM의 실제 추론 효율은 수년간 KV 캐싱·어텐션 커널·스페큘러티브 디코딩으로 최적화된 자기회귀 LLM 시스템에 크게 뒤처져 있음

문제: KV 캐시 I/O 병목

  • 디노이징 반복마다 KV 상태가 반복적으로 생성·이동되어 빈번한 캐시 읽기/쓰기/갱신 발생
  • 변경되지 않은 캐시 상태까지 매번 다루어 불필요한 메모리 트래픽 유발
  • 순진한 KV 캐싱은 연산량(FLOPs)은 줄이지만, 오히려 GPU 메모리 접근 오버헤드를 증가시킴
  • 기존 가속 기법들은 KV 캐싱과 병렬 디코딩을 따로따로 연구하여 공동 적용 시의 I/O 병목을 간과

핵심 발견: KV 캐시 읽기·쓰기의 중복이 런타임을 지배하며, 캐시 재사용으로부터 얻을 수 있는 실질적 속도 향상을 제한

세 가지 핵심 관찰 (LLaDA-1.5)

1.37×

I/O 병목

컨벤셔널 캐시 파이프라인은 메모리 바운드 연산이 지배 → 융합 커널로 중간 materialization 제거 시 1.37× 속도 향상

~50%

어텐션 희소성

중간 레이어에서 상위 32개 주목 토큰이 전체 어텐션의 절반 차지 → 전체 재계산 대신 선택적 추적이 효과적

양의 상관

신뢰도 동학

평균 예측 신뢰도가 높을수록 조기 디코딩 가능 토큰 수 증가 → 신뢰도 향상이 단계당 디코딩 토큰 수를 직접 증대

Flash-dLLM 개요

학습 불필요(training-free) 추론 가속 프레임워크 — IO 인지 KV 캐싱과 캐시 기반 병렬 디코딩을 통합 최적화

1
Flash-Cache
I/O 인지 융합 커널로 불필요한 메모리 이동 최소화, 캐시 지역성 향상
2
선택적 추적
토큰 희소성 활용 — 현재 디코딩에 영향 큰 토큰에 집중
3
Flash-Verify
KV 캐시 기반 초안-검증으로 신뢰도를 높여 병렬 커밋

디퓨전 언어 생성의 본래 병렬성을 실질적인 wall-clock 가속과 메모리 확장성으로 전환

Flash-Cache: I/O 인지 융합 KV 캐시 커널

  • KV 캐싱의 어텐션 연산과 캐시 갱신을 하나의 융합 커널(fused kernel)로 처리
  • 중간 결과물의 메모리 materialization을 제거하여 중복 메모리 이동 감소
  • 반복 디노이징 중 캐시 지역성(cache locality) 개선 → 메모리 바운드 구간 단축

기존 파이프라인

캐시 읽기 → 중간 저장 → 어텐션 → 쓰기가 분리되어 메모리 왕복 반복

융합 커널

단일 패스로 처리, 캐시 파이프라인에서 1.37× 속도 향상 달성

Scheduled Flash Attention

각 스텝에서 고정 크기 쿼리 βm개 토큰만이 전체 KV 캐시에 양방향 어텐션 수행

쿼리 구성

  • 직전 스텝에 디코딩된 토큰 (𝒟t)
  • 슬라이딩 마스크 윈도우 (βm개)

추적 토큰 선정

어텐션 중요도 상위 k개 디코딩 토큰을 매 스텝 재선정하여, 캐시 기반 표현이 전체 재계산과 정렬되도록 유지

관찰 ②에 기반 — 소수의 영향력 있는 토큰만 선택적으로 추적하여 메모리 대역폭 낭비 제거

Flash-Verify: 초안-검증 병렬 디코딩 (1/2)

보조 모델 없이 dLLM 자신이 drafter이자 verifier 역할 — 완전한 학습 불필요

1
초안 생성
캐시된 KV 상태를 활용해 후보 토큰들의 신뢰도를 향상시키며 다수 토큰 초안 작성
2
신뢰도 정렬
초안 예측을 신뢰도 기준으로 정렬
3
즉시 확정
임계값 ε를 넘는 토큰은 추가 검증 없이 바로 디코딩

관찰 ③ 활용: 캐시 재사용으로 후보 토큰의 신뢰도를 높이면 스텝당 정확히 디코딩되는 토큰 수가 증가 → 총 디노이징 스텝 수 감소

Flash-Verify: 이중 뷰 검증 (2/2)

토큰 복제

남은 검색 토큰을 쿼리에 두 번 복제 — 초안 예측 버전과 [MASK] 버전

인과적 어텐션 마스크로 두 뷰가 서로를 참조하지 못하도록 차단

수용 조건

  • 두 뷰의 예측이 일치
  • 마스크 뷰 신뢰도 > γ
  • 왼쪽→오른쪽 순서로 수용

유계 편차 보장(bounded-deviation guarantee) 제공 — 품질 저하 없이 안전한 병렬 커밋

실험 결과

수학적 추론(GSM8K) 및 코드 생성(HumanEval) 벤치마크, 최강 기존 기법 Elastic-Cache 대비

기여 요약 및 결론

I/O 병목 규명

KV 캐시 활성화 dLLM 추론에서 중복 읽기/쓰기 메모리 접근이 핵심 병목임을 규명하고 I/O 인지 융합 캐시 기법 제안

자기 초안-검증

보조 모델·추가 학습 없이 dLLM이 drafter와 verifier를 겸하는 학습 불필요 병렬 디코딩 전략 제안

실증적 성능

수학 추론·코드 생성에서 속도와 메모리 효율을 동시에 개선하며 생성 품질 유지

핵심 메시지: I/O 인지 캐싱과 캐시 기반 병렬 검증의 통합 설계만이 dLLM의 이론적 병렬성을 실제 가속으로 전환할 수 있다
