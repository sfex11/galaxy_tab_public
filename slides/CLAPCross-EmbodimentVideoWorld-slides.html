CLAP: Cross-Embodiment Video World Models are Zero-Shot Physical Simulators

다양한 로봇 및 인간 비디오 데이터로 학습하여, 범용 물리 법칙을 습득하고 제로샷 실세계 일반화를 달성하는 교차 구현체 비디오 월드 모델 프레임워크

Kechen Liu, Ola Shorinwa (Equal Contribution)

문제 정의: 단일 구현체의 한계

최신 액션 조건부 비디오 모델은 단일 로봇 구현체에 국한되어, 인터넷 규모의 이질적 비디오 데이터를 활용할 수 없습니다.

  • WidowX(6-DoF), Franka(7-DoF) 등 각 플랫폼마다 별도 모델 필요
  • 액션 레이블이 없는 인간 비디오 활용 불가
  • 다양한 형태에서 일반화 가능한 물리 법칙 학습 불가

핵심 질문

생성 비디오 모델은 교차 구현체 데이터 스케일링을 통해 일반화 가능한 물리 사전 지식을 학습할 수 있는가?

아니면 이질적인 로봇 형태가 에이전트별 아키텍처를 요구하는가?

핵심 통찰: 보편적 물리 법칙

동일한 보편적 물리 법칙이 에이전트의 구현체와 무관하게 모든 동적 상호작용을 지배한다.

병이 넘어지는 방식

Franka, WidowX, 인간 손 — 모두 동일한 물리

수건이 접히는 방식

형태에 무관하게 동일한 역학 적용

서랍이 미끄러지는 방식

액터가 달라도 마찰력 법칙은 동일

→ 이질성에 대한 적절한 대응은 하나의 구현체로 학습을 제한하는 것이 아닌, 통합하는 것이다.

CLAP 세 가지 핵심 기여

1

이질적 액션 공간 조화

엔드이펙터 포즈, 자연어 지시사항, 학습된 잠재 액션 표현으로 인간·로봇 형태 간 격차 해소

2

커리큘럼 기반 교차 구현체 학습

잠재 액션으로 무라벨 비디오에서 물리 사전 학습 → 엔드이펙터 액션으로 제로샷 실세계 배포 정제

3

샘플 효율적 단일 구현체 적응 패러다임

교차 구현체 모델을 타겟 로봇 플랫폼으로 파인튜닝하여 고품질 단일 구현체 모델 구축

액션 표현 방식 비교

표현 방식 장점 한계 데이터 요구
엔드이펙터 제로샷 실세계 배포 가능, 세밀 제어 무라벨 비디오 학습 불가 액션 레이블 필수
자연어 구현체 불변, 직관적 미세 제어 한계, 모호성 텍스트 주석
잠재 액션 무라벨 비디오 학습 가능 제로샷 배포 불가, 하위 정렬 필요 레이블 불필요

→ 각 방식의 상호 보완적 강점을 결합하는 커리큘럼 접근법이 필요하다.

액션 공간 조화 상세

엔드이펙터 액션

  • 조인트 공간이 아닌 엔드이펙터 6D 포즈 사용
  • DoF 차이 흡수: WidowX(6) ↔ Franka(7)
  • 고정 차원 컨디셔닝 입력 보장

잠재 액션 (Latent Actions)

  • VQ-VAE 목적으로 잠재 액션 학습
  • 액션 레이블 없는 인간 비디오 활용
  • Genie, LAPA와 유사하나 하위 정렬 문제 해결

자연어 액션

텍스트 주석이 있는 비디오에 대해 자연어 지시사항을 컨디셔닝으로 사용. 구현체 불변 표현이지만 미세 제어에 한계가 있어, 엔드이펙터와 결합하여 보완.

커리큘럼 기반 학습 파이프라인

1
잠재 액션 사전학습
무라벨 비디오(인간+로봇)에서 잠재 액션으로 기초 물리 사전 지식 학습
2
엔드이펙터 정제
레이블된 로봇 비디오로 엔드이펙터 액션 공간에서 물리 사전 지식 정제
3
제로샷 배포
실세계 로봇 정책에 제로샷 일반화 및 추론 시 플래닝

단계 1의 핵심

인터넷 규모의 무라벨 데이터에서 광범위한 물리 역학 습득

단계 2의 핵심

엔드이펙터 공간에서 실제 로봇 제어 가능한 표현으로 정밀화

제로샷을 넘어: 샘플 효율적 적응

CLAP의 세 번째 기여: 교차 구현체 모델을 타겟 로봇 플랫폼으로 파인튜닝하여 고품질 단일 구현체 비디오 월드 모델 구축.

적응 방법 1: 크로스 폴리시 플래닝

추론 시간에 CLAP 월드 모델 내에서 다양한 정책을 롤아웃하여 최적 행동 탐색

적응 방법 2: RL 기반 파인튜닝

비디오 월드 모델 내에서 강화 학습 기반 정책 파인튜닝으로 타겟 구현체에 특화

핵심: 제로샷 성능이 이미 강력하며, 소수샷 적응을 통해 성능이 복합적으로 향상됨.

실험: 교차 vs 단일 구현체

CLAP은 DROID 환경에서 단일 구현체 SOTA 모델에 근접하거나 초과하는 성능 달성.

모델 구현체 DROID 성능 비고
단일 구현체 베이스라인 DROID만 기준 성능 제한된 데이터
CLAP (제로샷) 교차 구현체 베이스라인 근접/초과 DROID 미사용
CLAP (소수샷 적응) 교차 → DROID 현저히 향상 복합적 이점

상대 액션 공간이 절대 액션 공간보다 교차 구현체 비디오 모델링에서 우수함.

실세계 제로샷 일반화

CLAP 월드 모델을 통해 실세계 조작 작업에서 SOTA 로봇 정책의 성능 향상 달성.

π₀.₅ + CLAP

성능 향상

CLAP 월드 모델 내 크로스 폴리시 플래닝으로 π₀.₅ 기본 성능 대비 더 높은 성공률 달성

MolmoAct-2 + CLAP

성능 향상

마찬가지로 기본 정책 성능을 클리어하게 상회하는 결과 확인

핵심: CLAP은 학습된 물리 사전 지식을 실세계 정책 개선에 직접 활용 가능한 시뮬레이터로 기능.

포괄적 모델 스위트

CLAP은 현재 가장 포괄적인 액션 조건부 비디오 월드 모델 모음을 제공합니다.

액션 컨디셔닝 공간

  • 엔드이펙터 포즈 기반
  • 자연어 지시사항 기반
  • 잠재 액션 (Latent) 기반

로봇 형태

  • 교차 구현체 (Cross-Embodiment)
  • DROID 데이터셋 특화
  • Bridge 데이터셋 특화
  • 양팔 YAM 로봇 (Bimanual)
  • G1 휴머노이드

핵심 요약

01

물리 보편성을 기반으로 교차 구현체 비디오 학습의 타당성 입증

02

커리큘럼 학습으로 잠재·엔드이펙터 액션의 상호 보완적 강점 결합

03

소수샷 적응으로 단일 구현체 모델 학습의 새로운 패러다임 제시

LLM이 웹 규모 텍스트로 언어를 통합한 것처럼, 비디오 월드 모델은 교차 구현체 데이터 스케일링으로 물리를 통합할 수 있다.

한계점 및 향후 방향

현재 한계

  • 잠재 액션의 하위 정렬 완전 해결 필요
  • 엔드이펙터 외의 제어 모달리티 확장
  • 장기 호라이즌 예측의 물리 일관성
  • 더 다양한 로봇 형태로의 일반화 검증

향후 방향

  • 더 광범위한 인터넷 비디오 데이터 활용
  • 다중 모달리티 액션 통합 강화
  • 비디오 월드 모델 기반 RL 파이프라인 고도화
  • 실세계 배포를 위한 안전성·견고성 연구
