TurboVLA: 실시간 비전-언어-행동 모델

RTX 4090에서 32 Hz, VRAM 1 GB 미만으로 구동되는
0.2B 파라미터 언어 조건부 로봇 조작 정책

혁시이(Xie Hengyi), 야오펀페이(Yao Chenfei) 외 · 화중과기대 & 화웨이

기존 VLA의 병목: LLM 중심 설계

기존 패러다임: V → L → A

  • 시각 관측 → LLM 잠재 공간 투영 → 행동 디코딩
  • 자가회귀 모델(OpenVLA, RT-2)은 토큰 단위 순차 디코딩 비용 발생
  • 연속 행동 전문가(π₀, π₀.₅)라도 수십억 파라미터 LLM 코어 통과 필요

핵심 문제점

  • 수십억 파라미터 LLM이 매 정책 호출마다 연산/메모리 오버헤드 유발
  • 높은 추론 지연 → 제어 주파수 저하
  • 자원 제약 로봇 플랫폼 배포 불가
  • 실행 수준 제어에 LLM의 광범위한 추론 능력은 과잉

"실행 수준 제어가 반드시 대형 언어 모델 중심이어야 하는가?"

핵심 관찰과 제안 패러다임

 핵심 관찰

언어는 지시 조건부 조작에 필요하지만, 실행 수준 제어가 LLM 중심일 필요는 없다. 지시가 조작 기술을 이미 지정한 후, 실행 정책은 개방형 언어 생성이나 자율적 작업 분해를 수행할 필요가 없다. 단지 현재 시각 증거가 행동을 어떻게 안내해야 하는지 결정하면 된다.

V → L → A
LLM 중심 (기존)
V + L → A
TurboVLA (제안)

다중모달 특징 인코딩

 시각 인코딩

  • ViT-S/14 백본으로 이미지를 패치 토큰 시퀀스로 변환
  • 로봇 상태(관절 각도, 그리퍼 상태)를 추가 토큰으로 결합
  • 위치 인코딩으로 공간 정보 보존
  • 다중 카메라 입력 지원 (토큰 수준 결합)

 언어 인코딩

  • 경량 BERT 기반 텍스트 인코더 사용
  • 실행 관련 의미 정보만 추출 — 과잉 추론 불필요
  • LLM 대비 극소수 파라미터로 충분한 표현력 확보
  • 토큰 시퀀스 형태로 V-L 상호작용 모듈에 전달

핵심 아이디어: 시각과 언어를 각각 독립적으로 인코딩하고, LLM 잠재 공간을 거치지 않고 직접 융합

시각-언어 상호작용 모듈

Grounding DINO에서 영감을 받은 양방향 크로스 어텐션

시각 토큰을 쿼리로, 언어 토큰을 키/값으로 사용하는 크로스 어텐션과 그 역방향을 교차로 수행. 이를 통해 지시 조건부 시각 표현을 직접 구성한다.

V→L
시각→언어 방향
시각 토큰이 언어 컨텍스트에서 관련 정보 조회
L→V
언어→시각 방향
언어 토큰이 시각 공간에서 대상 영역 파악
  • 수십억 파라미터 LLM 통과 없이 경량 크로스 어텐션만으로 모달리티 간 정보 교환
  • 여러 레이어 반복 적용으로 점진적 융합 (기본 3층)
  • 로봇 상태 토큰도 함께 참여하여 상태 조건부 표현 구성

연속 행동 청크 예측

기존 자가회귀 행동 생성

  • 행동을 토큰으로 표현 → 순차 디코딩
  • 액션 토큰 수만큼 전방향 패스 반복
  • 지연 시간 선형 증가

TurboVLA 비자가회귀 청크 예측

  • 단일 전방향 패스로 연속 행동 청크 출력
  • 컴팩트 MLP 디코더 사용
  • 지연 시간 일정 — 청크 길이 무관

행동 청크(Action Chunk)란?

한 번의 정책 호출로 여러 타임스텝의 연속 행동을 동시에 예측. 예측된 청크 내에서는 추가 정책 호출 없이 실행되어 제어 주파수를 효과적으로 높인다. Action Chunking with Transformers (Zhao et al., 2023) 방식 채택.

주요 발견

  • V-L 상호작용 모듈이 가장 큰 기여 (제거 시 -10.9%)
  • 1층 → 3층으로 깊어질수록 성능 향상
  • 로봇 상태 조건부 토큰이 운동학적 정보 제공에 필수적
  • 행동 청크 예측이 단일 스텝 대비 안정성 개선
  • 경량 BERT 인코더가 LLM 대비 근소한 차이로 충분

LIBERO 외 확장 실험

 양손 조작 (Bimanual)

  • LIBERO-Bimanual 벤치마크 평가
  • 두 로봇 팔의 좌표를 통합하여 단일 정책으로 제어
  • 대형 VLA 대비 경쟁력 있는 성능 유지
  • 행동 차원 증가에도 실시간 성능 저하 최소화

 실제 로봇 환경

  • 실제 Franka Emika Panda 로봇에서 검증
  • 다양한 조작 작업 (픽앤플레이스, 정렬 등)
  • 시뮬레이션→실제 전이(Sim-to-Real) 안정적 동작
  • 소비자급 GPU에서 실시간 제어 가능 확인

TurboVLA의 경량 설계는 단일 팔뿐 아니라 양손 조작과 실제 로봇 배포에서도 효과적임을 입증

핵심 요약과 시사점

 기여 요약

  • LLM 중심 VLA 설계의 병목 원인 분석
  • V+L→A 패러다임 제안 — LLM 코어 없는 실시간 VLA
  • 0.2B 파라미터로 LIBERO 97.7% 달성
  • RTX 4090에서 32 Hz, VRAM <1GB 실시간 구동

 향후 방향

  • 실행 수준 제어가 반드시 LLM 중심이어야 하는지 재검토 필요
  • VLA 평가 지표에 지연시간·효율성 포함 고려
  • 엣지 디바이스·임베디드 로봇 배포 가능성 개척
  • 고수준 계획(LLM) + 저수준 실행(TurboVLA) 계층적 구조

"TurboVLA는 시각, 언어, 행동을 효율적으로 연결하는 새로운 관점을 제공하며, 단순함과 효과성이 양립할 수 있음을 보여준다."
