동기: 왜 앙상블이 필요한가?

어휘적 정렬기

  • 용어가 유사하면 높은 재현율
  • 의미적 드리프트에 취약

KGE 기반 정렬기

  • 관계적 구조 포착에 강함
  • 그래프 희소성에 민감

LLM 기반 정렬기

  • 개방 어휘 맥락에서 일반화
  • 모델·도메인별 성능 편차 큼

  어느 하나의 패러다임도 모든 도메인에서 지배적이지 않음 → 보완적 강점을 결합하는 앙상블이 필수

문제 정의

소스 온톨로지 Osource와 타겟 온톨로지 Otarget가 주어졌을 때,

OA(Osource, Otarget) := M

M = { (s, t, r, Sr) | s ∈ Osource, t ∈ Otarget }

s: 소스 개체, t: 타겟 개체, r: 대응 관계, Sr: 신뢰도 점수

핵심 과제: 복수 정렬기가 생성한 후보 대응 집합 {M1, M2, ..., Mk}을 하나의 일관된 최종 정렬 M*으로 통합하는 것

OntoAligner-Ensemble 프레임워크

개별 정렬기
Lexical, KGE, RAG/LLM
후보 대응 생성
투표 기반 융합
Weighted Voting, RRF,
Condorcet, Borda Count
사후 선택 정책
임계값, 1:1 제약,
최종 정렬 산출
  • 정렬기 무관(modular & aligner-agnostic): OntoAligner 내 어떤 정렬기도 통합 가능
  • 설정 가능(configurable): 투표 방식과 선택 정책을 자유롭게 조합
  • 2단계 파이프라인: 융합 → 선택의 분리로 유연성 극대화

투표 기반 융합 전략

Weighted Voting

각 정렬기의 신뢰도 가중치를 반영하여 후보별 가중 합산 점수 산출

Reciprocal Rank Fusion (RRF)

각 정렬기의 순위 역수를 합산하여 순위 편차를 완화

Condorcet 투표

모든 쌍별 다수결 비교를 통해 Condorcet 승자 선정

Borda Count

각 정렬기 순위에 따라 점수 부여 후 총합 계산

  네 가지 융합 전략은 상호 교환 가능하며, 도메인 특성에 따라 최적 전략을 선택할 수 있음

앙상블 구성: 이종 패러다임 앙상블 (문자열+KGE+LLM) vs 동종 LLM 앙상블 (LLM만)

RQ1: 개별 정렬기 성능 비교

도메인별로 우위 정렬기가 다름 — 만능 정렬기는 존재하지 않음

정렬기 유형 강점 도메인 약점 도메인 특징
문자열 기반 용어 중복이 높은 트랙 의미적 드리프트 환경 높은 재현율, 낮은 정밀도
KGE 기반 구조적 패턴이 뚜렷한 경우 그래프가 희소한 온톨로지 관계 포착, 임베딩 품질 의존
RAG/LLM 개방 어휘, 복잡한 의미 전문 도메인 미세조정 부족 시 모델·프로바이더별 편차 큼

RQ2: 투표 기반 앙상블의 효과

↑

정밀도-재현율 균형 개선

단일 정렬기 대비 일관되게 균형 향상

F1

다수 태스크에서 최고 F1

개별 정렬기 및 기존 베이스라인 상회

투표 기반 융합은 거짓 양성(false positive)을 억제하면서도 진짜 대응을 보존하는 효과를 보임 — 다수결이 개별 편향을 상쇄

RQ3: 앙상블 구성의 영향

이종 패러다임 앙상블

문자열 + KGE + LLM

  • 정밀도(Precision) 우선 개선
  • 서로 다른 오류 패턴 상호 보완
  • 다양한 도메인에서 안정적
동종 LLM 앙상블

LLM + LLM (다중 모델)

  • 전체 F1-score 우선 개선
  • 재현율 측면에서 유리
  • 유사한 오류 패턴 공유 위험

  정밀도 중심이 필요하면 이종 앙상블, F1 중심이면 동종 LLM 앙상블 선택이 실용적 지침

핵심 발견 요약

1

만능 정렬기는 없다

패러다임별 강약점이 도메인에 따라 상호 보완적

2

앙상블이 일관되게 효과적

8개 태스크 중 다수에서 개별 정렬기 및 베이스라인 상회

3

구성이 정밀도-재현율 트레이드오프를 결정

이종 → 정밀도 향상 / 동종 LLM → F1 향상

4

재현 가능하고 실용적인 접근

설정 가능한 모듈식 프레임워크로 다양한 시나리오 지원

한계 및 향후 방향

현재 한계

  • 평가가 OAEI 벤치마크에 한정
  • 투표 가중치 수동 설정 필요
  • LLM 호출 비용 및 지연 고려 부족
  • 동적 앙상블(메타러닝) 미탐색

향후 연구 방향

  • 메타러닝 기반 자동 가중치 학습
  • 도메인 특화 앙상블 자동 선택
  • 비동등 관계(beyond equivalence) 확장
  • 산업 규모 온톨로지로 스케일업

결론

체계적인 앙상블 학습은 온톨로지 정렬에 있어 견고하고 재현 가능한 전략이며, 앙상블 구성 선택은 정밀도-재현율 트레이드오프를 직접적으로 제어하는 실용적 레버리지입니다.
