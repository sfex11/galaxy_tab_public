RLVR × LLM 추론 일반화

Not All Reasoning Generalizes

RLVR에서 일반화 가능한 추론 전략 학습에 대한 케이스 스터디

Ziqi Pang, Yu-Xiong Wang

University of Illinois Urbana-Champaign

arxiv.org/abs/2611.03627

핵심 질문: RLVR 일반화는 언제, 왜 실패하는가?

알려진 긍정적 결과

  • 수학/코딩 RL 이후 일반 추론·에이전트 능력 향상
  • 합성 문자열 과제에서 구성적 확장
  • 게임/퍼즐 → 추론 벤치마크 전이

간과된 문제

기존 연구는 주로 베이스 모델과의 관계로 일반화를 해석했을 뿐, 개별 추론 전략을 분류하고 OOD 일반화를 분석하지 않았음

→ 추론 전략 관점에서 일반화를 체계적으로 탐구

연구 프레임워크: 제어 가능한 방정식 풀이 과제

f(x) = y 를 만족하는 여러 입력 x를 찾는 역문제 (f는 비-단사(non-bijective) 문자열 함수)

1

관찰 가능성
추론 전략이 출력에 직접 드러남

2

명확한 OOD 정의
held-out 함수 + 더 긴 y + 더 많은 해 k

3

실제 문제와 유사
수학 방정식 풀이, 코딩 버그 추적을 반영

k > 1개의 서로 다른 해를 요구하여 전략 차이를 명확히 구분

두 가지 추론 전략

Derivation (유도)

단계별 구조적 유도로 후보 해 공간을 한 번에 크게 축소

한 스텝에 여러 후보를 동시에 제거 → 높은 bits/token

효과적 · 일반화 유리

Enumeration (무차별 열거)

모든 자릿수를 동시에 브루트포스 탐색

한 스텝에 잘못된 후보 하나만 제거 → 낮은 bits/token

비효율적 · OOD에서 붕괴

추론 과정 = 후보 해 공간을 점진적으로 축소하는 과정으로 볼 수 있다

핵심 발견: 추론 전략 붕괴 (Strategy Collapse)

1
ID 학습
Mono 모델이 높은 정확도로 단계별 유도 전략 습득
2
OOD 전환
더 긴 y, 더 많은 해 k가 요구되는 어려운 과제 투입
3
전략 붕괴
유도를 버리고 무차별 열거로 퇴행 → 정확도 급락

LLM은 ID에서 효과적인 추론 전략을 배울 수 있지만, OOD 상황에서는 훨씬 나쁜 전략으로 급격히 퇴행한다

이 붕괴는 미묘한 문제다

보상 해킹이 아님

모델은 학습 분포에서 올바른 추론 전략으로 유효한 추론 trace를 따르며 높은 정확도 달성

무능한 베이스 모델도 아님

베이스 모델의 한계가 아니라, RLVR이 어떤 전략에 보상을 주는지의 문제

핵심은 학습 정확도를 높이는 것이 아니라,
RLVR이 어떤 추론 전략을 장려하는가를 바꾸는 것이다

해법: 단사(bijective) 역문제 공동학습 → Mixed 모델

1
의도하지 않은 간접 개입 — 해가 하나뿐인 단사 과제 f(x)=y 를 공동 학습에 추가 (비-단사 OOD 평가와는 오히려 더 멀고, 더 어렵지도 않음)
2
직관 — 단사 과제는 탐색 공간을 줄여 단계별 유도를 더 확실하게 만듦
3
결과 — Mixed 모델이 유도 전략을 회복하고 OOD 정확도 대폭 향상 (ID 성능은 Mono와 유사)

놀라운 점: OOD 평가와 더 거리가 먼 과제가 오히려 OOD 일반화를 크게 복원시킴

Mono vs Mixed 비교

항목 Mono 모델 Mixed 모델
ID 성능 높은 정확도, 구조적 유도 유사한 수준의 정확도
OOD 전략 유도 붕괴 → 무차별 열거 유도 전략 유지
OOD 정확도 급격한 하락 크게 개선
교훈 정확도만으로 일반화 판단 불가 전략 구성이 일반화를 결정

교란 요인(과제 난이도, 다른 함수 집합, 학습 다양성, 반복 실행)을 통제한 후에도 효과가 유지됨

이론: 토큰당 비트(bits per token)가 전략과 일반화를 형성

정보 관점의 추론

  • 유도: 한 스텝에 여러 후보를 구조적으로 가지치기 → 많은 비트 기여
  • 열거: 스텝당 잘못된 후보 1개 제거 → 미미한 비트 기여
  • 어려운 과제일수록 더 많은 비트가 필요 → 유도 전략이 일반화에 유리

RL 알고리즘과의 연결

  • 결과만 주는 보상(outcome-only RLVR)도 성공 증분을 통한 암묵적 크레딧 할당
  • 프로세스 감독 없이도 효과적인 추론 과정에 더 많은 크레딧 부여 (GRPO 분석)
  • 비트율(bit-rate) 개입 실험으로 이론 검증

결과 기반 RLVR이 프로세스 감독 없이도 효과적 추론 전략을 자연스럽게 장려할 수 있음을 설명

행동 분석: 전략은 표현과 전이로 검증된다

표현 분석

히든 스테이트 프로빙으로 전략 확약(strategy commitment)을 조기에 탐지 가능

과제 혼합

과제 혼합 비율에 따른 상세 오류 분석으로 전략 구성의 영향 정량화

전이 실험

제로샷 수학 벤치마크 및 에이전틱 과제로의 전이에서도 전략 효과 확인

추론 trace 감사 + 히든 스테이트 프로빙이 추론 전략을 RLVR 일반화를 이해하는 원리적 관점으로 자리매김함을 질적으로 보여줌

기여 요약

1
통제된 반례 발견 — RLVR이 ID에서는 올바른 추론 전략을 가르치지만 OOD 전이 시 전략이 붕괴함을 보임 (무능한 베이스 모델과 구별되는 새로운 실패 양상)
2
원리적 개입 — 단사 역문제 공동학습이 OOD 일반화를 크게 향상시켜 추론 전략의 결정적 역할 입증
3
이론적 설명 — 스텝당 정보량 관점에서 결과 기반 RLVR이 효과적·일반화 가능한 전략을 자연히 장려함을 규명
4
질적 검증 — 추론 trace 감사와 히든 스테이트 프로빙으로 전략이 일반화 행동과 연결됨을 확인

결론

모든 추론이 일반화되는 것은 아니다.
RLVR 일반화의 열쇠는 어떤 추론 전략을 장려하는가에 있다.

  • 합성·통제 가능한 데이터로 LLM 추론 일반화를 정밀하게 진단하는 프레임워크 제시
  • 전략 관점은 보상 해킹·베이스 모델 한계로는 설명되지 않는 실패를 포착
