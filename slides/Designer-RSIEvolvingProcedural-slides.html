Designer-RSI

사용자 트래픽으로부터 절차적 메모리를 진화시키는
에이전틱 그래픽 디자인

Hongyang Du · Lan Yan · Christian Flores · Asim Kadav
Adobe / Brown University

arXiv:2609.22086

왜 그래픽 디자인은 어려운가?

전문 그래픽 디자인은 장기(long-horizon) 에이전틱 작업입니다 — 수십 개의 상호 의존적인 동작으로 구조화되고 편집 가능한 결과물을 만들어냅니다.

신용 할당 문제

최종 피드백만으로는 수십 개의 동작 중 무엇이 성공/실패를 유발했는지 파악하기 어려움

검증 불가능한 결과

계층, 구도, 스타일 같은 주관적 기준이 섞여 있어 코드의 실행 테스트 같은 성공 오라클이 없음

모델 업데이트 불가

파운데이션 모델이 외부 호스팅되어 있거나 파라미터 업데이트가 비현실적인 상황

지도 학습은 비용이 큰 시연(demonstration)을 요구하고, 결과 기반 최적화는 장기 신용 할당과 불완전한 프록시 보상을 모두 다뤄야 합니다.

핵심 아이디어: 절차적 메모리가 학습 대상

모델 가중치 대신, 프로즌(frozen) 모델을 둘러싼 절차적 메모리를 학습 목표로 삼습니다.

고정되는 것

  • 파운데이션 모델 가중치
  • 도구, 렌더러, 평가기
  • 진화 역할(프롬프터 등)

진화하는 것

  • 자연어 스킬 라이브러리(SKILL.md)
  • 재사용 가능한 디자인 절차
  • 경험에서 축적·정제된 노하우

스프레드시트 매크로나 포토샵 액션처럼 반복 워크플로우를 재사용 가능한 루틴으로 담되, 고정된 순서를 벗어나 모델이 적응·재배열·부분 적용할 수 있는 자연어 가이드로 완화합니다.

절차(procedure)는 원자적 도구 호출과 전체 궤적 사이에 위치 — 실행을 유도할 만큼 구체적이고, 전이될 만큼 일반적입니다.

시스템 개요: 전문 디자인 에이전트

프로즌 프론티어 모델

Photoshop·Illustrator·InDesign에 해당하는 전문 소프트웨어를 230개 이상의 도구로 제어합니다.

  • 래스터 편집 · 벡터 그래픽
  • 페이지 레이아웃 · 에셋 검색
  • 중간 문서 상태의 멀티모달 검증

스킬 뱅크 인터페이스

실행 전 SKILL.md 플레이북과 축소된 도구 목록을 컨텍스트에 주입합니다.

제어 조건 스킬 검색을 비활성화하면 원래 에이전트가 복원되어, 진화 효과를 측정하는 자연스러운 대조군이 됩니다.

1
브리프 입력
사용자 프롬프트 또는 LLM 프롬프터
2
스킬 검색
상위 스킬 주입 + 도구 필터링
3
도구 실행
중간 문서 상태를 거쳐 출력 이미지
4
보상 산출
그레이더가 스칼라 보상 계산

진화 루프: 4가지 역할

모델 가중치는 그대로 둔 채, 오프라인 루프로 스킬 뱅크만 진화시킵니다.

Prompter

사용자 데이터와 LLM으로부터 디자인 브리프를 생성합니다.

Solver

에이전트 자신 — 스킬 뱅크 + 도구를 사용해 이미지를 렌더링합니다.

Grader

멀티모달 평가로 각 이미지를 채점하고, 미충족 요구가 왜 실패했는지 설명합니다.

Reflector

실패를 SKILL.md에 대한 표적화된 수정으로 변환합니다.

오직 SKILL.md 파일만 변경됩니다 — 뱅크는 미커버 의도에 대한 신규 스킬을 발행하며 넓어지고(widening), 기존 스킬을 실패에 대비해 단련하며 깊어집니다(deepening).

Widening: 반복되는 미커버 하위작업에서 신규 스킬 발행

현재 스킬 라이브러리가 커버하지 못하는 하위작업을 발견하여 새로운 스킬로 증류합니다.

1
하위작업 추출
프로즌 LLM이 브리프와 도구 호출에서 수행된 하위작업을 추출·표준화
2
미커버 판정
검색 결과가 없거나 검색된 스킬이 다른 부분을 다룰 때
3
커버리지 풀
표준 라벨 키로 미커버 하위작업을 지속적으로 누적
4
스킬 증류
라벨이 kmin=3회 도달 시 후보 스킬로 증류
5
리플레이 게이트
노스킬 베이스라인 대비 통과 시에만 뱅크에 등록

실패 원인으로 지목된 스킬에 연관된 하위작업도 미커버로 간주하여, 문제가 되는 영역을 놓치지 않습니다.

Deepening: 기존 스킬의 반복적 단련

이미 존재하는 스킬이 반복적으로 실패와 연관될 때, 같은 스킬의 성공 사용 사례와 실패 실행을 대조하여 수정합니다.

원인 규명

그레이더의 설명과 스킬 호출 이력을 통해 실패한 궤적에서 책임 있는 스킬을 특정합니다.

표적화된 수정

리플렉터가 실패를 SKILL.md의 구체적 개정안으로 변환합니다 — 전면 재작성 또는 부분 편집.

스킬은 자연어 가이드이므로, 모델이 순서를 바꾸거나 일부만 적용할 수 있습니다. Deepening은 이 가이드가 실제 실패에서 배우도록 만듭니다.

Widening + Deepening은 함께 작동합니다: Widening은 커버리지 갭을 메우고, Deepening은 이미 커버된 절차의 신뢰성을 높입니다.

Replay Gate: 보수적 변경 승인

LLM 평가자의 위치·순서 편향과 노이즈가 있는 피드백 속에서, 변경은 시스템을 실제로 개선할 때만 지속되어야 합니다.

매칭 리플레이

상류 컨텍스트를 고정하고, 후보 스킬과 현행 스킬을 동일한 리플레이 사례에서 비교합니다. 안전 정책 개선(safe policy improvement)에서 영감을 받았습니다.

승인 조건

  • 최소 1개 리플레이 사례에서 현행 스킬을 능가
  • 관찰된 성공 사례에서 퇴행 없음
  • 동점 구간(tie band)과 판정 규칙 사전 정의

제안(proposal)과 승인(admission)의 분리 — Widening과 Deepening은 경험에서 변경을 제안하고, Replay Gate는 노이즈가 있는 판정과 롤아웃 피드백 속에서 배포 뱅크로 들어갈 변경을 통제합니다.

거부되면 변경은 폐기되고, 뱅크는 안정적으로 유지됩니다.

기여점

1

전문 디자인 에이전트에서의 스킬 진화

프로즌 파운데이션 모델 주변에서 재사용 가능한 절차 라이브러리를 학습 대상으로 취급하고, 사용자 트래픽에서 절차를 습득·개정하는 메커니즘 제시

2

검증 불가능한 피드백 하의 보수적 진화

노이즈가 있는 판정과 롤아웃 피드백 속에서 배포 뱅크에 들어갈 변경을 통제하는 매칭 리플레이 게이트 도입

3

배포 환경에서의 결합된 습득과 개정

5개 진화 라운드, 다중 프로즌 백본, 다수 벤치마크에서 습득과 개정이 단독보다 결합 시 실질적으로 더 효과적임을 입증

결론 및 시사점

  • 절차적 메모리는 가중치 업데이트 없이 에이전트가 경험을 축적하게 하는 실용적인 지속 적응 경로
  • 성공 오라클이 없는 도메인에서도 보수적 승인 절차로 신뢰할 수 있는 개선 달성
  • 습득(Widening)과 개정(Deepening)의 시너지가 핵심 — 커버리지 확장과 신뢰성 강화는 상호 보완적
  • 자연어 스킬은 고정 루틴보다 유연 — 모델이 적응·재배열·부분 적용 가능

한계

개인화(사용자 선호 반영)는 검색·주입만으로는 부족한 영역으로, 별도 메커니즘과 향후 연구가 필요

확장 가능성

노이즈가 있고 검증 불가능한 피드백 환경의 다른 장기 에이전틱 작업으로 일반화 가능
