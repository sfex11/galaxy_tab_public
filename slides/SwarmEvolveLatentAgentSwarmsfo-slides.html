LLM-guided Evolutionary Search

SwarmEvolve

잠재 에이전트 군집(Swarm)을 통한 진화적 발견과 최적화

수백 개의 저비용 에이전트가 잠재 공간에서 추론하고
KV 캐시를 전달하며 진화하는 프로그램 탐색 프레임워크

arXiv: 2611.08483  ·  github.com/Qile-J/SwarmEvolve

배경: LLM 기반 진화 탐색의 성공과 한계

지금까지의 성과

  • FunSearch — 새로운 cap set 구성 발견
  • AlphaEvolve — 4×4 복소수 행렬 곱셈 알고리즘 개선
  • LLM을 변이(mutation)·교차(crossover) 연산자로 활용
  • 다양한 제안 + 아이디어 교배 + 반복 개선이 핵심 동력

하지만 느리고 비싸다

  • 에이전트마다 긴 텍스트 기반 사고(Chain-of-Thought) 생성
  • 인구 다양성 유지를 위해 동일한 생성을 수차례 반복
  • 솔루션 아카이브·평가 피드백으로 컨텍스트 급증
  • 에이전트·모델 규모 확장 시 비용이 곱셈적으로 증가
핵심 질문: "저비용 에이전트의 군집(swarm)이 진화 탐색을 더 빠르고, 더 좋게 만들 수 있을까?"

핵심 아이디어: 잠재 공간에서 진화하는 에이전트 군집

SwarmEvolve는 텍스트로 디코딩하지 않고 잠재 공간(latent space)에서 추론하며, KV 캐시를 주고받아 정보를 공유하는 진화 탐색 프레임워크입니다.

450

라운드당 450개의 잠재 에이전트가 동시에 다양한 관점에서 문제를 탐색

40

각 에이전트는 텍스트 없이 40 스텝의 잠재 추론을 수행

0

스텝 간 텍스트 인코딩/디코딩 비용 없음 — 저비용 고효율

기반 기술: 잠재 추론(Latent Reasoning) + 잠재 통신(Latent Communication) — 특히 훈련 없이 KV 캐시 기반 협업을 수행하는 LatentMAS를 대규모 진화 탐색으로 확장

사전 지식: KV 캐시와 잠재 통신

KV 캐시 (KV Cache)

Decoder-only 트랜스포머는 각 위치의 키(K)와 값(V)을 레이어별로 저장합니다. 새 토큰은 캐시에 attend 하고 자신의 K·V를 추가하는 단일 위치 forward pass만으로 처리됩니다.

  • 공유 프리픽스의 KV 캐시는 재사용 가능
  • 숨겨진 상태 벡터 ht가 다음 토큰 분포를 결정

잠재 추론 · 잠재 통신

  • 잠재 추론: 샘플링된 토큰 대신 연속 벡터로 추론
  • 잠재 통신: 텍스트 대신 토큰 임베딩·활성값·숨김 상태·KV 캐시를 교환
  • LatentMAS: 훈련 없이 잠재 추론 + KV 캐시 전달 + 요약기(summarizer)로 답변 생성
이 메커니즘을 "대규모·저비용 진화 탐색"의 기반으로 사용한 것이 SwarmEvolve입니다.

SwarmEvolve의 작동 방식

1
군집 형성
서로 다른 관점(문헌 기반 구성, 교과서적 방법 등)의 스웜 구성
2
잠재 추론
각 에이전트가 고유 관점으로 40 잠재 스텝 추론
3
신규성 필터
숨김 상태 벡터 간 코사인 거리로 가장 거리가 먼 아이디어만 유지
4
KV 캐시 전달
유지된 에이전트들의 KV 캐시를 요약기 에이전트에 전달
5
프로그램 작성
요약기가 군집의 아이디어를 통합한 새 프로그램 생성

이후 파라미터 튜닝 → 평가(Evaluate)를 반복하며, 각 군집의 요약기가 서로 다른 부모 프로그램의 아이디어를 자연스럽게 교차(crossover)시킵니다.

세 가지 핵심 강점

1. 더 큰 다양성

기존 방법은 한 번에 하나의 응답 또는 소수의 에이전트 팀만 운영. SwarmEvolve는 라운드당 450개의 에이전트가 각기 다른 특화 분야·부모 프로그램·사고 방식으로 훨씬 다양한 제안을 생성합니다.

2. 내장된 교차(Crossover)

아이디어 재조합이 잠재 공간에서 자연스럽게 일어납니다. 서로 다른 부모 프로그램을 연구한 에이전트들의 KV 캐시를 요약기가 읽어, 아이디어를 결합한 하나의 프로그램을 작성합니다.

3. 높은 처리량

스텝 사이에 텍스트를 디코딩·인코딩하지 않아, 기존 SOTA 프레임워크 대비 시간당 5~13배 더 많은 프로그램을 평가하고 60분 점수를 중앙값 3~8분에 도달합니다.

다양성 ↑ 교차 자동화 처리량 5~13×

텍스트 생성 병목을 제거하는 것이 확장의 핵심

실험 설정

벤치마크

21개 문제 — 수학적 발견 + 과학 컴퓨팅 영역

  • 원·육각형·직사각형 패킹 (Circle/Hexagon Packing)
  • 하일브론 문제, 거리 비율 문제
  • 자기상관·불확정성 부등식, Erdős Minimum Overlap
  • 희소 선형 시스템, 비정규 행렬 고유값
  • Viscous Burgers, 대류-확산, Helmholtz 방정식

비교 대상과 조건

기준 프레임워크: OpenEvolve, ShinkaEvolve, CodeEvolve

  • 모델: Qwen3 8B / 14B / 32B-FP8 (동일 조건 공정 비교)
  • GPU 1장, 문제당 60분 실행
  • 평가 지표: 평균 최고 점수, 프로그램 수, 목표 점수 도달 시간

모든 프레임워크에 동일한 모델·시간 예산을 부여해 프레임워크 자체의 효율성만을 비교

결과 ③ — 프론티어 모델의 결과를 8B 모델로 능가

AlphaEvolve가 프론티어 Gemini 모델로 처음 발견한 구성(construction)을, 동결된(frozen) Qwen3 8B만을 사용한 SwarmEvolve가 3개 문제에서 향상시켰습니다.

의미하는 바

  • 모델 크기보다 탐색 구조(다양성·교차·처리량)가 결정적
  • 저비용 오픈 모델로도 개방형 수학 문제에서 새로운 발견 가능
  • 잠재 공간 통신이 에이전트 수 확장의 병목을 제거

잠재 공간 분석

요약 및 시사점

  • 수백 개의 저비용 에이전트가 군집을 이루어 잠재 공간에서 추론하고 KV 캐시로 소통하는 진화 탐색 프레임워크 SwarmEvolve 제안
  • 21개 수학·과학 컴퓨팅 문제에서 최고 평균 점수 달성
  • 기존 SOTA의 60분 최고 점수를 중앙값 3~8분 만에 도달, 시간당 프로그램 수 5~13배
  • Qwen3 8B만으로 프론티어 Gemini 기반 AlphaEvolve의 발견을 3개 문제에서 개선
  • 잠재 공간에서 소통하는 에이전트 군집은 과학 문제의 빠르고 저렴한 프로그램 탐색이라는 새로운 패러다임 제시
"잠재 공간에서 소통하는 에이전트 군집은 과학적 문제를 위한 프로그램 탐색에 빠르고 저비용인 접근법을 제공한다."
