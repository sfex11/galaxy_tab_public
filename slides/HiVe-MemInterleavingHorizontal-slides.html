Multimodal Agent Memory

HiVe-Mem

수평적 기억 확장과 수직적 증거 구성을 결합한
멀티모달 에이전트 기억 프레임워크

Horizontal Memory Expansion × Vertical Evidence Composition

Nanyang Technological University · Tsinghua University · Sun Yat-sen University · Aumovio Singapore

왜 장기 기억이 중요한가?

  • 멀티모달 에이전트는 텍스트와 이미지가 섞인 장기 상호작용 이력을 축적
  • 과거 정보를 검색하고 재활용하는 능력이 장기 상호작용의 핵심
  • 기존 시스템: 압축된 기억에 대한 의미론적 검색 + 고정된 표현에 의존
핵심 질문: 이질적인 상호작용 이력에서 추론 시점에 유용한 정보를 유연하게 식별·활용하려면 어떻게 해야 하는가?

기존 멀티모달 기억 시스템의 두 가지 한계

한계 1: 에피소드 중심 구조 부재

구조화된 기억이 추상적 개체·관계를 중심으로 구성되어, 상호작용 에피소드 간 문맥적 유사성(엔티티, 장면, 이벤트 공유)을 놓침

→ 여러 상호작용에 분산된 관련 기억을 검색에서 누락

한계 2: 사전 정의된 고정 표현

검색된 기억이 고정된 표현 형태로 노출되어, 쿼리별로 상이한 증거 요구(요약만으로 충분 vs. 세밀한 시각 증거 필요)를 반영하지 못함

→ 불충분한 활용 또는 불필요하게 과도한 토큰 소비

HiVe-Mem: 가로(Horizontal) × 세로(Vertical) 2차원 설계

↔ 수평적 기억 확장

텍스트·시각 앵커로 에피소드를 관계 그래프로 구성. 의미 검색으로 찾은 시드에서 출발해 관련 이웃 에피소드로 검색 범위 확장

목표: 기억 커버리지 확대

↕ 수직적 증거 구성

기억마다 요약, 캡션, 그라운드된 시각 뷰, 원본 이미지, 대화 이력 등 다양한 증거 형태를 보존. RL 학습된 경량 선택기가 쿼리별 증거 부분집합을 독립적으로 구성

목표: 쿼리 적응형 이질 정보 활용

두 차원이 결합하여 관련 기억의 재현율을 넓히고, 개별 기억이 기여하는 증거를 쿼리에 맞게 적응시킴

전체 파이프라인: 3단계 방법론

1
멀티모달 기억 형성
상호작용 이력을 에피소드 중심 기억으로 구성하고 텍스트·시각 정보를 앵커로 추출
2
수평적 기억 확장
의미 검색 시드를 에피소드 간 문맥 연관성으로 확장하여 누락된 관련 기억 회수
3
수직적 증거 구성
경량 학습 선택기가 쿼리 조건에 따라 각 기억의 증거 형태를 적응적으로 결정

성장하는 상호작용 이력 ℋ = {x₁, …, x_T}의 각 상호작용은 텍스트 콘텐츠와 연관 이미지를 포함

수평적 기억 확장 — 관계 그래프 기반 검색 확대

  • 멀티모달 이력에서 텍스트 앵커 + 시각 앵커를 추출해 에피소드를 경량 관계 그래프로 조직
  • 의미 검색으로 찾은 시드 에피소드에서 출발하여, 교차 에피소드 문맥 친화성을 따라 연관 에피소드로 확장
  • 직접 의미 매칭만으로는 잡지 못하는 부분적 단서(엔티티·장면·이벤트 공유)를 보완하는 관계 신호 활용
  • 여러 상호작용에 분산된 보완 정보를 회수하여 답변 품질 향상

핵심 통찰: 관련 에피소드들은 명시적 기호 관계 없이도 텍스트와 이미지에 걸쳐 부분적 단서를 공유한다 → 그래프 확장이 의미 검색의 사각지대를 메운다

수직적 증거 구성 — 다층 증거의 쿼리 적응 선택

각 검색된 기억은 5가지 증거 형태를 동시에 보존하며, 선택기가 쿼리에 따라 필요한 층만 노출

요약

컴팩트한 텍스트 요약

캡션

이미지에 대한 텍스트 설명

시각 뷰

그라운딩된 시각 영역 뷰

원본 이미지

전체 원본 시각 정보

상호작용 이력

원문 대화 맥락

적응 선택

RL 학습 경량 선택기가 조합 결정

서로 다른 기억이 서로 다른 증거 부분집합을 노출 — 답변 품질과 토큰 소비를 동시에 고려

실험 설정

벤치마크

  • 3개 멀티모달 기억 벤치마크 (Mem-Gallery, H2HMem, WorldMemArena 계열)
  • 장기 텍스트–이미지 상호작용에서의 QA 평가

베이스 모델

  • 2개 베이스 모델 위에서 일관된 성능 향상 확인
  • 비교 대상: MIRIX, M3-Agent, M2A, MemVerse 등 멀티모달 기억 방법
90%↓

가장 효율적인 경쟁 멀티모달 베이스라인 대비 토큰 소비 약 90% 감소

일관된 향상

3개 벤치마크 × 2개 베이스 모델 전반에서 과제 성능 꾸준히 개선

증거 구성은 어떻게 적응하는가?

쿼리 유형별 행동

단순 팩트 질의에는 컴팩트한 요약 위주로 응답하고, 세밀한 시각 정보가 필요한 질의에는 원본 이미지·시각 뷰를 추가로 노출

전이 평가에서도 유지

학습되지 않은 설정으로 전이해도 증거 구성 정책이 일관된 적응 행동을 보여 선택기의 일반화 능력 확인

런타임 오버헤드

그래프 확장과 증거 선택을 포함한 전체 파이프라인이 런타임 오버헤드는 미미하면서 토큰 효율은 크게 개선

어블레이션: 두 구성 요소의 상호 보완성

설정수평 확장수직 구성효과
HiVe-Mem 전체✓✓최고 성능 + 최소 토큰
수평 확장 제거✗✓분산된 관련 기억 누락으로 성능 저하
수직 구성 제거✓✗고정 표현 노출로 토큰 소비 증가
둘 다 제거✗✗기존 방식과 동일한 한계
두 메커니즘은 독립적으로도 유효하지만, 결합할 때 시너지가 극대화 — 커버리지 확대와 적응적 증거 활용이 서로를 보완

기여 요약

1
통합 프레임워크 제안: 기억 검색과 증거 활용을 동시에 개선하여, 고정된 검색·표현 파이프라인을 넘어 긴 텍스트–이미지 상호작용 이력을 유연하게 활용
2
상호 보완적 메커니즘 구현: 수평적 기억 확장으로 교차 에피소드 문맥 친화성을 검색에 반영하고, 수직적 증거 구성으로 기억별 멀티모달 증거를 적응적으로 조합
3
실증적 검증: 3개 벤치마크 × 2개 베이스 모델에서 기존 멀티모달 방법 대비 성능 향상 + 토큰 소비 대폭 절감, 쿼리·예산 설정 변화에 대한 유연성과 두 구성 요소의 유효성 분석

결론 및 향후 방향

  • 멀티모달 에이전트의 장기 기억은 "무엇을 저장하느냐"뿐 아니라 "추론 시 무엇을 노출하느냐"가 핵심
  • 수평 확장 + 수직 구성의 2차원 설계가 커버리지와 효율성을 동시에 해결
  • RL 기반 경량 선택기가 답변 품질–토큰 비용의 균형을 학습적으로 최적화
  • 향후 과제: 더 긴 이력 누적 시 확장성, 더 풍부한 모달리티(영상·오디오)로의 확장
