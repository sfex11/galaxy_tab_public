SwarmWorld

공유 환경을 통한 자극매개적 기술 진화:
언어 모델 에이전트 사회에서의 누적 문화

Subhadeep Pal · Fiona Y. Wang · Markus J. Buehler

MIT Laboratory for Atomistic and Molecular Mechanics

연구 배경

집단 지능의 근본 질문

"분산화된 에이전트가 단순한 병렬 탐색을 넘어, 미래 행동을 위한 공유되고 누적된 기반을 구축할 수 있는가?"

자연계의 사례

  • 개미의 군집 채집 — 정보 화학적 자극매개
  • 꿀벌의 nest-site 선택 — 쿼럼 기반 결정
  • 물고기 떼의 집단 행동 — 국소 피드백

핵심 원리

  • 중앙 조정자 불필요
  • 국소 행동이 지속적 구조로 축적
  • 자극매개(Stigmergy): 환경 수정이 조정 매개체
문제 제기

기존 다중 에이전트 시스템의 한계

①

직접 대화 의존

에이전트 간 메시지 교환에 과도하게 의존하여 환경 매개 조정이 없음

②

사전 정의된 역할

탐색자·건설자 등 고정 역할 할당으로 자발적 분화 불가

③

중앙 집중 워크플로우

설계된 파이프라인 내에서만 상호작용 허용

기존 시스템은 "소통·전문화·산출물 창출이 가능한가?"를 묻지만,
"상호작용이 독립 탐색보다 기능적으로 우수한 기술 생태계를 만드는가?"는 검증하지 않음

제안

SwarmWorld: 핵심 개념

인지와 결과의 분리

에이전트는 고정된 액션·재료 스키마 내에서 아키텍처와 컨트롤러를 제안하고, 시뮬레이션 세계가 기능을 판정

자극매개적 기술 진화

개미의 페로몬처럼, 에이전트가 남긴 물리적 산출물이 후속 에이전트의 행동을 안내

필수 4가지 속성

  • 초기 동등한 에이전트 (역할 없음)
  • 수정이 유지되는 공유 세계
  • 에이전트 주장과 독립적인 기능 평가
  • 정합된 독립 탐색 베이스라인

SwarmWorld 시스템 아키텍처

에이전트-세계 인터페이스

구조화된 출력으로 이동·수집·조합·건설 액션 수행. 자유 텍스트가 아닌 스키마 기반 제약

결정론적 시뮬레이터

에이전트 제거 후 보이지 않는 교란(disturbance) 하에서 산출물 기능 독립 평가

실험 설계

통제된 비교: 세 가지 검색 메커니즘

물리적 자극매개

에이전트가 세계를 수정하고, 다른 에이전트가 물리적 관찰을 통해 재사용. 통신 불가

가장 기본적 조건

문화적 메커니즘 포함

물리적 자극매개 + 에이전트 간 명시적 통신, 가르침, 요청

전체 SwarmWorld

독립 탐색 (Best-of-N)

동일 연산량의 개별 에이전트가 독립적으로 탐색, 최고 성능만 선택

강력한 베이스라인

800 틱 단기 실험 + 3,200 틱 장기 실험 / 동일 연산 예산 정합

핵심 결과 1

공유 사회 vs 독립 탐색

기술 포트폴리오 다양성

공유 사회가 더 넓고 회복력 있는 기술 포트폴리오 개발

  • 다양한 성능 수준에 걸쳐 균형 잡힌 분포
  • 단일 실패점에 대한 선택적 취약성 분석 가능

최고 개별 산출물

최강 산출물 하나에 대해서는 독립 탐색이 여전히 경쟁력 보유

  • Best-of-N이 단일 최고점 탐색에 효율적
  • 그러나 장기 호라이즌에서 격차 축소

상호작용의 가치는 "가장 강한 개별 발명"이 아니라 "기능적으로 강한 기술 생태계"에 있음

핵심 결과 2

자발적 역할 분화

초기 동질적 에이전트가 사전 할당 없이 세계의 성숙도에 따라 역할 전환

탐색

초기 단계: 자원 발견, 지도 확장

건설

중기: 산출물 조립, 아키텍처 설계

유지보수

후기: 기존 산출물 수정·개선

조정

전 기간: 정보 교환, 요청 중개

역할은 고정된 정체성이 아니라 동적 상태 — 에이전트는 세계 상태에 따라 행동 패턴 전환

핵심 결과 3

기술 누적 메커니즘

물리적 관찰 기반 재사용 주요 경로

대부분의 기술 재사용은 통신이 아닌 세계에 존재하는 산출물을 직접 관찰하는 것에서 시작

실행 가능한 상속

이전 에이전트가 작성한 컨트롤러 코드를 후속 에이전트가 복사·수정하여 새 산출물에 적용

지속적 에이전트-산출물 네트워크

기술 계보가 모듈화되고 확산적이며, 선택적 취약성을 보이는 네트워크 형성

분산 요청의 지속적 가르침화

일회성 대화 요청이 물리적 거래나 지속적 교육 행위로 변환되는 문화적 전이 관찰

핵심 결과 4

물리적 자극매개 vs 문화적 메커니즘

측면 물리적 자극매개만 문화적 메커니즘 포함
기본 기능성 유능한 사회 지원 유능한 사회 지원
조직화 수준 제한적 협업·조직 증폭
기술 생태계 개별 수준에 머묾 지속적 생태계 구축
보편적 우위 — 결과·시간척도에 의존

"물리적 자극매개만으로도 유능한 사회가 가능하지만, 상호작용은 개별 발명의 보편적 우위가 아닌 지속적 기술 생태계를 구동"

일반화

도메인 전이 가능성

화산 재료 세계

완전히 다른 재료 체계(화산성 물질)로 세계를 재구성

  • 동일 아키텍처가 새로운 도메인에서도 작동
  • 집단 조직 패턴 재현
  • 기술 생태계 형성 확인

서열 정의 단백질 생체재료

아미노산 서열 기반 단백질 설계로 확장

  • 서열-구조-기능 관계 탐색
  • 에이전트 간 서열 상속 및 수정
  • 실제 생체재료 설계에의 적용 가능성

세계 아키텍처가 특정 재료에 종속되지 않고 다양한 설계 도메인으로 전이 가능함을 시사

종합

시사점과 결론

핵심 발견

  • 초기 동질적 LLM 에이전트가 자발적 기술 사회 형성
  • 공유 세계가 더 넓고 회복력 있는 기술 포트폴리오 산출
  • 역할 분화가 고정이 아닌 동적 상태로 발생
  • 재사용의 주요 경로는 통신이 아닌 물리적 관찰
  • 물리적 자극매개만으로 유능한 사회 가능

방법론적 기여

  • 인지-결과 분리: 에이전트 주장과 독립적 기능 평가
  • 정합된 Best-of-N 베이스라인으로 상호작용의 순수 효과 측정
  • 물리적·문화적 검색 메커니즘의 분리 통제
  • 도메인 전이 가능한 세계 아키텍처

"다중 에이전트 시스템의 목표는 가장 강한 개별 발명이 아니라, 그 자체로 적응적이고 지속적인 기술 생태계를 구축하는 것"
