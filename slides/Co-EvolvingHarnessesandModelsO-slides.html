  • 서브 에이전트

모든 태스크는 객관적으로 검증 가능

발견 1: 진화된 Harness는 상향 전이된다

  • 약한 모델을 위해 진화시킨 Harness를 강한 전문가 모델이 손쉽게 활용
  • 전문가는 진화된 Harness에서 모든 태스크에서 약한 모델을 능가
  • 전문가 자신의 기본 Harness 성능과 비교해도 동등하거나 더 뛰어남

시사점 A

진화된 Harness는 모델 백본을 넘어 전이 가능

시사점 B

약한 모델이 아직 실현하지 못한 모델 측 여유 공간(headroom)을 드러냄

자연스러운 다음 단계: 전문가를 모방해 약한 모델이 격차를 좁히도록 학습?

발견 2: 전문가 모방은 역효과를 낸다

재현성

대조 결과

실패의 원인은 모방 자체가 아니라, 모방과 Harness 진화의 상호작용에 있다

계획 전략 적합성

붕괴 ← 진짜 원인

전문가의 전략을 따라함

약한 모델은 전문가의 계획 전략을 모방했지만 그것을 실행할 역량이 없고, 자신의 원래 계획 스타일에 맞춰 진화한 Harness와 더 이상 맞지 않게 된다

해결책: On-Policy 전문가 교정

1
롤아웃 생성
약한 모델이 자신의 방식으로 태스크 수행
2
실패 국소화
메타 MLE 에이전트가 롤아웃에서 실패한 턴을 찾아냄
3
국소 교정
전문가가 해당 턴만 재작성 (Best-of-N 선택)
4
SFT
모델의 계획 스타일을 보존한 채 학습

핵심 아이디어

전체 궤적 모방이 아닌, 학생 모델이 실제 방문한 상태에서 국소적 교정만 제공

자동화

메타 수준 MLE 에이전트가 파이프라인을 엔드투엔드로 자동화

결과: Harness 진화 + 모델 적응의 결합 성공

접근법진화 전 Harness진화된 Harness결과
전문가 궤적 모방 (SFT-imit.) 성능 향상 −4 ~ −30충돌 발생
On-Policy 교정 (SFT-corr.)— 추가 향상두 레버 결합 성공
  • 진화된 Harness의 이득 위에 모델 측 추가 이득 확보
  • Harness 진화와 모델 가중치 적응이 서로를 방해하지 않고 결합
  • 업데이트된 모델이 다음 라운드의 Harness 진화에 재진입 가능한 공동 진화 루프 구성

실무자를 위한 설계 원칙

Harness 진화 이후에는, 강한 모델의 궤적을 전체 모방하는 대신 학생 모델이 방문한 상태에서 On-Policy 감독을 제공하라

1

Harness 먼저 진화

약한 모델 중심으로 스캐폴드 최적화

2

적합성 보존

가중치 업데이트는 모델–Harness 적합성을 깨지 않도록

3

반복적 공동 진화

경제적으로 Harness와 모델을 함께 발전

결론

  • 상향 전이: 진화된 Harness는 모델을 넘어 전이되며 모델 측 여유 공간을 드러냄
  • 모방의 함정: 진화된 Harness 하 전체 궤적 모방은 계획 전략 표류로 7개 태스크 모두 악화
  • On-Policy 교정: 국소적 전문가 교정이 충돌을 해결하고 공동 진화 루프를 가능하게 함
