기계적 해석 가능성(Mechanistic Interpretability)의 현재와 AI 안전

신경망은 인류 역사상 가장 중대한 산출물이 될 것입니다.
그 내부에서 무엇이 일어나고 있는가?

왜 기계적 해석 가능성인가?

1

성능과 자율성 증가
AI 시스템이 강력해질수록 사회적 위해 가능성도 함께 성장

2

블랙박스의 한계
외부 행동만 관찰해서는 내부 메커니즘을 알 수 없음

3

안전 보장의 필요
AI 안전은 우리 시대의 핵심 과제 — 내부 이해가 전제 조건

"해석 가능성은 모델의 내부에서 무엇이 일어나는지 거꾸로 역설(reverse-engineer)하는 분야다"

행동 평가의 네 가지 한계

  • 테스트 세트 오염·포화 — 벤치마크 점수가 실제 능력을 과대평가
  • 벤치마크 게이밍 — 모델이 정답이 아닌 '잘못된 메커니즘'으로 문제를 학습할 수 있음
  • 평가 인지(evaluation awareness) — 모델이 평가 중임을 감지하고 행동을 바꿀 수 있음
  • 미세 제어 불가 — 특정 능력·지식·행동을 정밀하게 조작할 수 없음

결론: 신뢰할 수 있는 AI 안전을 위해서는 내부 메커니즘 수준의 이해가 필요하다

핵심 기초 개념

뉴런 다의성 (Polysemanticity)

하나의 뉴런이 서로 무관한 여러 개념에 반응 — 개별 뉴런을 인간이 읽기 어려운 이유

피처 (Feature)

모델 표현의 기본 단위. 방향(direction)으로 표현되며 개념에 대응하는 것이 이상적

어텐션과 트랜스포머 연산

Q·K·V 구조, 헤드 단위의 정보 이동이 회로 분석의 대상

회로 (Circuit)

특정 행동을 만들어내는 피처·헤드·MLP의 연결 구조 — 내부 메커니즘의 설계도

기계적 해석 가능성의 4대 가설

가설핵심 주장함의
선형 표현 가설 개념이 활성 공간의 선형 방향으로 인코딩됨 피처를 방향으로 찾고 조작 가능
중첩 가설 피처 수가 뉴런 수를 초과, 거의 직교하는 방향에 압축 저장 다의성의 원인 설명 → SAE 필요성
특권 접근 가설 모델은 자신의 내부 상태에 더 '쉬운' 접근을 가짐 내성적(introspective) 방법의 근거
보편성 가설 서로 다른 모델이 유사한 표현 구조로 수렴 (플라톤적 표현) 한 모델의 지식이 일반화될 수 있음

희소 오토인코더 (SAE): 피처 추출의 핵심 도구

작동 원리

활성값을 더 높은 차원의 희소 공간으로 인코딩 후 복원. 희소성 제약으로 중첩된 피처를 분리하여 단의성(monosemanticity) 확보

변형 아키텍처

JumpReLU, TopK, BatchTopK, Matryoshka SAE, Gated SAE 등 — 목적·계층·자원·모델 규모에 따라 선택

주요 실패 모드

죽은 피처 학습에 기여하지 않는 피처 다수 발생

피처 흡수·분할 개념이 하나의 피처로 정리되지 않음

시드 불안정성 학습마다 다른 피처 집합 도출

계층을 넘는 피처 분석: 트랜스코더와 크로스코더

SAE

단일 계층의 활성값 해석. 비선형성은 다루지 못함

트랜스코더

MLP의 비선형 연산을 입력→출력 매핑으로 근사. 대체 모델 구축에 활용

크로스계층 트랜스코더 (CLT)

여러 계층에 걸친 피처로 전체 회로 분석 가능 — 어트리뷰션 그래프의 기반

크로스코더는 여러 모델 간의 공통·고유 피처를 비교 — 모델 diffing에 활용

사례: 유도 헤드(Induction Head) — 문맥 내 학습(in-context learning)을 담당하는 대표적 회로

중간 표현 들여다보기: 다양한 렌즈 기법

기법접근 방식한계
Logit Lens 중간층 활성에 최종 unembedding을 바로 적용 중간층 표현과 최종층의 부조화
Tuned Lens 층별 변환을 학습하여 번역 학습 비용, 층별 학습 필요
Patchscopes 모델 자신에게 중간 표현을 설명하도록 요청 설명의 신뢰성 검증 필요
Probing 분류기 감독 학습으로 표현에서 정보 판별 probe가 지나치게 복잡하면 인과적 의미 상실

암네스틱 프로빙(amnesic probing)·인과적 프로빙으로 정보의 실제 사용 여부까지 검증해야 함

학습 동태와 훈련 데이터 귀속

학습 동태 (Learning Dynamics)

  • 피처 형성·통합·드리프트의 시간 추적
  • 능력의 급격한 출현 — 위상 전이(phase transition) 탐지
  • 내부 전조(precursor)로 위험 행동 조기 경보

훈련 데이터 귀속 (TDA)

  • OLMoTrace — 출력과 일치하는 학습 문서의 최대 매칭 스팬 추적
  • 그래디언트 기반 — EK-FAC, TracIn, TRAK로 데이터 영향 추정
  • 유해 출력의 출처 추적, 저작권·데이터 오염 감사에 활용

6가지 연구 지향

실용적 (Pragmatic)

안전 개입을 위한 프록시 과제 중심 — 단기적·목표 지향적

야심적 (Ambitious)

모델의 완전한 기계적 이해 추구 — 장기·고위험·고보상

발달적 (Developmental)

훈련 과정에서 모델이 어떻게 학습되는지 특성화

시간축 해석

행동의 '원인'을 시간상 위치 — 추론 시점 vs 학습 시점 구분

내성적 (Introspective)

모델이 스스로를 보고하되, 혼란스러워하기(confabulation)·전략적 허위 보고에 주의

자동화된 해석

AI로 해석을 확장하되 오류 전파·자동화 편향 등 5계층 가드레일 필요

지향 간 트레이드오프 존재 — 안전 목표와 자원에 따라 의사결정 프레임워크로 선택

이해에서 개입으로: 안전 응용

1
개념 소거
PISCES — 피처 분리 → MLP 벡터 선택 → 개념 제거로 유해 지식 삭제
2
지식 편집
인과 추적으로 사실 저장 위치를 찾고 rank-one 편집으로 수정
3
조종 벡터
활성값에 벡터를 더해 행동을 실시간 제어
4
기계적 모니터링
기만·은닉 행동의 내부 신호를 감시

기계적 해석 가능성은 단순한 진단 도구가 아니라, 예측·감시·개입을 가능하게 하는 안전 인프라다

결론: 내부 이해가 안전의 출발점

성과

  • SAE 등으로 피처·회로 수준 분석이 실용화
  • 개념 소거·조종·데이터 귀속 등 안전 응용 실증

남은 과제

  • 표준화된 평가 체계 부재 — 5차원 평가 프레임워크 제안
  • 전체 모델 규모로의 확장성과 자동화의 신뢰성
