Computer-Use Agents Are Embodied Generalists

컴퓨터 사용 에이전트는 이미 구현된 체화된 범용가입니다

Pranjal Aggarwal, Sean Welleck  ·  Carnegie Mellon University

arXiv: 2611.09847

배경: AI의 대전환이 반복되고 있다

많은 AI 분야에서 범용 모델이 손으로 만든 방법과 특화 아키텍처를 점차 대체해 왔습니다.

텍스트·코드

컴퓨터 사용

CUA가 특화 도구 없이 모든 소프트웨어를 조작

Embodied AI

이제 이 전환의 한복판에 서 있습니다

저자들은 embodied AI가 이와 같은 전환을 맞이할 준비가 되었다고 주장합니다.

핵심 통찰: 체화된 작업 = 소프트웨어와의 상호작용

핵심 주장 — 체화된(embodied) 작업은 디지털 소프트웨어와의 상호작용으로 공식화될 수 있습니다.

1
소프트웨어 구축
물리 환경의 관찰을 화면에 렌더링
2
제어 제공
환경에서 행동할 수 있는 조작 인터페이스 제공
3
CUA가 수행
스크린샷 + 키보드·마우스로 체화된 작업 실행

물리 환경이 소프트웨어로 노출되면, 그것은 같은 에이전트를 위한 또 하나의 인터페이스가 됩니다.

왜 가능한가? 공통된 과제들

컴퓨터 조작과 물리 환경에서의 행동은 겉보기와 달리 유사한 도전 과제를 공유합니다.

시각적 그라운딩

화면 혹은 장면에서 목표물을 정확히 찾아내기

탐색

익숙하지 않은 환경을 능동적으로 살펴보기

피드백 기반 행동 조정

환경의 반응을 관찰하고 다음 행동을 수정하기

  • 작업별 기능은 에이전트가 아니라 소프트웨어에 존재
  • 특화 모델 개발 없이 기존 CUA를 다양한 embodied 작업에 재사용 가능

방법론: 하나의 공유 CUA 설계

에이전트 루프

  • 소프트웨어가 스크린샷 등 시각 관찰 (ot) 제시
  • 에이전트가 키보드/마우스 행동 (at) 선택
  • 소프트웨어가 행동 실행 후 갱신된 관찰 반환
  • Submit 버튼을 누르면 결과 내보내기

설계 세부사항

  • Gemini 3.5 / 3.6 Flash 기반
  • 4개 소프트웨어에 동일한 에이전트·시스템 프롬프트·행동 공간
  • 한 번에 최대 16개 입력 배치 실행
  • 컨텍스트 관리: 가장 오래된 스크린샷 10개 제거, 참조·오버레이 영상은 유지

대회별 튜닝 없음 — 모든 대회에서 변경된 것은 오직 소프트웨어뿐입니다.

4개 대회를 위한 4개 소프트웨어

같은 CUA가 키보드와 마우스만으로 4개의 서로 다른 인터페이스를 조작합니다.

VLN·비전-언어 내비게이션

VLNVerse

3D 장면 뷰어 + 1인칭 이미지. 이동·회전 조작으로 언어로 묘사된 목적지까지 탐색

대화 기반 내비게이션

DialNav

360° 파노라마 + 번호가 매겨진 출구 + Guide와의 메시지 패널. 대화를 통해 목적지 도달

언어 기반 3D 분할

OpenSUN3D

컬러 포인트 클라우드 렌더러. 자유 카메라 이동 후 해당 부품(예: 서랍 손잡이) 클릭 → 3D 마스크 생성

지칭 영상 분할

MeViSv2

객체 선택과 트랙 검토 인터페이스. 언어 지칭에 해당하는 영상 내 객체 분할

공유된 에이전트 설계 하나로 다양한 embodied 작업에서 강력한 성능을 달성 — 스크린 조작 스킬이 체화된 작업으로 이전됨을 보여줍니다.

시사점: 2년 전 컴퓨터 사용의 현재, embodied AI의 현재

2년 전의 컴퓨터 사용 에이전트 오늘의 embodied AI (VLA)
정밀한 클릭에 어려움을 겪고 오버레이·별도 그라운딩 모델에 의존 연속 제어를 위해 전용 액션 헤드 추가
작업 특화 API 에이전트에 크게 뒤처짐 특화 파이프라인에 의존하는 구조
오늘: 코드·수학을 푸는 같은 모델이 좌표를 일반 텍스트로 작성해 컴퓨터 조작 목표: 화면 조작과 API가 동등한 성능 — 이미 CUA에서는 달성됨

CUA의 발전을 이끈 3가지 — 정밀 그라운딩 학습, 강화학습 환경, 실시간 추론 속도 — 는 모두 embodied AI에 직접 대응됩니다.

입장(position): CUA는 Embodied Generalist다

이미 증명된 것

  • CUA가 소프트웨어에서 학습한 스킬(시각 그라운딩, 정밀 클릭, 탐색)이 embodied 작업으로 이전
  • CUA의 embodied AI에서의 활용 범위가 기존 인식보다 훨씬 넓음

향후 경로

  • 시뮬레이터로 그라운딩 데이터를 대규모 생성
  • embodied 환경을 강화학습에 활용
  • 빠른 추론으로 실시간 제어 달성

소프트웨어를 통한 노출 덕분에 CUA의 진보는 embodied AI로 직접 이전되며, embodied 작업은 미래 범용 에이전트의 학습 데이터의 일부가 될 수 있습니다.

결론

1
공식화
체화된 작업을 소프트웨어 상호작용으로 변환
2
검증
하나의 CUA로 4개 대회 수상 (1·2·3·6위)
3
수렴
컴퓨터 사용의 길을 따라 단일 범용 모델로

컴퓨터 사용이 그랬듯이, embodied AI도 단일 범용 모델로 수렴할 것입니다 — 범용 embodied AI의 새로운 시대가 열립니다.
