LeapQuant

정확한 순환 상태 양자화를 통한 고효율 선형 어텐션

Yi Pan*, Haocheng Xi*, Kan Zhu, Xingyang Li, Yibo Wu, Mayank Mishra, Hongtao Zhang, William X. Zheng, Baris Kasikci, Song Han, Kurt Keutzer, Rishabh Iyer, Ion Stoica

UC Berkeley · University of Washington · MIT · Perplexity AI · NVIDIA

Training-Free 8-bit 근접 무손실 커널 최대 3.70× 가속

배경: 선형 어텐션과 순환 상태

최신 LLM(Qwen·Kimi·GLM 계열)은 대부분의 어텐션 레이어를 Gated DeltaNet(GDN)이나 Kimi Delta Attention(KDA) 같은 선형 어텐션으로 대체한 하이브리드 구조를 채택

St = Diag(αt) St−1 + kt (vt − St−1⊤ βt)⊤,    ot = St⊤ qt

고정 크기 순환 상태

토큰 이력 전체를 고정 크기 상태 행렬로 압축 → 긴 컨텍스트에서 계산·메모리 증가 없이 효율적 처리

매 디코딩 스텝 상태 갱신

HBM에서 상태 로드 → 경량 업데이트 → 토큰 출력 계산 → 갱신된 상태를 HBM에 저장하는 과정을 매 토큰마다 반복

문제: 순환 상태 접근이 추론의 주요 병목

디코딩 시간 병목

업데이트·출력 계산은 연산량이 적고 전송 바이트가 많아 HBM 대역폭에 병목. 여러 선형 어텐션 레이어와 동시 요청의 상태 읽기·쓰기가 디코딩 시간의 상당 부분 차지

메모리 공간 부담

Prefix caching 활성화 시 서빙 시스템이 캐시된 prefix마다 별도의 상태를 유지 → GPU 메모리 사용량 대폭 증가

상태 양자화는 메모리 트래픽과 점유 공간을 동시에 줄이는 자연스러운 해법이지만, 모델 품질을 유지하며 낮은 비트로 양자화하는 것은 어려움

도전: 양자화 오류의 두 가지 원인

오류 1 재귀적 오류 누적

각 업데이트가 이미 양자화된 상태에서 시작하고, 결과를 다시 양자화할 때마다 반올림 오류가 추가 → 긴 생성 과정에서 상태가 FP32 궤적에서 점진적으로 이탈. 긴 사고(thinking) 과정에서 특히 심각

오류 2 이상치(Outlier)

큰 이상치가 상태의 일부 행·열에 집중 → 양자화 범위가 넓어지고 작은 값들이 거친 양자화 레벨에 배정되어 매 양자화마다 오류 증폭

정확한 저비트 양자화의 조건: 오류 도입 빈도 ↓ + 매 양자화의 오류 크기 ↓

LeapQuant: 학습 없이 8-bit 근접 무손실 실현

Training-Free 캘리브레이션 데이터 불필요 — 오류의 두 원인을 각각 겨냥한 세 가지 설계

1
윈도우 단위 양자화
토큰 윈도우를 건너뛰어(leap) 양자화를 윈도우당 1회로 제한 → 오류 누적 완화
2

3

아이디어 1: 윈도우 단위 양자화 (Per-window Quantization)

1
윈도우 시작

순환 상태를 저정밀(8-bit)로 저장하고 윈도우 내내 고정

2
윈도우 내부

토큰 업데이트는 더 높은 정밀도의 버퍼에 저장, 각 출력은 고정된 저비트 상태 + 버퍼된 업데이트로 계산

3
윈도우 끝

버퍼에서 전체 상태를 재구성한 뒤 단 1회 양자화하여 다음 윈도우로 전달

토큰마다 재양자화하는 대신 윈도우당 1회만 양자화 → 양자화 오류가 도입되는 빈도 자체를 줄여 긴 컨텍스트에서 누적 지연

아이디어 2: Compensator Tokens

상태의 가장 큰 이상치들을 소수의 고정밀 토큰으로 보존하여 매 양자화의 오류를 감소

랭크-1 외적 구조

각 Compensator Token은 두 벡터의 외적(랭크-1 항)으로, 행·열 양쪽의 큰 크기 패턴을 동시에 포착 → 남는 잔차가 양자화하기 쉬워짐

기존 갱신 경로 재사용

실제 토큰 업데이트와 동일한 형태이므로 윈도우의 업데이트 경로에 그대로 통합 — 추가 벡터 몇 개만 필요하고 별도의 상태 갱신 경로가 없음

  • 이상치가 양자화 범위를 넓히는 문제를 고정밀 성분으로 흡수
  • SVDQuant·KVQuant 계열의 이상치 격리 아이디어를 순환 상태에 맞게 재설계

아이디어 3: 잔차 스무딩 (Residual Smoothing)

채널 간 평활화

Compensator Tokens로 이상치를 제거한 뒤 남은 잔차를 채널 방향으로 스무딩하여 값 분포를 균일하게 만듦

오류 추가 절감

스무딩된 잔차를 양자화하면 매 양자화마다 발생하는 오류를 추가로 축소 → 8-bit에서 근접 무손실 달성의 마지막 조각

오류 도입 빈도 감소(윈도우 양자화) + 오류 크기 감소(Compensator Tokens + 스무딩) = 두 오류 원인을 동시에 해결

실험 설정

모델

Qwen · Kimi · GLM 계열의 GDN/KDA 하이브리드 모델, 총 12개 모델–태스크 쌍에서 다운스트림 태스크 평가

하드웨어

NVIDIA B200, RTX PRO 6000, RTX 5090 3종 GPU에서 커널·디코드·엔드투엔드 성능 측정

비교 대상

FP32 기준선과 비교, 8-bit 순환 상태 양자화. 학습도 캘리브레이션도 전혀 사용하지 않음

  • 정확도: 다운스트림 태스크 + 저비트(8-bit 이하) 설정에서 평가
  • 효율성: 커널 속도, 디코드 속도, 메모리 절감, 엔드투엔드 추론 속도 측정
  • 절제 실험: 각 설계 요소별 기여, 윈도우 길이, Compensator Token 수 분석

절제 실험: 각 설계가 모두 기여

설계 요소별 효과

윈도우 양자화 · Compensator Tokens · 잔차 스무딩 각각이 정확도 회복에 기여하며, 조합 시 FP32 수준 도달

윈도우 길이

윈도우가 길수록 양자화 횟수가 줄어 누적 오류는 감소 — 효율과 정확도의 균형점에서 운용

Compensator 수

소수의 Compensator Tokens만으로 이상치의 대부분을 포착, 추가 오버헤드는 미미

핵심 메시지: 순환 상태의 구조(윈도우 경계 + 랭크-1 갱신)를 활용하면 학습 없이도 정확한 저비트 양자화가 가능

결론

  • 선형 어텐션의 순환 상태 읽기·쓰기가 LLM 서빙의 주요 병목 (대역폭 + 메모리)
  • 윈도우 단위 양자화로 오류 도입 빈도를 줄여 재귀적 누적 완화
  • Compensator Tokens + 잔차 스무딩으로 매 양자화의 오류 최소화
  • 학습·캘리브레이션 없이 FP32급 정확도에서 상태 트래픽 3.4× 감소, 커널 2.05–3.70× · 엔드투엔드 1.47× 가속
