기존 물리학 벤치마크의 한계

교과서 수준 질문

고정된 질문들로 구성되어 모델이 빠르게 포화(saturation)되어 벤치마크의 신호가 사라짐

고립된 하위 과제

과학 워크플로우의 개별 작업만 평가하며 전체 연구 능력을 측정하지 못함

논문 재현 방식

원본 논문이 제공되어 연구 질문과 솔루션 구조가 사전에 명시됨 → 개방형 탐구 평가 불가

핵심 문제: 기존 벤치마크는 정답 여부만 확인하고 연구 품질(research quality)을 함께 평가하지 않음

솔루션을 숨긴 연구 문제 변환 방식도 있으나, 개방성 유지와 거짓 판정 방지 등 원저자의 전문성이 필요한 미묘한 판단이 요구됨

FrontierPhysics 개요

활동 중인 물리 연구자들이 자신의 연구를 기반으로 제작한 종단간 벤치마크

과제 설계: PI의 지시처럼

각 과제는 연구 프로젝트 시작 시 PI(지도교수)가 제공하는 수준의 고수준 프롬프트로 구성

고수준 프롬프트 입력

연구 목표와 방향만 제시 — 구체적인 풀이 방법이나 정답 구조는 제공되지 않음

개방형 연구 프로세스

주제 조사 → 연구 계획 수립 → 적절한 방법 선택 → 결과 검증 → 발견의 중요성 확립

이중 산출물 요구

과학 원고(논문) + 결정론적으로 검증 가능한 수치 출력물을 모두 제출해야 함

텍스트북 문제가 아닌 실제 연구의 출발점에서부터의 전 과정을 평가

과제 큐레이션과 품질 검수

개방성을 유지하면서 거짓 음성/양성을 최소화하기 위한 다단계 수동 검수

검수가 해결하는 문제

  • 지시문이 개방성을 유지하는가
  • 거짓 음성(잘못된 불통과) 방지

원저자 전문성의 역할

  • 실패가 진짜 이해 부족인지 판별
  • 전문가 직관 부족과의 구분

평가 방법론: 정확성 + 게재 가능성

결정론적 검증기 (Deterministic Verifier)

테스트 스크립트가 에이전트의 수치 출력물을 자동으로 검사

객관적·재현 가능한 정확성 판정

결과가 수학적·물리적으로 맞는지 확인

전문가 루브릭 채점 (Rubric Grading)

검토자(reviewer) 에이전트가 도메인 전문가가 작성한 루브릭으로 원고 평가

연구의 질적 측면 평가

원고가 게재 가능한 수준인지 판단

통과 조건: 모든 검증기 테스트 + 블로커(blocker) 루브릭을 모두 통과해야 Pass@1 인정

FrontierPhysics는 완전 에이전틱(agentic)·원저자 제작·원고 품질+결과 정확성 동시 채점·수동 검수와 실패 모드 분석을 모두 갖춘 유일한 벤치마크

실패 모드 분석: 에이전트는 왜 실패하는가

관리자 팀과 기여자들이 GPT-6 Astra의 168개 롤아웃 궤적과 출력 원고를 수동 검토

실제 주요 약점

  • 불충분하게 엄격한 추론 — 가정 검증과 논리적 정밀성 부족
  • 제한된 전문가 직관 — 숙련 연구자가 감으로 판단하는 부분에서 취약

문제가 아니었던 것

  • 물리학 지식 자체의 격차는 아님
  • 단순한 실행(execution) 오류도 아님

시사점: 진전을 위해서는 더 많은 지식 주입이 아니라 연구자 수준의 엄격한 추론 습관과 전문가적 직관이 필요

결론

기여 1: 새로운 평가 패러다임

물리학자가 자신의 연구에서 제작한 56개 과제로, 문헌 조사부터 원고 작성까지 종단간 연구 능력 평가

기여 2: 정확성 + 품질 동시 채점

결정론적 검증기와 전문가 루브릭을 결합해 올바르면서도 게재 가능한 연구만 통과 인정

기여 3: 현 수준의 정밀 진단

22개 모델·26개 구성·4,364 롤아웃 평가 결과, 최고 구성도 168 롤아웃 중 46개 이상 통과 못함

기여 4: 실패 원인의 규명

지식이나 실행이 아닌 추론의 엄격성과 전문가 직관이 핵심 병목임을 수동 분석으로 밝힘
