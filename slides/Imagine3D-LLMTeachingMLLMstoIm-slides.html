Imagine3D-LLM

MLLM에게 답하기 전에 3D 장면을 상상하도록 가르치다

Teaching MLLMs to Imagine 3D Scenes Before Answering

  • KAIST AI · ETH Zürich · Google · TUM
  • Jaewoo Jung, Hyeonseo Yu, Honggyu An 외 · Federico Tombari, Marc Pollefeys, Seungryong Kim, Sunghwan Hong 등

문제: MLLM은 다중 뷰에서 3D를 이해할 수 있을까?

단일 이미지 입력

현대 MLLM은 단일 이미지 해석에서 인간 수준에 도달하거나 능가하는 성능을 보임

다중 뷰 이미지 입력

여러 시점의 증거를 통합해 일관된 3D 이해를 구축하는 데는 가장 큰 모델조차 인간 수준에 크게 미달

멀티뷰 3D 추론은 로봇공학 · Embodied AI · AR/VR · 장면 이해의 기반이 되는 근본 과제

기존 접근법과 한계: 픽셀 단위 3D 신호 주입

시점 간 픽셀 대응 강화

  • 포인트클라우드 3D 좌표를 패치 특징에 삽입 (Video-3D LLM, LLaVA-3D)
  • BEV 마커 시각화 (GPT4Scene), 시점 간 재구성 pretext (Ross3D)
  • 대응 관계 감독 기반 특징 증류 (3DRS)

3D 파운데이션 모델 융합

CUT3R · VGGT 등 3D 재구성 파운데이션 모델의 기하학 인지 feature를 MLLM 이미지 특징과 융합 (VLM3R, G²VLM, 3DThinker)

두 계열 모두 정교한 픽셀 단위 신호에 의존하지만 얻는 향상은 미미 — 인간 수준 추론과의 격차는 여전히 큼

영감: 인간은 어떻게 3D를 인식하는가?

인지과학 연구에 따르면, 인간은 픽셀 단위 대응 관계나 조밀한 depth map을 머릿속에 유지하지 않는다

1
여러 뷰에서 공통 객체를 식별
2
객체를 앵커 삼아 시점 간 대략적인 공간 관계 추론
3
장면의 컴팩트한 3D 배치를 머릿속에 조립

가설: 추론을 지지하는 표현은 픽셀 정밀한 것이 아니라 객체 수준의, 근사적인 표현이다

핵심 아이디어: 답하기 전에 상상하기

Imagine3D-LLM은 답변 생성 전에 장면의 컴팩트한 3D 재구성을 스스로 조립하고, 이 표현 위에서 추론

  • 이미지 토큰 뒤에 소수의 학습 가능한 Gaussian 요약 토큰 부착
  • 요약 토큰을 3D Gaussian Splatting(3DGS) 파라미터로 디코딩 — 각 토큰이 장면 일부를 설명하는 Gaussian 군집에 대응
  • 광도(photometric) 재구성 손실 + 표준 next-token prediction 손실로 공동 학습

"장면을 상상하는 것이, 픽셀 단위 기하학을 주입받는 것보다 효과적일 수 있다"

전체 아키텍처

1
다중 뷰 입력
여러 시점의 이미지
2
토큰화
이미지 토큰 + Gaussian 요약 토큰
3

5
렌더링 · 손실
광도 재구성 + 언어 모델링

출력 1: LLM이 3D 표현을 조건으로 텍스트 답변 생성

출력 2: 디코딩된 3DGS 렌더링으로 재구성 감독 부여

핵심 설계 선택 2가지

설계 1

이미지 특징이 아닌 요약 토큰에서 Gaussian 예측

이미지 특징에서 직접 예측하면, 모델이 기하학을 복원하는 대신 2D 내용을 이미지 정렬 Gaussian으로 복사-붙여넣기하는 지름길을 학습할 위험

전용 요약 토큰 경유로 하부 3D 기하학의 실질적 복원을 강제

설계 2

정보 병목: 이미지 토큰보다 적은 요약 토큰

토큰 수 제한으로 뷰 간 중복 콘텐츠가 공유 토큰 세트로 병합되어야만 재구성 가능

모델이 어떤 객체가 여러 뷰에 반복 등장하는지, 통합 3D 배치에서 어떻게 맞물리는지 추론하도록 유도

학습 목적함수와 컴팩트 Gaussian Teacher 증류

손실 항목역할
Next-token prediction표준 언어 모델링 — 질의응답 능력 유지
광도 재구성 손실렌더링된 3DGS가 입력 뷰를 재현하도록 — 3D 구조 학습
증류 손실컴팩트 Gaussian Teacher의 표현으로 수렴 가속
  • 컴팩트 Gaussian Teacher: feed-forward 3DGS 계열(C3G에서 영감)의 사전학습 모델
  • 증류는 학습 초기의 안정화와 수렴 가속에 기여

분석: 재구성 학습이 모델 전체를 재편한다

재구성 감독은 요약 토큰에만 직접 주어지지만, LLM 내부의 이미지 특징 자체가 3D 인지적으로 변화

시점 간 Attention 날카로워짐

대응하는 이미지 특징 간 cross-frame attention이 더 선명해져 픽셀 수준 대응이 암묵적으로 강화

의미적 조직화 (PCA 분석)

같은 객체가 서로 다른 뷰에서 일관되게 인코딩 — 이미지 특징이 객체 중심으로 재조직화

요약 토큰은 병목에 의해 객체 단위로 자발적 그룹핑 — 장면을 상상하라는 요구가 LLM 전체에 3D 인지 신호를 전파

실험: 7개 벤치마크에서 일관된 최고 성능

7

공간 추론 + 3D 장면 이해 벤치마크

ScanNet 기반

3D 질의응답·그라운딩 등 실내 장면 이해 태스크

SPAR-Bench

멀티뷰 공간 추론 능력 평가

  • Video-3D LLM, LLaVA-3D, GPT4Scene, Ross3D, VLM3R, G²VLM 등 기존 3D 인지 MLLM 대비 일관되게 우위
  • 추가 모듈이나 픽셀 단위 3D 신호 없이 추상적 장면 재구성만으로 달성한 결과

절삭 연구: 무엇이 성능 향상을 만드는가

요인발견
베이스라인 통제 비교동일 조건 멀티뷰 MLLM 대비 명확한 향상 확인
Gaussian 디코딩 층 선택LLM의 어느 층에서 디코딩하느냐가 성능에 영향
증류 효과수렴 가속 및 안정적 학습에 기여
향상 원인 격리성능 향상은 재구성 학습 자체에서 비롯됨을 검증
요약 토큰 수컴팩트함(병목)과 표현력 간 트레이드오프 존재

결론

  • 인간의 공간 추론을 재해석 — 객체 식별 → 관계 추론 → 컴팩트 3D 배치 조립의 과정을 MLLM에 이식
  • Gaussian 요약 토큰 + 3DGS 디코딩 + 광도 재구성 손실로 답변 전 장면 상상을 학습
  • 재구성 감독이 이미지 특징 전반에 3D 인지 신호를 전파 — 시점 간 대응과 객체 중심 표현이 창발
  • 7개 벤치마크에서 기존 방법을 일관되게 능가 — 추상적 장면 재구성은 강력한 귀납적 편향

픽셀 단위 기하학을 주입받는 것보다 장면을 상상하는 것이 더 효과적이다
