토큰 수준 교정을 통한 LLM·에이전트 온폴리시 정렬 데이터 효율적 어노테이션

Efficient Annotation of On-Policy Alignment Data for LLMs and Agents via Token-Level Correction

Lei Yang, Mengyin Liu, Jia Wang, Hangyu Guo 외 · StepFun / Xiamen University

문제 상황: 고품질 정렬 데이터가 병목이다

높은 어노테이션 비용

SFT용 응답을 직접 작성하거나 수동 후편집하는 것은 인지적·타이핑 부담이 크고 시간이 많이 소요됨

오프폴리시 데이터

인간이 직접 쓴 응답은 롤아웃 모델의 분포에서 벗어나(on-policy fidelity 저하) 학습 신호가 왜곡될 수 있음

조악한 감독 신호

선호 데이터는 응답 수준의 감독만 제공하며, 모델이 좋은 응답을 샘플링하지 못하면 교정 신호도 얻을 수 없음

에이전트 궤적은 더 어렵다 — 다단계 환경 상호작용으로 구성되어, 교정이 실제로 도구를 실행하고 실제 피드백을 받은 뒤에야 생성이 계속될 수 있음

핵심 아이디어: 토큰 수준 교정 (Token-Level Correction)

어노테이터는 응답을 읽으면서 첫 번째 부적절한 토큰만 찾으면 됩니다

1
탐색 (Locate)
응답을 읽으며 첫 부적절 토큰 발견
2
교정 (Correct)
top-k 후보 토큰에서 클릭 선택, 또는 자유 편집
3
계속 (Continue)
이후 내용을 잘라내고 교정된 프리픽스에서 모델이 재생성

교정 후 전체 응답을 다시 읽을 필요 없이, 요구를 만족할 때까지 "탐색–교정–계속" 루프를 반복

인터페이스 구성 (Figure 1)

  • 확률 시각화 — 각 토큰 아래 생성 확률을 색으로 표시 (초록: 높음, 빨강: 낮음)
  • 후보 선택 — 부적절 토큰에 호버하면 해당 위치의 top-20 후보 토큰이 팝업으로 표시, 적절한 토큰을 클릭
  • 교체 후 계속 생성 — 토큰 교체 시 이후 내용을 잘라내고 교정된 프리픽스에서 모델이 이어서 생성
  • 자유 편집 — 적합한 후보가 없으면 더블클릭으로 입력창을 열어 임의 텍스트로 교체
  • 버전 보존 — 세션은 모든 중간 버전을 저장, 최종본은 긍정 샘플(is_good=Y), 이전 버전은 부정 샘플로 유지

네 가지 핵심 장점

1. 효율적인 어노테이션

대부분의 교정이 마우스 클릭, 후보가 부족할 때만 짧은 타이핑. "읽으면서 교정"하는 선형 워크플로우로 반복 검토 비용 제거

2. 높은 온폴리시 충실도

인간 개입은 오류 위치에만 발생. 대부분의 토큰은 롤아웃 모델이 직접 생성하므로 SFT 데이터가 모델 분포에 가까움

3. 정밀한 감독 신호

모든 토큰 수준 교정을 자동 기록 → 오류 위치·대체 토큰·자연스럽게 쌍을 이루는 긍정–부정 샘플. RM/DPO/PRM 학습에 활용 가능

4. 완전한 표현력

자유 편집이 폴백 역할 — 모델이 정답을 샘플링하지 못해도 어노테이터가 정답 텍스트를 주입해 후속 생성을 유도

시스템 개요

경량 웹 앱

정적 호스팅으로 배포, 데이터베이스 불필요. 로컬 어노테이션 파일을 드래그하여 바로 작업 시작, 브라우저에서 Chat Completions API로 요청

임베디드 컴포넌트

기존 데이터 플랫폼에 컴포넌트로 통합, 백엔드가 작업 분배와 데이터 수집을 담당. 실제 사내 프로덕션 어노테이션 시스템에 통합됨

API 요구사항은 단 2가지:

  • assistant 메시지 프리픽스에서 이어 생성 (예: vLLM의 continue_final_message)
  • 각 토큰의 top-k 후보와 확률(logprobs) 반환

토큰 수준 교정 엔진

  • 스트리밍 + logprobs — 각 토큰의 샘플링 확률과 top-k(기본 20) 후보를 기록하고 토큰 아래에 확률 색상 렌더링
  • 청크(chunk) 단위 상호작용 — 이모지·다중 바이트 문자가 토큰에 걸쳐질 수 있으므로 그래핌 경계로 최소 가독 단위를 묶어 UI는 청크 단위, 기록은 토큰 정밀도 유지
  • 교정 3요소 보존 — 교정 위치, 대체 텍스트, 교정 전후 샘플
  • 프리픽스 유지 — 교정 지점 이후만 잘라내어 네이티브 이어쓰기 요청, 이전 토큰은 재생성하지 않고 그대로 유지
  • 확률 재계산(refresh) — 자유 편집 텍스트는 prompt_logprobs 요청 한 번으로 전체 응답의 확률·후보 재계산. 외부 텍스트 붙여넣기·모델 전환에도 적용되어 모델 검사 도구로도 활용 가능

어노테이션 트리와 데이터 프로토콜

어노테이션 트리

세션은 대화(dialog)를 노드로 하는 트리로 구성. 각 교정은 새 노드로 포크되며 부모는 교정 전 대화. 모든 중간 버전이 어노테이터의 별도 버전 관리 없이 자동 저장됨 (예: Dialogs [1,2,3] 체인)

.panda.json

메시지, 어노테이션, 작업 로그, 확률 캐시 등 세션의 모든 산출물이 단일 파일로 직렬화되어 배포·수집·파싱이 용이

완전한 추적 가능성: 각 노드는 작업 유형, 타임스탬프, 교정 내용, on-policy 여부 표시, 샘플링 설정 스냅샷을 담은 작업 로그를 보유. 각 대화는 품질 판정 is_good과 프로젝트 정의 어노테이션 스키마(단일/복수 선택, 텍스트 등)를 포함

데이터 변환: onpanda 파이썬 라이브러리가 .panda.json을 학습 데이터로 변환 — is_good=Y 노드는 SFT 샘플로 export

평가 결과: 효율과 데이터 품질

52%

수동 후편집 대비 중앙값 어노테이션 시간 단축 (소규모 통제 실험)

베이스라인 비교

처음부터 작성, 수동 후편집 등 기존 방식과 시간·품질 비교 실험 수행. onPanda의 "클릭 기반 교정" 워크플로우가 인지 부담과 반복 검토를 크게 줄임

온폴리시 충실도 검증

최종 응답의 대다수 토큰이 모델 자체 생성이므로, 결과 데이터가 롤아웃 모델의 샘플링 분포를 크게 보존함을 실증

사용자 스터디 및 실제 배포: 실환지 프로덕션 어노테이션 시스템에 통합되어 실사용 검증 완료, 모델 검사(inspection) 용도로도 활용

에이전트·멀티모달 어노테이션

도구 연동

onPanda는 MCP를 통해 외부 도구에 접속하고 실제 환경에서 대화형 궤적 어노테이션을 지원

하네스 통합

Claude Code, Codex, OpenClaw 등 에이전트 하네스에 연결 — 교정된 추론과 도구 호출이 실제 환경에서 실행됨

기존 도구들은 라이브 에이전트를 관찰·채점하거나 실행될 텍스트를 편집하는 수준에 머물렀지만, onPanda는 다양한 환경에서 일반 추론과 도구 호출을 실시간으로 교정하고 그 교정된 호출을 실행하는 최초의 대화형 도구

또한 멀티모달(VLM) 어노테이션도 지원하여 이미지 기반 응답 교정에도 활용 가능

Panda-CVL 데이터셋 & 벤치마크

Panda-CVL 데이터셋

onPanda로 어노테이션된 중국어 비전-언어(Vision-Language) 데이터셋 — 토큰 수준 교정 데이터의 공개 연구 자원으로 공개

동반 벤치마크

토큰 수준 교정(task) 평가를 위한 벤치마크를 함께 공개 — 평가 프로토콜과 메트릭 포함

의의: 토큰 수준 교정 데이터라는 새로운 데이터 유형에 대한 커뮤니티 연구를 촉진하는 공개 리소스 제공

기여 요약

  • onPanda 제안 — 토큰 수준 교정을 중심으로 LLM 정렬 데이터와 에이전트 궤적을 롤아웃 모델 분포에 가깝게 효율적으로 어노테이션하는 도구
  • 실험적 검증 — 어노테이션 효율성(중앙값 52% 시간 단축)과 생성 데이터의 온폴리시 충실도를 실증하고, 멀티모달·에이전트 궤적 어노테이션 지원 입증
  • 공개 리소스 — 멀티모달 Panda-CVL 데이터셋과 동반 벤치마크를 공개하여 토큰 수준 교정 데이터 연구의 토대 제공
