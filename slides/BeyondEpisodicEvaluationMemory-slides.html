동기: 에피소딕 평가의 한계

"기존 EQA 평가는 각 질문을 독립적인 작업으로 처리하고, 에피소드 간에 에이전트의 내부 상태를 초기화한다."

  실제 로봇의 동작 방식

  • 연속적으로 환경에서 작동
  • 이전 상호작용에서 얻은 정보를 누적·보존·재사용
  • 중복 탐색을 피해 효율적으로 후속 작업 수행

  암묵적 가정의 문제

  • 메모리를 "켜두기만" 하면 성능이 일률적으로 향상될 것이라는 가정
  • 메모리 구조에 따른 지식 축적 능력 차이 무시
  • 순차적 설정에서의 아키텍처 병목 미탐색

Sequential-EQA 평가 프로토콜

기존 에피소딕 EQA 벤치마크를 최소 개입으로 순차적 설정으로 변환

1
동일 환경
같은 3D 환경 내에서 여러 질문을 연속적으로 제시
2
상태 전달
에이전트의 내부 메모리를 질문 간에 유지
3
최소 개입
환경과 모델 파라미터는 변경하지 않음
4
진단 평가
실패 모드 분석에 집중, 최적화된 성능 측정 아님

대상 벤치마크: OpenEQA — 에이전트를 의도적으로 추가 최적화 없이 적용하여 메모리 아키텍처 자체의 한계를 격리

평가 대상 메모리 아키텍처

경량 기하 메모리

ExploreEQA

  • 2D 점유 맵(Occupancy Map) 기반
  • 탐색 가능 여부만 저장
  • 시각-의미 정보 미포함

암시적 메모리 (VLA)

UniNavid

  • 엔드-투-엔드 비전-언어-행동 모델
  • 단기 에피소딕 버퍼 사용
  • 단기 호라이즌 데이터로 학습 → 분포 외향 붕괴

구조화 3D 공간 메모리

3D-Mem

  • 시각 관측을 3D 기하에 매핑
  • VLM으로 의미적 정보 보존
  • 공간 좌표에 앵커링 → 재사용 가능한 장면 표현

핵심 발견 1: 경량 메모리의 한계

2D 점유 맵이 기억하는 것

  • 로봇이 어디를 탐색했는지 (통행 가능성)
  • 장애물의 위치 (기하 정보)

2D 점유 맵이 잊어버리는 것

  • 객체의 시각-의미 증거 (색상, 형태, 카테고리)
  • 질문에 답하기 위한 핵심 정보

결과

"탐색 위치는 기억하지만, 이후 질문에 필요한 시각-의미 증거가 없어 정답률이 정체되거나 하락한다."

메모리 지속성 ≠ 지식 축적
단순히 메모리를 유지하는 것만으로는 충분하지 않다

핵심 발견 2: VLA 에이전트의 시간적 불일치

UniNavid의 순차적 설정에서의 문제

학습 시: 단기 호라이즌의 에피소딕 데이터

배포 시: 연속적인 다중 질의 히스토리

상속된 컨텍스트가 재사용 가능한 장면 표현이 아닌 심각한 시간적 불일치(Temporal Mismatch)를 유발

의미적 간섭 (Semantic Interference)

이전 질문의 컨텍스트가 현재 질문의 추론을 방해

재해석 문제 (Overwriting)

새 관측이 이전 지식을 덮어써서 치명적 망각 발생

→ 내비게이션 비용은 감소하지만, 정답률이 정체되거나 체계적으로 하락

해결책: 공간적으로 기반된 3D 메모리

3D-Mem 아키텍처의 핵심 원리

1
시각 관측 수집
로봇 이동 중 지속적 이미지 획득
2
3D 기하 매핑
관측을 메트릭 3D 좌표에 영속적으로 부착
3
VLM 의미 부착
VLM으로 시각-의미 정보를 3D 위치에 저장
4
선택적 재사용
질문에 관련된 공간 영역만 조회하여 답변

  치명적 망각 방지: 공간 좌표에 앵커링되어 이전 정보가 덮어쓰기되지 않음

  의미적 노이즈 제거: 질문과 무관한 과거 정보가 현재 추론을 간섭하지 않음

시뮬레이션 실험 결과

OpenEQA 벤치마크 기반 순차적 평가

메모리 아키텍처 정답률 변화 내비게이션 비용 정확도-효율성 트레이드오프
2D 점유 맵
ExploreEQA		 정체 또는 하락 감소 깨짐 — 의미 정보 부재
암시적 메모리
UniNavid (VLA)		 체계적 하락 감소 깨짐 — 시간적 불일치
3D 공간 메모리
3D-Mem		 +33.3% 향상 -53.3% 감소 돌파 — 동시 달성

"공간적으로 기반된 3D 메모리만이 순차적 설정에서 정확도-효율성 트레이드오프를 돌파한다."

실제 로봇 검증

실험 설정

  • 실제 사족보행 이동 로봇 활용
  • 실내 및 실외 환경에서 테스트
  • 현실적인 센싱 및 구동 노이즈 존재
  • 시뮬레이션과 동일한 평가 프로토콜 적용

결과

"시뮬레이션에서 발견된 병목 현상이 실제 환경에서도 일반화됨을 확인."

  • 공간적으로 기반된 시각 메모리의 필요성 재확인
  • 시뮬레이션 결과가 단순한 아티팩트가 아님을 입증
  • 물리적 환경에서의 연속적 지능적 동작 가능성 확인

정성적 분석 인사이트

  실패 모드 분석

  • 의미적 희석: 질문과 무관한 영역의 정보가 메모리에 축적되어 관련 정보의 검색 정밀도 저하
  • 과신(Overconfidence): 과거 관측에 의존하여 추가 탐색을 수행하지 않다가 정보가 불충분한 경우 발생
  • 컨텍스트 오염: VLA에서 이전 질문의 언어 컨텍스트가 현재 질문 해석을 왜곡

  3D-Mem의 성공 요인

  • 공간 분리성: 서로 다른 객체와 장소의 정보가 3D 공간에서 자연스럽게 분리되어 보존
  • 선택적 접근: 질문과 관련된 공간 영역만 효율적으로 조회 가능
  • 점진적 축적: 새 관측이 이전 정보를 덮어쓰지 않고 추가됨

주요 기여 요약

1

Sequential-EQA 프로토콜 도입

EQA를 고립된 에피소드에서 연속적 다중 질의 작동으로 전환. 기존 모델과 환경 수정 없이 메모리 재사용 효율을 측정.

2

아키텍처 병목 식별

메모리 지속성이 지식 축적을 보장하지 않음을 4가지 아키텍처(VLM-agent, VLA 포함)에서 입증.

3

트레이드오프 돌파 증명

공간 기반 3D 메모리가 순차적 설정에서 정확도 +33.3%, 내비게이션 비용 -53.3%를 동시 달성.

4

실제 로봇 검증

사족보행 로봇에서 실내·실외 환경 테스트로 식별된 병목이 시뮬레이션을 넘어 일반화됨을 확인.
