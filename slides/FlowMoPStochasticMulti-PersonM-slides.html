FlowMoP

Stochastic Multi-Person Motion Prediction

확률론적 다중 인간 3D 모션 예측

Aadya Agrawal  ·  Ho Kei Cheng  ·  Alexander Schwing

University of Illinois Urbana-Champaign

arXiv: 2611.09882 Conditional Flow Matching Multi-Person 3D

왜 다중 인간 모션 예측인가?

공유된 환경에서 사람들의 미래 움직임을 예측하는 것은 수많은 응용의 기반 기술

자율 주행 내비게이션

주변 보행자·차량의 미래 움직임 예측이 안전한 경로 계획의 필수 요소

스포츠 분석

선수들의 협력·전술 행동 이해 및 경기 분석에 활용

핵심 도전: 개인의 신체 역학만으로는 부족 — 사람들은 서로 조율(coordinate)하고, 반응(react)하며, 상대의 움직임을 예측(anticipate)한다. 이러한 상호의존성을 포착해야 유용한 예측이 가능

인간 모션은 본질적으로 확률적(Stochastic)이다

하나의 과거, 여러 개의 미래

동일한 관측 이력이라도 의도(intent), 상호 조율, 사회적 맥락에 따라 여러 그럴듯한 연속 동작이 존재

예시: 갈림길의 보행자

갈림길을 향해 걸어가는 사람은 좌회전 · 우회전 · 정지 중 무엇이든 할 수 있음 — 정답은 관측 불가능한 의도에 달려 있음

그러나 다중 인간 3D 모션 예측의 지배적 패러다임은 결정론적(deterministic) — 각 에이전트마다 고정된 개수의 출력만 생성. 실제로 결정론적 베이스라인은 경로 제안은 다양해도 대응되는 자세 예측이 거의 정지된 자세로 퇴화하는 문제가 있음

기존 연구와 한계

다중 인간 3D 예측

MRT, SoMoFormer, JRT, TBIFormer, T2P, EMPMP — 상호작용 모델링은 발전했으나 모두 결정론적

기존 확률론적 방법

DuMMF: 고정된 학습 의집합 기반 DDPM (다양성 제한) · Social Diffusion: 맞춤형 사실성 지표 중심 → 통합 생성 프레임워크 부재

단일 인간 확률론적 예측

SkeletonDiffusion, HumanMAC 등 확산·MAE 기반 — 그러나 에이전트 간 의존성 미모델링

연구 공백: Flow Matching은 텍스트 조건 모션 생성·단일 인간 예측에는 적용되었으나, 다중 인간 3D 자세 예측에는 적용된 바 없음. 본 연구가 최초로 전체 예측 구간을 비자기회귀(non-autoregressive)로 생성

핵심 기여 (Key Contributions)

  • 조건부 Flow Matching 프레임워크 — 전역 궤적(global trajectory)과 국소 자세(local pose)를 공동으로 모델링하는 확률론적 다중 인간 3D 모션 예측
  • B-spline 재매개변수화 — 예측 공간을 압축하여 적분 비용을 줄이고, 정확도를 희생하지 않으면서 시간적 평활성(temporal smoothness)을 보장
  • 듀얼 스트림 트랜스포머 — CMU-Mocap (UMPM)과 3DPW에서 최고 수준(SOTA) 성능 달성
  • WorldPose 상호작용 연구 — 실제 중계 영상 조건의 풀 장면 축구 모션 예측에 대한 최초의 생성 기준선(generative baseline) 제시

FlowMoP 방법 개요

1
분해
관절 위치를 전역 루트 궤적 + 루트 상대 자세로 분해, 하나의 생성 모델에서 공동 처리
2
B-spline 공간
매 프레임 독립 생성 대신 압축된 제어점 공간에서 예측
3
Flow Matching
조건부 확률 흐름으로 미래 모션 분포를 학습·생성
4
듀얼 스트림
관측 이력과 노이즈된 미래를 분리된 어텐션 경로로 처리

결과: 각 에이전트에 대해 예측 분포 전체를 출력 — 우도(log-likelihood)로 색상 표현 가능한 다양한 미래 후보들을 생성

B-spline 제어점 재매개변수화

  • 모든 미래 프레임을 개별 생성하는 대신 압축된 B-spline 제어점 공간에서 예측 수행
  • 생성 상태 공간(generative state space)을 크게 압축 → Flow Matching ODE 적분 비용 절감
  • 스플린트 매개변수화가 자연스럽게 시간적 평활성을 강제 — 들쭉날쭉한 부자연스러운 궤적 억제
  • 전역 루트 궤적과 루트 상대 자세 모두 동일한 방식으로 매개변수화

기존 DCT 기반 압축(SiMLPe, T2P, EMPMP)은 결정론적 방법에서 주파수 영역 압축에 사용 — FlowMoP는 B-spline으로 생성 모델 내부에서 효율성과 평활성을 동시에 확보

조건부 Flow Matching

학습

노이즈 분포에서 데이터 분포로 이어지는 확률 흐름(velocity field)을 학습. 관측 이력을 조건으로 주어 미래 모션 분포를 모델링

추론

학습된 벡터장을 ODE로 적분하여 다양한 미래 샘플을 생성. 비자기회귀 방식으로 전체 예측 구간을 한 번에 생성

전역 궤적 + 국소 자세

에이전트가 공간에서 어디로 이동하는지(root trajectory)와 어떻게 움직이는지(root-relative pose)를 하나의 생성 모델에서 공동으로 다룸

완전한 예측 분포

고정 개수의 후보가 아닌 연속적인 예측 분포 출력 — 우도 기반 샘플링·스코어링 가능

듀얼 스트림 트랜스포머 + 상호작용 조건화

듀얼 스트림 구조

관측된 과거 토큰과 노이즈된 미래 토큰을 분리된 어텐션 경로로 처리 → 생성 과정 전반에서 과거 관측이 안정적인 조건으로 유지됨

최근접 이웃 조건화

각 에이전트의 예측 분포를 주변 에이전트의 관측된 움직임으로 조건화 → 상호작용을 고려한 예측(interaction-aware forecasting)

동기: WorldPose 같은 22인 풀 장면 축구에서는 상호작용이 전략적 집단 행동을 반영 — 이웃 궤적을 문맥으로 넣는 조건화가 본질적으로 필요

실험 결과: 3D 다중 인간 벤치마크

표준 벤치마크 CMU-Mocap (UMPM) 및 3DPW에서 평가

확률론적 생성 모델임에도 결정론적 베이스라인을 모든 주요 지표에서 능가 — 다양성과 정확성의 양립을 입증

WorldPose 상호작용 연구

  • 대규모 프로 축구 데이터셋 WorldPose에 최초의 모션 예측 기준선 확립
  • 실험실 캡처가 아닌 중계 영상에서 추정된 3D 자세 — 22명 선수 전원이 등장하는 현실적 풀 장면
  • 제어된 환경의 기존 데이터셋(최대 3인, 대본 기반 상호작용)의 한계를 극복하는 시험대
  • 사회적 조건화(social conditioning)가 예측 불확실성을 상호작용 제약 방향으로 집중시킴을 실증

상대 선수의 관측된 움직임을 조건으로 넣으면, 모델이 "가능한 모든 움직임"이 아닌 전술적 상호작용이 허용하는 미래에 확률 질량을 집중시킨다는 의미

기대 효과와 의의

패러다임 전환

다중 인간 예측을 결정론적 점 추정에서 확률적 분포 추정으로 전환

효율성

B-spline 재매개변수화로 적합 비용·추론 비용 절감 + 시간적 평활성 무료 확보

사회적 인식

이웃 조건화를 통한 상호작용 인식 예측으로 복잡한 군중·팀 상황 대응
