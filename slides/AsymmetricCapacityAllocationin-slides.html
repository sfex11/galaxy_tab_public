Self-Refinement 파이프라인에서의
비대칭 용량 할당

Asymmetric Capacity Allocation in Self-Refinement Pipelines

Zhuoyi Yang, Ian G. Harris, Salar Hashemitaheri 외 · UC Irvine & Drexel University

동기 및 문제 제기

Self-refinement(생성→비평→수정)은 LLM 성능 향상을 위한 핵심 패러다임이며, 다수의 에이전트 시스템에서 핵심 메커니즘으로 활용됩니다.

그러나 세 단계는 서로 다른 인지적 요구를 가짐에도, 대부분의 연구에서는 각 단계의 모델 크기를 동일하게 설정하거나 임의로 선택합니다.

핵심 문제

  • 모델 용량을 균일하게 할당 → 자원 낭비
  • 각 단계의 모델 크기가 파이프라인 성능에 미치는 영향에 대한 체계적 연구 부재
  • 비평 단계를 생략하면 성능이 저하되는지 여부 불명확

Self-Refinement 파이프라인 구조

1
Generator (G)
입력 x에 대해 초기 해답 y₀ 생성
2
Critic (C)
x와 y₀을 분석하여 자연어 피드백 f 생성
3
Refiner (R)
x, y₀, f를 바탕으로 최종 해답 yᵣ 생성
y₀ = G(x)

초기 생성

f = C(x, y₀)

비평 피드백

yᵣ = R(x, y₀, f)

수정된 해답

파이프라인 표기법: P(G, C, R) — 예: P(32B, 0.6B, 32B)

연구 질문

Self-Refinement 파이프라인의 각 단계에 모델 용량을 어떻게 할당해야 하는가?

생성기의 크기를 키우면 파이프라인 성능이 일관되게 향상하는가?

Q₂ Critic

비평기의 크기가 파이프라인 성능에 얼마나 영향을 미치는가? 비평을 생략하면?

Q₃ Refiner

수정기의 크기에 대한 파이프라인의 민감도는 어느 정도인가?

발견 1: Generator 크기 분석

Generator Sweep

발견 1

파이프라인 성능은 Generator 크기 스케일링과 일관되게 향상합니다.

  • Generator가 클수록 초기 해답 y₀의 품질이 향상
  • 향상된 초기 해답은 이후 비평 및 수정 단계에 긍정적 영향
  • 5개 벤치마크 모두에서 일관된 추세 확인
  • Qwen3, Gemma 3 양 모델 패밀리에서 동일한 패턴

해석: Generator는 고품질 초기 출력을 위한 충분한 용량이 필요

발견 2: Critic 크기 분석

Critic Sweep

발견 2.1

파이프라인 성능은 Critic 크기에 거의 민감하지 않습니다.

발견 2.2

가장 작은 Critic이라도 비평 없는 파이프라인보다 일관되게 우수합니다.

  • 0.6B Critic이 32B Critic과 유사한 성능 제공
  • Critic 크기를 키워도 성능 향상은 미미
  • 그러나 비평 단계 자체를 생략하면 성능 저하

해석: Critic의 역할은 "존재하는 것"이 중요하고, 정교한 비평을 위한 대규모 모델은 불필요

발견 3: Refiner 크기 분석

Refiner Sweep — 가장 민감한 단계

발견 3.1

파이프라인 성능은 Refiner 크기에 매우 민감합니다.

주의 용량이 부족한 Refiner는 초기 생성 성능보다 더 낮은 결과를 낼 수 있습니다.

  • Refiner 크기 스케일링이 가장 큰 성능 변화를 유발
  • 소형 Refiner는 피드백을 잘 활용하지 못해 성능 악화
  • 수정 작업은 생성보다 더 높은 인지적 부담 요구
  • Generator와 Refiner 간 크기 불균형 시 파이프라인 전체 성능 하락

해석: Refiner는 입력(원문+초기해답+피드백)을 종합적으로 이해하고 개선해야 하므로 충분한 용량 필수

세 단계의 스케일링 특성 비교

단계 크기 민감도 스케일링 방향 실무 권장
Generator 높음 클수록 일관되게 향상 가능한 큰 모델 할당
Critic 매우 낮음 크기 증가 효과 미미 소형 모델로 충분 (단, 생략 금지)
Refiner 매우 높음 작으면 성능 악화 가능 Generator와 동등한 크기 권장

세 단계는 명확히 다른 스케일링 특성을 보이며, 균일한 모델 할당은 비효율적입니다.

실무적 시사점

비용 효율적 파이프라인 설계

Critic에 소형 모델(예: 0.6B)을 사용하여 연산 비용을 대폭 절감하면서도 성능 유지

비대칭 할당 전략

Generator ≥ Refiner ≫ Critic 순으로 용량을 배분하는 것이 최적

Refiner 과소설계 경고

소형 Refiner는 self-refinement의 이점을 상쇄하고 오히려 성능을 저하시킬 수 있음

권장 구성 예시

P(32B, 0.6B, 32B)

vs 균일 구성

P(32B, 32B, 32B)

유사한 성능 while ~50% 연산 비용 절감

결론

본 연구는 Self-Refinement 파이프라인에서 단계별 모델 크기가 성능에 미치는 영향을 최초로 체계적으로 분석했습니다.

5개 벤치마크, 2개 모델 패밀리(Qwen3, Gemma 3)를 통한 실험 결과, 세 단계는 명확히 상이한 스케일링 특성을 보입니다.

이는 균일한 모델 할당이 비효율적임을 시사하며, 계산 효율적인 다단계 언어 모델 시스템 설계를 위한 실질적 지침을 제공합니다.
