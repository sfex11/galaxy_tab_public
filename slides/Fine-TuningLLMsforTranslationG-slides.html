"다음 문장을 격식 있는 어조로 스페인어로 번역하세요" — 자막 번역 등에서는 제어가 번역 과제의 일부 (Matusov et al., 2019)

기존 NMT는 전용 메커니즘 + 주석 데이터가 필요했지만, 지시 튜닝된 LLM은 자유 형식 프롬프트로 처리

예시: 격식 제어는 망각되지만, 그 방식은 제각각

핵심: EWC는 일반 능력 손실을 대부분 회복하지만, 격식 지시는 복원하지 못함 — 일반 벤치마크 점수만으로는 이 손실을 탐지할 수 없음

연구 질문

Q1

망각 완화 방법의 결론이 MT 파인튜닝으로 전이되는가?
기존 평가는 수학·코드 등 도메인 + 일반 벤치마크 기준으로 수행됨

Q2

이 방법들이 MT-IF(격식·성별·길이 제어)를 보존하는가?
일반 벤치마크 보존과 MT-IF 보존은 별개일 수 있음

기여

  • 3가지 앵커 유형의 완화 방법을 3개 언어쌍 × 2개 모델 크기에서 비교
  • 일반 벤치마크 보존과 MT-IF 손실이 공존할 수 있음을 입증 — 일반 점수만으로는 놓치는 능력 존재

EWC의 한계

일반 능력은 완벽히 보존했지만, 격식·성별 제어 점수는 표준 SFT와 거의 동일한 수준으로 낮음

일반 벤치마크 보존 ≠ MT-IF 보존

유일한 예외: Data Mixing

해당 제어 과제의 예시를 학습 데이터에 혼합한 경우에만 격식·성별 제어 보존

즉, 앵커가 아니라 과제별 학습 데이터가 효과의 원천

전이 실패: 같은 과제라도 학습에 사용하지 않은 미지의 프롬프트로는 Data Mixing의 향상이 전이되지 않음

같은 프롬프트 형식으로 얻은 향상이 미지의 프롬프트로 일반화되지 않음 → "보존"이 아니라 프롬프트별 암기에 가까움

분석: 왜 이런 결과가?

1

EWC는 일반 능력은 지키지만 MT-IF는 못 지킨다
MT-IF는 Fisher 정보로 포착되는 중요 파라미터와 겹치지 않는 좁은 능력 — 일반 벤치마크 중심의 중요도 추정이 놓침

2

모델 출력 앵커 방법(KL·STM·CC·EAFT)은 실패
고정된 SFT 응답(off-policy) 학습에서 원본 출력 분포로의 정규화는 학습 신호 자체를 약화시켜 SFT 기준선으로 수렴

3

SPD는 부분적 예외
파라미터 앵커 중에서는 일부 균형을 보이나, MT-IF 보존에는 불충분

실무 시사점: MT-IF가 필요하면 완화 방법이 아니라 제어 과제 데이터를 직접 혼합하고, 미지 프롬프트 일반화까지 확인해야 함

결론

  • 일반 능력 기준: EWC가 최고 — 8B 모델에서 하락 1.7점 vs SFT 11.0점
  • MT-IF 기준: EWC를 포함한 완화 방법 대부분 실패 — 격식·성별 제어는 SFT 수준
  • 유일한 보존 경로: 제어 과제 예시의 Data Mixing — 단, 미지 프롬프트로 전이 안 됨
  • 평가 교훈: 일반 벤치마크 점수만으로는 MT 파인튜닝의 능력 손실을 놓칠 수 있음 → 과제별 지시 수행 평가 필수
