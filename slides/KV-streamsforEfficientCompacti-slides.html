KV-streams

Agentic 강화학습에서 효율적인 컴팩션

KV 캐시를 flush하지 않고 스트리밍하여
컴팩션의 재프리필 비용을 제거하는 플러그 앤 플레이 전략

Emiliano Penaloza, Dane Malenfant, Dheeraj Vattikonda, Roger Creus Castanyer 외 다수

Mila · Microsoft · McGill University · Université de Montréal · Microsoft Research

문제: 긴 에이전트 롤아웃이 GPU 메모리를 병목시킨다

선형적으로 증가하는 KV 캐시

장기(long-horizon) 에이전트 과제는 다수의 동시 롤아웃을 생성하며, 각 롤아웃의 KV 캐시는 길이에 비례해 선형 증가

메모리 독점 현상

고정된 GPU 메모리 예산 하에서 가장 오래 실행되는 롤아웃이 병목이 되어, 짧은 롤아웃이 쓸 수 있는 메모리를 독점

환경 피드백의 가중

소프트웨어 엔지니어링에서 파일 읽기/쓰기 한 번이 나중에 불필요한 컨텍스트를 대량으로 소비

처리량 감소

메모리 압박은 학습 처리량을 제한하여 옵티마이저 스텝 수와 배치 크기를 모두 제약

기존 해법: 컨텍스트 컴팩션 (Context Compaction)

토큰 예산 초과 시 컨텍스트 일부를 제거하여 메모리 사용량을 일정하게 유지

컴팩션 연산자 κ = gen ∘ del

  • del (삭제): 최소 b ≥ 1개 토큰 스팬을 제거하여 컨텍스트가 항상 축소됨을 보장
  • gen (생성): 제거된 자리에 브리지 s (예: 요약)를 생성 — 비어 있을 수도 있음
  • 트리거 T: 고정 토큰 예산 B 초과, 또는 모델 스스로의 컴팩션 결정

메모리 문제는 해결하지만, "남긴 컨텍스트를 매번 다시 prefill"해야 하는 새로운 계산 병목이 발생

재프리필(Re-prefill)의 숨은 비용

무엇이 초기화되는가?

  • 컴팩션 후 새 트레이스에서 이어짐
  • 보존된 토큰의 위치 인코딩 리셋
  • 캐시도 재계산됨: (k′ᵢ, v′ᵢ) ≠ (kᵢ, vᵢ)
  • 이미 계산한 KV를 다시 prefill할 수밖에 없음

추가 prefill 토큰 수

Δ = N·r / (B−r)

N: 롤아웃 길이 · r: 컴팩션당 보존 토큰 · B: 예산

보존 토큰이 예산에 가까울수록 재처리 배수가 급격히 증가

같은 토큰에 대해 모델이 반복적인 forward pass를 수행 → 학습 처리량 저하 (KV-streams는 재프리필 0)

핵심 아이디어: KV-streams

컴팩션 후 KV 캐시를 flush하는 대신 앞으로 스트리밍한다

추론 엔진 측

  • KV 항목을 추론 엔진 내부에서 직접 축출(evict)
  • 컴팩션의 메모리 절감 효과는 그대로 유지
  • 하나의 연속적인 KV 스트림 유지 → 재프리필 비용 완전 제거

트레이너 측

  • 커스텀 어텐션 마스크로 축출 패턴을 재현
  • 토큰을 전혀 재처리하지 않음
  • 하나의 연속 트레이스로 학습 가능

간단한 플러그인으로 모든 컴팩션 전략과 호환 — 학습·추론 처리량 모두 대폭 향상

KV-streams 작동 방식

1
예산 초과 감지
트리거 T 발동 — 토큰 예산 B 도달 또는 모델의 자발적 결정
2
KV 직접 축출
삭제할 토큰의 KV를 추론 엔진에서 제거 (메모리 확보)
3
연속 스트림 유지
남은 KV와 위치 인코딩을 그대로 보존 — 새 트레이스 없음
4
어텐션 마스크 학습
트레이너가 마스크로 축출 패턴을 재현 — 재프리필 0

재프리필 방식과 달리 각 토큰은 정확히 한 번만 계산됩니다

Wall-clock 절감

GPU 시간과 실제 경과 시간 모두에서 동일 점수를 훨씬 적은 비용으로 달성

성능 보존

스트리밍이 성능을 해친다는 증거 없음 — 재프리필과 통계적으로 동등

발견: SFT 없이 RL만으로 의사-순환(pseudo-recurrent) KV가 등장

선행 연구의 주장

컴팩션 간 KV를 보존하면 KV 캐시가 "의사-순환 상태"로 작동하지만, 이 동작에는 사전 SFT 단계가 필요하다고 보고

본 논문의 발견

스트리밍된 KV 캐시는 컨텍스트에서 오래전 사라진 정보까지 보존하며, RL만으로 이 행동이 충분히 발현

  • SFT에 드는 추가 wall-clock 시간은 성능 향상으로 이어지지 않음
  • 통제된 합성 실험: 초기에 전혀 노출되지 않은 객체(zero-support)도 회상
  • 컨텍스트가 달라져도 KV를 통한 정보 전달이 일반화됨

핵심 기여 요약

  • 플러그 앤 플레이: 어떤 컴팩션 전략에도 추가되는 경량 모듈 — 4가지 전략에서 검증
  • 2.6× ~ 5× 학습 가속: 재프리필 비용을 완전히 제거 (TextWorld 5×, SWE-bench 3× 조기 도달)
  • 성능 무손실: 재프리필 컴팩션과 동등하거나 능가, 충분한 학습 시 전체 컨텍스트까지 상회
  • 일반화 향상: 미학습 텍스트 게임에서 더 우수한 전이 성능
  • SFT 불필요: 의사-순환 KV 동작이 RL 사후학습만으로 발현 — 사전학습 단계 절약

KV-streams는 어떤 사후학습 파이프라인에도 손쉽게 추가할 수 있는 효율적이고 가벼운 개선책입니다
