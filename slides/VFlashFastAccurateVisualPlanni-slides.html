VFlash

Fast, Accurate Visual Planning via Flash Primitive Decoding

플래시 프리미티브 디코딩을 통한 빠르고 정확한 시각 계획

arXiv: 2611.08449 · NVIDIA · Johns Hopkins University

배경: 물리 AI는 언어만으로 추론하지 않는다

로봇·자율주행의 VLM은 시각 관찰과 지시를 해석하는 고급 두뇨 역할을 하며, 중간 예측을 시각 계획(Visual Plan)으로 표현할 수 있다

점 (Points)

관련 위치·객체 식별

바운딩 박스

공간적 목표 영역 명시

궤적 (Trajectory)

의도된 움직임·장면 전개 예측

시각 계획은 행동에 앞서 공간적 목표와 예상되는 움직임을 명시적으로 만든다 — 각 프리미티브는 식별 가능한 경계와 조직화된 좌표 배치를 가진다

문제: 자기회귀(AR) 디코딩의 순차적 한계

좌표 토큰을 하나씩 생성 — AR VLM은 시각 계획을 토큰 단위로 순차 디코딩
공간적 세부가 커질수록 비용 급증 — 긴 궤적, 다수 객체, 2D 이미지+3D 동시 예측은 더 많은 좌표 토큰 필요
고정 지연 시간 예산의 제약 — 새 관측마다 계획을 갱신해야 하는 물리 에이전트는 세부도·갱신 주기가 모두 제한됨
목표: 더 적은 순차 forward pass로 완전한 시각 계획을 생성하면서 공간 정확도는 유지하는 디코딩 방법

기존 병렬 디코딩 접근법과 한계

접근법아이디어한계
Speculative Decoding 드래프트 모델이 γ개 토큰 제안, 타깃이 병렬 검증 greedy 검증은 첫 불일치에서 중단 → τ가 γ 이하로 포화, 블록을 키워도 처리량 증가 없음
dLLM 병렬 디노이징 AR 대비 속도–품질 트레이드오프 존재
DFlash 경량 블록 확산 드래프터가 1회 forward pass로 드래프트 + 타깃 검증 텍스트 중심 설계, 토큰 수준 일치에 의존
핵심 문제: 토큰 수준 일치(token agreement)는 공간 정확도와 동일하지 않다 — 시각 출력에는 다른 수용 기준이 필요

VFlash: 핵심 아이디어

Flash Primitive Decoding (FPD) — 시각 프리미티브의 알려진 구조를 활용해 좌표들을 공동(jointly)으로 예측

  • 경량 확산 드래프터가 프리미티브 전체를 한 번의 forward pass로 생성
  • 적응형 레이아웃 — 프리미티브의 유형·차원·길이에 따라 블록 구조가 변함 (컴팩트한 박스 ~ 긴 가변 길이 궤적)
  • 구조 기반 수용 — 구조적으로 유효한 예측을 타깃 토큰 일치 없이 전체 수용
  • 범용 프레임워크 — 텍스트(하위 태스크 계획)는 검증 기반 speculative decoding 유지
핵심 관찰: 경량 확산 드래프터가 AR 타깃보다 공간 정확도가 높으면서 훨씬 빠르게 디코딩할 수 있다

Flash Primitive Decoding의 작동 방식

1
도구 호출
가변 길이 예측의 크기 지정
2
레이아웃 결정
프리미티브 유형이 좌표 배치 결정
3
드래프팅
frozen 타깃 VLM 특징 조건하에 확산 드래프터가 프리미티브 전체 예측
4
구조적 수용
레이아웃별 문법 제약 적용 후 유효한 프리미티브 전체 수용

학습

주석된 프리미티비(annotated primitives)로 직접 학습 — 좌표 배치와 경계에 맞춘 블록 단위 훈련

텍스트 처리

일반 텍스트는 타깃 검증 speculative decoding 유지 → 출력 분포 보존

왜 구조 정렬이 작동하는가?

알려진 구조

프리미티브의 유형·차원·길이가 정해지면 경계와 좌표 레이아웃이 결정된다

→ 드래프트 블록을 프리미티브 경계에 정렬하면 수십~수백 토큰을 한 번에 공동 예측 가능

완화된 수용 기준

무손실 speculative decoding은 타깃 분포 보존이 목표 — 그러나 시각 계획은 공간 정확도와 행동 유용성으로 판단 가능

→ 구조적으로 유효한 드래프트는 타깃 토큰 일치 없이 수용

VLM의 System-1 모드의 시각 계획 — 좌표 공동 디코딩을 통한 빠르고 구조화된 공간 예측

실험 설정

다양한 시각 프리미티브 태스크와 다운스트림 응용에서 평가

시각 프리미티브 예측

  • 2D 로봇 궤적
  • 3D 로봇 궤적
  • 바운딩 박스 생성
  • Dense 3D 포인트 모션 예측

다운스트림 응용

  • 로봇 조작 파이프라인 (MolmoSpaces 세계 액션 모델)
  • LIBERO 조작 벤치마크
  • 자율주행 액션 모델 조건화

평가 플랫폼: NVIDIA Jetson Thor · DGX Spark · H100

결과 ① 정확도 — 속도만 빠른 것이 아니다

궤적 예측 오차 감소

평가된 2D·3D 로봇 궤적 태스크 전반에서 VFlash는 AR 디코딩 대비 예측 오차를 일관되게 감소

경량 확산 드래프터가 자기회귀 타깃 모델의 공간 정확도를 능가하는 현상 관찰

VFlash 계획 조건화 — 4개 태스크 스위트 평균 성공률

  • 시각 계획은 액션 모델에 유용한 조건 정보로 작용 — 정확도 향상이 조작 성공률 향상으로 직결
  • 동시에 파이프라인 전체의 추론 지연 약 80% 감소 (Jetson Thor · DGX Spark)

결론

  • 범용 디코딩 프레임워크 — 텍스트, 바운딩 박스, 가변 길이 2D/3D 궤적, dense 포인트 모션을 하나의 프레임워크로 처리
  • 구조 인지 병렬 디코딩 — 프리미티브의 유형·차원·길이에 맞춘 블록 정렬로 완전한 기하 객체를 한 번에 예측
  • 속도와 정확도의 동시 향상 — 자기회귀 디코딩이 시각 출력의 품질 상한일 필요 없음
  • 새로운 관점 — 시각 계획은 토큰 일치가 아닌 공간 정확도와 행동 유용성으로 평가되어야 한다
VFlash는 VLM에 System-1 모드의 시각 계획을 부여한다 — 빠르고, 구조화되며, 더 정확한 공간 예측
