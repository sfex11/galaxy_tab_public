Comparing Human Role-Players and
LLM-Simulated Clients in Online Counselling Training

온라인 상담 훈련에서 인간 역할자와 LLM 시뮬레이션 클라이언트 비교: 상담 패턴 분석

Eric Rudolph · Philipp Steigerwald · Jens Albrecht

Technische Hochschule Nürnberg Georg Simon Ohm, Nürnberg, Germany

Large Language Models Counselling Training Client Simulation

연구 배경

텍스트 기반 온라인 상담은 대면 상담의 유연하고 접근성 높은 대안으로 부상하였으며, 특별한 요구를 가진 다양한 집단에게 도달하는 데 기여하고 있습니다.

역할극(Role-Play) 훈련

상담사 교육에서 핵심 커뮤니케이션 역량 개발의 중심 · 통제되고 실습 중심적인 시나리오를 통해 기술을 탐색·성찰·개선할 기회 제공

인간 역할극의 현실

동료 학생이 클라이언트 역할을 수행 · 실제와 유사한 상호작용이 가능하지만 운영상의 제약이 존재

인간 역할극의 한계

  • 일정 조율 등 물류적 제약 — 여러 세션에 걸쳐 일관된 복잡성 유지가 어려움
  • 역할극 파트너의 가용성과 몰입 수준의 한계
  • 상호작용 전반에서 캐릭터의 깊이와 일관성을 유지하기 어려움

핵심 문제  이러한 제약은 훈련의 질적 일관성과 확장성을 저해하며, 보다 표준화되고 반복 가능한 연습 환경에 대한 요구로 이어짐

LLM 가상 클라이언트의 잠재력

표준화

일관된 시나리오와 난이도로 훈련 품질 보장

24시간 가용성

시간·장소 제약 없이 언제든 연습 가능

안전한 반복 연습

위험 없는 환경에서 자유로운 실험과 실수 학습

그러나 핵심 질문이 남는다 — LLM이 만들어낸 클라이언트는 진정성 있는 대화 역학을 보이는가? 인간 상대와 동일한 커뮤니케이션 패턴을 상담사에게 유발하는가?

연구 질문

Q1

LLM이 생성한 응답은 진짜 대화 역학(authentic conversational dynamics)을 어느 정도까지 재현하는가?

Q2

상담사의 커뮤니케이션 행동은 인간 클라이언트와 대화할 때와 LLM 시뮬레이션 클라이언트와 대화할 때 달라지는가?

방법  두 종류의 역할극 세션을 녹화하고, 문장(sentence) 수준에서 상담 커뮤니케이션 패턴 체계로 분석 — Mixtral 8x7B(4-bit 양자화) 기반 클라이언트 사용

관련 연구

  • Human-LLM 역할극 연구 — 구조화된 시나리오는 가능하나 자발성·맥락 적응에서 인간 대비 차이 존재
  • GPT-4 기반 세션 생성 연구 — 전문 상담사 평가에서 대화 패턴 재현 가능성 입증, 그러나 응답 일관성·정서적 진정성은 개선 필요
  • VirCo — 오픈소스 LLM + 페르소나 기술·역할극 전사(transcript)를 활용한 가상 클라이언트 시스템, 프라이버시 고려
  • 체계적 문헌 검토 — 위험 없는 환경에서 소통 전략 연습·즉각적 피드백 가능, 편향·윤리·오정보 우려 병존

본 연구의 차별점  GeCCo 표준 범주 체계를 사용하여 인간-인간 vs 인간-LLM 상담 대화를 정량적으로 직접 비교한 최초의 연구

데이터셋 구성

Human–Human

  • 사회복지 학위 프로그램의 온라인 상담 기초 수업
  • 채팅 플랫폼에서 64개 상담 세션 진행
  • 학생 1명이 클라이언트 역할, 사례 스터디(case study)를 선택해 역할 구성

Human–LLM

  • VirCo 방법론 기반 채팅 상담 연습 학습 플랫폼
  • 74개 세션 · 동일한 사례 스터디를 시스템 프롬프트에 통합
  • Vicuna 13B → Mixtral 8x7B (4-bit 양자화)로 교체 — MoE 아키텍처로 빠른 추론, 동시 다중 요청 처리에 유리

단일 모델을 사용하여 두 데이터셋 간 문장 수 유사성을 확보하고, 분석의 교란 변수를 최소화

방법론: GeCCo 범주 체계

위계적 분류 프레임워크

  • 독일어 온라인 상담 대화 분석을 위한 특화 체계 (German E-Counselling Conversation Dataset)
  • 최대 5계층의 추상화 구조 — 5계층에서 상담사 40개·클라이언트 28개 세부 범주
  • 동기부여 면담(Motivational Interviewing) 등 다양한 상담 모델의 통합

자동 분류 파이프라인

  • GBERT Large 분류기를 기반으로 학습
  • GPT-4 합성 데이터로 추가 fine-tuning하여 대화 분류 수행
  • 본 연구는 Layer 3에서 분석 수행 (Layer 1: 가장 추상적 → Layer 5: 가장 세분화)

결과 ① 패턴 분포 분석

유사점

두 시나리오에서 상담 패턴의 전반적인 분포가 유사하게 나타남 — LLM 클라이언트가 상담사로부터 인간과 비슷한 상호작용 패턴을 이끌어낼 수 있음을 시사

차이점

클라이언트가 고민을 개시·표현하는 방식과 상담사가 세션을 구조화하고 응답하는 방식에서 시나리오 간 차이 확인

핵심 발견: 상담 패턴의 적용에서 유사점과 차이점이 공존 — LLM 역할극이 진정성 있는 훈련 경험을 제공할 잠재력을 보이면서도, 개선이 필요한 영역을 특정할 수 있음

결과 ② 시간적·의미적 분석

시간적 분석 (Temporal)

세션 진행에 따른 상호작용 패턴의 시간적 진화를 비교 · 세션의 시작—전개—마무리 단계에서 두 시나리오 간 상담사 행동과 클라이언트 반응 패턴의 변화 양상 확인

의미적 분석 (Semantic)

문제 명료화, 목표 합의, 문제해결 지원, 동기 부여 등 GeCCo 주요 범주별 사용 양상 분석 · 클라이언트의 고민 개시와 상담사의 대응에서 의미적 유사성·차이 식별

  • LLM 기반 역할극은 상담 훈련의 핵심 패턴을 상당 부분 재현
  • 동시에 가상 클라이언트가 실제 인간과의 상호작용에서만 나타나는 역학을 완전히 대체하지는 못함

교육적 시사점

역량 강화 잠재력

LLM 기반 역할극 연습은 상담 역량 향상을 위한 실질적인 훈련 도구가 될 수 있음

개선 영역 식별

패턴 비교 분석을 통해 가상 클라이언트 시뮬레이션에서 정교화가 필요한 지점을 구체적으로 특정

보완적 활용

표준화·반복 가능성 덕분에 인간 역할극을 대체하기보다 보완하는 하이브리드 훈련 설계에 적합

LLM 기반 역할극은 미래 상담사 훈련 방식을 증강하고, 나아가 변혁할 잠재력을 지님 — 단, 가상 클라이언트와 인간 클라이언트 간 격차를 좁히기 위한 추가 개발이 전제되어야 함

한계점 및 결론

한계점

  • 단일 LLM(Mixtral 8x7B, 4-bit 양자화)만 사용 — 모델 일반화에 한계
  • 독일어 데이터와 자동 분류기에 대한 의존
  • 학생(초심자) 참가자 중심의 세션 구성

결론 및 향후 연구

  • LLM 시뮬레이션 클라이언트가 유의미한 수준의 대화 역학 재현
  • 가상·인간 클라이언트 간 격차를 좁히기 위한 지속적 개선 필요
  • 다양한 모델·범주 체계로의 확장이 향후 과제
