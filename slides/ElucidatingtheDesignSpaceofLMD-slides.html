Elucidating the Design Space of LM Data Attribution

왜 어트리뷰션은 실패하는가? — 통제 가능한 벤치마크 CATT로 실패 원인을 고립하고, 손실 설계와 토큰 집계라는 두 가지 설계 선택만으로 성능을 크게 개선합니다.

CATT 벤치마크 Negative Log-Odds 희석(Dilution) 현상

데이터 어트리뷰션이란?

모델의 특정 행동을 유발한 학습 예시를 식별하는 기술
  • 예측: 해당 예시 없이 학습하면 목표 행동이 사라진다는 반사실(counterfactual) 예측
  • 예: "Marie Curie는 바르샤바에서 태어났다"는 사실을 만든 학습 문서를 찾아냄
  • 그러나 대규모 모델을 재학습하며 검증하는 것은 계산적으로 불가능

→ 신뢰할 수 있는 평가 방법이 없는 상태에서 알고리즘 개선이 이루어져 왔습니다.

CATT: Controlled Attribution Benchmark

사전학습에 전혀 없던 가상의 지식으로 LLM(Qwen3.5-4B)을 파인튜닝

1
가상 사실 생성
합성 문서가 해당 지식의 유일한 인과적 원천
2
파인튜닝
명확한 정답(ground truth) 확보
3
질의 평가
학습 문서와 다른 표현의 질의로 문서 랭킹 검증
데이터셋 속성을 한 번에 하나씩 변경 → 어트리뷰션 실패 원인을 정밀하게 진단

두 가지 파인튜닝 태스크

Task I

Function Bindings

새로운 함수가 항상 고정된 값을 반환하도록 학습하는 원자적(atomic) 바인딩 태스크

예: f(x) = 상수값

Task II

Routing Rules

객체의 속성에 조건부로 결과를 라우팅하는 합성적(compositional) 규칙 태스크

예: 조건 → 결과 분기 규칙

서로 다른 두 태스크에서 결론이 일관되면, 발견의 범용성을 확신할 수 있습니다.

통제 가능한 설계 공간

중복성 (Redundancy)

같은 사실을 N개의 서로 다른 스타일의 문서로 반복 제시

어휘 교란자 (Distractors)

질의 형식을 완벽히 모방하지만 무관한 문서를 주입

사실 개수 (Facts)

데이터셋에 포함된 사실의 수를 단계적으로 증가

교란자는 표면적 텍스트 중복에 의존하는 방법을 적나라하게 드러냅니다.

핵심 발견: 희석(Dilution) 현상

  • 중복과 교란자가 어트리뷰션 성능을 일관되게 저하
  • 문서 내 진짜 인과 증거는 소수 토큰에 국지화
  • 기존 방법은 문서 전체에 걸쳐 평균하여 신호를 노이즈로 희석

토큰별 영향력 분포 비교

해결책 1: 토큰 수준 Negative Log-Odds

문제

Cross-Entropy의 함정

모델이 타깃 토큰을 자신 있게 예측하면 그래디언트가 0이 되어, 정답의 핵심 토큰의 증거가 소실

해결

Log-Odds로의 전환

토큰 수준 negative log-odds는 신뢰도 인자를 제거하여 중요한 토큰이 노이즈에서 명확히 부상

모든 그래디언트 기반 어트리뷰션 방법에 즉시 적용 가능한 범용 수정

해결책 2: Top-k 토큰 집계

1
토큰 점수 계산
NLL 손실로 토큰별 영향력 산출
2
Top-k 선택
국지화된 증거 토큰만 추림
3
문서 점수 집계
선택된 토큰만으로 문서 랭킹

  • 중복성·교란자로 인한 희석 효과를 완화

TRAK EK-FAC Grad-Dot

테스트한 모든 방법에서 개선 → NLL 교정은 다양한 태스크에서 인과 증거를 안정적으로 추출

기여 요약

  • CATT 벤치마크 제안 — 중복성·어휘 교란자 등 속성을 통제하는 설정 가능한 합성 fact-tracing 벤치마크
  • 희석 현상 규명 — 표준 방법이 문서 전체 평균으로 국지화된 토큰 증거를 잡음에 묻는 메커니즘 발견
  • 간단한 두 가지 수정 — NLL 그래디언트 + Top-k 토큰 집계로 recall 35~72%p 향상
  • 일반성 입증 — FTRACE-TREX에서 TRAK·EK-FAC·Grad-Dot 개선, 최대 4.9×
