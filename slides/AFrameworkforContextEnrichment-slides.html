연구 배경: LLM 사회 시뮬레이션의 검증 문제

LLM 에이전트 시뮬레이션

  • 역할·설정·관계·기억·목표 등을 프롬프트로 제공
  • Concordia, SOTOPIA 등에서 사회적 세계를 언어로 구성
  • 프롬프트된 맥락(context)이 시뮬레이션의 근본 변수

취약성(Brittleness) 문제

의미는 동일하게 유지되는 프롬프트 변화(표현·형식)만으로도 에이전트 행동이 크게 달라짐 → 사회 시뮬레이션의 검증(validation) 문제 발생

죄수의 딜레마 게임에서 맥락 형식만 바꿨을 때 협력률이 최대 76 퍼센트포인트까지 변동 (Ye et al., 2026)

핵심 질문

"맥락이 취약한 것은 접지(grounding) 부족 때문일 것이다. 그렇다면 더 풍부한 맥락이 견고성을 높여줄까?"

문제 1: 맥락 풍부화의 정의 부재

"풍부함(richness)"은 단일한 개입이 아님 — 텍스트 추가, 일반적 사회 정보, 결정 연계, 규범적 지시 등 서로 다른 기능이 섞여 있음

문제 2: 견고성의 정의 부재

견고성과 풍부함이 통제된 비교가 가능한 방식으로 정의되지 않아, 어떤 속성이 행동 변화를 만드는지 파악하기 어려움

세 가지 기여

1
통제된 맥락 풍부화
최소 맥락 기저선 + 4개 풍부화 조건(중립 패딩, 일반 사회 배경, 서술적 결정 접지, 규범적 결정 접지)의 규칙 기반 분해
2
선택적 견고성
표면 불변성(surface invariance)과 사회 세계의 의미 있는 변화에 대한 방향성 반응성을 결합한 검증 기준
3
파일럿 연구
두 모델에서 맥락 구성의 상이한 행동 효과와 상이한 실패 양상을 드러내는 실증 사례

파일럿 연구는 단일 시나리오로 수행되어 프레임워크의 유용성을 보여주는 것이 목적이지, 일반적 효과를 입증하지 않음

프레임워크 ①: 통제된 맥락 풍부화

  • 공통 프롬프트 스캐폴드 안에서 규칙 기반 치환(substitution)으로 맥락 풍부화를 조작화
  • 5개 조건 모두에서 초점 역할, 결정 과제, 사회 세계 대비(world contrast)는 고정
  • 풍부화 블록은 누적되지 않고 서로 대체 — 같은 위치에 하나씩 삽입
  • 조건 간 순서는 기능의 차이를 반영할 뿐, 더 길거나 "더 풍부한" 정도의 그라디언트가 아님

사회 세계 대비를 포함하면, 에이전트가 세계의 의미 있는 변화에 반응하는지 — 즉 선택적 견고성의 요구 — 를 함께 점검할 수 있음

5가지 맥락 조건

조건추가 맥락세계 대비결정 연계규범 강제
1. 최소없음✓––
2. 중립 패딩무관한 배경 세부사항✓––
3. 일반 사회 배경결절에 묶이지 않은 역할 정보✓––
4. 서술적 결정 접지관계·규칙·적용 범위✓✓–
5. 규범적 결정 접지4와 동일 + 역할 요구사항✓✓✓

역할·결정 과제·결정 관련 세계 대비는 항상 포함되며, 풍부화 블록은 서로 대체됩니다.

조건별 기능 상세

1. 최소 (Minimal)

역할 식별, 결정 이해, 관련 사회 세계 구분에 필요한 최소 정보만 포함

2. 중립 패딩 (Neutral Padding)

에이전트의 사회적 위치를 확장하거나 결정과 연결되지 않는 배경 정보 추가

3. 일반 사회 배경 (Generic Social Background)

관계·집단 소속·반복적 역할 등 사회적 맥락은 제공하나 현재 결정과 절차에는 비연결

4. 서술적 결정 접지 (Descriptive)

관련 관계, 규칙·절차의 범위, 결정에의 적용을 명시. 의무 부여나 행동 권고 없음

5. 규범적 결정 접지 (Normative)

서술적 접지의 관계·절차 사실을 유지하면서 요구사항·책임을 명시적으로 표현. 규범적 강제력은 도입하되 특정 행동까지는 지시하지 않음

프레임워크 ②: 선택적 견고성 (Selective Robustness)

견고성은 선택적이어야 한다 — 표면 변화에는 안정적이되, 의미 있는 변화에는 반응적이어야 함

표면 불변성 (Surface Invariance)

  • 고정된 세계·조건 내에서 의미 보존 표현 변화에 행동이 유사해야 함
  • 페르소나 형식, 게임 프레이밍, 서사 변화를 통한 기존 견고성 감사와 연결
  • 표현 간 큰 차이 = 사회 상황이 아닌 표면 형식에 민감하다는 신호

세계 반응성 (World Responsiveness)

  • 고정된 조건·표현 내에서 결정 관련 세계 변화에 행동이 반응해야 함
  • 사전 지정된 방향으로 행동이 이동하는지 확인
  • 메타모픽 테스트·CheckList(불변성 + 방향성 기대 테스트)의 논리를 LLM 사회 에이전트에 적용

파일럿 실험 설계

게임 설정
죄수의 딜레마 유사 게임에서 협력/배신 결정을 확률로 측정
요인 설계
5개 맥락 조건 × 표현 변형(표준 산문 vs 대체 산문) × 세계 대비
모델 비교
두 개의 LLM에 동일 프로토콜 적용하여 행동 패턴 비교

프롬프트 재질: 고정 오프닝·결정 블록, 사회 맥락 블록, 표준/대체 산문 버전의 세계 사실과 풍부화 모듈

분석: 선택적 견고성의 두 축(표면 불변성, 세계 반응성)에 따라 조건별 행동을 정량 평가

주요 발견

01

풍부화 조건들이 상이한 행동 패턴을 만들어냄 — "풍부함"이라는 한 단어로는 포착할 수 없는 기능별 차이

02

이러한 패턴은 테스트된 두 모델 간에 달라짐 — 동일한 맥락 개입이 모델마다 다르게 작용

03

프레임워크가 모델별 상이한 실패 양상을 드러냄 — 어떤 풍부화가 더 바람직하고 견고한 행동을 만드는지 식별 가능

즉, 맥락 풍부화와 견고성을 통제된 방식으로 분해하면, 단순히 "더 많은 맥락"이 아니라 어떤 종류의 맥락이 어떤 효과를 내는지 구체적으로 진단할 수 있다.

논의 및 한계

의의

  • 맥락 풍부화를 기능별로 분해하는 재현 가능한 프롬프트 규칙 제공
  • 불변성 + 방향성 반응을 결합한 실용적 검증 기준 제시
  • 사회 시뮬레이션의 표준화·재현성 논의에 기여

한계

  • 단일 글로벌 시나리오에서 수행된 파일럿 규모
  • 결과는 프레임워크 유용성의 예시일 뿐, 맥락 풍부화의 일반 효과 입증이 아님
  • 두 모델로의 결과 일반화에는 주의 필요
