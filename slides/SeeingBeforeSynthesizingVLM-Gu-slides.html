  배경: Weakly-Supervised Dense Video Captioning

  Dense Video Captioning (DVC)

  • 긴 untrimmed 비디오에서 여러 이벤트를 localize하고 설명
  • Fully-supervised는 이벤트별 시작/끝 타임스탬프 + 캡션 필요
  • 세밀한 dense annotation은 비용이 크고 확장이 어려움

  Weakly-Supervised 설정 (WSDVC)

  • 비디오당 순서가 있는 이벤트 캡션 시퀀스만 제공
  • 타임스탬프는 전혀 주어지지 않음
  • 학습의 핵심 단서 = Vision-Language 정렬

  핵심 과제: 언어 supervision을 실제 시각 콘텐츠와 어떻게 정렬하여 세밀한 이벤트 localization을 학습할 것인가?

  기존 방법(SAIL)의 두 가지 한계

SAIL은 LLM으로 GT 텍스트만 참고해 transition caption을 합성하고, 모든 이벤트 간 gap에 기계적으로 삽입

1

Whether — 전환 존재 여부를 묻지 않음

  • 모든 gap에 전환 이벤트가 있다고 맹목적 가정
  • 이미 GT 캡션이 잘 커버한 영역에 중복 캡션 → 노이즈
  • 비디오를 보지 않은 합성이라 hallucination 발생 (예: 실제 없는 "pour a cup of water")
2

Where — 위치가 고정 규칙에 갇힘

  • 전환은 항상 두 이벤트 중심의 중간점(midpoint)에 있다고 가정
  • 고정된 duration 부여 → 실제 전환 패턴과 무관
  • 실제 전환 위치가 중간점에서 어긋나면 학습에 악영향

  핵심 아이디어: 합성하기 전에 먼저 본다

"VLM을 캡션 생성기가 아니라 전환 이벤트 탐색 도구(transition-search tool)로 활용하자"

  Whether

프레임 간 시맨틱 변화를 측정하여, 정보성 있는 전환이 실제로 존재할 때만 적응적 gate가 열리고 transition supervision이 활성화

  Where

가장 큰 변화가 일어나는 semantic change point를 기반으로 전환 이벤트의 중심과 폭을 콘텐츠에 맞게 결정

  인지과학적 착안: 인간은 지각 변화가 큰 지점에서 연속적인 활동을 이산적 이벤트로 분할한다 (Event Segmentation Theory, Tversky & Zacks)

  왜 저수준 특징이 아닌 '언어' 신호인가?

  저수준 시각 특징의 문제

  • 카메라 움직임, 조명 변화 등 비시맨틱 노이즈에 매우 취약
  • 노이즈가 실제 이벤트 전환으로 오인되기 쉬움

  VLM 기반 언어 기술의 장점

  • 각 프레임을 의미적으로 추상화된 설명으로 변환
  • 외관은 유사해도 의미 전환은 명확히 포착 가능
  • 캡션 임베딩 간 변화 = 노이즈에 강한 전환 신호

  주요 기여

  • 재정립: WSDVC의 전환 증강을 text-only 합성에서 visually grounded 전환 이벤트 발견으로 전환
  • 프레임워크: VLM 기반 적응적 gate + semantic change point를 통한 전환 영역 localization (SBS)
  • 검증: ActivityNet·YouCook2에서 captioning과 localization 모두 SOTA 달성

  SBS 전체 프레임워크

1
이벤트 마스크 예측
CLIP ViT-L/14 특징 + Transformer decoder + event queries로 각 이벤트의 중심/폭 → Gaussian mask
2
Gap 내러티브 생성
이벤트 간 gap의 프레임들에 대해 VLM이 프레임별 의미 기술 생성
3
전환 탐지 (Gate)
연속 프레임 캡션 임베딩 간 시맨틱 변화를 적응적 임계값과 비교
4
위치·폭 결정
change point와 midpoint를 보간해 중심 결정, VL 정렬 최대화 폭 선택
5
추가 정렬
transition caption을 해당 시각 영역에 정렬하여 supervision 강화

  기반 구조: differentiable Gaussian mask로 이벤트 영역 표현 → 각 이벤트 표현에서 시간 중심 cn과 폭 wn을 sigmoid로 예측

  방법 ① 적응적 전환 Gate (Whether)

프레임 내러티브
gap 내 연속 프레임을 VLM으로 언어 기술
시맨틱 변화 측정
연속 캡션 임베딩 간 의미 변화를 신호로 계산
적응적 Gate 판정
gap별 국소 변화 통계로 임계값을 결정

  신호 > 임계값

유의미한 전환으로 판단 → gate 개방 → 해당 gap에 inter-event supervision 활성화

  신호 ≤ 임계값

전환 없음으로 판단 → gate 폐쇄 → 불필요한 transition caption 생략

  효과: hallucination 감소 + 이미 잘 묘사된 영역에 대한 중복 캡션 노이즈 방지 — "필요한 곳에만" 언어 guidance 제공

  방법 ② 전환 이벤트 Localization (Where)

  기존 방식

이웃 이벤트 중심들의 고정 midpoint에 고정 폭 할당 → 영상 내용에 blind

  SBS 방식

최대 변화 지점인 semantic change point를 활용한 콘텐츠 적응형 결정

  • 중심 결정: semantic change point와 midpoint를 보간(interpolation) — 변화 지점 근처에 anchor하되, 이웃 이벤트 중심으로 붕괴하는 것을 방지
  • 폭 결정: 전환 caption과 시각 영역의 vision-language 정렬을 최대화하는 폭을 탐색하여 선택
  • 효과: 결정된 temporal span이 전환 caption의 시각 영역을 정의 → 모델에 추가 정렬 신호 공급

  실제 전환의 위치와 지속 시간에 유연하게 적응 → 고정 규칙으로 인한 misalignment 해소

  실험: 주요 결과

  ActivityNet Captions

다양한 일상 활동의 긴 untrimmed 비디오 — 복잡한 이벤트 흐름에서 captioning·localization 모두 SOTA

  YouCook2

순서가 명확한 요리 절차 비디오 — 절차적 전환이 많은 도메인에서도 SOTA

  정성적 결과

  기존 (SAIL)

  • 실제로 물을 따르지 않는데 "pour a cup of water" 라는 환각 캡션 생성
  • 전환이 필요 없는 gap까지 모두 강제로 연결
  • 영상 내용과 무관한 언어 신호로 정렬 학습 오염

  제안 (SBS)

  • 실제 semantic transition이 감지된 gap만 선택적으로 보강
  • 실제 변화 지점에 visually grounded 캡션 배치
  • 더 정확한 이벤트 경계와 hallucination 감소

  "먼저 보고(SB) 나중에 합성(S)" — 관찰에 기반한 선택적 언어 신호가 WSDVC의 두 task를 동시에 끌어올림

  결론

  • WSDVC의 transition augmentation을 text-only 합성에서 visually grounded 전환 이벤트 발견으로 재정의
  • VLM을 transition-search 도구로 재활용 — 적응적 gate(whether)와 semantic change point 기반 localization(where)을 모두 해결
  • ActivityNet Captions·YouCook2에서 captioning과 localization 동시 SOTA 달성
