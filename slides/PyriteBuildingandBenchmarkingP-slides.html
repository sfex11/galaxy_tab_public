Pyrite

단백질-리간드 포즈 랭킹 에이전트의 구축과 벤치마킹

Megha Srivastava (Stanford) · Michael H. Lim · Allison M. Keys · Pranav Murugan · Nate Gruver

Genesis Molecular AI

왜 포즈 랭킹인가?

구조 기반 약물 설계의 현실

  • 실험적 결정 구조는 느리고 비용이 큼
  • 최신 코폴딩 모델이 다양한 후보 포즈 생성 가능
  • 다양성이 유용하려면 가장 그럴듯한 포즈를 골라내야 함

랭킹이 어려운 이유

  • 이용 가능한 신호들이 개별적으로는 약함
  • MM-GBSA, torsional strain 등 점수들이 서로 모순되는 경우가 많음
  • 도구 호출은 쉽지만, 출력 해석이 어려움

핵심 질문: 화학자와 동일한 도구를 준 AI 에이전트가 도구 단독이나 전문가보다 정확하게 포즈를 랭킹할 수 있을까?

문제 설정: Pairwise Pose Ranking

테스트 시점에는 단백질-리간드 복합체의 실제 결정학적 결합 모드를 알 수 없음. 좋은 랭커는 주어진 두 후보 포즈 중 실제 구조에 더 가까운 쪽을 선택해야 함.

전문가 화학자의 추론 예시: "두 포즈 모두 평면형 공액 시스템의 소수성/방향족 상호작용이 지배적. Pose A가 더 매몰된 것으로 보임. 피리딘이 회전해 Pose B처럼 Lys 648와 같은 수소결합을 형성할 수 있음."

화학자는 물리적 추론과 직관적 특징을 결합해 수많은 요소를 저울질하며 결정을 내림 — 이 과정 전체를 AI 에이전트가 수행할 수 있는가?

고유 포즈

기존 벤치마크와의 차별점

공개 코폴딩 모델은 포즈 다양성이 낮아 물리 기반 점수의 랭킹 효용이 떨어짐. Pyrite는 독자 코폴딩 모델 + 다양성 촉진 샘플링으로 어려운 decoy를 포함한 도전적 벤치마크 구축.

놀라운 발견: 전문가도 확률 수준

실험 설정

  • 전문 화학자 + 3D 시각화 도구 제공
  • MM-GBSA 점수, Mogul 비정상 torsion 수 등 물리 점수 제공
  • 2D 접촉맵 · 3D · overlay 뷰 토글 가능

결과

  • 전문가 성능이 무작위 수준에 근접 또는 그 이하
  • 그럼에도 주석자 간 일관성(substantial agreement)은 높음
  • 물리 점수는 일부 반상관(anti-correlated) 경향

기존 화학 직관은 고품질 코폴딩 포즈를 구분하는 데 오히려 misleading할 수 있음 → 자동화된 랭킹의 필요성 부각

PyriteRep: AI 에이전트를 위한 구조화 표현

원시 3D 좌표만으로는 LLM이 포즈를 판단하기 어려움. PyriteRep는 포즈를 텍스트 친화적 구조화 데이터로 변환.

분자 기하학

포즈의 3D 형상 정보를 구조화된 형태로 표현

단백질-리간드 상호작용

수소결합, 소수성 접촉 등 결합 인터페이스 정보

물리화학 점수

MM-GBSA 등 사전 계산된 물리 기반 특징 포함

PyriteRep는 원시 3D 좌표 대비 LLM 에이전트의 포즈 랭킹 정확도를 크게 향상

두 가지 LLM 에이전트 설계

텍스트 추론 기반

PyriteReasoner

  • PyriteRep 표현을 직접 읽고 텍스트 기반 화학 추론으로 두 포즈 비교
  • 최대 67% 정확도 달성
  • 관찰된 전문가 성능 초과
코드 생성 기반

PyriteFeaturizer

  • LLM이 실행 가능한 코드를 생성해 예측적 구조 특징 발견
  • 특징으로 경량 로지스틱 회귀 분류기 학습
  • 최대 74% 정확도 — 벤치마크 최고 성능

연구 질문: LLM은 직접 랭커로 더 효과적인가, 아니면 통계 모델의 특징 엔지니어로 더 효과적인가?

PyriteFeaturizer의 하위 호출 설계

1
코드 특징
LLM이 정량적 구조 서술자 코드를 작성
2
LLM 서브콜
단백질/포즈 분석 등 지식 기반 특징을 서브콜로 생성
3
로지스틱 회귀
코드 특징 + LLM 특징을 결합해 경량 분류기 학습

핵심 통찰: LLM 유도 특징 발견(LLM-guided feature discovery)이 직접 추론보다 일반적으로 우수하며, 계산화학 도구의 출력을 해석·결합하는 유망한 접근법

GRPO로 강화된 오픈 웨이트 모델

Group Relative Policy Optimization (GRPO) 강화학습을 적용해 오픈 웨이트 모델의 포즈 랭킹 능력을 개선

PyriteReasoner에 적용

오픈 웨이트 모델의 성능을 향상시켜 클로즈드 소스 프론티어 모델과의 격차를 축소

PyriteFeaturizer에 적용

오픈 웨이트 모델의 특징 발견 능력이 대폭 개선되어 프론티어 모델을 추월 또는 대등하게 달성

실험 결과 요약

방법접근 방식최고 정확도

고전적 ML(정량적 구조 특징 학습)이 직접 LLM 추론과 놀랍도록 경쟁력 있음 — 그러나 LLM 유도 특징 발견이 화학·생물학 지식을 추가로 통합해 이를 능가

핵심 기여 정리

1
Pyrite — 다양한 고품질 코폴딩 포즈로 구축된 최초의 전용 pairwise 포즈 랭킹 벤치마크. 전문가가 확률 수준임을 밝히고 물리 점수의 반상관 확인
2
PyriteRep — 분자 기하학·상호작용·물리 특징을 담은 구조화 데이터 포맷. 원시 좌표 대비 정확도 대폭 향상
3
PyriteReasoner — 텍스트 기반 화학 추론으로 최대 67% 달성. RL로 오픈 웨이트 모델 격차 축소
4
PyriteFeaturizer — LLM 코딩 에이전트 기반 특징 발견으로 최대 74%, 벤치마크 최고 성능 기록

결론과 향후 방향

현대 코폴딩 모델이 생성한 포즈의 랭킹은 경험 많은 화학자에게도 어려운 문제. LLM 유도 특징 발견은 계산화학 도구 출력을 해석하고 결합하는 유망한 길.
