RAPID

Robot Agentic Programming from Demonstrations

단 하나의 시각적 시연으로 로봇 프로그램을 자동 생성·검증·개선하는 에이전틱 프레임워크

Yuyao Liu · Jiayuan Mao · David Hsu · Leslie Pack Kaelbling · Tomás Lozano-Pérez

MIT · NUS · UPenn · NVIDIA

배경: 코딩 에이전트를 로봇 조작으로

코딩 에이전트는 복잡한 소프트웨어 개발에서 뛰어난 성능을 보여왔으며, 로봇 조작 과제를 프로그래밍으로 해결하려는 시도가 활발합니다.

인간 엔지니어의 개발 워크플로우

과제가 주어지면(시리얼 박스 집기) → 해결 전략을 프로그램으로 구현 (press → push → flip → grasp) → 테스트 케이스로 검증 → 반복 디버깅

이것이 바로 에이전틱 코딩 루프: 한 번의 코드 생성이 아니라 생성 → 실행 → 검증 → 수정의 반복

도전 과제: 에이전틱 루프를 닫기 위한 3가지 요소

로봇 조작에 에이전틱 코딩 루프를 적용하려면 사전에 주어지지 않은 재료들이 필요합니다.

1

테스트 가능한 과제 명세

의도된 결과를 정의하고 프로그램 성공 여부를 판정

2

조작 프리미티브

프로그램 수준 추론과 저수준 실행을 연결

3

대화형 환경

프로그램의 실행·검증·수정을 위한 시뮬레이션

기존 로봇 코딩 에이전트 시스템은 정답 보상, 인간이 설계한 프리미티브, 리셋 가능한 환경을 사전에(a priori) 제공받는다고 가정합니다.

핵심 아이디어: 시연(Demonstration)을 프로그래밍 인터페이스로

하나의 시연은 과제를 수행하는 실행 가능한 방법을 직접 보여주며, 언어 설명과 함께 의도된 결과를 전달합니다.

  • 시연으로부터 과제 명세를 자동 추론
  • 시연으로부터 조작 프리미티브를 구성하고 전략으로 합성
  • 시연으로부터 대화형 시뮬레이션 환경을 재구성하여 검증·개선 루프 구동
  • 장면 변형(variant)을 생성하여 일반화 능력까지 향상

단 하나의 시연이 에이전틱 코딩 루프에 필요한 세 가지 재료를 모두 부트스트랩합니다.

RAPID 시스템 개요

시각적 시연 D와 언어 설명 l이 주어지면, 재사용 가능한 전략 프로그램 Π을 생성합니다.

1
환경 재구성
시연 장면을 대화형 시뮬레이션 E로 복원
2
프리미티브 구성
궤적 최적화 프로그램 P1…PN 자동 작성
3
전략 합성
관계형 제약 ci로 프리미티브를 연결해 Π 생성
4
검증 · 개선
장면 변형 집합에서 실행하고 실패 기반 반복 수정

입력으로 정답 보상, 인간 설계 프리미티브, 리셋 가능한 환경이 전혀 제공되지 않습니다.

객체 중심 관계형 프로그램 표현

목표는 시연을 단순히 재현하는 것이 아니라 재사용·일반화 가능한 조작 프로그램을 추출하는 것입니다.

고정 좌표 방식

자세·거리·경유지를 직접 인코딩
→ 시연 장면에서만 성공, 장면 변화에 취약

RAPID의 접근

객체 중심 관계와 효과로 전략의 구조를 표현
→ 모양·자세·물성·장면 구성 변화에 강건

"구체적인 모션 자체가 아니라 시연된 전략의 근본 구조에 집중한다"

프리미티브 = 지역 궤적 최적화 프로그램

각 프리미티브는 객체 수준의 모션 효과를 실현하는 궤적 최적화 프로그램으로 작성됩니다.

Press & Move

객체를 지정된 변위만큼 밀어 이동

Flip

객체를 지정된 각도만큼 뒤집기

Grasp

최종 대상 객체 파지

밀기·피벗·넘기기·뒤집기·미끄러뜨리기 등 비예동적(nonprehensile) 조작은 접촉 의존적 상호작용이 다양해 고정 프리미티브 라이브러리 구축이 어렵습니다. RAPID는 프리미티브를 자동 구성합니다.

관계형 제약을 통한 전략 합성

프리미티브들은 관계형 제약으로 연결됩니다. 한 단계의 결과가 다음 단계의 목표를 결정합니다.

예시: press-move 단계의 목표 계산

1. 고정 모션이 아니라 장애물-고정구의 관계로부터 목표 위치를 계산

2. 이전 프리미티브 (flip)이 만든 상태에 기반해 현재 프리미티브 (press-move)가 객체를 얼마나 이동시킬지 결정

불변 구조 보존

시연된 전략의 논리적 구조는 유지

실행 시점 적응

장면별 기하는 실행 시점에 관계로부터 해결

에이전틱 루프: 환경 재구성과 검증

대화형 환경 재구성

시연으로부터 시뮬레이션 환경을 복원하여 프로그램 실행·평가·수정이 가능한 공간 확보

장면 변형(variant) 생성

시연 장면을 섭동하여 일반화 검증용 장면 변형 집합 구축

과제별 필터링

코딩 에이전트가 물리적으로 불가능하거나 과제와 불일치하는 변형을 제거하는 필터를 자동 작성

실행 → 관찰 → 반복 수정

검증 집합 전체에서 후보 프로그램을 실행하고, 관찰된 실패를 바탕으로 반복적으로 개선

평가 질문: 단 하나의 시연 사례로 구성된 프로그램이 객체 외형·자세·기하·물성·장면 구성의 큰 변화에 일반화할 수 있는가?

실험 결과

  • 사전 제공된 성공 신호·인간 설계 프리미티브·리셋 가능한 환경 없이도 기존 베이스라인을 능가
  • 비예동적 조작 8과제 모두에서 강력한 성능 달성 (시뮬레이션 + 실제 Franka)
  • 객체 자세 · 형상 · 재질 · 환경 변화에 걸친 일반화 입증
  • LIBERO-Pro 예동적 조작에서도 범용성 확인
