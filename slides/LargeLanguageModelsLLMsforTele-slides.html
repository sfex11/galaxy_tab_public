통신 RCA의 진화: 규칙 기반 → ML → LLM

1
규칙 기반 전문가 시스템
사전 정의된 알람 패턴과 KPI 임계값에 의존 · 투명하고 결정적이지만 확장·갱신이 어려움
2
머신러닝(ML) 기반
원격측정 데이터의 통계적 패턴 학습 · 확장성은 우수하나 진단 추론이 아닌 라벨 예측에 그침
3
LLM 기반 추론
이기종 증거를 통합 추론 · 다단계 진단과 해설 생성 가능하나 구조적 정렬이 필요
핵심 과제는 LLM을 단순 적용하는 것이 아니라, 이기종 증거와 진단 결정을 연결하는 방식을 제어하는 것

왜 LLM인가: 통신 RCA에서의 세 가지 강점

다단계 추론

규칙 엔진의 고정 논리나 ML의 통계적 상관관계와 달리, 여러 시스템 지표를 단계별로 분석하여 잠재적 근본 원인을 도출

도메인 간 지식 통합

무선 접속망·전송망·코어망 등 분리된 특징 집합으로 운영되던 기존 방식과 달리, 이기종 도메인 지식을 통합한 교차 추론 수행

해설 생성

진단 과정을 사람이 읽을 수 있는 설명으로 생성 → RCA 결과의 해석 가능성 향상, 엔지니어의 근거 이해 지원

그 외에도 지식 이해, 전력 제어, 트래픽 예측, 네트워크 관리 등 통신 분야 전반에서 LLM 활용이 확대되는 중

vanilla LLM 직접 적용의 한계

한계문제 상황결과
불안정한 추론 이동성 동작, 자원 스케줄링, 커버리지 기하 등 다중 진단 요소의 체계적 검증 필요 유사한 네트워크 측정값에도 일관성 없는 추론 경로 생성
구조적 증거 미정렬 다중 계층의 이질적·구조화된 증거를 다루는 명시적 메커니즘 부재 인과관계가 아닌 표면적 상관관계에 의존한 진단
환각(Hallucination) KPI, 토폴로지 관계, 설정 파라미터 등 구체적 지표에 근거하지 않은 원인 추측 뒷받침 없는 잘못된 결론 도출

→ 이를 해결하기 위해 본 논문은 SEKA-FT: 구조화된 증거·지식 정렬 파인튜닝 프레임워크를 제안

LLM 기반 통신 RCA 기법들의 지형

왼쪽에서 오른쪽으로: 내부 구조화 → 외부 지식 정합 → 환경 상호작용 → 물리적 검증 정렬 (외부 정합성과 실세계 결합도 점진적 확대)

Chain-of-Thought (CoT)

진단 논리를 단계별로 구조화하여 모델 내부에서 체계적인 추론 경로를 형성

Retrieval-Augmented Generation (RAG)

외부 도메인 지식을 검색해 결합함으로써 추론의 지식 기반 정합성 확보

Agentic 오케스트레이션

환경과 능동적으로 상호작용하며 계획을 수립·수행하는 에이전트형 진단

RLVR (검증 가능한 보상 기반 강화학습)

결과 기반 피드백으로 물리적으로 검증 가능한 추론과 정렬을 달성

제안 프레임워크: SEKA-FT 개요

Structured Evidence- and Knowledge-Aligned Fine-Tuning

RCA를 입력→라벨 예측 문제가 아닌 구조화된 추론 문제로 정식화:
최종 결정 전에 이질적 네트워크 증거를 단계적으로 검토하는 증거 → 경로 → 결정 구조
  • 이질적 장애 분석 입력을 정규화된 컨텍스트 블록으로 재구성
  • 결정 경로 추론으로 RCA를 단계적 진단 점검으로 분해 — 지원되지 않는 가설을 배제
  • 증거 기반 해설을 감독 대상에 포함 → 구체적 통신 지표와 도메인 지식에 추적 가능한 진단

SEKA-FT의 세 가지 설계 축

① 정규 컨텍스트 구조화

사용자 평면 KPI, 이동성 통계, 이웃셀 관계, 엔지니어링 파라미터 등 이질적 텔레메트리를 일관되게 해석 가능한 정규 컨텍스트로 정리 → 안정적 파인튜닝의 기반

② CoT 기반 결정 경로 제어

RCA를 단계적 진단 점검으로 분해하는 결정 경로 추론 도입 → 신뢰할 수 없는 가설을 조기에 배제하고 일관된 진단 경로 유지

③ 증거·지식 정렬 해설 설계

생성된 진단이 구체적 통신 지표와 도메인 지식으로 추적 가능하도록 해설을 감독 대상에 포함 → 환각 완화

구조화된 증거, 중간 진단 경로, 최종 RCA 라벨, 추적 가능한 해설을 단일 파인튜닝 프로세스에서 공동 정렬

증거 → 경로 → 결정: 통합 정렬 목적함수

1
증거 (Evidence)
KPI · 이동성 통계 · 이웃셀 관계 · 엔지니어링 파라미터를 정규 컨텍스트로 통합
2
진단 경로 (Path)
단계별 점검 항목을 수행하며 지지되지 않는 가설 제거
3
결정 + 해설 (Decision)
최종 근본 원인 판정과 함께 구체적 증거에 연결된 해설 생성
  • 최종 라벨 감독만이 아니라 구조화된 진단 증거와 중간 추론 일관성까지 학습
  • 예측 기반 장애 처리에서 결정 경로 제어형 추론으로 전환
  • 근본 원인 식별 정확도와 진단 신뢰성 동시 향상

케이스 스터디: 실험 설정

TeleLogs

5G RCA 데이터셋 — 로그 기반 증거 표현과 진단 특성을 가진 벤치마크

TelecomTS

5G 관측 가능성(observability) 데이터셋 — 서로 다른 증거 표현을 지닌 시계열 중심 벤치마크

  • 5G 스루풋 저하 시나리오에서 진단 성능 평가
  • 비교 대상: ICL(문맥 내 학습), 비(非)LLM 기법, SFT 기반 베이스라인
  • 평가 지표: 진단 정확도(diagnostic accuracy) 및 결정 일관성(decision consistency)

실험 결과

정확도 향상

두 데이터셋(TeleLogs, TelecomTS) 모두에서 제안 프레임워크가 모든 베이스라인 대비 일관되게 높은 진단 정확도 달성

결정 일관성

유사한 증거 입력에 대해서도 안정적인 추론 경로와 일관된 결정 유지 — vanilla LLM의 불안정성 해소

교차 데이터셋 결과는 제안 프레임워크가 특정 데이터셋 템플릿에 한정되지 않고, 상이한 증거 표현과 진단 특성을 지닌 다양한 5G RCA 환경에서도 효과적임을 입증

결론 및 기여

기여 1: 체계적 고찰

통신 RCA의 진화(규칙 기반 → ML → LLM)를 체계적으로 정리하고, 구조화 추론 · RAG · Agentic 오케스트레이션 · RLVR 등 LLM 기반 패러다임의 역할 분석

기여 2: SEKA-FT 프레임워크

이질적 증거, 중간 진단 점검, 근본 원인 결정, 증거 기반 해설을 증거-경로-결정 감독 구조로 통합한 통신 RCA 전용 파인튜닝 프레임워크

  • 모델이 최종 라벨뿐 아니라 통신 증거와 도메인 제약에 부합하는 구조화 추론 경로를 학습
  • 차세대 통신망을 위한 실용적 LLM 기반 RCA 시스템에서 구조화 추론 설계의 중요성 입증
