On-policy Self-distillation Token-level Adaptation Post-training LLM

Every Token Needs Its Own Teacher

Multi-Teacher Adaptive On-Policy Self-Distillation (MTA-OPSD)

"모든 토큰은 자신만의 전용 교사가 필요하다" — 동일한 응답 안에서도 교사 선호는 토큰마다 다릅니다.

Yifu Luo, Chuang Ma, Zeyu Chen, Enkelejda Kasneci, Qi Chen, Gjergji Kasneci

배경: On-policy Self-distillation (OPSD)이란?

동일한 모델이 학생(student)과 교사(teacher) 역할을 동시에 수행합니다. 교사는 학생이 접근할 수 없는 특권 참조(privileged reference, 예: 정답 풀이)를 조건으로 받아 학생의 생성에 밀도 높은 감독을 제공합니다.

RLVR (예: GRPO) 대비

희소한 결과 보상(reward)이 아닌, 밀도 높은 토큰 수준 학습 신호를 제공

SFT 대비

학생이 직접 샘플링한 trajectory로 학습하여 노출 편향(exposure bias) 완화

SFT, RLVR 같은 기존 post-training 패러다임보다 우수한 성능을 보이는 유망한 접근법

문제점: 교사-학생 불일치 (Student-Teacher Mismatch)

  • 정보가 지나치게 풍부한 참조를 교사에 노출 → 지나치게 sharp한 교사 분포 유발
  • sharp한 감독은 학생의 학습 동역학과 어긋남 (예: 불확실성 억제) → 추론 성능 저하

기존 해결책: 적응형 참조 노출 (Adaptive Reference Exposure)

참조 전체를 주는 대신, 학생-교사 격차 등에 따라 교사가 받는 참조의 양을 조절

하지만 이러한 적응은 응답(response) 수준에만 적용됩니다 — 응답 내 모든 토큰이 동일한 교사의 감독을 받습니다.

핵심 주장

적응형 교사는 토큰 수준에서 작동해야 한다 — 모든 토큰은 자신만의 전용 교사가 필요하다.

동일 응답에 서로 다른 교사를 적용하면 일부 위치에서는 학습 신호가 유사하지만, 다른 위치에서는 감독 방향이 서로 상충합니다.

한 토큰에서 유용한 교사가 다른 토큰에서도 적합하다는 보장 없음

토큰별 선호 교사를 검증하고 식별하는 방법은 기존에 미개척

파일럿 실험: 교사 개입(Teacher-intervention)으로 선호도 측정

토큰 위치별 교사 선호도를 정량화하기 위해 "학생-교사-학생" 릴레이 실험을 설계했습니다.

1
학생 프리픽스 보존
학생이 생성한 접두부(prefix)를 그대로 유지
2
교사 개입
후보 교사가 선택된 토큰 위치에서 짧은 continuation 생성
3
학생 완성
제어권을 학생에게 돌려주어 응답을 완성

순수 학생 생성 대비 정확도 향상 = 해당 토큰 위치의 교사 선호도 proxy
큰 향상 → 그 위치에 적합한 교사 / 작은 향상 → 부적합한 교사

파일럿 실험 결과: 단순하지만 명확한 두 가지 발견

1

교사 선호는 토큰마다 다르다

같은 응답 내에서도 토큰 위치별로 선호되는 교사가 달라짐 → 토큰 수준 적응의 필요성 검증

2

선호 교사를 식별하는 실용적 규칙

토큰 수준에서 다수결(majority voting)로 신뢰할 수 있는 교사 부분집합 도출, 선호 교사는 큰 student-teacher KL 거리를 가짐

발견 1은 핵심 주장을 검증하고, 발견 2는 토큰 수준 교사 선택의 실용적 규칙을 제시합니다.

MTA-OPSD: 최초의 토큰 수준 적응형 OPSD

파일럿 결과를 바탕으로, 각 토큰이 학습 중 다중 교사 풀에서 자신의 선호 교사를 적응적으로 선택하는 방법을 제안합니다.

1
다중 교사 풀 구성
참조 노출 조건을 달리하는 후보 교사들
2
다수결 (Majority Voting)
신뢰할 수 있는 교사 후보 축소
3
KL 기반 선택
토큰별 최종 선호 교사 결정
구분기존 적응형 OPSDMTA-OPSD
적응 단위응답(response) 전체각 토큰
교사응답 내 고정 (모든 토큰 동일)토큰별 선택
참조 노출응답 간에만 변화토큰마다 최적화

구성 요소 ①: 다중 교사 풀 (Multi-teacher Pool)

특권 참조의 절단 전략(truncation strategy)과 노출 비율(exposure ratio)을 다양화하여 후보 교사들을 구성합니다.

절단 전략

참조를 어디까지 교사에게 보여줄지 달리하여 다양한 교사 분포 형성

노출 비율

참조 노출량을 단계적으로 조절해 정보량이 다른 교사 확보

후보 교사 집합

동일 모델 기반의 다양한 교사들이 토큰별 선택지를 제공

단일 교사의 지나치게 sharp하고 경직된 분포 대신, 더 균형 잡힌 학습 신호를 제공하여 교사-학생 불일치를 정밀하게 해소합니다.

구성 요소 ②: 토큰별 교사 선택

1

다수결 (Majority Voting)

여러 후보 교사의 학습 신호를 집계하여 신뢰할 수 있는 교사 부분집합을 먼저 도출

2

KL 기반 선택 (KL-based Selection)

student-teacher KL 거리가 큰 교사를 선호하여 각 토큰의 최종 교사 결정 (파일럿 실험에서 확인된 규칙)

각 토큰이 학습 중 자신의 선호에 따라 교사를 선택하므로, 응답 전체가 하나의 교사에 묶이지 않고 토큰 단위 최적의 감독이 가능해집니다.

실험 결과: 수학 추론 벤치마크

+5.9

기본 모델 대비 최대 평균 향상

  • Qwen3 모델군의 수학 추론 태스크에서 평가
  • 기존 OPSD 방법들을 모든 설정에서 일관되게 능가
  • 토큰 수준 교사 적응이 성능 향상의 핵심 요인

다양한 ablation 연구를 통해 다중 교사 풀, 다수결, KL 기반 선택 각각의 기여를 분석했습니다.

핵심 기여 요약

  • 토큰 수준 교사 선호 정량화 — 교사 개입 파일럿 연구로 동일 응답 내에서도 선호 교사가 토큰마다 다름을 검증하고, 다수결 + KL 기반 선택으로 선호 교사 식별 가능함을 규명
  • MTA-OPSD 제안 — 최초의 토큰 수준 적응형 OPSD. 다중 교사 풀을 감독 원천으로 구축하고, 다수결과 KL 발산 하에서 각 토큰이 선호 교사를 적응적으로 선택하여 교사-학생 불일치를 해소
  • 광범위한 실험 검증 — 다양한 모델과 수학 추론 태스크에서 기존 OPSD 대비 우수한 성능 입증, 포괄적인 ablation 분석으로 후속 연구의 길 제시

한 줄 요약: 교사 감독을 응답 단위가 아닌 토큰 단위로 세분화하는 것이 LLM post-training의 새로운 방향입니다.
