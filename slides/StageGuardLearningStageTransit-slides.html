StageGuard

Agentic Distillation을 통한 장기 로봇 과업의 단계 전이 학습

Jinbang Huang · Yuanzhao Hu · Zhiyuan Li · Ran Qi · Yixin Xiao · Yangzheng Wu · Tengyue Ba · Zhanguang Zhang · Yingxue Zhang

Huawei Noah's Ark Lab · University of British Columbia · University of Toronto · McGill University

01 · 배경

장기 로봇 과업의 핵심 질문: "언제 다음 단계로?"

계층적 계획 프레임워크는 목표를 하위 과업으로 분해하고, 여러 로봇 제어 정책의 스킬을 조합하여 실행합니다.

너무 이른 전이

다음 하위 과업의 필요 조건이 충족되지 않은 채 전환되어 실행이 무너집니다.

너무 늦은 전이

시스템 지연을 유발하거나, 이미 달성된 상태를 방해할 수 있습니다.

과업 계획과 개별 정책이 모두 올바르더라도, 잘못된 단계 전이는 이후 모든 하위 과업으로 오류가 전파됩니다.
02 · 문제

기존 접근법의 두 가지 딜레마

사전 설계된 완료 신호 체커

  • 실제 환경 실행에서는 신호 획득이 어려움
  • 학습된 정책에는 종료 조건 명시가 곤란
  • 시뮬레이터 특권 신호에 의존하는 경우 다수

대형 VLM의 직접 배포

  • 결정 경계가 과업 완료 기준과 정렬되지 않음
  • 그럴듯한 장면 해석도 잘못된 전이 판단으로 이어질 수 있음
  • 클라우드 지연 + 긴 추론 → 실시간 모니터링 주기 제약

시연 궤적은 전이 시점은 알려주지만, 결정의 시각적 근거와 과업 의존성은 설명하지 못합니다.

03 · 핵심 아이디어

StageGuard: Agentic Distillation

교사 모델의 추론과 시연 궤적을 결합해 "완료 판단의 근거"를 배우는 경량 실행 모니터

1
교사 다층 추론
시연 궤적에서 구조화된 추론 트레이스 생성
2
학생 자기 설명
경량 VLM이 간결한 CoT로 압축
3
지도 미세조정
교사가 선별한 설명으로 SFT
4
실행 모니터
정확하고 빠른 단계 전이 판단
관찰과 과업 맥락을 완료·정책 전환의 결정 경계에 명시적으로 연결하는 것이 핵심입니다.
04 · 문제 정식화

모니터링 결정의 정의

입력 x_t = (g, u_t, o_t, h_{t-1}, P) — 목표, 현재 과업 명세, 관찰, 의미 이력, 과업 계획  |  출력 y_t = (d_t, v_t, h_t)

결정 d_t의미
continue현재 하위 과업 유지 — 아직 진행 중
advance완료 조건 충족 — 다음 정책으로 전환
skip복구 불가능한 실패 — 현재 하위 과업 우회

시연 데이터 D = {(g_i, P_i, τ_i)}: 각 궤적에는 목표, 과업 계획, 라운드별 정답 결정(d*)과 다음 과업(v*)이 주석되어 있습니다.

05 · 방법 ①

다층 Agentic 추론 (교사 모델)

교사 VLM이 시연 궤적의 정답 전이 결정에 도달하도록 유도되는 3계층 추론 트레이스를 생성합니다.

상태 계층
State Layer

관찰 이력, 로봇 상태, 로봇–객체 관계, 객체 간 공간 관계를 분석합니다.

과업 계층
Task Layer

과업 계획과 하위 과업, 결정 근거를 상호 연결합니다.

결정 계층
Decision Layer

과업 진행도를 평가하고 다음 단계를 식별하며 단계 전이를 판단합니다.

시연의 ground-truth 주석이 추론의 안내자 역할을 하여, 설명이 실제 결정 경계와 정렬됩니다.
06 · 방법 ②

설명을 통한 학습 (Learning by Explanation)

1

학생 자기 설명

학생 VLM이 교사의 완전한 CoT 트레이스를 컨텍스트로 받아, 스스로 출력할 간결한 자기 설명을 생성합니다.

2

간결한 CoT 모니터링

배포 시 모니터는 자기 설명 r_t^S과 결정 y_t를 함께 출력합니다: (r_t^S, y_t) = M_θ^FT(x_t)

3

가중 지도 미세조정

교사가 선별한 설명과 대응하는 모니터링 목표를 사용해 경량 학생 모델을 SFT합니다.

결과: 대형 교사의 판단 능력 + 소형 학생의 추론 효율을 동시에 확보

07 · 실험 설정

평가 프로토콜

벤치마크

• LIBERO — 궤적 기반 전이 예측
• BEHAVIOR-1K — 계층 제어 통합 폐루프
• 실제 로봇 시스템 검증

비교 대상

• 프롬프트·인컨텍스트 기반 VLM
• 시각적 진행도(progress) 모델
• 다양한 크기의 백본 모델

평가 지표

• 단계 전이 예측 성공률
• 폐루프 과업 성공률
• 추론 지연(온라인 모니터링 주기)

어블레이션으로 다층 추론, 자기 설명, 가중 SFT의 개별 기여를 검증하고, 시스템 통합 테스트로 계층 제어 내 역할을 확인합니다.

08 · 결과 ①

단계 전이 예측: 정확도

  • 프롬프트 기반 방식은 백본의 정확도–지연 트레이드오프를 그대로 상속: 큰 모델은 느리고, 작은 모델은 전이 판단이 불안정
  • StageGuard는 시연된 하위 과업 경계와 전이 시점에 결정 경계를 정렬시켜 예측 정확도를 크게 향상
  • 교사 설명이 시각적 증거 ↔ 정답 결정의 연결을 학습 신호로 제공하여, 단순 라벨 학습 대비 일반화가 우수
LIBERO와 BEHAVIOR-1K 궤적 모두에서 단계 전이 예측이 유의미하게 개선되었습니다.
09 · 결과 ②

추론 효율성과 폐루프 성공

효율적 온라인 모니터링

간결한 자기 설명 + 경량 학생 구조로 낮은 추론 지연을 달성하여, 실행 중 높은 빈도의 모니터링이 가능합니다.

폐루프 과업 성공

BEHAVIOR-1K 계층 제어에 통합한 결과, 시뮬레이션 폐루프 과업 성공률이 향상되었습니다.

  • 정확한 전이 시점 판단이 조기 종료·지연 전이로 인한 실패 연쇄를 차단
  • 실제 로봇 실험에서도 성능 개선이 재현되어 실환경 적용 가능성 확인
10 · 분석

어블레이션 & 시스템 통합

어블레이션 연구

다층 Agentic 추론(상태·과업·결정 계층), 교사 CoT 기반 자기 설명, 가중 SFT의 각 구성 요소가 전이 예측 성능에 기여함을 확인했습니다.

시스템 통합 테스트

계층 로봇 제어 스택 내에서 StageGuard가 스킬 오케스트레이션의 실행 모니터로 안정적으로 동작함을 검증했습니다.

계층적 계획 + 이기종 정책 오케스트레이션에서 "언제 넘어갈지"를 아는 것이 전체 시스템 신뢰성을 좌우합니다.
11 · 결론

기여 요약

3
  • 시연 기반 Agentic Distillation 프레임워크 — 시각적 증거와 과업 요구를 주석된 단계 전이 결정과 연결하는 다층 교사 설명 구축
  • 설명 기반 학습 파이프라인 — 교사 추론을 간결한 학생 자기 설명으로 재구성하여 경량 실행 모니터를 SFT
  • 종합적 평가 — LIBERO·BEHAVIOR-1K에서 전이 예측 향상과 효율적 추론, 시뮬레이션·실로봇 폐루프 성공률 개선 입증

정확성과 효율성을 모두 만족하는 실행 모니터로, 계층적 로봇 제어의 실시간 단계 전이 문제를 해결합니다.
