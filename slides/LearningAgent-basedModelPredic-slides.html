Learning Agent-based Model Predictive Control
for Holistic Vehicle Performance

차량 전체 성능을 위한 학습 기반 에이전트 모델 예측 제어 (LAMPC)

Jiaming Zhong · Reza Valiollahi Mehrizi · Mohammad Pirani · Chao Yu · Alireza Kasaiezadeh · Yash Vardhan Pant · Amir Khajepour

University of Waterloo · University of Ottawa · General Motors

배경: 통합 차량 제어 (HVC)와 AMPC

Holistic Vehicle Control

  • 디퍼렌셜 브레이킹, 능동 전륜 조향, 토크 벡터링 등 차량 동역학에 영향을 주는 제어기 활용
  • 단일 또는 복수의 컨트롤러로 차량의 전체(holistic) 성능 최적화

Agent-based MPC (AMPC)

  • 각 제어 모듈을 지역 제어 과제를 맡은 상호작용 에이전트로 개별 모델링
  • 플러그 앤 플레이 방식의 유연한 연결, 장치 고장에 대한 강건성
  • 중앙집중식 MPC에 필적하는 성능을 분산 구조로 구현

도전 과제: 미지의 에이전트

AMPC의 최적성은 예측 정확도에 좌우되며, 이는 모든 에이전트와 그 기여도가 알려져야 함을 전제로 한다 — 실제 구현에는 지나치게 이상적인 가정이다.
01

블랙박스 컨트롤러

서드파티가 개발한 제어기는 별도 인터페이스가 없으면 알고리즘과 기여도를 알 수 없음

02

예측 오차

정보 부족은 차량 거동 예측에 큰 오차를 유발하고 예상치 못한 제어 결과로 이어짐

03

안전성 요구

차량 안정 제어는 safety-critical 문제로, 예측이 불안정해도 제약 만족이 필수

기존 연구 동향

Learning-based MPC

  • GP(Gaussian Process)가 가장 널리 쓰이는 학습 도구 (신경망·강화학습 대비)
  • 기존 GP-MPC는 반복 주행·레이싱 등 고정 시나리오에 국한
  • 대량 주행 데이터는 GP의 시간 복잡도 때문에 계산 부담 → 기존 희소 근사로는 HVC의 실시간 요구 충족 불가

Robust vs. Stochastic MPC

  • Robust MPC: 최악의 경우 고려 → 보수적 제어, 계산 비용이 커 실시간 적용 드묾
  • Stochastic MPC: 불확실성을 확률 요소로 모델링, "chance constraint"로 제약 위반을 확률적으로 허용 → 덜 보수적
  • GPR은 확률 모델이므로 확률론적 MPC와 자연스럽게 결합
HVC에 GP-MPC를 적용할 때 정확도 · 효율성 · 안전성 · 실현가능성의 균형이 여전히 풀어야 할 과제

주요 기여

1

하이브리드 제어 전체 파이프라인

학습 능력을 갖춘 LAMPC가 기존 AMPC 대비 더 높은 추적 성능을 달성하며, 임의의 에이전트 토폴로지에 적용 가능

2

다단계 GPR 예측용 데이터 관리 전략

예측 지평선 전체에 걸쳐 정밀한 예측과 효율적인 실시간 GPR 추론을 동시에 달성

3

닫힌 형태의 확률론적 안전 보장

GPR 예측 분산 기반 soft chance constraint로 제어 안전성을 보장하고, 피드백 가정과 soft 제약으로 최적화 실현가능성 향상

기초: Agent-based MPC의 구조

2단계 모델링 접근

1
1단계: 차량 무게중심(CG)에서 순 힘·모멘트 UCG에 의한 차량 거동 모델링
2
2단계: 제어 입력 Ui에서 UCG로의 액추에이터 동역학 모델링

에이전트 구성과 지역 최적화

  • 액추에이터를 에이전트로 클러스터링: SU = {S1 ∪ … ∪ SNa}, 상호 배타적 부분집합
  • 모든 에이전트는 제어 네트워크를 통해 완전 연결 가정
  • 복수의 제어 가능 에이전트가 있으면 합의를 위한 반복 수행
  • 각 에이전트는 상태·입력 제약 (χ, Ωi) 하에 추적 비용을 최소화하는 지역 최적화 수행

LAMPC: 전체 아키텍처

모델 기반 AMPC + 데이터 기반 학습을 결합한 실용적 하이브리드 제어 스킴

1
데이터 준비
차량 상태·입력 데이터를 학습용으로 변환
2
데이터 관리
온라인 전략으로 학습 데이터셋을 효율적으로 유지
3
GPR 학습
미지의 에이전트 기여도를 평균·분산으로 예측
4
Soft 확률론적 MPC
보정된 모델로 최적 제어, chance constraint로 안전 확보
GPR의 예측 평균은 학습된 미지의 기여로 시스템 모델을 완성하고, 예측 분산은 안전 제약 설계의 기반이 된다

학습 코어: GPR과 온라인 데이터 관리

Gaussian Process Regression

  • 미지의 에이전트 기여를 비모수 방식으로 학습
  • 예측 평균 μ: 학습된 미지 기여도 → MPC 예측 모델 보정
  • 예측 분산 σ²: 불확실성의 척도 → 안전 제약 설계에 활용

온라인 데이터 관리 전략

  • GP의 시간 복잡도 문제를 해결하는 핵심 요소
  • 학습 데이터셋 크기를 실시간 추론 가능한 수준으로 유지
  • 다단계(multi-step) 예측 메커니즘과 결합해 지평선 전체에서 정밀한 예측 달성

안전 보장: Soft 확률론적 MPC

Soft Chance Constraints

GPR 예측 분산에 기반한 확률 제약: 제약 위반 확률을 주어진 임계값 이하로 제한

  • 덜 학습된 시나리오에서도 제약 만족 보장
  • Robust MPC 대비 덜 보수적인 제어 결과

실현가능성(Feasibility) 향상

  • 불확실성 전파 과정에서 피드백 가정 적용
  • Soft 제약 설계로 최적화 문제의 feasibility 개선
  • 닫힌 형태(closed-form)의 확률론적 스킴으로 실시간 계산 가능

적용 사례: 차량 안정성 제어

에이전트 구성

  • 차량 안정성 제어를 위한 다중 액추에이터를 에이전트로 할당
  • 일부 에이전트(예: 서드파티 컨트롤러)의 기여도는 미지로 가정
  • LAMPC가 미지의 기여를 학습하여 전체 차량 성능 추구

검증 방식

  • 시뮬레이션과 실시간 실험을 모두 수행하여 검증
  • Less-learned 학습 초기·미지 시나리오 → 안전성 평가
  • Well-learned 반복 주행 후 → 성능 향상 평가

결과 ① 덜 학습된 시나리오: 안전성 보장

상황

주행 초기 또는 미지의 시나리오에서 학습 데이터가 부족해 GPR 예측을 신뢰하기 어려운 상태

  • 예측 분산이 커지며 불확실성이 제약에 명시적으로 반영됨

결과

LAMPC: 제약 만족 항상 보장

  • 학습이 불충분해도 차량 상태 제약 위반 없음
  • Soft chance constraint가 불확실성 크기에 맞춰 제어를 보수적으로 조정
  • safety-critical 차량 제어의 핵심 요건 충족
