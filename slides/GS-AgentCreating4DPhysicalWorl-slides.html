GS-Agent

생성형 시뮬레이션으로 4D 물리 세계 구축하기

Hongxin Zhang, Chunru Lin, Junyan Li, Zhou Xian, Tsun-Hsuan Wang, Chuang Gan

UMass Amherst · Genesis AI

왜 4D 물리 세계 생성인가?

다양한 응용 분야

  • 임베디드 AI 학습 및 평가 환경
  • 자율주행 시뮬레이션
  • 게임 및 영화 제작
  • Sim-to-Real 갭 해소

기존 방법의 한계

  • 전통 CG: 막대한 수작업 비용
  • 생성 모델: 물리적 타당성 부족
  • 생성 모델: 제어 가능성 부족
  • 생성 모델: 시간적 일관성 문제
자연어로 4D 세계를 구축하고 제어할 수 있다면 창작의 장벽을 획기적으로 낮출 수 있다.

핵심 아이디어

인간이 4D 세계를 만드는 방식을 에이전트 시스템으로 모방하여, 물리 엔진을 루프에 통합한 완전 자동화 프레임워크를 제안합니다.

다중 에이전트 협업

감독·전문가 역할 분담, 자연어 기반 의사소통, 반복적 개선

물리 엔진 인루프

코드 기반 상호작용, 유체·변형체·강체 물리 시뮬레이션

멀티모달 피드백

시각적·물리적 피드백을 통한 자율적 오류 감지 및 복구

GS-Agent 전체 구조

1
자연어 입력
"붉은 공이 물 위로 떨어져 튀어오르는 장면"
2
Manager Agent
작업 분해·위임·진행 관리
3
Entity Agent
에셋·재질·배치·모션 제어
4
Render Agent
카메라·조명·렌더링 설정
5
4D 세계 출력
시뮬레이션 코드 + 렌더링 영상

에이전트 간 SendMessage 도구로 메시지를 교환하고, 구조화된 도구 인터페이스를 통해 물리 엔진과 상호작용합니다.

Manager Agent

주요 역할

  • 자연어 설명 해석 및 작업 분해
  • 전역 시뮬레이션 옵션 설정
  • 하위 에이전트에 작업 위임
  • 씬 진행 상황 제어
  • 최종 결과 검토 및 승인

사용 도구

SendMessage — 다른 에이전트에게 작업 지시

SetSimulationOption — 시뮬레이션 파라미터 설정

AdvanceScene — 시뮬레이션 시간 진행

GetSceneState — 현재 씬 상태 조회

Entity Agent

3D 에셋 관리부터 물리적 모션 제어까지, 씬 내 모든 물리적 객체를 담당합니다.

01

에셋 큐레이션

3D 에셋 검색 및 형태 생성, 프리미티브 구성

02

재질 튜닝

마찰계수, 탄성, 밀도 등 물리 재질 파라미터 조정

03

배치 및 모션

공간적 제약 기반 객체 배치, 힘/속도/모션 제어

강체 유체 변형체 세 가지 물리 타입 모두 지원

Render Agent

카메라 제어

  • 카메라 위치·방향 설정
  • 시네마틱 궤적 구성
  • FOV 및 렌즈 파라미터 조정
  • 다양한 앵글에서의 녹화

조명 설계

  • 조명 타입·위치·강도 설정
  • 색온도 및 그림자 제어

출력 형태

GS-Agent는 단순한 픽셀 영상을 넘어 다양한 데이터 모달리티를 생성합니다:

  • RGB 영상
  • 깊이 맵(Depth)
  • 법선 맵(Surface Normals)
  • 실행 가능한 시뮬레이션 코드

에이전트-시뮬레이터 인터페이스

에이전트는 코드를 통해 물리 엔진과 상호작용하며, 구조화된 도구 호출과 멀티모달 피드백을 결합합니다.

공통 도구

SendMessage, GetSceneState, ExecuteCode 등 모든 에이전트가 공유하는 기반 도구

자기 검토(Self-Review)

렌더링된 이미지를 직접 관찰하여 결과를 평가하고, 문제가 있으면 자율적으로 수정 코드를 생성

코드 기반 인터페이스는 자유도가 높아 에이전트가 물리 엔진의 전체 기능을 활용할 수 있으며, 일반화 가능성도 높습니다.

실험 설정

비교 대상

  • Sora2 — 최신 Text-to-Video 모델
  • Wan2.2 — 최신 Text-to-Video 모델
  • SWE-Agent — 에이전트 베이스라인
  • SWE-Agent+Vis — 시각 피드백 추가 변형

평가 차원

  • 물리적 타당성 (Physical Plausibility)
  • 명령 준수도 (Instruction Fidelity)
  • 제어 가능성 (Controllability)
  • 사용자 연구 (User Study)

평가 시나리오: 유체·변형체·강체 간 복잡한 상호작용 + 다양한 카메라/조명 제어 장면

주요 실험 결과

방법 물리적 타당성 명령 준수도 제어 가능성

Wan2.2 낮음 중간 낮음
SWE-Agent 중간 낮음 낮음
SWE-Agent+Vis 중간 중간 낮음

Text-to-Video 모델은 픽셀만 생성하며 물리적 상호작용을 보장하지 못함. GS-Agent는 물리 엔진 기반으로 세 가지 차원 모두에서 우수한 성능 달성.

새롭게 등장하는 능력

자율적 오류 감지 및 복구

시뮬레이션 중 예기치 않은 물리적 실패(객체 튕김, 관통 등)를 멀티모달 피드백으로 자동 감지하고, 수정 코드를 생성하여 스스로 복구합니다.

→ 인간 개입 없이 완전 자율적으로 동작

세밀한 제어 가능성

단순한 장면 생성을 넘어, 특정 객체의 재질 파라미터, 카메라 앵글, 조명 강도 등을 개별적으로 세밀하게 제어할 수 있습니다.

→ 생성형 모델에서는 불가능한 수준의 제어

제거 연구

다중 에이전트 설계

단일 에이전트로 축소 시 성능 크게 저하. 역할 분담이 복잡한 4D 생성에 필수적.

전문화된 인터페이스

일반적 코드 실행만 사용 시 성능 하락. 물리 엔진 전용 구조화 도구의 중요성 확인.

LLM 백본 강인성

GPT-4o, Claude, Gemini 등 다양한 백본에서 일관된 성능, 프레임워크의 범용성 입증.

다중 에이전트 설계와 전문화된 인터페이스의 조합이 GS-Agent 성능의 핵심 요소입니다.

한계점 및 논의

현재 한계

  • 물리 엔진의 시뮬레이션 정확도에 의존 — 엔진의 한계가 곧 시스템의 한계
  • 3D 에셋 가용성 제한 — 기존 에셋 라이브러리에 없는 객체 생성 어려움
  • LLM 추론 비용 — 다중 에이전트 반복 과정에서 상당한 API 호출 비용 발생
  • 복잡한 장면에서의 계산 시간 — 반복적 수정으로 인한 긴 생성 시간

향후 방향

  • 생성형 3D 모델과의 통합으로 에셋 제한 극복
  • 더 강력한 물리 엔진 도입으로 시뮬레이션 품질 향상
  • Physical AI를 위한 대규모 데이터 생성 파이프라인 구축

결론

GS-Agent는 자연어로부터 물리적으로 타당하고 제어 가능한 4D 세계를 자동 생성하는 최초의 다중 에이전트 프레임워크입니다.

3

다양한 응용 가능

GS-Agent는 4D 세계 생성의 새로운 패러다임을 위한 초석이며, 인터랙티브 콘텐츠 창작과 물리적 AI 지원을 가능하게 합니다.
