Agentic RL × On-Policy Distillation

RetireOPD

Self-Retiring On-Policy Distillation
for Agentic Reinforcement Learning

교사는 언제 도와야 하고, 언제 물러나야 하는가?

배경: 희소한 보상의 문제

RL(RLVR)의 한계

  • 멀티턴 에이전트는 궤적(trajecory)당 단일 스칼라 보상만 받음
  • 긴 상호작용 속 중간 의사결정은 감독 없음

On-Policy Distillation (OPD)

  • 학생이 샘플링한 궤적에서 교사가 토큰 수준 밀집 감독 제공
  • 특권 정보(예: 검색된 태스크 스킬)를 조건으로 한 자기 교사 활용
  • 추론 시 추가 컨텍스트 없이 스킬을 매개변수에 내재화
기존 패러다임의 두 가지 암묵적 가정: ① 특권 정보가 있으면 교사는 반드시 더 뛰어나다 ② 학습 내내 교사 매칭이 유용하다

핵심 발견: 두 가지 가정은 모두 깨진다

1

특권 정보만으로 신뢰할 만한 교사가 되지 않는다

GRPO+OPSD 하에서 스킬 조건 브랜치가 자신이 감독하는 학생보다 일관되게 좋지 않음. 공유 파라미터가 스킬 없는 학생 목적 위주로 최적화되어, 정책은 스킬 컨텍스트를 활용하도록 학습되지 않음. 스킬을 준 7B 모델조차 ALFWorld 성공률 23.4%에 그침.

2

교사 감독의 효과는 단계에 따라 다르다

교사-학생 불일치(discrepancy)는 먼저 줄어들었다가 다시 벌어짐. 학생이 스킬 유발 행동을 내재화한 뒤에는 보상 최적화가 교사가 취하지 않는 행동을 선호하며, 두 그래디언트가 충돌 → 교사의 성능 천장에 갇힘.

교사 감독은 임시 비계(scaffolding) — 진짜 질문은 "언제 제거할 것인가?"

기존 방법의 답: 고정된 스케줄

사전 고정 방식

  • 어닐링: 학습 중 증류 가중치를 선형 감쇠
  • 2단계 레시피: 미리 정한 스텝에서 증류 → RL 전환
  • 교사가 여전히 유용한지 관찰하지 않음

온라인 결정은 세분화된 수준뿐

  • 프롬프트별 / 토큰별 게이팅만 존재
  • 어떤 방법도 교사 자체를 제거하지 않음

실험상 불일치 정체 시점은 모델·태스크에 따라 스텝 50~90으로 변동 → 단일 스케줄은 어떤 곳에선 너무 이르고 어떤 곳에선 너무 늦음

RetireOPD: 자기 은퇴하는 증류

교사의 유용성은 학습 신호 자체에서 읽을 수 있다 — 전환은 미리 정하지 않고 온라인으로 결정

1
교사 구축
스킬 조건 교사를 학생과 분리하고 환경 보상으로 최적화해 스킬을 실제로 활용하도록 학습
2
공동 스킬 내재화
스킬 없는 학생이 GRPO + OPD를 동시에 학습하며 스킬을 내면화
3
적응적 은퇴
불일치 정체 + 성공률 목표 도달 시 교사 제거, 이후 RL 단독으로 학습
은퇴 후에는 학생이 교사의 천장에 묶이지 않고, 교사 순전비(forward pass)도 더 이상 필요 없음

적응적 은퇴(Adaptive Retirement) 조건

일정 간격으로 두 신호를 모니터링 — 둘 다 만족되면 교사 은퇴

불일치 정체

교사-학생 discrepancy가 더 이상 감소하지 않을 때. 1차 분석(Appendix A)에 따르면 불일치 정체는 국소적으로 반대 방향의 그래디언트, 즉 두 목적의 충돌 신호를 의미.

상대 역량 도달

학생 성공률이 교사 성공률의 목표 비율(τ)에 도달했을 때. 스킬이 충분히 내재화되었음을 나타냄.

선형 어닐링과의 차이: 어닐링은 시간에만 반응하지만, RetireOPD는 학습 상태(충돌 + 역량)에 반응 → 모델·태스크마다 최적 전환 시점이 다른 문제를 해결

실험 설정

벤치마크

ALFWorld (텍스트 기반 가정/실행 태스크)
WebShop (웹 쇼핑 상호작용)

모델

Qwen2.5 1.5B / 3B / 7B
3개 스케일 일관 평가

베이스라인

RL 단독(GRPO), 증류 단독(OPD), RL+증류 하이브리드, 어닐링, 2단계 방식 등

  • ATOD(교사 구축 포함 전체 프레임워크) 및 은퇴 기준에 대한 정량적 절제 실험 수행
  • 은퇴 임계값에 대한 민감도와 선형 어닐링 대비 우위 검증

주요 결과: 기본선 대비 큰 폭 향상

자신의 교사를 능가

모든 설정에서 스킬 조건 교사 자신보다 높은 성능 달성 — 교사 천장의 속박에서 벗어났음을 입증

전 베이스라인 초과

RL, 증류, 하이브리드 방식을 3개 모델 스케일 × 2개 벤치마크 전체에서 일관되게 앞섬

절제 실험 인사이트

요소발견
교사 구축환경 보상으로 최적화된 분리형 교사가 미최적화 교사보다 신뢰할 만한 지도 제공 → 교사 구축 단계가 필수
은퇴 기준불일치 정체 + 상대 역량 두 신호의 결합이 단일 기준보다 안정적
임계값 민감도은퇴 임계값 변화에 성능이 견고함(robust)
어닐링 대비선형 어닐링은 시점이 모델·태스크에 맞지 않으면 조기/지연 이탈 → 적응적 은퇴가 우위
타이밍 견고성은퇴 시점이 모델·태스크별로 변동(스텝 50~90)하면서도, 신호 기반 결정이 각 설정에 자동으로 적응

기여 요약

1

실패 모드 규명

특권 정보 증류의 두 실패 모드 식별: 미최적화 스킬 조건 교사는 신뢰 불가, 스킬 내재화 이후 교사 매칭은 보상 최적화와 충돌

2

RetireOPD 제안

동일 용량의 스킬 조건 교사를 환경 보상으로 학습하고, 불일치 정체 + 목표 성공률 도달 시 온라인으로 은퇴

3

실증 검증

3개 스케일 × 2개 벤치마크에서 RL·증류·하이브리드를 일관되게 능가하고 자신의 교사조차 초과

"교사는 학습의 비계다 — 필요할 때 세우고, 충분할 때 치운다."
Takeaway

결론

RetireOPD는 밀집 토큰 감독(OPD)으로 희소 보상의 느린 시작을 잡고, 학습 신호 기반 적응적 은퇴로 교사 천장의 속박을 제거하여 최종적으로는 교사를 능가하는 에이전트를 만든다.
