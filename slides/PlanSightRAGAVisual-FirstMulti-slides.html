문제 정의: 토목 도면 규제 검사의 현실

현재 방식

  • 엔지니어가 수천 장의 2D 도면을 수동 검토
  • 비용이 높고, 느리며, 오류 발생 가능성 큼
  • 다중 시트 간 복잡한 공간 규약 처리 어려움
  • DOT에서 레거시 도면 여전히 권위적 참조로 유지

기존 자동화의 한계

  • OCR 기반 접근: 기하학·레이아웃 정보 소실
  • 토큰화 후 도면을 "단어 주머니"로 축소
  • 치수 체인, 단면 부호, 교차 뷰 심볼 상실
  • 검색기가 관련 도면을 신뢰성 있게 찾지 못함
핵심 간극: 토목 표준 도면의 기본 의미론은 기하학과 레이아웃에 있으나, 기존 RAG는 이를 텍스트 변환 과정에서 파괴한다.

왜 비전 우선(Vision-First)인가?

실제 WYDOT 질의: "철망 랩랩(stake spacing & wire-tie config, WYDOT 511-1A)?"

방식 처리 과정 결과 Recall@5
OCR + BM25 텍스트 RAG "WIRE TYP SPACING FT SEE RIPRAP" 토큰화 실패 기하학 소실 58.02%
VisionRAG (Pyramid) 저해상도 전역 패치 실패 미세 디테일 소실 45.99%
ColNomic (본 연구) 32×32 멀티벡터 MaxSim 성공 영역 기반 정밀 검색 92.69%

ColPali 계열의 시각 검색

페이지를 패치 임베딩 그리드로 인덱싱, late-interaction MaxSim으로 레이아웃 보존

VLM의 도면 이해 능력

Qwen-VL, Gemini 등이 다이어그램에서 정밀한 시각 그라운딩 시현

문서 수집 및 시각 인덱싱

고해상도 타일링 절차

  • 대형 도면을 겹침(overlap)이 있는 타일로 분할
  • 각 타일에 원본 페이지 메타데이터 부착
  • 미세 디테일(치수선, 심볼) 보존
  • 저해상도 전역 뷰의 한계 극복

ColNomic-3B 멀티벡터 인덱싱

  • ColPali 기반 late-interaction 모델
  • 페이지를 32×32 패치 임베딩 그리드로 인덱싱
  • 쿼리와 패치 간 MaxSim 점수로 순위화
  • 레이아웃·기하학 정보를 임베딩에 직접 보존
핵심 차별점: 도면을 텍스트로 변환하지 않고, 검색 계층 자체가 도면을 "본다". 패치 수준 인덱싱이 치수 체인과 단면 상징을 보존한다.

쿼리 처리, 검색 및 시각 그라운딩

1
VLM Cross-Encoder 재랭킹: 초기 후보를 VLM이 교차 인코딩하여 정밀 재순위화
2
하이브리드 밀집-희소(Dense-Sparse) 융합: 시각 임베딩과 텍스트 희소 신호 결합
3
Sharpened MaxSim 히트맵: 패치 간 유사도를 날카롭게 sharpening하여 관련 영역 강조
4
영역 수준 그라운딩: 히트맵에서 임계값 이상 패치를 클러스터링하여 답변 근거 영역 추출

증거 흔적(Evidence Trail)

MaxSim 히트맵은 검색 결과의 어느 패치가 쿼리와 일치하는지를 시각적으로 보여주어, 단순한 텍스트 인용을 넘어 도면 상의 공간적 근거를 제공한다.

특징: 토목 표준 도면 검색 평가를 위한 최초의 대규모 멀티-DOT 벤치마크이며, 단순 QA를 넘어 준수 검사 태스크까지 포괄한다.

H1 지지됨

패치 수준 시각 검색이 OCR 기반 및 하이브리드 대안을 약 33%p 초과 달성

H3 지지됨

LoRA 미세조정이 zero-shot 전이에 추가 이익 없음 → 도메인 적응 불필요

판정 정확도 (사전 해결 임계값 제공 시)

대조: 비-VLM OCR 베이스라인은 동일 조건에서 76.4%에 그침

멀티 플랜 준수 검사

  • N∈{2,3,4,5} 플랜 동시 검사 성공
  • 멀티 플랜 스케일업 (n=100): 안정적
  • 단일 문서 스케일업 (n=500): 안정적
  • 적대적 임계값 스트레스 테스트 (n=50) 통과
H2 지지됨 — 에이전트 파이프라인이 밀집 다중 뷰 시트와 다중 플랜 설계를 신뢰성 있게 감사한다. 단, 100% 정확도는 사전 해결된 임계값이라는 "통제된 천장"임을 명시.

자동 시각 규칙 그라운딩

문제 설정

기존: 엔지니어가 규칙의 수치 임계값을 수동으로 파이프라인에 주입

본 연구: 에이전트가 스스로 규칙을 찾고 수치를 추출

수행 절차

  • 사양 코퍼스(1,913 후보)에서 지배적 요구사항 검색
  • Recall@5 = 100%
  • 기호 해석: "d/2" 등 수식을 수치로 변환
  • 자가 추출 임계값으로 감사 수행

실제 931페이지 코퍼스 검증

WYDOT 실제 사양 문서 931페이지에서 자율 규칙 그라운딩 성공

의미

사람이 제공한 규칙 없이도 수동 주입 천장(100%)과 동일한 성능 달성

교차 기관 일반화 및 외적 타당성

평가 항목 결과 해석
미시간 DOT 제로샷 전이 91.40% Recall@5 훈련에 없는 DOT에도 강력한 전이
LoRA 미세조정 추가 실험 이익 없음 사전 학습된 시각 표현이 충분
실제 WYDOT 프로젝트 도면 검색·감사 모두 전이 성공 합성 테스트를 넘어 실제 환경 검증
고해상도 타일링 효과 H4 부분 지지 판정 정확도 향상, 단 일부 실패 모드 존재
핵심 발견: ColNomic-3B의 시각 표현이 토목 도면 도메인에 대해 이미 충분히 일반화되어 있어, 추가 도메인 적응(LoRA)이 불필요하다. 이는 배포 관점에서 매우 중요한 장점이다.

실패 분석 및 한계

주요 실패 모드

  • 고해상도 타일링으로 인한 컨텍스트 파편화
  • 매우 작은 폰트의 주석 텍스트 오인식
  • 도면 간 교차 참조(cross-reference) 추론 한계
  • 복잡한 기호 해석(약식 표기, 단위 혼용)

인정된 한계

  • 합성 테스트셋 기반 "통제된 천장"에서 100%이나, 실제 도면에서는 미달 가능
  • VLM의 환각 가능성이 판정에 영향
  • 대규모 코퍼스에서의 지연 시간(Latency) 문제
  • 비영어 도면에 대한 검증 미수행

H4 평가: 고해상도 타일링

판정 정확도는 향상되나, 타일링이 도면의 전체 맥락을 단절시키는 trade-off가 존재. 이는 향후 해결해야 할 구조적 한계로 식별됨.

결론 및 향후 과제

핵심 성과

  • OCR 없이 토목 도면을 직접 인덱싱·검색하는 최초의 엔드투엔드 시스템
  • 5개 DOT 벤치마크에서 91.47% Recall@5 달성
  • 미공개 기관에 제로샷 91.40% 전이
  • 사람 제공 규칙 없이 자율 규칙 그라운딩 시현
  • MaxSim 히트맵 기반 투명한 증거 추적

향후 과제

  • 고해상도 타일링의 맥락 파편화 문제 해결
  • 실제 프로젝트 도면에서의 대규모 평가
  • 비영어 토목 도면으로의 확장
  • 지연 시간 최적화 및 실시간 감사
  • 다중 에이전트 협업 구조 고도화
PlanSightRAG는 토목 인프라 규제 검사에서 OCR 의존성을 완전히 제거하고, 시각 정보를 보존한 채 엔드투엔드 자동화를 달성한 새로운 패러다임을 제시한다.
