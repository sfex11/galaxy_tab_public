Efficient Test-Time Adaptation
through Human-AI Interaction

인간-AI 상호작용을 통한 효율적인 테스트 시점 적응 (TAHI)

Zora Zhiruo Wang 외 22인

Carnegie Mellon University · University of Washington · Stanford University 외

arXiv:2609.04141v1

배경: 범용적이지만, 전문가는 아닌 AI 에이전트

AI 에이전트의 현재

  • 인구 규모 데이터로 학습되어 다양한 실무자의 능력을 포괄
  • 글쓰기, 소프트웨어 엔지니어링 등 폭넓은 작업에서 준수한 출력 생성

전문가의 기대

  • 응답이 획일화되거나 사용자 의견에서 벗어나는 문제
  • 자신의 평판을 걸고 사용하려면 추가 편집이 반복적으로 필요
개인 전문성은 평균으로부터의 도약과 상승에 존재한다. 특히 성공 기준이 이질적이고 충분히 문서화되지 않은 현실적 개방형 작업에서 그렇다.

핵심 통찰: 반복 상호작용은 미활용 학습 신호

사용자는 작업을 처음에 완전히 명세할 수 없음 → 여러 차례의 인간-에이전트 상호작용을 통해 목표를 반복적으로 조정
자기 성찰(reflection)만으로는 개선이 정체됨 — 외부의 새로운 신호가 필요
많은 상호작용 신호는 작업 세션을 넘어 반복적으로 재사용됨 — 그러나 기존 에이전트 시스템은 이를 버림
아이디어: 여러 세션에 걸쳐 축적된 교차 세션 상호작용 데이터를 에이전트의 적응을 위한 풍부한 학습 신호로 활용하자

TAHI: Test-time Adaptation through Human-agent Interaction

인간 상호작용 신호를 스트리밍 방식으로 처리하여, 이전 세션의 학습으로 이후 세션을 해결하는 테스트 시점 적응 프레임워크

1
작업 수행
에이전트가 작업 실행, 인간이 지시·수정·피드백 제공
2
신호 수집
반복 세션(iter 1 → iter 2 → …)에서 다채널 인간 신호 축적
3
적응
컨텍스트 또는 가중치에 통합, 진화하는 루브릭으로 기준 정형화
4
수렴
전문가 기대 충족에 필요한 상호작용 횟수 점진 감소

백본: 학습 가능한 LM (Qwen3.6-35B) + 편집 가능한 컨텍스트 조건화

다채널 인간 상호작용 인터페이스

텍스트 피드백뿐 아니라 다양한 형태의 인간 신호를 수집

A. Plan — 계획 조정

에이전트의 작업 계획을 직접 수정하여 방향 유도

B. Deliverables — 산출물 편집

출력 파일을 직접 편집하여 시범(demonstration) 제공

C. Message — 텍스트 피드백

기존 프레임워크들과 동일한 지시·제안·교정 채널

D. Rubrics — 기준 명세

성공 기준을 명시적으로 표현하고 루브릭 오류를 교정

핵심 다채널 신호의 가치를 정량적으로 분석 가능

두 가지 적응 방식

구분컨텍스트 적응 (Context)가중치 적응 (Weight)
방법 사실적·선호 지식을 담은 메모리 + 절차적 지식을 담은 스킬 유도 DPO로 인간이 안내한 최종 출력을 초기 출력보다 선호하도록 LoRA 어댑터 학습
장점 사용자가 학습 내용을 쉽게 검수·수정 가능 지속적인 행동 변화 포착, 컨텍스트 창 팽창 방지
효과 단독 성공률 +4.5~12.9% 단독 성공률 +4.5~20.9%

두 방식 모두 단 20개 작업 세션 내에서 효율적으로 수렴

진화하는 검증기(Evolving Verifier) 모듈

LLM이 인간 활동을 구체적인 평가 기준으로 정형화하고, 사용자는 부정확한 항목을 교정

1
인간 신호 관찰
이전 반복에서의 지시·수정·피드백 수집
2
루브릭 갱신
인간 선호를 포착하도록 평가 기준 진화
3
활용
학습·평가 기준으로 사용, 개방형 작업용 수작업 명세 불필요
개방형 작업의 성공 기준을 사람이 직접 쓰는 부담을 덜어주는 확장 가능한 어노테이션 도구 역할

실험 설정

30

인간 전문가 개별 적응

600

총 작업 수행

2

고활용 도메인: 글쓰기 · 시각 창작

세 가지 시나리오

  • 온라인 컨텍스트 적응 — 세션을 거듭하며 메모리·스킬 축적
  • 온라인 가중치 적응 — 세션 신호로 LoRA 어댑터 갱신
  • 오프라인(적응 없음) — 비교 대조군

인간당 총 20개 작업 (도메인당 5인 수집)

결과 ①: 효율적인 개인화 적응

+4.5~20.9%

단독 작업 성공률 향상
단 20개 세션 내 달성

+3.2~6.6%

홀드아웃 작업 일반화
같은 인간의 루브릭 기준 (가중치 적응 +4.8~5.2%)

  • 컨텍스트·가중치 적응 모두 유사한 수준의 실질적 개선 달성
  • 사용자의 인내가 바닥나기 전인 수십 회 세션 만으로 선호 작업 방식에 수렴
  • 강력한 교차 작업 일반화 능력 확인

결과 ②: 진화한 루브릭의 우수성

+16.0~22.3%

LM 단독 또는 인간 단독 루브릭 대비
불완전한 에이전트 솔루션의 실패 포착률 향상

LM 단독 루브릭의 한계

중요한 평가 측면을 놓치기 쉬움

인간 단독 루브릭의 한계

같은 함정을 피하려 상당한 동기부여·훈련 필요

결론 인간-에이전트 상호작용에서 도출된 루브릭이 상호 보완적으로 더 포괄적

결과 ③: 개인 적응이 사용자 간에도 일반화

인간 전문성은 공유된 커뮤니티 지식 + 개인화된 전략·선호의 결합

+0.3~8.8%

공유(Shared) 루브릭 항목에서
교차 사용자 성능 향상

+6.2~19.6%

개인(Personal) 루브릭 항목에서
교차 사용자 성능 향상

  • 개인에게 적응된 에이전트가 다른 사용자에게도 이득 (최대 8.8%)
  • 개인 적응에서 커뮤니티 전문성을 도출하는 탐색적 방법 제시 (§4.4)

결론

1
TAHI — 반복적인 인간-에이전트 상호작용을 테스트 시점 적응의 학습 신호로 전환: 컨텍스트·가중치 양쪽으로 통합
2
소수의 세션(20개 작업)만으로 성공률 4.5~20.9% 향상, 홀드아웃 작업으로의 일반화 확인
3
진화하는 루브릭 모듈은 LLM·인간 단독 대비 16.0~22.3% 더 많은 실패를 포착하는 확장형 평가 도구
4
개인화된 적응이 타 사용자에게도 최대 8.8% 일반화 — 커뮤니티·개인 전문성을 모두 학습
미래의 AI 에이전트는 범용 도구가 아니라, 서비스 대상 개인에 의해 형성되고 그 개인에게 책임지는 적응형 도구여야 한다.
