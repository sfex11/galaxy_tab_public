In-Context Robot Learning
with VLM Agents

GPT-Policy: 범용 VLM 에이전트를 통한 로봇의 문맥 기반 학습

Dongzhou Cheng, Taoran Yi, Ye Fang, Xingwu Zhang, Fan Feng, Yixuan Li 외
Morphi Robot · Shanghai Innovation Institute · HUST · Fudan University 등

왜 In-Context Learning인가?

어떤 유한한 시연 데이터셋도 로봇이 마주할 모든 과제와 상황을 커버할 수 없습니다.

데이터의 한계

새로운 과제, 낯선 물체 배치, 예상 못한 상호작용은 배포 시점에 끊임없이 발생

인간의 적응 방식

타인을 관찰하고, 예시를 해석하며, 행동의 결과로부터 학습하여 즉시 적응

핵심 질문

기존 로봇 정책은 ICL이 사실상 불가능 — 범용 VLM으로 가능할까?

연구 질문

범용 목적의 VLM(예: GPT-6 Astra)이 시연, 예시, 상호작용 피드백으로부터 학습하여, 경사 업데이트나 과제별 파라미터 변경 없이 새로운 초기 상태에서 실행 가능하고 검증 가능한 로봇 행동으로 변환할 수 있을까?

기존 접근

로봇 전용 정책 학습 (sensorimotor 궤적, 비디오-액션 모델 등)

본 연구

로봇 특화 학습 없이 off-the-shelf 범용 멀티모달 에이전트의 ICL 능력 탐구

로봇 ICL의 정의와 5가지 문맥 유형

테스트 시점에 제공되는 시연·예시·상호작용 경험에 기반한 행동 적응 (경사 업데이트 없음)

인간 비디오

절차를 보여주는 시연 영상

로봇 비디오 + 액션

정렬된 동작 레퍼런스 제공

목표 이미지

원하는 최종 결과 명시

자기 상호작용 이력

이전 관찰과 결과 기록

온라인 인간 피드백

의도·규칙 변경 명확화

핵심 과제

현재 결정에 중요한 정보를 선별 → 물리적 행동으로 변환

GPT-Policy 아키텍처

범용 VLM을 로봇 도구에 연결하는 공유된 문맥-행동 인터페이스

1
컨텍스트 컴파일러
과제 관련 시각적 전환과 사용 가능한 액션 레퍼런스를 보존
2
VLM (고정)
현재 장면 + 문맥을 해석하여 파라미터화된 로봇 도구 액션 제안
3
제약 실행 계층
액션 검증·실행 후 관찰과 결과를 반환 → 재계획 지원

폐루프(Closed-Loop): 실행 결과가 다시 컨텍스트로 업데이트되어 다음 의사결정에 반영 — 공용 인터페이스로 다양한 모델과 문맥 유형을 공정하게 비교

문제 정식화

과제 명세

과제 지시문 T 와 최신 관찰 ot = (It, st) — 카메라 뷰별로 레이블된 이미지와 로봇 상태로 구성

컨텍스트 구성

  • 과제 레퍼런스: 목표 이미지, 인간/로봇 시연
  • 온라인 상호작용 이력: 관찰·행동·결과 누적

구조화된 도구 인터페이스

VLM의 도구 요청을 임베디드 어댑터가 실행 가능한 명령으로 변환

제약 실행 계층

  • 포즈 보간(pose interpolation)
  • 역기구학(IK) + 백엔드 검사
  • 실행 후 타이밍·동기화·피드백

폐루프 실행 과정

1
컨텍스트 조립

과제 지시 + 현재 상태 + 과제 레퍼런스 + 상호작용 이력 + 공유 지침 + 도구 스키마 → VLM 입력

2
도구 요청 생성

고정된 VLM이 목표 좌표·그리퍼 명령을 포함한 구조화된 도구 요청을 선택

3
검증 및 실행

제약 확인 후 포즈 보간과 IK를 거쳐 물리적 액션 수행

4
관찰·피드백 반영

실행 결과와 새 관찰을 컨텍스트에 업데이트하여 재계획 또는 종료 판단

실험 설계: 5개 문맥 패밀리

실제 로봇 실험 · 매칭된 모델 비교 · 통제된 컨텍스트 어블레이션

문맥 패밀리제공 정보평가 초점
인간 비디오액션 레이블 없는 인간 시연교차 임바디먼트 모방
로봇 비디오 + 액션정렬된 동작 레퍼런스접촉 민감 조작
목표 이미지원하는 결과 이미지목표 추종
자기 상호작용 이력자신의 시도 기록능동적 탐색
온라인 인간 상호작용실시간 피드백인간-로봇 상호작용

측정 지표: 과제 성공률, 의사결정 수, 실행 시간

주요 결과 ① — 인간 비디오로 학습

✓

로봇 액션 레이블 없이도 성공

인간 비디오 시연만으로도 과제 완수율이 향상 — VLM이 인간의 행동을 관찰하여 로봇 실행으로 변환

↓

효율성도 함께 개선

과제 관련 문맥은 성공률을 높이는 동시에 의사결정 수와 실행 시간을 감소시킴

범용 VLM은 이기종(heterogeneous) 문맥을 활용해 로봇 의사결정에 정보를 제공할 수 있다 — 훈련 분포를 넘어선 적응의 출발점

주요 결과 ② — 정렬된 액션 레퍼런스

로봇 비디오에 기록된 액션이 정렬되어 제공되면, 특히 접촉 민감형(contact-sensitive) 과제에서 추가적인 성능 향상

  • 액션 레퍼런스가 궤적 선택을 유도하여 모호성 감소
  • 정확한 접촉이 필요한 조작에서 시각 정보만 사용할 때보다 우수
  • 모델별 비교에서도 동일 실행 프레임워크 하에 일관된 경향 확인
성공률 ↑
의사결정 수 · 실행 시간 ↓

드러난 결정적 격차

더 나은 과제 이해와 행동 선택이 정밀한 접촉, 신뢰할 수 있는 결과 검증, 물리적 안전을 보장하지는 못한다.

정밀 접촉

문맥이 올바른 행동을 이끌어도 실행 수준의 접촉 실패는 잔존

결과 검증

행동이 의도대로 수행되었는지 신뢰성 있게 확인하기 어려움

물리적 안전

신뢰 가능한 배포를 위해 반드시 해결해야 할 과제

→ 로봇 ICL은 지각-행동 루프 전체에서 어디서 적응이 성공하고 어디서 무너지는지에 대한 구체적 질문

결론 및 향후 방향

기여

  • 범용 VLM 기반 로봇 ICL의 공통 프레임워크 제시
  • 5가지 문맥 패밀리에 대한 체계적 실증 평가
  • VLM의 범용 능력 → 물리적 행동 변환의 경험적 기반

향후 연구

  • 물리 실행 전반에서 적응력을 의존 가능하게 만들기
  • 접촉 정밀도와 결과 검증 신뢰성 향상
  • 임바디드 파운데이션 모델을 위한 연구 어젠다 정의

범용 VLM은 이미 이기종 문맥을 활용할 수 있습니다. 다음 과제는 그 적응력을 물리적 실행 전체에서 신뢰할 수 있도록 만드는 것입니다.
