University of Chicago, Department of Computer Science

연구 배경: 상반된 증거

상호작용이 도움이 된다

  • Debate — 사실성 향상 (Du et al., 2024)
  • Critique loops — 수학 정확도 향상 (Chen et al., 2025)
  • MoA synthesis — 벤치마크 성능 향상 (Wang et al., 2025)

상호작용이 도움이 안 된다

  • 비용만 증가, 품질은 불변 (Tran & Kiela, 2026)
  • 동일 예산 하 손실 (Xu et al., 2026; Jarrett et al., 2025)
  • 독립 샘플링이 이미 이점 포착 (Li et al., 2024)

이 모순은 누락된 구분을 반영한다 — 모든 다중 에이전트 소통이 동일하지 않다.

핵심 개념: 상호작용 세금 (Interaction Tax)

서로 다른 모델 패밀리는 구조적으로 다른 해답을 찾는다. 하지만 에이전트가 서로의 완전한 출력을 읽으면, 제안은 단 1라운드 안에 수렴하여, 여러 모델을 사용하는 근거가 되는 다양성이 지워진다.

1
독립 제안
Claude, GPT-4o, Gemini가 각각 다른 구조의 해답 생성
2
완전 해답 교환
에이전트가 서로의 출력을 전부 읽음
3
수렴 발생
이후 해답들이 유사해져 다양성 상실

상호작용 세금 = 다양한 모델이 제공하는 해답 다양성이 소통 과정에서 손실되는 현상

다양성이 만드는 커버리지

동일 모델 팀은 최소 1개 과제에서 Q=0을 기록하지만, 다양한 모델 팀은 어느 과제에서도 0점이 아니다.

과제 Claude GPT-4o Gemini 우승 모델
Circle Packing 1.000 0.519 0.745 Claude
TSP-50 0.141 0.115 0.142 Claude
Erdős 0.131 0.710 0.142 GPT-4o
TSP-100 0.013 0.021 0.010 GPT-4o

Best-of-N Q-점수. 각 모델 패밀리가 서로 다른 과제에서 우승한다.

다중 에이전트 워크플로우 (6)

피드백 구조의 두 유형

등급 피드백 과제

  • MaxCut, Circle Packing 등
  • 잘 형성된 거의 모든 답변이 의미 있는 점수 획득
  • 점수 개선 방향이 비교적 명확

엄격 유효성 과제

  • Knapsack, 3AP-Free 등
  • 구조적 규칙을 만족해야 점수가 의미 있음
  • 작은 수정이 규칙 위반 → 점수 붕괴

이 구분이 크리티크의 효과를 결정한다 — 규칙 위반이 쉽게 발견·수정 가능한 과제에서만 크리티크가 도움이 된다.

성능 향상의 핵심은 에이전트 수가 아니라 모델 다양성에 있다. 합성 방식은 부수적이다.

상호작용 세금의 증거

MIG (Multi-agent Interaction Gain): 상호작용이 독립 생성보다 얼마나 나은지

설정 동일 모델 MIG 다양 모델 MIG 세금 여부
Chain 양성 (정제 효과) −0.024 세금 발생
MAgICoRe 양성 (정제 효과) −0.035 세금 발생
Debate 양성 (정제 효과) 음성 세금 발생
MoA 약양성 양성 세금 없음

완전 해답 교환 설정들은 동일 모델에서는 이점이지만, 다양 모델에서는 역전된다. MoA만 유일하게 탈출한다.

왜 MoA만 세금을 피하는가?

Chain / MAgICoRe / Debate

  • 에이전트가 서로의 완전한 해답을 읽음
  • 첫 번째로 본 해답에 고착
  • 1라운드 내 제안 수렴
  • 모델 간 구조적 차이가 소실

MoA (Mixture-of-Agents)

  • 제안자들이 서로의 출력을 보지 않음
  • 각 제안자가 독립적으로 해답 생성
  • 합성은 최종 단계에서만 발생
  • 다양성이 보존된 채 선택

핵심 차이: 제안 단계에서 에이전트 간 정보 교환을 차단하면 수렴을 막을 수 있다.

크리티크는 언제 도움이 되는가?

Knapsack (도움됨)

  • 위반 규칙이 명확하게 위치
  • LLM이 쉽게 찾고 수정 가능
  • 수리 중심 크리티크가 효과적

3AP-Free (도움 안 됨)

  • 위반 원인을 찾기 어려움
  • 수정 시도가 새로운 위반 유발
  • 크리티크 회귀율 높음

크리티크는 위반 규칙이 LLM이 발견·수정하기 쉬운 경우에만 도움이 된다. 그렇지 않으면 오히려 점수를 붕괴시킨다.

수렴 메커니즘의 이해

완전 해답 상호작용이 수렴을 일으키는 구조적 원인:

1

앵커링 효과 — 에이전트가 첫 번째로 읽은 해답에 고착되어 다른 접근법 시도 저하

2

정보 과부하 — 완전한 해답을 읽으면 독립적 사고보다 모방이 쉬워짐

3

앙상블 다양성 분해 — 앙상블 오차 = 평균 오차 − 다양성 항; 수렴 시 다양성 → 0

4

진화적 접근(FunSearch, AlphaEvolve)은 선택 압력으로 다양성 보존 — 이 메커니즘을 우회

핵심 메트릭 정리

MEG

Multi-agent Exceedance Gain

해당 설정이 모든 단일 에이전트 베이스라인을 능가하면 양성

MoA를 제외한 모든 설정이 양성 MEG 기록

MIG

Multi-agent Interaction Gain

상호작용이 독립 생성보다 개선되면 양성

다양 모델 + 완전 교환 → 음성 MIG (세금)

MEG는 양성이어도 MIG가 음성일 수 있다 = 다중 에이전트이긴 하지만 상호작용 자체는 해로운 상태

결론 및 시사점

완전 해답 상호작용은 약한 기본값이다 — 다양한 모델 간 유용한 차이를 지울 수 있다

다중 에이전트 성능은 에이전트 수보다 교환하는 정보의 내용에 의존한다

독립 생성은 수렴 붕괴를 피하는 간단한 전략이다

크리티크는 수리 가능한 결함에만 초점을 맞춰야 한다

상호작용은 에이전트가 올바른 정보를 올바른 시간에 공유할 때만 도움이 된다

한계: 발견은 과제 의존적 — Leave-one-out 분석에서 일부 과제는 다양성 이점이 불안정함
