VABAR

A Variational Automation Benchmark for Agentic Robotics

에이전틱 로보틱스를 위한 변이 자동화(Variational Automation) 벤치마크

UC Berkeley · Siemens · NVIDIA  |  Shuangyu Xie, Ken Goldberg 외

Variational Automation (VA)란?

상업·산업 현장의 로봇은 객체 형상과 자세의 알려진 변이 속에서도 특정 작업을 지속적으로 수행해야 합니다.

고정 자동화

정밀하게 설계된 프로그램을 구조화된 환경에서 반복 실행. 높은 신뢰성·처리량을 제공하지만 조건이 바뀌면 막대한 재설계·재튜닝 비용 발생

범용 로보틱스

개방형 작업의 범위는 넓지만, 현재의 모델프리 end-to-end 정책은 산업·상업 도입에 요구되는 속도와 신뢰성 확보에 어려움

변이 자동화 (VA)

운영 목표와 작업 공간은 유지되지만 객체·레이아웃·작업 파라미터·실행 조건에 구조적 변이가 존재하는 중간 영역

에이전틱 로보틱스 = 고전 로봇 프로그래밍의 신뢰성·해석 가능성 + 학습 정책의 개방형 적응성이라는 유망한 접근법

왜 새로운 벤치마크가 필요한가?

LIBERO, ManiSkill, SimplerEnv 등 기존 벤치마크는 언어 조건부 심층 시각운동 정책의 일반화를 평가

구분기존 벤치마크VABAR
작업 유형가정용 픽앤플레이스 중심산업·의료·인프라 응용 지향
평가 대상모델프리 시각운동 정책LLM/VLM 코딩 에이전트 시스템
변이 처리새로운 장면 구성 위주명시적 변이 축 + 난이도 계층
포화 상태높은 성공률로 이미 포화포화에 저항하도록 설계
VABAR는 같은 작업 클래스의 영속적 운영 목표를 시간에 걸쳐 구조화된 변이 속에서 달성하는 "응용 지향 자동화"에 초점

에이전틱 로보틱스 벤치마크 설계 기준 (7가지)

  • 접근성 — 누구나 쉽게 설치·실행 가능
  • 반복 가능성 — 재현 가능한 평가 절차
  • 통제된 다양성 — 구조화된 변이 축 제공
  • 관련성 — 에이전틱 로보틱스와 실제 응용에 부합
  • 물리적 실현 가능성 — 실세계 이행 가능한 과제
  • 포화 저항성 — 단기간 해결되지 않는 난이도
  • 계산 효율성 — 현실적인 컴퓨팅 자원으로 평가 가능
  • 완전 오픈소스 — Newton 물리 엔진 기반 손쉬운 복제

6가지 작업 클래스

공구 분류
Tool Sorting

산업용 공구를 형상·자세 변이 속에서 정확히 분류·정렬

공구 걸기
Tool Hanging

공구를 걸이에 매달는 정밀 조작 과제

기어 물림
Gear Meshing

NIST 조립 태스크 보드에서 영감을 받은 접촉 풍부 조립

주사기 포장
Syringe Packing

의료 응용 — 주사기의 정밀 포장 과제

케이블 삽입
Cable Insertion

인프라 응용 — 변형 가능한 케이블의 삽입 과제

케이블 라우팅
Cable Routing

변형 가능한 객체의 장기 호라이즌 경로 배치

과제 정의: 변이 · 난이도 · 성공 조건

각 작업은 명시적 구성 요소를 갖춘 인스턴스 집합으로 정의됩니다.

변이 축

기하학적 변이(객체 형상·자세)와 물리적 변이를 계층화하여 표준화

난이도 계층

난이도 티어를 제공해 난이도 상승에 따른 성능 확장성 분석 가능

성공 조건

작업별 성공 메트릭이 명확히 정의되어 객관적 비교 보장

단일 팔 Franka와 양팔 YAM 구성을 모두 지원하여 협동 조작도 평가

스킬 라이브러리와 인간 작성 참조 솔루션

33개의 일반화 가능한 스킬 — 지각, 계획, 제어 모듈을 이름으로 호출 가능한 재사용 라이브러리
인간 작성 참조 솔루션 — 동일한 스킬 라이브러리 위에서 계산 그래프(computation graph)로 표현된 해법
공정한 비교 — 참조 솔루션은 코딩 에이전트와 동일한 지각·계획·실행 스택으로 실행됨
에이전틱 시스템은 단일 모놀리식 정책 대신 여러 LLM 에이전트가 과제 인스턴스를 추론하고, 실행 가능한 로봇 프로그램을 생성·수정하며 스킬을 호출

평가 프로토콜

1
인스턴스 샘플링
변이 축과 난이도 티어에 따라 과제 인스턴스 생성
2
프로그램 생성
에이전트가 작업을 추론하고 실행 코드를 생성·수정
3
스킬 실행
지각·계획·제어 스킬을 호출하여 조작 수행
4
성공 평가
표준화된 성공 메트릭으로 결과 기록
  • GaP (Graph-as-Policy) — 오픈 에이전틱 조작 베이스라인으로 초기 평가 수행
  • Isaac Lab Arena — 확장된 평가 환경 지원

5가지 핵심 기여

1
변이 자동화 과제 정식화 — 고정 자동화와 범용 조작 사이의 과제 클래스를 정의하고 형식화
2
에이전틱 벤치마크 설계 원칙 — 접근성, 반복성, 통제된 다양성, 응용 관련성, 물리 실현성, 포화 저항성, 계산 효율성 기준 제시
3
VABAR 과제 정의 — 6개 응용 지향 작업 클래스를 표준화된 변이·난이도·성공 메트릭과 함께 제공
4
시뮬레이션·스킬·참조 솔루션 — 사실적 시뮬레이션, 33개 스킬, 인간 작성 코드 솔루션 제공
5
초기 베이스라인 — 오픈 에이전틱 시스템으로 평가하여 난이도·변이 증가에 따른 성능 특성 규명

논의와 향후 과제

  • 베이스라인 결과는 과제 복잡도와 인스턴스 변이가 증가할수록 에이전틱 시스템 성능에 미치는 영향을 보여줌
  • 접촉 풍부 과제(기어 물림, 케이블 조작)와 같은 에이전틱 조작의 남은 도전 과제를 명확히 식별
  • 완전 오픈소스 구성으로 손쉬운 복제·확장이 가능하여 커뮤니티 전체의 발전 촉진
  • 산업·의료·인프라라는 실용적 응용과의 직접적 연결로 연구의 실세계 relevance 확보
VABAR는 포화된 기존 벤치마크를 대체하는, 신뢰성 있는 로봇 자동화를 향한 새로운 평가 기준을 제시합니다.
