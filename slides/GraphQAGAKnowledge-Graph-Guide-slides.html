QA 쌍 생성의 중요성

지식베이스 구축

문서 지식을 구조화된 QA 형식으로 조직하여 검색 가능한 지식 자산 생성

QA 시스템

질의응답 시스템의 학습 데이터로 활용되어 시스템 성능 직접 향상

LLM 사후 학습 (Post-training)

최신 LLM들은 QA 형식의 데이터를 핵심 학습 신호로 활용

  • Phi-4-reasoning: 추론 과정이 포함된 QA 쌍으로 미세 조정
  • DeepSeek-V4: 도메인 특화 QA로 전문가 모델 학습 및 지식 증류

문제 정의: 장문서 QA 생성의 한계

장문서의 중요한 지식은 여러 단락에 분산되어 있으며, 복잡한 엔티티 관계를 통해 연결된다. 이러한 단편화되고 관계적인 지식은 기존 QA 생성 방법에 큰 과제를 제기한다.
1

핵심 내용 누락

문서의 핵심 내용을 충분히 덮지 못함

2

단락 간 연결 부재

단락 간 의미적 연결을 포착하지 못함

3

다엔티티 관계 무시

다중 엔티티 간 복잡한 관계를 반영하지 못함

세 가지 핵심 과제

C1

그래프 기반 생성 공간으로의 변환

고수준 생성 목표를 구체적인 그래프 구조로 대응시키기 어려움 — 지식이 다단락에 분산되고 다중 관계로 연결된 경우

C2

그래프 구조에서 자연어 QA로의 변환

그래프는 관계 지식을 인코딩하지만, 질문 의도·답변 경계·언어 표현을 직접 결정하지 못함

C3

생성 QA 쌍의 평가 및 정제

QA 쌍을 지식 구조와 연결하지 않으면 품질 문제의 원인을 파악하기 어려워 개선 방향 결정 곤란

형성 연구(Formative Study): 문헌 검토 + 4명 도메인 전문가 반복 인터뷰를 통해 도출

GraphQAG: 3단계 워크플로우

1
문서 KG 구축
문서를 단락으로 분할하고 핵심 엔티티와 관계를 추출하여 지식 그래프 생성
2
그래프 기반 생성 공간
엔티티·관계·다홉 경로로 생성 공간을 구성하여 LLM 기반 QAG를 제약 및 안내
3
시각적 탐색·정제
KG를 대화형 시각 표현으로 활용하여 지식 구조 탐색, 증거 검증, QA 쌍 반복 정제

핵심 아이디어

지식 그래프를 생성의 가이드이자 평가의 렌즈로 동시에 활용하여, 자동 생성의 효율성과 인간 검증의 신뢰성을 결합

방법론: KG 구축 → QAG → 검증

① 핵심 엔티티 식별

LLM을 활용하여 각 단락에서 주요 엔티티를 추출하고 유형 분류

② 로컬 서브그래프 검색

타겟 엔티티를 중심으로 관련 엔티티·관계·경로를 포함한 서브그래프 구성

③ 서브그래프 안내 QAG

서브그래프 구조를 프롬프트로 제공하여 LLM이 그래프 기반 QA 쌍 생성

④ 역검증 및 최적화

생성된 QA 쌍을 원문과 KG에서 역추적하여 충실성과 정확성 검증

시각 설계: Knowledge Map

문서 지식 그래프를 노드-링크 다이어그램으로 시각화하여 전체 지식 구조를 한눈에 파악

  • 노드: 엔티티 (크기=중요도, 색상=유형)
  • 에지: 엔티티 간 관계 (라벨 표시)
  • 커버리지 오버레이: QA 쌍이 덮는 엔티티는 진한 색, 미달 영역은 밝은 색으로 구분
  • 단락 클러스터링: 동일 단락 출처 엔티티를 시각적으로 묶어 배치

시각적 인코딩

시각 채널매핑 정보
노드 크기엔티티 중요도
노드 색상엔티티 유형
노드 테두리QA 커버리지 여부
에지 두께관계 강도
배경 영역단락 경계

시각 설계: Evidence Bridge & QA Space

Evidence Bridge

QA 쌍을 지원하는 단락과 그래프 요소를 연결하는 증거 브릿지

  • QA 쌍 → 참조 단락 매핑
  • QA 쌍 → 관련 서브그래프 하이라이트
  • 근거 추적 가능한 신뢰성 검증

QA Space

생성된 QA 쌍의 분포를 산점도로 표현

  • X축: 핵심 엔티티 기준 분류
  • Y축: 추론 복잡도 수준
  • 컬렉션 수준 패턴 파악 (밀집/누락 영역)

QA Card: 선택된 QA 쌍의 질문, 답변, 해당 서브그래프를 함께 표시하여 개별 품질 상세 검토 지원

상호작용 설계

탐색

KG 노드 호버/클릭으로 관련 엔티티·관계 확장 탐색

검사

QA 쌍 선택 시 증거 단락과 서브그래프 동시 하이라이트

정제

미커버리지 엔티티 선택 후 해당 영역 QA 재생성 트리거

연계된 뷰 간 상호작용

Knowledge Map에서 엔티티 클릭 → Evidence Bridge에 관련 QA 쌍 표시 → Document View에서 해당 단락 스크롤
QA Space에서 밀집/누락 영역 식별 → Knowledge Map에서 해당 엔티티 영역 확인 → 재생성 또는 삭제 결정

평가: 사용자 연구

실험 설계

  • 16명 참가자
  • 2개의 장문서 (학술 논문)
  • GraphQAG vs Baseline (LLM 직접 생성) 비교
  • 정성·정량 평가 항목 포함

주요 결과

  • 지식 커버리지 갭 식별 능력 유의미하게 향상
  • 생성 QA 쌍의 근거 검증 효율성 개선
  • QA 쌍 세트 정제 작업 만족도 높음
  • 단락 간 연결 QA 생성에서 특히 우수
"Knowledge Map을 통해 어떤 엔티티 관계가 QA 쌍으로 변환되지 않았는지 직관적으로 확인할 수 있어, 누락된 지식을 빠르게 보완할 수 있었습니다."

사례 연구

사례 1: 타겟 영역 QA 정제

지식 갭 탐지

Knowledge Map에서 커버리지가 낮은 엔티티 클러스터를 식별하고, 해당 영역에 대해 집중적으로 QA 쌍을 재생성하여 전체 커버리지를 효과적으로 향상

사례 2: 단락 간 QA 구성

크로스 파라그래프

서로 다른 단락의 엔티티를 연결하는 다홉 경로를 KG에서 발견하고, 이를 바탕으로 단락 경계를 넘어서는 복합 추론 QA 쌍을 성공적으로 생성

전문가 인터뷰 결과

도메인 전문가들은 GraphQAG가 자동 생성의 효율성과 인간 검증의 신뢰성을 효과적으로 결합하며, 특히 장문서에서 지식의 구조적 파악을 크게 돕는다고 평가

논의: 한계 및 향후 과제

한계점

  • 엔티티·관계 추출 품질이 KG 구축 품질에 직접 영향
  • 매우 large-scale 문서에서의 그래프 가시성 문제
  • LLM 생성의 비결정성으로 인한 재생성 결과 편차
  • 특정 도메인(수식·표 포함 문서)에 대한 추가 적응 필요

향후 방향

  • 동적 KG 업데이트 및 증분적 QA 생성
  • 다양한 도메인(법률·의료·금융)으로 확장
  • 자동 품질 피드백 루프 통합
  • 그래프 레이아웃 스케일링 기법 개선

결론

GraphQAG는 지식 그래프, LLM 기반 생성, 시각 분석의 융합을 통해 장문서에서 더 포괄적이고 신뢰할 수 있는 QA 쌍을 생성하는 새로운 패러다임을 제시한다.
