SCALE

사이버물리 에이전트를 위한 실시간 잠재 표현 통신

Real-Time Latent Communication for Cyber-Physical Agents

Shanghao Shi, Jian Xiao, Ching-Hsiang Chan, Sanjoy Baruah, Sastry Kompella, Yevgeniy Vorobeychik, William Yeoh, Ning Zhang

Washington University in St. Louis · Nexcepta Inc.

배경: 왜 통신 방식이 문제인가?

원시 센서 데이터 전송

카메라·라이다 등 로우 데이터는 용량이 매우 크고, 대역폭이 제한된 네트워크에서는 전송 지연이 발생하여 실시간 협업이 어려움

자연어 메시지 전송

텍스트 생성(송신 측)과 해석(수신 측)에 추가적인 계산 오버헤드가 발생하며, 정보 손실과 지연이 초래됨

잠재 통신(Latent Communication)은 중간 모델 표현을 직접 교환하여 두 문제를 동시에 해결할 수 있는 "AI 언어"로 주목받고 있음

기존 연구의 한계

LLM 기반 잠재 통신

  • hidden state, KV cache 교환으로 모델 연산 절감
  • 모델 측 계산 효율에만 집중
  • 통신 대역폭과 태스크 마감시간(deadline) 미고려

통신 효율적 협업 인지

  • 대역폭·지연 고려 (특성 선택, 희소화 등)
  • 태스크 특화 인지에 한정
  • 대역폭 제한 링크를 공유하는 다중 이기종 CPS 태스크 미고려

연구 공백: 실용적 네트워크 제약과 이기종 태스크 마감시간 하에서의 CPS 에이전트 잠재 통신은 거의 탐구되지 않음

SCALE: 핵심 아이디어

물리 세계의 시공간적 연속성(spatio-temporal continuity)을 활용한 실시간 잠재 통신

1. 시공간적 잠재 재사용

연속 프레임 간 토큰 유사도 매칭으로 수신 측이 이미 가진 정보를 식별 → 중복 전송 제거

2. 효용–비용 프로파일링

전송 크기별 누적 의미적 이득과 통신 비용을 메시지별로 분석

3. 실시간 스케줄링

대역폭과 마감시간 제약 하에서 전송할 메시지와 토큰 수를 동시 결정

경량 설계: 기존 모달리티 인코더의 latent token에 그대로 동작 — 모델 수정 불필요, 다양한 감각 모달리티·CPS 태스크 지원

문제 정식화

시스템 모델: 각 CPS 에이전트는 관측 xi를 로컬 인코더로 잠재 표현으로 변환

Hi = E(xi) = {hi,1, …, hi,Ni}

hi,j ∈ ℝd는 고정 차원의 latent token, Ni는 토큰 길이

네트워크·타이밍 모델

제한적이고 시간 변동하는 대역폭을 여러 다운스트림 태스크가 공유하며, 태스크별로 서로 다른 마감시간 존재

스케줄링 목표

태스크 유틸리티(성능)와 메시지 정시 도달률(on-time delivery)을 동시에 최대화

SCALE 파이프라인

1
의미 변화 평가
수신 측 인지 상태와 토큰 매칭으로 변화한 정보만 식별
2
효용–비용 프로파일링
전송 크기별 의미적 이득과 비용 곡선 생성
3
실시간 스케줄링
대역폭·마감시간 제약 하 토큰 할당 결정

세 가지 기술적 도전 과제를 각각 해결: 고정 위치 비교의 과대평가 문제, 고정 전송 크기의 비효율, 이기종 마감시간 간 대역폭 경쟁

1단계: 의미 변화 평가

도전 과제

물리 관측은 연속적으로 진화하지만, 물체·에이전트·시점의 이동 때문에 고정 위치 비교는 이동 자체를 의미 변화로 과대평가함

→

해결: 유사도 기반 토큰 매칭

현재 latent token을 수신 측의 승인된(acknowledged) 잠재 상태와 매칭하고, 각 토큰의 최적 대응 관계 기준으로 의미 변화를 측정

  • 변화한 토큰만 우선 전송 대상으로 선별
  • 수신 측이 재사용 가능한 정보는 재전송하지 않음 → 대역폭 절감

2단계: 효용–비용 프로파일링

도전 과제

추가 latent token 전송의 의미적 이득은 메시지마다 다름 — 고정 전송 크기는 비효율적

→

해결: 메시지별 프로파일링

latent token을 의미 변화 순으로 랭킹하고, 전송 크기별 누적 의미적 이득과 통신 비용을 특성화하여 스케줄러에 입력으로 제공

효용 곡선: k번째 토큰까지 전송 시 얻는 태스크 성능 향상

비용 곡선: 토큰 수에 비례하는 대역폭 소모량

3단계: 실시간 스케줄링

도전 과제

한 메시지에 토큰을 더 배정하면 의미적 이득은 커지지만, 다른 메시지가 마감시간을 초과할 수 있음

  • 탐욕적 토큰 할당: 단위 통신 비용당 한계(한계치) 의미적 이득이 가장 큰 토큰부터 배정
  • EDF(최소 마감시간 우선) 정렬: 선택된 모든 메시지의 마감시간 실행 가능성(deadline feasibility) 유지
  • 대역폭·마감시간 제약을 만족하면서 전송할 메시지와 토큰 수를 공동 최적화

결과: 태스크 유틸리티와 정시 도달률을 동시에 향상

실험 설정

CooperScene

자율주행 협업 인지 벤치마크

OPV2V

차량 간 협업 3D 객체 검출 벤치마크

LIBERO

로봇 조작(manipulation) 벤치마크

  • 네트워크 조건: 제한 대역폭, 시변 링크 용량, 배경 트래픽 + 이기종 태스크 마감시간
  • 비교 대상: 전체 잠재 전송, 균일 압축, 최신 SOTA 4종 (Where2comm, V2VNet 등 계열)
  • 평가 지표: 태스크 성능(mIoU 등) + 메시지 정시 도달률

주요 결과

최고

거의 모든 설정에서 최고의 태스크 성능 달성 (OPV2V 15Mbps에서 최고 mIoU)

정시율 ↑

대역폭 제한 네트워크에서 메시지 정시 도달률 대폭 향상

  • 다양한 네트워크 조건(15Mbps 등)과 이기종 마감시간에서 일관된 우수성
  • 실제 스파이더 로봇 케이스 스터디: 벤치마크를 넘어 실제 물리 로봇 시스템에서도 효과 입증
  • 런타임 오버헤드 분석으로 실시간 동작 가능성 확인

기여 요약

1

문제 정의

이기종 마감시간을 가진 다중 CPS 태스크가 대역폭 제한 링크를 공유하는 실시간 잠재 통신 문제를 최초로 정식화

2

방법 제안

시공간적 잠재 재사용 + 효용–비용 프로파일링 + 마감시간 인지 스케줄링을 결합한 SCALE 제안

3

실증 평가

3개 CPS 벤치마크 + 실제 스파이더 로봇 케이스 스터디에서 다양한 네트워크 조건으로 효과 검증

결론

SCALE은 대역폭 제약과 이기종 태스크 마감시간을 고려한 최초의 CPS 에이전트 실시간 잠재 통신 방법으로, 태스크 성능과 정시 도달률을 동시에 크게 향상시킴
