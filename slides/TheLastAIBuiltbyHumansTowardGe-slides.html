인간이 만드는 마지막 AI

Toward Genuine Recursive Self-Improvement
진정한 재귀적 자기개선(RSI)을 향하여

AI 시스템이 경험과 피드백을 지속 가능한 개선 능력으로 전환하는 방법

"AI 진화는 인류의 진화처럼 광대한 역사가 될 것입니다. 지금까지의 모든 성취는 바다의 한 물방울에 불과합니다."

배경: 확장(Scaling)의 부담이 커지고 있다

최신 프론티어 모델 개발은 개발 파이프라인 전반에 걸쳐 기하급수적 규모 확장을 보여줍니다.

모델 개발의 3대 난제

1
자원 집약적인 파운데이션 모델 학습

데이터 준비, 아키텍처 설계, 분산 최적화, 평가 전반이 고비용. GDPval 벤치마크 구축에만 약 9,240 전문가-시간, Humanity's Last Exam은 7만 회 이상 제출 시도 필요.

2
피드백과 학습 환경의 확장

합성 데이터·강화학습에 경험 생성 인프라와 신뢰할 수 있는 평가·보존 메커니즘 필요. NVIDIA AIMO-2는 320만 개 장기 추론 해답과 54만 개 문제를 큐레이션.

3
배포 후 반복되는 적응

에이전트 워크로드는 일반 대화 대비 약 4배(멀티에이전트는 15배) 토큰 소비. 단일 회귀 진단에만 약 10 엔지니어-시간 소요.

기존 LLM의 한계를 드러내는 HCI

Headroom-Closed Index (HCI) — 모델의 실제 역량과 도달 가능한 상한(headroom) 사이의 닫힌 정도를 측정하는 지표

현대 파운데이션 모델의 능력 진보는 불균형합니다. 특정 과제에서는 인간 수준에 도달하지만, 개선 여지(헤드룸)가 남은 영역에서는 자체적으로 그 간극을 메우지 못합니다.

  • 개선은 여전히 외부 조정자(엔지니어)에 의해 주도됨
  • 경험과 피드백이 지속 가능한 능력으로 축적되지 않음
  • 개선 과정 자체는 개선되지 않는 일회성 최적화에 머묾

RSI란 무엇인가?

재귀적 자기개선(Recursive Self-Improvement): AI 시스템이 자신의 한계를 스스로 식별하고, 개선을 개발·검증하며, 그 결과로 얻은 능력으로 개선 과정 자체를 향상시키는 자율적 폐쇄 루프 프로세스

자율성

규정된 업데이트 실행에서 벗어나 한계 식별 → 경험 추출 → 변경 제안 → 검증·보존까지 책임 확대

효율성

데이터, 연산, 추론, 인간 검증, 재작업 대비 검증된 개선을 극대화

혁신성

인간이 규정한 업데이트 전략을 넘어서 탐색하고, 유용한 발견을 이후 개선 라운드에 재투입

RSI의 5단계 자율성 로드맵

자율성이 단계적으로 확장됩니다: B0 → L1 → L2 → L3 → L4 → L5

단계자율성의 대상핵심 질문
B0과제 내 개선 (In-Task)주어진 작업 안에서 스스로 개선할 수 있는가?
L1개선 실행규정된 개선을 사람 개입 없이 수행할 수 있는가?
L2개선 전략어떤 개선 방법을 선택할지 스스로 결정하는가?
L3미래 학습 경험스스로 과제·환경을 만들어 경험을 획득하는가?
L4배포·환경 적응실제 배포 환경의 피드백으로 적응하는가?
L5메타-개선이후 개선을 지배하는 메커니즘 자체를 개선하는가?

L1–L2: 실행과 전략의 자율성

L1 · 개선 실행 자율성

  • 데이터 수준: 합성 데이터 생성·필터링 자동화
  • 학습 방법 수준: RL·증류 파이프라인 실행
  • 학습 플랫폼 수준: 분산 학습 인프라 운영
  • 평가·안전 수준: 벤치마크 실행 및 안전 검증
  • 배포 최적화·응용 시스템 수준: 추론 최적화, 앱 개선

L2 · 개선 전략 자율성

  • 프롬프트 탐색: 최적 프롬프트 자동 탐색
  • 에이전트·하니스 탐색: 워크플로/도구 구성 진화
  • 모델·학습 탐색: 아키텍처 및 학습법 자동 탐색 (예: AgentNAS)
  • 목적 함수와 탐색 공간 설계까지 자율화가 핵심 과제

L3–L5: 경험, 적응, 메타-개선

L3
경험 획득 자율성
적응적 과제 생성, 자기 대국(self-play), 환경 상호작용을 통한 자율적 연습
L4
배포·환경 적응
궤적 증류, 에이전트 시스템의 반복 개정, 업데이트의 선택적 보존·배포
L5
재귀적 메타-개선
탐색 절차 개선, 후속 평가기 개선, 연구 목표·정책의 스스로 수정

L5에 도달하면 시스템은 "개선을 개선하는 방법"까지 스스로 진화시킵니다 — 이것이 진정한 RSI의 완성입니다.

4대 응용 분야에서의 RSI

S1 · 과학

가설 모듈 진화, 실험 에이전트 진화, 반성(reflection) 시스템과 개선자(improver) 진화

S2 · 구현 지능

환경·커리큘럼 진화, 기술·메모리·하니스 진화, 정책·행동 모델 진화, 세계 모델·평가기 진화

S3 · 소프트웨어 엔지니어링

코딩 에이전트 구현·하니스 진화, 경험·기술·협업 진화, 개선 과정 자체의 진화

S4 · 헬스케어

임상 메모리·지식 진화, 임상 추론 전략 진화, 의료 도구·워크플로 진화

각 분야는 서로 다른 요구사항과 발전 속도를 보이며, 도메인별 개선 루프의 폐쇄 방식이 다릅니다.

도전 과제와 미래 방향

핵심 과제

  • 자기개선 업데이트의 신뢰할 수 있는 검증과 보존
  • 레벨별 자율성에 대한 정량적 평가 체계 부재
  • 안전성·정렬(alignment) 유지 하의 자율 개선
  • 개선 루프의 누적 오류·붕괴 방지

미래 방향

  • 도메인을 넘는 범용 개선 루프 설계
  • 경험 생성·평가 인프라의 표준화
  • 인간 감독과 자율성의 최적 균형 탐구
  • L5 메타-개선을 향한 점진적 경로 검증

결론

1

모델 개발의 확장 부담은 개선 과정 자체를 시스템의 내재적 능력으로 전환해야 해결됩니다.

2

RSI는 실행 → 전략 → 경험 → 적응 → 메타-개선으로 이어지는 자율성 로드맵을 제시합니다.

3

과학·구현·소프트웨어·헬스케어 전 분야와 산업계의 초기 실천이 이미 RSI로의 전환을 예고하고 있습니다.
