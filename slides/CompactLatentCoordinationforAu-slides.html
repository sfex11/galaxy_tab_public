문제 정의 및 동기

신호등 없는 교차로

다수 자율주행차가 복잡한 동적 환경에서 충돌 없이 통행을 보장하면서 처리량을 유지해야 하는 핵심 과제

기존 MARL의 한계

  • 조합적 행동 공간 (|𝒜|N)
  • 특권 정보 의존 (미래 궤적, 전문가 시연 등)
  • 고정·이산적 행동 설계로 확장성 부족
  • 제한된 일반화 성능
"기존 계층적 방법은 이산 명령이나 명시적 하위 목표를 발행하여, 에이전트 수에 따라 행동 공간이 조합적으로 증가함"

아키텍처 상세

Master Agent (중앙집중)

  • 전역 상태 sMt 관측
  • Proto-plan zt ∈ ℝd 생성
  • 전략적 의도 인코딩
  • DDPG 알고리즘 기반 학습

Worker Agent (분산)

  • 국소 관측 oit + zt 결합
  • 차량별 행동 ait 선택
  • 전술적 실행 담당
  • 독립적 최적화 가능
핵심 분리: 협업(전략)과 제어(전술)의 완전한 분해 — 각 모듈 독립 업데이트 가능

상태 공간 설계

Master 상태 공간

전역 교통 상태 파악

  • 모든 차량의 정규화된 위치 (x, y)
  • 모든 차량의 속도 (vx, vy)
  • 교차로 진입 여부 인디케이터

Worker 상태 공간

국소 관측 + Proto-plan

  • 자 차량 위치 및 속도
  • 타 차량과의 상대 위치·속도
  • Proto-plan 임베딩 zt ∈ ℝd

핵심: 운동학 상태(위치·속도)만으로 충분 — 미래 궤적, 전문가 시연 등 특권 정보 불필요

행동 공간 및 Proto-Plan 메커니즘

Master 행동 공간

연속 잠재 공간 ℝd — 차량별 명령 할당이 아닌 전역 협업 전략을 직접 출력

기존: |𝒜|N 조합적 행동 → MAPS: O(d) 고정 크기

Worker 행동 공간

연속 가속도 a ∈ [−1, 1] — proto-plan과 국소 관측을 결합하여 차량별 제어 신호 생성

입력 크기가 차량 수 N에 무관하게 일정

보상 구조

Worker 보상 함수

  • 목표 도달 보상: 교차로 성공 통과 시 +10
  • 시간 페널티: 매 스텝 −0.1
  • 충돌 페널티: −50 (에피소드 즉시 종료)
  • 속도 유도: 목표 속도 근접 시 소량 보상

Master 보상 함수

  • 전역 효율성: 모든 Worker 보상의 합
  • 충돌 강력 페널티: 단일 충돌도 −100
  • 통과 완료 보상: 전체 차량 통과 시 추가 보상

네트워크 아키텍처 및 학습

네트워크 구성

  • Master & Worker 모두 DDPG 기반
  • Actor-Critic 아키텍처
  • ReLU 활성화 함수 사용
  • Batch Normalization 적용

  • 4방향 교차로 (T형, 十자형 등)
  • 다양한 차량 진입 패턴

  • VN-MADDPG — 가변 노이즈 MADDPG
  • 공정 비교를 위한 동일 환경 설정

전이 가능성의 근원

  • Proto-plan이 에이전트 수에 무관한 일반적 협업 전략을 학습
  • Worker 입력 크기가 고정되어 구조적 변경 불필요
  • 점진적 학습이 전이 가능한 표현을 촉진
"Proto-plan 기반 계층적 학습이 다차량 협업을 위한 유망한 프레임워크임을 확인"

절제 연구

Master 기여도

Master 없이 Worker만 학습 시 충돌률 급증 — 글로벌 조율의 필수성 입증

Proto-Plan 분석

학습된 임베딩의 t-SNE 시각화에서 교통 상황별 클러스터 형성 확인 — 의미론적 구조 보유

임베딩 차원 민감도

차원 d가 너무 작으면 정보 병목, 너무 크면 학습 어려움 — 적정 범위 존재

학습 동향 분석

MAPS는 베이스라인 대비 더 빠른 수렴을 보이며, 학습 초기부터 충돌률이 낮게 유지됨 — proto-plan이 효과적인 탐색 가이드 역할

결론 및 향후 과제

핵심 기여

  • 연속 proto-plan 임베딩으로 이산 명령 기반 협업 대체 — O(d) 복잡도 유지
  • 점진적 학습을 통한 제로샷 일반화 — 3→5 에이전트 94% 성공률
  • 운동학 상태만으로 충돌 제로 달성 — 특권 정보 불필요
  • 72개 교차로 구성에서 최고 베이스라인 대비 38% 통행 시간 개선

향후 과제

  • 고충실도 시뮬레이터로 확장 (CARLA 등)
  • 센서 기반 원시 인식 통합
  • 더 큰 차량 군집으로 스케일업
  • 보행자·자전거 등 혼재 교통 환경
