SpeakerMem-R1

Speaker-Centered Dual-Track Memory for Multi-Party Dialogue

화자 중심 이중 트랙 메모리로 다자 대화의 장기 기억을 재구성하다

Haobo Zheng, Tan Tang†, Yan Chen, Weijie Wang, Yingcai Wu
저장키 국가 CAD&CG 연구소, 저장대학교 (State Key Lab of CAD&CG, Zhejiang University)

배경: 그룹 채팅은 평평한 메시지 스트림이 아니다

  • 기존 장기 대화 메모리 연구는 1인·2인 대화 중심 — 관련도 기반 분할·압축·인덱싱·검색에 의존
  • 다자 그룹 채팅에는 화자 관계, 답장 구조, 교차 토픽 브랜치, 상태 수정이 존재
  • 참가자들은 서로 다른 토픽 브랜치를 논의하고, 상이한 입장을 표명하며, 서로를 지칭하고, 이전 상태를 수정
  • 벤치마크 결과: 범용 LLM 메모리 시스템은 인물·집단 관계를 잃거나 구성원 간 흩어진 단서를 통합하지 못함
문제는 단순히 관련 텍스트를 찾는 것이 아니라, 다자 대화 속 관계와 역사적 구조를 보존·복원하는 것이다.

두 가지 핵심 병목

메시지 귀속 (Message Attribution)

  • 누가 무엇을 말했는가
  • 그 발화가 누구에 관한 것인가
  • 개인 정보인가, 집단 공유 정보인가 (PERSON/GROUP 범위)

상태 재구성 (State Reconstruction)

  • 구성원·집단·시간에 흩어진 단서로부터 현재/과거 상태 복원
  • 요약·팩트 집계·범용 그래프는 출처/소유자, 범위, 상태 버전을 잃음
  • 저빈도 구성원이 제한된 후보 집합에 누락될 수 있음

필요한 것: 참가자 관계를 갖춘 검증 가능한 증거 + 질의 조건부 지역 상태 재구성

축어 트랙과 구조화 트랙의 증거를 엔티티·이벤트·시간 기준으로 질의 시점에 결합 → 귀속 오류와 갱신 오류를 줄이면서도 질의·응답 모듈은 동결(freeze)하여 안정성 유지

5계층 추적 가능한 이중 트랙 메모리

축어 트랙 (Verbatim Track)

  • 화자 라벨이 붙은 원문 메시지 저장
  • 누가, 누구에게 관련된 발화인지 손실 없이 보존
  • 검증 가능한 근거(grounding) 제공

구조화 트랙 (Structured Track)

  • 개인 수준(person-level) 뷰: 개인의 상태·선호·관계
  • 집단 수준(group-level) 뷰: 집단 공유 정보·집합 상태
  • 출처(provenance) 연결로 추적성 보장
  • 온라인 기록 + 비파괴적 갱신: 대화 도중 실시간 기록하며 기존 상태를 덮어쓰지 않고 버전 관리
  • 종단 간 실행: 기록 → 투영 → 선택 → 확장 → 응답의 전체 파이프라인

질의 조건부 증거 구성: Anchor–Separate–Resolve–Compose

1
Anchor
질의를 엔티티·이벤트·시간 축으로 투영
2
Separate
축어 트랙에서 화자 조건 증거 선택·확장
3
Resolve
충분성 판단 후 보충 검색(ASK) 결정
4
Compose
이중 트랙 증거를 결합해 동결된 응답자에 전달

두 개의 검색 경로(축어 + 구조화)와 4단계 조직화를 통해 참가자·이벤트·시간별로 증거를 정렬 — 저빈도 구성원 누락과 PERSON/GROUP 범위 혼동을 방지

Writer-R1 학습: 화자 조건 강화학습

화자 조건 매칭(speaker-conditioned matching)으로 구조화 상태의 귀속 정확도를 소유자 기준으로 평가 — 누가 말했는지, 누구에 관한 상태인지를 정밀 채점

소거 실험: 무엇이 기여하는가

이중 트랙 기여

  • 축어 트랙: 검증 가능한 원문 커버리지 제공
  • 구조화 트랙: 귀속·범위·상태 버전 정리
  • 구조화 트랙의 이점은 축어 커버리지에 의존 — 축어 없이는 판단 품질 저하

계층 구조 기여

  • 개인 수준 뷰: 개인 귀속 질문 처리
  • 집단 수준 뷰: 공유 정보·집합 상태 질문 처리
  • 두 뷰의 결합이 단일 뷰 대비 일관되게 우수

검색 Top-k 민감도: 커버리지 추가는 도움이 되지만 예산 슬롯당 수익은 감소, 과잉 레코드는 오히려 판단을 방해 — Acc와 token-F1을 함께 고려해 예산 선택

기여 요약

기여 1  SpeakerMem-R1 설계 — 추적 가능한 축어 메시지와 개인·집단 수준 구조화 뷰를 결합한 이중 트랙 메모리로 다자 대화의 귀속·범위 제어·상태 재구성 달성

기여 2  분석 프레임워크 제공 — 구성원 커버리지, 정보 귀속, 개인/집단 범위, 용어·이벤트 중의성, 시간 갱신·멀티홉 추론의 5차원 분석 체계

기여 3  로컬 배포형 Writer-R1 학습 — SpeakerLevenshtein과 화자 조건 GRPO로 Qwen2.5-3B를 학습, LLM Writer 기준 정확도의 95.4% 달성하며 종단 간 파이프라인 검증

결론

다자 대화의 장기 기억은 관련 콘텐츠 검색을 넘어 귀속 가능한 증거와 질의 조건부 상태 재구성을 요구한다

  • 이중 트랙(축어 + 구조화) 메모리로 3개 벤치마크 최고 성능 달성
  • 강화학습 Writer로 로컬 3B 모델이 LLM Writer 수준의 기록 품질 확보
  • 향후 과제: 더 긴 대화·더 큰 집단 규모로의 확장 및 멀티모달 확장
