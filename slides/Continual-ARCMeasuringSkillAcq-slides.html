Continual Learning Benchmark

Continual-ARC

작업 수명 전반에 걸친 스킬 습득 측정

Daniel Lenton · Unify

arXiv: 2611.14505

배경: 몇 주씩 일하는 에이전트는 무엇을 배우는가?

  • ARC (Chollet, 2019): 사전지식과 경험을 스킬로 전환하는 효율로 지능을 측정
  • 그러나 ARC는 스킬 습득을 단일 에피소드 안에서 한 번만 측정
  • 에이전트 하네스는 지속학습의 유망한 메커니즘으로 부상

암기 (Memorization)

한 작업에서 습득한 스킬이 다음에 유사한 시나리오를 다시 만났을 때도 남아 있는가?

일반화 (Generalization)

그 경험이 비슷하지만 만난 적 없는 작업을 더 잘하게 만드는가?

기존 벤치마크의 세 가지 한계

1. 단일 도메인

코딩·오피스 업무 등 한 적용 도메인에만 집중 — 사전학습에서 이미 알던 지식이 개입해 이득의 출처가 불분명

2. 일회성 인스턴스

고정된 인스턴스를 한 번씩만 제공 — 같은 개념 과제가 새 입력으로 돌아오지 않아 암기와 추상적 스킬 구분 불가

3. 단일 학습자 계열

파인튜닝 벤치마크는 가중치 업데이트만, 에이전트 벤치마크는 프롬프팅·메모리만 가정 — 동일 척도 비교 부재

Continual-ARC: ARC 위에 세운 평생 스트림

  • ARC-AGI 3개 에디션(1·2·3)으로 구성된 3개 트랙 — 난이도가 순차적으로 상승
  • 도메인 지식 불필요 — 객체성·셈하기 같은 핵심 사전지식(core-knowledge priors)만 요구
  • 각 과제의 규칙은 소수의 시연으로부터 유도해야 함
  • 학습자는 인스턴스 사이에 무엇이든 유지 가능 — 메모리 기반과 가중치 기반이 같은 스트림, 같은 시험

Re-ARC 생성기가 검증된 새 인스턴스를 요청 시 생성 — 캐시해 둔 답으로는 풀 수 없는 새 입력이 매번 주어진다

인스턴스 점수: 피드백 예산의 소비 비율

ARC 과제 = 입력 격자를 출력 격자로 바꾸는 규칙. 학습자는 인스턴스마다 아래 중 선택할 수 있다.

답 제출

오답에는 비용을 지불하며 재시도 허용, bare verdict(정답 여부)만 수신

시연 구매

비용을 지불하고 입출력 시연 한 쌍을 추가로 구매

하네스 행동

하네스가 제공되는 경우 그 안에서 도구 사용·메모 저장 등의 행동 수행

오답 시도 1회 또는 시연 1개의 비용

전체 피드백 예산 — 미해결 인스턴스는 전액 소진

과제는 돌아오고, 새 과제도 계속 온다

  • 과제의 재등장 시점은 스트림 스케줄 생성기가 결정

200 라운드 동안 지속적으로 학습
2
동결
학습자를 얼리고 더 이상 갱신 금지
3
두 시험
암기와 일반화를 각각 측정

시험 1 — 암기

스트림에서 만났던 과제들의 새 인스턴스로 측정

시험 2 — 일반화

스트림이 한 번도 보여주지 않은 ARC-AGI-1 평가 세트 100개 과제로 측정

두 가지 레짐: 개인과 집단

개인 (Individual)

하나의 시스템이 한 명의 사용자를 단독으로 서비스

집단 (Collective)

하나의 시스템이 2 또는 4명의 사용자를 동시에 서비스 — 각 사용자는 서로 겹치지 않는 자신만의 과제를 담당

  • 팀원마다 다른 과제를 맡는 실제 작업 환경을 모사 — 학습은 그룹 전체에 걸쳐 집단적으로 일어남
  • 동시 사용자가 많을수록 200 라운드 동안 더 다양한 학습 데이터가 생성
  • 그 결과 미지 과제에 대한 일반화가 향상됨

같은 스트림, 다섯 계열의 학습자

학습자설명
프롬프팅 플로어 (C0, C)과제별 시연을 단순 캐시하는 하한 기준선
엔지니어드 레퍼런스 (P)시연에서 프로그램을 유도하는 프로그램 유도 방법
에이전트 하네스 (Q, G)prime-agent 등 — 동결된 가중치, 지속성 유무를 비교
교사의 노트 (T)GLM-5.3 Flash가 Qwen3.5-9B가 읽을 노트를 작성
가중치 (DE)GLM-5.3 Flash를 모방하도록 학습된 Qwen3.5-9B (DAgger)

주 실험 모델: Qwen3.5-9B, GLM-5.3 Flash — 노트와 가중치가 같은 교사에게서 배운다

결과 ① 재등장 과제: 지속성만으로는 부족

  • 하네스에 지속성(persistence)을 부여해도, 명시적 전문가 지도가 없으면 암기는 개선되지 않음
  • 테스트한 모든 모델에서 대부분의 하네스 기반 방법은 "과제별 시연을 단순 캐시"하는 플로어보다 낮게 학습
  • 교사의 하네스가 "과제당 프로그램 하나를 저장하라"는 명시적 지시를 받았을 때에만 프로그램 유도 방법과 경합

기성 하네스가 자동으로 쌓아 올리는 메모리보다, 단순한 시연 캐시가 더 잘 "기억"한다

결과 ② 미지 과제: 가중치만이 일반화한다

하네스·노트·프로그램

미지 과제에서 측정 가능한 이득이 전혀 없음

가중치 기반 (교사 모방)

교사(GLM-5.3 Flash)의 행동으로 학습한 학생(Qwen3.5-9B)이 미지 과제에서 상당한 이득

  • 집단 레짐: 동시 사용자를 2→4명으로 늘리면 미지 과제 일반화가 더 향상
  • 하네스 기반 방법은 사용자 수와 무관하게 미지 과제에서 이득 0

논의와 향후 방향

  • 기성 에이전트 하네스는 낯선 도메인에서 거의 "학습"하지 못한다는 점을 정량적으로 드러냄
  • 가중치 기반 지속학습으로 새로운 도메인에서 하네스를 구동하는 법을 모델에 가르치는 연구의 문을 엶
  • ARC-AGI-2·3 트랙 예비 결과와 프라이빗 평가 세트로 게이밍을 방지하는 검증 절차 정의
