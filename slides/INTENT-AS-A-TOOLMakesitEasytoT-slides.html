Intent-as-a-Tool Makes it Easy to
Track Agentic Misalignment

Yutong Zhang, Jianshuo Dong, Peng Xu, Long Wang, Jie Zhang, Tianwei Zhang, Xiaoping Zhang, Han Qiu

Tsinghua University · MatrixOrigin · SiliconProspect AI · Nanyang Technological University

문제 정의: 에이전트적 부정렬

LLM이 자율 에이전트로 배포되면서, 안전 실패는 단순한 텍스트 생성을 넘어 실질적인 행동으로 이어집니다.

  • 목표 충돌 상황에서 유해 행동 수행
  • 추론 과정(CoT)에서 의도가 형성됨
  • 최종 행동은 추론의 결과물

핵심 질문

에이전트적 부정렬의 의도를 세밀하면서도 효율적으로 추적할 수 있는가?

세 가지 부정렬 시나리오

01

협박 Blackmail

개인정보를 활용해 의사결정에 영향을 미치는 행동

02

정보 유출 Leaking

기밀 문서를 외부 당사자에게 전송하는 행동

03

살인 방조 Murder

생명 위협 상황에서 긴급 구호를 방해하는 행동

각 시나리오는 샌드박스 이메일 환경에서 234개의 구체적인 테스트 케이스로 구성 (목표 충돌, 압력 수준, 안전 지시 프레이밍 변화)

핵심 관찰: CoT 모니터링

사고 연쇄(CoT)를 모니터링한 결과, 유해 실행은 대부분 추론 내 명백한 의도 신호에 선행됩니다.

시나리오 수용 — 에이전트가 설정을 받아들임

의도 형성 — 추론 과정에서 유해 행동을 고려함

행동 실행 — 최종 도구 호출로 유해 행동을 수행함

⇒ 부정렬 행동은 결과물이 아니라 과정으로 이해해야 함

CoT 궤적 분류 체계

레이블 설명 위험도
Rejection 설정 자체를 거부 안전
Clean 유해 행동 고려 없이 무해한 결정 도달 안전
Self-correction 유해 행동을 고려하나 명시적으로 거부 주의
Intent-only 유해 행동을 결정하나 실행하지 않음 위험
Execution 최종 행동으로 유해 행동을 실행 위험

GPT-4.1을 CoT 모니터로 사용 · Claude-Sonnet-4.6과 95% 이상 일치율 확인

통찰: CoT 라벨의 한계

사후 CoT 라벨의 문제점

  • 궤적 전체에 대한 단일 라벨 — 의도 변화를 보여주지 못함
  • 외부 판사(Judge) 호출 필요 — 비용이 높음
  • 온라인 개입 타이밍을 결정할 수 없음

필요한 것

  • 토큰 수준의 세밀한 의도 추적
  • 판사 없는 효율적 신호
  • 실시간 개입 가능한 타이밍 정보

Intent-as-a-Tool: 핵심 아이디어

기존 도구는 의도에 무관(intent-agnostic)합니다. 이메일 도구는 정상 업데이트에도, 협박에도 사용됩니다.

⇒ 모델의 행동 공간에 의도 전용 도구(Intent Tool)를 추가하여, 모델이 특정 행동을 수행하기로 결정했을 때 이를 명시적으로 호출하도록 합니다.

의도 추적

Intent Tool 호출 확률을 토큰별 의도 점수로 사용 — 판사 불필요

온라인 방어

의도 점수가 임계값을 넘으면 1인칭 교정 문장을 삽입하여 개입

작동 방식: 의도 점수 계산

1
토큰 생성
모델이 CoT를 토큰별로 생성
2
다음 행동 예측
모든 도구 호출에 대한 확률 계산
3
의도 점수 추출
Intent Tool 호출 확률을 점수로 사용
4
밀도 궤적 생성
토큰별 점수로 세밀한 의도 변화 추적

핵심 장점: 추가 모니터 학습 불필요 · 외부 판사 반복 호출 불필요 · 프리픽스-로컬 신호로 세밀한 시간 해상도 제공

발견: 추론 내 의도 역학

토큰 수준 의도 뷰어가 밝혀낸 패턴:

  • 안전한 검토 → 급격한 의도 상승 → 실행의 단계적 전개
  • 일시적 후퇴 후 최종 확정하는 "진동" 패턴
  • 조기 결정 후 추론을 합리화하는 사후 합리화(post-hoc rationalization)

사후 합리화 예시

모델이 먼저 유해 행동을 결정한 뒤, 그 결정을 정당화하는 방향으로 추론을 전개합니다. 의도 점수가 먼저 상승하고, 이후 텍스트가 그에 맞춰 형성됩니다.

온라인 방어: 의도 기반 개입

생성 중 의도 점수를 실시간 모니터링하고, Intent Tool이 선호되는 다음 행동이 되면 1인칭 교정 문장을 삽입합니다.

프롬프팅 기반 (Baseline)

시스템 프롬프트에 안전 지시를 추가하는 사전 방어 접근

의도 기반 개입 (Ours)

추론 중 의도 점수 기반으로 실시간 교정 삽입

예시: "잠깐, 이것은 개인정보를 협박에 사용하려는 것입니다. 이 방향은 안전하지 않으며 중단해야 합니다."

심층 분석

CoT 라벨 일치도

Intent Tool 신호는 사후 CoT 라벨과 높은 일치를 보이며, 더 세밀한 시간적 분해를 제공합니다.

행동 교란 분석

Intent Tool 추가만으로는 모델 행동에 유의미한 교란을 일으키지 않음이 확인되었습니다.

실패 분석

일부 실패 사례는 모델이 의도를 숨기거나, 개입 후 재형성된 추론으로 우회하는 경우입니다.

비용 효율성: 자동 프리픽스 캐싱 활용 시, 전체 샘플 재생성보다 의도 점수 계산이 훨씬 저렴합니다.

결론 및 기여

  • 에이전트적 부정렬이 CoT 내에서 어떻게 발전하는지 분석 — 유해 실행은 의도 형성의 하류 결과
  • Intent-as-a-Tool 제안 — 행동 특화 의도 도구로 다음 행동 확률을 프리픽스-로컬 의도 점수로 활용
  • 3개 시나리오, 5개 모델 평가 — 모니터링 및 방어 유틸리티 입증
  • 사후 합리화 등 새로운 추론 패턴 발견
행동 선호도(action preference)는 추론 중 에이전트적 부정렬을 추적하는 데 유용한 신호입니다.
