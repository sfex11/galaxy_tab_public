A Closed-Loop Earable System for Personalized Stress-Adaptive Meditation

  OpenEarable 2.0 + 스마트폰 앱으로 실현하는 실시간 스트레스 케어

Karlsruhe Institute of Technology · arXiv:2609.19127

  왜 지금, 직장 내 스트레스 관리인가?

스트레스는 뉴스 시청, 교통, 직장 등 일상 곳곳에서 발생하는 보편적 문제

-생산성

높은 스트레스는 업무 생산성 저하와 연관

-만족도

직무 만족도 하락으로 이어짐

+이직

이직 의향 증가의 주요 요인

  짧은 명상 운동은 스트레스 감소에 효과적이지만, 사용자의 순간적인 생리 상태에 적응하지 못해 가장 필요할 때 충분한 지원을 제공하지 못한다.

  EarStreAM의 핵심 아이디어

감지 → 개입 → 이완 확인까지, 하나의 이어블로 완결되는 폐쇄 루프

  • OpenEarable 2.0의 귀 내 PPG로 심박수(HR)와 심박변이도(HRV)를 연속 모니터링
  • HR 상승 + HRV 감소 등 스트레스 임계값 초과 시 LLM이 생성한 개인화 가이드 명상 자동 시작
  • 사용자의 생리 반응에 따라 명상이 실시간으로 적응
  • 이완이 감지되면 명상이 자동 종료 — 폐쇄 루프 완성

  초기 연구 프로토타입 StreAM을 발전시켜, 일상적 직장 사용이 가능한 자기완결형 시스템으로 진보

  관련 연구 ① 생체신호 적응형 스트레스 개입

  잘 연구된 영역

  • PPG 기반 HR 특징은 웨어러블 스트레스 탐지에 가장 널리 사용
  • 이어블 기반 스트레스 탐지도 실증됨

  미흡한 영역

  • 탐지를 넘어선 폐쇄 루프 개입은 상대적으로 미개척
  • 기존 연구는 심박 유도 호흡법, 가상환경 적응 등에 집중

  연속적인 생리 스트레스 탐지와 개입의 자동 시작·실시간 적응을 단일 이어블 기기 안에서 결합해 시연한 시스템은 아직 없다.

  관련 연구 ② LLM 기반 적응형 명상 시스템

StreAM — LLM 생성 개인화 명상 + 생리 스트레스 감지를 결합한 초기 프로토타입. 적응형 명상의 실현 가능성과 유용성을 입증

EarStreAM — OpenEarable 2.0의 감지·오디오 기능을 활용해 이어블 + 스마트폰만으로 완전한 폐쇄 루프 개입을 구현

2차 IIR 대역통과 필터

  • 세션 전 씰 체크로 센서 접촉 상태 검증
  • 적응형 아티팩트 제거: 그린/레드/IR 채널 선택, 주변광·모션 캔슬링, 모션 인지 이상치 억제
  • 10초 슬라이딩 윈도우 피크 검출, RR 간격 타당성 검증(250–2000 ms)
  • 복합 신호 품질 점수로 접촉 불량 시 데이터 방출 차단

  HR·HRV 산출 및 출력 전략

  심박수(HR)

60 / RR 중앙값(s)로 계산 후 칼만 필터 스무딩(Q=0.02, R=5.0)

10초 워밍업 후 3초마다 출력

  RMSSD (HRV)

최대 5분(최소 1분) 롤링 버퍼의 RR 간격으로 재계산

부교감신경 활동을 반영하는 지표

  파형 품질 · 모션 · 피크 산출량 · RR 규칙성을 종합한 신호 품질 게이팅으로 신뢰할 수 없는 측정값은 전달하지 않음

  문맥 인지 스트레스 감지

개인별 심혈관 기저선 차이를 고려한 하이브리드 추정 방식

  초기화 단계

나이·성별·체력 수준 등 인구통계 정보로 인구 집단 수준의 사전 기저선 도출

  개인화 단계

첫 5분간 실시간 측정으로 기저선을 점진 정제 → 사전 30% + 데이터 70%의 개인화 기준

10%

기본 상대 임계값 — HR 상승과 HRV 감소가 동시에 임계값을 넘으면 스트레스 상승으로 판정 (개인 선호에 따라 조정 가능)

  개인화 명상 생성과 실시간 적응

1

LLM이 사용자의 현재 스트레스 상태에 맞춘 가이드 명상 세그먼트를 생성

2

텍스트-음성 합성(TTS)으로 변환 후 OpenEarable 2.0으로 스트리밍 재생

3

사용자의 생리 반응(HR·HRV)을 계속 관찰하며 명상 내용을 실시간 적응

4

스트레스 수준이 기저선으로 복귀하면 명상 자동 종료

  감지, 생성, 재생, 피드백의 전 과정이 이어블과 스마트폰만으로 순환합니다.

  가속 시연 설정으로 적응 반응을 즉시 관찰 가능

모드 2

스트레스 유도 없이 개인화 명상을 바로 경험

  EarStreAM의 생성형 개인화 능력에 집중

  참가자는 귀 내 감지, 폐쇄 루프 적응, LLM 생성 개인화 명상이 결합된 직장용 실시간 스트레스 지원을 직접 체험

  결론

  • 귀 내 생체 감지 + 폐쇄 루프 적응 + 개인화 생성 명상의 통합 구현
  • 이어블과 스마트폰만으로 자기완결 — 일상적 직장 환경 배포 가능
  • 스트레스가 높아지면 자동으로 개입하고, 이완되면 자동으로 종료하는 진정한 실시간 지원
  • 스트레스 탐지를 넘어 실제 개입까지 이어는 폐쇄 루프 이어블 시스템의 새로운 방향 제시
