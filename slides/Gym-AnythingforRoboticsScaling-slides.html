시뮬레이션, 왜 중요한가?

시뮬레이션은 embodied AI를 대규모로 학습시킬 수 있는 가장 유망한 경로입니다.

시뮬레이터의 장점

  • 수천 개 에피소드 병렬 실행
  • 즉각적인 리셋
  • 완전한 ground-truth 상태 접근
  • 인간 감독 없는 보상 제공

핵심 병목

  • 현실적인 시뮬레이션 제작에 막대한 전문가 노력 필요
  • 수십 년의 발전에도 불구하고 좁은 범위의 작업과 물리 현상만 커버
  • 시각적 충실도 제한
  • 전문가 의존적 제작 방식은 확장 불가

핵심 통찰

"시뮬레이션 제작은 코딩 에이전트 과제로 재정의할 수 있다"

시뮬레이션 구축 = 코드 작성:

  • 에셋을 조립하여 장면 구성
  • 물리 설정 구성
  • 작업 정의 및 보상 구현
  • 코딩 에이전트의 발전 → 더 풍부하고 충실한 시뮬레이션
  • 시간이 지날수록 개선되는 확장 가능한 시뮬레이션 제작

GDP 기반 시뮬레이션 선정

미국 GDP 데이터에 근거해 경제적으로 가치 있는 물리적 작업을 우선 커버

1
직업 분해
각 직업의 물리적 작업 부분을 원자적 물리 동작으로 분해
2
경제 가치 가중
동작을 경제적 가치로 가중치 부여
3
커버리지 선택
가장 가치 높은 동작과 필요한 로봇·물리 능력을 커버하는 시뮬레이션 선택

예시: 현실적인 적정(titration) 실험 — 용액이 적하되고, 혼합되며, 종말점에서 분홍색으로 변해야 함 (빨강이 아님)

생성-감사 루프

코딩 에이전트가 만든 시뮬레이션에는 오류가 잦음 — 대립적(adversarial) 검증 루프로 해결

생성 에이전트

시뮬레이션의 품질 증거를 제시해야 함:

  • 렌더링 이미지
  • 물리 측정값
  • 보조 시연(demonstration)

4개 감사 에이전트

좋은 시뮬레이션의 기준을 검사:

  • 현실성 — 표면 장력, 벽 통과 오류 등 포착
  • 해결 가능성
  • 속도
  • 악용 방지 — 대립 에이전트가 합법적 로봇 행동으로 시뮬레이션 파괴 시도

작업 생성과 난이도 제어

너무 쉽거나 너무 어려운 작업만 있으면 평가·개발 신호가 없음 → 목표 난이도로 작업 생성

6개 감사 에이전트

해결 가능성, 보상 정확성 등을 수작업 체크리스트로 독립 검증

보상 설계

진행도 + 최종 결과를 물리 상태에서 계산 — 예: 청소 작업에서 객체별 정확 배치에 부분 점수 부여

변동성

단일 팔 → 양팔 → 휴머노이드 등 다양한 로봇, 객체 자세·외형·물리 변화로 동일 작업을 변주

작업 감사는 불완전한 검증기(verifier)도 포착 — 보상이 잘못된 작업을 걸러냄

전체 벤치마크 성공률

  • 모든 프론티어 모델이 RoboWorld의 모든 테스트 작업에서 실패
  • 더 쉬운 부분 집합에서는 최고 모델이 32% 도달 — 여전히 미해결
  • 로봇의 자유도가 증가할수록 성공률 급락
  • 대립적 감사의 합법적 로봇 행동으로 대부분의 시뮬레이션이 파괴됨을 확인 — 감사 루프가 물리 오류를 잡아냄

프론티어 모델의 새로운 학습 방법

시뮬레이션만이 제공하는 특권 상태(privileged state) — 완전한 ground-truth — 를 활용

  • In-context 학습: 반복 시도를 거치며 개선, 특권 상태 접근 시 가속
  • 교사-학생 코칭: 시뮬레이터 상태를 읽는 특권 교사가 맥락 내에서 학생을 지도 — 언어적 힌트만으로도 전이
  • 자기 경험 학습: 모델 자신의 특권 경험으로부터 학습
  • 코드 정책: 다양한 장면에서 시연을 생성하여 π₀.₅ 같은 VLA(시각-언어-행동 모델) 학습

흥미로운 발견: 프론티어 모델은 작업 해결을 위해 스스로 도구를 만들어 사용하기도 함

시뮬레이션 품질 검증

기존 시뮬레이터 대비

동일한 상호작용에 대해 가장 강력한 기존 시뮬레이터보다 우수한 품질을 달성

감사의 역할

  • 잘못된 물리를 포착
  • 대립적 감사가 합법적 로봇 행동으로 대부분의 시뮬레이션을 파괴 — 취약점 검증
  • 작업 감사가 불완전한 검증기 포착

생성-감사 루프는 코딩 에이전트가 만든 시뮬레이션의 신뢰성을 담보하는 핵심 장치

결론

  • 시뮬레이션 제작을 코딩 에이전트 과제로 재정의 → 코딩 에이전트의 발전이 곧 시뮬레이션의 발전
  • GDP 기반 선정으로 경제적으로 가치 있는 물리 작업을 체계적으로 커버
  • 대립적 생성-감사 루프로 현실성·해결 가능성·속도·악용 방지 검증
  • RoboWorld: 25개 시뮬레이션, 200개 RL 환경 — 프론티어 모델조차 미해결
  • 특권 상태를 활용한 4가지 새로운 학습 방법으로 성능 대폭 향상
