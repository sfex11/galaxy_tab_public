01 배경: LLM 정렬(Alignment)의 두 가지 접근

RLHF

인간 선호 쌍으로 보상 모델을 학습한 뒤, 강화학습으로 정책을 최적화

  • 검증된 강력한 실증 성능

다단계 파이프라인 → 높은 메모리·계산 비용

직접 정렬 (DPO, SimPO 등)

보상 모델 없이 선호 쌍만으로 정책을 직접 최적화

  • 단순하고 안정적인 학습
  • 계산·메모리 효율성

그러나 likelihood displacement라는 고질적 문제에 직면

02 핵심 문제: Likelihood Displacement

선호 응답의 상대적 우도는 비선호보다 높아지지만, 그 절대 확률은 오히려 하락 → "의도치 않은 얼라인먼트 해제(unintentional unalignment)"

직관적 예시

"Never"보다 "No"를 선호하도록 학습시키면, 엉뚱하게 "Yes"의 우도가 급증

안전성 위험 (Gemma-2B-it)

유해 요청에 거부 응답을 생성하던 모델이 DPO 학습 후 이에 응답 — 확률 질량이 거부 응답으로부터 이탈

관련 문제: 장황함(verbosity) — 품질 향상 없이 더 긴 응답을 생성하는 경향

03 Noisy Preference Pairs: 버릴 수 없는 정보

원인

  • 선호/비선호 응답이 모델 관점에서 유사한 작은 마진(small margin) 쌍
  • 선호 신호가 약하거나 모호함 → 마진 기반 손실 최적화 시 역효과 유발

기존 대응과 한계

  • SFT 정규화 추가 → 제한적 효과
  • CHES 점수 기반 필터링 → 효과적이지만 해당 쌍을 학습에서 완전히 제거

필터링된 쌍에도 여전히 유용한 비교 정보가 담겨 있음

핵심 질문: noisy 쌍에서 정보를 버리지 않고 안전하게 추출할 수는 없을까?

04 핵심 아이디어: 선호 정렬을 "비교 오라클"로 재해석

1

명시적 미분 가능 목적함수 대신, 정책 섭동이 선호 쌍에서 국소 행동을 개선하는지를 질의

2

유리한 섭동 = 선호 응답 우도 증가 + 비선호 응답 우도 감소

3

Noisy 쌍은 고정 손실의 학습 표본이 아니라, 잠재 정렬 목표에 대한 비교 신호로 활용

Zeroth-Order 패러다임: 기울기 없이 함수 값 비교(1비트 신호)만으로 정규화된 업데이트 방향을 추정

05 ComPO — Offline 스킴의 동작 방식

1
정책 섭동
출력층(output-layer) 섭동으로 후보 정책 생성
2
비교 질의
선호/비선호 응답의 우도 변화로 1비트 신호 획득
3
신호 집계
엔트리별 임계값 처리(entry-wise thresholding) 후 업데이트 방향 추정
4
정책 정제
정렬된 정책을 noisy 쌍으로 미세 정제(refinement)

핵심: noisy 쌍 위에서 미분 가능한 선호 손실을 직접 최적화하지 않음 → DPO/SimPO로 정렬된 정책을 보완·정제

06 Online ComPO: 무레이블 생성으로 KL 제어

유지되는 것

  • 오프라인 선호 쌍 기반 비교 메커니즘 (비교 신호의 원천)

추가되는 것

  • 레이블 없는 현재 정책 생성 샘플 활용
  • 참조 정책 대비 역방향 KL(reverse-KL) 제약으로 스텝 크기 적응
커버리지 관점: 역방향 KL은 평가 대상 정책의 생성만으로 추정 가능 → 전체 정책 클래스가 아닌 참조 정책 근방의 국소 커버리지 기반으로 성능 분석 가능

07 이론적 보장

Offline ComPO

가정: 매끄러움(smoothness) + 기울기 희소성(sparsity) + 오라클-잠재 목표 간 호환성(compatibility)

→ 기본 스킴에 대한 best-iterate 수렴 보장 확립

Online ComPO

가정: 정확한 역방향 KL 제약 + 국소 커버리지 + 분포 내(in-distribution) 쌍별 보상 정확도

→ 제약 스킴의 실행 가능성(feasibility) 증명 및 성능 갭 상계

커버리지는 별도의 가정이며, KL 제약만으로 자동으로 함의되지 않음

08 실험 ①: DPO·SimPO 증강 (Offline)

DPO + ComPO

noisy 쌍을 ComPO로 처리 → likelihood displacement 완화 및 성능 향상

SimPO + ComPO

참조 모델이 없는 SimPO에도 동일하게 호환되며 승률 개선

  • Mistral, Llama 등 베이스/인스트럭션 튜닝 모델에서 기존 직접 정렬 대비 향상
  • 쌍 단위(pair-level) 우도 진단: noisy 쌍에서 선호 응답의 절대 우도 감소 경향 완화

09 실험 ②: 5개 모델 계열 + Length-Controlled 승률

베이스 및 인스트럭션 튜닝 모델 전반에서 평가:

Mistral Llama Gemma-2 Qwen3 Gemma-3

LC Win Rate 개선

응답 길이를 보정한 승률에서 기존 직접 정렬 방법 대비 향상 → 길이 효과를 배제한 실질적 판정 성능 향상

쌍 단위 진단

쌍별 우도 변화 분석이 likelihood displacement 완화와 일관된 증거 제공

10 Ablation 연구

설계 선택

  • 섭동 개수(perturbations)의 영향
  • 기울기 임계값과 noisy 쌍 수의 영향

실용성

  • 효율성 및 DPO/SimPO와의 호환성
  • 성공적 섭동 비율과 클리핑 임계값 λ의 역할

Online 정규화

역방향 KL damping이 정책 이탈 제어에 미치는 효과 검증

Replay

replay 메커니즘이 온라인 학습 안정성에 미치는 영향 평가

11 결론

  • ComPO 제안: 저마진(noisy) 선호 쌍을 미분 가능 손실 없이 정렬에 활용하는 비교 기반(zeroth-order) 방법
  • 이론: offline 스킴의 best-iterate 수렴 보장 / online 스킴의 역방향 KL 제약 하 실행 가능성과 국소 커버리지 기반 성능 보장
  • 실증: Mistral·Llama·Gemma-2·Qwen3·Gemma-3에서 기존 직접 정렬 대비 향상 — LC 승률과 쌍 단위 진단으로 뒷받침
ComPO는 기존 직접 정렬을 대체하지 않고, clean 쌍의 손실 최적화와 상호 보완적으로 결합되는 새로운 정렬 패러다임
