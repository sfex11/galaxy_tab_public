Terminal-Universe

에이전트 궤적을 확장 가능한 터미널 환경으로 바꾸기

Qwen Team, Alibaba Group · Tsinghua University

왜 환경(Environment)인가?

터미널 에이전트의 궤적은 대규모로 축적되었지만, 실행 가능한 현실적 환경은 여전히 희소합니다.

궤적 (Trajectory)

  • 하나의 고정된 시연(frozen demonstration)
  • 품질이 정책 모델의 능력에 종속
  • 코드베이스 변경의 정답 여부 검증 불가

환경 (Environment)

  • 재질의(re-query)하여 다수의 검증 가능한 태스크 생산
  • 실행 피드백(execution feedback) 제공
  • 같은 워크스페이스에 더 어려운 태스크 부과 가능
포스트트레이닝이 실제로 필요한 자원은 궤적이 아니라 환경입니다.

핵심 아이디어: 매핑의 역전

궤적 속 도구 실행 기록은 실행 환경의 구조와 내용을 그대로 노출합니다.

Read 호출 → 파일 내용 확인 가능
Write / Edit 호출 → 워크스페이스의 변화 과정 확인 가능
기존: 환경 →(롤아웃)→ 궤적    제안: 궤적 →(역매핑)→ 환경 복원

원본 저장소 없이, 새로 만들지도 않고, 궤적 자체에서 실행 가능한 워크스페이스를 재구성합니다.

생성된 검증 가능 태스크

1단계: 환경 재구성

원본 저장도 없는 궤적으로부터 미해결 상태의 워크스페이스를 복원합니다.

결정론적 재생 (Replay)

  • 기록된 파일 연산을 순서대로 재생
  • 에이전트가 수정하기 이전 상태로 각 파일 복원
  • 에이전트의 편집을 보류 → 워크스페이스가 미해결 상태로 시작

에이전틱 완성 (Completion)

  • 재생만으로는 부분적 워크스페이스만 얻어짐
  • 완성 에이전트가 누락된 파일·의존성 자동 보충
  • 솔루션 유출 없이 태스크 실행에 필요한 최소 구성만 추가

2단계: 재질의 — 폭과 깊이의 두 축

실제 소프트웨어 엔지니어링의 루틴을 재현하며 태스크를 확장합니다.

폭 확장 (Breadth)

관련 환경 간 의존 관계를 발굴하여 여러 코드베이스에 걸친 교차 워크스페이스 태스크 합성

  • 참조 구현 읽고 적용하기
  • 한 프로젝트에서 다른 프로젝트로 기능 이식
  • 두 컴포넌트 연결하기

깊이 확장 (Depth)

단일 턴 질의를 다중 라운드 세션으로 확장

  • 유저 에이전트가 워크스페이스 변화에 근거한 후속 요구 제시
  • 요구사항 정제·기능 추가·실패 시 원인 기반 수정 요청
  • 매 라운드 검증 후 결과를 자연스러운 피드백으로 전달

3단계: 검증과 필터링

모든 새 태스크는 실행 가능한 검증기와 함께 생성됩니다.

  • 에이전트가 컨테이너 내부에서 태스크별 검증기(verifier)를 직접 작성
  • 롤아웃된 해결 궤적 중 모든 테스트를 통과한 것만 학습 데이터로 유지
  • 태스크 충분성(task sufficiency) 평가로 품질 보장
  • 검증기 필터링이 노이즈 데이터를 걷어내 학습 신뢰도를 높임
환경이 있기에 우리만의 테스트로 결과를 검증할 수 있습니다 — 궤적 모방으로는 불가능한 일입니다.

분석 및 절제 연구

재해결 vs 궤적 모방

복원된 환경에서 태스크를 재해결(re-solving)하는 것이 원본 궤적을 그대로 모방하는 것보다 훨씬 우수

검증기 필터링의 역할

필터링을 제거하면 노이즈가 섞인 데이터로 학습 품질 저하 — 검증기 필터링이 핵심 기여

폭·깊이 확장 기여

교차 워크스페이스(폭)와 다중 라운드(깊이) 확장이 각각 독립적으로 성능 향상에 기여

교차 도메인 일반화

학습 시드가 없던 도메인으로의 일반화 능력도 확인

핵심 기여 요약

  • 환경 재구성 — 에이전트 궤적을 재사용 가능한 실행 환경으로 재정의하고, 결정론적 재생 + 에이전틱 완성으로 복원 (원본 저장소 불필요, 제로부터 생성 불필요)
  • 재질의 방법 — 단일 워크스페이스·단일 턴을 넘어, 교차 워크스페이스 합성(폭)과 다중 라운드 유저 질의(깊이)로 환경의 활용도 확장 · 에이전트 작성 검증기 부착, 통과 궤적만 유지
  • 실증적 검증 — Qwen3.5-27B 파인튜닝으로 Terminal-Bench 2.1 +11.9, EvoCode-Bench v2 MT@4 +13.8 · 재해결이 궤적 모방을 크게 상회함을 확인

"궤적은 환경의 관찰 기록이다" — 방치된 궤적 자산을 포스트트레이닝용 환경으로 전환하는 새로운 패러다임을 제시합니다.
