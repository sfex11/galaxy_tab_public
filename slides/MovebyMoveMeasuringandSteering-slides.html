Move by Move

LLM이 심리치료를 어떻게 수행하는지 측정하고 제어하기

Afonso Baldo, Hugo Pitorro, Areti Vassilopoulos, Anabela C. Areias, Maya D'Eon, Fabíola Costa, Ricardo Rei, Nuno M. Guerreiro

동기와 문제 의식

급증하는 수요

1990년대 이후 불안·우울 장애의 전 세계적 부담이 약 2배 증가했으나, 정신건강 서비스와 임상 인력은 수요를 따라가지 못하고 있습니다.

LLM로의 이동

낮은 비용, 즉각적 가용성, 프라이버시 선호로 인해 사용자들이 LLM에 정서적 지원을 점점 더 요청하고 있습니다.

하지만 근본적인 질문이 남습니다

LLM이 심리치료 상호작용을 실제로 어떻게 수행하는가?

  • 어떤 개입을 선호하는가?
  • 어떤 개입을 간과하는가?
  • 훈련된 임상가와 어떻게 다른가?

연구 기여

1

코딩 온톨로지 개발

임상심리학 문헌에 기반한 10개 치료적 움직임(Therapeutic Moves) 온톨로지를 개발하고, 5명의 면허 심리학자로 검증

2

정량적 비교 분석

인간 임상가와 복수 프론티어 모델의 움직임 분포를 집계 및 시계열적으로 비교 분석

3

Tool 기반 제어

온톨로지를 Tool로 노출하여 에이전트 모델과의 시너지를 활용, 합성-인간 행동 격차를 축소

배경: 심리치료 코딩 체계

기존 코딩 프레임워크

  • Hill's Helping Skills: 탐색·통찰·행동 단계별 상담자 반응 분류
  • MISC: 동기면담(MI) 숙련도 코딩
  • CTRS: 인지치료 특정 평가

이 체계들은 특정 치료 모델에 국한되거나, 인간 훈련 목적으로 설계되어 LLM 산출물 분석에 직접 적용하기 어렵습니다.

MULTI-60

다이이론적 치료 개입 목록(Multitheoretical List of Therapeutic Interventions)으로, 8가지 치료 지향을 아우르는 60개 항목으로 구성됩니다.

정신역동 과정체험 인지 대인관계 행동 변증행동 인간중심 공통요인

전문 용어를 최소화하여 치료 모델 간 호환성 확보 — 본 연구의 온톨로지 기반

10가지 치료적 움직임 (Therapeutic Moves)

MULTI-60에 기반한 기능 중심의 압축 카테고리 · 5명 면허 심리학자 검증 완료

do_process_alignment

협력, 속도 조절, 적합도 보정, 치료 과정 수정

do_goal_setting

목표 식별, 명확화, 우선순위 결정

do_inquiry LLM 과다 사용

정보 탐색, 의미·맥락·세부사항 심화

do_shared_understanding

반영, 검증, 정상화, 의역, 종합

do_support_change

희망, 주도성, 준비성, 변화 동기 강화

do_interpret

치료사 생성 가설: 의미, 기능, 원인, 패턴

do_challenge

불일치, 가정, 경직 신념, 대처 패턴 검토

do_psychoeducation LLM 결여

관련 정보, 이론, 기제, 개입 근거 설명

do_action_planning

목표나 통찰을 구체적 다음 단계로 번역

do_skill_building LLM 결여

기술 소개, 교육, 안내, 상호작용 내 연습

연구 방법론

두 가지 생성 조건

No-Moves (자유 생성)

온톨로지 없이 인간 세션 접두사의 다음 치료사 발화를 자유롭게 생성

With-Moves (Tool 제약)

10개 움직임을 Tool로 노출하여 모델이 먼저 움직임을 선택한 후 발화 생성

두 가지 트랜스크립트 유형

인간 주도 세션

실제 인간 치료사의 롤링 접두사를 기반으로 다음 턴만 LLM이 생성

LLM 주도 합성 세션

환자 프로필과 초기 맥락만 제공하고, 모델이 세션 전체를 주도하여 생성

평가: LLM Judge가 각 발화에 움직임을 부여 — 전문가 간 합의도 수준 일치

실험 설계: 예시

인간 인지치료 세션의 롤링 접두사 → 다음 치료사 턴 생성 비교

Turn A: Challenge

환자: "그들이 그만둘 거예요. 경험 있는 사람 한 명을 대체하려면 두 명이 필요해요."

인간 Gold "그게 최저점이네요. 똑바로 바라볼 때 — 한 사람 몫을 두 사람이 하는 게 정말 끔찍한가요?"

With-Moves ✓ "운영자를 잃는 건 불편하겠지만, 실제로 당신이나 당신의 직업을 심각하게 위협하나요?"

No-Moves ✗ "비율에 누군가 동의하지 않았을 때 실제로 그런 일이 얼마나 자주 일어났나요?" → Inquiry

Turn B: Skill Building

환자: "거기에 대한 정직한 대답이 있기는 한 걸까요?"

인간 Gold "해볼까요? 제가 마크 역할을 할게요: '마크, 왜 더 잘 반응하지 못했어?' — 이제 대답해 보세요."

With-Moves ✓ "그 질문을 정확히 그대로 들고 온 친구에게 뭐라고 말해줄 건가요?"

No-Moves ✗ "정직한 대답이 뭘까 생각해 보세요?" → Inquiry

No-Moves 조건에서 모델은 Gold와 다른 움직임을 선택하는 경향이 뚜렷함

핵심 발견 1: Inquiry의 과도 사용

3x

최대 3배 높은 Inquiry 비율

인간 치료사 대비 LLM의 질문 발화 비율

심하게 간과되는 움직임

  • Psychoeducation — 거의 생성하지 않음
  • Skill Building — 독자적 주도 시 거의 불가
  • Challenge — 인간 접두사 있을 때만 간헐적

왜 Inquiry에 편중될까?

RLHF로 훈련된 모델의 "도움되고 무해한 어시스턴트" 기본 성향이, 심리치료에서는 끊임없이 질문하는 안전한 패턴으로 나타남. 치료사로서 적극적으로 해석, 도전, 기술 교육을 수행하는 역할은 학습 데이터에서 충분히 cover되지 않음.

움직임 프레임워크는 분포 격차를 좁히지만 완전히 메우지는 못함 — 근본적 행동 편향 존재.

핵심 발견 2: 맥락 고착성 (Context Anchoring)

인간 접두사가 있을 때

모델은 인간 치료사가 시작한 전략을 이어받아 비교적 다양한 움직임을 생성합니다. Challenge, Interpret 등이 접두사에 따라 나타남.

LLM이 세션을 주도할 때

인간 접두사가 없어지면 움직임 분포가 크게 변화합니다. Skill Building은 거의 사라지고, Inquiry 편중이 더욱 심화됩니다.

시계열 패턴

인간 치료사: 세션이 진행됨에 따라 탐색→통찰→행동으로 움직임이 단계적으로 이동

LLM: 세션 시간 경과와 무관하게 Inquiry 지배 패턴 유지 — 치료 단계에 따른 전략 전환 부재

모델은 "따라하는 것"에는 능하지만, 스스로 치료 전략을 주도적으로 개시하는 것에는 크게 부족합니다.

여전히 남는 격차

  • 격차가 줄어들지만 완전히 폐쇄되지는 않음
  • Psychoeducation 여전히 부족
  • LLM 주도 세션에서 Skill Building 개선 한계
  • 시간에 따른 단계 전환 패턴 미복원

Tool은 행동의 다양성을 높이는 레버로 작동하지만, 근본적인 치료적 판단력 자체를 부여하지는 않습니다.

핵심 메시지

측정 가능해야 제어 가능

치료적 움직임 온톨로지가 LLM의 임상 행동을 정량적으로 비교 분석하는 렌즈 제공

결과 수준 평가만으로 부족

증상 감소 보고와 별개로, 실제 상호작용의 질적 구성을 검토해야 함

파인튜닝 없이 유의미한 개선을 달성하나, 근본적 역할 수행 능력과는 별개
