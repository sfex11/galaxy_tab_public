Skill-Space Shooting

자율 로봇 정책 개선을 위한 스킬 공간 슈팅

재사용 가능한 스킬을 "후보 교정"으로 탐색(shooting)하여,
성공한 시도를 정책 개선의 감독 신호로 바꾸는 자율 개선 프레임워크

Zihang Rui† · Renhao Wang† · Haoxu Huang · Yang Gao

Tsinghua University · UC Berkeley · Shanghai Qi Zhi Institute

왜 배포 이후 개선이 필요한가?

실세계에 배치된 로봇은 초기 학습만으로 새로운 상황과 실패에 계속 대응할 수 없습니다.

새로운 객체 · 장면 변화

배포 환경은 학습 시와 다릅니다. 낯선 물체와 바뀐 배치가 정책의 약점을 드러냅니다.

작은 실행 오차의 누적

미세한 조작 오류도 장기 태스크에서는 실패로 이어집니다.

반복만으로는 부족

시도를 늘려도 같은 실수를 되풀이할 뿐, 올바른 수정을 스스로 발견하지 못합니다.

매 실패마다 사람의 시범·교정을 요구하면 감독(supervision)이 병목이 됩니다. 필요한 것은 스스로 교정 경험을 생성하는 개선 과정입니다.

기존 접근법의 한계

자율 개선의 세 갈래 길 — 각각 결정적인 장벽이 존재합니다.

접근법강점한계
강화학습 (RL) 보상 기반 상호작용 학습, 사전학습 정책 주변 탐색 희소 보상 장기 태스크의 물리적 탐색 비용이 과도함
대화형 모방학습 (DAgger) 학습자가 실제 방문한 상태에서 전문가 교정 수집 반복적 인력 비용 태스크가 늘수록 사람 개입이 계속 필요
Agentic 로보틱스 파운데이션 모델 추론으로 스킬·프로그램 구성 정책 미개선 도움으로 태스크를 완수해도 정책 자체는 그대로
핵심 난제: 정책의 실패 지점에서 교정을 생성하고, 성공적인 지원을 학습용 감독으로 전환하는 것

핵심 통찰: 스킬 = 교정(Correction)

겉보기에 다른 장기(long-horizon) 태스크들은 짧은 행동, 즉 스킬을 공유하며,
이 스킬이 곧 국소적 교정(local correction)이 될 수 있다.

예시: 키팅 태스크의 픽킹 스킬

엔드투엔드 키팅이 아직 불안정한 정책도, 별도 학습된 픽킹 스킬은 국소 조작 문제만 해결하면 됩니다. 정책의 현재 상태에서 스킬을 호출하면 정책 자신이 만든 상황을 처리하며, 새 시범이 커버하지 못하는 부분을 메꿉니다.

파운데이션 모델의 역할

FM은 장면·객체·태스크 구조에 대한 지식으로 어떤 스킬을 시도할지 추론하고, 물리적 롤아웃을 모니터링해 복구 성공 여부를 판정합니다.

  • 성공한 시도 = 태스크를 이어가는 방법 + 정책이 난관을 헤치는 법을 가르치는 행동 데이터
  • 스킬이 교정 감독의 자급 자원이 되어, 남은 실패로 개선 시도를 확장 가능

Skill-Space Shooting: 전체 파이프라인

학습된 스킬을 태스크 정책 롤아웃의 후보 연속(candidate continuation)으로 자율 시도합니다.

1
실패 감지
학습된 가치 모델이 실패 가능성이 높은 상태를 감지해 개입 시점 결정
2
스킬 선택
VLM이 의미 지식으로 스킬 라이브러리에서 복구용 스킬 선택
3
복구 · 검증
스킬 실행으로 롤아웃 복구, VLM이 성공 여부 확인 후 정책 재개
4
집계 · 개선
완료된 롤아웃의 복구 구간을 DAgger 스타일로 집계해 다음 정책 학습
개선된 정책이 다음 라운드의 경험을 수집 → 자율 개선 루프가 닫힙니다. 스킬 공유까지 더하면 새 태스크의 가르침所需 인력도 감소합니다.

언제, 어떻게 슈팅할 것인가

When: 실패 감지기

학습된 가치 모델이 현재 상태에서 실패 가능성을 추정합니다. 예측값이 낮아지는 순간, 즉 정책이 난관에 부딪히기 직전에 스킬 호출을 트리거합니다.

자동 개입 시점 판단

How: 의미 기반 스킬 선택

각 스킬은 시각·텍스트 설명을 동반합니다. VLM은 이 설명과 현재 장면을 결합해 객체·행동·태스크 구조 지식을 활용, 시도할 행동을 고릅니다.

FM 추론으로 후보 탐색
  • 스킬은 정책이 도달한 현재 상태에서 호출 — 이전 행동이 만든 조건을 그대로 처리
  • 태스크 전체를 몰라도, 국소 문제만 풀면 되는 스킬이 교정으로 충분
  • 사람의 새 시범 없이, 기존 가르침이 교정 행동의 원천으로 재사용됨

복구 검증과 정책 개선 루프

1
VLM 검증: 스킬 실행 중 물리적 롤아웃을 모니터링하여 실패가 실제로 복구되었는지 확인
2
정책 재개: 검증을 통과하면 태스크 정책이 다시 제어를 이어받아 롤아웃 완주
3
복구 구간 추출: 완료된 롤아웃에서 수락된 복구 세그먼트(accepted repair segments)만 수집
4
DAgger 스타일 집계: 복구 데이터를 집계하여 다음 태스크 정책을 업데이트

지원 → 감독으로 전환

실행 도움을 주던 스킬이 곧 학습 데이터가 되어, 구성·복구 시스템을 제거해도 정책 스스로 그 이득을 유지합니다.

점진적 자립

정책이 좋아질수록 개입이 줄고, 남은 실패에만 슈팅이 집중되는 자기 강화 개선이 진행됩니다.

스킬 라이브러리의 재사용과 공유

스킬은 하나의 태스크에 고유하지 않습니다 — 교정 감독의 원천이 태스크 간에도 이어집니다.

태스크 간 공유

한 태스크에서 학습한 스킬 데이터를 공유하면, 새 태스크의 교정 준비에 필요한 추가 가르침이 줄어듭니다.

프리미티브 적응

기존 스킬 데이터를 재활용하면 새로운 motion primitive에 스킬을 적응시키는 인간 노력도 감소합니다.

새 태스크 부트스트랩

공유된 스킬은 완전히 새로운 태스크에서의 정책 개선 출발점으로도 활용됩니다.

초기 인간 가르침이 한 번 쓰이고 끝나지 않고, 자율 정책 개선의 재usable 자원이 됩니다.

실험 설정

실험 환경

  • 실제 로봇 4개 태스크에서 평가 (시뮬레이션 아님)
  • 초기 시범으로 학습된 불완전한 BC 태스크 정책에서 출발
  • 시각·텍스트 설명을 갖는 스킬 라이브러리 구성

평가 항목

  • 주요 결과: 반복(iteration)별 무보조(unaided) 정책 성공률 변화
  • 신뢰성: 개입 시점과 복구 성공률 분석
  • 공유 효과: 스킬 데이터 공유가 새 태스크 개선에 미치는 영향
질문은 하나입니다 — "도움 없이 혼자 행동하는 정책이 반복마다 좋아지는가?"

주요 결과: 반복될수록 좋아지는 정책

4

실세계 로봇 태스크 전반에서 성공률 향상 확인

0

초기 태스크 성공이 관찰되지 않은 정책에서도 개선 시작 가능

반복(iteration)이 거듭될수록 무보조 성공률 지속 상승

  • 개입 없이 정책 단독으로 수행한 시도에서 측정 — 도움에 대한 의존이 아닌 실제 학습을 입증
  • 수락된 복구 세그먼트가 쌓일수록 정책이 스스로 실패를 극복
  • 사람의 추가 시범 없이 자율 루프만으로 개선 달성

개입과 복구는 믿을 수 있는가?

개입 분석

개입이 실제로 정책의 실패 상태에서 발생했음을 확인했습니다. 즉, 스킬 라이브러리가 필요한 순간에 필요한 복구를 제공합니다.

복구 신뢰성

VLM의 사전·사후 검증이 성공한 복구를 선별하여, 노이즈가 섞인 데이터가 학습에 유입되는 것을 방지합니다.

실패 감지 → VLM 선택 → 물리 시도 → 검증의 각 단계가 서로를 보완하며 오류를 걸러냄
실패한 복구 시도는 폐기되고, 검증된 교정만 정책 개선의 감독이 됨

스킬 공유: 새 태스크로의 확장

교정 감독의 원천이 태스크 경계를 넘어 전이됩니다.

  • 기존 태스크의 스킬 데이터를 공유하면 새로운 motion primitive에 스킬을 적응시키는 데 필요한 인간 시범이 크게 감소
  • 공유된 스킬 라이브러리가 완전히 새로운 태스크에서도 정책 개선을 촉진
  • 새 태스크 준비 비용이 라이브러리가 채워질수록 점점 줄어드는 규모의 경제 형성
"초기 인간 가르침(initial teaching)이 태스크 내부와 가로질러 자율 정책 개선을 위해 재사용 가능해진다."

한계 및 향후 방향

스킬 라이브러리 의존성

복구는 라이브러리에 이미 존재하는 스킬의 범위 안에서 가능합니다. 미지의 실패 유형에는 새로운 가르침이 여전히 필요합니다.

판단 모듈의 오류

실패 감지기와 VLM 검증이 틀리면 개발 기회를 놓치거나 부적절한 데이터가 유입될 수 있습니다.

향후 방향

  • 경험으로부터 새로운 스킬을 자동 발굴하여 라이브러리를 스스로 확장
  • 더 긴 호라이즌 태스크와 다단계 실패로 개선 루프 확대
  • 더 강건한 실패 감지·복구 검증으로 완전 자율 개선에 근접

결론

  • 재사용 가능한 스킬을 교정 감독의 원천으로 전환한 자율 정책 개선 프레임워크
  • 가치 모델의 개발 시점 판단 + VLM의 의미 기반 스킬 선택·검증
  • 수락된 복구 세그먼트의 DAgger 스타일 집계로 실세계 4개 태스크에서 반복 개선 달성
  • 스킬 공유로 새 태스크의 가르침 비용까지 절감 — 확장 가능하고 일반화 가능한 개선
