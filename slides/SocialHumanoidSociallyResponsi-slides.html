Social Humanoid

Socially Responsive Human–Humanoid Interaction

사람을 지각하고, 예측하고, 반응하는 휴머노이드 로봇

Vongani H. Maluleke*, James Ni*, Kie Horiuchi, Lea Wilken, Jiahui Lei, Evonne Ng, Roei Herzig, Jitendra Malik, Trevor Darrell, Angjoo Kanazawa

UC Berkeley · Sony Group Corporation · Meta

상호작용은 조율(Attunement)의 예술

하이파이브를 맞추거나 함께 작업할 때, 사람들은 말 없이도 시선·자세·타이밍으로 서로를 예측하고 맞춰갑니다. 이것이 사회적 지능의 핵심입니다.

인간

  • 상대의 의도를 실시간으로 예측
  • 자연스럽게 조율하며 정렬

기존 휴머노이드

  • 혼자 있는 단일 에이전트로 학습됨
  • 사회적 신호를 인식·반응하지 못함

휴머노이드가 가정·직장·공공장소로 확장되는 지금, 사람과 함께(with) 움직일 능력이 필수입니다.

문제 정의: 인간-휴머노이드 상호작용

휴머노이드는 인간 파트너의 모션 관측을 조건으로, 조율되고 사회적으로 반응적인 전신(whole-body) 모션을 지속적으로 생성·실행해야 합니다.

1
관측
RGB-D 영상으로 인간 모션을 재구성하고 3D 공간에 위치시킴
2
예측·생성
미래 인간 모션과 사회적으로 조율된 휴머노이드 반응을 생성
3
실행
저수준 전신 트래킹 컨트롤러가 실제 로봇에서 실행

예시: 포옹, 인사 후 함께 사진 포즈 취하기 — 로봇은 카메라 프레임에서부터 폐루프(closed-loop)로 사람과 상호작용합니다.

실물 휴머노이드 배포의 세 가지 갭

데이터 갭

인간-인간 상호작용은 대규모로 캡처되지만 인간-휴머노이드 상호작용 데이터셋은 부재. 각 파트너를 독립적으로 리타겟팅하면 접촉·도달성·공간 구조가 파괴됨.

표현 갭

인간과 휴머노이드 모션이 서로 다른 공간에 존재 → 생성 모델이 상호작용 자체 대신 두 임베디드의 차이를 학습하게 됨. 기존 연구에서 간과된 부분.

생성 갭

최적화 기반 리타겟팅은 깨끗한 오프라인 데이터용으로, 노이즈·불연속이 많은 실시간 파트너 관측에는 취약 → feed-forward 생성 모델 필요.

Social Humanoid: 계층적 시스템

고수준 정책

  • 공유 토큰 표현으로 인간+휴머노이드 모션을 유연하게 시퀀스 모델링
  • 관측된 파트너 모션에 기반한 반응적(reactive) 모션 생성
  • 파트너가 가려져도(occlusion) 모션을 예측하여 연속적 상호작용 유지

저수준 정책

  • 생성된 모션을 실제 로봇에서 실행하는 전신 트래킹 컨트롤러
  • 29-DoF Unitree G1 휴머노이드 대상
  • 시뮬레이션과 실세계 하드웨어 모두 지원

핵심 설계 모션 생성과 실행이 비동기적으로 구동되어 카메라 프레임 → 로봇 명령까지 중간 308ms의 낮은 지연 시간을 달성합니다.

기여 ① 두 단계 Adaptive-HHI Retargeting

1
Pass 1 — 로봇 리타겟팅: 한 상호작용 파트너의 모션을 29-DoF Unitree G1으로 리타겟팅합니다.
2
Pass 2 — 파트너 공동 모핑(Co-morphing): 나머지 파트너의 신체 자세를 변형하여 접촉 역학(contact dynamics)·도달 가능성(reachability)·상대적 신체 스케일을 보존합니다.

5개 모션 캡처 데이터셋에 적용:

Chi3D Hi4D Harmony4D Inter-X Embody3D

→ 상호작용 구조를 유지하며 HHI 벤치마크를 구축합니다.

새로운 HHI 벤치마크

260시간

인간-휴머노이드 상호작용 데이터

Dyadic + Polyadic

2인 상호작용뿐 아니라 다중 인물(polyadic) 상호작용까지 포함

G1 페어링

모든 상호작용이 Unitree G1 휴머노이드와 쌍을 이루도록 변환됨

기여 ② Shared-Codebook VQ-VAE

핵심 통찰: 공유된 모션 표현을 사용하면 단일 생성 모델이 두 임베디드(embodiment)를 공동으로 추론할 수 있습니다.

  • 인간과 휴머노이드 모션을 하나의 이산(discrete) 어휘로 토크나이즈
  • 인코더 Eh·Er로 상대 상태를 latent 토큰 z*로 인코딩
  • 디코더 Dh·Dr로 미래 인간 행동과 휴머노이드 모션을 복원
  • 표현 갭 해소 — 모델이 상호작용 자체에 집중

부수 효과 이 공유 어휘는 최적화 기반 리타겟팅 없이 G1의 실시간 섀도우 텔레오퍼레이션(shadow teleoperation)도 지원합니다.

기여 ③ Diffusion Forcing Transformer (DFoT)

  • 공유 어휘 위에서 휴머노이드 반응을 자기회귀적으로(autoregressive) 생성
  • Diffusion-forcing 목적함수는 불완전한 실세계 입력에 강건
  • 유창한 장기(long-horizon) 상호작용 지원
  • 파트너가 가려지거나 입력이 끊겨도 인간 모션을 예측(anticipation)하여 상호작용 연속성 유지
저수준 실행기: NVIDIA SONIC 전신 트래킹 컨트롤러가 생성된 모션을 실제 로봇에서 안정적으로 실행

전체 파이프라인

1
관측
RGB-D에서 인간 포즈 재구성, depth·중력 추정으로 3D 로컬라이제이션
2
인코딩
VQ-VAE로 상대 상태 인코딩 → latent 토큰 z*, 상대 포즈 T*, 정규 변환 ΔT* 결합
3
생성
DFoT 정책이 미래 인간 행동 + 조율된 휴머노이드 모션을 디코딩
4
실행
SONIC이 시뮬레이션/실제 로봇에서 실행, 로봇 상태 갱신으로 폐루프

로봇 상태가 다시 관측에 반영되어 연속적 폐루프 상호작용이 이루어집니다.

실시간 배포 성능

308ms

카메라 프레임 → 휴머노이드 명령까지의 중간(median) 종단 지연

비동기 구조

  • 모션 생성과 실행이 비동기적으로 구동
  • 노이즈·불연속 관측에도 유창한 동작 유지

섀도우 텔레오퍼레이션

공유 코드북 덕분에 최적화 기반 리타겟팅 없이, 휴머노이드가 사람의 동작을 실시간으로 그대로 따라하는 원격 조작이 가능합니다.

실험 결과

  • 시뮬레이션과 실세계 하드웨어 모두에서 검증
  • 다양한 상호작용 유형에서 조율되고 인간 정렬된(human-aligned) 행동 달성
  • 실제 사람과의 포옹, 인사, 함께 포즈 취하기 등 밀접 접촉 상호작용 성공
  • 파트너가 가려진 상황에서도 예측 기반으로 상호작용 지속

사회적 반응성

RGB-D 관측 → 인간 모션 조건화 → 미래 인간 행동 + 휴머노이드 반응 예측

데모 영상

결론

Social Humanoid는 휴머노이드가 사람을 지각·예측·반응하며 전신으로 상호작용하는 사회적 반응성을 실현했습니다.

  • 데이터 갭 → 2단계 Adaptive-HHI Retargeting으로 접촉·도달·스케일을 보존하며 260시간 HHI 벤치마크 구축
  • 표현 갭 → Shared-Codebook VQ-VAE로 두 임베디드를 단일 어휘에서 공동 추론
  • 생성 갭 → DFoT 고수준 정책 + SONIC 저수준 실행기로 실시간(308ms) 폐루프 제어
  • 시뮬레이션과 실세계에서 다양한 상호작용 유형에 대해 조율된 행동 입증
