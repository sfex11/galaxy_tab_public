멀티턴 장기 계획의 물리학

사전학습부터 사후학습까지:
단일·다중 교사 온폴리시 에이전트 증류를 통한 접근

Tianyi Men · Zhuoran Jin · Kang Liu · Jun Zhao

중국과학원 자동화연구소 · 중국과학원대학교 인공지능학부

왜 멀티턴 장기 계획인가?

파운데이션 모델이 에이전트 시스템으로 진화하면서, 멀티턴 장기 계획(Multi-turn Long-Horizon Planning) 능력은 실세계 지능형 에이전트 구현의 핵심이 되었습니다.

  • 복잡한 작업 분해
  • 환경 상태 추적
  • 상태 전이 모델링
  • 원자 기술의 장기적 구성

현재 벤치마크의 한계

OSWorld 2.0, EdgeBench, DeepPlanning 등의 벤치마크에서 파운데이션 모델은 단기 계획은 수행하지만, 장기 계획에서는 여전히 큰 어려움을 보입니다.

핵심 질문

"파운데이션 모델의 장기 계획 능력을
각 학습 단계에서 근본적으로 어떻게 향상시킬 것인가?"

월드 모델 내면화, 원자 기술 구성, 궤적 품질을 통해 어떻게 계획 능력을 얻는가?

사후학습에서의 성형

RL이 장기 계획을 어떻게 성형하며, 적용 경계는 어디인가?

3

사후학습에서의 통합

다중 교사 증류가 장기 계획 능력을 어떻게 통합하는가?

연구 방법: 통제된 멀티턴 환경

기존 물리학 프레임워크가 단일턴 수학 추론에 집중한 것과 달리, 본 연구는 멀티턴 장기 계획을 지원하는 통일된 통제 환경을 제안합니다.

정밀 통제 가능 변수

  • 환경 수준 및 카테고리
  • 작업 길이(계획 수평)
  • 데이터 품질
  • 계획 지식(Planning Knowledge)
  • 계획 패턴(Planning Pattern)

핵심 구성

  • 스킬 그래프 기반 환경 구성
  • 난이도 제어 메커니즘
  • SFT 및 RL 패러다임 모두 호환
  • 체계적 데이터셋 분할

Stage 1: 사전학습 — 데이터 형식

내면화된 월드 모델

Chain-of-Thought를 통한 상태 전이 모델링을 명시적으로 수행하는 모델이 직접 행동 예측보다 장기 계획에서 더 강한 일반화 능력을 보입니다.

스킬 내면화 월드 모델링

각 스킬의 사전·사후 조건을 내면화하여 상태 전이를 추론하는 방식이 장기 수평에서 유효합니다.

핵심 발견: 명시적 월드 모델 구성은 장기 일반화에 필수적이다. 행동을 직접 예측하는 것보다 상태 전이를 추론하는 것이 훨씬 강건하다.

Stage 1: 사전학습 — 분포와 품질

데이터 분포

원자 기술만으로는 구성적 일반화(Compositional Generalization)를 달성하기 어렵습니다.

하지만 사전학습에 소량의 장기 수평 데이터를 추가하면 계획 능력이 상당히 향상됩니다.

데이터 품질

실제 사전학습 데이터에는 최적이 아닌 궤적이 불가피하게 포함됩니다.

장기 의사결정에서 오류가 누적·증폭되므로, 비최적 궤적은 장기 계획 능력을 심각하게 저해합니다.

인터넷 데이터의 불투명성이 장기 계획 분석의 근본적 장벽이 된다.

Stage 2: 상호정보 관점의 분해

사후학습 단계에서 계획 능력을 상호정보(Mutual Information) 관점에서 두 가지로 분해하여 분석합니다.

계획 패턴 (Planning Pattern)

작업 간에 공유되는 일반적 계획 행동을 캡처합니다. 예: 탐색 전략, 백트래킹 패턴, 상태 추적 방식 등

일반적 · 전이 가능

계획 지식 (Planning Knowledge)

작업 특정 절차와 해결책을 포함합니다. 예: 특정 환경의 API 사용법, 도메인 규칙 등

작업 특정 · 독립적

Stage 2: GRPO vs OPD — 계획 패턴

계획 수평과 데이터 품질의 두 축에서 RL 적용 공간을 3개 영역으로 구분합니다.

불필요 영역

사전학습 데이터가 양호하고 단기 계획인 경우 — RL 불필요

효과 영역

RL이 계획 패턴을 효과적으로 성형할 수 있는 영역

미지원 영역

데이터 품질이 너무 낮거나 수평이 너무 긴 경우

방법 효과 영역 범위 기울기 일관성
GRPO 상대적으로 좁음 Sparse credit assignment로 인해 불일치
OPD 더 넓음 이상적 교사 시 더 일관된 업데이트 방향

Stage 2: 계획 지식 증류의 한계

지식 격차 문제

학생 모델이 보지 못한 다경로 절차를 기저 지식이 다른 교사로부터 증류하려 할 때, 새로운 지식이 완전히 확립되기 전에 학생의 기존 월드 모델링을 저해할 수 있습니다.

KL 역학 분석

KL 발산의 역학을 분석한 결과, 교사와 학생 간의 분포 겹침(Overlap)이 증류 성공의 핵심 결정 요인입니다.

겹침이 부족하면 증류가 오히려 기존 능력을 훼손합니다.

경고: 계획 지식 증류는 패턴 증류와 달리, 교사-학생 간 지식 격차가 크면 오히려 해로울 수 있다.

Stage 3: 다중 교사 온폴리시 증류 (MOPD)

MOPD는 여러 교사의 장기 계획 능력을 통합하는 사후학습 방법입니다. 핵심 메커니즘은 교사 간 공유 계획 패턴 분포로의 수렴입니다.

호환 패턴

교사들이 유사한 계획 패턴 공유

환경 간 일반화

부분 공유 패턴

일부 패턴만 교사 간 공유

지속 학습 지원

완전 충돌 패턴

교사 간 계획 패턴이 완전히 모순

치명적 망각 · 간섭

MOPD: 파라미터 역학 분석

수렴 메커니즘

MOPD는 교사들이 공유하는 계획 패턴의 공통 부분으로 파라미터를 수렴시켜 능력을 통합합니다.

이는 단순한 파라미터 평균화가 아닌, 온폴리시 샘플링 기반의 동적 수렴 과정입니다.

충돌 시의 문제

완전히 충돌하는 패턴에서는:

  • 치명적 망각(Catastrophic Forgetting)
  • 환경 간 간섭(Cross-environment Interference)
  • 어느 교사의 능력도 유지 불가

실무적 시사점: MOPD 적용 전 교사 간 패턴 호환성을 반드시 평가해야 한다.

통합: 패턴 호환성이 성공의 열쇠

핵심 결론

  • 명시적 월드 모델 구성이 장기 계획의 일반화에 필수적이다
  • 소량의 장기 데이터라도 구성적 일반화에 크게 기여한다
  • 비최적 궤적은 오류 누적으로 인해 장기 계획을 심각히 저해한다
  • OPD는 낮은 품질·긴 수평에서 GRPO보다 더 넓은 효과 영역을 가진다
  • 계획 지식 증류 시 교사-학생 지식 격차를 주의해야 한다
  • MOPD는 공유 패턴으로 수렴하지만, 충돌 시 치명적 망각 발생
