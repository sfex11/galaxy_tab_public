왜 '가르치는 능력'을 측정하는가

재귀적 인간 자기 개선 (RHSI)

  • 좋은 교육 기술 → 인간 능력 향상
  • 향상된 인간 → 기술을 더 잘 활용
  • 더 나은 활용 → 지속적 추가 학습 성과

GRE 섹션별 AI 튜터(LLM)

핵심 질문: LLM 튜터링이 1시간의 전문가 인간 튜터링과 동등한 학습 향상을 만들어내는가?

실험 설계: 학습 향상 측정

1
사전 검사
GRE Quant/Verbal 27문항 + 정답 복습 5분
2
튜터링 배정
AI 튜터 / 인간 튜터 / 무튜터링 대조군
3
사후 검사
동일 길이·개념의 검사로 학습 향상 측정

사전·사후 검사 형태를 무작위 교차하여 난이도 차이가 학습 효과로 오인되지 않도록 설계

최소한의 소프트웨어 스캐폴딩 + 2개의 저안내 프롬프트 → 프롬프트 기술이 아닌 LLM의 교육 능력을 순수하게 측정

핵심 결과 1

AI 튜터링 ≈ 인간 튜터링, 통계적으로 동등

p = .015

풀링된 AI 튜터링과 전문가 인간 튜터링의 학습 향상이 동등함이 입증됨

동등성 경계 ±0.25 표준편차 내 90% 신뢰구간 확인

더 엄격한 ±0.20 SD 경계에서도 동등 (p = .023)

핵심 결과 2

도메인별로 보면? AI가 앞선 영역도 존재

5/7

7개 GRE 도메인 중 5개에서 최고 성적 AI 튜터가 인간 튜터의 평균을 능가

경량·오픈웨이트 모델을 포함한 다양한 LLM에서 인간 수준 성능 달성

Verbal 전체 섹션 평균은 여전히 인간 튜터가 최고 — 그러나 AI–인간 동등성은 LLM 능력의 하한선(lower bound)일 가능성이 높다. 모델이 개선될수록 학습 효과와 비용 효율은 더 향상될 전망.

AI 교육 능력의 3가지 평가

수업 계획

LLM 생성 수업 계획의 전문가 평가

연습 문제 출제

LLM 생성 문제의 품질 루브릭 비교

대화형 교육법

실제 튜터링 대화의 pedagogy 평가

2차 연구: 전문 GRE 튜터들이 LLM 생성 교육 자료를 2,028회의 쌍별(pairwise) 루브릭 평가로 비교 → AI 튜터 리더보드 구축

5가지 축으로 AI 튜터를 명확히 구분

  • ① 수업 계획 — 전문가 루브릭 평가
  • ② 연습 문제 출제 — 쌍별 품질 비교
  • ③ 대화형 교육법 — 실세션 분석
  • ④ 비용 — 학습 향상 1%p당 비용
  • ⑤ 참여도 — 대화량·응답 속도

기존 벤치마크는 모델 능력(model capabilities)에 집중 → StudentBench는 실제 학생의 실제 시험에서의 학습 성과(learning gains)라는 새로운 평가 패러다임 제시
