GUI Web Agent Environment

WebHarbor

Docking Real Websites for Evolving GUI Agent Environments

실제 웹사이트를 정밀( dock )하여 만드는, 진화하는 GUI 에이전트 환경

arXiv: 2611.03634v1

배경: GUI 웹 에이전트는 환경이 필요하다

  • 웹 GUI 에이전트는 실제와 유사하고 인터랙티브한 환경 속에서 평가·학습되어야 함
  • 에이전트는 클릭, 입력, 탐색 등 실제 브라우저 조작을 통해 작업을 수행
  • 평가와 훈련 전 과정에서 환경이 안정적(stable)으로 유지되는 것이 핵심 요건

현실성

실제 웹의 복잡한 UI와 동작을 반영

상호작용성

에이전트의 행동에 실제로 반응

안정성

시간이 지나도 결과가 재현 가능

문제 1: 라이브 웹사이트 평가의 한계

변화하는 콘텐츠

뉴스, 가격, 레이아웃이 수시로 바뀌어 동일한 작업의 재현이 불가능하고 평가 결과가 일관되지 않음

접근 제약

봇 차단, 로그인 요구, 지역 제한 등으로 에이전트가 사이트에 접근조차 어려움

인증 워크플로우 부재

로그인 후 이용 가능한 인증 기반 작업(계정 관리, 결제 등)을 테스트하기 어려움

안전·윤리 문제

실제 서비스에 에이전트를 직접 실행하면 부작용(실제 주문, 데이터 변경)이 발생할 수 있음

문제 2: 기존 합성 환경의 한계

기존 학습용 합성 환경은 안정성은 있지만 현실성이 크게 떨어짐

  • 소수의 수작업 제작 사이트만 포함 → 커버리지 제한
  • 실제 웹의 다양한 디자인·기능·예외 상황이 반영되지 않음 → 도메인 갭(domain gap)
  • 환경 구축에 막대한 수작업 비용 → 확장성 부족
  • 실제 사이트처럼 진화하지 않아 학습-실전 불일치 지속

"현실성은 포기하고 안정성을 얻을 것인가, 안정성은 포기하고 현실성을 얻을 것인가?"

핵심 아이디어: 실제 웹사이트의 정박(Docking)

실제 웹사이트를 그대로 캡처하여 로컬 환경에 "정박(dock)"시켜,
현실성과 안정성을 동시에 확보

스냅샷 기반 재현

실제 사이트의 프런트엔드와 상호작용 동작을 캡처해 로컬에서 완전히 재현

에이전트 학습·평가 양립

동일한 환경에서 안정적인 평가와 대규모 학습 데이터 생성이 모두 가능

WebHarbor 시스템 파이프라인

1
탐색·캡처
실제 웹사이트를 자동 크롤링하고 사용자 상호작용 흐름을 녹화
2
상태 재구성
백엔드 동작과 상태 전이를 모사하여 로컬 미러로 재구성
3
환경 정박
재현된 사이트를 안정적인 에이전트 환경으로 호스팅
4
활용
평가 벤치마크 구성 및 학습용 궤적 데이터 대량 생성

사람의 개입을 최소화하면서 다양한 실제 사이트를 환경으로 변환하는 것이 핵심

기술 요소 1: 웹사이트 캡처와 재현

  • 자동 크롤링으로 페이지, 자산, 동적 콘텐츠를 포괄적으로 수집
  • 네트워크 요청 가로채기를 통해 프런트엔드가 기대하는 응답을 기록
  • 기록된 응답을 로컬 서버가 재생(replay)하여 동일한 UI 동작 재현
  • 클라이언트 사이드 스크립트와 상태 전이까지 포함해 인터랙티브성 보장

정적 스냅샷의 한계 극복

단순 HTML 저장이 아니라 동작하는 웹앱 수준으로 재현

상태 리셋

에이전트가 환경을 변경해도 초기 상태로 복원 가능 → 반복 실험 가능

기술 요소 2: 인증 워크플로우 지원

기존 벤치마크가 다루기 어려웠던 로그인 기반 작업을 환경 안에서 안전하게 재현

01

가상 계정 생성

실제 자격 증명 없이 로컬 환경 내 가상의 계정·프로필·데이터 구성

02

로그인 상태 캡처

인증 흐름과 세션 동작을 함께 기록해 로그인 이후 페이지까지 재현

03

상태 변경 시뮬레이션

장바구니 추가, 설정 변경 등 쓰기(write) 작업의 결과를 로컬에서 반영

실제 서비스에 전혀 영향을 주지 않으면서도, 인증이 필요한 현실적인 고난도 작업을 평가·학습에 활용 가능

기술 요소 3: 환경의 진화(Evolving)

정적 환경과 달리, WebHarbor는 실제 웹의 변화를 지속적으로 흡수

  • 원본 사이트가 업데이트되면 재캡처를 통해 환경을 최신 상태로 갱신
  • 시점별 환경 버전을 관리하여 장기적인 평가 일관성과 환경 다양성을 동시에 확보
  • 새로운 사이트·새로운 기능을 환경에 추가하는 비용이 낮아 벤치마크 확장이 용이

버전 고정 평가

특정 시점의 환경을 고정해 공정한 비교 평가 수행

지속적 갱신 학습

최신 UI 트렌드를 반영한 환경으로 에이전트를 지속 학습

활용: 평가와 학습의 통합 환경

안정적 평가

  • 시간이 지나도 결과가 변하지 않는 재현 가능한 벤치마크
  • 인증·쓰기 작업을 포함한 고난도 작업 커버리지
  • 네트워크·봇 차단 이슈로부터 완전히 자유로운 실행

대규모 학습

  • 환경 내에서 성공/실패 판정이 가능한 자동 보상 제공
  • 에이전트 궤적(trajectory)을 무제한 반복 수집
  • 강화학습·SFT 등 다양한 학습 방식에 바로 활용

접근 방식 비교

기준 라이브 웹사이트 기존 합성 환경 WebHarbor
현실성 높음 낮음 높음 (실제 사이트 기반)
안정성·재현성 낮음 높음 높음 (스냅샷 고정)
인증 작업 커버리지 제한적 제한적 지원 (가상 계정)
구축 비용 낮음 높음 (수작업) 낮음 (자동 캡처)
학습 활용 부작용 위험 가능 가능 (안전하게)

기대 효과와 의의

신뢰할 수 있는 평가

환경 변이로 인한 평가 오류를 제거하고 공정한 모델 비교를 가능하게 함

확장 가능한 학습

현실성 있는 환경을 저비용으로 대량 구축해 GUI 에이전트 학습 데이터 병목 해소

실전으로의 연결

학습 환경과 실제 웹의 간극을 줄여 배포 환경에서의 성능 향상 기대

"실제 웹의 현실성을 그대로 담되(抱), 실험실의 안정성을 갖춘 환경 — 그것이 WebHarbor"

결론

  • WebHarbor는 실제 웹사이트를 캡처·재현하여 현실성과 안정성을 모두 갖춘 GUI 에이전트 환경을 제공
  • 인증 워크플로우와 쓰기 작업까지 안전하게 평가·학습 가능
  • 환경의 지속적인 진화로 벤치마크의 노후화 문제를 해결
  • 평가와 학습을 하나의 통합 환경에서 수행하는 새로운 패러다임 제시
