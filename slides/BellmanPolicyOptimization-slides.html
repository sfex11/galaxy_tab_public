RLVR Critic-Free LLM Reasoning

Bellman Policy Optimization

PMD에서 유도된 Critic-free 정책 최적화로 LLM 추론 능력 향상

Bellman 방정식을 이용해 Policy Mirror Descent(PMD)를 궤적(trajectory) 수준 목적함수로 재구성하여, 중간 상태의 가치 추정 없이 터미널 보상만으로 학습하는 새로운 RLVR 알고리즘

Zhuoqing Song · Haotian Xu · Xikun Zhang · Lidong Bing  |  Apodex US, Inc. · Princeton University

배경: RLVR과 정책 최적화

RLVR이란?

과제별 검증기(verifier)가 생성된 응답에 결과 수준(outcome-level) 보상을 부여하여, LLM의 추론 능력을 향상시키는 강화학습 접근법

정책 최적화의 중요성

정책 최적화 방법의 선택이 추론 성능과 학습 안정성 모두에 상당한 영향을 미침

GRPO와 그 변형들은 value model 없이(critic-free) 대규모 추론 모델 학습을 지원하는 RLVR의 사실상 표준으로 널리 사용됨

기존 방법의 한계

GRPO의 방식

프롬프트별 그룹 샘플링으로 정규화된 advantage를 계산하고, 응답 내 모든 토큰이 동일한 advantage를 공유한 채 PPO-style 클리핑에 사용

Value Model의 비용

PMD를 언어 생성에 직접 적용하려면 중간 상태의 가치 추정이 필요 → 별도 value model 학습으로 메모리·계산 비용 증가

부정확한 가치 추정

추론 과제에서는 학습된 value 추정치가 부정확한 경우가 많아 신뢰하기 어려움

목표: value model을 학습하지 않고도 동일한 PMD 정책 업데이트를 재현하는 재구성

핵심 아이디어: PMD → BPO

터미널 보상을 갖는 자기회귀 생성에서 Bellman 방정식으로 PMD를 궤적 수준 목적함수로 재구성

문제 설정: RLVR as Episodic MDP

상태와 전이

  • 초기 상태 s1 = 프롬프트 x
  • 상태 st = (x, y<t): 프롬프트 + 생성된 접두어
  • 결정론적 전이: 토큰 yt를 붙여 다음 상태로 이동

보상과 목적

  • 결정론적 검증기 R이 터미널 보상 할당
  • 목적함수: J(π) = Ex∼D, y∼Pπ[R(x, y)]
  • EOS 생성 또는 최대 길이 도달 시 응답 종료
실제 RLVR 상황: 응답은 rollout 정책 μ에서 생성되고, 최적화는 현재 정책 π에서 수행 → 두 정책 간 불일치(mismatch)가 존재

Bellman 방정식과 텔레스코핑

  • 터미널 보상 하에서 각 토큰 advantage는 연속된 두 상태의 value 함수 차이로 표현됨
  • 이 차이들은 응답을 따라 telescoping → 터미널 보상과 초기 value만 남음
  • 초기 value = 프롬프트에 대한 기대 보상 → 샘플링된 응답들의 평균 보상으로 추정 가능

항등식

토큰 advantage들의 합 = R(x, y) − V(s1)

제거된 것

중간 상태에서의 value 및 advantage 추정이 완전히 불필요해짐

이론적 보장: PMD와의 동치성

동일한 유일 최적해

재구성된 궤적 수준 목적함수와 원래 PMD 목적함수는 rollout 정책 하에서 도달 가능한 상태들에서 동일한 유일 최적해를 가짐을 증명

  • PMD의 최적성 조건과 Bellman 항등식을 결합하여 궤적 수준 목적함수를 유도
  • 재구성의 충분조건과 필요조건을 모두 증명 — 근사가 없는 한 PMD 업데이트가 정확히 보존됨
  • 이론적으로 손실 없는 critic-free 전환임을 보장

실용적 BPO Loss 유도

1
초기 value 추정 — 각 프롬프트에 대해 샘플링된 응답들의 평균 보상 사용 (그룹 기반)
2
기울기 근사 — 궤적 수준 목적함수의 기울기를 근사
3
Binary KL 근사 — 전체 KL 발산을 이진(binary) 근사로 대체
4
가중치 스무딩 — 수치 안정성을 위해 가중치에 가산 스무딩(additive smoothing) 적용
핵심: mismatch-correction weight — rollout과 현재 토큰 확률로 결정되는, 보완 토큰 확률(complementary token probabilities)의 스무딩된 비율이 GRPO의 importance-sampling ratio를 대체

결론

  • BPO는 Bellman 방정식을 통해 PMD를 중간 상태 value 추정 없이 궤적 수준으로 재구성
  • mismatch-correction weight가 GRPO의 importance ratio를 대체하는 실용적 critic-free loss
  • 수학 추론 벤치마크에서 기존 방법 대비 강력한 성능 향상 입증
