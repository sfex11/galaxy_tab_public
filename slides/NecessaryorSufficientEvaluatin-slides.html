Necessary or Sufficient?

행동 증거로 평가하는 LLM 설명의 신뢰성

Evaluating LLM Explanations With Behavioural Evidence

Urja Pawar · Rajitha Ramanayake · Nabeel Kemal · Ashwin Kandath · Owen O'Neill · Guillaume Bourgeon · Houssem Chatbri (BNY)

arXiv:2609.05385v1 [cs.AI]

배경: LLM 설명은 운영자의 신뢰를 전제로 한다

에이전트 워크플로우 속 LLM

추천 후보 선정, 요청 판단, 다음 행동 결정 등 행동 관련 판단과 함께 설명을 출력

운영자의 설명 활용

시스템 모니터링, 오류 진단, 출력 에스컬레이션 판단에 명시된 요인들을 사용

이러한 활용은 "설명이 모델의 관찰 가능한 결정 행동과 일치한다"는 암묵적 가정에 기반한다. 과연 그럴까?

두 가지 해석: 필수성 vs 충분성

필수성 (Necessity)

해당 요인을 바꾸면 출력이 바뀌는가?

개입 시 원래 출력이 변경되는 빈도로 점수화

충분성 (Sufficiency)

해당 요인만 남기고 다른 정보를 제거해도 출력이 유지되는가?

개입 시 원래 출력이 보존되는 빈도로 점수화

모델이 스스로 인용한 상위 3개 요인(top-3)이 두 기준에서 실제 가장 영향력 있는 요인을 식별하고 순위를 매기는가를 검증

연구 질문

Q1
모델이 진술한 순위는 인용된 피처의 필수성/충분성 점수와 일치하는가?
Q2
인용되지 않은 피처가 가장 낮은 인용 피처보다 높은 점수를 받는 경우가 얼마나 자주 발생하는가?

왜 중요한가? 에이전트 워크플로우에서 어느 하나라도 불일치하면, 모니터링이나 에스컬레이션이 입력의 잘못된 부분으로 향할 수 있음

방법론: 개입 기반 블랙박스 평가 프레임워크

1
출력 + Top-3 인용
모델이 고정된 피처 이름으로 상위 3개 요인을 자기 보고
2
필수성 개입
피처를 변경, 나머지 유지 → 출력 변경 빈도 측정
3
충분성 개입
피처를 유지, 나머지 제거 → 출력 보존 빈도 측정
4
비교 평가
인용 순위 vs 점수 순위 비교, 미인용 피처도 동일 개입 적용

관찰 가능한 입력-출력 행동만을 테스트하며, 모델의 내부 추론 회복을 주장하지 않음

두 가지 평가 대상 사용 사례

어드바이저 추천

  • 합성 고객 프로필 100개 (18개 피처)
  • 자산, 소득, 목표, 인구통계 등
  • 고정된 어드바이저 풀 13명
  • 최적 매칭 선택 + 영향 큰 고객 피처 top-3 인용

프롬프트 위험 모니터링

  • 합성 프롬프트 100개 (저위험 요청 + 위험 세그먼트 결합)
  • 8개 위험 범주: 개인정보, 불법 조언, 탈옥 시도 등
  • 위험 점수 1(양호)~5(위험) 부여
  • 판단에 영향 큰 위험 피처 top-3 인용

실험 설계: 모델과 통제 변수

평가 대상 모델

Claude · GPT · Gemini 계열 총 8개 모델

프롬프트 형식 선택

13개 프롬프트 형식 비교 → 고정 피처명 형식이 가장 재현성 높음

개입 통제

대조 치환 vs 빈 값 제거 · 유사 값 치환으로 우연한 일치 배제 · 프롬프트 선택 통제

높은 재현성은 설명 유도 형식에 대한 정당화일 뿐, 인용 피처가 실제 행동과 일치한다는 증거는 아님

결과 1: 인용 순위는 부분적 신호만 담고 있다

유용하지만 모델과 사용 사례에 따라 달라지는 부분적·맥락 의존적 신호

결과 2: 미인용 피처가 인용 피처를 넘어서는 빈도

인용되지 않은 피처가 최하위 인용 피처보다 높은 점수를 받은 비율

사용 사례필수성 기준충분성 기준
어드바이저 추천 57.6% 58.1%
프롬프트 모니터링 25.8% 8.9%

어드바이저 추천에서는 약 6할의 응답에서 더 영향력 있는 미인용 피처가 존재 → top-3 인용이 최강 피처 셋을 신뢰롭게 식별하지 못함

추가 발견

GPT-5.4의 추론 노력을 높이면 충분성 기준 누락(omission)이 감소 — 추론 자원이 설명-행동 일치에 긍정적
탐색적 전체 순위 분석에서 top-3 경계 바깥 순위는 불안정 — 모델은 상위 3개 이후의 순위를 일관되게 유지하지 못함
반복 질의에서 동일한 순위를 일관되게 반환하더라도, 실제 출력은 다른 피처에 더 강하게 의존할 수 있음 — 일관성 ≠ 정확성

기여와 시사점

  • LLM 의사결정 지점의 설명이 해석된 필수성/충분성을 식별·순위화하는지 평가하는 개입 기반 프레임워크 제안
  • Claude·GPT·Gemini 계열 8개 모델, 2개 사용 사례에 적용 — 인용 피처는 유용하지만 일관성 없는 정보
  • 에이전트 모니터링·감독에 사용되는 설명을 위한 외부 신뢰성 검증 도구로 활용 가능
  • 설득력 있거나 반복되는 설명 자체는 올바른 피처 선택의 증거가 아님을 실증

한계 개별 LLM 결정으로 범위가 한정되며, 다단계 에이전트 행동 전반에 대한 일반화는 별도 검토 필요

결론

인용된 top-3은 유용한 정보를 담지만, 필수성·충분성 기준에서 가장 영향력 강한 세 피처를 신뢰롭게 식별하지 못한다
