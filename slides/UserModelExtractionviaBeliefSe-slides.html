User Model Extraction via
Belief Self-Distillation

신념 자기 증류를 통한 LLM 사용자 모델 추출

  Ali Holmov · Yiran Huang · Kirill Bykov · Zeynep Akata

Technical University of Munich · Helmholtz Zentrum München

  arxiv.org/abs/2609.31603

LLM은 "누가 묻는가"를 암묵적으로 추론한다

LLM은 대화 맥락에서 사용자의 속성을 추론하고, 이 추론에 따라 행동을 조정합니다.

개인화
추론된 사용자 특성에 따라 응답의 스타일과 내용이 달라짐
준수성
사용자 신원에 대한 추론이 요청 수용 여부와 방식에 영향
안전 행동
지각된 사용자 페르소나가 유해 정보 공개 여부를 좌우
문제: 이러한 효과를 이끄는 내부 사용자 모델은 여전히 대체로 불투명하며, 검사하거나 인과적으로 조작하기 어렵습니다.

핵심 질문

LLM은 사용자에 대해 무엇을 믿는가?
그리고 그 믿음을 분리하고 인과적으로 수정할 수 있는가?

핵심 통찰: 사용자 신념에는 외부 정답(ground truth)이 존재하지 않습니다.

잘못된 초점

사용자가 실제로 누구인가?

올바른 대상

모델이 사용자가 누구라고 믿는가?

공통 한계: 읽기와 개입이 별도의 단계로 처리되며, 통제된 속성이나 합성적 단서에서 출발 → 자연스러운 대화에서 형성된 신념과는 거리가 있음

Belief Self-Distillation (BSD)

선형 프로빙과 인과 프로빙을 잇는 통합 읽기-쓰기(read–write) 프레임워크

읽기 (Read)

컴팩트한 사용자 벡터 vuser를 디코딩하여 모델이 추론한 사용자 표현을 검사

쓰기 (Write)

편집한 벡터를 모델에 재주입하여 신념의 인과적 역할을 직접 검증

  • 프로즌(frozen) LLM이 자기 자신을 교사로 사용 — 외부 주석 불필요
  • 자연스러운 대화에서 신념을 증류하여 저차원 사용자 상태로 압축
  • 정보가 있는지 확인을 넘어, 직접 개입 가능한 상태를 분리

방법 ① 신념 감독 (Belief Supervision)

대화 c가 주어지면, 프로즌 모델에 객관식(MCQ) 질문을 던져 속성 a에 대한 확률 분포 ba(c)를 획득

왜 객관식인가?
속성 값들에 대한 잘 정의된 분포를 제공. 개방형 응답은 거부·회피하거나 값의 범위를 벗어나 깨끗한 readout이 어려움
순서 편향 완화
여러 프루브 템플릿 사용 + 답안 선택지를 순환적으로 치환 후 평균 → MCQ 옵션 순서 민감성 감소
ba(c)는 모델의 내부적 사용자 관점을 나타내며, 사용자의 실제 속성과 다를 수 있음 → 신념 상태 학습의 감독 신호로만 사용

방법 ② 자기 증류 구조

동일한 언어모델에서 teacher와 student를 초기화하고 둘 모두 파라미터를 프리즈 — 정보 비대칭 구조

Teacher
대화만 입력으로 받아 사용자 신념을 형성
→ 은닉 상태 hteacher
Student
속성 프루브만 입력으로 받음
→ 저랭크 프로젝터 BA가 신념을 전달해야 함
  • 읽기 사상 A: hteacher를 컴팩트한 사용자 벡터 vuser로 압축
  • 쓰기 사상 B: vuser를 student의 은닉 상태에 주입
  • A와 B만 학습 — teacher와 student의 답변 분포 간 KL 발산 최소화

BSD 학습 과정 한눈에 보기

1
대화 관찰
프로즌 teacher가 자연 대화를 입력
2
신념 유도
MCQ로 신념 분포 ba(c) 획득
3
압축 (A)
hteacher → vuser 변환
4
주입 (B)
vuser를 student에 재주입
5
KL 정렬
teacher–student 답변 분포 정합
핵심 메커니즘: 모델은 개입 그 자체를 통해 자신의 신념을 압축하는 법을 학습 — 압축 벡터가 신념을 디코딩하고, 재주입 시 신념을 인과적으로 조향

실험 ① 읽기와 쓰기 — 모두 가능

읽기: 선형 프로빙

여러 모델 계열에서 BSD 상태가 모델의 사용자 신념을 충실히 복원

쓰기: 활성화 스티어링

동일 조건의 은닉 상태 스티어링보다 실질적으로 강한 개입 달성

  • 모델의 사용자 신념은 읽을 수 있고 다시 쓸 수 있는 내부 상태
  • BDS는 어디에 쓸지(where to write)까지 학습 — 단순 프로빙과의 결정적 차이
  • vuser를 편집해 주입하면 모델의 응답이 실제로 변화

실험 ② 암시적 vs 명시적 사용자 표현

명시적 단서
사용자가 직접 진술한 속성("나는 ~이다")
암시적 추론
자연스러운 대화 흐름에서 수동적으로 형성된 신념
명시적 단서만으로는 자연스럽게 추론된 사용자 표현을 복원할 수 없다.

시사점: 신념을 연구하려면 자연스러운 대화가 필수 — BSD는 합성 데이터가 아닌 실제 대화에서 신념을 증류

실험 ③ 사용자 의도가 거부(Refusal)를 조절한다

거부 예측
사용자 신념 상태만으로 모델의 거부 여부를 예측 가능
거부 조절
요청을 고정한 채 추론된 사용자 의도 신념만 변경 → 거부 행동 변화
거부는 무엇이 요청되었는가뿐만 아니라,
모델이 누구와 상호작용하고 있다고 믿는가에 달려 있다.

잠재 사용자 신념은 안전 관련(safety-relevant) — 안전 결정이 사용자 모델에 조건화됨

실험 ④ 사용자 모델의 공유 기하학

기본 사용자 (Default User)
각 모델은 대화 전에도 가지는 기본적인 사용자 표현 상태를 보유
신념 전이 (Belief Transfer)
한 모델에서 추출한 vuser가 다른 모델에도 주입 가능
독립적으로 학습된 LLM들이 사용자를 표현하는 방식에서 공유 기하학(shared geometry)으로 수렴
  • 사용자 모델은 개별 시스템의 우연한 특징이 아님
  • 모델 간 일반화될 수 있는 구조화된 인과적 표현

결론 및 시사점

  • BSD: 자연 대화에서 읽기·쓰기에 모두 최적화된 컴팩트한 사용자 상태를 학습하는 통합 프레임워크
  • 안전성: 추론된 사용자 의도가 요청과 무관하게 거부를 인과적으로 조절
  • 일반성: 독립 학습된 LLM 간 공유되는 사용자 모델 기하학 발견
  • 시사점: 정렬(alignment), 관측 가능성(observability), 이중 사용(dual use) 문제에 직결
