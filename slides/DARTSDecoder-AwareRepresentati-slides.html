모델 병합의 배경과 한계

현실적 문제

  • 과제별 파인튜닝 → 전문 모델 증가
  • 독립 배포 비용 기하급수적 증가
  • 다과제 통합의 필요성 대두

모델 병합의 약속

  • 추가 학습 데이터 없이 가중치 결합
  • Task Arithmetic, TIES, DARE 등
  • 오픈소스 LLM 생태계의 표준 도구

그러나 병합 모델은 개별 파인튜닝 모델 대비 성능 저하를 겪으며, 그 원인과 해법은 미해결 과제였다.

표현 편향(Representation Bias)이란?

정의

병합 모델의 은닉 상태와 각 개별 소스 모델의 은닉 상태 간의 체계적 차이

인코더 모델에서의 선행 연구

Yang et al. (2024a) — ViT 기반 비전 모델에서 표현 편향 분석

  • 양방향 어텐션 → 편향이 위치에 무관
  • 모든 패치가 분류에 유사하게 기여
  • 위치 무관 L1 서지리로 효과적 교정

디코더 모델에서의 문제

자기회귀 트랜스포머에서는 인코더와 근본적으로 다름

  • 인과적 어텐션 마스크 → 편향 누적
  • 토큰 위치별 중요도 불균등
  • 기존 서지리 프레임워크 부적합

과제 1: 위치 의존적 편향 누적

인과적 어텐션 마스크 하에서 토큰 t는 토큰 0, 1, ..., t−1만 참조할 수 있다.

  • 초기 위치의 편향이 어텐션을 통해 전파 및 누적
  • 후속 토큰은 자체 편향 + 모든 선행 편향의 합을 갖음
  • 후반부 위치에서 편향이 2~3배 증가

위치 무관 보정 모듈은 이 패턴을 포착할 수 없어, 후반부는 과소 보정하고 전반부는 과대 보정하는 딜레마에 빠짐

과제 2: 위치별 중요도 비균등

자기회귀 생성에서 모든 토큰 위치가 동등하게 중요한 것이 아니다.

저엔트로피 위치

닫는 괄호, 결정적 구문, 빈번한 구절 등

모델이 단일 토큰에 높은 확률을 할당 → 작은 은닉 상태 오류가 결과에 무영향

고엔트로피 위치

여러 후속 토큰이 plausible한 결정 임계점

작은 오류가 argmax 예측을 뒤집고 이후 토큰들로 오류 연쇄

표준 L₁ 손실은 모든 위치를 동등하게 취급하여, 생성 품질에 영향이 없는 위치에 서지리 모듈의 제한된 보정 능력을 낭비한다.

DARTS: 제안 방법 개요

Decoder-Aware Representation Tuning via Surgery — 자기회귀 설정에 표현 서지리를 적응시키는 두 가지 상보적 혁신

엔트로피 가중 L₁ 손실 (EWL1)

핵심 아이디어

표준 L₁ 손실에 타겟 모델의 예측 엔트로피를 가중치로 곱하여, 결정에 임계적인 위치에서 보정을 강화

  • 저엔트로피 위치 → 가중치 ↓ (보정 우선순위 낮음)
  • 고엔트로피 위치 → 가중치 ↑ (보정 집중)
  • 제한된 파라미터 예산을 효율적으로 활용

동작 원리

각 위치에서 타겟 모델의 예측 분포 계산
위치별 엔트로피 H(t) 측정
H(t) × |bias(t)| 로 가중 L₁ 페널티 산출
서지리 모듈이 고엔트로피 위치에 학습 집중

위치 보정 모듈 (Position Correction)

설계 동기

저랭크 내용 보정만으로는 위치 의존적 편향 패턴을 포착 불가

구조

  • 토큰 위치별 독립적 가산 편향 테이블
  • 위치 t마다 고유한 보정 벡터 학습
  • 네트워크 과파라미터화 없이 구조화된 패턴 포착

절제 연구 (Ablation Study)

손실 함수 절제

  • 순수 L₁ → 기준선 성능
  • 엔트로피 가중 L₁ → 일관된 향상
  • 가중치 변형들 비교 분석 (부록 E)

엔트로피 가중이 L₁ 편향 감소와 과제 성능 모두에서 최적

모듈 구성 절제

  • 저랭크 보정만 → 불충분
  • 저랭크 + 위치 보정 → 상호 보완적 효과
  • 학습률 민감도 분석 (안정적 범위 존재)

결론

1
디코더 모델의 표현 편향을 최초로 분석하고, 인코더에 없는 두 가지 과제를 실증적으로 입증
2
엔트로피 가중 L₁ 손실과 위치 보정 모듈을 제안하여 디코더 특화 해법 제시
3
코드, 수학, 지시 수행 3개 도메인에서 인과적 표현 편향 감소 및 다과제 성능 유의미 향상 달성

DARTS는 단 0.1%의 추가 파라미터로 모델 병합의 성능 격차를 효과적으로 좁히며, 디코더 기반 LLM 병합 생태계에 실용적 기여를 제공한다.
