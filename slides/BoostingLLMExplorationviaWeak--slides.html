RLVR: 검증 가능한 보상을 통한 강화학습

RLVR는 외부 검증자(verifier)로부터 피드백을 받아 LLM의 추론 능력을 향상시키는 사후 학습 방법입니다. 추가 인간 주석 없이 시퀀스 수준 최적화가 가능합니다.

  • DeepSeek-R1, GPT-5, Gemini 등에 채택
  • 수학 추론 벤치마크에서 높은 정확도 달성
  • 인간 피드백 없이 자동으로 학습 가능

문제 정의: 엔트로피 붕괴

RLVR 학습 과정에서 정책 엔트로피가 급격히 감소하는 현상이 관찰됩니다. 모델이 소수의 추론 경로에 과신념(over-confidence)을 갖게 되어 다양성이 상실됩니다.

"LLM은 강화학습 과정에서 엔트로피를 성능과 교환하는 경향이 있다." — Cui et al. (2025)

pass@k 지표에서 k가 충분히 크면, 기반 모델이 RLVR 학습 모델을 역전하는 현상이 발생합니다.

엔트로피 붕괴의 결과
  • 추론 커버리지 축소
  • pass@k (큰 k) 성능 저하
  • 대안 경로 탐색 기회 상실
  • 특정 쿼리에 확률 질량 붕괴
토큰 레벨 엔트로피가 0에 가까워지면 불확실성과 탐색 능력이 함께 감소합니다.

기존 접근법과 한계

엔트로피 붕괴를 완화하기 위한 기존 방법들은 모두 목표 모델의 내부 탐색 공간 내에서만 동작합니다.

방법 접근 방식 한계
엔트로피 정규화 학습 과정에 엔트로피 항 추가 내부 분포 내에서만 탐색
그래디언트 보정 선택적 토큰의 정책 그래디언트 조절 복잡한 조정 메커니즘 필요
보상 설계 탐색을 장려하는 보상/이점 함수 수정 정교한 보상 엔지니어링 요구
본 연구 크로스 모델 비파라메트릭 섭동 직교적 관점, 단순하고 효과적

동기: 크로스 모델 접두사가 정책 불확실성을 증가시키는 메커니즘

사전 학습 데이터, 모델 아키텍처, 최적화 역학의 차이로 인해 동일한 문제에 대해 서로 다른 모델은 substantially 다른 추론 궤적을 생성합니다.

핵심 가설: 목표 모델이 익숙하지 않은 부분 궤적에서 이어서 생성하도록 강제하면, 기존 RLVR에서 과신념으로 인해 낮은 확률이 할당되었을 대안 경로를 탐색하게 됩니다.

지식 증류와의 차이: 강한 모델이 약한 모델을 가르치는 것이 아니라, 약한 모델이 강한 모델의 탐색을 돕는 구조입니다.

분포 차이 → 불확실성 증가 → 탐색 확장

부분 추론 궤적(접두사) 생성
분포 불일치
목표 모델에게 익숙하지 않은 패턴
정책 불확실성 증가
과신념 파괴, 다양한 경로 탐색

방법론: 접두사 안내 RLVR 프레임워크

세 가지 핵심 구성요소로 구성된 단순하면서도 효과적인 프레임워크를 제안합니다.

1

접두사-완성 RLVR

약한 보조 모델이 부분 추론 궤적(접두사)을 생성하고, 목표 모델이 이를 이어받아 완성합니다. 표준 GRPO 목적 함수를 접두사 조건부 생성에 적용합니다.

2

엔트로피 기반 접두사 절단

목표 모델의 엔트로피를 모니터링하여, 불확실성이 임계값 이하로 떨어지는 지점에서 접두사를 절단합니다. 최적의 탐색 자극 지점을 동적으로 결정합니다.

3

혼합 학습

접두사 안내 샘플과 일반(접두사 없는) 샘플을 혼합하여 학습합니다. 원래의 학습 신호를 유지하면서 탐색 다양성을 추가합니다.

접두사-완성 RLVR 상세

보조 모델 πaux가 프롬프트 q에 대해 부분 궤적 p를 생성합니다. 목표 모델 πθ는 p를 접두사로 받아 나머지를 완성합니다.

학습 과정
1
접두사 생성
πaux(p|q)
2
완성 생성
πθ(c|q,p)
3
보상 평가
R(q, p⊕c)
4
GRPO 업데이트
접두사 이후 토큰만

GRPO 업데이트 시 접두사 토큰은 고정하고, 완성 부분의 토큰에 대해서만 정책 그래디언트를 계산합니다.

  • 보조 모델은 더 작고 약한 모델 사용
  • 접두사가 최적 해결책으로 이어지지 않아도 무방
  • 비파라메트릭 방해 신호로서 동작
  • 추가 SFT나 복잡한 프롬프팅 불필요
핵심: 접두사의 품질이 아니라 분포적 불일치 자체가 탐색을 촉진하는 메커니즘

엔트로피 기반 접두사 절단 & 혼합 학습

엔트로피 기반 접두사 절단

모든 접두사가 동일하게 효과적인 것이 아닙니다. 목표 모델이 이미 낮은 불확실성을 보이는 구간에서는 접두사가 탐색 효과를 내지 못합니다.

  • 스텝 레벨 엔트로피 H̄(sj) 계산
  • 엔트로피가 임계값 τ 미만인 지점에서 절단
  • 높은 불확실성 구간만 접두사로 활용
목표: 목표 모델이 "당황하는" 지점에서만 외부 접두사를 주입하여 효율적으로 탐색 자극

혼합 학습 전략

접두사 안내 샘플만으로 학습하면 원래의 학습 신호가 희석될 수 있습니다. 비율 α로 두 종류의 샘플을 혼합합니다.

α
접두사 안내 샘플
πaux 접두사 + πθ 완성
1−α
일반 샘플
πθ가 처음부터 전체 생성
원래 RLVR의 이점을 유지하면서 탐색 다양성을 추가하는 균형 있는 접근

주요 실험 결과

다양한 벤치마크에서 제안 방법이 vanilla RLVR을 일관되게 초과하는 성능을 보입니다.

벤치마크 Vanilla GRPO + 접두사 안내 향상
MATH-500 (pass@1) 기준선 지속적 향상 ↑
AIME 2024 (pass@1) 기준선 유의미한 향상 ↑
pass@k (k 증가 시) 급격한 포화 지속적 성능 상승 ↑↑
정책 엔트로피 급감 안정적 유지 북괴 완화

핵심 발견: k가 커질수록 성능 격차가 더욱 벌어지며, 이는 추론 커버리지가 실제로 확장되었음을 시사합니다.

분석: 학습 역학

엔트로피 유지 효과

Vanilla GRPO는 학습 초기에 엔트로피가 급격히 감소하지만, 접두사 안내 방법은 엔트로피를 안정적으로 유지합니다.

  • 초기 학습 단계에서 엔트로피 붕괴 억제
  • 스텝 레벨 엔트로피 분포가 더 넓게 유지
  • 후반 학습 단계에서도 지속적 탐색

보조 모델 크기의 영향

흥미롭게도, 더 작은 보조 모델이 때로 더 큰 효과를 냅니다. 분포 불일치가 클수록 탐색 자극이 강해지기 때문입니다.

  • 0.5B 모델도 32B 목표 모델 탐색에 효과적
  • 모델 간 분포 차이가 핵심 인자
  • 접두사 품질보다 분포 거리가 더 중요

약한 보조 모델의 접두사가 거의 도움이 되지 않거나 심지어 오도하는 경우에도, 분포 불일치 자체가 탐색 촉진 메커니즘으로서 효과적으로 작동합니다.

절제 연구

각 구성요소의 기여도를 체계적으로 분석합니다.

구성요소별 기여
설정효과
접두사 안내만 중간 향상
+ 엔트로피 절단 추가 향상
+ 혼합 학습 최종 최고 성능
혼합 비율 α의 영향

α = 0.5 전후에서 최적 성능을 보입니다.

  • α = 0: vanilla GRPO와 동일
  • α = 1: 원래 학습 신호 상실
  • α ≈ 0.5: 균형 잡힌 향상 달성
세 구성요소가 모두 조합되었을 때 시너지 효과가 최대화됩니다.

핵심 요약 & 시사점

주요 기여

  • 크로스 모델 생성 다양성이 RLVR 탐색 역학에 미치는 영향을 체계적으로 연구
  • 약한 모델의 부분 궤적을 활용한 접두사 안내 RLVR 프레임워크 제안
  • pass@k 성능 향상이 k 증가에 비례하여 커짐을 통해 추론 커버리지 확장 실증
  • 분포 불일치가 탐색 촉진의 핵심 메커니즘임을 규명

실용적 장점

  • 추가 SFT 단계 불필요
  • 복잡한 보상 설계 불필요
  • 복잡한 프롬프트 엔지니어링 불필요
  • 매우 작은 보조 모델(0.5B)로도 효과적
  • 기존 RLVR 파이프라인에 최소 변경으로 적용 가능
