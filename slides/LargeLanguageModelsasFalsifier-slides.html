CPS Falsification이란?

시스템의 형식 명세를 위반하는 반례(counterexample)를 찾는 탐색 문제

대상

Simulink / Python 시뮬레이터로 모델링된 자동차, 드론 등 사이버물리시스템(CPS)

명세

Signal Temporal Logic(STL)로 작성된 시간 제약 요구사항 — 안전성, 시민감 목표 등

명세를 위반시키는 초기 상태와 입력 신호를 찾는 것이 목표

배경: STL 강건성(Robustness)

STL은 정량적 의미론(quantitative semantics)을 통해 만족의 정도를 실수 하나로 표현합니다.

따라서 falsification은 강건성 최소화 문제로 공식화 가능

기존 접근법의 한계

  • 강건성 함수는 중첩된 min/max 연산자로 인해 비평활(non-smooth)·비볼록(non-convex)
  • 미분 불가능 → 기존 도구들은 블랙박스 탐색 알고리즘에 의존
  • 서게이트 기반, 베이지안 최적화, 탐색 기반 테스팅 등이 사용됨
  • 각 샘플마다 비싼 시뮬레이션이 필요 → 샘플 효율성이 핵심 비용

반면, LLM은 반복 프롬프팅(OPRO)을 통해 미분 없이도
효과적인 최적화를 수행할 수 있음이 최근 밝혀짐

LLM-Falsifier 워크플로우

폐루프(closed-loop) 반복 구조

1
모델 요약
STL 명세·시스템 파일에서 메타프롬프트 구성
2
LLM 제안
다음 후보 입력 신호 생성
3
시뮬레이션
입력을 실행하여 출력 신호 획득
4
STL 모니터
강건성 ρ 와 임계 시점 계산

ρ < 0 반례 발견 → 탐색 종료

ρ ≥ 0 샘플·피드백을 프롬프트에 추가 → 반복

핵심 아이디어: 시맨틱 정보 노출

단순 스칼라 점수만 주는 OPRO와 달리, LLM이 언어로 추론하기 좋은 풍부한 정보를 제공

자연어 변수명

입력·출력 신호의 의미 있는 이름 (예: gear, velocity) — 숫자 배열이 아닌 개념으로 이해

출력 궤적

시간에 따른 출력 신호 값 — 시스템 동역학에 대한 인과 추론 가능

임계 시점 증거

최소 강건성이 발생한 시점과 그 순간의 신호 값 제공

강한 귀납 편향(inductive bias)을 부여하여 더 똑똑하고 샘플 효율적인 탐색 유도

OPRO와의 차이점

항목OPROLLM-Falsifier
피드백스칼라 점수뿐시맨틱·맥락 피드백 (이름, 궤적, 임계 시점)
초기 샘플사전 샘플 제공초기 샘플 없이 시작
반복당 제안여러 후보 생성샘플 1개 (시뮬레이션 비용 고려)
후보 선별외부 랭킹·선택외부 선별 없음
평가LLM 외부 채점시뮬레이터 + STL 모니터

실험 설정: ARCH-COMP 2025

벤치마크

  • ARCH-COMP falsification 벤치마크
  • 총 21개 STL 명세 (자동변속기 AT 등)
  • 지표: 반례 발견까지의 평균 시뮬레이션 횟수

비교 대상

  • 서게이트(surrogate) 기반 최적화
  • 베이지안 최적화
  • 탐색 기반 테스팅(search-based testing)

폐쇄형 모델뿐 아니라 오픈소스 모델과 추론 노력(reasoning effort)의 영향도 분석

첫 시도에서 반례를 찾는 것은 첫 샘플 이전에 아무 정보가 없는
순수 수치 최적화기에는 사실상 불가능한 일입니다.

샘플 효율성 = 반례 발견 전 생성·시뮬레이션해야 하는 후보 입력의 수 — falsification의 핵심 비용

Ablation: 어떤 정보가 효과인가?

프롬프트 구성 요소를 하나씩 제거하며 각 향상 기법의 기여를 정량 분석

  • 자연어 신호 이름 — 변수 의미를 이해해 목표 지향적 입력 생성
  • 출력 궤적 정보 — 시스템 반응에 대한 인과 추론 지원
  • 임계 시점(critical time) 값 — 최소 강건성 시점의 신호 포함 시 성능 향상 확인

모델 선택 효과도 분석: 오픈소스 모델에서도 유의미한 falsification 수행

설명가능성: LLM의 추론 과정

LLM의 reasoning trace를 분석하여 위조 입력을 구성하는 방식을 이해

명세 해석

STL 요구사항을 자연어로 이해하고 위반 조건 도출

동역학 추론

출력 궤적·임계 시점으로부터 시스템 행동 가설 형성

휴리스틱 탐색

정보에 기반한 휴리스틱으로 반례에 빠르게 수렴

한계점

비용

LLM API 호출 지연·비용이 시뮬레이션 비용과 함께 고려되어야 함

비결정성

LLM 생성의 확률적 특성으로 인한 결과 변동성 존재

형식적 보장 없이 탐색 기반 방법이라는 falsification 고유의 한계는 여전히 적용 — 반례를 찾으면 명세 위반이 증명되지만, 실패는 만족을 의미하지 않음

결론

  • LLM-Falsifier: LLM이 STL 강건성을 최적화하여 CPS falsification을 직접 수행하는 최초의 접근법
  • 시맨틱 정보(변수명·궤적·임계 시점)가 샘플 효율적인 강건성 탐색을 가능하게 함
  • ARCH-COMP 2025에서 21개 명세 중 14개로 최고 성능 달성
