SWE-Serve는 추론 커버리지, 성능 이상의 과제, GPU·CPU 실행, 클로즈드북 평가를 모두 갖춘 유일한 벤치마크입니다.

최고 구성의 평균 pass@1

  • CPU 전용 또는 단일 H100 GPU 환경에서 에이전트 실행
  • 숨김 기능·회귀 테스트로 패치 채점, 해당 시 E2E 서빙 테스트와 성능 게이트 적용
  • 클로즈드북 실행으로 상류 솔루션 검색 차단, 궤적 감사 병행

결과 ①: 40포인트 pass@1 격차

31개 모델–노력 구성 전반에서 최고와 최저 구성 사이 약 40포인트의 pass@1 격차가 관찰되었습니다.

최고 성능

최고 구성이 75% 평균 pass@1 달성

자원 트레이드오프

높은 추론 노력·에이전트 스텝은 성능 향상과 함께 연산 비용 증가 수반

에이전트 하네스 선택에 따라서도 성능이 민감하게 달라져, 벤치마크가 모델과 하네스 모두를 평가함을 보여줍니다.

결과 ②: 프로덕션 정확성 격차

E2E 커버리지가 있는 19개 과제에서, 모델 서빙 E2E 테스트는 다른 모든 테스트를 통과한 패치의 약 1/3을 거부합니다.

69.4%

E2E 테스트 제외 시 통과율

45.9%

E2E 테스트 포함 시 통과율

  • E2E 제외 시 23.4%p 상승 — 11개 최고 성능 구성 전부에서 증가
  • 12개 정합 비교 과제에서 E2E 제거는 동일 수량의 비-E2E 테스트 제거 대비 2.0배의 신규 통과 패치 유발

시사점: 격차를 측정 가능하게

"로컬 완성"에서 프로덕션 정확성으로 나아가는 미래 에이전트의 진전을 추적할 수 있게 합니다.

견고성 확인

  • 추론 노력 수준과 무관하게 프로덕션 정확성 격차는 지속
  • 과제 구성·E2E 전용 과제 민감도 분석으로 격차의 인과성 검증
  • 매칭된 테스트 제거 컨트롤로 E2E 테스트의 고유한 역할 확인

기여 요약

  • 프로덕션 추론 공학 벤치마크: 6개 공학 패밀리의 53개 프로덕션 기반 과제, CPU/H100 실행, 숨김 기능·회귀 테스트
  • 타당성·무결성 방법론: 프로덕션 기반 구성, 실행형 no-op·오라클 컨트롤, 에이전트 기반 적대적 탐침, 인간 심의, 클로즈드북 실행, 궤적 감사
  • 프로덕션 정확성 격차의 실증: E2E 테스트 제외 시 23.4%p 통과율 상승, 2.0배 신규 통과 패치
