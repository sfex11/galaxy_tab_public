왜 신뢰가 중요한가?

신뢰는 설명 가능성(Explainability)과 밀접하게 연결되며, 더 높은 수준의 자동화와 원활한 인간-AI 협업을 향해 나아가기 위한 핵심 전제조건이다.

블랙박스 문제

  • 전통적 RL은 의사결정 근거 불명확
  • 관제사가 AI 권고를 검증 불가
  • 오작동 시 원인 파악 곤란

신뢰 기반 협업

  • AI 의사결정의 근거 투명화
  • 관제사의 적절한 의존도 유지
  • 비상 상황 대응 능력 향상

RL 에이전트 설계 상세

상태 공간 (State)

  • 각 항공기의 3D 위치 (x, y, z)
  • 속도 벡터 및 항로 정보
  • 항공기 간 상대 거리·고도차
  • 기상 및 공역 제약 정보

행동 공간 (Action)

  • 고도 변경 지시 ( climb / descend )
  • 속도 조절 지시 ( speed up / slow down )
  • 항로 변경 지시 ( heading change )
  • 유지 ( maintain current )

보상 함수 설계

R = R안전 (최소 분리 간격 위반 페널티) + R효율 (항로 이탈 최소화 보너스) + R승객 (승객 편안함 보너스)

설명 생성 메커니즘

단순한 특성 중요도가 아닌, 관제사의 의사결정 논리와 일치하는 설명을 생성한다.

요인 식별

어떤 항공기 쌍이 행동을 유발했는지 국소화

의미 매핑

수치적 기여도를 관제 개념(간격 침범, 병목 등)으로 변환

자연어 생성

템플릿 기반 관제사 친화적 문장 출력

"AAL123을 FL350으로 상승 지시 — UAL456과의 수직 간격이 5NM 이하로 축소됨"

핵심 시사점

설명의 질이 양보다 중요

일반적 XAI 설명(SHAP 등)은 오히려 인지 부하를 증가시켰다. 관제 도메인에 맞춘 설명만이 신뢰와 이해도를 동시에 향상시킨다.

적절한 의존도 달성

설명 없는 AI는 과소신뢰, 관련 없는 설명은 과신을 유발했다. 도메인 설명은 적정 수준의 의존도를 유지하게 했다.

관제사는 수동적 수용자가 아님

관제사는 AI 설명을 자신의 판단과 교차 검증하는 데 활용했다. 설명은 통제권 이전이 아닌, 통제권 강화 도구로 기능했다.

한계와 향후 과제

시뮬레이션 환경 기반으로 실제 공역 검증 필요. 다국어 설명, 실시간 성능 최적화 등 추가 연구가 요구됨.

결론

항공 교통 관제와 같은 초고위험 도메인에서 AI의 성공적 통합은 기술적 성능만으로 충분하지 않다. 도메인 전문가의 언어와 논리에 부합하는 설명을 제공할 때 비로소 신뢰가 형성되고, 진정한 의미의 인간-AI 협업이 실현된다.
