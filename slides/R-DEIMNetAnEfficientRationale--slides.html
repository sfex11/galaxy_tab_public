Paraphrase Detection Dual-Expert Architecture

R-DEIM Net

Rationale-Augmented Dual-Expert Interaction Model for Paraphrase Detection

Pushp · Vaibhav Prajapati · Himangshu Sarma

IIIT Sri City, India · University of Technology Nuremberg (UTN), Germany

arXiv: 2609.30100v1 [cs.CL]

배경: 패러프레이즈 탐지란?

두 텍스트 조각의 의미적 동등성을 판별하는 작업으로, 현대 자연어 이해(NLU)의 초석입니다.

핵심 응용 분야

  • 지능형 검색 및 대화형 AI
  • 콘텐츠 중복 제거(de-duplication)
  • 표절 탐지

표준 벤치마크: QQP

2017년 Kaggle 대회 이후 Quora Question Pairs 데이터셋이 표준이 되었으며, 다양한 표면적 표현을 넘어 의미의 동일성을 포착해야 합니다.

핵심 문제: 정확도 vs 효율성의 트레이드오프

대규모 모델

LLM · 앙상블 BERT

  • 높은 정확도 달성
  • 막대한 연산 비용 → 실제 배포 제한
경량 모델

Siamese-BERT 계열

    • 실용적인 확장성
    • 이진 예측만 제공, 근거(rationale) 생성의 투명성 부족

    대부분의 효율적인 패러프레이즈 탐지 시스템은 결정을 설명하는 인간이 읽을 수 있는 명시적 근거가 부족합니다.

    관련 연구 동향 (QQP 기준)

    63 ~ 85%

    전통 · 어휘 기반

    CBOW, XGBoost + 수작업 특징, ABCNN, PWIM, LDC, Syn-tree. 계산은 가볍지만 깊은 의미 맥락 포착에 한계.

    79 ~ 89%

    순환 · 합성곱 신경망

    Siamese-CNN, MP-CNN, ESIM, InferSent, Bi-CAS-LSTM. 장거리 의존성 학습했으나 가변 길이 입력과 투명성에 취약.

    88 ~ 90%

    고차 상호작용 · 트랜스포머

    DIIN, MwAN, MFAE(BERT 앙상블), 최근에는 LLaMA-70B까지 적용. 정교한 어텐션 정렬 활용.

    수작업 특징 엔지니어링 → 자동화된 의미 표현으로의 전환이 이루어졌으나, 효율성과 근거 생성의 투명성 사이 절충이 여전히 존재합니다.

    기존 연구의 3가지 기술적 한계

    1

    F1 점수 미보고

    대부분의 선행 연구가 원시 정확도에만 집중하여, 불균형 데이터에서의 성능이 검증되지 않았습니다.

    2

    고정된 max_tokens 제한

    의미가 풍부한 문장 절단 vs 과도한 패딩 사이의 타협 강제 → 희소하고 비효율적인 행렬과 노이즈 있는 어텐션 가중치 유발.

    3

    이진 레이블만 제공

    예측력에도 불구하고 결정에 대한 인간이 읽을 수 있는 근거(rationale)를 제공하지 못합니다.

    제안: R-DEIM Net (76M 파라미터)

    문장 쌍을 입력받아 이진 분류 + 텍스트 근거(rationale)를 함께 출력하는 듀얼 익스퍼트 아키텍처입니다.

    Branch A: 상호작용 익스퍼트

    다중 스케일 2D 합성곱과 어텐션 기반 풀링으로 토큰 간 유사성 패턴을 포착. 가변 길이 입력 처리 가능.

    Branch B: 추론 익스퍼트

    Flan-T5-small 디코더로 근거를 생성하여 보조 학습 신호로 활용. 디코더 은닉 상태를 특징 벡터로 추출.

    • 토큰 상호작용과 생성적 추론 신호를 공동 모델링하는 듀얼 익스퍼트 프레임워크
    • 생성된 근거의 재인코딩 없이 은닉 상태를 특징으로 사용 → 불필요한 연산 오버헤드 회피

    Branch A: 상호작용 익스퍼트

    1
    공유 인코더
    paraphrase-MiniLM-L12-v2 선택 (33M, 정확도·효율 균형 최고)
    2
    상호작용 행렬
    M = EQ1 · EQ2T로 토큰별 유사도 계산
    3
    다중 스케일 2D-CNN
    다양한 커널 크기의 병렬 2D 합성곱으로 정렬 패턴 추출
    4
    어텐션 풀링
    가변 길이 입력을 지원하며 상호작용 특징 집계

    단순 벡터 유사도를 넘어, 두 질문 간 토큰-토큰 의미 관계를 직접 분석합니다.

    Branch B: 추론 익스퍼트

    근거 생성 (Flan-T5-small)

    디코더가 판단 이유를 자연어 근거로 생성하며, 이는 학습 시 보조 감독 신호로 작용합니다.

    은닉 상태 기반 특징화

    생성된 텍스트를 재인코딩하지 않고, 근거 생성 중의 디코더 은닉 상태를 추출·풀링하여 보완 특징으로 사용합니다.

    • 분류 결정을 자연어 특징에 기반하도록 정렬(grounding)
    • 재인코딩 회피로 불필요한 연산 오버헤드와 추가 인코딩 레이어 제거
    • 예측과 함께 인간이 읽을 수 있는 설명 제공

    융합 및 멀티태스크 학습 목표

    A
    상호작용 특징
    토큰 정렬 패턴에서 추출된 표현
    B
    추론 벡터
    디코더 은닉 상태에서 풀링된 특징
    F
    특징 융합
    두 특징을 결합해 최종 분류 수행
    L
    멀티태스크 손실
    분류 손실 + 근거 생성 손실 공동 최적화

    분류 레이블 y ∈ {Duplicate, Non-Duplicate} 예측과 근거 생성을 동시에 학습하여, 정확도와 설명 가능성을 하나의 프레임워크에서 달성합니다.

    아키텍처 분석

    구조적 · 다중 스케일 상호작용

    구조적 정렬 분석과 커널 활성화 동작을 통해, 다중 스케일 2D-CNN이 토큰 대응 패턴을 실제로 학습함을 확인했습니다.

    민감도: POS 기반 교란

    품사(POS) 기반 교란 실험으로 입력 변화에 대한 모델의 민감도를 정량적으로 평가했습니다.

    토큰 수준 민감도

    개별 토큰 변화가 예측에 미치는 영향을 분석하여 의사결정의 세부 기여도를 파악했습니다.

    전역 강건성

    전역적 교란에 대해서도 안정적인 예측 성능을 유지하는 강건성을 확인했습니다.

    상호작용 및 추론 구성 요소가 의미적 의사결정에 기여하는 방식에 대한 포괄적 실증 분석을 제공합니다.

    결론

    • 76M 파라미터의 중간 규모 모델로 QQP에서 90.07% 정확도 · 90.16% F1 달성
    • 상호작용 익스퍼트(2D-CNN + 어텐션 풀링)와 추론 익스퍼트(Flan-T5-small)의 효과적 결합
    • 생성된 근거의 재인코딩 없이 디코더 은닉 상태를 활용하는 효율적 근거 정렬 메커니즘
    • 인간이 읽을 수 있는 근거 생성으로 투명성과 효율성의 균형 확보

    향후 연구 (Future Work)

    근거 품질의 정량적 평가, 더 다양한 데이터셋으로의 확장, 멀티태스크 프레임워크의 일반화 가능성 탐구가 남아 있습니다.
