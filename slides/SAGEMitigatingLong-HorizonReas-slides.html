SAGE

Mitigating Long-Horizon Reasoning Biases via Topological Guidance

Structural Admissibility-Guided Exploration

Xinyue Zeng · Jiawei Zhang · Yujun Yan · Dawei Zhou

Virginia Tech · UW–Madison · Dartmouth College

문제 정의: 희소 보상 하의 장기 추론

LLM의 장기 추론은 여러 단계에 걸친 깊고 구조화된 추론 경로의 발견을 요구하며, 결과 기반 post-training은 희소 보상 환경에서 취약해집니다.

구조적 복잡성

탐색 공간은 |Ω| = O(ĀT)로 지수적으로 팽창하는 반면, 성공 궤적 𝒯*은 T가 커질수록 사라지는 비율로만 존재

희소한 결과 피드백

유의미한 보상은 궤적의 끝에서만 제공 → 신뢰도 할당(credit assignment)이 깊이에 따라 급격히 어려워짐

국소적으로 그럴듯하지만 전역적으로 불안정한 패턴이 학습되는 근본 원인

두 가지 장기 추론 편향

탐색 편향 (Exploration Bias)

복잡한 추론 공간으로 인해 발생

  • 국소적으로 타당하지만 구조적으로 불안정한 분기로 모델이 끌림
  • 성공으로 확장 가능한 경로는 좁은 영역에만 존재

누적 편향 (Compounding Bias)

희소 보상 환경으로 인해 발생

  • 작은 국소 오차가 깊이를 따라 축적
  • 조기 수정 불가 → 장기 실현 가능성에서 점점 멀어짐

Andrews-Curtis(AC) trivialization 문제: 수많은合法 변환이 존재하지만 단순화로 이어지는 경로는 극히 일부

기존 접근법과 한계

촘촘한 프로세스 감독

대화형 검증기, 학습된 verifier, LLM-as-a-Judge + MCTS 등으로 단계별 검증

한계 프로세스 감독의 확장이 구조적으로 비용이 큼 — 희소 보상 학습의 본질적 어려움은 미해결

결과 기반 RL 보강

STaR, ReST 같은 부트스트래핑, 엔트로피 정규화·구문 제약 기반 내재적 동기

한계 추론 공간의 구조를 모델링하지 않음 — 실현 가능한 궤적의 기하학이 암묵적으로 남음

두 접근 모두 편향의 원인인 추론 공간의 구조 자체를 다루지 못함 → 구조적 가이던스의 필요성 대두

핵심 연구 질문

Q1. 진단

구조적 복잡성과 희소 보상 환경 아래에서 장기 추론 실패를 유도하는 지배적 요인을 특성화할 수 있는가?

Q2. 해법

이 특성화를 탐색 편향과 누적 편향을 동시에 완화하는 통합 프레임워크로 구현할 수 있는가?

이론: SCA  →  방법론: SAGE

SCA: Symbolic Closure Analysis

추론을 국소 허용(locally admissible) 변환의 연쇄로 모델링하고, 팽창하는 추론 공간에서 실현 가능 지지 집합(feasible support)의 진화를 분석하는 이론적 렌즈

구조적 복잡성의 효과

실현 가능 지지가 대용량이지만 생산적이지 않은 분기들에 희석됨 → 탐색 편향 유발

희소 보상의 효과

중간 보상 부족으로 국소 편차가 깊이와 함께 누적 → 누적 편향 유발

  • 두 편향은 깊이가 증가하며 상호작용함을 이론적으로 규명
  • 비공식적 추론 과제에서도 구조적 사전(prior) 설계의 원리로 확장 가능

SAGE: 구조적 가이던스의 통합 프레임워크

정책 최적화 과정에 구조적 가이던스를 주입하여, 학습된 정책이 구조화된 추론 공간의 유용한 성질을 내면화하도록 유도

1
대수적 희소화
연산자 인덱스 대수 부분공간으로 투영 → 가짜 분기 억제
2
쌍곡 구조 가이던스
음의 곡률 공간 임베딩 → 깊이별 밀집 신호 제공
3
정책 최적화
SCA 진단을 학습 가능한 가이던스 신호로 변환

희소화 → 탐색 편향 완화

쌍곡 가이던스 → 누적 편향 완화

구성 요소 ①: 대수적 희소화 (Algebraic Sparsification)

  • 국소 허용 후보들을 연산자 인덱스(operator-indexed) 대수 부분공간으로 투영
  • 잔차 표현(residual representation)과 대수적 희소화로 가짜 분기(spurious branching) 억제
  • 의미 군집화(meaning clustering)와 고정 부분집합 엔트로피 필터링으로 후보 정제

효과: 성공으로 확장 불가능한 국소적 경로에 소요되는 탐색 예산 낭비를 줄여 탐색 편향을 완화

구성 요소 ②: 쌍곡 구조 가이던스 (Hyperbolic Structural Guidance)

  • 추론 상태를 음의 곡률 공간(쌍곡 공간)에 임베딩하여 위상적(topological) 구조 반영
  • 희소한 최종 보상 대신 깊이에 따른 밀집(dense) 신호를 제공
  • 트리/계층 구조에 자연스럽게 적합한 기하학으로 장기 실현 가능성 보존

효과: 초기 국소 편차를 조기에 포착·교정하여 누적 편향을 완화

두 요소는 상호 보완적: 희소화(분기 정제) + 쌍곡 가이던스(깊이 감독)

기여 요약

1

이론 (SCA) — 구조적 복잡성과 희소 보상 하에서 장기 추론 실패의 지배 요인을 규명하는 이론적 렌즈 제시

2

방법론 (SAGE) — 대수적 희소화 + 쌍곡 구조 가이던스로 두 편향을 동시 완화하는 통합 프레임워크 제안

3

실증 평가 — 12개 벤치마크 × 7개 모델 패밀리에서 경쟁 기법들을 일관되게 능가, AC 문제에서 최대 8배 향상

결론

장기 추론의 취약성은 탐색 편향과 누적 편향에서 비롯되며, SCA가 그 기제를 밝히고 SAGE의 위상학적 구조 가이던스가 이를 효과적으로 완화합니다.
