MIRROR

다른 뷰로부터 배우는 멀티모달 추론

Modality-Informed Reciprocal Reasoning Optimization

Wen Ye1, Yuxiao Qu2, Aviral Kumar2, Xuezhe Ma1

1 USC · 2 CMU

문제 인식: VLM의 시각적 추론 한계

대형 언어 모델(LLM)은 강력한 추론 능력을 보이지만, 시각-언어 모델(VLM)은 시각적 추론에서 여전히 어려움을 겪는다.

특히 기하 문제에서 동일한 문제가 텍스트, 도형, 결합 뷰로 제시될 때 모델의 성능이 크게 달라진다.

"문제의 난이도가 아니라, 정보가 제시되는 뷰(view)에 의해 실패가 결정된다."

핵심 질문

  • 한 뷰에서 성공한 추론 경로를 다른 뷰로 전이할 수 있는가?
  • 외부 교사 없이 자기 자신의 강점을 활용할 수 있는가?
  • 뷰 간 불일치가 단순한 결함이 아니라 감독 신호가 될 수 있는가?

핵심 관찰: 뷰 간 추론 불일치

동일한 모델이 동일한 문제에 대해 뷰에 따라 서로 다른 거동을 보인다.

텍스트 지향 뷰

수량과 관계를 언어로 기술. 텍스트로는 풀지만 도형으로는 실패

이미지 지향 뷰

도형이 핵심 기하 정보를 담음. 도형으로는 풀지만 텍스트로는 실패

결합 뷰

텍스트와 이미지 모두 제공. 정보 중복으로 인해 더 쉬워질 수 있음

이러한 비대칭성(asymmetry)은 단순한 강건성 결함이 아니라, 상호 보완적 추론 경로를 노출시키는 잠재적 감독 신호다.

ODA-Data: 짝지어진 멀티모달 기하 데이터셋

동일한 기하 문제에 대해 세 가지 뷰를 짝지어 구축한 고품질 데이터셋

구성

  • Text-dominant: 수량·관계를 언어로 완전 기술
  • Image-dominant: 도형이 핵심 정보, 텍스트는 질문만
  • Combined: 두 뷰를 동시에 제공

특징

  • 문제 식별자를 뷰 간에 보존
  • 정확도와 뷰 간 일관성 측정 가능
  • ODA-Train (학습) / ODA-Val (평가) 분할

뷰 의존적 풀이 가능성 측정

ODA-Val은 모델이 다른 뷰로 제시된 동일 문제를 일관되게 푸는지 측정하는 헬드아웃 벤치마크다.

분할용도
ODA-Train포스트트레이닝
ODA-Val뷰 의존적 평가

MIRROR: 개요

Modality-Informed Reciprocal Reasoning Optimization — 강한 뷰의 추론으로 약한 뷰를 개선하는 자기감독 RL 프레임워크

1
다중 뷰 평가
각 문제를 text, image, combined 세 뷰로 평가
2
교사 선택
가장 성능이 좋은 뷰를 문제별 교사로 지정
3
온정책 증류
학생이 자신의 뷰에서 샘플링, 교사가 재채점
4
결합 학습
결과 보상 RL + reverse-KL 정규화

핵심 아이디어: 외부 교사 없이, 동일 문제의 짝지어진 뷰가 드러내는 성능 비대칭을 자기감독 신호로 활용한다.

MIRROR: 알고리즘 상세

문제별 교사 선택

문제 𝐱에 대해 세 뷰에서 각각 롤아웃을 생성하고, 가장 높은 성능을 보인 뷰를 교사 τ로 선택:

τ*(𝐱) = argmaxv∈{text,img,comb} R(π(·|𝐱v), 𝐱)

학생 뷰 제한

학생은 정보 중복이 없는 제한된 뷰(text-dominant 또는 image-dominant)에서만 학습한다.

손실 함수 구성

결과 보상 RL

학생 뷰에서의 정답 여부를 보상으로 사용 (GRPO 기반)

Reverse-KL 정규화

학생 분포를 교사 분포 쪽으로 당김

β 가중치 균형

두 목표 간 균형을 조절하는 하이퍼파라미터

On-policy Distillation 메커니즘

분포 불일치 문제를 해결하기 위한 핵심 설계

기존 방식의 한계

  • 교사가 생성한 궤적만 학습 → 분포 불일치
  • 학생이 방문하지 않은 상태에 대한 가이드
  • 교사 뷰에만 존재하는 정보에 의존하는 위험

MIRROR의 해결책

  • 학생이 자신의 뷰에서 직접 롤아웃을 샘플링
  • 교사 뷰는 학생이 생성한 동일 궤적을 재채점만 수행
  • 학생이 실제로 방문한 상태에서만 최적화

학생의 제한된 뷰에서 사용할 수 없는 정보에 의존하는 궤적을 모방하도록 강제하지 않으면서, 밀도 높은 교사 가이던스를 제공한다.

의미

MIRROR는 특정 뷰에 치우침 없이, 뷰에 구애받지 않는 강건한 추론을 학습한다.

논의 및 향후 방향

기여 요약

  • 뷰 간 추론 불일치를 자기감독 신호로 활용하는 새로운 관점 제시
  • ODA-Data: 뷰 간 일관성 측정이 가능한 짝지어진 기하 데이터셋 구축
  • MIRROR: 온정책 증류 기반의 교차 뷰 RL 프레임워크
  • 정확도와 일관성 동시 향상 달성

향후 방향

  • 기하 외의 도메인(자연 이미지, 표 등)으로 확장
  • 더 다양한 뷰 정의 (캡션, 코드, 형식화 증명 등)
  • 교사 선택 전략 고도화 (신뢰도 가중치 등)
  • 더 큰 규모 모델(72B+)에 대한 스케일링 연구
  • 중간 구조(코드, 기호 기술)와의 결합 탐색

MIRROR는 엔드투엔드 방식으로, 명시적인 중간 표현이나 증거 선택 없이도 전이 가능한 추론 구조를 내재화하도록 모델을 유도한다.
