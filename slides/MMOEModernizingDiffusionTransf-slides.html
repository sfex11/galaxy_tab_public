동기: LLM과 AFM의 스케일링 괴리

대규모 언어 모델 (LLM)
  • 희소 전문가(MoE)로 용량-연산 분리
  • 제로 연산 전문가, 게이트 잔차 라우팅 등 효율 메커니즘 도입
  • 토큰당·배포 비용 제어하며 스케일링 성공
AIGC 파운데이션 모델 (AFM)
  • 디퓨전-트랜스포머 백본에 MoE 도입 시작
  • 주로 전체 파라미터와 희소 비율만 확대
  • LLM의 효율 메커니즘 대부분 미도입
핵심 질문: LLM 스케일링의 효율적 아키텍처 원칙을 AFM에 더 균형 있게 적용할 수 있는가?

MMOE 아키텍처 개요

SiT 스타일 디퓨전 트랜스포머에 4가지 핵심 현대화 요소를 점진적으로 통합
1
라우팅 전문가
표준 top-k 게이트 기반 희소 FFN 전문가
2
공유 전문가
모든 토큰이 공통으로 거치는 FFN
3
경량 전문가 (MoE++)
Zero, Copy, Constant — 연산 없는 전문가
4
어텐션 잔차 재사용
이전 블록 상태를 어텐션·전문가 양쪽에 집계
디노이징 목적함수, 조건부 인터페이스, 잠재 표현, 샘플러는 모두 변경 없이 트랜스포머 블록 내부 연산만 수정

MoE++ 경량 전문가 층

MoE++에서 제안한 연산 비용이 없는 세 가지 전문가를 디퓨전 트랜스포머에 적용
Zero 전문가
출력이 항상 0. 무거운 업데이트가 불필요한 토큰을 위한 저비용 라우트 제공
Copy 전문가
입력을 그대로 통과시킴. 이미 충분한 표현을 가진 토큰의 보존에 기여
Constant 전문가
학습 가능한 고정 벡터 출력. 글로벌 바이어스 역할, 안정적인 기저 정보 제공
게이트 잔차 라우팅 라우팅 가중치에 잔차 항을 더해, 게이트가 전문가 선택을 완전히 무시하지 않도록 안정화

MMOE 트랜스포머 블록

Vanilla MoE 블록 vs MMOE 블록의 구조적 차이
Vanilla MoE 블록
  • 어텐션 서브레이어 → 잔차 연결
  • MoE FFN 서브레이어 → 잔차 연결
  • 토큰마다 소수의 FFN 전문가만 라우팅
  • 경량 라우트 없음
  • 크로스-깊이 정보 재사용 없음
MMOE 블록
  • 어텐션 전에 이전 블록 상태 집계
  • 라우팅 전문가 + 공유 전문가 병렬
  • MoE++ 경량 전문가 (Zero/Copy/Const)
  • 게이트 잔차 라우팅 안정화
  • 전문가 서브레이어에도 잔차 집계

어텐션 잔차 순방향 프로세스

깊이별 정보를 명시적으로 재사용하여 표현력 향상
이전 블록 출력 집계
완료된 모든 이전 블록의 상태를 가중 합산하여 현재 입력에 병합
어텐션 서브레이어
집계된 입력으로 셀프 어텐션 수행 후 잔차 연결
MoE++ 전문가 서브레이어
동일한 집계 메커니즘을 전문가 층 입력에도 적용
블록 출력 전달
현재 블록 출력을 다음 블록의 집계 대상으로 저장
새로운 생성 목적함수나 샘플링 절차 없이, 블록 내부 연산만으로 크로스-깊이 정보 흐름 확보

실험 설정

학습 환경
  • 단일 8×H100 노드
  • 배치 크기 256
  • 400K 학습 스텝
  • 접근 가능한 단일 머신 예산
베이스라인 및 비교 대상
  • Dense SiT (밀집 기준)
  • MoE-only (라우팅 전문가만)
  • MoE + Shared (공유 전문가 추가)
  • MoE++ (경량 전문가 추가)
  • MMOE (전체 구성)
ImageNet 256×256, 클래스 조건부 생성, 동일한 학습·샘플링 프로토콜 하에 공정 비교

주요 결과: FID 비교

모든 기록된 체크포인트에서 MMOE가 최저 FID 달성
모델 활성 파라미터 FID (200K) FID (400K) 품질-비용 균형
Dense SiT 100% 기준 기준 —
MoE-only 일부 개선 개선 중간
MoE + Shared 일부 더 개선 더 개선 양호
MoE++ 일부 우수 우수 우수
MMOE (전체) 일부 최저 최저 최고
스텝당 수렴 속도가 가장 빠르며, 희소 변종 중 품질-비용 균형이 최고

절제 연구: 각 구성요소의 기여

점진적 설계를 통해 각 현대화 요소의 독립적 효과 분리 분석
라우팅 전문가 추가
Dense 대비 FID 개선. 용량 증가와 선택적 연산의 기본 효과 확인
공유 전문가 추가
라우팅되지 않는 정보 손실 방지. 수렴 안정성 향상
경량 전문가 추가
Zero/Copy/Constant 라우트가 실제로 활발히 사용됨. 효율성과 품질 동시 향상
어텐션 잔차 재사용
크로스-깊이 정보 흐름 추가로 수렴 가속화. 품질 한계 추가 상승
모든 LLM 영감 MoE 설계가 AFM 적응 시 성능·수렴·속도에 긍정적 기여

전문가 라우팅 분석

깊이별 전문화
블록 깊이에 따라 강한 전문가 전문화 관찰. 얕은 층과 깊은 층이 서로 다른 전문가를 선호
경량 라우트 사용
Zero/Copy/Constant 전문가가 실제로 상당한 비율로 선택됨. 무거운 연산의 선택적 회피 확인
스텝간 안정성
디노이징 단계 간 라우팅 변화율이 낮음. 인접 스텝에서 안정적인 전문가 할당 유지
희소 전문가 현대화는 단순한 명목상 용량 확장을 넘어, 생성 파운데이션 모델에서 안정적인 적응적 연산 할당 메커니즘으로 기능할 수 있음

논의 및 한계

강점
  • 단일 H100 노드에서 검증 가능한 접근성
  • 점진적 설계로 각 요소의 기여 명확히 분리
  • 디노이징 과정에서의 라우팅 안정성 입증
  • AFM이 LLM의 균형 스케일링 경로를 따를 수 있음 시사
한계
  • 이전 디퓨전 MoE 방법들과의 직접 비교 미수행 (학습 규모 차이)
  • ImageNet 256×256 클래스 조건부에 한정
  • 텍스트-이미지, 비디오 생성 등 다양한 AFM 태스크 미검증
  • 더 큰 스케일에서의 효과 불확실

결론

AFM 스케일링은 단순한 파라미터 확대가 아닌, 연산 활성화·건너뛰기·재사용·라우팅의 설계 문제
  • AFM 스케일링을 현대화 문제로 공식화하고, LLM MoE 설계의 이전 가능성을 체계적으로 검증
  • 라우팅·공유·경량 전문가, 게이트 잔차 라우팅, 어텐션 잔차 재사용을 통합한 MMOE 아키텍처 제안
  • 단일 8×H100 노드에서 모든 베이스라인 대비 빠른 수렴과 최고 품질-비용 균형 달성
  • 라우팅 분석으로 안정적인 전문가 전문화와 적응적 연산 할당 확인
AFM은 단순히 전체 파라미터와 희소 비율을 늘리는 대신, 검증된 효율 설계를 도입하여 LLM의 균형 잡힌 스케일링 경로를 따를 수 있다.
