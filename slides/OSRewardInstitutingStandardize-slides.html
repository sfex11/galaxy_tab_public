동기: CUA 평가의 근본적 문제

컴퓨터 사용 에이전트(CUA)는 웹, 모바일, 데스크톱 등 디지털 환경 전반에서 빠르게 발전하고 있습니다. 궤적(trajectory)은 에이전트의 행동, 상태, 추론이 교차된 기록입니다.

이 궤적이 과제 지시를 실제로 수행했는지 검증하는 것은 평가, 데이터 큐레이션, 강화 학습의 핵심입니다.

하지만 기존 방법에는 치명적 한계가 있습니다:

  • 인간 작성 검증기는 소수의 정제된 과제만 커버
  • 실시간 환경이 없는 정적 코퍼스에는 적용 불가
  • 인간 주석은 규모 확장이 불가능
  • VLM 판사의 신뢰성은 검증되지 않음

핵심 질문

VLM 판사들은 CUA 궤적을 판단하는 데
충분히 신뢰할 수 있는가?

최고의 VLM 판사조차 기존 벤치마크 검증기와 약 25%의 데스크톱 판정에서 불일치

기존 에이전트 벤치마크의 궤적을 재사용하면 판사 오류와 실행 오류가 혼재

체계적인 연구를 위한 전용 벤치마크가 전무한 상황

OSReward: 벤치마크 구축

기존 궤적 재사용 대신, 전용 크로스 플랫폼 데이터 인프라를 처음부터 설계하여 구축했습니다.

1
환경 준비
Web, Windows, Ubuntu, Android 4개 플랫폼의 순수 환경 구축
2
과제 지시 작성
환경 기반의 검증된 지시어 큐레이션
3
궤적 수집
4개 모델 패밀리가 실행하여 성공/실패 궤적 확보
4
다단계 인간 주석
엄격한 심사를 거친 골드 라벨 획득

최종 결과: 1,019개의 인간 골드 궤적 (최대 100스텝의 장기 수행)

크로스 플랫폼 데이터 인프라

Web

실제 웹사이트 탐색, 폼 작성, 정보 검색 등 브라우저 기반 과제

Windows

데스크톱 앱 조작, 파일 관리, 일반 및 전문 응용 프로그램 과제

Ubuntu

CLI+GUI 혼합 워크플로우, 터미널 명령, 시스템 설정 과제

Android

모바일 앱 탐색, 설정 변경, 알림 관리 등 모바일 환경 과제

일반 앱(Chrome, VS Code 등)뿐 아니라 전문 앱(Adobe, Office 등)까지 실제 사용자 환경을 반영한 현실적 시작 상태 제공

OSReward의 세 가지 변형

Full Set OSReward

  • 1,019개 인간 골드 궤적
  • 4개 플랫폼 전체 커버
  • 이진 성공/실패 판정
  • 평가의 폭(breadth) 제공

Challenge OSReward-Hard

  • 주석자 간 분기된 난이도 높은 사례
  • 현재 판사가 공통적으로 실패하는 케이스
  • 오류 모드 진단에 특화
  • 남은 성능 여유(headroom) 노출

Fine-Grained OSReward-Multi

  • 이진 판정 위에 세분화 라벨
  • 효율성(efficiency) 점수
  • 의도 정렬(align ment) 점수
  • 정밀한 등급 평가 가능

VLM 판사 벤치마킹 결과

전체 세트(OSReward)

프론티어 모델(Claude-Opus-4-8, GPT-5.5 등)은 전체 세트에서 비교적 양호한 성능을 보입니다.

OSReward-Hard

최고 판사도 70% 미만으로 급락

평균 판사는 52%에 불과 → 거의 무작위 수준

개방–폐쇄 격차

모델 유형 Full 정확도 Hard 정확도
Claude-Opus-4-8 ~89% ~69%
GPT-5.5 ~87% ~67%
개방 모델 평균 ~70% ~45%

27개 모델 대상, 역대 최대 규모 CUA 판사 평가

핵심 발견: 관대성 편향 (Leniency Bias)

가짜 성공 (False Success)

에이전트가 "작업 완료"를 선언하지만 실제로는 실패한 경우

VLM 판사는 이를 성공으로 압도적으로 잘못 수용

모든 모델이 공유하는 지배적 오류 유형

엄격–관대 평면

거짓 부정(false negative)보다 거짓 긍정(false positive)이 압도적으로 많음

Hard 세트에서 이 편향이 더욱 확대됨

판사는 화면보다 에이전트의 서사(narrative)를 더 읽음

신뢰할 수 있는 판사는 너무 비싸고, 저렴한 개방 모델은 너무 부정확하다.
신뢰성과 저렴함을 모두 갖춘 판사가 존재하지 않는다.

분석: 판정을 결정하는 것은 무엇인가

시각 입력

스크린샷 유무가 판정에 거의 영향을 주지 않음

텍스트 기록만으로도 유사한 판정 → 시각 정보 활용 부족

텍스트 기록

에이전트의 텍스트 기록이 판정의 주요 근거

서사에 쉽게 속아 관대성 편향 발생

실행 방식

프롬프트 변경, 체인 오브 사고, 자기 일관성 등 어느 것도 근본적 해결 안 됨

편향은 실행 방식이 아닌 모델 자체의 문제

신뢰할 수 있는 판정의 비용: Claude-Opus-4-8 기준 1회 판정 약 $0.15 → 백만 건 판정 시 ~$150,000

OS-Shepherd-100K: 개방형 학습 코퍼스

판사 평가의 발견을 바탕으로, 새로운 인간 주석 없이 라벨링 전략을 설계하여 구축한 100K 규모의 추론 주석 궤적 판정 코퍼스입니다.

  • 300K+ 판사 인스턴스에서 거르고 정제
  • 다양한 에이전트 백본, 시나리오, 과제 유형 포함
  • 성공과 실패 모두 풍부하게 포함
  • 실패 유형(failure type) 주석 포함
  • 합성 지시어 및 네거티브 샘플 포함
100K

추론 주석 판정 샘플

4

플랫폼 커버

300K+

원본 판사 인스턴스

OS-Shepherd: 학습과 성능

1
SFT 단계

2
RL 단계
가짜 성공(false success)을 직접 타겟으로 디바이싱

OS-Shepherd-9B

상용 판사 대비 30~60배 저렴하면서 유사한 정확도 달성

OS-Shepherd-35B

규모 확장의 이득은 제한적 — 9B로도 충분한 가성비

비용–정확도 프론티어에서 OS-Shepherd는 가장 저렴한 점으로,
상용 판사에 근접하는 성능을 학술 예산으로 제공합니다.

기존 벤치마크로의 일반화

판사 vs 인간 작성 검증기

기존 벤치마크(OSWorld, WindowsAgentArena 등)의 인간 작성 검증기와 VLM 판사 간에도 상당한 불일치가 존재합니다.

이 불일치가 판사의 문제인지 검증기의 문제인지를 논의합니다.

OS-Shepherd의 전이

  • 실패 잡기(catching failures)가 잘 전이
  • 보지 못한 벤치마크에서도 관대성 편향 디바이싱 효과 유지
  • 확장 가능한 검증자(scalable verifier)를 향한 방향성 제시

기여 요약

OSReward 벤치마크

전용 인프라에서 구축한 크로스 플랫폼 CUA 보상 신호 표준 평가 세트. Hard 챌린지 세트와 Multi 세분화 세트 포함.

포괄적 VLM 판사 평가

27개 모델 대상 역대 최대 규모 평가. 관대성 편향, 시각 정보 미활용, 난이도 붕괴 등 핵심 발견.

OS-Shepherd-100K 데이터셋

100K 추론 주석 판정 코퍼스. 실패 유형 주석 포함, 커뮤니티에 완전 공개.

OS-Shepherd 모델 (9B, 35B)

개방형, 저비용, 자체 호스팅 가능한 보상 모델. 상용 판사 대비 30~60배 저렴하며 유사 정확도.

결론

CUA 궤적 판단에서 VLM 판사는 체계적인 관대성 편향을 공유하며, 신뢰할 수 있는 판사는 비용이 너무 높습니다.

OSReward는 이 문제를 체계적으로 연구하기 위한 표준화된 벤치마크를 제공하고, OS-Shepherd는 학술 예산 내에서 안정적이고 신뢰할 수 있는 보상 신호를 실현합니다.

평가, 데이터 큐레이션, 강화 학습에 필요한 백만 건 규모의 판정이 이제 개방형 모델로 가능해졌습니다.
