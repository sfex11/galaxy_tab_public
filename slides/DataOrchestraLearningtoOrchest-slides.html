Pretraining Data Processing for Large Language Models

배경

사전학습 데이터의 중요성

데이터가 모든 것을 결정

LLM의 하위 성능은 모델 구조보다 사전학습 데이터의 품질에 더 크게 의존합니다. 데이터 처리 전략은 최종 모델 성능을 좌우하는 핵심 요소입니다.

데이터 처리 파이프라인

중복 제거, 품질 필터링, 민감 정보 제거 등 다양한 전처리 단계가 적용되며, 각 단계의 선택이 데이터 구성에 지대한 영향을 미칩니다.

"사전학습 데이터 처리는 LLM의 하위 성능에 결정적인 역할을 합니다."

문제 제기

기존 접근법의 한계

고정된 처리 전략

코퍼스 또는 도메인 단위로 하나의 고정된 처리 전략을 정의하고, 수많은 예시에 동일하게 적용합니다.

개별 예시 무시

각 예시의 고유한 특성과 필요에 맞춤형으로 적응하지 못하는 근본적 한계가 존재합니다.

핵심 질문: 각 예시의 특성에 맞게 데이터 처리를 개별화할 수 있는가?

핵심 아이디어

DataOrchestra의 제안

사전학습 데이터의 각 예시마다 최적의 큐레이션 전략을 학습하여 자동으로 오케스트레이션하는 프레임워크입니다.

  • 코퍼스/도메인 단위가 아닌 예시 단위(Per-Example)의 큐레이션
  • 각 예시의 특성에 맞는 처리 전략 자동 선택
  • 하위 성능 향상을 목표로 하는 학습 기반 오케스트레이션

"Learning to Orchestrate Per-Example Curation of Pretraining Data"

각 단계는 예시별로 독립적으로 결정되며, 전체 파이프라인은 하위 성능을 최대화하도록 학습됩니다.

방법론

예시별 큐레이션 전략

A

품질 필터링

예시의 품질 점수에 따라 임계값을 동적으로 조정하여 보존 여부를 결정

B

중복 처리

예시의 유사도 패턴에 따라 중복 제거 강도를 개별적으로 설정

C

도메인 믹싱

예시의 도메인 특성에 맞게 샘플링 가중치를 동적으로 할당

각 전략은 독립적이면서도 상호 보완적으로 작동하며, 오케스트레이터가 최적의 조합을 학습합니다.

학습 메커니즘

오케스트레이터 학습 방식

학습 신호

하위 작업의 성능을 직접적인 보상으로 사용하여, 최종 모델 품질을 최대화하는 방향으로 정책을 학습합니다.

정책 아키텍처

예시의 특성을 입력으로 받아, 각 처리 전략에 대한 할당 확률을 출력하는 학습 가능한 오케스트레이터 네트워크를 구성합니다.

예시 입력 → 특성 추출 → 정책 네트워크 → 전략 할당 → 처리 수행 → 하위 성능 평가 → 정책 업데이트

핵심 기여

연구의 주요 기여점

기여 1

사전학습 데이터 처리를 예시 단위로 개별화하는 새로운 패러다임을 제안합니다.

기여 2

하위 성능을 직접적인 학습 신호로 활용하는 오케스트레이션 학습 프레임워크를 제공합니다.

기여 3

고정 전략 기반 방법들 대비 일관된 성능 향상을 실험적으로 입증합니다.

기여 4

다양한 도메인과 코퍼스에 대해 범용적으로 적용 가능한 확장 가능한 설계를 제공합니다.

의의

연구의 시사점

패러다임 전환

"하나의 크기가 모두에게 맞다(One-size-fits-all)"는 데이터 처리 관행에서, 개별 예시에 맞춘 정밀한 큐레이션으로의 전환을 제시합니다.

향후 방향

데이터 처리 파이프라인 전체를 학습 가능한 컴포넌트로 재구성하는 방향으로, LLM 사전학습의 새로운 설계 원칙을 제시합니다.

"모델 아키텍처의 발전만큼, 데이터 큐레이션의 지능화가 LLM 발전의 다음 프론티어입니다."
