  • 아키텍처는 LLM의 스케일링 동작을 결정합니다
  • 학습 효율과 추론 비용에 직접적인 영향을 미칩니다
  • 산업계와 학계 모두의 핵심 연구 대상입니다

DeepSeek · Qwen · Kimi 등 산업계의 지속적인 아키텍처 혁신

새로운 설계 검증에는 고비용 학습 실험이 수반

그러나 실험과 트레이드오프의 내역은 공개되지 않음

문제 1: 산업계 — 검증 과정의 기록 부재

공개 보고서의 한계

어떤 아이디어가 성공했고, 어떤 아이디어가 포기되었는지, 그 이유가 문서화되지 않습니다

커뮤니티의 손실

검증 과정의 완전한 공개 기록은 새로운 아이디어 그 자체만큼 후속 연구에 가치가 있습니다

"열린 아키텍처 혁신 이면의 실험 기록은 공유되지 않아,
커뮤니티는 아이디어의 성패와 근거를 학습할 수 없습니다."

문제 2: 학계 — 가시성과 검증 기회의 부족

~1/3

전체 아키텍처 논문 중 학술 연구가 차지하는 비율

< 10%

학술 연구가 받는 인용 비율 — 주목은 산업계에 집중

  • 제한된 컴퓨트로 소규모 단일 지점 비교에 머무름
  • 일관된 베이스라인 부재로 공정한 비교가 어려움
  • 더 큰 스케일에서 개선이 유지되는지 확인 불가

해결책: ArchSpace의 3R 프레임워크

1

Recording
기록

각 제안을 실험 결과와 설계 근거와 함께 공개 기록

2

Reviewing
검토

커뮤니티가 결과가 결론을 뒷받침하는지 검증

3

Referencing
인용

후속 연구가 기록을 인용하고 확장하며 발전

검증된 아이디어는 다시 새로운 베이스라인이 되어 선순환 구조를 형성합니다

PR은 구현, 설정, 체크포인트, 학습 로그, 평가 결과, 재현 지침뿐 아니라 실패한 시도와 탐색 선택까지 기록하여 결론에 이른 과정을 추적 가능하게 합니다

Phase I: 스케일링 사다리와 3가지 검증 설정

학습 FLOPs 사다리 1×1018 → 3×1018 → 1×1019 → 3×1019 → 1×1020에서 베이스라인과 동일한 데이터·토크나이저로 비교

설정구성스케일링 법칙 피팅총 FLOPs
Setting 1
베이스라인-최적 지점		 베이스라인의 LR·BS 재사용 L̂(C) 1.4×1020
Setting 2
IsoFLOP 크기 스윕		 버드당 4–6개 모델 크기 L̂(M, D) 7.2×1020
Setting 3
LR/BS 튜닝 IsoFLOP		 LR·BS 4×4 그리드 탐색 L̂(M, D, η, B) 1.2×1022

정밀도↑ = 비용↑: 예산과 검증 신뢰도 사이의 균형을 선택 가능

Phase II: 1B 모델 학습 레시피

스케일링 사다리 이후, 1.2–1.5×1021 FLOPs 규모의 실제 학습으로 이득의 지속성을 확인합니다

150B 토큰 사전학습

  • Dolma 3 Pool 샘플 150B 토큰
  • 8K 컨텍스트
  • Base Main 평가 수행

10B 토큰 롱컨텍스트 미드트레이닝

  • Dolma 3 Longmino Mix (50B)
  • 64K 컨텍스트 확장
  • Base Long-Context 평가 추가

베이스라인과 동일한 데이터·컨텍스트 스케줄·토큰 수로 공정한 비교를 보장

스케일링 법칙 기반 예측 방법론

1
2단계 피팅 — 손실 곡면을 안정적으로 추정하기 위해 피팅을 두 단계로 분리
2
최소 손실 모델링 — 모델 크기(M)와 데이터 규모(D)에 따른 최소 도달 손실을 표현
3
LR–BS 항 모델링 — 최적 학습률·배치 크기에서 벗어났을 때의 손실을 cosh 형태로 포착
4
예측 최적값 활용 — 컴퓨트-최적 모델 크기·데이터량과 최적 LR·BS를 미리 예측하여 탐색 비용 절감

작은 규모 실험만으로 더 큰 스케일에서의 손실을 예측 — 산업계에서 이미 표준으로 쓰이는 관행을 공개 검증 체계로 이식

옵티마이저·초기화·스케줄·탐색 그리드까지 문서화

  • 플랫폼이 처음부터 바로 사용 가능하도록 참조 자원 제공
  • 검증을 통과한 아이디어는 새 베이스라인으로 축적되어 후속 연구의 기반이 됨

목표: 아키텍처 연구의 공유 기반

PR = 연구 논문

검토를 통과한 PR이 전통적인 연구 논문과 동등한 위상을 갖고, ArchSpace 내 기여 소통·인용의 주된 수단이 되도록 지향

아이디어 계보 추적

후속 PR이 이전 기여를 링크하여 아이디어가 연구 간에 발전하는 과정을 추적 가능

  • 학술 아이디어의 가시성과 인정 확대 — 인용 격차 해소
  • 열린 문서화된 연구 과정으로 더 폭넓은 아이디어가 다음 세대 모델에 기여
  • 커뮤니티 검증을 통과한 신뢰할 수 있는 비교 문화 정착

결론

ArchSpace는 기록 · 검토 · 인용을 아우르는 공개 플랫폼으로, 스케일링 법칙 기반의 2단계 검증 프레임워크와 공개 베이스라인을 통해 아키텍처 연구의 투명성과 재현성을 높입니다.
