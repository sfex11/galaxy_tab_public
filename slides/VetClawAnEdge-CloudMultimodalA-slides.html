VetClaw

엣지-클라우드 멀티모달 에이전트 시스템을 활용한
수의학 질병 조기 선별

Syed Mhamudul Hasan · Anas AlSobeh · Hussein Zangoti · Abdur R. Shahid

Southern Illinois University · Utah Valley University · Jazan University

문제 인식

동물 생물보안의 중요성

전염성 질병이 축산 군집 내로 확산되면 피부병이 주요 임상 징후로 나타남. 조기 발견이 핵심이지만, 현장에서의 신속한 선별 도구가 부족함.

진단의 근본적 한계

동물은 증상을 언어로 표현할 수 없으며, 질병 양상이 종·해부학·생리·행동에 따라 크게 달라져 단일 모달리티로는 정확한 판단이 어려움.

정적 예측 모델에서 벗어나, 도구 활용·워크플로우 관리·실패 처리·불확실 사례 에스컬레이션이 가능한 시스템이 필요함.

해결 접근법

VetClaw는 정적 이미지 분류를 조율된 안전 인식 시스템으로 변환함

1

시각 증거 수집

Raspberry Pi 카메라로 동물 이미지 캡처

2

멀티모달 추론

이미지 + 증상 텍스트를 서버 VLM에 전송

3

안전 규칙 검토

결정론적 안전 규칙으로 결과 검증 후 알림 생성

최종 출력은 조기 선별 알림이며, 임상 진단이 아님을 명확히 구분

배경 기술

OpenClaw

오픈소스 자율 에이전트 프레임워크. LLM, 외부 도구, 로컬 스크립트, 스케줄링, 통신 채널 간 인터페이스 제공.

LangGraph

상태 유지 LLM/에이전트 워크플로우를 위한 그래프 기반 프레임워크. 노드 간 결정론적·조건부 전환으로 워크플로우 표현.

멀티모달 AI

텍스트·이미지·오디오·비디오 등 다양한 데이터 유형을 처리하고 추론하는 시스템. VLM은 시각+언어를 결합한 특정 유형.

VetClaw는 이 세 기술을 엣지-클라우드 아키텍처 내에서 각각의 강점에 맞게 분리 배치하여 통합

관련 연구와 차별성

연구 분야 한계

Darvesh et al. IoT + ML 축산 모니터링 에이전트 오케스트레이션 없음

세 가지 기여

VetClaw 시스템 설계 및 구현

OpenClaw 기반 엣지-클라우드 에이전트 워크플로우. Raspberry Pi 카메라 캡처 → 서버 VLM 추론의 완전한 파이프라인 구축.

다중 설정 제로샷 평가

2개 VLM × 3가지 입력 설정(이미지 전용·텍스트 전용·텍스트+이미지) × 2개 공개 수의학 데이터셋에 대한 체계적 평가.

증상 기반 멀티모달 융합 분석

텍스트 안내 VLM 추론이 이미지 전용 예측을 개선함을 입증. 동시에 정보 누출 및 안전 리스크를 식별하고 제어된 프롬프팅의 필요성을 제시.

시스템 아키텍처 개요

엣지 레이어

  • Raspberry Pi + Camera Module 3
  • OpenClaw (에이전트 인터페이스)
  • 경량 로컬 LLM (명령 해석용)
  • LangGraph (워크플로우 오케스트레이션)

센싱 · 스케줄링 · 검증 · 통신 · 알림 수행

서버 레이어

  • FastAPI 엔드포인트 (요청 검증)
  • 서버 호스팅 VLM (멀티모달 분류)
  • 영속 로깅 및 스토리지 서비스

계산 집약적 VLM 추론 수행

대형 VLM을 Raspberry Pi에 직접 배포할 수 없으므로, 엣지-클라우드 분리 아키텍처 채택

에이전트 워크플로우 상세

1
스케줄링
OpenClaw가 선별 작업 트리거
2
이미지 캡처
카메라 도구 호출 → 타임스탬프 저장
3
입력 검증
이미지 유효성 확인, 증상 텍스트 유무 판단
4
조건부 라우팅
이미지 전용 또는 텍스트+이미지 분기
5
VLM 추론
FastAPI → 서버 VLM 호출
6
안전 검토
응답 형식 검증 + 결정론적 안전 규칙 적용
7
조건부 처리
통과 → 알림 / 실패 → 재시도·재촬영·인간 검토
8
알림 전달
OpenClaw가 구조화된 로그 기록 후 알림 발송

핵심 설계 원칙: VLM은 추론 도구일 뿐 워크플로우 제어자가 아님. 결과를 전달·억제·재시도·에스컬레이션할지는 LangGraph가 결정.

데이터셋 및 평가 설정

데이터셋

Pet Disease Images

1,736장의 이미지, 22개 질병 카테고리 분포

Dogs Skin Disease Dataset

개 피부병 전용 공개 이미지 데이터셋

평가 설정

  • 입력 유형: 이미지 전용 / 텍스트 전용 / 텍스트+이미지
  • VLM 모델: 2종 서버 호스팅 VLM 비교
  • 방식: 제로샷 분류 (파인튜닝 없음)
  • 하드웨어: Raspberry Pi (엣지) + 원격 서버 (클라우드)

성능 평가 결과

입력 설정 제로샷 분류 성능 특징
이미지 전용 제한적 VLM 단독 시각 예측만으로는 정확도 부족
텍스트 전용 중간 증상 텍스트만으로도 일정 수준 분류 가능
텍스트 + 이미지 개선됨 멀티모달 융합이 이미지 전용 대비 성능 향상

증상 기반 텍스트 안내가 VLM의 제로샷 분류 성능을 이미지 전용 예측보다 개선시킴. 그러나 증상 텍스트에 질병 라벨이 포함될 경우 정보 누출 리스크 존재.

핵심 발견과 시사점

긍정적 발견

  • 멀티모달 입력이 단일 모달리티 대비 우수
  • 에이전트 오케스트레이션으로 안전 제어 가능
  • 엣지-클라우드 분리가 실제 배치 가능성 입증
  • 제로샷 설정에서도 의미 있는 성능 달성

주의 사항

  • 증상 텍스트에 질병 라벨 포함 시 정보 누출 위험
  • 제어된 프롬프팅과 규칙 기반 검토 필수
  • 최종 출력은 조기 선별 알림, 임상 진단 아님
  • 불확실 사례의 자동 에스컬레이션 메커니즘 필요

핵심 메시지: VLM 자체의 성능보다, VLM을 안전하게 래핑하는 에이전트 시스템의 설계가 더 중요

한계점

데이터 제약

공개 수의학 이미지 데이터셋의 규모와 다양성이 제한적. 더 많은 종과 질병 카테고리에 대한 검증이 필요함.

네트워크 의존성

엣지-클라우드 구조상 원격 서버와의 네트워크 연결이 필수적. 오프라인 환경에서는 VLM 추론 불가.

정보 누출 문제

증상 텍스트에 질병 이름이 포함되면 제로샷 평가의 의미가 훼손됨. 프롬프트 설계에 세심한 주의 필요.

임상 검증 부족

실제 수의사와의 협업 평가 미수행. 조기 선별 알림의 실제 임상 유용성은 추가 연구 필요.

결론

VetClaw는 정적 예측 모델을 도구 활용, 워크플로우 관리, 실패 처리, 불확실 사례 에스컬레이션이 가능한 조율된 안전 인식 시스템으로 변환함.

  • OpenClaw + LangGraph의 책임 분리 설계가 추적 가능성과 재현성을 향상
  • 증상 안내 멀티모달 입력이 이미지 전용 제로샷 분류보다 우수
  • 엣지-클라우드 아키텍처로 실제 축산 현장 배치 가능성 입증
  • 결정론적 안전 규칙 기반 검토로 부적절한 결과 전달 방지

향후 방향: 더 다양한 종·질병 데이터 확장, 오프라인 추론 지원, 수의사 협업 임상 검증, 실시간 비디오 스트리밍 통합
