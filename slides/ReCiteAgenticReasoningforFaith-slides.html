ReCite: Agentic Reasoning
for Faithful Citation

충실한 인용을 위한 에이전틱 추론 프레임워크

  • 정확한 인용은 학술 논문 작성의 기반 — 지적 기원을 추적하고 핵심 주장을 뒷받침
  • LLM이 학술 텍스트를 작성하면서 "그럴듯하지만 틀린 참고문헌"이라는 심각한 리스크 등장
  • 핵심 주장: 인용은 유사도 기반 검색이 아닌 능동적인 claim 수준의 추론 과제

문제 정의: 인용 환각의 두 가지 형태

RAG 아키텍처로 조작(Fabrication)은 크게 해결되었지만, 잘못된 귀속(Misattribution)은 여전히 미해결

Fabrication · 해결됨

존재하지 않는 논문 조작

없는 논문을 지어내는 문제. 검색 증강 아키텍처로 대부분 해소 — 실제 데이터베이스만 검색하면 발생하지 않음

Misattribution · 미해결

잘못된 논문 인용

실제 존재하지만 저자의 주장을 논리적으로 뒷받침하지 못하는 논문을 인용하는 문제. 의미 유사도 기반 검색의 근본 한계

단일 방향 파이프라인 구조에서는 한 번의 잘못된 검색이 되돌릴 수 없는 오류가 됨 — 자기 교정의 기회가 없음

핵심 통찰: 인용은 검색이 아니라 추론

주제적 관련성(topical relevance)이 논리적 뒷받침(logical support)을 보장하지 않는다

예시 "NLP에서 Transformer의 성공"이라는 주장을 뒷받침할 논문은?

Vision Transformer (Dosovitskiy et al., 2021)

텍스트적 중첩은 높지만 논리적 지지 없음 → 오인용

Attention Is All You Need (Vaswani et al., 2017)

주장의 논리적 기둥 → 올바른 인용

Misattribution 해결을 위한 3가지 요구사항

  • 의도 인식 검색 — 인용 맥락(배경 소개 vs 방법 비교)마다 검증 기준이 다름
  • Claim 수준 검증 — 후보 논문이 주장을 실제로 논리적으로 지지하는지 확인
  • 반영적 루프 — 오류 복구를 위한 재검색 메커니즘

CAP-8: 8범주 인용 의도 분류

인용 맥락마다 요구되는 검증 기준이 다르므로, 의도 분류가 쿼리 계획과 검증의 기반이 됨

BG 배경 (Background) — 연구 도메인의 배경 지식 제공
MG 동기·격차 (Motivation & Gap) — 연구 동기 제시 또는 기존 문헌의 한계 식별
CMP 비교 (Comparison) — 현재 연구나 베이스라인과 선행 방법 비교
BS 기반·지지 (Basis & Support) — 이론적 토대나 개념적 지지 제공
MTD 방법·데이터 (Method & Data) — 활용된 방법·알고리즘·도구·데이터셋 참조
VLD 검증 (Validation) — 실증적 증거·결과·평가 지표로 주장 검증
EV 발전 (Evolution) — 방법론의 역사적 발전 과정 서술
CRT 비판 (Critique) — 선행 연구에 대한 비판·갈등·반론 제기

방법론: 3개 모듈

CiteLocator

논리적 분절점 인식

인용이 모두 제거된 문단에서 정당한 인용 위치마다 [#CITE#] 마커를 복원하는 시퀀스 복원 과제로 공식화

위치 + 필요성 주석 포함

QueryPlanner

의도 인식 쿼리 계획

예측된 인용 의도(CAP-8)를 조건으로 목적에 맞는 검색 키워드 생성. 맥락과 정렬된 검색 수행

Intent → Keywords

Master Brain

태스크 오케스트레이션

후보 논문과 claim의 논리적 일관성 검증 후 최종 인용 결정. 실패 시 원인 분석 → 쿼리 재작성 → 재검색

폐루형 자기 교정

학습: 합성된 추론 궤적(Reflective Trajectory Synthesis)으로 SFT 수행 후, 핵심 모듈에 GRPO (Group Relative Policy Optimization) 강화학습 적용

실험: 주요 결과

경량 프레임워크(Qwen3-4B)가 최신 대형 생성 모델을 엄격한 인용 정확도(strict citation accuracy)에서 능동

베이스라인
Zero-shot LLM · 범용 에이전트(ReAct, Reflexion) · 휴리스틱/인간 기준

모듈 수준 평가
CiteLocator(위치 인식) · QueryPlanner(쿼리 계획) 개별 성능 검증

핵심 발견
기존 LLM에게 인용 추론이 본질적으로 어려운 과제임을 입증

의미적 중복(semantic overlap)에 의존하는 범용 생성 모델과 달리, 검증 가능한 논리에 기반한 매칭으로 진위 구분 성공

소거 실험 및 심층 분석

소거 실험 (Ablation)

  • Claim-Evidence 검증 제거 시 성능 저하 → Misattribution 방지에 필수
  • 의도 기반 계획 제거 시 검색 품질 저하 → 맥락 정렬에 필수
  • 반영 루프 제거 시 오류 복구 불가 → 세 모듈 모두 indispensably 상호 보완적

심층 분석

  • 교차 범.Cross-venue 데이터에서도 강건한 성능
  • 의도별 재현율 분석 — 의도 조건화가 검색 정밀도 향상
  • 검색 후보 수 분석 — 후보량과 검증 정확도 간 상호작용 규명

세 메커니즘의 결합이 폐루형 신뢰 인용의 핵심 설계임을 정량적으로 확인

결론 및 기여

문제 재정의 — 인용 환각을 조작(fabrication)과 오인용(misattribution)으로 체계적으로 분해하고, LLM 시대의 핵심 과제로 오인용을 확립. 인용을 추론 과제로 재프레임

ReCite 제안 — 최초의 폐루형 claim-evidence 검증 프레임워크. 의도 기반 쿼리 계획과 반영적 재검색 루프 통합

실증 검증 — 현재 LLM에게 인용 추론이 본질적으로 어려움을 밝히고, ReCite의 유효성을 실험으로 입증

문헌 매칭을 의미적 중첩이 아닌 검증 가능한 논리에 기반시켜, 자동 학술 작문의 신뢰할 수 있는 토대를 구축
