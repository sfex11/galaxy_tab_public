A Vision-Centric Multimodal LLM System for Holistic Medical Understanding

항지에 원 · 치천 칸 · 지웨이 탕 외 | DAMO Academy, Alibaba Group · Tsinghua University · Zhejiang University

도입: 의료 MLLM의 핵심 도전

의료 분야에서 MLLM을 성공적으로 배포하는 것은 근본적으로 비전 중심(vision-centric) 과제다.

시각 지식 흡수

X-ray, 병리 슬라이드, 안저 이미지 등 이종 2D와 CT, MRI 등 3D 체적 데이터를 네이티브로 처리하고 내면화해야 함

비전 기반 평가

표면적 텍스트 매칭을 넘어, 영역 수준의 분석을 통해 실제 진료 실무를 반영하는 평가 체계가 필요함

기존 접근법의 한계

문제 1 단일 모놀리식 인코더

Lingshu, Hulu-Med 등은 데이터 중심 접근에 집중하며, 기저 비전 아키텍처는 단일 인코더로 유지

문제 2 2D 강제 변환

3D 볼륨을 밀집 슬라이스로 샘플링하여 2D로 처리 → 핵심 3D 구조 정보 손실

문제 3 평가의 임상 부적합

BLEU, ROUGE 등 표면적 매칭 지표는 환각·누락을 정밀하게 분해하지 못함

Cambrian-1의 병렬 설계는 네이티브 3D 인코더와 유도적 퓨전 메커니즘을 모두 갖추지 못함

ClinFusion 시스템 개요

1
조합형 비전 인코더
기저 + 전문가 2D 앙상블 + 네이티브 3D 인코더
2
CaSL 퓨전
계층적 연쇄적 특징 풍부화 및 2D-앵커 3D 정렬
3
LLM 백본
융합된 비전 표현을 통합적 의료 추론에 활용
4
에이전트 도구
지식 검색 + 전문 시각 분석 도구 통합

비전 기반 평가 프레임워크

  • MedIF-Bench: 지시 수행 능력 평가
  • RoI-기반 리포트 평가: 사실성 중심 분해

단계적 훈련 전략

  • 대규모 고품질 시각 학습 신호 확보
  • Instruction Warping, Dense Caption, CoT 등

조합형 비전 인코더 아키텍처

2D 전문가 앙상블

  • 기저 비전 트랜스포머 (잘 정렬된 기초 표현)
  • 전문가 2D 인코더 군 (모달리티 특화 지식)
  • 계층적 연쇄적 상호작용으로 점진적 특징 풍부화

네이티브 3D 인코더

  • 전용 3D 인코더로 체적 데이터 직접 처리
  • 밀집 슬라이스 샘플링의 구조 정보 손실 방지

기존 병렬 설계 vs ClinFusion

구분 병렬 설계 ClinFusion
2D 인코더 간 독립 처리 연쇄적 풍부화
3D 처리 미지원 네이티브 지원
2D→3D 정렬 없음 2D-앵커 유도

CaSL 퓨전 메커니즘

Cascade Spatial-Aware Locality Fusion (카슬, /ˈkɑːsəl/)

2D 인코더 간 연쇄적 퓨전

1
기저 인코더가 초기 정렬된 시각 표현 생성
2
전문가 1의 지식이 기저 표현을 공간 인식 방식으로 풍부화
3
전문가 2가 풍부화된 표현을 다시 한번 증강

→ 각 단계에서 정렬 보존, 점진적 지식 축적

2D-앵커 깊이 인식 퓨전

  • 잘 정렬된 2D 특징이 앵커 역할
  • 3D 특징을 2D 공간에 투영하여 정렬 유도
  • 깊이(depth) 정보를 인식하는 퓨전 연산
  • 3D 인코더의 복잡한 정렬 절차 불필요

핵심 아이디어: 2D 모달리티에서 이미 확보된 정렬을 3D로 전이하여 학습 부담 감소

비전 기반 평가 프레임워크

신규 MedIF-Bench

의료 맥락에서의 지시 수행 능력 평가 벤치마크

  • 도메인 특화 파인튜닝으로 저하되는 지시 수행 능력 측정
  • 복잡하고 실용적인 의료 지시 실행 평가
  • 임상 배치를 위한 필수 전제 조건 평가

신규 RoI-기반 리포트 평가

관심 영역(Region-of-Interest)에 기반한 사실성 중심 평가

  • 환자 임상 맥락(의뢰 사유, 병력)을 반영한 지시 제공
  • 일치(Matched) · 누락(Missed) · 환각(Hallucinated) 정밀 분해
  • 실제 방사선과 의사 판단과 강한 상관관계 확인
기존 평가: 모델에게 "종합 리포트 작성" 지시 → 참고 리포트와 텍스트 매칭
ClinFusion 평가: 환자 맥락 기반 지시 → 해부학적 영역별 사실성 분해 평가

3D 및 텍스트 벤치마크 평가 결과

3D 멀티모달 벤치마크

  • 네이티브 3D 인코더의 효과가 3D VQA 벤치마크에서 직접적으로 검증
  • 2D 슬라이스 기반 접근법 대비 구조적 이해 능력 월등
  • CT, MRI 체적 데이터에서 의미적 추론 성능 크게 향상

텍스트 의료 벤치마크

  • 비전 중심 설계에도 불구하고 텍스트 의료 과제에서도 경쟁력 유지
  • 멀티모달 학습이 텍스트 의료 지식에도 긍정적 전이 효과
  • MedIF-Bench에서 지시 수행 능력이 특히 두드러짐
ClinFusion은 2D · 3D 멀티모달 벤치마크뿐 아니라 텍스트 의료 과제까지 포괄하는 전방위적 홀리스틱 이해를 달성함

전문가 방사선과 의사 임상 검증

블라인드 평가 설계

  • 보드 인증 전문 방사선과 의사 참여
  • 모델 식별자 마스킹된 블라인드 설정
  • ClinFusion이 최고 순위 리포트 생성으로 선정

평가 지표 상관관계

  • RoI-기반 지표가 전문가 판단과 가장 강한 상관관계
  • BLEU, ROUGE, BERTScore 등 기존 지표보다 월월히 우수
  • GREEN, RadGraph-F1보다도 정밀한 사실성 분해
평가 지표 전문가 판단 상관관계 사실성 분해
BLEU / ROUGE / CIDEr 낮음 불가
RadGraph-F1 / RaTEScore 중간 제한적
GREEN (LLM-based) 중간 정확도·완전성 혼합
RoI-기반 지표 (제안) 가장 강함 일치·누락·환각 정밀 분해

설계 분석 및 절제 연구

RoI-기반 리포트 생성 분석

  • 환자 맥락 제공 시 환각률 감소 확인
  • 특정 해부학적 영역에 집중하도록 유도 가능
  • 임상 실무와 정렬된 리포트 구조 생성

아키텍처 절제 연구

  • CaSL 연쇄적 퓨전 제거 시 성능 현저히 저하
  • 단일 인코더 대비 조합형 설계의 이점 명확
  • 2D-앵커 3D 정렬이 독립 3D 정렬보다 효율적
핵심 발견: 단순히 더 많은 인코더를 병렬로 추가하는 것만으로는 부족하며, 계층적 연쇄적 풍부화와 2D-앵커 유도 정렬이 성능 향상의 핵심 메커니즘임

에이전트 도구 사용 확장

MLLM의 한계 — 정적 지식, 추적 불가능한 추론, 전문 태스크에서의 인식 병목 — 을 도구 사용으로 극복

지식 도구 (Knowledge Tools)

증거 기반 검색을 위한 하이브리드 리트리벌

  • 다원 소스 교차 집적(Cross-Source Aggregation)
  • 의료 지식 베이스 실시간 조회
  • 추론의 근거 추적성 확보

인식 도구 (Perception Tools)

전문 시각 분석을 위한 전문가 AI 모델 호출

  • 특정 태스크에 특화된 전문 모델 라우팅
  • 분할, 검출 등 세밀한 시각 분석 위임
  • MLLM의 인식 병목 해소

결론 및 요약

핵심 기여

조합형 비전 인코더 + CaSL 퓨전으로 이종 2D/3D 의료 영상의 네이티브 통합 처리
비전 기반 평가: MedIF-Bench와 RoI-기반 리포트 평가로 임상 실무 정렬
오픈소스·상용 모델 대비 포괄적 SOTA 및 전문가 검증 완료
에이전트 도구 사용으로 검색 증강 및 도구 보조 임상 워크플로우 실현

핵심 메시지

의료 MLLM의 성공적 배포를 위해서는 데이터 중심 접근을 넘어 비전 중심 아키텍처 혁신과 임상 정렬 평가 체계가 동시에 필요하다.
