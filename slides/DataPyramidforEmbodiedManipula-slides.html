관찰·물리 상태·행동이 결합된 데이터 필요

  • 인터넷에서 구할 수 없는 신호
  • 단축 경로 없음 — 직접 수집 필수

"체화된 파운데이션 모델은 무엇으로 학습해야 하는가?"

체화된 데이터 피라미드: 전체 구조

5가지 상호보완적 데이터 소스를 확장성과 로봇 정렬의 축으로 조직화

① 실제 로봇 데이터 — 로봇에서 직접 수집된 관찰-행동 궤적
② UMI 스타일 데이터 — 로봇 없이 수집, 객체/엔드이펙터 중심 궤적
③ 자기중심적·타인중심적 데이터 — 인간 상호작용의 에고/엑소 시점 기록
④ 시뮬레이션 데이터 — 가상 환경에서 합성 생성된 로봇 궤적
⑤ 일반 비전-언어 데이터 — 인터넷 이미지, 비디오, 텍스트, QA 쌍

두 가지 핵심 설계 원칙

S

확장성 (Scalability)

데이터 소스를 얼마나 효율적으로 확장할 수 있는가?

  • 하드웨어 의존도
  • 인간 노동 요구
  • 환경 리셋 비용
  • 안전 감시 필요성
  • 한계 생성 비용
R

로봇 정렬 (Robot Alignment)

실제 로봇 학습·실행에 얼마나 직접적으로 활용 가능한가?

  • 관찰 표현의 호환성
  • 행동 공간의 일치도
  • 감각 신호의 충실도
  • 전이 가능성

이 두 원칙은 핵심적으로 긴장 관계에 있음: 로봇에 밀접하게 정렬된 데이터는 확장이 어렵고, 고도로 확장 가능한 데이터는 물리적 상호작용에 대한 간접적·불완전한 감독만 제공

네 가지 보조 특성 차원

품질 (Quality)

수집된 경험의 유효성, 일관성, 정보성, 과제 관련성. 단순한 볼륨 증가는 궤적 반복, 주석 부정확도, 신호 비동기화 시 한계가 명확함

다양성 (Diversity)

과제, 객체, 장면, 시점, 지시, 구현체, 감각 구성, 행동, 결과에 대한 포괄적 커버리지. 분포 변화 하의 강건성에 핵심적 역할

재사용성 (Reusability)

과제, 환경, 구현체, 감각 시스템, 모델 패밀리 간 전이 용이성. UMI 데모는 더 교묘한 구현체로 재타겟팅 가능

물리적 충실도 (Physical Fidelity)

접촉, 마찰, 순응, 감각 피드백 등 실제 상호작용 역학을 얼마나 충실포하게 포착하는지

실제 로봇 데이터

수집 패러다임

스크립트 기반 — 미리 정의된 경로/파라미터
원격 조작 — 인간이 직접 조작 수행
Human-in-the-Loop — 교정·피드백 기반 향상

특성

최고 물리적 충실도 완벽한 로봇 정렬

장점과 한계

  • 실제 물리 역학 직접 포착
  • 관찰-행동 쌍의 완전한 정렬
  • 감각 피드백(접촉, 힘) 포함
  • 하드웨어 의존 — 확장 극히 어려움
  • 환경 리셋에 인간 노동 필요
  • 안전 감시 필수
  • 단일 구현체로 편향됨

UMI 스타일 데이터

핵심 아이디어

로봇 없이 수집: 간단한 고정 장치 + 카메라로 객체 중심 상대 궤적을 기록

상대 궤적 표현

엔드이펙터의 이동을 객체 좌표계 기준으로 표현하여, 구현체 간 재타겟팅을 가능하게 함

교차 구현체 배포

단일 데모를 여러 로봇(그리퍼, 핸드, 모바일 매니퓰레이터)에 전이 가능

장점과 한계

  • 로봇 없이 저비용 수집
  • 높은 재사용성 — 다양한 구현체 전이
  • 비전 기반 관찰의 범용성
  • 힘/접촉 감각 정보 부재
  • 복잡한 환경 상호작용 제한
  • 상대 궤적 정렬의 정확도 의존

자기중심적·타인중심적 데이터

캡처 인프라

  • 시각 센싱: 헤드 마운티드/타인중심 카메라
  • 모션/자세 추적: 손/신체 키포인트, 모션 캡처
  • 보조 센싱: 오디오, 깊이, 오브젝트 추적

감독 구성

의미론적 기하학적 멀티모달 로봇 지향적

장점과 한계

  • 대규모 수집 가능 (수천 시간)
  • 풍부한 의미론적·기하학적 감독
  • 손-객체 상호작용, 아포던스 이해에 재사용
  • 과제 분해에 활용 가능
  • 로봇 행동 레이블 직접 제공 불가
  • 시점/조작 방식 차이로 전이 간극
  • 로봇 정렬 낮음

시뮬레이션 데이터

인프라 생태계

  • 로봇 구현체 & 센서: 다양한 로봇 모델, 카메라, LiDAR
  • 객체·장면 에셋: 3D 자산 라이브러리, 스캔된 환경
  • 물리·렌더링 백엔드: PhysX, MuJoCo, 레이트레이싱

월드 모델 = 시뮬레이터

  • 정책 학습·사후학습에 활용
  • 정책 평가를 위한 가상 환경
  • 합성 데이터 엔진으로 기능

장점과 한계

  • 최고 확장성 — 무한 생성 가능
  • 완전한 행동 레이블 제공
  • 다양한 구현체·환경 커버
  • 안전한 실험 환경
  • Sim-to-Real 간극 핵심 과제
  • 물리적 충실도 한계 (접촉, 변형)
  • 에셋 구축 초기 비용 높음

일반 데이터 및 소스별 비교

일반 데이터의 구성

  • 비전-언어: 이미지 캡션, VQA, 지시-따르기
  • 분할·국소화: 의미론적/인스턴스 분할
  • 3D 데이터: 점운, 메시, 3D 스캔
  • 계획 데이터: 과제 분해, 단계별 지시
  • 비디오/시간적: 동적 이해, 인과 추론
  • 파지 데이터: 파지 성공/실패 예측

데이터 레시피: 조합 전략

각 모델은 이질적 소스를 선택·정렬·혼합하는 고유한 레시피를 가짐

1
사전학습
일반 VL + 비디오 데이터로 지각·언어 기반 구축
2
체화 사전학습
에고/엑소 + 시뮬 데이터로 물리 이해·과제 분해 학습
3
로봇 미세조정
실제 로봇 + UMI 데이터로 행동 생성 능력 부여
4
배포·적응
새로운 환경·구현체로 전이 및 온라인 적응

핵심: 각 단계에서 어떤 소스를 선택하고, 행동 공간을 어떻게 표현하며, 소스 간 정렬을 어떻게 수행하는가가 모델 성능을 좌우

여섯 가지 열린 과제

① 촉각 데이터 for 접촉 밀집 학습

대규모 촉각 데이터셋 구축의 어려움. 접촉-풍부 조작에 필수적이나 현재 피라미드에서 크게 부재

② 실패 데이터 & 복구 중심 학습

성공 사례만 수집되는 경향. 실패·복구 궤적의 체계적 수집과 활용 방법 필요

③ 피라미드 계층 간 확장 가능한 수집

각 계층의 데이터 수집 파이프라인을 어떻게 통합·자동화하여 전체 확장성을 극대화할 것인가

④ 교차 구현체 상태-행동 정렬

서로 다른 구현체 간 행동 공간을 어떻게 통일적으로 표현하고 정렬할 것인가

⑤ 교묘한 손 조작을 위한 에고 사전

인간 손의 에고 비디오에서 교묘한 조작 사전지식을 어떻게 추출하고 로봇에 전이할 것인가

⑥ 원칙적 데이터 레시피 설계

경험적 조합을 넘어, 이론적 기반을 가진 데이터 레시피 설계 프레임워크 필요

결론

체화된 데이터 생태계를 체계적으로 "데이터 피라미드"로 조직화하고, 각 소스의 특성과 trade-off를 분석하여 차세대 체화된 시스템 설계의 기반을 제공
