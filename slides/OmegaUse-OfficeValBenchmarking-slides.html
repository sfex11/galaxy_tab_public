OmegaUse-OfficeVal

경제적 가치 기반 장기 오피스 제품군 작업에서의
LLM 에이전트 벤치마크

Baidu Inc. · arXiv:2607.27155v1 · 2026년 7월

배경

"바이브 코딩"에서 "바이브 워킹"으로

LLM 에이전트는 코드 생성에서 상당한 상업적 성공을 거두었으며, 다음 단계는 장기 오피스 제품군 작업을 수행하는 것으로 예상됩니다. 문서, 스프레드시트, 프레젠테이션, PDF 등 일상적 생산성 작업을 에이전트가 대신 완수할 수 있다면 사회적·경제적 파급효과가 클 것입니다.

"실제로 이러한 잠재력을 실현하려면, 에이전트가 오피스 워크플로우를 수용 가능한 비용으로 수행할 수 있는지 측정하는 벤치마크가 필요합니다."

기존 벤치마크의 한계

세 가지 벤치마크 계층의 공통적 부족

생산성 에이전트

GDPVal, RLI, ALE 등은 경제적 가치를 광범위한 직무 범주에만 연결하고, 개별 작업 수준 주석이 부족함

오피스 자동화

OfficeBench, SpreadsheetBench 등은 단기·합성 워크플로에 집중하며 경제적 주석 없음

GUI/컴퓨터 사용

OSWorld 등은 프로세스 수준 평가에 집중하고, 최종 산출물의 품질과 활용성을 평가하지 않음

핵심 질문: "에이전트가 올바르고 사용 가능한 산출물을 제공할 수 있는가? 그리고 그것이 얼마의 인력/시장 가치를 나타내는가?"

소개

OmegaUse-OfficeVal 개요

실무자가 제안한 진짜 오피스 요청을 개인정보 보존 과정을 통해 적응시켜 구축한 100개 장기 오피스 제품군 작업 벤치마크

작업 구성

  • 상위 수준 사용자 지시문
  • 하나 이상의 입력 파일
  • 에이전트가 생성해야 할 산출물
  • 문서·스프레드시트·PPT·PDF 포괄

핵심 특징

  • 작업별 경제적 가치 주석 (2가지 신호)
  • 코드 기반 검증 프로토콜
  • 완전 공개 벤치마크 자산
  • 인간 기준선과의 직접 비교
설계 원칙

세 가지 설계 원칙

1

진정한 오피스 생산성 반영

실제 직장 시나리오에서 유래하며, 초급 오피스 작업자가 완료할 수 있는 명확한 목표와 구체적 산출물 보유. 인위적인 저수준 연산 순서가 아닌 자연스러운 요청 형태

2

작업 수준 경제적 가치 부착

GDPVal·RLI와 달리 광범위한 직무 범주가 아닌 개별 작업마다 경제적 가치를 부착하여, 인력 비용과 LLM 추론 비용의 직접 비교 및 가치 가중 평가 가능

3

장기 작업만 선정

단순 작업 제외, LLM 에이전트의 최전선 능력과 미래 잠재력을 탐색하기 위해 도전적인 장기 작업만 의도적으로 선정

경제적 가치

작업별 경제적 가치: 두 가지 신호

인력 소요 시간

인간 주석자가 LLM 지원 없이 작업을 완료하는 데 걸린 시간을 기록합니다. 인센티브 메커니즘을 적용하여 정확한 측정을 보장하며, 평균 2.32시간입니다.

작업 가격 프록시

작업 완료의 시장 가격을 추정합니다. 실무자의 명시적 가격 신호가 있으면 활용하고, 없으면 전문가 추정치의 일관성 기반 집계를 사용합니다.

이 두 신호를 통해 인력 비용 vs LLM 추론 비용의 직접 비교와 가치 가중 평가가 가능해집니다.

평가 방법

코드 기반 검증 프로토콜

LLM이 발전함에 따라 안정적인 평가를 위해 인간 판사와 LLM-as-Judge 대신 코드 기반 검증기를 채택했습니다.

세부 루브릭

완료된 요구사항에 보상, 사용자의 수정 부담을 증가시키는 의도치 않은 손상에 페널티 부여

실행 가능한 코드 변환

루브릭을 실행 가능한 검증 코드로 번역하여 재현 가능하고 일관된 평가 보장

인간-코드 불일치 해결

반복적인 불일치 해결 과정을 통해 검증 코드를 보정하여 인간 판단과의 정렬 달성

분석

핵심 발견

평균 점수 ≠ 경제적 가치 포착 능력

가치 가중 평가 결과, 평균 점수가 가장 높은 모델이 반드시 경제적으로 가장 중요한 작업을 가장 잘 수행하는 것은 아닙니다. 이는 단순 평균 점수로는 실제 경제적 가치를 반영하지 못함을 시사합니다.

인력 소요 시간에 따른 성능 편차

작업의 인력 소요 시간에 따라 LLM 성능이 이질적으로 변동합니다. 장기 오피스 작업은 여전히 LLM에게 도전적이고 이질적인 설정입니다.

비용-품질 트레이드오프

모든 평가 LLM이 인간 노동자보다 저렴하고 빠르지만, 아직 인간 수준의 산출물 품질에는 도달하지 못했습니다.

결론

기여 요약

완전 공개 벤치마크

100개 장기 오피스 워크플로 + 작업 지시문, 입력 파일, 루브릭, 검증 코드, 경제적 주석 전체 공개

작업 수준 경제적 가치 주석

인력 소요 시간과 작업 가격 프록시를 통한 가치 가중 평가 프레임워크 제공

LLM vs 인간 비교 분석

LLM이 빠르고 저렴하지만 산출물 품질에서 여전히 인간에 미달한다는 실증적 증거 제시

"장기 오피스 작업에서 LLM 에이전트는 의미 있는 진전을 보였으나, 인간 수준의 산출물 품질에는 아직 도달하지 못했습니다."
