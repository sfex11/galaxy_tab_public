Beyond Scores

요약 평가에서 LLM-as-a-Judge의 내부 메커니즘 이해

Himil Vasava, Ming Jiang

University of Wisconsin-Madison

배경: LLM 평가자의 시대

LLM-as-a-Judge의 확산

  • 전용 평가 모델: Themis (Llama-3-8B), Prometheus (Mistral-7B)
  • 프롬프트 기반: G-Eval, MT-Bench
  • 선호 레이블링·보상 모델링의 자동 신호로 활용

그러나 본질적 질문은 미해결

기존 연구는 행동 분석에 집중 — 인간 평가와의 일치도, 오류 유형, 편향 측정

"점수는 알지만, 모델 내부에서 그 점수가 어떻게 계산되는지는 거의 알려져 있지 않다."

연구 질문

LLM 평가자는 특정 품질 결함을 실제로 식별하는가, 아니면 학습 분포 패턴에 맞춰 결함에 관여 없이 점수만 일관되게 출력하는가?

기계론적 접근

행동 수준이 아닌 내부 계산 절차를 인과적으로 분석

태스크: 요약 평가

가장 성숙한 NLG 평가 태스크 — 국소적 개입에 적합한 기사-요약 구조

대상: 평가자 2종

서로 다른 베이스 모델 계열에서 파인튜닝된 Themis와 Prometheus

8개 공격 유형의 교란(perturbation) 분류 체계

기존 NLG 벤치마크의 교란 유형을 두 품질 차원으로 통합

가독성 (Readability)

전치사 불일치문법 오류
시제 불일치잘못된 동사 형태
철자 오류문자 단위 노이즈
순서 재배열어순 교란·문장 교환

적절성 (Adequacy)

개체명 교체엔티티 스왑
숫자·날짜 교체수치 스왑
지시어 불일치대명사 스왑
반의어·부정의미 반전

데이터 파이프라인: 메커니즘 분석을 위한 통제된 쌍 생성

1
기사 + 깨끗한 요약
기존 벤치마크 데이터셋 활용
2
국소 교란 적용
8개 공격 유형, 통제된 오류 강도
3
토큰 수준 수정 지도
어느 토큰이 수정되었는지 명시적 기록
4
쌍 데이터
clean/corrupt 쌍 + 점수 변화

기존 적대적 벤치마크는 문장·문서 수준에서 오류를 도입 → 토큰 수준 추적 불가. 본 파이프라인은 위치 메타데이터를 보존하여 기계론적 분석을 가능하게 함

4가지 기계론적 분석 방법

인과 추적 (Causal Tracing)

윈도우 모드 & 마지막 토큰 모드 — 오류가 어디서 등록되고 어떻게 전파되는지 국소화

로짓 렌즈 (Logit Lens)

중간 잔차 스트림을 어휘 공간으로 투영 — 점수 결정이 언제 결정화되는지 추적

어텐션 헤드 제거 (Knockout)

특정 헤드를 비활성화 — 어떤 헤드가 평가 판정을 구현하는지 검증

베이스 모델 대조

동일 규모의 Llama-3-8B 베이스 모델과 비교 — 파인튜닝이 무엇을 설치하는지 분리

적용 대상: Themis (Llama-3-8B) · Prometheus (Mistral-7B)

핵심 발견 ①: 2단계 평가 파이프라인

Stage 1 Layer < 15

어텐션: 오류 식별 & 신호 라우팅

  • 국소적 오류 비교 수행
  • 오류 신호를 마지막 입력 위치로 전달

Stage 2 Layer > 15

MLP: 신호 통합 & 점수 출력

  • 라우팅된 신호를 MLP 연쇄가 통합
  • 최종 층에서 점수를 잔차 스트림에 기록

LLM 평가자는 표면 특징→점수의 즉흥적 사상이 아니라, 구조화되고 일관된 정보 전달 파이프라인을 구현한다

핵심 발견 ②: 결정의 결정화 시점

로짓 렌즈 분석 결과, 점수 결정은 예리한 후기 층에서 잔차 스트림에 결정화

L=26

Themis (Llama-3-8B)

L=25

Prometheus (Mistral-7B)

L=28

Llama-3-8B 베이스 모델

두 평가자 모두 동일한 후기 층 결정화 패턴을 보이며, 이는 계열이 다른 베이스 모델 간에도 일반화됨

핵심 발견 ③: 오류 유형별 상이한 어텐션 전략

가독성 오류

확산형 — 인접한 통사적 문맥 전반으로 어텐션이 퍼짐

→ 문맥 전체를 고려해야 판별 가능한 오류

적절성 오류

집중형 — 교란된 토큰에만 어텐션이 집중

→ 국소 토큰 자체만으로 판별 가능한 오류

LLM 평가자는 평가 기준에 따라 서로 다른 어텐션 전략을 선택적으로 배치한다 → 기준별 어텐션 감독으로 평가자 견고성 개선 가능

핵심 발견 ④: 평가자별 상이한 점수 기록 방식

평가자점수 기록 패턴최종 층 동작
Themis 최상위 층에서 단일 지배적 단계로 점수 확정 —
Prometheus 중간~후기 층에 걸쳐 분산적 기록 반대 방향 보정 적용

동일한 2단계 파이프라인을 공유하더라도, 최종 점수를 잔차 스트림에 쓰는 구체적 방식은 평가자마다 다름 — 파인튜닝 데이터와 절차의 차이가 반영

베이스 모델 대조: 파인튜닝이 설치하는 것

Llama-3-8B 베이스 모델은 이미 라우팅 아키텍처와 후기 층 결정화(L=28)를 보유

이미 존재 일반 기반(substrate)

  • 어텐션 기반 오류 라우팅 구조
  • 예리한 후기 층 결정화 (L=28)
  • L15 이상 MLP 크기 = Themis와 동일

파인튜닝이 설치 두 가지 수정

  • 마지막 위치에서 L15 미만 MLP 기여 억제 → 2단계 분리가 명확해짐
  • 결정화 깊이의 2층 전진 (L=28 → L=26)

파인튜닝은 평가 파이프라인을 처음부터 구축하는 것이 아니라, 기존 기반 위를 조각(sculpt)한다

기여와 의의

최초의 체계적 기계론 분석

LLM 기반 NLG 평가의 내부 메커니즘을 최초로 체계적으로 규명 (요약 평가 중심)

재사용 가능한 분류 체계

토큰 수준 수정 지도를 갖춘 8-공격 교란 분류 체계 + 쌍 생성 파이프라인 공개

견고성 개선 방향

기준별 어텐션 전략의 발견은 평가자 견고성 향상을 위한 감독 설계에 시사점 제공

해석 가능한 평가자

내부 절차의 이해는 평가자 신뢰성 제고와 실패 사례 예측으로 이어짐

한계점

  • 모델·태스크 범위 — 요약 평가 중심, 2개 평가자만 분석
  • 행동 필터 선택 — 교란에 민감하게 반응하는 샘플 중심 분석
  • 단일 강도·단일 공격 샘플 — 강도별 일반화 미검증
  • 로짓 렌즈 근사 — 어휘 투영의 한계 존재, 생성기 모델 의존성

향후 방향: 다양한 NLG 태스크·평가자로 확장, 기준별 어텐션 감독을 통한 견고성 실험

결론

LLM 평가자는 하위 층 어텐션이 오류를 라우팅하고 상위 층 MLP가 점수를 결정하는 2단계 파이프라인으로 작동하며, 파인튜닝은 이 기반을 조각하는 것이다
