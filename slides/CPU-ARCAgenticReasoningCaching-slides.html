CPU-ARC
Agentic Reasoning Caching
for on-CPU Reasoning Reuse

Peter Belcak · Greg Heinrich · Saurav Muralidharan · Shizhe Diao · Pavlo Molchanov

  Project Moonshot: Local Frontier Intelligence

문제 제기: LLM은 매번 처음부터 풉니다

"Large language models re-invent the wheel all the time."

  과제 해결과 실행의 혼동

LLM은 문제를 푸는 것(task-solving)과 푼 해답을 실행하는 것(execution)을 하나로 섞어 처리합니다.

  반복되는 쿼리의 낭비

AI 에이전트는 같은 지시·계획에 페이로드만 다른 쿼리를 반복 호출하며, 매 인스턴스마다 동일한 추론을 처음부터 수행합니다.

  핵심 질문: 한 번 추론해 낸 해답을, 새 문제 인스턴스에 최소한의 LLM 개입으로 재사용할 수 있을까?

핵심 통찰: 추론 단계는 그대로 재사용된다

MATH-500 예제 — "196의 양의 약수는 몇 개인가?"

변형질문추론 변화
원본 196의 양의 정수 약수 개수는? —
재구문
파라미터 동일		 196을 균등하게 나누는 양의 정수 개수는? 한 단어도 변하지 않음
재파라미터화
표현 동일		 144의 양의 정수 약수 개수는? 산술값만 조정, 절차 동일

196 = 2²×7² → (2+1)(2+1) = 9  vs.  144 = 2⁴×3² → (4+1)(2+1) = 15

  같은 추론으로 풀리는 문제들의 집합 = equirational (등추론) 문제 클래스

두 가지 관찰 (Observations)

O1

해답 탐색과 실행의 분리

문제를 한 번 추론해 해답을 찾았다면, 그 해답의 실행(계산·데이터 조작)은 LLM의 개입 없이도 수행할 수 있습니다.

전략: 대화 기록을 코드로 변환 — 유사도 검색·값 추출 등 소규모 작업에만 소형 LM 사용

O2

추론의 클래스 단위 재사용

특정 문제 인스턴스에 대한 추론 대부분은, 그 인스턴스 하나를 넘어 동일 추론으로 풀리는 문제 집합에 재사용 가능합니다.

전략: 고정된 변수명이 아닌 자연어 매개변수 인식으로 코드를 파라미터화

기존 연구: 시스템 레벨 캐싱 (SLC)의 두 계열

  모놀리식 캐싱

  • 프리픽스 캐싱, 대화 ID, 의미 유사도 매칭
  • 전체 대화·생성 상태(KV 캐시 등)를 통째로 저장
  • 검토 가능, 계산 비용 저렴
  • 약점: 사소한 입력 변화에도 불안정, 메모리·대역폭 비쌈

  모듈러 캐싱

  • 컨텍스트를 기계적 분해하거나 핵심 논리 단계로 증류
  • 분해 결과를 LM에 재공급해 추론 가속
  • 파라미터 변화에 강건, 메모리 효율적
  • 약점: 히트 시에도 재생성 필요, 정답 보증 불가

CPU-ARC는 이 둘의 하이브리드 — 커버리지는 강건하고, 비동기 검증으로 정답 보장이 가능하며, 완전한 설명 가능성과 저렴한 비용을 모두 갖춥니다.

Agentic Reasoning Cache (ARC)란?

LLM 추론 기록에서 만들어지는, CPU에서 실행 가능한 소형 전문 분할 에이전트(fractional agents)들의 캐시

  강건한 커버리지

재구문·재파라미터화된 입력에도 안정적으로 캐시 히트

  검증 가능한 정답

사람이나 심판 에이전트가 비동기적으로 캐시 항목의 정답을 보장

  완전한 설명 가능성

코드 형태로 누구나 추론 과정을 검사·감사 가능

  지속적 학습 가능

캐시를 계속 훈련·개선할 수 있음

  극도로 저렴한 호출

원본 모델 대비 16–291배 저렴한 호출 비용

코드로 구현·컴파일
  • 결과물은 시맨틱 함수(semantic functions)의 집합 — 고정된 변수·함수명이 아닌 자연어 매개변수에 의존
  • 동일 추론으로 풀리는 모든 문제(equirational)에 대해 재사용 가능하도록 파라미터화

시맨틱 함수와 ARC 실행

  런타임 프리미티브

  • do: 의미 기반 매칭으로 서브태스크 실행
  • load: 캐시된 함수 적재·재사용
  • 타입 안전성(type safety) 보장

소형 LM이 담당: 유사도 검색, 값 추출, 형식 변환, 분류, 요약

  컨텍스트·메모리 모델

캐시 항목은 입력 파라미터를 바인딩받아 독립적으로 호출됩니다.

  컴파일

구축된 코드는 CPU에서 직접 실행 — 대형 GPU 추론 없이도 프론티어급 성능 재현

캐시 요소 = 새로운 파라미터에 재사용되는 소형·전문 분할 에이전트 — 그래서 "agentic" reasoning cache

의의와 배치 (Placement)

  • LLM의 역할을 해답 탐색으로 한정하고, 실행은 CPU 캐시에 위임하는 새로운 추론 아키텍처
  • 반복 질의가 많은 AI 에이전트·에이전트 기반 소프트웨어에 즉시 적용 가능한 시스템 레벨 최적화
  • 캐시 항목이 코드이므로 감사(audit), 규제 검토, 지속적 개선이 모두 가능
  • 목표 모델은 합성 데이터 증강 + supervised fine-tuning으로 제작되어 자체 완결적 구축 가능
