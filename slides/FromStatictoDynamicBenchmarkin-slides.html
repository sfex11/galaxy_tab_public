RQ1: 전반적 성능

결함 탐지 성능

  • 주류 LLM 모두 제한적인 성능만 보여줌
  • 결함을 정확히 식별하더라도 수명주기 상태 예측은 여전히 큰 과제
  • PR 수준 기존 베이스라인보다 LLM이 우세하지만 절대적 수치는 낮음

결함 상태 추적 능력

  • 상태 추적 정확도가 결함 탐지보다 현저히 낮음
  • 모델들이 Resolved 상태와 Open 상태를 혼동하는 경향
  • 다중 라운드 맥락에서 상태 전이를 올바르게 인식하지 못함

"결함 탐지와 상태 추적은 서로 다른 인지 능력을 요구하며, 후자가 현재 LLM에게 훨씬 더 어려운 과제이다."

RQ2: 라운드 수에 따른 성능 변화

핵심 발견: 라운드 증가 → 성능 저하

1R
단일 라운드
상대적으로 양호한 성능
2-3R
중간 라운드
성능 점진적 하락
4R+
고라운드
현저한 성능 저하

결함 유형별 편차

  • 의미적으로 단순한 결함: 비교적 잘 탐지
  • 의미적으로 복잡한 결함: 누락률 현저히 높음
  • 저돌출성(Low-salience) 결함: 탐지 확률 급감

심각도별 편차

  • 높은 심각도: 상대적으로 잘 탐지
  • 낮은 심각도: 누락 비율 크게 증가
  • 라운드가 진행될수록 심각도 간 격차 확대

RQ3: 오류 근본 원인 분석

오픈 코딩 분석을 통한 위양성(False Positive)과 위음성(False Negative)의 세분화된 원인 분류

위양성 (False Positive)

  • 시간적 오정렬: 과거에 해결된 결함을 현재 미해결로 잘못 판단
  • 과도한 감지: 실제 결함이 아닌 스타일 차이를 결함으로 오인
  • 맥락 혼동: 다른 파일/라인의 결함을 잘못된 위치에 할당

위음성 (False Negative)

  • 장거리 기억 부족: 이전 라운드에서 식별된 결함을 잊어버림
  • 의미적 복잡성: 논리적 결함 등 복잡한 결함 탐지 실패
  • 새로 도입된 결함 누락: 후속 커밋에서 새로 생긴 결함 미탐지

핵심 취약점: 라운드 간 시간적 오정렬과 장거리 기억 부족이 다중 라운드 리뷰에서 LLM의 가장 치명적인 한계로 확인됨

핵심 발견 요약

발견 1

제한된 전반적 역량

주류 LLM은 결함 탐지와 수명주기 상태 추적에서 모두 제한적 성능을 보이며, 상호작용 라운드가 증가할수록 성능이 유의미하게 저하됨

발견 2

결함 민감적 성능 편차

결함 유형과 심각도에 따라 성능이 크게 편차를 보이며, 의미적으로 복잡하거나 돌출성이 낮은 결함이 누락될 확률이 유의미하게 높음

발견 3

근본적 실패 메커니즘

위양성과 위음성의 원인이 다름: 위양성은 시간적 오정렬에서, 위음성은 장거리 기억 부족에서 주로 발생

발견 4

코멘트 품질 한계

생성된 리뷰 코멘트는 실제 리뷰어 수준에 미치지 못하며, 구체성과 실행 가능성 측면에서 개선 여지가 큼

기여 및 시사점

주요 기여

  • 실제 다중 라운드 코드 리뷰를 위한 최초의 상태 인식 벤치마크 구축
  • "국소 검출 → 전역 추적" 전략 기반의 자동화 구축 파이프라인 개발
  • 주류 LLM의 다중 라운드 리뷰 능력 경계를 체계적으로 평가
  • 위양성/위음성 원인에 대한 세분화된 분류 체계 제안

향후 방향

  • 라운드 간 장거리 기억 메커니즘 강화 필요
  • 시간적 정렬 능력을 갖춘 아키텍처 연구
  • 결함 유형별 특화된 탐지 전략 개발
  • 에이전트 기반 반복적 리뷰 시스템 설계
