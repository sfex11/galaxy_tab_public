Long Video Understanding Edge-Cloud Agentic AI

Caption-once, Frames-on-Demand

Budget-Aware Agentic Long Video Understanding를 위한 Visual-Need Routing

긴 영상을 "한 번" 요약하고, 필요할 "때만" 프레임을 보는 에지-클라우드 에이전트 프레임워크

문제 설정: 몇 시간짜리 영상, 한정된 예산

  • 엣지 디바이스의 긴 영상 이해는 몇 시간 분량의 콘텐츠를 타이트한 연산·대역폭 예산 안에서 추론해야 함
  • 긴 영상 QA는 단순 모델링 문제가 아니라 모델링 + 자원 할당의 결합 문제
  • 전체 시간 범위를 커버하면서도, 작지만 결정적인 사건·속성 하나를 놓치면 바로 오답으로 이어짐
핵심 질문: 영상 전체를 고르게 처리하지 않고도, 쿼리에 필요한 기억과 증거를 어떻게 선택적으로 확보할 수 있을까?

기존 접근법의 두 축과 한계

시각 압축 (Visual Compression)

프레임 선택 or 토큰 압축으로 MLLM에 들어가는 시각 토큰을 줄임

한계: 긴 영상에서 커버리지·충실도 상실, 시간 구조 손상 위험

텍스트 변환 (Textual Translation)

영상을 캡션·전사·언어 메모리로 바꿔 텍스트 공간에서 검색·추론

한계: 세밀한 시각 증거 손실, 반복 재방문 시 쿼리 비용이 상호작용 깊이에 따라 증가하고 예산 관리가 어려움

두 접근 모두 "무엇을 잃는가"와 "비용이 어디서 발생하는가"를 제어하지 못함 → 새로운 패러다임 필요

인간의 기억처럼: 픽셀 단위 세부사항은 버리지만, 경험의 간결한 스토리라인은 유지하고 조회한다. 텍스트는 영상의 손실된 대체재가 아니라, 시간 구조의 더 강력한 운반체가 될 수 있다.

CFD 패러다임: Caption-once, Frames-on-Demand

1
오프라인 인덱싱 (엣지)
가벼운 MLLM이 질문 비의존적으로 단 한 번 캡셔닝 → 이중 트랙 내러티브 인덱스 구축·캐싱
2
스토리 우선 추론 (클라우드)
강한 클라우드 MLLM이 캐시된 인덱스 위에서 스토리 우선으로 답변 시도
3
Visual-Need Routing
질문 유형에 따라 필요할 때만 키프레임 검색 트리거
4
멀티모달 재추론
텍스트 메모리 + 검색된 시각 증거를 통합 프롬프트로 재추론

효율은 시각 연산을 획일적으로 줄이는 것이 아니라, 속성이 중요한 순간에만 시각 접근을 배분하는 데서 나온다.

3계층 에지-클라우드 메모리 아키텍처

Tier 1: 이벤트 메모리

샷 경계 검출로 세그먼트 후, 짧은 구간 병합 → 가변 길이 이벤트별 스토리 스켈레톤 (장면 개요, 엔티티, 사건 흐름, 검색 앵커 태그)

전체 영상을 커버하는 글로벌 타임라인, 항상 전체 제공

Tier 2: 클립 메모리

이벤트와 독립적으로 고정 길이 클립 단위로 균등 분할 → 이벤트 사이 로컬 시간 디테일을 보존하는 마이크로 로그

필요 시 겹치는 클립 캡션으로 세부 보강

Tier 3: 시각 메모리

텍스트만으로 불충분할 때 원시 픽셀 증거를 제공하는 온디맨드 계층

라우터가 텍스트 → 픽셀 에스컬레이션 여부를 결정

기존 계층형 메모리는 답변 중 캡셔닝 모델을 반복 호출하지만, CFD는 모든 텍스트 메모리를 오프라인 단일 패스로 생성 → 쿼리 시 추론은 주로 언어 공간에서, 시각 접근은 경계가 있는 선택적 보조

Visual-Need Router: 질문 유형 기반 게이팅

쿼리마다 경량 게이팅 모듈이 질문을 분류하고, 프레임 검색 트리거 여부를 결정

지각형 질문

프레임 검색 실행 — 픽셀 수준 검증 필요

  • "이 머그컵은 무슨 색이야?"
  • 외모 · 화면 속 텍스트(OCR) · 속성 구별
시간-구조형 질문

언어 공간 유지 — 내러티브 메모리로 충분

  • "그 남자가 떠난 후 무슨 일이 있었어?"
  • 사건 순서 · 인과 · 이벤트 관계
프레임 검색을 파이프라인의 부산물이 아니라, 질문에 조건화된 1급 비용(first-class, query-conditioned cost)으로 취급하는 최초의 에이전틱 비디오 QA 설계

Story-First 추론 루프

1
스토리 우선 답변 시도 — 이벤트 메모리(전체 스토리 스켈레톤)에서 바로 답변 생성
2
신뢰도 검사 — 불충분하면 관련 미탐색 이벤트를 국소화하고, 겹치는 클립 캡션으로 보강 후 재시도
3
Visual-Need Router 판정 — 픽셀 검증이 필요한 질문인지 판단 → 필요 시 국소화된 이벤트에서 키프레임 검색
4
멀티모달 재추론 — 텍스트 메모리 + 검색된 시각 증거를 통합 프롬프트로 재추론
5
종료 조건 — 신뢰도 도달 또는 쿼리 예산 소진 시 루프 종료

백트래킹 기반 반복 루프이지만, 시각 접근은 항상 상한이 통제됨

예산 통제: 고정 용량 FIFO 작업 메모리

  • 시각 검색 트리거 시, 국소화된 이벤트에서 상한이 정해진(bounded) 키프레임 집합만 검색
  • 고정 용량 FIFO 작업 메모리에 저장 → 오래된 프레임부터 교체
  • 영상 길이와 무관하게 쿼리당 시각 소비량이 통제됨
  • 쿼리당 프레임 소비를 명시적 하이퍼파라미터로 노출 (상호작용 깊이의 암묵적 부산물이 아님)

설계의 의미

시각 접근 비용 = 질문 유형 × 프레임 상한

라우터가 에스컬레이션을 결정하므로, 질문 비의존적 인덱스가 세부사항을 놓쳤을 때도 잘못된 텍스트-only 답변에 매몰되지 않음

실험 결과: 정확도-효율 트레이드오프

정확도

Video-MME, InfiniBench 등 장기 영상 벤치마크에서 기존 에이전트 기반 방법들과 경쟁력 있는 정확도 달성

효율

질문당 사용 프레임 수가 약 한 자릿수(10배) 적음 — 온라인 시각 처리 대폭 절감

시각 접근은 획일적으로가 아니라 선택적으로 배분될 수 있다는 설계 가설의 실증적 뒷받침

사전 연구에서도 이중성 확인: CaptionQA(속성)에서는 픽셀이 +15.15%p, InfiniBench 시간 추론에서는 캡션이 +8.02%p 우수

기여 요약

  • Visual-Need Router — 질문을 지각형/시간-구조형으로 분류해 후자에 한해 원시 프레임 검색을 트리거하는 쿼리별 게이팅 모듈. 프레임 검색을 명시적 질문 조건부 비용으로 전환한 최초의 에이전틱 설계
  • CFD 프레임워크 — 재사용 가능한 이중 트랙 내러티브 인덱스(이벤트 스켈레톤 + 클립 마이크로 로그) + Visual-Need Router + 고정 용량 FIFO 작업 메모리를 결합한 예산 인지 에지-클라우드 파이프라인
  • 실증 연구 — Video-MME·InfiniBench에서 질문당 프레임을 약 10분의 1 수준으로 줄이면서 경쟁력 있는 정확도 유지

결론

텍스트는 영상의 손실된 대체재가 아니라 시간 구조의 강력한 운반체이며, 픽셀은 속성 수준 검증에 여전히 결정적이다.
  • 시간 구조는 한 번 언어로 인덱싱해 캐시하고 재사용 (Caption-once)
  • 세밀한 시각 속성이 필요할 때만 경계가 있는 키프레임 검색 (Frames-on-Demand)
  • 비주얼 니즈 라우팅으로 영상 길이와 무관한 상수 수준의 쿼리 비용 실현

대화형 비디오 어시스턴트, 온디바이스 개인 메모리, 웨어러블 시각 보조 등 엣지 제약 애플리케이션에 적합
