Environment Evolution
for Terminal Agents

터미널 에이전트를 위한 환경 진화:
오프폴리시 난이도 증가를 통한 지속적 학습 신호 제공

Hunyuan Team, Tencent

Zhiyuan Fan · Tinghao Yu · Yuanjun Cai · Jiang Zhou · Jiangtao Guan · Jincheng Liu 외

배경: 환경이 RL 스케일링의 다음 병목

터미널 에이전트란?

  • 명령줄 도구로 컴퓨팅 시스템과 상호작용
  • 환경 피드백을 반복 활용해 장기 과제 수행
  • 검증 가능한 피드백 기반 학습에 적합

핵심 레버: 난이도와 다양성

  • 적응적 난이도 → 지속적 학습 가능성 확보
  • 다양성 → 일반화 능력 지원
  • 알고리즘·인프라가 안정화되며 초점이 환경으로 이동
문제: 프론티어 모델일수록 처음부터 합성한 환경은 쉽게 풀려버려 유효한 학습 신호를 제공하지 못함

기존 환경 스케일링 패러다임과 한계

(a) 환경 앙상블

어려운 원시 환경 여러 개를 조합해 새 환경 생성

단순 구성이라 난이도 상승 폭 제한적

(b) 에이전트-환경 공진화

온폴리시 롤아웃으로 weakness bank를 채우고 이를 기반으로 새 환경 합성

롤아웃 모델·초기 분포에 종속 → 일반화 제한

(c) 환경 진화

파생된 난이도 신호로 환경 자체를 진화시켜 계통(lineage) 구성

본 논문이 제안하는 패러다임

공진화의 근본 한계: 학습이 포화되어 모델 실패가 희소해지면 지속적으로 학습 신호를 공급하기 어려움

제안: Environment Evolution

롤아웃 모델 없이 오프폴리시로 환경 난이도를 세대별로 점진 증가시키고, 진화된 환경을 학습 중 세대 단위로 스케줄링

1
모델 무관 난이도 정식화 — 다중 턴 학습 목적함에서 난이도의 세 요인을 도출 (Preliminaries)
2
루프 엔지니어링 멀티에이전트 하네스 — 선택된 방향으로 기존 환경을 점진 수정
3
진화 계통 스케줄러 — 난이도가 증가하는 검증된 계통을 세대별로 학습에 투입

장점 1: 타깃 정책과 독립적 → 일반화된 난이도 향상

장점 2: 모델이 강해져도 학습 신호 지속 공급

Preliminaries: 오프폴리시 난이도 정식화

특정 모델 θ의 합격률은 모델별 약점일 뿐 환경 난이도가 아님 → 환경 자체의 난이도 지표 필요

저수준: 마르코프 프로세스

관측-행동이 교차하는 실행 궤적

ζ = (o₀, a₀, o₁, a₁, …, o_T)

고수준: 시나리오-스킬 교차

계층적 실행으로 궤적 재해석 (σ: 시나리오, κ: 스킬)

ξ = (σ₀, κ₁, σ₁, …, κ_L, σ_L)

모델별 난이도: D_θ(ξ) = −log p_θ(ξ|g) = Σt [ −log p_θ(σt−1|g) −log p_θ(κt|σt−1, g) ]

이 값의 세 기여 요인이 곧 진화 방향이 됨 → 후자 두 항은 정책 의존적이므로 이를 정책 독립적으로 치환

세 가지 진화 방향

다중 턴 학습 목적함에서 유도된, 환경 난이도를 좌우하는 세 요인

시나리오 신규성

Scenario Novelty

모델이 도달하기 어려운 새로운 상황·설정으로 환경 확장

스킬 희귀성

Skill Rarity

해당 시나리오에서 요구되는 희소·전문 스킬의 필요

실행 길이

Execution Length

해결에 필요한 의미 있는 솔버 턴 수 L의 증가

이 세 방향 중 하나를 선택해 환경을 점진 수정함으로써, 원래 환경 분포 주변에 다양한 변형을 도입하며 난이도 증가 계통을 구축

접근법: 루프 엔지니어링 멀티에이전트 하네스

Evolver(진화기)가 세 진화 방향을 따라 기존 환경을 반복적으로 개선

1
시드 환경
기존 환경을 진화의 시작점으로 선택
2
Loop 1
계획 정제
Plan Refinement — 진화 방향에 맞는 과제 계획 수립·개선
3
Loop 2
환경 정제
Environment Refinement — 환경 수정 및 검증 시스템 정합성 확보
4
다음 세대
검증된 더 어려운 환경이 계통에 추가

진화 노력(Evolution effort): 반복 횟수를 조절해 난이도 상승 폭 제어

검증 루프: 지시문-검증기 정합성을 유지해 보상 신호 품질 보장

진화 계통 스케줄러 (Evolution-Lineage Scheduler)

진화된 환경들을 그냥 모아두지 않고, 학습 중 세대 순서대로 투입해 커리큘럼 효과 생성

초기 학습: 낮은 세대(쉬운) 환경으로 기본 역량 형성
점진 전환: 모델이 성장함에 따라 상위 세대 환경으로 스케줄링
지속 신호: 모델이 강해져도 항상 학습 가능한 최전선 난이도 유지
핵심 차별점: 진화가 오프폴리시이므로 학습 중인 모델과 무관하게 미리 계통을 구축 가능 → 일반화된 난이도 + 끊기지 않는 학습 신호

결과 ① 진화 효과와 방향 분석

  • 일관된 난이도 상승: Hy4 preview · Claude Opus 5 · GPT-5.6 Sol 모두에서 진화된 환경이 더 어려움 — 오프폴리시 합성임에도 모델 불문 도전적
  • SFT 이후에도 유효: 시드 환경이 이미 SFT에 사용되었어도 진화 환경은 도전적 RL 신호를 지속 제공
  • 진화 방향별 효과: 세 방향 모두 난이도를 높이며, 방향 선택이 계통의 다양성과 난이도 프로파일에 영향

기여 요약

1
모델 무관 난이도 정식화: 다중 턴 학습 목적함에서 환경 난이도를 유도해, 환경 진화가 난이도를 높이는 더 일반적인 접근임을 입증
2
환경 진화 프레임워크: 루프 엔지니어링 멀티에이전트 하네스로 기존 환경을 점진 진화시켜 검증된 난이도 증가 계통 구축
3
실증 검증: 200스텝 장기 RL에서 공진화·앙상블 대비 오래 지속되는 학습 신호, Terminal-Bench 2.1에서 +14.4%p / +18.0%p
결론: 환경 자체를 진화시키는 것이 에이전트 학습용 환경 스케일링의 지속 가능한 다음 단계
