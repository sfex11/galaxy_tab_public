Chain-of-Thought 추론 연구

Legibility is Not Interpretability

Chain-of-Thought 추론에서 판단된 중요도와 실제 중요도의 비교

Kevin Du (ETH Zürich) · Alexander Hoyle (ETH Zürich) · Laura Ruis (MIT) · Acyr Locatelli (Cohere)

arXiv:2609.04194

가독성만으로 알 수 없는 것: 동일해 보이는 두 추론 단계

경시 대회 기하학 문제에 대한 추론 모델의 두 self-check 단계 — 텍스트만 보면 구별 불가

정답 확률 변화 없음
"Alternatively, maybe I made an error in the problem setup. Let me check again."

정답에 도달할 확률이 전혀 바뀌지 않음

정답 확률 +0.42
"Alternatively, maybe my error is in the coordinate assignment for point A."

한 점의 부호 오차를 발견 → 확률 ≈52% → ≈94%

핵심 질문: 텍스트가 추론 단계의 실제 역할을 담고 있을까?

연구 질문

Q1. CoT 단계 중요도의 적절한 측정 기준은?

어떤 추론 단계가 최종 답변에 실질적으로 기여했는가를 정량화하는 원칙적 방법

Q2. 그 중요도는 텍스트만으로 해독 가능한가?

LLM 심사 모델(judge)이나 파인튜닝된 비평 모델(critic)이 중요 단계를 찾아낼 수 있는가

왜 중요한가? 오류 진단, 충실성 평가, 프로세스 보상 모델(PRM) 등 LLM 심사 모델 활용이 급증하는 상황에서, 이 관행은 "단계 텍스트가 기능적 역할에 대한 정보를 담고 있다"는 가정에 의존

배경: CoT 가독성에 대한 믿음과 의심

가독성에 기반한 활용

  • Gandhi et al.: 단계별 "인지 행동" 분류
  • Zhang et al.: LLM-as-a-Judge로 담화 속성 기반 단계 범주화
  • Xiong et al.: 단계별 보상 모델링을 추론 과제로 재정의

충실성에 대한 회의론

  • 프롬프트 내 "힌트"를 사용하면서도 CoT에는 언급하지 않음 (Turpin et al.)
  • CoT는 "외부화된 계산 상태"일 수 있음 (Levy et al.)
  • 답을 이미 확정한 후에도 토큰 생성 지속 — "연기적(performative)" CoT

기존 충실성 연구는 응답 수준에 머물렀다 → 개별 추론 단계 수준의 분석이 부재

방법 ①: 중요도를 Advantage(이득)로 정의

추론 과정을 문자열 위의 순차적 의사결정 과정으로 형식화

1
Prefix 재표본추출
각 단계 t의 prefix에서 Monte Carlo rollout으로 이어지는 추론을 재생성
2
가치 추정
원래 최종 답변과 일치할 확률을 추정 → 단계별 value
3
Advantage 계산
해당 단계를 포함함으로써 기대 보상이 얼마나 개선되는지 측정
"단계의 중요도 = 이 단계를 추가하는 것이 최종 답변의 가능성을 얼마나 높이는가" — RL에서의 advantage 개념

방법 ②: Changepoint 기반 중요 단계 식별

가치 궤적(value trajectory)에서 실질적 변화가 있는 단계를 라벨링

1
PELT 분할
정확한 이항 비용으로 가치 궤적을 조각별 상수(piecewise-constant) 구간으로 분할
2
페널티 보정
과도한 분할을 방지하도록 페널티를 데이터에 맞게 조정
3
효과 크기 필터
Beta 사후분포로 변화 크기가 충분히 크고 지속적인지 검증
4
라벨 부여
핵심(consequential) vs 무정보(uninformative) 단계 라벨링

단순 단계별 가설검정보다 시뮬레이션에서 검출력-오류 균형이 우수하며, 실제 데이터에서도 분할-반복(split-half) 검증으로 안정성 확인

Advantage가 밝혀낸 추론 행동

  • 중요 단계는 드물다 — 대부분의 추론 단계는 답변 가능성을 실질적으로 바꾸지 않음
  • 불확실성 관리 단계(예: "wait", 재검토)가 정답 응답에서 중요한 역할 — thinking / non-thinking 모델 모두에서 관찰
  • 스케일과 thinking 모드의 성능 향상은 추론 과정 중 답을 "발견"해서가 아니라, 첫 단계 이전의 강한 사전 확신에서 비롯됨

기존 충실성 검사와의 보완 관계

큐 기반 perturbation 검사
프롬프트를 수정해야 하므로 제한적이거나 부자연스러운 상황만 탐색

Self-advantage 분석
프롬프트 수정 없이 자연스러운 샘플에서 측정 → 상호 보완적 신호 제공

텍스트만으로 Advantage를 예측할 수 있을까?

다양한 생성기 모델 × 데이터셋 × 프롬프팅 전략에서 평가

Zero-shot LLM Judge

프롬프트만으로 중요 단계를 식별하도록 지시 · 다양한 모델 크기 · few-shot 등 프롬프팅 전략 비교

Fine-tuned Critic

Monte Carlo advantage 라벨로 단계 수준 비평 모델을 직접 파인튜닝

평가 기준: prevalence baseline(다수 클래스 비율) vs noise ceiling(라벨 노이즈를 고려한 이론적 상한)

결과: 중요도는 텍스트에서 부분적으로만 회복 가능

모델 / 조건결과해석
Zero-shot Judge 모델 크기가 커질수록 prevalence baseline은 넘어섬 그러나 noise ceiling에는 크게 미달
Critic (오답 응답) zero-shot 대비 큰 폭 향상 noise ceiling에 근접
Critic (정답 응답) 해독 가능한 신호 중 일부만 회복 ceiling에서 크게 멈
비대칭성: 오답 응답에서는 중요 단계를 잘 찾지만, 정답 응답에서는 못함 — 이 경향은 생성기 크기와 추론 스타일(thinking 여부) 전반에서 일관됨

시사점: 가독성 ≠ 해석가능성

과잉 해석 경계

CoT 텍스트가 읽히기 쉽다고 해서 모델의 실제 계산을 반영하는 것은 아님 — 단계 텍스트는 기능적 중요도에 대한 불완전한 신호

프로세스 보상 모델링에의 함의

텍스트 기반 단계 감독은 실제로 중요한 단계를 놓치거나 잘못 보상할 수 있음 — 특히 정답 응답에서 그렇음

해석가능성과 RL의 연결

Advantage는 프롬프트 수정 없이 측정 가능한 원칙적 중요도 척도로, 해석가능성 연구와 강화학습 기반 추론 최적화를 잇는 다리 역할

결론

  • CoT 단계 중요도를 advantage로 조작화하고, changepoint 분석으로 핵심 단계 vs 무정보 단계를 식별하는 방법 제안
  • 핵심 단계는 드물며, 불확실성 관리 단계가 정답 응답에서 중요 · 스케일/thinking의 이득은 강한 사전 확신에서 기인
  • 충분히 큰 LLM judge는 baseline을 넘지만 ceiling에 크게 미달 · 파인튜닝 critic은 오답에서는 강하지만 정답 응답에서는 신호의 일부만 회복
  • 단계 중요도는 CoT 텍스트만으로 완전히 해독될 수 없음 — 추론 흔적의 가독성을 해석가능성으로 취급하는 데 대한 경고
