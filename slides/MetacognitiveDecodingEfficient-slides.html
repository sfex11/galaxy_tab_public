Metacognitive Decoding

확산 언어 에이전트를 위한 효율적 추론

Mingyu Zhao† · Shuhang Lin† · Ligong Han · Xiaojing Yu · Zhenting Wang · Yifei Pang · Yang Zhou · Dimitris N. Metaxas

Rutgers University · UNC Chapel Hill · Amazon

평균 FLOPs 20.6% 절감 확산 언어 에이전트 경량 플러그인 컨트롤러

배경: 확산 언어 모델과 에이전트

확산 언어 모델

여러 토큰 위치를 병렬로 생성하여 효율적인 언어 에이전트의 유망한 기반이 됨 (LLaDA, Block Diffusion 등)

에이전트 상호작용

과제 추론 → 도구 호출 → 환경 관찰 → 이어서 생성. 각 응답은 진행 중인 상호작용의 일부

상호작용이 진행됨에 따라 에이전트가 생성해야 할 내용이 계속 달라집니다. 따라서 핵심 과제는 확산 생성을 에이전틱 추론과 상호작용의 동적 요구에 적응시키는 것입니다.

문제: 경직된 디코딩이 만드는 계산 중복

기존 디코딩 방식과 고도로 구조화된 에이전트 궤적의 불일치가 병목

비효율 1

모든 토큰을 똑같이 취급

  • 출력은 예측 가능한 포맷(API 템플릿)과 복잡한 추론의 혼합
  • 쉬운 토큰은 불필요하게 과잉 처리 → 계산 낭비
  • 복잡한 토큰은 너무 일찍 확정 → 오류 유발
비효율 2

실행 경계를 넘는 초과 계산

  • 도구 호출 생성 후에는 환경 피드백 대기 필수
  • 확산 모델은 고정 크기 블록으로 처리
  • 경계 뒤 불필요한 꼬리 토큰까지 계산 후 폐기

고효율을 위해서는 예측 신뢰도와 상호작용 상태 모두에 기반한 동적 디코딩 전략이 필요

핵심 아이디어: 메타인지 컨트롤러

무작정 생성하지 않습니다. 경량 컨트롤러가 상호작용 상태와 예측 신뢰도를 관찰해 두 가지 결정을 조율

어떤 토큰을 확정할까?

Confidence Alignment Decoding — 구조적 세그먼트의 동시 확정 + 토큰별 수용 임계값 적응 조정

몇 개 위치를 계산할까?

Flux Decoding — 능동 계산 범위를 동적으로 축소하고, 필요할 때만 재확장

  • 확산 백본에 결합하는 경량 플러그인 형태의 컨트롤러
  • 에이전트 궤적으로 학습하여 정확성과 생성 비용의 균형을 학습
  • 생성 과정을 에이전트가 수행하는 상호작용 자체와 연결

방법론 ① 백본: Block Diffusion

LLaDA2.0 등의 확산 모델은 응답을 블록 단위로 생성합니다.

1
블록 간 자기회귀
이전 블록이 조건이 되어 다음 블록 생성
2
블록 내 병렬 디노이징
여러 토큰 위치를 동시에 반복 정제
3
토큰 확정
어느 위치를 최종 텍스트로 확정할지 결정

p(𝐱 | 𝐜) = ∏k=1..K p(𝐱(k) | 𝐜, 𝐱(<k))  —  쿼리·상호작용 이력 𝐜가 주어지면 응답 𝐱를 K개 블록으로 분해해 생성

가변 길이 시퀀스를 지원하지만, 어디에 얼마만큼 계산을 쓸지는 여전히 디코딩 정책의 몫

방법론 ② 컨트롤러: 모니터링 → 제어

Monitoring

상태 관찰

  • 백본의 토큰별 예측 신뢰도 확인
  • 도구 호출 여부 등 에이전트 상호작용 상태 확인
Controlling

디코딩 최적화

  • 각 단계에서 cascaded 정책을 적용
  • 토큰 확정과 계산 범위를 동시에 조율

계산은 필요한 곳에만 집중되어, 도구 호출이 트리거되는 순간 생성을 즉시 멈추고 효율적으로 종료합니다.

방법론 ③ Cascade 1: Confidence Alignment

토큰 수용(acceptance)을 관리하는 정책

구조적 세그먼트 동시 확정

표준 도구 호출 포맷처럼 높은 예측 가능성을 가진 구조를 식별해 한 번에 최종 확정

토큰별 임계값 적응 조정

개별 토큰의 수용 임계값을 적응적으로 조절해 확정 시점을 세밀하게 제어

  • 쉬운 포맷 토큰의 과잉 처리 제거 → 계산 절약
  • 복잡한 추론 토큰의 조기 확정 방지 → 정확도 보호

방법론 ④ Cascade 2: Flux Decoding

능동 계산 범위(active computation range)를 최적화하는 정책

1
범위 축소
불필요한 하류 위치를 계산 대상에서 제외
2
필요 시 재확장
응답이 더 많은 공간을 요구할 때만 범위 확대
3
낭비 제거
도구 호출 경계 뒤 꼬리 위치의 폐기 계산 방지
  • 복구 가능한 빈 토큰(recoverable empty tokens)을 활용해 범위를 되돌릴 수 있게 설계
  • 고정 블록 방식의 "경계 너머 계산 후 폐기" 문제를 근본적으로 해소

방법론 ⑤ 컨트롤러 학습

궤적 수준 보상

정답 정확성(correctness)과 생성 비용(generation cost)을 함께 고려한 궤적 단위 보상으로 학습 신호 구성

컨트롤러 최적화

실제 에이전트 궤적에서 컨트롤러를 학습시켜 백본의 생성 방식과 상호작용 요구를 정렬

이 접근은 에이전트의 생성 프로세스와 그 생성이 serve하는 상호작용을 연결합니다 — 확산 디코딩이 상호작용의 맥락을 인식하게 됩니다.

실험 설정

데이터·환경

5개 벤치마크의 에이전트 상호작용 환경에서 평가

베이스라인

① 일반 확산 모델 ② 태스크 특화 모델 ③ 디코딩 가속 기법

평가 지표

추론 FLOPs(효율) + 태스크 정확도(품질)

  • 다양한 백본에서의 일반화 성능도 추가 검증
  • 실제 상호작용 흐름 속에서 컨트롤러 동작을 보여주는 케이스 스터디 포함

주요 결과

20.6%

가장 효율적인 베이스라인 대비 추론 FLOPs 평균 20.6% 추가 감소하면서도, 경쟁력 있는 태스크 정확도를 유지

일반 확산 모델 대비
정확도 손실 없이 효율 대폭 개선

태스크 특화 모델 대비
범용 방식으로 경쟁력 있는 성능

디코딩 가속 기법 대비
모든 축에서 FLOPs 절감 우위

절제 연구와 추가 분석

구성 요소별 기여

Confidence Alignment와 Flux Decoding을 개별 제거하며 각 메커니즘의 독립적 기여를 확인 — 메타인지 제어 전체의 유효성 입증

정확도–효율 트레이드오프

계산량 절감 수준을 달라지게 하며 분석 — 기존 기법 대비 파레토 우위의 트레이드오프 곡선 달성

  • 다른 백본에 적용해도 효과가 유지되어 백본 독립성 확인
  • 케이스 스터디: 상호작용 중 컨트롤러가 확정 시점과 계산 범위를 실제로 조율하는 모습 관찰

결론

  • 병목 규명 — 확산 언어 에이전트는 경직된 디코딩으로 인해 낮은 토큰 효율에 시달림 (균일 처리 + 경계 초과 계산)
  • 메타인지 컨트롤러 제안 — 예측 신뢰도와 상호작용 상태를 모니터링하고, Confidence Alignment(구조 확정·수용 제어)와 Flux(계산 범위 조정)의 cascaded 정책으로 디코딩 제어
  • 실증 검증 — 5개 벤치마크에서 평균 20.6% FLOPs 절감 + 경쟁력 있는 정확도, 절제 연구로 유효성 입증

생성 어디에 계산을 쓸지와 얼마나 생성할지를 상호작용에 맞춰 결정하는 것 — 그것이 효율적인 확산 언어 에이전트의 열쇠입니다.
