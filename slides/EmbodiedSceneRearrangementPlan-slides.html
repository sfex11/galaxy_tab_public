Embodied Scene
Rearrangement Planning

3D 실내 환경에서 에이전트가 자기중심적 관찰과 타겟 레이아웃만을 이용해 가구를 재배치하는 새로운 과제

Canzhi Chen · Zan Wang · Siqi Zhu · Qi Wu · Yixuan Li · Wei Liang

Beijing Institute of Technology

기존 연구의 한계

테이블탑 재배치

  • 로봇 매니퓰레이터로 소형 물체 이동
  • 제한된 작업 공간에 국한
  • 장거리 내비게이션 불필요

실내 전체 수준의 재배치 불가

2D 평면 재배치

  • 장면 수준의 객체 재배치
  • 2D 평면으로 환경 단순화
  • 전역 관찰 접근 가능

3D 공간적 제약 무시 → 실제 배치 불가

"기존 연구와 실제 가구 재배치 수요 사이에 큰 간극이 존재한다"

ESRP: 세 가지 핵심 과제

1

부분 관측 가능성

에이전트는 1인칭 시점만 의존하므로, 부분적인 관찰을 전역 타겟 레이아웃과 정렬해야 함

2

객체 간 의존성

대형 가구 조작으로 인한 장기horizon 계획 필요, 물리적 교착 상태와 상호 가림 회피 필수

3

동적 장면 변화

재배치 과정에서 3D 장면이 동적으로 변화하며, 비정상 환경에서의 지각·위치추정·내비게이션 요구

핵심 차별점: 전역 상태 접근 불가 + 상호 객체 가림 현상 → 실제 로봇 배포 제약 반영

ESRP 과제 개요

1
초기 장면
3D 실내 환경의 현재 가구 배치 (빨간색)
2
타겟 레이아웃
Top-down 관점의 목표 배치 이미지 (초록색)
3
에이전트 관찰
에고센트릭 RGB + 타겟 이미지 + 파지 상태
4
재배치 실행
내비게이션 + 파지/배치 행동 시퀀스

금지된 정보

전역 상태 정보, Ground-truth 위치, 3D 모델 접근

성공 조건

모든 이동 가능 객체가 목표 위치에 정확히 배치됨

ESRP-Bench: 벤치마크 개요

5,400+

초기-타겟 장면 쌍

8,200+

이동 가능 가구 객체

3D-FRONT

데이터셋 기반

시뮬레이션 환경

OmniGibson 기반으로 구축된 완전히 가구가 배치된 실내 3D 환경

다양한 공간 유형

침실, 서재, 거실 등 다양한 방 유형과 의자, 테이블, 식물 등 다양한 가구 범주 포함

각 시나리오 구성: (i) 초기 장면 레이아웃 · (ii) Top-down 타겟 레이아웃 이미지 · (iii) 전문가 데모 궤적

난이도 수준 분류

난이도 재배치 객체 수 특징
Easy 1개 단일 객체 이동, 의존성 없음
Medium 2~3개 다중 객체 간 순서 추론 필요
Hard 4~6개 복잡한 상호 가림 및 교착 상태 위험

관찰 공간과 행동 공간

관찰 (Observations)

  • 에고센트릭 RGB 이미지 (128×128)
  • Top-down 타겟 레이아웃 (128×128)
  • 파지 상태 이진 지시자 g ∈ {0, 1}

행동 (Actions)

  • 내비게이션: 전진, 후진, 좌회전, 우회전
  • 조작: 파지(fetch), 배치(release)
  • 이산적 모션 프리미티브 기반

다중 수준 평가 지표

1

객체 수준 지표 (Object-Level)

개별 객체의 목표 위치 도달 여부 평가

2

장면 수준 지표 (Scene-Level)

전체 장면의 재배치 완성도 종합 평가

3

효율성 지표 (Efficiency)

재배치 완료에 소요된 스텝 수 및 경로 효율성

세 수준의 지표는 단순한 성공/실패를 넘어, 재배치 품질의 다각적 분석을 가능하게 함

베이스라인 방법론: 학습 기반

Imitation Learning (IL)

Behavior Cloning + Diffusion Policy

  • 전문가 데모 궤적으로 학습
  • Diffusion Policy 기반 행동 시퀀스 예측
  • 시각 관찰과 그리퍼 상태 조건부 반복적 노이즈 제거
Reinforcement Learning (RL)

PPO + Vision LSTM

  • PPO 알고리즘으로 정책 학습
  • 비전 인코더 + 단일 LSTM 층으로 시간 기억 유지
  • 에고센트릭 관찰의 시계열 처리

두 방법 모두 에고센트릭 관찰과 Top-down 타겟 레이아웃을 공통 입력으로 사용

베이스라인 방법론: VLM & TAMP

Foundation Model

ESRP-VLM (Multimodal ReAct)

  • 사전 학습된 VLM 기반 다중모달 ReAct 에이전트
  • In-context 프롬프팅만으로 ESRP 전이 시도
  • 범용 사전지식의 재배치 과제 전이 가능성 검증

추가 파인튜닝 없이 제로샷 평가

Planning-based

ESRP-PLAN (Hierarchical TAMP)

  • 계층적 TAMP 프레임워크
  • 상위: 최적 재배치 순서 결정 (Task Planner)
  • 하위: 충돌 없는 경로 계산 (Motion Planner)

특권 정보(전역 상태) 활용 — 상한선 성능 참고용

실험 결과

방법론 패러다임 성공률 Hard 난이도
ESRP-PLAN (TAMP) Planning 30.20% 거의 0%
IL (Diffusion Policy) Learning 낮음 거의 0%
RL (PPO + LSTM) Learning 낮음 거의 0%
ESRP-VLM (ReAct) Foundation 매우 낮음 0%

"최강 베이스라인조차 30.20% 성공률에 그치며, 복잡 시나리오에서는 거의 0%에 달한다"

논의: 각 패러다임의 한계

학습 기반 (IL / RL)

  • 부분 관측에서 장기horizon 의존성 학습 곤란
  • 데모 커버리지 부족으로 IL 성능 저하
  • RL은 희소 보상으로 수렴 어려움

VLM 기반

  • 공간 추론 능력 부족
  • 행동 공간 이해 한계
  • 제로샷만으로는 복잡한 재배치 불가

TAMP 기반 (ESRP-PLAN)

  • 특권 정보(전역 상태) 사용으로 가장 높은 성능 달성
  • 그럼에도 30% 대 성공률 — 3D 공간 추론 복잡도에 직면
  • 객체 수 증가 시 계층적 분해 한계 노출

핵심 시사점 및 향후 방향

핵심 시사점

  • ESRP는 장면 이해와 장기horizon 계획의 새로운 프론티어
  • 기존 패러다임 각각이 독특한 한계를 보유
  • 부분 관측 + 3D 공간 추론의 결합이 핵심 난관
  • 단순히 더 큰 모델로 해결되지 않는 문제

향후 연구 방향

  • 부분 관측을 위한 강건한 장면 표현 학습
  • 객체 간 의존성 추론을 위한 계획 아키텍처
  • 학습 기반과 계획 기반의 하이브리드 접근
  • 실제 로봇 환경으로의 시뮬→리얼 전이

"본 연구는 실제 시나리오에 지능형 에이전트를 배포하기 위한 출발점이다"
