과학 시설을 위한 교정형 에이전트 하이브리드 RAG 및 운영 기반 평가

A Corrective Agentic Hybrid RAG and an Operations-Grounded Evaluation for a Scientific Facility
Rajat Sainju, Dariusz Jarosz, Hairong Shang, Michael Prince, Ryan M. Aydelott,
Mathew J. Cherukara, Yine Sun, Michael Borland
Advanced Photon Source, Argonne National Laboratory

문제 정의: 파편화된 운영 지식

대규모 과학 사용자 시설은 수십 년간 운영 지식을 축적하지만, 단일 검색 인덱스로는 전체를 덮을 수 없습니다.
기록 기반
전자 로그북, 기술 문서, 내부 위키, 정책 문서, 유지보수 기록
소통 기반
운영 채팅 메시지, 다운타임 기록, 그룹별 전문 지식
실시간 기반
제어 시스템 프로세스 변수(PV), EPICS 아카이버 실시간 데이터
빔 손실 사건: 로그북에 기록 → 유지보수 요청은 며칠 전에 접수 → 해결책은 위키에 존재 → 사양은 ICMS에 → 관련 셋포인트는 EPICS 라이브 데이터에 — 하나의 질문에 5개의 시스템 필요

APS-RAG: 시스템 개요

APS(Advanced Photon Source)의 분산된 운영 기록을 자연어 질문 하나로 접근 가능하게 하는 배포된 플랫폼
  • 9개 데이터 소스 통합 (8개 인덱스 + EPICS 실시간)
  • 일일 diff-and-upsert 파이프라인으로 데이터 신선도 유지
  • Dense + Sparse + Knowledge Graph 하이브리드 검색
  • 쿼리 유형 적응형 RRF(Reciprocal Rank Fusion)
  • 교정형 에이전트 루프(Corrective Agentic Loop)
  • MCP(Model Context Protocol) 툴링 레이어
Fast 모드 빠른 응답, 기본 검색
Thinking 모드 교정형 에이전트 루프 활성화
AI Troubleshoot 지식 그래프 기반 장애 해결

데이터 수집 및 인덱싱

1
소스별 스키마
각 데이터 소스에 맞춤 파싱 스키마 적용
2
일일 Diff & Upsert
매일 변경분만 감지하여 인덱스 갱신
3
부모-자식 인덱싱
문서-청크 계층 구조 유지
4
임베딩 생성
청크 단위 밀집 벡터 임베딩
핵심 설계: 전체 재인덱싱이 아닌 증분 업데이트로 데이터 신선도를 보장하면서 연산 비용 최소화. 부모-자식 관계를 유지하여 검색 시 문맥 복원 가능.

적응형 3-way 검색 융합

Dense 검색
DPR(Dense Passage Retrieval) 기반 의미적 유사도 검색. 자연어 질의의 의도를 파악하는 데 강점.
Sparse 검색
BM25 기반 키워드 매칭. 부품 번호, 고유 명칭 등 정확한 용어 검색에 필수적.
KG 검색
장애 해결 지식 그래프 기반. 증상-원인-해결의 연쇄적 탐색에 특화.
쿼리 유형 적응형 RRF: 세 채널의 순위를 고정된 가중치가 아닌, 질의 유형(사실형, 원인 분석형, 장애 해결형 등)에 따라 동적으로 가중치를 조정하여 융합. 단일 융합 방식보다 유연한 검색 결과 달성.

교정형 에이전트 루프와 자기 비판 게이트

1
초기 검색
3-way 하이브리드 검색 실행
2
답변 생성
검색 결과 기반 임시 답변
3
자기 비판
Self-Critique Gate가 답변 품질 평가
4
교정 또는 통과
불충분 시 쿼리 재작성 후 재검색
  • Corrective RAG(Yan et al., 2024) 패러다임 기반: 검색 결과가 불충분할 경우 자동으로 쿼리를 재작성
  • Self-Critique Gate: 답변의 충실성과 완전성을 스스로 평가하여 추가 검색 여부 결정
  • 지식 그래프 그라운딩 트리거: 특정 패턴 감지 시 KG 채널 우선 활성화

장애 해결 지식 그래프

운영 시설의 장애 해결 워크플로우를 그래프 구조로 모델링하여, 증상에서 해결책까지의 경로를 탐색 가능하게 함.
그래프 구조
증상(Symptom) 노드
원인(Cause) 노드
해결(Resolution) 노드
하위 시스템(Subsytem) 노드
활용 예: "킥커(kicker) 불발이 발생했을 때, 과거 3회의 동일 증상 해결 경로를 어떻게 찾는가?"
그래프 검색은 구조적 관계 탐색에 강점이 있지만, 구축 및 유지보수 비용이 발생하며, 일반적인 사실형 질의에서는 효과가 제한적임.

MCP 툴링 레이어와 Native-Tool ReAct

Model Context Protocol(MCP) 기반으로 검색 문서와 실시간 시설 데이터를 결합하고, 통계 질의에 대한 코드 생성까지 수행.
ReAct 실행기 구조
  • Thought-Action-Observation 순환
  • 검색 도구 호출 → 문서 조회
  • EPICS 아카이버 도구 → 실시간 PV 조회
  • 코드 실행 도구 → 통계 계산
  • 계획 우선, 도구 경계 제한 설계 철학
예시 질의: "2026년에 킥커에 대해 접수된 워크 리퀘스트는 몇 건인가?"
이 질의는 단순 문서 검색으로는 답할 수 없음. ReAct 실행기가 EPICS 아카이버 및 유지보수 DB에 코드를 생성하여 실행하고, 결과를 자연어 답변으로 합성.

APS-Bench: 운영 기반 벤치마크

InPars 방식을 차용하여 운영 코퍼스에서 자동 생성한 50개 QA 쌍과 감사 가능한(auditable) 골드 답변
1
시드 발견
코퍼스에서 핵심 패시지 샘플링
2
QA 생성
유형 조건부 질문-답변 생성
3
난이도 분류
구조 기반 난이도 할당
4
과생성 & 필터링
품질 기준으로 선별
5
너겟 주석
핵심 정보 단위 표시
모든 질문은 출처(Provenance) 추적 가능하며, 편향(Bias)에 대한 명시적 기록 포함. 다른 시설에서의 재현 및 도입을 지원하기 위해 구축 방법론 공개.

6계층 평가 체계

단순한 리콜 지표를 넘어, 다각도의 자동화된 평가 프레임워크를 구축
계층 1
너겟 리콜 (Nugget Recall)
AutoNuggetizer 기반 핵심 정보 단위 회수율
계층 2
엄밀한 필수 너겟 리콜
가장 엄격한 기준, 본 논문의 주요 지표
계층 3
충실성 (Faithfulness)
FaithJudge 스타일 클레임 수준 평가
계층 4
HHEM-2.1 백스톱
환각 검출을 위한 안전망
계층 5
RAGAS 스타일 프록시
관련성, 완전성 등 보조 지표
계층 6
정합성 매트릭스
EM, F1, Accuracy 포함

주요 결과: 답변 품질

모든 RAG 변형이 순진한 BM25 베이스라인을 수치적으로 상회
시스템 구성 엄밀한 필수 너겟 리콜 비고
BM25 베이스라인 63.8% 기준점
Dense + Sparse + RRF 65.5% +1.7%p
+ Cross-Encoder Reranker 70.3% +6.5%p, 가장 큰 기여
+ KG 채널 + 교정 루프 (전체) 70.3% 한계적 추가 기여
Cross-Encoder Reranker 제거 시 엄밀한 필수 리콜이 32.8%p 하락 (95% CI [−47.4, −19.1], p < 10⁻⁴). LLM이 직접 관련성을 평가하게 하면 성능이 급감함.

구성 요소 소거 분석(Ablation)

핵심 발견
  • Cross-Encoder Reranker가 답변 품질에 가장 큰 기여 — 제거 시 리콜 32.8%p 하락
  • KG 채널은 장애 해결형 질의에서는 도움이 되지만, 전체 성능 향상은 한계적
  • 교정 루프는 기대대로 긍정적 기여지만, 마진은 작음
  • 임베딩 모델 변경은 재랭커만큼의 영향 없음
LLM 합성 비교
오픈소스 LLM과 폐쇄소스 LLM을 최종 답변 합성 단계에서 비교. 검색 품질이 이미 결정적이므로, 합성 모델 간 차이는 재랭커 효과보다 작음.
시사점: RAG 시스템에서 검색 및 재랭킹 품질이 합성 모델 선택보다 훨씬 중요하다는 실증적 증거.

한계점

본 연구가 인정하는 주요 한계와 향후 개선 방향
벤치마크 규모
APS-Bench은 50문항으로, 통계적 유의성 검정에는 충분하지만 대규모 벤치마크로는 제한적.
KG의 한계적 기여
지식 그래프와 교정 루프는 긍정적이나 마진이 작아, 구축 비용 대비 효과에 대한 재평가 필요.
단일 시설 한정
APS에 특화된 구현으로, 다른 시설로의 전이 가능성은 방법론 수준에서만 검증됨.
사용자 연구 부재
2개월 배포 기간의 사용량(일평균 8건)은 초기 채택 단계이며, 체계적인 사용자 만족도 조사 미수행.

결론 및 공헌

APS-RAG는 신뢰 가능하고 통계적으로 기반된 AI 보조 운영을 위한 유망한 워크플로우를 제시합니다.
주요 공헌
  • 9개 데이터 소스를 통합한 실제 배포 플랫폼
  • Dense + Sparse + KG 적응형 3-way 융합
  • 교정형 에이전트 루프 + MCP 툴링 레이어
  • 운영 데이터 기반 APS-Bench 및 6계층 평가
  • 재랭커가 합성 모델보다 결정적이라는 실증적 발견
  • 코드, 벤치마크, 방법론 전체 공개
"다른 대형 과학 기기로의 전이 가능한, 신뢰할 수 있고 통계적으로 기반된 AI 보조 운영을 위한 유망한 워크플로우"
