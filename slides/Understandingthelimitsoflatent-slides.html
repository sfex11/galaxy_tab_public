잠재 세계 모델의 한계 이해하기

Rodrigo Gonzalez Laiz & Steffen Schneider

Helmholtz Munich · Munich Center for Machine Learning (MCML)

arXiv:2610.37588v1

배경: 세계 모델은 꼭 "세계"를 모델링하는가?

기대되는 역할

  • 일반 에이전트가 긴 시간·공간 범위에서 추론하려면 세계 모델이 핵심 구성 요소
  • 행동에 따라 환경이 어떻게 변화하는지 예측할 수 있어야 함

현실의 평가 방식

  • 잠재 세계 모델은 주로 과제 보상(task reward)으로 평가됨
  • 보상은 에이전트의 성공 여부만 알려줄 뿐, 학습된 잠재 동역학이 환경의 구조를 포착했는지는 알려주지 않음

핵심 연구 질문

"성공적인 잠재 세계 모델은 실제로 환경을 모델링하는 표현과 동역학을 학습하고 있는가?"

Do successful latent world models actually learn representations and dynamics that model their environment?

이를 정량적으로 답하기 위해 충실한(faithful) 잠재 세계 모델 개념과 잠재 롤아웃 일관성(LRC) 지표를 제시

문제 정식화: 환경과 세계 모델

환경 (부분 관측 제어 동역학계)

sₜ₊₁ = f(sₜ, aₜ)

xₜ = g(sₜ)

sₜ: 관측되지 않는 상태, aₜ: 행동, xₜ: 관측
g: 믹싱 함수(mixing function) — 상태의 비선형 뷰일 수 있음

잠재 세계 모델의 두 역할

zₜ = h(x≤ₜ, a<ₜ)

ẑₜ₊₁ = f̂(zₜ, aₜ)

① 관측에서 잠재 표현 추론 ("demixing")
② 행동 조건부 잠재 동역학 모델링

1
관측
xₜ = g(sₜ)
2
인코딩
h로 잠재 zₜ 추론
3
예측
f̂로 ẑₜ₊₁ 계산

정의: 충실한(Faithful) 잠재 세계 모델

상태→잠재 사상 r ≔ h∘g : S → Z 를 기준으로 두 조건 제시

① 동역학 등변성 (Dynamics Equivariance)

f̂(r(s), a) = r(f(s, a))

실제 전이 후 인코딩한 결과와, 잠재 공간에서의 예측이 일치해야 함 — 롤아웃이 환경의 동역학을 따름

② 상태 충분성 (State Sufficiency)

r 은 단사(injective)

관측으로부터 상태의 모든 정보를 복원해야 함 — 과제에 무관하게 동일한 세계 모델을 다양한 과제에 사용 가능

MDP 준동형사상(MDP homomorphism), 인과 추상화의 일관성 조건과 관련 — 그러나 이들과 달리 정보 손실을 허용하지 않고 전체 상태 보존을 요구

평가 지표: LRC와 상태 디코딩

잠재 롤아웃 일관성 (Latent Rollout Consistency, LRC)

LRC(H) = R²( h(x≤H, a<H), ẑH )

자기회귀적 잠재 예측 ẑH 와 실제 관측 궤적에서 추론한 잠재 표현을 비교

충실한 모델은 모든 horizon에서 LRC = 100%

주의: LRC만으로는 불충분

표현이 붕괴(collapse)되면 잠재가 예측하기 쉬워져 LRC가 높아질 수 있음

보완: 사후 상태 디코딩

잠재 표현에서 실제 상태를 얼마나 복원할 수 있는지 측정 → 단사성(injectivity) 검증

실험 설정

평가 대상 SOTA 모델

  • DreamerV3 — 재구성 기반 세계 모델
  • TD-MPC2 — 보상 기반 모델
  • LeWM — 잠재 세계 모델

환경: 의도적으로 단순한 3가지

  • Pendulum · CartPole · Reacher
  • 저차원이고 명확히 정의된 동역학 → 세계 모델링의 최소 테스트 케이스

이렇게 통제된 설정에서의 실패는 반례(counterexample)가 되며, 실패 메커니즘을 분리해 분석할 수 있게 해준다.

핵심 발견 1 과제 성능 ≠ 정확한 잠재 예측

연구된 SOTA 잠재 세계 모델 중 어떤 모델도 환경의 동역학을 충실하게 모델링하여 과제를 해결하지 않았다.

보상이 말해주는 것

에이전트 전체가 과제를 수행했는지 여부

보상이 말해주지 않는 것

학습된 잠재 동역학이 환경 동역학을 정확히 포착했는지, 물리 상태를 보존했는지

LRC와 상태 디코딩은 이러한 실패를 직접적으로 노출하는 진단 도구

핵심 발견 2 픽셀 관측은 잠재 예측을 저하시킨다

같은 환경에서 관측 형태만 바꿔 비교 — 상태(state) 관측 vs 픽셀(pixel) 관측

관측 형태잠재 예측 (LRC)해석
상태 관측 (저차원)양호환경 동역학에 대한 예측이 비교적 잘 유지됨
픽셀 관측 (이미지)저하잠재 롤아웃 일관성이 크게 떨어짐 — 상태 관측 대비 뚜렷한 격차 발생

픽셀에서의 성공적 과제 수행이 곧 좋은 세계 모델을 의미하지는 않음

핵심 발견 3 속도(velocity) 정보의 부재

픽셀 관측에서 부정확한 속도 추정이 픽셀–상태 간 격차의 상당 부분을 설명

왜 속도가 문제인가

  • 상태 관측에는 속도가 직접 포함되어 있음
  • 픽셀에서는 속도가 관측되지 않아 인코더가 추정해야 함
  • 동역학 예측에 필수적인 속도가 부정확하면 롤아웃 오차가 누적

검증 방법: 통제된 개입

  • 속도 가시성(observability)을 통제하는 실험 설계
  • 속도가 관측 가능해지면 격차가 줄어드는지 확인

핵심 발견 4 비선형 관측 매핑을 통한 동역학 학습의 어려움

믹싱 함수 g에 해당하는 비선형 관측 매핑을 통과한 관측으로부터 잠재 동역학을 학습하기 어려움

1
상태 s
명확한 동역학 존재
2
비선형 믹싱 g
관측 x = g(s)
3
동역학 학습 실패
demixing과 예측을 동시에 학습해야 하는 부담

비선형 상태 믹싱 통제 실험을 통해 표현 학습(h)과 동역학 학습(f̂)이 결합된 문제임을 분리해 확인

종합: 두 가지 주요 메시지

1

과제 보상만으로는 세계 모델이 정확한 잠재 동역학을 학습했는지, 근본 물리 상태를 보존했는지 알 수 없다 — LRC와 상태 디코딩이 이를 직접 드러낸다.

2

픽셀 관측 하에서 두 가지 반복적인 실패 모드가 나타난다 — ① 부정확한 속도 추정, ② 비선형 관측 매핑을 통한 동역학 학습의 어려움.

더 충실한(faithful) 세계 모델을 만들기 위해서는 학습된 표현과 잠재 동역학 양쪽의 개선이 모두 핵심이다.

결론

SOTA 잠재 세계 모델조차 단순한 환경에서 환경 동역학을 충실하게 모델링하지 못한다는 반례 제시

등변성 조건 + LRC + 상태 디코딩이라는 진단 프레임워크로 세계 모델 평가의 새로운 기준 제안
