환경 합성이 '무엇이든 환경이 될 수 있다'는 가능성 실증을 넘어 '무엇을 얼마나 구성해야 하는가'의 스케일링 법칙 발견 단계로 진화했으며, 환경 구성 다양성이 모델·데이터에 버금가는 제3의 스케일링 축임을 입증한다.

## 📖 분석

## Scaling Laws for Tool-Use Agents via Controllable Environment Synthesis (2026-10-29)

SynthAPI 파이프라인은 합성 도구 사용 환경의 다양성을 **도구·태스크·데이터베이스**라는 명시적 축으로 제어 가능하게 만들고, 458개 설정의 체계적 변이를 통해 환경 구성이 에이전트 훈련에 미치는 스케일링 법칙을 확립한다.

이 논문은 [[agent-environment-generation]]의 위상을 전환한다. Gym-Anything이 '모든 소프트웨어가 환경이 될 수 있다'는 가능성을 보였다면, 본 논문은 환경 생성 구성 자체를 통제된 실험의 독립 변수로 격상시켜 환경 합성이 경험적 기술이 아니라 예측 가능한 과학임을 입증한다. [[environment-supply-scaling]] 관점에서 공급량이 아닌 공급 구조가 학습 효율의 핵심임을 정량화한다.

[[environment-diversity-layered-guarantee]]에 도구·태스크·데이터 3축 분해를 제공하여 '무엇이 다양해야 하는가'를 조작 가능한 변수로 만든다. [[implicit-curriculum]]의 환경 수준 버전으로, 구성 비율이 사실상 훈련 커리큘럼임을 드러낸다. [[environment-capability-causality]]의 인과율을 스케일링 법칙으로 형식화하며, [[synthetic-data-generation]]과 [[scaling-laws]]의 교차점에서 환경 구성이라는 제3의 스케일링 축을 연다.
